# 习题测试

顶部可**选择笔记**（C 语言笔记 / Python 数据分析笔记 / Matlab 笔记 / 全部），系统会从对应笔记的题库里随机抽取一组题（含选择题、判断题、填空题、代码题与程序设计题）；作答后点「提交并查看解析」即可判断正误并给出正确答案与解析。其中**程序设计题**会给出程序框架与预期输出，请在空白处逐空填入关键代码，使程序能得出指定结果。作答过程中可随时修改答案、重新作答或换一组题。题库内容由 AI 助手依据各篇笔记自动生成，会随笔记更新而扩充。

> **Matlab 笔记**的题库覆盖全书 14 章，包含矩阵与点运算、流程控制、绘图、数据分析与多项式、数值积分、方程求解、符号计算、句柄图形、GUI、Simulink 与接口等内容，并针对原书（基于 R2016a）中已废弃的函数加入了「修正」类题目（如 `quad` → `integral`、`ezplot` → `fplot`、`GUIDE` → App Designer）。
