# 习题测试

顶部可**选择笔记**（C 语言笔记 / Python 数据分析笔记 / Matlab 笔记 / 税法笔记（CPA） / 会计笔记（CPA） / 全部），系统会从对应笔记的题库里随机抽取一组题。题型包括**单选题、多选题、判断题、填空题、代码题、程序设计题与计算分析题**；作答后点「提交并查看解析」即可判断正误并给出正确答案与解析。其中**程序设计题**会给出程序框架与预期输出，请在空白处逐空填入关键代码；**多选题**可勾选多个选项。作答过程中可随时修改答案、重新作答或换一组题。

> **税法笔记（CPA）**：题库来自《2026 谦达教育税法习题册》及配套答案册，共 **522 道**（单选 291 / 多选 193 / 计算分析 38），覆盖 14 章，答案与解析均为官方原文。**计算分析题**提交后会展示官方参考答案，由你对照自评。
>
> **会计笔记（CPA）**：题库来自《2026 谦达教育会计习题》共 **376 道**（单选 166 / 多选 179 / 计算分析 31），覆盖 30 章。⚠️ 该习题册**未附答案册**，为避免给出未经核实的答案，这些题采用**自评模式**：正常作答、提交后对照《会计笔记》对应章节核对，再点「我答对了 / 我答错了」计入得分。若后续提供官方答案册，可一键切换为自动判分。
>
> **Matlab 笔记**的题库覆盖全书 14 章，包含矩阵与点运算、流程控制、绘图、数据分析与多项式、数值积分、方程求解、符号计算、句柄图形、GUI、Simulink 与接口等内容，并针对原书（基于 R2016a）中已废弃的函数加入了「修正」类题目（如 `quad` → `integral`、`ezplot` → `fplot`、`GUIDE` → App Designer）。
