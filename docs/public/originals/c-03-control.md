# 第3章 流程控制

## 3.1 if 条件语句

**格式**：`if (条件) {代码}`

```c
if (score >= 60) {
    printf("及格\n");
}
```

## 3.2 if-else 语句

**格式**：`if (条件) {代码} else {代码}`

```c
if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

- if-else 可以嵌套（**else 与最近的、还没有 else 配对的 if 配对**）
- 多分支 `else if`：

```c
if (条件1)      { ... }
else if (条件2) { ... }
else if (条件3) { ... }
else            { ... }
```

::: tip 提示
无论分支里只有一行还是多行，都写上 `{ }`。省略大括号时，「悬空 else」和后续插入一行代码的错误非常常见（历史上还造成过真实的重大缺陷）。
:::

## 3.3 switch case 语句

```c
switch (控制表达式) {
    case 常量: 语句; break;
    case 常量: 语句; break;
    default:   语句;
}
```

- `case` 后面的常量可以是常数，也可以是常数计算表达式
- `break` 是这一 case 的终止信号，如果没有 break 则会「穿透」进下一个 case
- `default` 匹配所有未命中的情况

::: danger 订正 · 控制表达式的类型
原笔记写「控制表达式必须是 int 型的」。准确说法是：必须是**整数类型**（integer type），包括 `char`、各种 `short`/`int`/`long`、枚举，以及它们的无符号版本；`float`、`double`、指针、字符串都不行。`case` 标签也必须是**整型常量表达式**，不能是变量或字符串。
:::

::: info 补充 · 有意的穿透要写明
穿透（fallthrough）并不总是错误，比如多个 case 共用一段处理逻辑。为了让读代码的人和静态检查工具知道这是故意的，写一个显式注释；C23 起可以用标准属性 `[[fallthrough]];`：

```c
case 'a':
case 'A':
    count_a++;
    /* fallthrough */
case 'e':
    count_vowel++;
    break;
```
:::

## 3.4 while 循环

**格式**：`while (条件) {循环体}`

```c
int i = 1;
while (i <= 10) {
    printf("%d ", i);
    i++;
}
```

`if` 和 `while` 的区别：`if` 是一次性判断，`while` 是多次循环。

## 3.5 do-while 循环

```c
do {
    <循环体语句>
} while (<循环条件>);
```

和 `while` 的区别：do-while 是先进入循环体再判断条件（**至少执行一次**）；while 是先判断条件才进入循环体。注意结尾的分号不能漏。

## 3.6 for 循环

**格式**：`for (初始动作; 条件; 每轮的动作) {循环体}`

```c
for (i = 1; i <= 10; i++) {
    sum += i;
}
```

- `for` 中的每个表达式都是可以省略的
- `for (; 条件; )` 等价于 `while (条件)`（注意：两个分号不能省）

::: info 补充 · C99 起可在 for 内定义变量
`for (int i = 0; i < 10; i++)` 中的 `i` 作用域只在循环内，能避免变量污染和外部误用，推荐这样写（需 `-std=c99` 或更新）。循环条件里不要用浮点数做相等判断，也不要在循环体内修改循环变量之外的计数状态。
:::

## 3.7 三种循环的选择

| 场景 | 选择 |
| --- | --- |
| 有固定次数 | `for` |
| 必须执行一次 | `do-while` |
| 其他情况 | `while` |

## 3.8 break 与 continue

- `break`：跳出（它所在的）循环
- `continue`：跳过循环这一轮剩下的语句，进入下一轮循环
- `break` 和 `continue` 只能对它所在的那**一层**循环起作用

::: warning 易错点
`while` 里的 `continue` 会直接跳到条件判断，如果递增语句写在 `continue` 之后，就会死循环；`for` 里的 `continue` 会先执行「每轮的动作」再判断条件，行为不同。
:::

## 3.9 嵌套循环与 goto

- 循环可以嵌套：内层循环完整跑完一遍，外层循环才走一步
- `goto` 可以跳到所指标号处（如 `goto out`），常用于多重循环中一次性跳出：

```c
for (...) {
    for (...) {
        if (...) { goto out; }
    }
}
out:
return 0;
```

::: tip 提示
`goto` 只建议用于「多重循环整体跳出」和「统一错误处理、集中释放资源」这类场景，滥用会让程序流程混乱难读。多数情况下把内层逻辑抽成函数再 `return` 更清晰。
:::

## 3.10 随机数 rand()

- `rand()` 返回一个 0 到 `RAND_MAX` 之间的随机整数（需引入 `<stdlib.h>`）
- 配合 `%` 可以得到指定范围的随机数：`rand() % 100` 得到 0 ~ 99
- 默认每次运行序列相同，可配合 `srand(time(0))` 改变随机种子

::: info 补充 · rand() 的三个坑
1. **种子只播一次**：`srand()` 应放在程序开始处，不要放进循环里反复调用，否则连续调用会得到相同序列。
2. **取模有偏**：`RAND_MAX + 1` 通常不能被 100 整除，小的余数出现概率略高。要求均匀时用拒绝采样。
3. **质量不保证**：`rand()` 是实现定义的伪随机算法，不适合密码学、也不适合严肃模拟。需要可复现的高质量随机可用 PCG / xoshiro 等实现，密码学场景用系统提供的安全随机源。
:::

## 3.11 经典循环应用

### 整数的分解

- 取个位数：对整数做 `% 10` 的操作
- 去掉个位数：对整数做 `/ 10` 的操作
- 取十位数：先去掉个位数（`/ 10`），再对得到的结果做 `% 10` 的操作
- 由此类推，可以得到任意位

### 取逆序

```c
#include <stdio.h>

int main() {
    int x;
    scanf("%d", &x);
    int digit;
    int ret = 0;

    while (x > 0) {
        digit = x % 10;
        ret = ret * 10 + digit;
        printf("x=%d, digit=%d, ret=%d\n", x, digit, ret);  /* 调试输出 */
        x /= 10;
    }

    printf("%d", ret);
    return 0;
}
```

::: tip 提示
核心是两句话：`digit = x % 10;` 取出最后一位，`ret = ret * 10 + digit;` 把这一位接到结果尾部。中间那个 `printf` 是调试输出，用来观察每一步的变化。
:::

::: warning 补充 · 边界情况
`x = 0` 时循环一次都不进，输出 `0`（正确）；`x` 为负数时 `x > 0` 直接不成立，需要先取绝对值；末尾有 0 的数（如 1200）逆序后前导零会自然丢失，这是数学上的正确结果，若要求保留位数应改用字符串处理。
:::

### 阶乘

```c
int n;
scanf("%d", &n);
int fact = 1;
int i = 1;

while (i <= n) {
    fact *= i;
    i++;
}

printf("%d!=%d\n", n, fact);
```

::: danger 补充 · 阶乘极易溢出
`12!` 已经超过 32 位 `int`，`20!` 超过 64 位 `unsigned long long`。原笔记用 `int` 只是为了演示循环，实际计算大阶乘要用 `double`（近似）、大整数库，或先检查 `n` 的上限。
:::

### 求和

```c
int i;
int sum;

for (i = 1, sum = 0; i <= 10; i++) {
    sum += i;
}

printf("%d到%d的和是%d\n", 1, 10, sum);
```

::: tip 提示
循环经常要做「计数」和「累加」两件事：计数 `count = 0; count++;`，累加 `sum = 0; sum += x;`，注意**初始值一定是 0**（累加）或 1（累乘）。这类「累加器」就是后面第 4 章把重复代码提取成函数的动机。
:::
