## 本次订正的知识点

正文里每一处都用「订正」框标出并给出理由，这里先集中列一遍：

| 位置 | 原笔记说法 | 订正 |
| --- | --- | --- |
| 2.2 数据类型 | 各类型表达范围「大致」为 `char < short < int < float < double` | 整型与浮点型不能这样串成一条范围链；`float` 的数值范围（约 ±3.4×10³⁸）远大于任何整型。整型内部是 `char ≤ short ≤ int ≤ long ≤ long long`，浮点内部是 `float ≤ double ≤ long double` |
| 1.5 变量 | 未初始化变量里是「内存残留的随机值」 | 读取未初始化的自动变量是**未定义行为**（UB），不只是拿到随机值，编译器可能做任意优化 |
| 1.6 占位符 | `%lf` 用于「实型 double」输出 | `printf` 里 `%lf` 与 `%f` 等价（都接收 `double`，C99 起允许写 `%lf`）；只有 `scanf` 读 `double` 才**必须**用 `%lf`，`%f` 读的是 `float` |
| 2.6 补码 | 「补码和原码可以加出一个溢出的 1」 | 表述含糊。n 位下负数 −x 的补码是 2ⁿ − x，等价于「按位取反再加一」 |
| 3.3 switch | 控制表达式「必须是 int 型」 | 应为**整数类型**（integer type），`char`、各整型、枚举都可以；浮点、指针、字符串不行 |
| 5.3 数组 | `int a[0];` 可以存在 | 标准 C 要求数组长度大于 0；零长数组是 GCC/Clang 扩展，加 `-pedantic` 会告警 |
| 5.4 / 6.7 | 数组变量「是 const 的指针」 | 数组名不是指针变量，而是在多数表达式中**退化**为指向首元素的地址常量。这正是 `sizeof(a)` 在函数内外的结果不同的原因 |
| 7.1 字符串 | `'\0'` 是一个字节，整数 `0` 是四个字节 | 字符常量 `'\0'` 的类型是 `int`（通常 4 字节）；只有存进 `char` 数组时才占 1 字节。两者**值**都是 0 |
| 7.2 字符串 | `char *s = "Hello";` | 字符串常量不可修改，应写 `const char *s = "Hello";`，让编译器帮你拦住写操作 |
| 7.6 strcmp | 返回 1 / −1 / 0（教材简化说法） | 标准只规定返回「负 / 0 / 正」，常见实现返回首个不同字符的差值；判断大小时写 `> 0`、`< 0`，不要依赖具体数值 |
| 4.7 本地变量 | `void f();` 表示参数表未知 | 对 C89～C17 成立；**C23 起** `void f()` 已等价于 `void f(void)`，明确表示无参数 |

## 本次补充的知识点

- **标准版本**：C89 / C99 / C11 / C17 / C23 的差异（VLA、变长数组、`bool`、`nullptr`、`%zu` 等都和标准版本有关）。
- **未定义行为**：整数溢出、数组越界、未初始化读取、修改字符串常量、重复 `free`，都不是「运行结果奇怪」而是标准不保证任何结果。
- **精确宽度类型**：`<stdint.h>` 的 `int32_t` / `uint64_t` 与 `<limits.h>` 的 `INT_MAX`，比记忆「int 通常是 4 字节」可靠。
- **安全写法**：`fgets` 代替 `scanf("%s")`、浮点比较用 `fabs(a−b) < eps`、`malloc` 后判空、`free` 后指针置空。
- **内存模型**：数组退化、结构体填充、指针的三种 `const` 位置、栈帧与生存期。
