# 第4章 函数

## 4.1 为什么要写函数

同样的代码写三遍，既啰嗦又难改；把重复代码提取成一个函数，**一处定义、多处调用**：

```c
int i;
int sum;

for (i = 1, sum = 0; i <= 10; i++)  { sum += i; }
printf("%d到%d的和是%d\n", 1, 10, sum);
for (i = 20, sum = 0; i <= 30; i++) { sum += i; }
printf("%d到%d的和是%d\n", 20, 30, sum);
for (i = 35, sum = 0; i <= 45; i++) { sum += i; }
printf("%d到%d的和是%d\n", 35, 45, sum);
```

提取成函数后：

```c
void sum(int begin, int end) {
    int i;
    int sum = 0;
    for (i = begin; i <= end; i++) {
        sum += i;
    }
    printf("%d到%d的和是%d\n", begin, end, sum);
}

int main() {
    sum(1, 10);
    sum(20, 30);
    sum(35, 45);
    return 0;
}
```

::: info 补充 · 函数的价值不只是少打字
它给一段计算**起了名字**、划定了**作用域**、明确了**输入输出**，于是可以单独测试、单独修改、单独复用。判断该不该抽函数，看的是「这段逻辑能不能用一句话命名」，而不是它有多长。
:::

## 4.2 函数的定义

函数由**函数头**（第一行）和**函数体**（`{ }` 内的代码）组成：

```c
void sum(int begin, int end)   // ← 函数头（函数原型）  {  // ┐
    int i;                                        //  │
    int sum = 0;                                  //  │ 函数体
    for (i = begin; i <= end; i++) {              //  │
        sum += i;                                //  │
    }                                            //  │
    printf("%d到%d的和是%d\n", begin, end, sum); //  │
}                                                //  ┘
```

**函数头的各部件**（以上例为准）：

| 部件 | 上例中的值 |
| --- | --- |
| 返回类型 | `void`（不返回任何东西） |
| 函数名 | `sum` |
| 参数表 | `(int begin, int end)` |

::: info 补充 · 定义与声明不是一回事
「函数头 + 分号」是**声明**（告诉编译器这个函数长什么样），「函数头 + 函数体」是**定义**（真正给出实现）。一个函数可以有多个声明，但整个程序里只能有一个定义。上面的注释把函数头称作"函数原型"，严格说只有带分号时才是原型。
:::

## 4.3 调用函数

**格式**：`函数名(参数值);`

- 即使没有参数也要写 `()`
- 如果有参数，则需要给出正确的数量和顺序（类型也要正确）
- 可以传递给函数的值是「表达式的结果」，包括：字面量、变量、函数返回值、计算结果

```c
int a, b, c;
a = 5; b = 6;

c = max(10, 12);          /* 字面量 */
c = max(a, b);            /* 变量 */
c = max(c, 23);           /* 变量 + 字面量 */
c = max(max(23, 45), a);  /* 函数的返回值 */
c = max(23 + 45, b);      /* 计算结果 */
```

::: warning 补充 · 求值顺序不确定
`f(g(), h())` 里 `g` 和 `h` 谁先执行是**未指定**的；`f(i++, i++)` 更是未定义行为。别让参数表达式互相依赖，先算好再传。
:::

## 4.4 返回值

`return` 停止函数的执行，并送回一个值。两种形式：`return;` 和 `return 表达式;`

- 一个函数可以出现多个 `return` 语句
- **没有返回值的函数（`void`）**：不能使用带值的 `return`；可以没有 `return`；调用的时候不能把返回值拿来参与运算
- 如果函数有返回值，则必须使用带值的 `return`

```c
int max(int a, int b) {
    int ret;
    if (a > b) { ret = a; }
    else       { ret = b; }
    return ret;
}
```

::: danger 补充 · 别返回局部变量的地址
`return &local;` 返回的是函数栈帧上的地址，函数返回后那块空间已经失效，属于**悬垂指针**。需要返回一块内存时，用 `malloc` 分配、或由调用者传入缓冲区。
:::

## 4.5 函数原型声明

C 的编译器从上到下顺序分析你的代码。在调用 `sum(1, 10)` 的时候，编译器需要知道 `sum()` 长什么样：要几个参数、每个参数的类型如何、返回什么类型。

**函数头以分号 `;` 结尾，就构成了函数的原型**，原型的目的就是提前告诉编译器这个函数长什么样：

```c
double max(double a, double b);   /* 函数原型（提前声明） */

int main() {
    int a, b, c;
    a = 5; b = 6;
    c = max(10, 12);
    printf("%d\n", c);
    return 0;
}

double max(double a, double b) {  /* 实际的函数定义可以写在后面 */
    ...
}
```

旧标准习惯把函数原型写在调用它的函数**里**；现在一般写在调用它的函数**前**（更常见的做法是放进 `.h` 头文件）。

::: warning 订正 · 上例的类型不一致
原笔记这段示例声明 `double max(double, double)`，却用 `int c` 接收返回值、再用 `%d` 打印。返回值会被隐式截断成 `int`，`%d` 与实参类型也对不上。教学示例应统一类型，例如改成 `int max(int, int)`，或把 `c` 声明为 `double` 并用 `%f` 输出。
:::

## 4.6 值传递（传值）

```c
void swap(int a, int b);

int main() {
    int a = 5; int b = 6;
    swap(a, b);
    printf("a=%d b=%d\n", a, b);
    return 0;
}

void swap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}
```

::: tip 核心结论
> C 语言在调用函数时，永远只能**传值**给函数。函数对参数的修改不会影响调用处的变量 —— 所以上面这样的代码不能交换 a 和 b 的值。想交换，必须用指针（见 6.4）。
:::

::: info 补充 · 数组是"例外"吗
不是。传数组时确实能改到原数组，但那是因为数组名退化成了**指向首元素的地址**，传进去的值是地址，函数通过地址间接访问了同一块内存 —— 本质上仍然是传值。这也解释了为什么函数内部 `sizeof(数组参数)` 得到的是指针大小。
:::

## 4.7 本地变量

**本地变量的规则**：

- 每个函数有自己的变量空间，参数也位于这个独立的空间中，和其他函数没有关系
- 过去把函数参数表中的参数叫做「形式参数」，调用函数时给的值叫做「实际参数」。这种称呼容易让初学者误以为调用函数时把变量（而不是值）传了进去，所以现在不建议继续使用
- **生存期**：什么时候这个变量开始出现，到什么时候它消亡
- **作用域**：在（代码）什么范围内可以访问这个变量
- 对于本地变量，这两个问题的答案是统一的：**大括号内 —— 块**
- 本地变量定义在块内 —— 可以是函数的块内，也可以是语句的块内，甚至可以随便拉一对括号来定义变量
- 程序运行进入这个块之前，其中的变量不存在；离开这个块，其中的变量就消失了
- 块外定义的变量在块内仍然有效
- 块内定义了和外面同名的变量，则掩盖了外面的
- 不能在一个块内定义同名的变量
- 本地变量不会被默认初始化；参数在进入函数的时候被初始化了

**没有参数时**：

```c
void f(void);   /* 明确表示没有参数 */
void f();       /* 在传统 C 中，表示 f 的参数表未知，并不表示没有参数 */
```

::: warning 订正 · C23 起变了
`void f();` 在 C89～C17 中确实表示「参数未指定」，编译器不会检查实参；但 **C23 起 `void f()` 已等价于 `void f(void)`**，明确表示不接收参数。写新代码时一律写 `void f(void)`，跨标准都不会有歧义。
:::

::: danger 易错点
C 语言**不允许函数嵌套定义**（函数里不能再定义函数）。GCC 的嵌套函数是非标准扩展。另外，`static` 局部变量虽然作用域仍在块内，但生存期是整个程序运行期，且只初始化一次 —— 它不属于这里说的「本地变量」常规情形。
:::
