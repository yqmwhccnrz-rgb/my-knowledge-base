## 第 1 章 导论与学习范式（★★★）

### 1.1 什么是机器学习

**机器学习**研究如何让计算机利用经验（数据）改善性能：给定任务 T、性能度量 P、经验 E，若程序在 T 上以 P 衡量的性能随 E 增加而提高，就称其在学习。形式化地，从假设空间 `H` 中选一个函数 `f: X → Y`，使在**未见数据**上的期望风险最小。

![机器学习范式总览与全书知识地图](/mlt/mlt-overview.svg)

| 范式 | 数据形式 | 目标 | 典型算法 |
| --- | --- | --- | --- |
| 监督学习 | 带标签 `(x, y)` | 学映射 `f(x)≈y` | 回归、分类、SVM、决策树、神经网络 |
| 无监督学习 | 只有 `x` | 发现隐藏结构 | K 均值、GMM、PCA/ICA、自编码器 |
| 强化学习 | 状态/动作/奖励序列 | 最大化长期累计回报 | Q-learning、DQN、策略梯度 |
| 半监督 / 自监督（补充） | 少量标签 + 大量无标签 / 自造监督信号 | 降低标注成本 | 伪标签、对比学习、掩码语言模型 |
| 迁移学习（补充） | 源域知识 + 目标域少量数据 | 复用表征 | 预训练 + 微调 |

::: danger 易错 · 概念边界
- 机器学习 ≠ 深度学习：后者只是前者中用深层神经网络的一支。
- 训练误差最低 ≠ 模型最好：目标是在**未知数据**上泛化，不是记住训练集。
- 「从数据中发现相关性」不等于发现因果性；也不等于结论可迁移到分布变化后的场景。
:::

::: tip 补充 · 没有免费午餐定理（NFL）
不存在对所有问题都最优的算法：若算法 A 在某类问题上优于 B，则必存在另一类问题使 B 优于 A。因此「哪种模型最好」必须**相对于具体数据分布与归纳偏好**回答，这正是要按问题选模型（见第 5 章与选型图）的根本原因。
:::

### 1.2 经验风险最小化与归纳偏好

```text
期望风险 R(f) = E_{(x,y)~P} [L(f(x), y)]        （不可直接计算，P 未知）
经验风险 R̂(f) = (1/N) Σᵢ L(f(xᵢ), yᵢ)          （可计算，用训练集近似）
结构风险   = R̂(f) + λ·Ω(f)                     （加正则项控制复杂度）
```

学习算法 = 「**假设空间 + 优化目标 + 求解算法 + 归纳偏好**」四要素。假设空间太小会欠拟合、太大易过拟合；正则项 `Ω(f)`（如 `‖w‖²`）体现「偏好更简单的模型」这一归纳偏好。

::: tip 工作例题 · 为什么必须加正则
用 9 次多项式拟合 10 个带噪声的点，训练误差可精确降到 0，但曲线剧烈震荡，在新点上误差极大——这正是「经验风险最小 ≠ 期望风险最小」的直观例证。加 `λ‖w‖²` 或降低多项式次数后，训练误差略升、泛化误差显著下降。
:::

### 1.3 偏差-方差分解（★★★）

![偏差-方差分解、欠拟合与过拟合](/mlt/mlt-biasvariance.svg)

对回归问题，在平方损失下可严格分解：

```text
Err(x) = Bias²(f̂) + Var(f̂) + σ²
Bias = E_D[f̂(x)] − f(x)        （平均预测与真值的偏离）
Var  = E_D[(f̂(x) − E_D[f̂(x)])²] （对训练集扰动的敏感度）
σ²   = 数据本身的不可约噪声
```

| 状态 | 训练误差 | 验证误差 | 主导项 | 对策 |
| --- | --- | --- | --- | --- |
| 欠拟合 | 高 | 高 | 偏差 | 加特征/减正则/训更久/换更强模型 |
| 恰到好处 | 低 | 最低 | 平衡 | 用验证集或交叉验证选复杂度 |
| 过拟合 | 很低 | 高（与训练差距大） | 方差 | 增数据/正则/早停/Dropout/Bagging |

::: tip 补充 · 集成的偏差方差视角
**Bagging** 对多个高方差基模型求平均，主要**降方差**；**Boosting** 串行纠正前面模型的偏差，主要**降偏差**。这解释了为什么随机森林用深树、GBDT 用浅树。
:::

::: danger 易错 · 偏差方差
- 「偏差大」不等于「模型有偏见」，它是统计学术语，指系统性偏离真值。
- 噪声项 `σ²` 无法通过任何模型消除，构成泛化误差下界。
- 偏差与方差通常此消彼长，调参的目标是找**总误差最小**的点，不是单独最小化某一项。
:::

![机器学习的统计与优化基础](/mlt/mlt-stats.svg)

### 2.1 概率、最大似然与贝叶斯

| 关系 | 公式 | 说明 |
| --- | --- | --- |
| 和规则（边际） | `p(x) = Σ_y p(x,y)` | 离散求和、连续积分 |
| 积规则 | `p(x,y) = p(y|x)p(x)` | 链式法则的基础 |
| 全概率 | `p(x) = Σ_k p(x|C_k)p(C_k)` | 生成式分类的基础 |
| 贝叶斯 | `p(θ|D) = p(D|θ)p(θ)/p(D)` | 先验 → 似然 → 后验 |
| 最大似然 MLE | `θ̂ = argmax_θ Σᵢ log p(xᵢ|θ)` | 点估计，视 θ 为未知常数 |
| 最大后验 MAP | `θ̂ = argmax_θ [Σᵢ log p(xᵢ|θ) + log p(θ)]` | 加先验；等价于带正则的 MLE |

::: tip 工作例题 · MLE 与 MAP
抛硬币 N 次出现 m 次正面，Bernoulli 的 MLE 为 `p̂ = m/N`（如 N=10、m=7 → 0.7）。
若加 Beta 先验，MAP 会给平滑估计 `(m+a)/(N+a+b)`，避免小样本下 `p̂=0` 或 `1` 的极端结论。这正是朴素贝叶斯需要**拉普拉斯平滑**的原因。
:::

::: danger 易错 · MLE
- 高斯分布的 MLE 方差是 `(1/N)Σ(xᵢ−μ̂)²`，**除以 N 而非 N−1**，因此是有偏估计；无偏样本方差才除以 N−1。
- MLE 给点估计，贝叶斯给整个后验分布；「贝叶斯方法 = MLE 加先验」只在 MAP 意义下近似成立，完全贝叶斯需对后验积分做预测。
- 似然 `p(D|θ)` 是 θ 的函数，**不是** θ 的概率密度。
:::

### 2.2 信息论与决策论

```text
熵       H(X) = −Σ p(x) log p(x)              （不确定性，等概率时最大）
交叉熵   H(p,q) = −Σ p(x) log q(x)            （用 q 编码 p 的平均代价）
KL 散度  D_KL(p‖q) = Σ p log(p/q) ≥ 0        （非对称，p=q 时为 0；不是距离）
互信息   I(X;Y) = H(X) − H(X|Y) = D_KL(p(x,y)‖p(x)p(y))
```

**最小风险决策**：给定后验 `p(C_k|x)` 与损失 `λ(决策, 真类)`，选期望损失（条件风险）最小的类别；当损失为 0-1 时退化为「选后验概率最大的类」。

::: tip 工作例题 · 熵与交叉熵
二分类均匀分布 `p=(0.5,0.5)` → `H=1 bit`；确定性分布 `p=(1,0)` → `H=0`。
若真实 `p=(1,0)`、模型 `q=(0.9,0.1)`，交叉熵 = `−log 0.9 ≈ 0.1053`；q 越接近 p，交叉熵越接近熵 0——这就是分类用交叉熵作损失的根据。
:::

::: danger 易错 · KL
`D_KL(p‖q) ≠ D_KL(q‖p)`（非对称），且不满足三角不等式，因此不是度量距离；VAE 的正则项方向固定为 `D_KL(q_φ(z|x)‖p(z))`，不能随意交换。
:::

### 2.3 优化：梯度下降与优化器

```python
import numpy as np
# 小批量梯度下降的通用骨架
def sgd(X, y, lr=0.01, epochs=100, batch=32, seed=42):
    rng = np.random.default_rng(seed)
    w = np.zeros(X.shape[1])
    for _ in range(epochs):
        idx = rng.permutation(len(y))
        for s in range(0, len(y), batch):
            b = idx[s:s+batch]
            pred = X[b] @ w
            grad = X[b].T @ (pred - y[b]) / len(b)   # 均方损失的梯度
            w -= lr * grad
    return w
```

| 优化器 | 更新要点 | 适用 |
| --- | --- | --- |
| 批量 GD | 全量梯度，稳定但慢 | 小数据、凸问题 |
| SGD / 小批量 | 单样本/小批量估计梯度 | 大数据、深度学习主流 |
| 动量 | `v ← αv − ηg; w ← w + v` | 抑制震荡、加速峡谷方向 |
| AdaGrad / RMSProp | 按历史梯度平方自适应缩放 η | 稀疏特征、非平稳目标 |
| **Adam** | 一阶 + 二阶动量 + 偏差修正 | 默认首选；课件推荐 η=0.001、β₁=0.9、β₂=0.999、ε=1e−8 |

::: danger 易错 · 优化
- 学习率过大发散、过小收敛慢；损失下降不代表泛化提升。
- **凸函数**的局部最优即全局最优（线性回归、逻辑回归、SVM 原问题）；深度网络目标非凸，只能保证收敛到局部极小/鞍点附近。
- 特征未标准化会让损失等高线呈狭长椭圆形，梯度下降震荡且慢；SVM、KNN、神经网络、正则化都要求先缩放。
:::

::: tip 补充 · 约束优化与 KKT
对带约束问题 `min f(w) s.t. gᵢ(w) ≤ 0`，构造拉格朗日函数 `L = f + Σαᵢgᵢ (αᵢ≥0)`；KKT 条件（驻点、原始/对偶可行、互补松弛 `αᵢgᵢ=0`）是 SVM 对偶推导与「只有支持向量 αᵢ>0」的理论依据，见第 6 章。
:::

### 2.4 从最大似然推出交叉熵、牛顿法与 IRLS（深挖）

**逻辑回归的交叉熵不是「拍脑袋选的」，而是 Bernoulli 的负对数似然。** 设 `p(y=1|x)=σ(wᵀx)`、`p(y=0|x)=1−σ`，则单样本似然 `p(y|x)=ŷ^y(1−ŷ)^{1−y}`，取负对数：

```text
−log p(y|x) = −[ y log ŷ + (1−y) log(1−ŷ) ]   ← 正是二元交叉熵
∇_w L = (ŷ − y)x ；  H = E[∂²L/∂w²] = XᵀRX，R = diag(ŷᵢ(1−ŷᵢ))
```

同理，softmax + 多元交叉熵来自多类 Bernoulli（Categorical）的 MLE；线性回归的均方误差来自「`y=xᵀw+ε, ε~N(0,σ²)`」的高斯似然。**损失函数由标签的噪声模型决定**，这是统一第 3、4 章的钥匙。

**牛顿法 / IRLS**（用二阶信息，比一阶梯度下降迭代次数少但每步更贵）：

```text
w ← w − H⁻¹∇L = w + (XᵀRX)⁻¹ Xᵀ(y−ŷ)
等价视角：每步求解一个加权最小二乘问题（IRLS，迭代重加权最小二乘）
```

::: tip 工作例题 · 一步牛顿更新
单样本 `x=1, y=1`，`w₀=0`：`ŷ=σ(0)=0.5`；
`∇L=(0.5−1)×1 = −0.5`；`H=ŷ(1−ŷ)x² = 0.25`；
`w₁ = 0 − (−0.5)/0.25 = 2.0`。
对比梯度下降（`η=0.1`）一步只走 `0.05`——牛顿法自动按曲率缩放步长，但每次要算 `O(d³)` 的 Hessian 逆，高维下仍以一阶方法为主。
:::

::: danger 易错 · 二阶方法
`H=XᵀRX` 半正定；当特征完全共线或数据线性可分（ŷ→0/1 使 R→0）时 H 奇异，牛顿步会发散，须加阻尼/正则。逻辑回归**线性可分时 MLE 不存在有限解**（‖w‖→∞），必须加正则化。
:::

### 3.1 线性模型与最小二乘

设扩充特征向量 `x=(x₁,…,x_d,1)ᵀ`、权向量 `w`，模型 `y = wᵀx`（截距并入 w）。给训练集 `{(xᵢ,yᵢ)}ᵢ₌₁ᴺ`，用平方损失：

```text
L(w) = ½ Σᵢ (yᵢ − wᵀxᵢ)² = ½ ‖Xw − y‖²
∇_w L = Xᵀ(Xw − y)
闭式解 w* = (XᵀX)⁻¹Xᵀy        （正规方程，要求 XᵀX 可逆）
```

```python
import numpy as np
X = np.array([[1., 1.], [1., 2.], [1., 3.]])   # 已含常数列
y = np.array([2., 4., 5.])
w = np.linalg.solve(X.T @ X, X.T @ y)          # 比显式求逆更数值稳定
print(w, X @ w)                                # 闭式解 + 拟合值
```

::: danger 易错 · 闭式解
- `XᵀX` 在**特征共线**或 `d > N` 时奇异，须用 `np.linalg.lstsq`、伪逆或加 λI（岭回归）。
- 复杂度 O(d³) 且需存整个 X，高维/大样本时应改用梯度下降或迭代法。
- 上式把偏置并入 w，若单独写 `y=wᵀx+b` 则正规方程形式不同，答题时保持一致。
:::

### 3.2 梯度下降求解（工作例题）

```python
x = np.array([1., 2.]); y = np.array([2., 3.])
w, lr = 0.0, 0.1
for step in range(6):
    grad = np.sum((w * x - y) * x)     # Σ(wxᵢ − yᵢ)xᵢ
    w -= lr * grad
    print(step + 1, round(w, 4))
```

::: tip 工作例题 · 手算一步（无截距模型 ŷ=wx）
样本 `(1,2)`、`(2,3)`，`w₀=0`、`η=0.1`：
`L = ½[(0−2)²+(0−3)²] = 6.5`；
`∇L = (0−2)·1 + (0−3)·2 = −8` → `w₁ = 0 − 0.1×(−8) = 0.8`。
闭式解 `w* = (1×2+2×3)/(1²+2²) = 8/5 = 1.6`，迭代会逐步逼近 1.6。
（若 `η` 取 0.3，一步即 `w=2.4` 越过最优并开始震荡，说明学习率必须调。）
:::

### 3.3 正则化：岭、Lasso 与贝叶斯解释

| 方法 | 目标函数 | 解 / 效果 |
| --- | --- | --- |
| 岭回归 L2 | `½Σe² + (λ/2)‖w‖²` | `w*=(XᵀX+λI)⁻¹Xᵀy`；系数整体缩小、解稳定，**不为 0** |
| Lasso L1 | `½Σe² + λ‖w‖₁` | 产生**稀疏解**（部分系数恰为 0），可做特征选择 |
| 弹性网 | `L1 + L2` 折中 | 兼具稀疏与稳定，适合高度相关特征组 |
| 多项式回归 | 先升维 `(x, x², …)` 再线性回归 | 提高表达能力，但更易过拟合，须配正则 |

::: tip 补充 · 正则化的贝叶斯解释
L2 正则等价于给参数加**高斯先验** `w~N(0, σ²I)`，L1 等价于**拉普拉斯先验**；此时求解的是 MAP 估计，正则项就是负 log 先验。这一视角把「防过拟合」与「先验知识」统一起来。
:::

::: danger 易错 · 正则化
- 正则项**不含偏置项** `b`；自变量须先标准化，否则惩罚对不同量纲不公平。
- `λ` 越大 → 系数越小 → 偏差上升、方差下降；`λ=0` 退化为 OLS。
- 岭回归系数是有偏的（以偏差换方差），不能再按普通 OLS 的标准误与 p 值解释。
:::

::: tip 补充 · 回归的其它损失（课件未展开）
平方损失对异常值敏感；工程上还有 Huber（分段，兼顾稳健与可导）、MAE / 分位数回归（对异常值稳健）、以及用于计数的泊松回归。评估用 MSE / RMSE / MAE / R²，且必须在独立测试集上计算。
:::

## 第 4 章 分类学习（★★★）

![分类学习：三种建模路线与代表算法](/mlt/mlt-classification.svg)

### 4.1 三种基本模型（课件第 4 讲）

| 路线 | 学什么 | 代表 | 是否输出概率 |
| --- | --- | --- | --- |
| 判决函数模型 | 直接学 `f(x)→类别` | 感知机、SVM、KNN、决策树 | 否（ SVM 需校准） |
| 判别式概率模型 | 直接建模 `p(C_k|x)` | 逻辑回归、softmax 回归 | 是 |
| 生成式模型 | 先建 `p(x|C_k)`、`p(C_k)` 再用贝叶斯反推 | 朴素贝叶斯、LDA、GMM | 是（可生成样本） |

::: danger 易错 · 判别式 vs 生成式
区别在**是否对 `p(x)` 或 `p(x|C)` 建模**，而不是「能不能输出概率」。逻辑回归与朴素贝叶斯都能给后验概率，但前者直接拟合决策边界、后者假设类条件分布；生成式模型收敛更快（所需样本更少）但假设更强，判别式模型在大样本下渐近误差更低。
:::

### 4.2 逻辑回归与 softmax

```text
二分类：p(y=1|x) = σ(wᵀx) = 1/(1+exp(−wᵀx))
交叉熵损失：L(w) = −Σᵢ [yᵢ log ŷᵢ + (1−yᵢ) log(1−ŷᵢ)]
梯度：∇_w L = Xᵀ(ŷ − y)      （与线性回归形式相似，但 ŷ 经过 sigmoid）
多分类：p(C_k|x) = exp(a_k)/Σⱼ exp(a_j)，损失 = −Σᵢ log p(yᵢ|xᵢ)
```

```python
import numpy as np
sig = lambda z: 1 / (1 + np.exp(-z))
print(sig(0), round(sig(2), 4))                 # 0.5  0.8808
logits = np.array([2., 1., 0.1])
e = np.exp(logits - logits.max())               # 减 max 防溢出
print(np.round(e / e.sum(), 4))                 # [0.659  0.2424 0.0986]
```

::: tip 工作例题 · 决策边界与概率
`wᵀx=0` → `σ(0)=0.5`，正是决策边界；`wᵀx=2` → `σ(2)=0.8808` 判为正类；`wᵀx=−1.2` → `σ≈0.2315` 判为负类。
三分类 logits `(2, 1, 0.1)` 的 softmax 为 `(0.6590, 0.2424, 0.0986)`，和为 1，预测第 1 类。
:::

::: danger 易错 · 逻辑回归
- 名字里有「回归」，但它做的是**分类**；输出是概率不是连续值。
- 逻辑回归的平方损失非凸，因此用交叉熵（凸），不能用线性回归的均方误差直接训练。
- softmax 计算须减去 `max(logits)` 防 `exp` 溢出；多分类的 `sigmoid` 逐个输出不保证和为 1，两者不可混用。
:::

### 4.3 其它基本分类器

| 算法 | 核心 | 关键参数 / 前提 | 主要局限 |
| --- | --- | --- | --- |
| KNN | 近邻多数投票 | K、距离度量、特征标准化 | 预测慢、高维失效、需存全量数据 |
| 朴素贝叶斯 | `p(C|x) ∝ p(C)Πⱼ p(xⱼ|C)` | 条件独立假设、平滑系数 | 特征强相关时概率失真 |
| 感知机 | `y=sgn(wᵀx)`，误分则 `w ← w+ηyᵢxᵢ` | 仅**线性可分**才收敛 | 不输出概率、对重叠数据震荡 |
| LDA | 类内同协方差的高斯假设，最大化类间/类内比 | 需估计协方差矩阵 | 假设较强，得到线性边界 |
| Softmax 回归 | 多类逻辑回归 | 类别互斥 | 类别不互斥时应改多个二分类 |

::: tip 补充 · 类别不平衡（课件未展开）
准确率在正负比 99:1 时毫无意义（全预测负类也有 99%）。应看精确率/召回率/F1 与 PR-AUC，并采用重采样、类别权重 `class_weight='balanced'` 或调整决策阈值；阈值移动会沿 ROC 曲线滑动，取舍由业务代价决定。
:::

## 第 5 章 机器学习流程与性能评估（★★★）

![机器学习流程与性能评估](/mlt/mlt-evaluation.svg)

### 5.1 标准流程（课件第 5 讲）

| 步 | 内容 | 易错点 |
| --- | --- | --- |
| ① 数据清洗 | 缺失填补、异常值处理、去重 | 不可用**全体数据**的均值填补后再切分（泄露） |
| ② 归一化 | 范围归一化 `(x−min)/(max−min)`；概率/分布归一化（标准化 z=(x−μ)/σ） | 缩放参数只能在训练集拟合 |
| ③ 特征工程 | 编码、选择、构造、降维 | 特征选择也须在训练折内做 |
| ④ 划分数据集 | 训练 / 验证 / 测试三分 | 测试集只用于最终一次性评估 |
| ⑤ 训练与调参 | 交叉验证选超参、早停 | 反复看测试集调参 = 泄露 |
| ⑥ 评估部署 | 独立测试集指标、监控分布漂移 | 上线后数据分布会变 |

::: danger 易错 · 数据泄露（课件未强调，工程第一大坑）
任何用到**全体数据统计量**的预处理（标准化、缺失填补、PCA、特征选择、词表构建）都必须在训练集内拟合并应用到验证/测试集，sklearn 的 `Pipeline` 就是为此设计。时序数据必须按时间前向切分，绝不能随机打乱。
:::

### 5.2 混淆矩阵与评估指标

| 指标 | 公式 | 关注点 |
| --- | --- | --- |
| 准确率 Accuracy | `(TP+TN)/N` | 类别平衡时有效 |
| 精确率 Precision | `TP/(TP+FP)` | 「报出来的有多少是真的」 |
| 召回率 Recall / TPR | `TP/(TP+FN)` | 「真的有多少被报出来」 |
| F1 | `2PR/(P+R) = 2TP/(2TP+FP+FN)` | P 与 R 的调和平均 |
| FPR | `FP/(FP+TN)` | ROC 横轴 |
| ROC / AUC | TPR–FPR 曲线下面积 | 与阈值无关；0.5 为随机 |

::: tip 工作例题 · 手算全套指标
`TP=80, FP=20, FN=10, TN=90`（N=200）：
准确率 = 170/200 = **0.85**；精确率 = 80/100 = **0.80**；召回率 = 80/90 ≈ **0.8889**；
F1 = 2×80/(2×80+20+10) = 160/190 ≈ **0.8421**；FPR = 20/110 ≈ **0.1818**。
若改变决策阈值，P 与 R 沿相反方向变化，F1 折中；AUC 不受单一阈值影响。
:::

### 5.3 交叉验证与泛化理论

```python
from sklearn.model_selection import cross_val_score, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

pipe = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(pipe, X, y, cv=cv, scoring='f1')
print(scores.mean().round(4), scores.std().round(4))
```

::: tip 补充 · 泛化上界（课件第 5 讲定理）
在假设空间有限、样本独立同分布的条件下，以概率不小于 `1−δ` 有
`R(h) − R̂(h) ≤ √[(log|H| + log(2/δ))/(2N)]`（Hoeffding 型界）。
结论：**假设空间越大、样本越少，经验风险与期望风险的差距上界越大**；这为「控制模型复杂度 / 正则化」提供了理论依据。对无限假设空间需用 VC 维或 Rademacher 复杂度替代 `log|H|`。
:::

| 验证方式 | 做法 | 适用 |
| --- | --- | --- |
| 留出法 | 一次性按比例切分 | 数据量大、快速 |
| K 折交叉验证 | 轮流用 1 折验证、K−1 折训练，取平均 | 标准做法，K=5/10 |
| 分层 K 折 | 保持每折类别比例 | 分类且类别不平衡 |
| 留一法 LOOCV | K=N | 小样本，计算代价高 |
| 时间序列切分 | 按时间前向滚动 | 时序/金融数据（防泄露） |

::: danger 易错 · 评估
- 「在测试集上调参」等于把测试集当验证集用，报告的指标不再无偏。
- 类别不平衡优先看 PR 曲线而非 ROC（ROC 在负样本极多时过于乐观）。
- 交叉验证得分的**方差**也要看：均值接近但方差大说明结果不稳定。
:::

## 第 6 章 核函数与支持向量机（★★★）

![核函数与支持向量机 SVM](/mlt/mlt-svm.svg)

### 6.1 核函数与 Mercer 条件（课件第 6 讲）

由特征向量构造映射 `φ: x → φ(x)`，定义核函数 `k(x,z) = φ(x)ᵀφ(z)`。核函数满足**对称性** `k(x,z)=k(z,x)`，且对任意样本集构成的 Gram 矩阵 `Kᵢⱼ=k(xᵢ,xⱼ)` 必须是**对称半正定**矩阵（Mercer 条件）——这是判断一个函数能否作核的充要条件。

::: tip 工作例题 · 多项式核的显式特征映射（课件原例）
二维情形取 `k(x,z)=(1+xᵀz)²`：
展开 `(1+x₁z₁+x₂z₂)² = 1 + 2x₁z₁ + 2x₂z₂ + x₁²z₁² + x₂²z₂² + 2x₁x₂z₁z₂`
恰好等于 `φ(x)ᵀφ(z)`，其中
`φ(x) = (1, √2x₁, √2x₂, x₁², x₂², √2x₁x₂)`。
即二维输入被映射到**六维**特征空间；直接用核函数可省去显式构造 φ 的计算——这就是**核技巧**。
:::

::: danger 易错 · 核函数
- 核函数必须半正定；`sigmoid` 型核 `tanh(γxᵀz+c)` 在部分参数下**不满足** Mercer 条件，不是合法核。
- 高斯 RBF 对应**无穷维**特征空间，不可能显式写出 φ(x)。
- 核方法计算/存储开销随样本数平方增长（Gram 矩阵 O(N²)），超大样本需近似（随机特征、Nyström）。
:::

### 6.2 最大间隔分类器与对偶

```text
原问题（硬间隔）：min_{w,b} ½‖w‖²   s.t.  yᵢ(wᵀxᵢ+b) ≥ 1
几何间隔 γ = 2/‖w‖，最大化间隔 ⇔ 最小化 ‖w‖²
拉格朗日：L = ½‖w‖² − Σαᵢ[yᵢ(wᵀxᵢ+b) − 1]，αᵢ ≥ 0
对偶问题：max_α Σᵢαᵢ − ½Σᵢⱼ αᵢαⱼyᵢyⱼ xᵢᵀxⱼ
           s.t. Σᵢαᵢyᵢ = 0, αᵢ ≥ 0
决策函数：f(x) = sgn(Σᵢ αᵢyᵢ k(xᵢ,x) + b)
```

**KKT 互补松弛** `αᵢ[yᵢ(wᵀxᵢ+b)−1]=0` 说明：只有落在间隔边界上的样本（**支持向量**）才可能有 `αᵢ>0`，其余样本对解无影响——这是 SVM 稀疏性与抗噪性的来源。

::: tip 工作例题 · 间隔计算
`w=(1,1)`、`b=−3` 给出决策面 `x₁+x₂=3`，两条间隔边界为 `x₁+x₂=2` 与 `=4`。
`‖w‖=√2` → 几何间隔 `γ = 2/√2 = √2 ≈ 1.4142`；`‖w‖` 越小间隔越宽、泛化通常越好。
:::

### 6.3 软间隔与常用核

数据线性不可分或含噪声时引入松弛变量 `ξᵢ ≥ 0` 与惩罚参数 `C`：

```text
min ½‖w‖² + C Σᵢ ξᵢ   s.t. yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ,  ξᵢ ≥ 0
对偶中约束变为 0 ≤ αᵢ ≤ C（C 为 α 的上界）
```

| 核 | 形式 | 特点 |
| --- | --- | --- |
| 线性 | `k=xᵀz` | 特征多/样本大，不易过拟合、可解释 |
| 多项式 | `k=(γxᵀz+c)^d` | 显式控制交互阶数，d 大易过拟合 |
| 高斯 RBF | `exp(−‖x−z‖²/(2σ²))` | 无穷维、默认首选；γ=1/(2σ²) 越大边界越曲折 |
| Sigmoid | `tanh(γxᵀz+c)` | 部分参数下非半正定，慎用 |

::: danger 易错 · 超参数与输出
- `C` 越大越不容忍误分类 → 间隔变窄、易过拟合；`C` 越小间隔越宽、允许更多错分。
- `γ`（RBF）越大，单个样本影响范围越小，决策边界越复杂，易过拟合。
- SVM 输出是**距离符号**不是概率；要概率须 Platt 校准（或改用逻辑回归）。
- SVM 对特征缩放敏感，训练前必须标准化；对缺失值也敏感。
:::

::: tip 补充 · 多分类与回归（课件未展开）
SVM 本质是二分类器，多分类常用 **one-vs-rest / one-vs-one** 组合；`SVR` 把间隔思想推广到回归（ε-不敏感损失）。核技巧也可用于 PCA（核 PCA）、K-means 等，形成一整类「核方法」。
:::

### 6.4 hinge 损失视角与 SMO 求解（深挖）

把软间隔 SVM 的原问题改写成「正则化 + 经验损失」的无约束形式：

```text
min_w ½‖w‖² + C Σᵢ max(0, 1 − yᵢ(wᵀxᵢ+b))  = ½‖w‖² + C Σᵢ L_hinge(yᵢfᵢ)
C → ∞ 时逼近硬间隔；L2-SVM 用 max(0,1−yf)² 得处处可导的目标
```

**hinge 的关键性质**：当 `yᵢfᵢ ≥ 1`（样本被正确分类且在间隔外）时损失与梯度**恒为 0**，因此只有支持向量参与优化——这从损失角度解释了 SVM 的稀疏性；对比之下交叉熵对所有样本都有梯度，逻辑回归的解不稀疏。

**SMO（序列最小优化）** 是求解 SVM 对偶的经典算法：

```text
对偶约束 Σαᵢyᵢ=0 使「只优化一个 α」不可能（其余确定的话它也被确定）
⇒ 每次选两个变量 αᵢ、αⱼ，固定其余，用等式约束把 αⱼ 表成 αᵢ 的线性函数
⇒ 对偶目标化为单变量二次函数，解析求无约束极值 → 裁剪到 [0, C] 可行域
⇒ 更新 b 与误差缓存，按 KKT 违反程度选下一对，循环至收敛
```

::: danger 易错 · SVM 求解
- SMO 的「两个变量」是**约束导致的必然**，不是随意加速技巧；违反 KKT 的样本优先被选。
- 核 SVM 的训练复杂度约 `O(N²)–O(N³)`，且需缓存 `N×N` 核矩阵；`N` 极大时应改用线性 SVM（如 `LinearSVC` / SGD  hinge）或随机特征近似。
- `SVC` 默认 `kernel='rbf'`；若数据已高维稀疏（如文本），线性核往往更快且效果不差。
:::

## 第 7 章 决策树与集成学习（★★★）

![决策树：划分准则、三种算法与剪枝](/mlt/mlt-tree.svg)

### 7.1 决策树的构建与划分准则

决策树是分层的决策结构，可用于分类与回归，对**混合属性**（数值 + 类别）尤其有效。构建是自顶向下的贪心递归：遍历所有特征与切分点，选使「纯度提升最大」的划分，生成分支，对子集递归，直到满足停止条件（结点纯 / 无特征 / 样本过少 / 达最大深度）。

| 算法 | 准则 | 树结构 | 特点 |
| --- | --- | --- | --- |
| ID3 | 信息增益 `G(D,A)=H(D)−Σᵥ(\|Dᵥ\|/\|D\|)H(Dᵥ)` | 多叉 | 偏袒取值多的特征（如「编号」） |
| C4.5 | 增益率 `GR = G(D,A)/SplitInfo_A` | 多叉 | 惩罚多值特征；支持连续值与缺失 |
| CART | 基尼指数 `Gini(D)=1−Σpₖ²` | **二叉** | 分类用基尼、回归用平方误差 |

```text
熵          H(D) = −Σₖ pₖ log₂ pₖ
条件熵      H(D|A) = Σᵥ (|Dᵥ|/|D|) H(Dᵥ)
信息增益    G(D,A) = H(D) − H(D|A)          ← 取最大
分裂信息    SplitInfo_A = −Σᵥ (|Dᵥ|/|D|) log₂(|Dᵥ|/|D|)
基尼指数    Gini_index(D,A) = Σᵥ (|Dᵥ|/|D|) Gini(Dᵥ)   ← 取最小
```

::: tip 工作例题 · 三种准则完整手算
14 个样本（9 正 / 5 负），按属性 A 分为 `D₁`（8 个：7 正 1 负）与 `D₂`（6 个：2 正 4 负）：
- `H(D) = −(9/14)log₂(9/14) − (5/14)log₂(5/14) = 0.9403`；
- `H(D₁)=0.5436`、`H(D₂)=0.9183` → 条件熵 `= 8/14×0.5436 + 6/14×0.9183 = 0.7042`；
- **信息增益 `G = 0.9403 − 0.7042 = 0.2361`**；
- `Gini(D)=0.4592`、`Gini(D₁)=0.2188`、`Gini(D₂)=0.4444` → **基尼指数 `= 0.3155`**；
- `SplitInfo = 0.9852` → **增益率 `GR = 0.2361/0.9852 ≈ 0.2397`**。
:::

::: danger 易错 · 划分准则方向
信息增益/增益率**取最大**，基尼指数**取最小**，方向别弄反。连续特征须先排序、以相邻取值中点为候选切分点；「编号」这类唯一值特征的信息增益会虚高，正是 C4.5 引入增益率的原因。
:::

### 7.2 剪枝与树的性质

| 剪枝 | 做法 | 取舍 |
| --- | --- | --- |
| 预剪枝 | 分裂前估计增益，不达标即停 | 快，但可能过早停止（欠拟合） |
| 后剪枝 | 先长全树，自底向上把子树替换为叶 | 更可靠，计算开销大 |
| CCP（补充） | CART 的代价复杂度剪枝，用 α 权衡误差与叶数 | 用验证集选最优 α |

::: tip 决策树优缺点
优点：可解释、无需标准化、能处理混合属性与非线性、训练快。
缺点：**不稳定**（数据微扰导致树结构大变）、容易过拟合、贪心划分非全局最优、决策边界轴平行。后两点正是集成学习要解决的问题。
:::

### 7.3 集成学习：Bagging 与 Boosting

![集成学习：Bagging / 随机森林 与 Boosting](/mlt/mlt-ensemble.svg)

| 维度 | Bagging / 随机森林 | Boosting（AdaBoost / GBDT） |
| --- | --- | --- |
| 训练方式 | 并行、各基学习器独立 | 串行、后者依赖前者 |
| 样本权重 | Bootstrap 有放回抽样 | 每轮提高错分样本权重 / 拟合残差 |
| 组合方式 | 投票 / 平均（等权） | 加权组合 `F(x)=Σαₜhₜ(x)` |
| 基学习器 | 强且不稳定（深树） | 弱但优于随机（浅树 / 树桩） |
| 主要作用 | **降方差** | **降偏差** |
| 并行性 | 可并行 | 不可并行（XGBoost 在特征层面并行） |

```text
AdaBoost 第 t 轮：
εₜ = 加权错误率；αₜ = ½ ln((1−εₜ)/εₜ)
wᵢ ← wᵢ · exp(−αₜ yᵢ hₜ(xᵢ))，再归一化
GBDT：每一轮拟合当前损失函数的负梯度（伪残差），逐步加法建模
```

::: tip 工作例题 · AdaBoost 权重更新
`εₜ=0.3` → `αₜ = ½ln(0.7/0.3) = ½ln(2.3333) ≈ 0.4236`；
错分样本权重乘 `e^{0.4236} ≈ 1.5275`，正确样本乘 `e^{−0.4236} ≈ 0.6547`（错分样本被放大约 2.3 倍相对权重）。
若 `εₜ=0.5`（等同随机猜测）→ `αₜ=0`，该分类器对最终模型无贡献；若 `εₜ>0.5` 应停止或取反。
:::

::: danger 易错 · 集成
- 随机森林的「随机」有两层：**样本** Bootstrap + **特征**随机子集；仅做样本抽样是 Bagging。
- RF 可用 **OOB（袋外）样本**做近似无偏的泛化误差估计，不必额外划验证集。
- Boosting 对噪声与异常值敏感（错分样本被不断放大）；集成并非总能提升——基学习器需「有差异且各自优于随机」。
:::

::: tip 补充 · 算法谱系（课件只点到 XGBoost）
`Bagging → 随机森林 → ExtraTrees`；`AdaBoost → GBDT → XGBoost / LightGBM / CatBoost`（二阶泰勒展开 + 正则项 + 列采样 + 直方图加速）；`Stacking` 用元学习器组合异构基模型。工程上表格数据首选梯度提升树，图像/文本首选深度网络。
:::

### 7.5 AdaBoost 的推导：前向分步加法模型 + 指数损失（深挖）

AdaBoost 那些「看起来像启发式」的权重公式其实可以严格推导出来。设加法模型 `f(x)=Σₜ αₜhₜ(x)`，取**指数损失** `L(y,f)=exp(−yf)`，用**前向分步**（每轮只加一个基学习器，固定已有部分）：

```text
第 t 轮：min_{α,h} Σᵢ exp(−yᵢ[f_{t−1}(xᵢ) + α h(xᵢ)])
      = Σᵢ wᵢ^{(t)} exp(−α yᵢ h(xᵢ))，其中 wᵢ^{(t)} = exp(−yᵢ f_{t−1}(xᵢ)) 与 α,h 无关
① 固定 α，最小化 Σ wᵢ exp(−α yᵢ h(xᵢ)) ⇒ 等价于最小化加权分类误差 εₜ
   故 hₜ = 加权错误率最小的弱分类器
② 固定 hₜ，对 α 求导并令为 0：
   −(1−εₜ)e^{−α} + εₜ e^{α} = 0 ⇒ αₜ = ½ ln((1−εₜ)/εₜ)      ← 课件公式的来源
③ 代入 fₜ = f_{t−1} + αₜhₜ 得权重更新
   wᵢ ← wᵢ exp(−αₜ yᵢ hₜ(xᵢ))，再归一化                        ← 错分样本权重升高
```

**结论**：AdaBoost 等价于在指数损失上做**梯度下降式的前向分步优化**；GBDT 则把指数损失换成任意可微损失并拟合其**负梯度**（伪残差），二者是同一框架的不同损失选择。

::: tip 工作例题 · 权重公式自检
`εₜ=0.3` → `αₜ=½ln(0.7/0.3)≈0.4236`；
错分样本 `yᵢhₜ=−1` → 乘 `e^{+0.4236}≈1.5275`；正确样本乘 `e^{−0.4236}≈0.6547`。
当 `εₜ→0` 时 `αₜ→∞`（完美分类器权重极大）；`εₜ=0.5` 时 `αₜ=0`（等同随机）；`εₜ>0.5` 时 `αₜ<0` 应停止训练或取反。
:::

::: danger 易错 · Boosting 推导
- 指数损失对**错分/异常样本**惩罚随 `e^{|f|}` 指数增长，所以 AdaBoost 对噪声敏感；这也是 GBDT 常用更稳健的平方/绝对/Huber 损失的原因。
- 前向分步是**贪心**（不回溯调整已有基学习器），与决策树的贪心划分同理。
- AdaBoost 的「样本权重」与「分类器权重」是两个不同量，勿混为一谈。
:::

## 第 8 章 神经网络与反向传播（★★★）

![神经元、多层感知机与激活函数](/mlt/mlt-mlp.svg)

### 8.1 从神经元到多层感知机

单个神经元：`z = Σⱼ wⱼxⱼ + b = wᵀx + b`，`a = φ(z)`。多层感知机（MLP / 前馈网络）逐层计算：

```text
z^{(l)} = W^{(l)} a^{(l−1)} + b^{(l)}
a^{(l)} = φ(z^{(l)})           （a^{(0)} = x）
```

**万能逼近定理**：一个含足够多神经元的单隐层网络，用非多项式非线性激活，可任意精度逼近紧集上的连续函数。但「能表示」不代表「能学到」，深度网络用**多层非线性**以更少参数表示层次化特征。

::: danger 易错 · 激活函数不可替代
若所有层都用线性激活，多层复合仍是单个线性变换：`a^{(L)} = W_L…W_1 x`，等价于一层线性回归。**非线性激活是深度网络表达能力的来源**。
:::

### 8.2 激活函数对照（课件 Part-1）

| 函数 | 表达式 | 值域 | 优点 | 缺点 |
| --- | --- | --- | --- | --- |
| Sigmoid | `1/(1+e⁻ᶻ)` | (0,1) | 概率解释、门控 | 饱和区梯度趋 0、非零均值、指数运算 |
| Tanh | `(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)` | (−1,1) | 零均值 | 仍有梯度消失 |
| **ReLU** | `max(0,z)` | [0,∞) | 计算极简、正半轴梯度恒 1 | z&lt;0 神经元「死亡」 |
| LeakyReLU / ELU / GELU | ReLU 变体 | — | 缓解死亡、更平滑 | 需额外超参/计算 |
| Softmax | `exp(aₖ)/Σⱼexp(aⱼ)` | (0,1) 和为 1 | 多分类输出 | 须减 max 防溢出 |

::: tip 工作例题 · 一层前向计算
`x=(1,2)`、`w=(0.5,−1)`、`b=0.3` → `z = 0.5×1 − 1×2 + 0.3 = −1.2`；
`ReLU(z) = 0`，`sigmoid(−1.2) ≈ 0.2315`。
三分类 logits `(2,1,0.1)` → softmax `(0.6590, 0.2424, 0.0986)`，和为 1，预测第 1 类。
:::

### 8.3 反向传播（链式法则）

![反向传播、梯度问题与训练技巧](/mlt/mlt-backprop.svg)

```text
前向：逐层缓存 z^{(l)}、a^{(l)}，最后计算损失 L
输出层误差：δ^{(L)} = ∇_{a}L ⊙ φ′(z^{(L)})
逐层回传：δ^{(l)} = (W^{(l+1)})ᵀ δ^{(l+1)} ⊙ φ′(z^{(l)})
梯度：∂L/∂W^{(l)} = δ^{(l)}(a^{(l−1)})ᵀ，  ∂L/∂b^{(l)} = δ^{(l)}
```

```python
import numpy as np
# 两层网络在单个样本上的一次反向传播（平方损失、sigmoid 隐层）
x = np.array([1., 2.]); y = np.array([1.])
W1 = np.array([[0.1, 0.2], [-0.3, 0.4]]); b1 = np.array([0.0, 0.0])
W2 = np.array([[0.5], [-0.6]]); b2 = np.array([0.0])
sig = lambda z: 1 / (1 + np.exp(-z))
a1 = sig(W1 @ x + b1)
a2 = W2.T @ a1 + b2                       # 输出层线性
delta2 = (a2 - y) * 1.0                   # 平方损失对线性输出的梯度
delta1 = (W2 @ delta2) * (a1 * (1 - a1))  # sigmoid 导数 φ′=a(1−a)
gW2 = np.outer(a1, delta2); gW1 = np.outer(delta1, x)
print('a2 =', a2.round(4), ' |δ1| =', np.abs(delta1).round(4))
```

::: danger 易错 · 梯度消失与爆炸
深层 δ 含多个 `Wᵀφ′` 连乘：若每层因子约 0.5，5 层后首层梯度约 `0.5⁵ = 0.03125`（几乎消失）；若约 2，则 `2⁵ = 32`（爆炸）。
Sigmoid 导数最大仅 0.25，是深网络梯度消失的历史主因。对策：**ReLU、残差连接、批归一化、恰当初始化（Xavier/He）、LSTM 门控、梯度裁剪**。
:::

### 8.4 训练技巧（课件 Part-2）

| 技巧 | 机理 | 注意 |
| --- | --- | --- |
| 批归一化 BN | 每层输入标准化 + 可学习 γ、β | 训练用批次统计量，推理用滑动平均，二者不同 |
| Dropout | 训练时按概率 p 随机置零，测试全开并缩放 | 只在训练启用；等价于隐式集成 |
| 权重衰减 | L2 惩罚等价于参数乘 `(1−ηλ)` | AdamW 把权重衰减与梯度解耦，效果更好 |
| 早停 | 验证误差回升即停 | 验证集不能与测试集混用 |
| 残差连接 | `y = F(x) + x` 提供梯度高速路 | 使上百层网络可训练 |
| 初始化 | Xavier `Var≈1/d_in`、He `Var≈2/d_in`（配 ReLU） | 全零初始化会导致对称性问题 |

::: tip 补充 · 损失函数与输出层配对
回归 → 线性输出 + MSE；二分类 → sigmoid + 二元交叉熵；多分类 → softmax + 多元交叉熵。配对错误会导致梯度形式复杂或数值不稳（如 softmax 与 MSE 组合在饱和时梯度极小）。
:::

## 第 9 章 深度学习进阶（★★★）

### 9.1 卷积神经网络 CNN

![卷积神经网络 CNN 与输出尺寸计算](/mlt/mlt-cnn.svg)

三大思想：**局部感受野**（每个神经元只看一小块）、**权值共享**（同一卷积核滑过整图）、**层级特征 + 池化**（浅层边缘 → 深层语义）。

```text
输出尺寸 H_out = ⌊(H_in − K + 2P)/S⌋ + 1，W_out 同理
输出通道数 = 卷积核个数；参数量 = K×K×C_in×C_out + C_out
池化层无可训练参数；1×1 卷积用于通道变换与降维
```

::: tip 工作例题 · LeNet 风格尺寸演算（课件 max pool 2×2）
输入 `32×32×1`，6 个 `5×5` 卷积核、`S=1`、`P=0`：
`⌊(32−5)/1⌋+1 = 28` → `28×28×6`，参数量 `5×5×1×6+6 = 156`；
接 `2×2` max pooling、`S=2`：`⌊(28−2)/2⌋+1 = 14` → `14×14×6`；
后续再卷积+池化得 `5×5×16`，展平 400 维接全连接，最后 softmax 输出 10 类。
:::

::: danger 易错 · CNN
- 池化**不改变通道数**；「same」填充可保持尺寸不变。
- 卷积层参数量与输入图像尺寸无关，但计算量与尺寸成正比。
- 卷积具有**平移等变性**，池化只带来弱平移不变性；不要夸大 CNN 的旋转/尺度不变性（靠数据增强）。
:::

::: tip 补充 · 结构演进
`LeNet-5 → AlexNet（ReLU+Dropout+GPU）→ VGG（小核堆叠）→ Inception（多尺度）→ ResNet（残差）→ DenseNet / MobileNet（深度可分离卷积）/ ConvNeXt`；检测与分割派生 `R-CNN、YOLO、U-Net、FCN`。
:::

### 9.2 循环网络与序列建模

![循环网络、注意力与 Transformer](/mlt/mlt-rnn-attention.svg)

```text
RNN：hₜ = φ(W_xh xₜ + W_hh hₜ₋₁ + b)，yₜ = W_hy hₜ   （同一组 W 各时刻共享）
训练用 BPTT（沿时间反向传播）；长序列连乘导致梯度消失/爆炸
LSTM：遗忘门 f、输入门 i、输出门 o 与细胞状态 cₜ 形成「传送带」，
      cₜ = f⊙cₜ₋₁ + i⊙g，hₜ = o⊙tanh(cₜ)，能记住长程依赖
GRU：合并为更新门 z 与重置门 r，参数更少、训练更快
```

| 结构 | 能否并行 | 长程依赖 | 复杂度 |
| --- | --- | --- | --- |
| RNN / LSTM | 否（依赖上一步隐状态） | 有限（LSTM 改善） | O(n) 序列步 |
| 自注意力 / Transformer | **是** | 任意位置直接相连 | O(n²) 序列长度 |

### 9.3 注意力与 Transformer（课件 Part-3）

```text
Attention(Q,K,V) = softmax(QKᵀ / √d_k) · V
多头：把 Q/K/V 投影到 h 个子空间并行计算，拼接后再线性变换
Transformer 块 = 多头自注意力 + FFN，各带残差连接与 LayerNorm（Repeat × L）
```

除以 `√d_k` 的原因：维度高时点积方差变大，softmax 会进入梯度极小的饱和区。

::: danger 易错 · 注意力
- 编码器用**双向**自注意力；解码器必须加**因果掩码**防止「看到未来词」，否则训练时泄露答案。
- 自注意力本身不含顺序信息，必须补**位置编码**（正弦 / 可学习 / RoPE）。
- 「多头」不是多模型集成，而是让不同子空间关注不同关系。
:::

### 9.4 自编码器与表征学习（补充）

自编码器 `编码器 z=f(x) → 解码器 x̂=g(z)`，以重构损失 `‖x−x̂‖²` 作自监督信号，把「无监督」转化为一种监督学习。变体：降噪 AE、稀疏 AE、变分 AE（第 12 章）。当瓶颈维小于输入维时，等价于一种非线性 PCA。

::: tip 补充 · 现代训练范式
预训练（大规模自监督）→ 微调（下游任务）已成为主流；对比学习（SimCLR/MoCo）、掩码建模（BERT/MAE）、提示学习与参数高效微调（LoRA）都是课件未覆盖但工程必备的方向。
:::

### 9.5 归一化的两种粒度与 Transformer 块的维度流（深挖）

| 维度 | BatchNorm | LayerNorm |
| --- | --- | --- |
| 归一化轴 | 对**每个特征/通道**在 batch 与空间维上求均值方差 | 对**每个样本**在特征维上求均值方差 |
| 依赖 batch | 强依赖，小 batch 统计量不稳 | 不依赖，训练/推理一致 |
| 适用 | CNN（固定通道、大 batch） | Transformer / RNN / 变长序列 |
| 推理 | 用训练期滑动平均 | 直接按当前样本计算 |

Transformer 使用 **LayerNorm**（多为 Pre-LN：`x + Sublayer(LN(x))`），因为序列长度可变、batch 内各样本有效 token 数不同，BN 无法定义稳定的跨样本统计量。

```text
一个编码器块的完整维度流（n=序列长，d=d_model，h=头数，d_k=d_v=d/h）：
X ∈ R^{n×d}
 → Q=XW_Q ∈ R^{n×d}, K=XW_K, V=XW_V（投影矩阵 d×d）
 → 每个头：A_i = softmax(Q_iK_iᵀ/√d_k) ∈ R^{n×n}；head_i = A_i V_i ∈ R^{n×d_k}
 → MultiHead = Concat(head_1,…,head_h) W^O ∈ R^{n×d}
 → 残差 + LayerNorm → FFN: d → d_ff(常取 4d) → d，再残差 + LayerNorm
参数量 ≈ 4d²（QKV + 输出投影） + 2·d·d_ff（FFN）≈ 12d²（d_ff=4d 时）
```

::: tip 工作例题 · 参数量估算
`d_model=512`、`d_ff=2048`、12 层：每层注意力 `4×512²=1,048,576`，FFN `2×512×2048=2,097,152`，合计约 `3.15M`/层，12 层约 **37.7M** 参数（不含嵌入与输出头）。这解释了为何大模型参数量主要由 `d_model²` 与层数决定。
:::

::: danger 易错 · 维度与掩码
- `QKᵀ` 是 `n×n`，因此掩码是**方阵**（因果掩码为上三角 −∞）；不是 `d×d`。
- 多头拆分后每头维度 `d/h`，拼接后仍是 `d`，`W^O` 负责混合各头信息；不能把多头理解成把 `d` 变大。
- Pre-LN 与 Post-LN 的梯度行为不同：Pre-LN 更稳定、通常不需要很长 warmup，这也是现代 LLM 普遍采用它的原因。
:::

## 第 10 章 无监督学习（★★★）

![无监督学习：K 均值、EM/GMM、PCA 与 ICA](/mlt/mlt-unsupervised.svg)

### 10.1 K 均值聚类（课件 Part-1）

目标是把 N 个 d 维样本分到 K 个簇，最小化类内平方和：

```text
J = Σₙ Σₖ rₙₖ ‖xₙ − μₖ‖²
E 步（硬分配）：rₙₖ = 1 若 k = argminⱼ ‖xₙ−μⱼ‖²，否则 0
M 步（重算质心）：μₖ = Σₙ rₙₖ xₙ / Σₙ rₙₖ
```

```python
import numpy as np
def kmeans(X, K, iters=20, seed=42):
    rng = np.random.default_rng(seed)
    mu = X[rng.choice(len(X), K, replace=False)]      # 随机初始化
    for _ in range(iters):
        dist = ((X[:, None, :] - mu[None, :, :]) ** 2).sum(-1)
        lab = dist.argmin(1)                          # E 步
        new = np.array([X[lab == k].mean(0) for k in range(K)])
        if np.allclose(new, mu): break                # J 单调下降至收敛
        mu = new
    return mu, lab
```

::: danger 易错 · K-means
- 须**预设 K**；对初始质心与异常值敏感（用 K-means++ 与多次重启）。
- 假设簇近似**球形且大小相近**、须先标准化；非凸形状用 DBSCAN / 谱聚类 / 核 K-means。
- 交替最小化保证 `J` 单调下降，但只收敛到**局部极小**，不是全局最优。
- 聚类无标签，不能用准确率评价；用轮廓系数、肘部法或业务可解释性。
:::

### 10.2 EM 算法与高斯混合模型 GMM

GMM 假设数据由 K 个高斯成分混合生成：`p(x)=Σₖ πₖ N(x|μₖ,Σₖ)`，隐变量 `zₖ` 表示成分归属。直接最大化对数似然 `Σ log p(xₙ)` 因 log 内有求和而困难，EM 通过交替两步保证似然单调不降：

```text
E 步：γ(zₙₖ) = p(zₖ=1|xₙ) = πₖN(xₙ|μₖ,Σₖ) / Σⱼ πⱼN(xₙ|μⱼ,Σⱼ)   （责任度，软分配）
M 步：Nₖ = Σₙ γ(zₙₖ)；πₖ = Nₖ/N；
      μₖ = Σₙγ(zₙₖ)xₙ / Nₖ；Σₖ = Σₙγ(zₙₖ)(xₙ−μₖ)(xₙ−μₖ)ᵀ / Nₖ
```

::: tip 补充 · K-means 是 GMM 的特例
当各成分协方差取 `σ²I` 且令 `σ²→0` 时，GMM 的软责任度退化为 0/1 硬分配，EM 的 M 步退化为重算质心——**K-means 是 GMM 的硬分配极限**。理解这一点就打通了第 10 章两个算法的联系。
:::

::: danger 易错 · EM
EM 只能保证收敛到**局部极大**，初值敏感；协方差矩阵奇异（成分坍缩到单点）时须加正则。EM 还广泛用于隐马尔可夫模型（Baum-Welch）、缺失数据与混合回归，不限于聚类。
:::

### 10.3 降维：PCA 与 ICA（课件 Part-2）

| 维度 | PCA 主成分分析 | ICA 独立分量分析 |
| --- | --- | --- |
| 模型 | 找方差最大的**正交**方向 | `x = As`，求相互**统计独立**的源 s |
| 统计量 | 二阶（协方差矩阵特征值） | 高阶 / 非高斯性（负熵、峭度） |
| 约束 | 成分互不相关且正交 | 成分独立（更强，不要求正交） |
| 目标 | 最小化重构误差、最优低秩逼近 | 盲源分离 |
| 应用 | 降维、去噪、可视化 | 鸡尾酒会问题、EEG/MEG 去伪迹 |

```python
import numpy as np
# PCA：中心化 → 协方差 → 特征分解 → 取前 m 个特征向量
X = np.array([[1., 2.], [2., 1.], [3., 3.], [4., 3.], [5., 5.]])
Xc = X - X.mean(0)
vals, vecs = np.linalg.eigh(np.cov(Xc.T))
W = vecs[:, ::-1][:, :1]                 # 最大特征值对应的方向
Z = Xc @ W                               # 降到 1 维的主成分得分
print('解释方差比', (vals[::-1] / vals.sum()).round(4))
```

::: tip 补充 · PCA 与 LDA 的区别
PCA **无监督**（不用标签，最大化总方差），LDA **有监督**（用标签，最大化类间/类内散度比）——二者虽都做线性投影，但优化目标完全不同，是最高频的易混点。
:::

::: danger 易错 · 降维
- PCA 前必须标准化，否则量纲大的变量主导第一主成分；ICA 前通常先**白化**。
- 主成分只保证「累计方差最大」，不保证业务可解释性；必要时用因子分析 + 旋转。
- 主成分互不相关 ≠ 相互独立（独立是更强条件，这正是 ICA 要解决的）。
:::

### 10.4 PCA 的两种等价推导（深挖）

课件 Part-2 从「用低维向量逼近样本」出发讲 PCA，另一常见讲法是「找方差最大的投影方向」。二者数学上完全等价：

**推法 A · 最大化投影方差**（设数据已中心化，协方差 `S=(1/N)XᵀX`）

```text
max_w wᵀSw   s.t. ‖w‖=1
L = wᵀSw − λ(wᵀw − 1)；∂L/∂w = 2Sw − 2λw = 0 ⇒ Sw = λw
⇒ w 是 S 的特征向量，且目标值 wᵀSw = λ ⇒ 取最大特征值对应的 w
后续主成分在与已选方向正交的约束下依次取次大特征值
```

**推法 B · 最小化重构误差**（把 x 投影到 w 方向再还原）

```text
min_w ‖X − (Xw)wᵀ‖_F²  s.t. ‖w‖=1
展开 = tr(S) − wᵀSw（常数 − 被最大化的项）
⇒ 最小化重构误差 ⇔ 最大化 wᵀSw ⇔ 推法 A
```

**结论**：最优的 m 维子空间由 `S` 的前 m 个特征向量张成（Eckart–Young 定理），最小重构误差为被丢弃特征值之和 `Σ_{j>m}λⱼ`。这就把「方差最大」「重构误差最小」「协方差特征分解」三句话统一成一个结论。

::: tip 工作例题 · 贡献率与重构误差
协方差特征值 `λ=(2.4, 0.9, 0.5, 0.2)`、`Σλ=4`：
前 2 个累计贡献率 `= 3.3/4 = 82.5%`；丢弃部分 `= 0.5+0.2 = 0.7`，占总量 `17.5%`，正是保留 2 个主成分的最小重构误差。
:::

::: danger 易错 · PCA 推导
- 数据必须**中心化**（减均值）后协方差矩阵才等于 `S=(1/N)XᵀX`；若还要消除量纲影响，需先标准化（此时 `S` 实为相关矩阵）。
- `S` 半正定保证特征值非负；特征向量符号可整体翻转，不影响子空间与重构结果。
- 核 PCA 用 Gram 矩阵的特征分解替代 `S`，对应高维特征空间中的 PCA；与第 6 章核技巧同源。
- PCA 是**线性**降维；流形结构需 ISOMAP/LLE/t-SNE/UMAP（补充，课件未涉及）。
:::

## 第 11 章 强化学习（★★）

![强化学习：MDP、值函数与策略优化](/mlt/mlt-rl.svg)

### 11.1 MDP 与回报（课件 RL-1）

强化学习研究智能体（agent）如何在环境（environment）中通过行动最大化**长期累计收益**。建模为马尔可夫决策过程五元组 `(S, A, P, R, γ)`，满足马尔可夫性：`P(Sₜ₊₁|Sₜ, Aₜ)` 与更早的历史无关。

```text
折扣回报  Gₜ = Rₜ₊₁ + γRₜ₊₂ + γ²Rₜ₊₃ + … = Σₖ γᵏ Rₜ₊ₖ₊₁   （0 ≤ γ < 1）
状态值    V^π(s) = E_π[Gₜ | Sₜ = s]
动作值    q^π(s,a) = E_π[Gₜ | Sₜ = s, Aₜ = a]
关系      V^π(s) = Σₐ π(a|s) q^π(s,a)
```

::: danger 易错 · 折扣与目标
强化的目标是**累计回报**而非单步奖励：`γ` 小则短视、大则远视。若任务有明确终止时刻可用 `γ=1`；持续性任务必须 `γ<1` 保证回报有界。「即时奖励最高的动作」往往不是最优动作。
:::

### 11.2 贝尔曼方程与求解路线

```text
贝尔曼期望：V^π(s) = E_π[Rₜ₊₁ + γV^π(Sₜ₊₁) | Sₜ=s]
贝尔曼最优：V*(s) = maxₐ E[Rₜ₊₁ + γV*(Sₜ₊₁) | Sₜ=s, Aₜ=a]
           q*(s,a) = E[Rₜ₊₁ + γ maxₐ′ q*(Sₜ₊₁,a′) | Sₜ=s, Aₜ=a]
```

| 路线 | 代表 | 是否需要环境模型 | 特点 |
| --- | --- | --- | --- |
| 动态规划 | 策略/值迭代 | **需要** P、R | 表格型、精确但受限于状态规模 |
| 蒙特卡罗 | MC 控制 | 不需要 | 需完整回合、无偏但方差大 |
| 时序差分 | SARSA（on-policy）、**Q-learning**（off-policy） | 不需要 | 单步自举、可在线 |
| 函数逼近 | DQN、V̂(s,w)=x(s)ᵀw | 不需要 | 处理大规模/连续状态 |
| 策略优化 | REINFORCE、Actor-Critic、DDPG/PPO | 不需要 | 直接优化策略、支持连续动作 |

```text
Q-learning（off-policy）：
Q(s,a) ← Q(s,a) + α [ r + γ·maxₐ′ Q(s′,a′) − Q(s,a) ]
                                  └────── TD 目标 ──────┘   └── TD 误差 δ ──┘
```

::: tip 工作例题 · 一次 Q-learning 更新
`Q(s,a)=0.5`、`r=1`、`γ=0.9`、`maxₐ′Q(s′,·)=0.8`、`α=0.1`：
TD 目标 `= 1 + 0.9×0.8 = 1.72`；`δ = 1.72 − 0.5 = 1.22`；
`Q ← 0.5 + 0.1×1.22 = 0.622`。
课件 RL-2 给出的通用更新式 `Δw = α(目标 − 预测)·x(s)` 正是把这里的 δ 乘上特征向量——即「**步长 × 预测误差 × 特征值**」。
:::

::: danger 易错 · on/off policy
Q-learning 用下一状态**最大** Q 作目标，故是 off-policy（可按任意行为策略采样）；SARSA 用**实际采取的下一个动作** `Q(s′,a′)`，是 on-policy。二者在带陷阱的网格世界中会给出不同策略，不要混淆。
:::

### 11.3 大规模强化学习（课件 RL-2）

| 问题 | 方法 |
| --- | --- |
| 状态空间巨大 | 值函数逼近 `V̂(s,w)=x(s)ᵀw` 或用神经网络（DQN） |
| 训练不稳定 | 经验回放（打破样本相关）、目标网络（固定 TD 目标） |
| 连续动作 | 策略梯度 / Actor-Critic / 确定性策略梯度 DDPG |
| 探索-利用 | ε-贪心、UCB、Boltzmann 探索、熵正则 |

::: tip 补充 · 策略梯度定理
`∇_θ J(θ) = E_π[ Gₜ · ∇_θ log π_θ(Aₜ|Sₜ) ]`（REINFORCE）：用回报加权「对数策略梯度」，高回报动作被强化。Actor-Critic 用 Critic 估计的值函数替代 `Gₜ` 以降低方差；PPO 通过裁剪重要性采样比限制策略更新幅度，是课件未覆盖的现代主流算法。
:::

### 11.4 动态规划：策略评估、策略迭代与值迭代（深挖）

当环境模型 `P(s′|s,a)` 与 `R(s,a)` 已知时，可不用采样直接解 MDP。三类算法共享一个核心算子：

```text
策略评估（反复迭代直到收敛）：
  V_{k+1}(s) = Σₐ π(a|s) Σ_{s′} P(s′|s,a)[ R(s,a,s′) + γ V_k(s′) ]
策略改进：π′(s) = argmaxₐ Σ_{s′} P(s′|s,a)[R + γ V^π(s′)]
策略迭代：评估（至收敛）→ 改进 → 重复，直到策略不再变化
值迭代（把评估压缩为一步并直接取 max）：
  V_{k+1}(s) = maxₐ Σ_{s′} P(s′|s,a)[ R(s,a,s′) + γ V_k(s′) ]
```

值迭代的本质是**贝尔曼最优算子是不动点迭代**：算子是 γ-压缩映射，故从任意 `V₀` 出发都收敛到唯一 `V*`，误差按 `γᵏ` 衰减。这正是「γ 越小收敛越快、但越短视」的数学根源。

::: tip 工作例题 · 两状态 MDP 的值迭代（γ=0.9）
设 `s₁` 执行动作得 `r=1` 并转移到 `s₂`；`s₂` 执行动作得 `r=0`，以 0.5 概率回到 `s₁`、0.5 概率终止。
递推式为 `V(s₁)=1+0.9V(s₂)`、`V(s₂)=0.9×0.5×V(s₁)=0.45V(s₁)`。
从 `V₀=(0,0)` 迭代：
`k=1: (1.00000, 0)` → `k=2: (1.00000, 0.45000)` → `k=3: (1.40500, 0.45000)` → `k=4: (1.40500, 0.63225)` → `k=5: (1.56902, 0.63225)` → `k=6: (1.56902, 0.70606)` …
解析解：把 `V(s₂)=0.45V(s₁)` 代入第一式 → `V(s₁)=1/(1−0.9×0.45)=1/0.595≈1.6807`，`V(s₂)≈0.7563`，与迭代极限一致。
:::

```python
# 值迭代的通用骨架（纯 Python，无第三方依赖）
gamma = 0.9
V = {'s1': 0.0, 's2': 0.0}
for k in range(1, 40):
    V1 = 1 + gamma * V['s2']
    V2 = gamma * 0.5 * V['s1']
    if max(abs(V1 - V['s1']), abs(V2 - V['s2'])) < 1e-8:
        break
    V = {'s1': V1, 's2': V2}
print(k, round(V['s1'], 4), round(V['s2'], 4))   # ≈ 1.6807  0.7563
```

::: danger 易错 · 动态规划
- 策略迭代的「评估」要跑到收敛，值迭代只做**一步**就取 max；把二者混写会得到错误算法。
- 值迭代中间量 `V_k` 不对应任何具体策略（只是下界序列），只有收敛后的 `V*` 才是最优值函数。
- 动态规划要求**已知模型**且需遍历全部状态，状态空间大时用函数逼近（第 11.3 节）替代。
:::

### 11.5 蒙特卡罗、TD 与资格迹（深挖）

| 维度 | 蒙特卡罗 MC | 时序差分 TD(0) |
| --- | --- | --- |
| 更新时机 | 回合结束（需完整轨迹） | 每步在线 |
| 目标 | 实际回报 `Gₜ` | `Rₜ₊₁+γV̂(Sₜ₊₁)`（自举） |
| 偏差 / 方差 | 无偏、方差大 | 有偏（自举）、方差小 |
| 适用 | 有终止的回合任务 | 持续性任务也可 |

`TD(λ)` 用**资格迹**在 MC 与 TD(0) 之间插值：`λ=0` 退化为单步 TD、`λ=1` 近似 MC；实践中 λ∈[0.8,0.95] 常取得更低误差。

::: tip 工作例题 · 一次 TD 与 MC 的差别
轨迹 `s₀ --(r=0)--> s₁ --(r=1)--> 终止`，`γ=0.9`，初始 `V(s₀)=V(s₁)=0.5`，终止状态值恒为 0。
- **在 s₁ 处**：TD 目标 `= 1 + 0.9×0 = 1`，故 `δ = 1 − 0.5 = 0.5`（一步即可修正）；
- **在 s₀ 处**：TD 目标 `= 0 + 0.9×V(s₁) = 0 + 0.9×0.5 = 0.45`，用的是**对 s₁ 的估计**（自举）；
- **MC** 必须等回合结束，用实际回报 `G(s₀) = 0 + 0.9×1 = 0.9` 作目标。

可见 TD 只需一步就能更新、方差更小，但目标里含尚未学准的 `V(s₁)`，故有偏；MC 无偏却要等完整轨迹、方差更大。
:::

### 11.6 DQN 的三大稳定化机制与改进（深挖）

用神经网络近似 `Q(s,a;w)` 时，直接按 TD 误差训练极易发散，因为：① 样本强相关（连续帧）；② TD 目标依赖自身参数（移动靶）；③ 奖励尺度差异大。DQN 的三项对策：

| 机制 | 做法 | 解决 |
| --- | --- | --- |
| 经验回放 | 把 `(s,a,r,s′)` 存入缓冲区，随机小批量采样 | 打破样本相关性、提高数据复用 |
| 目标网络 | 单独冻结一份 `w⁻`，每 C 步同步一次 | 固定 TD 目标，避免「移动靶」 |
| 奖励裁剪 / Huber | 把奖励压到 `[-1,1]`、用 Huber 损失 | 稳定梯度尺度 |

```text
DQN 损失：L(w) = E_{(s,a,r,s′)~D}[ ( r + γ·maxₐ′ Q(s′,a′; w⁻) − Q(s,a;w) )² ]
改进：Double DQN（用在线网络选动作、目标网络估值，缓解过高估计）
      Dueling DQN（拆成 V(s) + A(s,a)）、优先经验回放（按 |δ| 采样）
```

::: danger 易错 · DQN
- 目标网络参数 `w⁻` **不参与梯度回传**，只周期性复制；把它当可训练参数会使目标随梯度漂移。
- Double DQN 解决的是 `max` 带来的**系统性高估**，不是梯度消失。
- 经验回放是 off-policy 才成立；on-policy 的策略梯度不能用旧策略数据回放。
:::

### 11.7 策略梯度定理推导与 Actor-Critic（深挖）

目标 `J(θ)=V^{π_θ}(s₀)=E_{π_θ}[Σ_t γᵗ R_t]`。用**似然比技巧**（log-derivative trick `∇π = π∇log π`）：

```text
∇_θ J(θ) = E_{π_θ}[ Σ_t ∇_θ log π_θ(A_t|S_t) · Q^{π_θ}(S_t,A_t) ]
          = E_{π_θ}[ Σ_t ∇_θ log π_θ(A_t|S_t) · A^{π}(S_t,A_t) ]
其中 A(s,a)=Q(s,a)−V(s) 称优势函数；减去任意只依赖 s 的基线 b(s) 不改变期望、
却能显著降低方差（因 E[∇log π · b(s)] = b(s)∇Σπ = 0）
```

```python
import math
# 一步策略梯度的数值示意
def grad_log_pi(a_logit, other_logits):
    e = [math.exp(v) for v in [a_logit] + other_logits]
    p = e[0] / sum(e)
    return 1 - p                    # softmax 对选中 logit 的导数
G, dlog = 2.0, 0.4                 # 回报与对数梯度（示意）
print('更新量 ∝', G * dlog)         # 0.8，正回报强化该动作
```

| 算法族 | 核心 | 动作空间 |
| --- | --- | --- |
| REINFORCE | 用完整 `Gₜ` 加权 log 梯度 | 离散/连续，方差大 |
| Actor-Critic (A2C/A3C) | Critic 估 `V` 给优势，Actor 更新策略 | 离散/连续 |
| TRPO | 用 KL 约束限制策略更新（信赖域） | 连续 |
| **PPO** | 裁剪重要性比 `clip(rₜ,1−ε,1+ε)`，易实现 | 通用，现代主流 |
| DDPG / TD3 / SAC | 确定性策略或最大熵框架 | **连续动作** |

::: danger 易错 · 策略梯度
- 基线 `b(s)` 必须**只依赖状态**，若依赖动作会引入偏差。
- PPO 的裁剪目标不是「限制梯度范数」，而是限制新旧策略概率比；同一次采样可多轮小批量更新（这是它比普通策略梯度样本效率高的原因）。
- DQN 输出离散动作的 Q 值，无法直接处理连续动作（无法对连续 a 取 max），这正是 DDPG/SAC 存在的原因。
:::

### 11.8 本章补充结论与自测

| 结论 | 说明 |
| --- | --- |
| 马尔可夫性 | 转移只依赖当前状态与动作；不满足时须把历史编码进状态（或改用 RNN 策略） |
| 探索-利用 | ε-贪心、UCB、Boltzmann、熵正则；ε 应随训练衰减 |
| 折扣与收敛 | γ<1 使贝尔曼算子成为压缩映射，保证值迭代收敛 |
| 值 vs 策略 | 值方法先学 Q 再贪心；策略方法直接优化 π，天然支持随机策略与连续动作 |
| 自举与偏差 | TD 用估计更新估计，带来偏差但降方差；与 MC 构成偏差-方差权衡 |

:::

## 第 12 章 深度生成模型（★★）

![深度生成模型：VAE / GAN / 扩散 / 归一化流](/mlt/mlt-generative.svg)

四类模型共同目标：从 i.i.d. 样本集学习数据分布 `p_data(x)`，并能生成新样本。

### 12.1 VAE 与变分下界（课件 DGM-2）

概率编码器 `q_φ(z|x)` + 解码器 `p_θ(x|z)`，隐变量 `z` 与样本同维或更低维。因 `log p_θ(x)=log ∫p_θ(x|z)p(z)dz` 不可解析，改最大化 **ELBO（证据下界）**：

```text
log p_θ(x) ≥ E_{q_φ(z|x)}[log p_θ(x|z)] − D_KL(q_φ(z|x) ‖ p(z))
               └──── 重构项（越准越好） ────┘   └─ 正则项（后验贴近先验）─┘
```

**重参数技巧**：`z = μ_φ(x) + σ_φ(x)⊙ε`，`ε~N(0,I)`，把随机性转移到无参数噪声，使梯度可经 μ、σ 回传（课件示例取 `M=100, L=1` 蒙特卡罗估计）。

::: danger 易错 · VAE
- 优化的是**似然下界**而非精确似然；`D_KL` 方向固定为 `q‖p`，交换会得到不同目标。
- KL 项过大时会出现「后验坍缩」（解码器忽略 z）；β-VAE 用系数权衡重构与解耦。
- VAE 生成样本常偏模糊（高斯假设 + 逐像素似然），GAN/扩散通常更清晰。
:::

### 12.2 GAN：极小极大博弈（课件 DGM-1）

```text
min_G max_D V(D,G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 − D(G(z)))]
判别器 D：梯度上升（区分真假）；生成器 G：梯度下降（骗过 D）
理论均衡：p_g = p_data 且 D(x) = 0.5
```

::: tip 补充 · 训练难点与改进
难点：**模式崩塌**（只生成少数几种样本）、训练震荡、生成器梯度消失。改进：WGAN（Wasserstein 距离提供平滑梯度）、DCGAN（卷积结构约束）、条件 GAN（cGAN）、StyleGAN、谱归一化。评估用 FID / IS 而非「看起来像不像」。
:::

### 12.3 扩散模型与归一化流（课件 DGM-3）

```text
前向加噪（固定 Markov 链）：xₜ = √αₜ·xₜ₋₁ + √(1−αₜ)·ε，  ε~N(0,I)
一步到位：q(xₜ|x₀) = N(√ᾱₜ x₀, (1−ᾱₜ)I)，ᾱₜ = Π_{s≤t} αₛ
反向去噪（需学习）：p_θ(xₜ₋₁|xₜ) = N(μ_θ(xₜ,t), Σ_θ)，从纯噪声逐步还原样本
训练目标：预测所加噪声 ε（简化后等价于变分下界的一项）
```

| 模型 | 似然 | 采样 | 主要特点 |
| --- | --- | --- | --- |
| VAE | 下界 | 一次前向 | 训练稳、有编码器，样本偏模糊 |
| GAN | 无显式似然 | 一次前向 | 样本清晰、训练不稳、易模式崩塌 |
| 扩散 | 变分下界 | **多步迭代** | 质量高、训练稳，但采样慢 |
| 归一化流 | **精确** `log p(x)=log p(z)+Σlog|det J|` | 一次可逆变换 | 要求变换可逆、维度不变 |

::: danger 易错 · 生成模型
- 扩散的「前向加噪」是**固定**、无需学习的过程；只有「反向去噪网络」含参数。
- 归一化流要求变换**双射且 Jacobian 行列式可算**，因此不能随意在中间降维。
- 「隐变量与样本同维度」（课件语）指扩散的 xₜ 序列，不是 VAE 的瓶颈 z，两者概念不同。
:::

### 12.4 VAE 的 ELBO 完整推导（深挖）

直接从 `log p_θ(x)` 出发，引入任意变分分布 `q_φ(z|x)`：

```text
log p_θ(x) = log ∫ p_θ(x|z)p(z) dz
          = log ∫ q(z|x) · [p_θ(x|z)p(z)/q(z|x)] dz
          = log E_q[ p_θ(x|z)p(z)/q(z|x) ]
          ≥ E_q[ log p_θ(x|z)p(z)/q(z|x) ]            （Jensen，log 是凹函数）
          = E_q[log p_θ(x|z)] − D_KL(q_φ(z|x) ‖ p(z)) ≜ ELBO
```

另一种推法（更直观）：

```text
D_KL(q_φ(z|x) ‖ p_θ(z|x)) = E_q[log q − log p_θ(x|z) − log p(z)] + log p_θ(x)
整理得：log p_θ(x) = ELBO + D_KL(q ‖ p_θ(z|x)) ≥ ELBO
```

两式说明：**最大化 ELBO 等价于同时（a）提升重构似然、（b）让近似后验贴近真实后验**；当 `q_φ=p_θ(z|x)` 时 KL 项为 0、界取等——这正是 EM 中 E 步取 `q=p(z|x,θ^old)` 的同一思想（第 10 章）。

**重参数技巧**：直接对 `z~q_φ` 采样无法把梯度传给 φ，改写 `z = μ_φ(x) + σ_φ(x)⊙ε`、`ε~N(0,I)`，则

```text
∇_φ E_q[log p_θ(x|z)] = E_ε[ ∇_φ log p_θ(x | μ_φ + σ_φ⊙ε) ]
```

课件示例 `M=100, L=1` 即每批次 100 个样本、每样本 1 次蒙特卡罗采样估计该期望。

::: tip 工作例题 · KL 项的方向
取 `q=(0.5,0.5)`、`p=(0.9,0.1)`：`D_KL(q‖p)=Σq log(q/p)=0.5108`；
反向 `D_KL(p‖q)=0.3681`。二者不相等，说明 ELBO 中 KL 的**方向不可随意交换**：
`q‖p`（反向 KL，VAE 用）倾向「模式寻找」，会低估方差；`p‖q`（前向 KL）倾向「质量覆盖」。这解释了 VAE 生成偏模糊的统计根源之一。
:::

::: tip 补充 · 后验坍缩与 β-VAE
若解码器过强，最优解会让 `q_φ(z|x)=p(z)`（KL=0）而完全忽略隐变量，称**后验坍缩**。
对策：KL 退火（训练初期把 KL 权重从 0 渐升）、β-VAE 用 `重构项 − β·KL`（β>1 强化解耦、β<1 提升重构）、free-bits（给每维 KL 设下限）。
:::

### 12.5 GAN：最优判别器与 JS 散度（深挖）

固定生成器 G，对判别器 D 逐点求导（把 `V(D,G)` 写成积分）：

```text
V(D,G) = ∫ p_data(x) log D(x) dx + ∫ p_g(x) log(1−D(x)) dx
对 D(x) 求导并令为 0：p_data/D − p_g/(1−D) = 0
⇒ D*(x) = p_data(x) / (p_data(x) + p_g(x))
```

代回目标函数：

```text
V(D*,G) = 2·JS(p_data ‖ p_g) − 2log2
```

JS 散度非负、在两分布完全相同时取 0，故全局最优为 `p_g=p_data`，此时 `D*=0.5`、目标值 `= −2log2 ≈ −1.3863`。

::: danger 易错 · GAN 失败模式
- 当 `p_data` 与 `p_g` **支撑集不重叠**（常见于高维图像）时 JS 恒为 `log2`，梯度为 0 → 生成器收不到有效信号，即「梯度消失」。WGAN 改用 Wasserstein 距离（要求判别器 1-Lipschitz，用梯度惩罚或权重裁剪）提供处处非零的梯度。
- **模式崩塌**：生成器只覆盖少数几个模式，但 JS 散度/判别器准确率未必能反映多样性缺失。
- 「判别器越好越难训练生成器」与「判别器太差给不出有效梯度」是一对矛盾，实践中靠谱归一化、TTUR、标签平滑平衡。
:::

### 12.6 扩散模型的完整推导（深挖）

**前向（固定、无参数）**：`q(xₜ|xₜ₋₁)=N(√αₜ·xₜ₋₁, (1−αₜ)I)`，即 `xₜ=√αₜ xₜ₋₁+√(1−αₜ)ε`。反复代入并利用高斯可加性得**一步闭式**：

```text
ᾱₜ = Π_{s=1}^{t} α_s
q(xₜ|x₀) = N( √ᾱₜ·x₀ , (1−ᾱₜ)I )
xₜ = √ᾱₜ·x₀ + √(1−ᾱₜ)·ε ,  ε~N(0,I)
```

**反向（需学习）**：真实后验 `q(xₜ₋₁|xₜ,x₀)` 也是高斯，其均值可解析写出；训练网络 `ε_θ` 预测所加噪声后：

```text
μ_θ(xₜ,t) = (1/√αₜ)·[ xₜ − (1−αₜ)/√(1−ᾱₜ) · ε_θ(xₜ,t) ]
p_θ(xₜ₋₁|xₜ) = N( μ_θ(xₜ,t), σₜ² I )
简化训练目标：L_simple = E_{t,x₀,ε} ‖ ε − ε_θ(√ᾱₜx₀+√(1−ᾱₜ)ε, t) ‖²
```

课件中「扩散模型 = 隐变量与样本同维度的 Markov 链」即指 `x₁,…,x_T` 序列；它与 VAE 的瓶颈 z 不是一回事。

::: tip 工作例题 · 前向加噪的数值演算
取 `αₜ≡0.9` → `ᾱ₁=0.9, ᾱ₂=0.81, ᾱ₃=0.729, ᾱ₄=0.6561, ᾱ₅=0.5905`。
设 `x₀=2`、`ε=0.5`、`t=3`：
`x₃ = √0.729×2 + √(1−0.729)×0.5 ≈ 1.7076 + 0.2603 ≈ 1.9679`。
ᾱₜ 单调下降 → 信号系数趋于 0、噪声系数趋于 1，最终分布收敛到 `N(0,I)`，这正是「加噪到纯噪声」的定量说明。
:::

::: tip 补充 · 采样加速与条件生成
DDPM 需逐步去噪 T 次（常 1000 步）；**DDIM** 构造非马尔可夫但同边际的反向过程，可跳步采样（几十步）；此外还有 DDPM+分类器引导、Classifier-Free Guidance（CFG）、Latent Diffusion（在低维潜空间扩散）与基于 score/概率流的采样器。
:::

### 12.7 归一化流：变量变换与耦合层（深挖）

设 `z=f_θ(x)` 可逆且可微，由概率密度变量变换公式：

```text
p_X(x) = p_Z(f_θ(x)) · |det ∂f_θ/∂x|
log p_X(x) = log p_Z(z) + log |det J_f|
```

因此训练目标就是**最大化 `log p_X(x)`**（精确似然，不需下界）。难点在 Jacobian 行列式一般是 O(d³)，故设计**三角 Jacobian** 的耦合层（RealNVP）：

```text
把 x 切成 (x₁, x₂)：
  y₁ = x₁                                （原样复制）
  y₂ = x₂ ⊙ exp(s(x₁)) + t(x₁)          （仿射变换，s/t 为任意网络）
Jacobian 为下三角 ⇒ det J = exp( Σᵢ s_i(x₁) )
逆变换：x₂ = (y₂ − t(y₁)) ⊙ exp(−s(y₁))，无需反演网络
```

::: tip 工作例题 · 行列式计算
若某耦合层输出 `s=(0.2, −0.3, 0.5)`，则 `log|det J| = Σs = 0.4`、`|det J| ≈ 1.4918`。
堆叠多层并交替通道掩码，即可构造表达力强且可逆的流（Glow 再加 1×1 可逆卷积）。
:::

::: danger 易错 · 归一化流
- 变换必须**双射**，故隐变量 z 与 x **维度相同**，不能像 VAE 那样随意降维（这是它与其它生成模型的根本约束）。
- `log p_Z` 常取标准正态；若 `s(x₁)` 数值过大，`exp(s)` 会溢出，实践中要对 s 做 tanh 或裁剪。
- 「精确似然」不等于「生成质量更好」：似然高的模型可能把容量花在难察觉的背景像素上。
:::

### 12.8 生成模型的评估与选型（深挖补充）

| 指标 | 做法 | 局限 |
| --- | --- | --- |
| IS（Inception Score） | 用分类网络看生成图的类别清晰度与多样性 | 不比较真实分布、易被对抗攻击 |
| **FID** | 比较真实/生成图在 Inception 特征空间的均值与协方差（Fréchet 距离） | 需足够样本、假设特征近似高斯 |
| Precision / Recall for Generative Models | 分别衡量「真实性」与「覆盖度」 | 需定义特征流形 |
| 人工评估 / 下游任务 | 主观质量、下游分类增益 | 成本高、不可复现 |

::: tip 四类模型再对照（含本轮推导结论）
| 模型 | 优化目标 | 似然 | 采样 | 主要失败模式 |
| --- | --- | --- | --- | --- |
| VAE | ELBO（重构 − KL） | 下界 | 1 次 | 后验坍缩、样本模糊 |
| GAN | `min_G max_D V` ↔ JS/Wasserstein | 无 | 1 次 | 模式崩塌、训练不稳 |
| 扩散 | 噪声预测 / 变分下界 | 下界 | 多步 | 采样慢 |
| 归一化流 | 精确 `log p` | **精确** | 1 次 | 可逆约束限制表达力 |
:::

::: danger 易错 · 评估
不能用「训练集上的似然」判断过拟合，必须用**留出集**；FID 越低越好但受样本量与特征提取器影响，跨论文比较须同协议。生成模型同样要防数据泄露与记忆训练样本（成员推断风险）。
:::

### 深 1 泛化界、VC 维与「为什么需要正则」（补第 1、5 章）

课件第 5 讲给出了有限假设空间的 Hoeffding 型泛化界。对 `|H|` 有限、样本 i.i.d.，以概率不小于 `1−δ`：

```text
R(h) − R̂(h) ≤ √[(ln|H| + ln(2/δ)) / (2N)]
```

::: tip 工作例题
`|H|=1000`、`N=100`、`δ=0.05` → 上界 `= √[(6.9078+3.6889)/200] ≈ 0.2302`。
即训练误差 0.05 的模型，真实误差可能高达约 0.28。把假设空间扩大 10 倍（ln|H| 增大）或样本减半，上界都会变大——这正是「**模型越复杂、数据越少，越要正则化/早停**」的定量依据。
:::

::: tip 补充 · 无限假设空间
`|H|` 无限时上式失效，需用 **VC 维** `d_VC`（能否打散的最大点数）或 Rademacher 复杂度，上界变为 `O(√((d_VC log(N/d_VC)+log(1/δ))/N))`。深度网络参数量远大于 VC 上界却仍泛化良好，说明传统容量度量不足，需要「隐式正则化」（SGD 偏好平坦极小、架构先验）来解释——这是当代研究课题。
:::

### 深 2 SVM 对偶与 KKT 完整推导（补第 6 章）

```text
L(w,b,α) = ½‖w‖² − Σᵢ αᵢ[yᵢ(wᵀxᵢ+b) − 1]，αᵢ ≥ 0
∂L/∂w = 0 ⇒ w = Σᵢ αᵢ yᵢ xᵢ        （最优 w 是支持向量的线性组合）
∂L/∂b = 0 ⇒ Σᵢ αᵢ yᵢ = 0
代回并取 max 得对偶：
  max_α Σᵢαᵢ − ½Σᵢⱼ αᵢαⱼyᵢyⱼ xᵢᵀxⱼ,  s.t. αᵢ ≥ 0, Σᵢαᵢyᵢ = 0
把 xᵢᵀxⱼ 换成 k(xᵢ,xⱼ) 即得核 SVM（核技巧）
b 由任一支持向量满足 yⱼ(Σᵢαᵢyᵢk(xᵢ,xⱼ)+b)=1 解出
```

**KKT 互补松弛** `αᵢ[yᵢ(wᵀxᵢ+b)−1]=0` 给出三类点：`αᵢ=0`（间隔外，不影响解）、`0 &lt; αᵢ &lt; C`（恰在间隔边界，支持向量）、`αᵢ=C`（间隔内或错分，软间隔情形）。

::: danger 易错
「支持向量」在软间隔中**包括被错分的点**（αᵢ=C），不只是恰好落在边界上的样本；硬间隔才只有边界点是支持向量。
:::

### 深 3 损失函数的统一视角（补第 3、4、6 章）

把各类监督学习写成 `min (1/N)Σᵢ L(yᵢ, f(xᵢ)) + λΩ(w)`：

| 模型 | 损失 L | 特点 |
| --- | --- | --- |
| 线性回归 | `½(y−f)²` | 对异常值敏感（平方放大） |
| 逻辑回归 | `−[y log σ(f)+(1−y)log(1−σ(f))]` | 概率输出、凸、对误分类线性惩罚 |
| SVM | `hinge: max(0, 1−yf)` | 间隔内点零梯度 → 稀疏解 |
| AdaBoost | `exp(−yf)` | 对错分样本指数加权，故对噪声敏感 |
| 平方损失分类 | `½(y−f)²` | 非凸/易饱和，逻辑回归不用它 |

::: tip 工作例题 · 交叉熵数值
真实类别为第 1 类，模型给该类的概率 `0.9` → 损失 `−log 0.9 ≈ 0.1054`；若只给 `0.8` → `−log 0.8 ≈ 0.2231`（损失翻倍）。交叉熵对「 confident but wrong 」的样本惩罚极重，这解释了为什么它比均方误差更适合分类。
:::

### 深 4 从决策树到 XGBoost 的推导链（补第 7 章）

GBDT 每轮拟合**负梯度**（伪残差）；XGBoost 进一步对损失作**二阶泰勒展开**并显式加正则：

```text
Obj ≈ Σᵢ [gᵢ f_t(xᵢ) + ½ hᵢ f_t²(xᵢ)] + Ω(f_t)，gᵢ=∂ℓ/∂ŷ，hᵢ=∂²ℓ/∂ŷ²
Ω(f) = γ·T + ½λ‖w‖²（T 叶数、w 叶权重）
最优叶权重 w*_j = −G_j/(H_j+λ)
分裂增益 Gain = ½[ G_L²/(H_L+λ) + G_R²/(H_R+λ) − (G_L+G_R)²/(H_L+H_R+λ) ] − γ
```

::: tip 工作例题 · 一次分裂增益
`G_L=−2,H_L=2`、`G_R=3,H_R=2`、`λ=1`、`γ=0` → `G=1,H=4`：
`Gain = ½[4/3 + 9/3 − 1/5] = ½[1.3333+3−0.2] ≈ 2.0667 > 0` → 值得分裂；
最优叶权重 `w*_L = −(−2)/3 = 0.6667`、`w*_R = −3/3 = −1.0`。
`γ` 是「分裂最小收益门槛」，起预剪枝作用。
:::

### 深 5 反向传播的矩阵形式与梯度检验（补第 8 章）

`δ^{(l)} = (W^{(l+1)})ᵀδ^{(l+1)} ⊙ φ′(z^{(l)})` 中所有量都是矩阵/向量，`⊙` 为逐元素乘。工程上必须做**梯度检验**：用数值梯度 `(J(θ+ε)−J(θ−ε))/(2ε)`（ε≈1e−5）与解析梯度比对，相对误差应小于 1e−7。这是排查反向传播实现 bug 的标准手段。

::: danger 易错 · 实现层面
数值梯度只能用于**调试**（计算量 O(参数数)），不能用于训练；检测时须关闭 Dropout 与 BN 的随机性，否则两次前向不一致。
:::

### 深 6 注意力复杂度与一次手算（补第 9 章）

```text
自注意力计算量 O(n²·d)（n 序列长度、d 每头维度），显存 O(n²)
多头：h 个头各 d_k=d_model/h 维，总计算量与单头相当，但能捕捉不同子空间关系
```

::: tip 工作例题 · 3 个 token、d=2
`Q=K=[[1,0],[0,1],[1,1]]`，`V=[[1,2],[3,4],[5,6]]`：
分数 `QKᵀ/√2` = `[[0.707,0,0.707],[0,0.707,0.707],[0.707,0.707,1.414]]`；
逐行 softmax 得权重 `[[0.4011,0.1978,0.4011],[0.1978,0.4011,0.4011],[0.2483,0.2483,0.5035]]`（每行和为 1）；
输出 `A@V` = `[[3.0,4.0],[3.4066,4.4066],[3.5107,4.5108]]`——每个位置都是 V 各行的加权平均。
:::

::: tip 补充 · 长序列优化
稀疏注意力（Longformer/BigBird）、线性注意力（核化或 Performer）、FlashAttention（IO 感知的精确注意力）、KV Cache（自回归推理加速）都是为缓解 O(n²) 而生；课件 Part-3 只给到标准 Transformer 块 `Repeat × L`。
:::

### 深 7 EM 收敛性的证明思路（补第 10 章）

用 Jensen 不等式对任意分布 `q(z)`：

```text
log p(x|θ) = log Σ_z q(z)·[p(x,z|θ)/q(z)] ≥ Σ_z q(z) log[p(x,z|θ)/q(z)] ≜ ELBO(q,θ)
E 步：固定 θ^old，取 q = p(z|x,θ^old) 使不等式取等（下界紧贴当前似然）
M 步：固定 q，最大化 ELBO 得 θ^new
于是 log p(x|θ^new) ≥ ELBO(q,θ^new) ≥ ELBO(q,θ^old) = log p(x|θ^old) → 似然单调不降
```

### 深 8 策略梯度定理与 PPO（补第 11 章）

```text
∇_θ J(θ) = E_{π_θ}[ Σₜ ∇_θ log π_θ(Aₜ|Sₜ) · Gₜ ]       （REINFORCE）
Actor-Critic：用 V̂ 或优势 A(s,a)=Q−V 替代 Gₜ，显著降低方差
PPO：优化裁剪代理目标 min(rₜ(θ)Âₜ, clip(rₜ(θ),1−ε,1+ε)Âₜ)，限制策略更新幅度
```

::: danger 易错 · 策略梯度
`log π` 的梯度是无偏的但方差极大；直接用回报 `Gₜ` 而非基线会放大方差。策略梯度是**on-policy**（数据须由当前策略采集），与 Q-learning/DQN 的 off-policy + 经验回放形成对比。
:::

| 视角 | 对应目标 |

:::

### 深 11 学习率调度与训练稳定性（补第 8–9 章）

固定学习率在深度训练中往往不是最优：**初期**需要较大步长快速下降、后期需要较小步长精细收敛。

| 策略 | 公式 / 做法 | 适用 |
| --- | --- | --- |
| Step decay | 每 k 轮乘 γ（如 0.1） | 经典 CNN |
| 余弦退火 | `ηₜ = η_min + ½(η₀−η_min)(1+cos(πt/T))` | 预训练/微调常用 |
| Warmup | 前若干步线性从 0 升到 η₀ | 大 batch、Transformer 必备（防初期梯度爆炸） |
| ReduceLROnPlateau | 验证指标停滞则降 η | 小数据、需自适应 |
| 周期性 / OneCycle | η 先升后降 | 快速收敛 + 正则效果 |

::: tip 工作例题 · 余弦退火
`η₀=0.1`、`η_min=0.001`、`T=100`，在 `t=50` 时
`η = 0.001 + ½×0.099×(1+cos(π/2)) = 0.001+0.0495 = 0.0505`，恰好约为初值的一半。
:::

::: danger 易错 · 训练稳定性
- **梯度裁剪**（`clip_grad_norm_`）针对梯度爆炸，不改变优化方向；对梯度消失无效。
- 混合精度（FP16）需配合**损失缩放**防止小梯度下溢；梯度累积只是用时间换显存，须相应缩放损失。
- 大 batch 需配合 warmup 与学习率随 batch 缩放，否则初期不稳定。
- 损失出现 NaN 的常见原因：学习率过大、除零（如 `log(0)`）、混合精度溢出、数据含 NaN。
:::

### 深 12 概率校准与预测不确定性（补第 4、5 章）

模型输出「0.9」不等于「真的有 90% 概率正确」。若业务需要**可信概率**（风险定价、医疗分诊、阈值决策），必须做校准。

| 方法 | 做法 | 特点 |
| --- | --- | --- |
| Platt Scaling | 用 sigmoid 拟合 `(a·f+b)`，在验证集上训练 | 参数少、适合 SVM |
| Isotonic Regression | 单调非参数映射 | 需较多数据、易过拟合 |
| 温度缩放 | `softmax(logits/T)`，单参数 T | 深度网络最常用，不改变 argmax（因而不改变准确率） |

::: tip 工作例题 · 温度缩放
二分类 logits `(2,1)`：`softmax = (0.7311, 0.2689)`；
取 `T=2` 变成 `(1, 0.5)` → `softmax = (0.6225, 0.3775)`，预测类别不变但置信度显著下降。
评估校准用 **Brier score** `=(ŷ−y)²` 与 **ECE**（按置信度分箱后加权平均 |acc−conf|）。
例：真实 y=1 时 `ŷ=0.8` → Brier `0.04`；`ŷ=0.3` → Brier `0.49`。
:::

::: danger 易错 · 校准
- 校准必须在**独立验证集**上拟合，用训练集校准会得到虚好的指标。
- 温度缩放 T>1 让分布更平滑（降置信），T&lt;1 更尖锐；它不改变排序，故 AUC 不变。
- 深度网络常「过度自信」（尤其分布外样本），OOD 检测需额外方法（能量分数、Mahalanobis 距离）。
:::

### 深 13 分布漂移、公平性与上线监控（补第 5 章，课件完全未提）

| 漂移类型 | 变化的是什么 | 检测 |
| --- | --- | --- |
| 协变量漂移 | `p(x)` 变、`p(y|x)` 不变 | PSI、KS 检验、特征分布对比 |
| 标签漂移 | `p(y)` 变（类别比例） | 预测分布与历史基线对比 |
| 概念漂移 | `p(y|x)` 变（规律本身变） | 只能用**延迟到达的真实标签**监控性能衰减 |

```text
PSI = Σ_bins (实际占比 − 期望占比)·ln(实际占比/期望占比)
经验阈值：PSI < 0.1 稳定；0.1–0.25 需关注；> 0.25 显著漂移
```

::: tip 补充 · 公平性指标
**Demographic parity**（各组预测正率相同）、**Equalized odds**（各组 TPR 与 FPR 相同）、**Equal opportunity**（各组 TPR 相同）。三者通常**无法同时满足**（与校准亦存在不相容定理），必须结合业务代价取舍，并在分组上报告指标而非只看总体。
:::

::: danger 易错 · 上线后
- 离线指标好不代表线上好：特征管线口径不一致（训练/服务偏差）是常见事故源。
- 「模型定期重训」不能替代漂移检测：若概念已变，用新数据重训同样的模型也可能无效。
- 上线应保留 **champion/challenger** 与回滚方案；监控需覆盖数据质量、延迟、性能与公平性四类。
:::

### 深 14 常用符号与矩阵维度速查（贯穿全书）

| 符号 | 含义 | 典型形状 |
| --- | --- | --- |
| `N` | 样本数 | 标量 |
| `d` | 特征维度 | 标量 |
| `K` | 类别数 / 簇数 | 标量 |
| `X` | 设计矩阵（含常数列） | `N×(d+1)` |
| `y` | 标签向量 | `N` 或 `N×K`（one-hot） |
| `W^{(l)}` | 第 l 层权重 | `d_l × d_{l−1}` |
| `δ^{(l)}` | 第 l 层误差 | `d_l × batch` |
| `K` / Gram | 核矩阵 | `N×N` |
| `Q, K, V` | 注意力查询/键/值 | `n×d_k` / `n×d_k` / `n×d_v` |

| `γ` | 折扣因子 / BN 缩放 | 标量 / `d_l` |

::: danger 易错 · 记号歧义
同一个希腊字母在不同章含义完全不同：`α` 在学习率是步长、在 SVM 对偶是拉格朗日乘子、在 AdaBoost 是分类器权重、在扩散是噪声调度系数；`K` 既是类别数/簇数也是核矩阵；`γ` 既是折扣因子、RBF 参数，也是 BN 缩放与 XGBoost 分裂门槛。**答题前先确认所在章节的记号定义。**
:::

### 深 15 模型可解释性（补全书，课件未涉及）

| 层次 | 方法 | 输出 |
| --- | --- | --- |
| 内在可解释 | 线性模型系数、决策树规则、GAM | 直接可读的结构 |
| 全局事后 | 置换重要性、PDP/ICE、全局 SHAP | 「整体上哪些特征重要」 |
| 局部事后 | LIME、单个样本的 SHAP 值 | 「为什么这个样本被判成这类」 |
| 深度模型 | 显著性图、注意力权重、概念瓶颈 | 需谨慎解读 |

::: danger 易错 · 解释性
- **注意力权重不等于解释**：注意力只是软对齐，多篇研究表明它与特征归因并不一致。
- 相关性 ≠ 因果：SHAP 说明的是「模型用了什么」，不是「现实中什么导致了结果」。
- 特征高度相关时，重要性会在相关特征间分摊/漂移；置换重要性也会因「造出不可能的特征组合」而失真。
- 高 stakes 场景（信贷、医疗、司法）应优先选择**内在可解释模型**，而不是给黑箱贴一张事后解释图。
:::

::: tip 补充 · 置换重要性的一步
在验证集上依次随机打乱第 j 列，记录性能下降量 `Δ_j`；`Δ_j` 越大说明模型越依赖该特征。它不依赖模型内部结构、可直接比较不同模型，但计算量与特征数成正比。
:::

### 深 16 联邦学习与隐私（补充）

| 概念 | 含义 |
| --- | --- |
| 横向联邦 | 各方样本不同、特征相同（如多家医院的同类病人） |
| 纵向联邦 | 各方样本重叠、特征不同（如银行 + 电商的同一批用户） |
| FedAvg | 各客户端本地训练 → 上传参数/梯度 → 服务器加权平均 → 下发，反复迭代 |
| 差分隐私 | 加噪声使单条记录难以被反推，用 `(ε,δ)` 量化隐私预算 |
| 主要风险 | 梯度反演/成员推断攻击、非独立同分布数据、通信开销与客户端掉队 |

::: danger 易错 · 隐私
「只传梯度不传数据」**不等于**安全：梯度可被反演还原训练样本。真正的保护需要安全聚合、差分隐私或同态加密等机制。ε 越小隐私保护越强、模型效用越低。
:::

### 深 19 偏差-方差分解的严格证明（补第 1 章）

设真实模型 `y=f(x)+ε`，`E[ε]=0`、`Var(ε)=σ²`，`f̂` 是随训练集 D 变化的估计。对固定 x，平方损失期望为：

```text
E_D,ε[(y−f̂)²] = E[(f+ε−f̂)²]
  = E[(f−f̂)²] + 2E[(f−f̂)ε] + E[ε²]
  = E[(f−f̂)²] + σ²                         （ε 与 f̂ 独立，交叉项为 0）
  = E[((f−E f̂) + (E f̂−f̂))²] + σ²
  = (f−E f̂)² + E[(f̂−E f̂)²] + σ²
  = Bias²(f̂) + Var(f̂) + σ²                  （交叉项 2(f−E f̂)·E[E f̂−f̂] = 0）
```

::: tip 工作例题 · 数值验证
设 `f=2`、`σ²=1`，两个训练集给出 `f̂=1.5` 与 `2.5`：
`E f̂=2` → `Bias=0`、`Var=[(−0.5)²+(0.5)²]/2=0.25`；
总误差 `= 0 + 0.25 + 1 = 1.25`。
若改用恒预测 `f̂≡1`：Bias²=1、Var=0 → 总误差 `2`，反而更差——说明**适当增加方差能换取偏差下降**。
:::

::: danger 易错 · 分解前提
该分解只在**平方损失**下严格成立；对 0-1 损失或交叉熵，偏差-方差不再可加分解（但仍有类似直观）。推导还要求噪声与 `f̂` 独立、且 `E[ε]=0`。
:::

### 深 20 VC 维与模型选择的定量联系（补第 1、5 章）

**VC 维** `d_VC`：假设空间能「打散」（shatter，即对任意标签指派都存在完美分类器）的最大样本点数。d 维线性分类器的 `d_VC = d+1`。

```text
无限 |H| 的泛化界（粗型）：
R(h) − R̂(h) ≲ O( √[ (d_VC·log(N/d_VC) + log(1/δ)) / N ] )
经验法则：训练样本量宜 ≥ 10×d_VC，否则极易过拟合
```

::: tip 工作例题
10 维特征的线性分类器 `d_VC=11` → 经验上至少需要约 **110** 个样本；若只有 50 个样本却用 100 维深度特征，界会非常松，必须靠正则化、预训练或数据增强来提供隐式约束。
:::

::: danger 易错 · 容量与泛化
深度网络参数量远大于经典 VC 上界却泛化良好，说明参数个数 ≠ 有效容量：SGD 隐式偏好平坦极小、架构（卷积/注意力）注入强先验、以及归一化/数据增强都在起作用。因此「参数越多越容易过拟合」只是粗略直觉，不是定理。
:::

### 深 21 GMM 的 EM 更新式逐项推导（补第 10 章）

对完全数据 `(x, z)`（z 为 one-hot 成分指示），对数似然 `ΣₙΣₖ zₙₖ[log πₖ + log N(xₙ|μₖ,Σₖ)]`。E 步用责任度 `γₙₖ=E[zₙₖ]` 替代 `zₙₖ` 得 Q 函数；M 步分别对参数求极值：

```text
∂Q/∂μₖ = Σₙ γₙₖ Σₖ⁻¹(xₙ−μₖ) = 0  ⇒ μₖ = Σₙγₙₖxₙ / Nₖ
∂Q/∂Σₖ⁻¹ = 0                        ⇒ Σₖ = Σₙγₙₖ(xₙ−μₖ)(xₙ−μₖ)ᵀ / Nₖ
带约束 Σπₖ=1 用拉格朗日乘子             ⇒ πₖ = Nₖ / N，其中 Nₖ = Σₙγₙₖ
```

::: tip 工作例题 · 一次 E 步
一维两成分 `π=(0.5,0.5)`、`μ=(0,4)`、`σ=1`，观测 `x=1`：
`π₁N(1|0,1)=0.12099`、`π₂N(1|4,1)=0.00222` →
`γ(z₁=1|x)=0.9820`、`γ(z₂=1|x)=0.0180`。
这是**软分配**；K-means 会直接把 x 硬分给成分 1（γ→(1,0)）。
:::

::: danger 易错 · GMM 实现
分母须包含 `2π` 归一化常数（比较同一 x 下各成分时可约掉，但写代码求概率时不能漏）；协方差接近奇异时加 `σ²I` 正则；EM 需多次随机重启避免局部极大。
:::

### 深 22 卷积层与转置卷积的反向传播（补第 9 章）

卷积在前向可写成**稀疏矩阵乘法** `y = C·x`（C 由卷积核构造的 Toeplitz 矩阵），因此反向传播只是转置：

```text
∂L/∂x = Cᵀ · ∂L/∂y           （等价于「用翻转的核再做一次卷积」，即转置卷积）
∂L/∂W = Σ_{sliding windows} (∂L/∂y) · x_patch
```

**转置卷积（反卷积）** 用于上采样（分割、生成器）：输出尺寸
`H_out = (H_in−1)·S − 2P + K + output_padding`。
例：`H_in=2, K=3, S=2, P=0` → `(2−1)×2+3 = 5`。

::: danger 易错 · 转置卷积
「转置卷积」不是卷积的数学逆（不满足 `f⁻¹∘f=id`），只是梯度的反向传播形式 / 可学习的上采样；步长大于 1 时会产生**棋盘格伪影**，工程上常用「双线性上采样 + 普通卷积」替代。
:::

### 深 23 位置编码、掩码与自回归推理（补第 9 章）

```text
正弦位置编码：PE(pos,2i)=sin(pos/10000^{2i/d_model})，PE(pos,2i+1)=cos(pos/10000^{2i/d_model})
优点：任意相对位移可用线性变换表示、可外推到更长序列（无需学习）
因果掩码：把 QKᵀ 的上三角置 −∞，softmax 后权重为 0，保证位置 t 只看到 ≤t
自回归推理：缓存已计算的 K、V（KV Cache），每步只算新 token，复杂度从 O(n²) 降到 O(n)
```

::: tip 工作例题 · 位置编码的一个分量
`pos=5`、`i=0`、`d_model=512` → `PE(5,0)=sin(5/10000⁰)=sin(5)≈−0.9589`，`PE(5,1)=cos(5)≈0.2837`。
不同 i 对应不同频率（低 i 高频、高 i 低频），从而给模型提供多尺度的位置信息。
:::

::: danger 易错 · 位置与推理
- 绝对位置编码在超过训练长度时外推能力有限；RoPE（旋转位置编码）把位置信息注入 Q/K 的旋转中，相对位置性质更好，是现代 LLM 主流。
- KV Cache 只加速**推理**，训练时仍并行计算整段；缓存随序列长度线性增长，是长上下文显存瓶颈。
- 因果掩码作用于 `n×n` 分数矩阵，不是 `d×d`；漏加掩码会让解码器在训练时「抄答案」。
:::

### 综 1 线性回归：闭式解与梯度下降（第 2–3 章）

**题**：样本 `(1,2)`、`(2,3)`，无截距模型 `ŷ=wx`，`w₀=0`、`η=0.1`。求①初始损失与梯度；②一步更新后的 w；③闭式解；④若改加 L2 正则 `λ=2`，闭式解变为多少？

**解**：
① `L=½[(0−2)²+(0−3)²]=6.5`；`∇L=Σ(wxᵢ−yᵢ)xᵢ = −2−6 = −8`；
② `w₁ = 0 − 0.1×(−8) = 0.8`；
③ `w* = Σxᵢyᵢ/Σxᵢ² = (2+6)/(1+4) = 8/5 = 1.6`；
④ 岭回归 `w* = Σxᵢyᵢ/(Σxᵢ²+λ) = 8/(5+2) ≈ 1.1429 < 1.6`，系数被缩小，正是 L2 的作用。

::: tip 解题要点
正则化后分母多了 `λ`；`λ` 越大越向 0 收缩，偏差上升、方差下降。
:::

### 综 2 逻辑回归、softmax 与交叉熵（第 2、4 章）

**题**：①`wᵀx=2` 时二分类正类概率？②三分类 logits `(2,1,0.1)` 的 softmax？③真实为第 1 类、模型给 `0.9` 与 `0.8` 时的交叉熵？

**解**：
① `σ(2)=1/(1+e⁻²)≈0.8808` → 判正类；`wᵀx=0` 时恰为 0.5（决策边界）。
② `softmax = (0.6590, 0.2424, 0.0986)`，和为 1，预测第 1 类。
③ `−log0.9≈0.1054`、`−log0.8≈0.2231`：概率降低 0.1，损失约翻倍，体现交叉熵对置信度的强惩罚。

### 综 3 评估指标与阈值（第 5 章）

**题**：`TP=80, FP=20, FN=10, TN=90`，求 Acc / P / R / F1 / FPR，并说明「提高召回率」通常如何操作及其代价。

**解**：`Acc=170/200=0.85`；`P=80/100=0.80`；`R=80/90≈0.8889`；`F1=2×80/(160+20+10)=160/190≈0.8421`；`FPR=20/110≈0.1818`。
降低分类阈值会把更多样本判为正 → TP、FP 同增 → **R 升、P 降**；F1 折中，AUC 不随单一阈值改变。类别不平衡时应看 PR-AUC 而非 accuracy。

### 综 4 核映射与 SVM 间隔（第 6 章）

**题**：①写出 `k(x,z)=(1+xᵀz)²` 在二维下的显式特征映射；②`w=(1,1), b=−3` 的最大间隔是多少？③C 增大对间隔与过拟合有何影响？

**解**：
① 展开得 `φ(x)=(1, √2x₁, √2x₂, x₁², x₂², √2x₁x₂)`，六维；核技巧让我们无需显式计算 φ。
② `γ = 2/‖w‖ = 2/√2 = √2 ≈ 1.4142`；间隔边界 `wᵀx+b=±1` 即 `x₁+x₂=2` 与 `=4`。
③ C 增大 → 更不容忍错分 → 间隔变窄、边界更复杂 → **更易过拟合**；C 减小则相反。

### 综 5 决策树准则与 AdaBoost 权重（第 7 章）

**题**：14 个样本（9 正 5 负），按 A 分为 `D₁`(7正1负)、`D₂`(2正4负)。①求信息增益、基尼指数、增益率；②若 AdaBoost 某轮 `ε=0.3`，求 α 与样本权重乘数。

**解**：
① `H(D)=0.9403`；`H(D₁)=0.5436`、`H(D₂)=0.9183` → 条件熵 `0.7042` → **Gain=0.2361**；
`Gini(D₁)=0.2188`、`Gini(D₂)=0.4444` → **Gini_index=0.3155**；
`SplitInfo=0.9852` → **GR≈0.2397**。
② `α=½ln(0.7/0.3)≈0.4236`；错分样本权重乘 `e^α≈1.5275`、正确样本乘 `e^{−α}≈0.6547`。

::: danger 答题要点
信息增益/增益率取**最大**、基尼指数取**最小**；AdaBoost 的 `ε` 必须 `<0.5`，否则 α≤0 该轮无意义。
:::

### 综 6 前向/反向传播与梯度消失（第 8 章）

**题**：①`x=(1,2)`、`w=(0.5,−1)`、`b=0.3`，分别求 ReLU 与 sigmoid 输出；②5 层网络每层反传因子 0.5，首层梯度约为多少？列出三条对策。

**解**：
① `z=0.5−2+0.3=−1.2` → `ReLU=0`、`sigmoid≈0.2315`；
② `0.5⁵=0.03125`，几乎消失（若为 2 则 `2⁵=32` 爆炸）。
对策：ReLU 系激活、残差连接、批归一化、He/Xavier 初始化、梯度裁剪（针对爆炸）、LSTM 门控（序列）。

### 综 7 CNN 尺寸与注意力计算（第 9 章）

**题**：①输入 `32×32×1`，6 个 `5×5` 卷积核 `S=1,P=0` 后的尺寸与参数量？再接 `2×2 / S=2` 池化？②3 个 token、`d=2` 的自注意力权重为何每行和为 1？

**解**：
① 卷积 `⌊(32−5)/1⌋+1=28` → `28×28×6`，参数 `5×5×1×6+6=156`；池化 `⌊(28−2)/2⌋+1=14` → `14×14×6`（无可训练参数）。
② 因对分数矩阵逐行做 softmax，权重非负且归一；输出是 V 各行的加权平均（例题结果 `[[3.0,4.0],[3.4066,4.4066],[3.5107,4.5108]]`）。除以 `√d_k` 是为防止高维点积把 softmax 推入饱和区。

### 综 8 强化学习与生成模型辨析（第 11–12 章）

**题**：①`Q=0.5,r=1,γ=0.9,max Q(s′,·)=0.8,α=0.1` 求更新后的 Q；②比较 VAE、GAN、扩散三类生成模型在「似然、采样、稳定性」上的差别。

**解**：
① TD 目标 `=1+0.9×0.8=1.72`；`δ=1.72−0.5=1.22`；`Q←0.5+0.1×1.22=0.622`。
② **VAE**：优化似然下界 ELBO，一次前向采样，训练稳但样本偏模糊；
**GAN**：无显式似然，一次前向采样、样本清晰，但训练不稳、模式崩塌；
**扩散**：变分下界/去噪目标，需多步迭代采样（慢），质量高且训练稳；
归一化流则是唯一能算**精确似然**的一类，代价是变换必须可逆、维度不变。

### 综 9 方案设计题（简答模板）

**题**：给定带标签的用户流失数据（数值 + 类别混合特征，正负比 1:9），设计完整建模方案。

**参考要点**：
① **业务理解**：定义流失口径、明确是「要概率排名」还是「要可解释规则」，代价矩阵（漏报 vs 误报）。
② **预处理**：数值标准化、类别独热/目标编码、缺失填补——**全部放进 Pipeline**；按时间或分层划分训练/验证/测试。
③ **基线**：逻辑回归（带 class_weight）+ 单棵决策树，交叉验证建立参照。
④ **模型**：随机森林 / GBDT（混合特征友好）→ 若需概率校准用 Platt/Isotonic；必要时上深度网络。
⑤ **评估**：因 1:9 不平衡，主看 **PR-AUC、Recall@固定 Precision、F1**，辅以 ROC-AUC；分组检查公平性。
⑥ **调参与防泄露**：网格/贝叶斯搜索只在验证折进行；测试集最后一次性评估。
⑦ **上线**：输出概率与阈值、监控数据漂移、定期重训、记录特征重要性与可解释报告。

### 综 10 正则化与偏差方差（第 1、3 章）

**题**：沿用综 1 的样本 `(1,2)`、`(2,3)`，模型 `ŷ=wx`。①无正则闭式解？②加 L2 `λ=2` 后的解？③解释「λ 增大时偏差/方差如何变化」；④说明何种迹象表明应该增大还是减小 λ。

**解**：
① `w*=8/5=1.6`；
② 岭回归 `w*=Σxy/(Σx²+λ)=8/(5+2)≈1.1429`；
③ `λ↑` → 系数向 0 收缩 → 模型变简单 → **偏差上升、方差下降**；`λ↓` 反之。总误差是 U 形，最优 λ 由验证集/交叉验证选取。
④ 若训练误差与验证误差**都高**（欠拟合）→ 应减小 λ / 加特征；若训练误差很低但验证误差高（过拟合）→ 应增大 λ / 增数据 / 早停。

::: tip 解题要点
不要把「正则化」与「归一化」混淆：前者改目标函数、后者改特征尺度。L2 使解稳定但不稀疏，L1 会给稀疏解。
:::

### 综 11 数据泄露辨析（第 5 章）

**题**：某同学先对全量数据做标准化与 PCA 降维，再随机 5 折交叉验证调参，最后在留出测试集上报告 0.96 的 AUC。指出三处问题并给出正确流程。

**解**：
问题① 全量标准化用了验证/测试折的均值方差 → **泄露**；
问题② 全量 PCA 同样把测试折信息泄漏进训练表征；
问题③ 「反复在测试集上看结果调参」即使只调一次阈值，也会让测试集不再独立（题中虽只报一次，但流程里已用全量预处理污染）。
正确流程：先划分训练/验证/测试 → 把所有预处理放进 `Pipeline` → 在训练折内 `fit`、验证折内 `transform` → 交叉验证选超参 → 最后在**未被任何步骤碰过**的测试集上评估一次。

::: danger 答题必备
若数据按时间产生，还必须把随机 K 折改为 `TimeSeriesSplit`；否则即便 Pipeline 正确，仍会用「未来」预测「过去」。

### 综 12 核方法与维度（第 6 章）

**题**：①核验 `K=[[1,0.5],[0.5,1]]` 是否可作合法核矩阵；②二维输入下 `k(x,z)=(1+xᵀz)²` 映射到几维？③若把次数升到 3，特征维度是多少？④说明为什么大样本下核方法慢。

**解**：
① 对称且特征值 `1±0.5` 即 `1.5` 与 `0.5`，均 ≥ 0 → **半正定，合法**；
② 展开为 6 个单项式 → **6 维**（`1, x₁, x₂, x₁², x₂², x₁x₂` 的带系数形式）；
③ d 次多项式核在 2 维输入下的特征维度为组合数 `C(2+d, d)`，d=3 → `C(5,3)=10` 维（d=2 → `C(4,2)=6`，与②一致）；
④ 需存储并计算 `N×N` 的 Gram 矩阵，训练复杂度约 `O(N²)–O(N³)`；N 很大时须用随机特征、Nyström 近似，或直接改用线性模型/神经网络。

::: tip 解题要点
「合法核」看 Gram 矩阵半正定，不是看函数是否简单；核技巧的价值在于**用 O(d) 的核计算替代 O(高维) 的显式映射**。
:::

### 综 13 图像分类方案设计（第 5、8、9 章）

**题**：10 类图像分类，训练集 5 万张、类别大致均衡，要求给出完整方案与过拟合应对措施。

**参考要点**：
① **数据**：划分训练/验证/测试（分层）；训练集做数据增强（翻转、裁剪、色彩抖动），验证/测试**不做**随机增强；统一尺寸与归一化（用训练集统计量）。
② **基线**：先用简单模型或小型 CNN 建立参照（避免一上来就调大模型）。
③ **模型**：CNN（如 ResNet 风格残差块）；可复用预训练权重做迁移学习 + 微调（小数据尤其有效）。
④ **训练**：交叉熵 + softmax；AdamW 或小批量 SGD+动量；学习率 warmup + 余弦退火；ReLU/BN/残差；Dropout 与权重衰减；早停。
⑤ **评估**：准确率 + 混淆矩阵（看哪两类易混）+ 每类 P/R/F1；单张测试集只评估一次。
⑥ **过拟合应对**：增数据/增强、正则、Dropout、早停、减小模型；**欠拟合**则反向（训更久、加容量、减正则）。
⑦ **上线**：概率校准（若需置信度）、监控数据漂移与延迟、记录版本与随机种子、保留回滚。

::: tip 答题加分项
提到「预训练+微调」「验证集不做随机增强」「监控分布漂移」「推理时关闭 Dropout 且 BN 用滑动平均」中的任意两条，通常能明显区别于背书式答案。
:::

### 综 14 端到端建模伪代码（综合全流程）

**题**：写出一个规范的表格数据建模脚本骨架，需体现「防泄露、交叉验证、基线对比、独立测试集、复现性」五个要点。

```python
import numpy as np
from sklearn.model_selection import train_test_split, StratifiedKFold, cross_val_score
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, average_precision_score

SEED = 42
np.random.seed(SEED)

# ① 先划分：测试集从一开始就隔离，全程不参与任何 fit / 调参
X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=SEED)

# ② 预处理放进 Pipeline：StandardScaler 只在训练折内 fit
models = {
    'baseline_lr': make_pipeline(StandardScaler(),
                                 LogisticRegression(max_iter=1000,
                                                    class_weight='balanced')),
    'random_forest': make_pipeline(StandardScaler(),
                                   RandomForestClassifier(n_estimators=200,
                                                          min_samples_leaf=5,
                                                          random_state=SEED)),
}
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=SEED)

# ③ 交叉验证选模型（只看训练部分），用 PR-AUC 应对类别不平衡
for name, pipe in models.items():
    s = cross_val_score(pipe, X_tr, y_tr, cv=cv, scoring='average_precision')
    print(name, round(s.mean(), 4), '+/-', round(s.std(), 4))

# ④ 用全部训练数据拟合最优模型，⑤ 测试集只评估一次
best = models['random_forest'].fit(X_tr, y_tr)
proba = best.predict_proba(X_te)[:, 1]
print('PR-AUC(test) =', round(average_precision_score(y_te, proba), 4))
print(classification_report(y_te, best.predict(X_te)))
```

`stratify=y` 保持类别比例；`Pipeline` 防泄露；`cross_val_score` 在训练部分上做；`average_precision`（PR-AUC）适配不平衡；测试集仅在最后一行出现。
:::

::: danger 常见扣分项
先对全体 `StandardScaler().fit_transform(X)` 再切分；在测试集上调 `class_weight` 或阈值；用 `accuracy` 评价 1:9 的数据；未固定随机种子导致结果不可复现。

### 综 15 值迭代手算（第 11 章推导题）

**题**：两状态 MDP，`s₁` 动作得 `r=1` 转移到 `s₂`；`s₂` 动作得 `r=0`，0.5 回 `s₁`、0.5 终止；`γ=0.9`。①写出贝尔曼最优方程组；②从 `V₀=(0,0)` 迭代 3 轮；③求解析解并说明收敛依据。

**解**：
① `V(s₁)=1+0.9V(s₂)`，`V(s₂)=0.9×0.5×V(s₁)=0.45V(s₁)`；
② `k=1: (1.00000, 0)` → `k=2: (1.00000, 0.45000)` → `k=3: (1.40500, 0.45000)`（依次代入前一轮 V）；继续 `k=4: (1.40500, 0.63225)`、`k=5: (1.56902, 0.63225)`；
③ 代入消元：`V(s₁)=1+0.9×0.45V(s₁)` → `V(s₁)=1/0.595≈1.6807`，`V(s₂)≈0.7563`。
收敛依据：γ<1 使贝尔曼最优算子为压缩映射，误差按 `γᵏ` 衰减，且不动点唯一。

### 综 16 VAE 与 GAN 的两个经典推导（第 12 章证明题）

**题**：①从 `log p_θ(x)` 出发用 Jensen 不等式推导 ELBO，并说明何时取等；②固定 G 求 GAN 的最优判别器 `D*`，代入后说明目标等价于什么散度、最小值是多少。

**解**：
① `log p(x)=log E_q[p(x|z)p(z)/q(z)] ≥ E_q[log p(x|z)] − D_KL(q(z|x)‖p(z)) = ELBO`。
等价形式 `log p(x)=ELBO + D_KL(q‖p(z|x))`，故当 `q(z|x)=p_θ(z|x)`（真实后验）时 KL=0、界取等。
② `V(D,G)=∫p_data log D + ∫p_g log(1−D)`，对 `D` 逐点求导令零：
`p_data/D − p_g/(1−D)=0` → `D*(x)=p_data/(p_data+p_g)`。
代回得 `V(D*,G)=2·JS(p_data‖p_g) − 2log2`，故最优时 `p_g=p_data`、`D*=0.5`、目标值 `−2log2≈−1.3863`。
若两分布支撑集不重叠，JS 恒为 `log2`、梯度为零 → 需 WGAN 等提供有效梯度。

### 综 17 扩散前向闭式与归一化流行列式（第 12 章计算题）

**题**：①设 `αₜ≡0.9`，求 `ᾱ₁…ᾱ₅`；取 `x₀=2, ε=0.5, t=3` 求 `x₃`。②某归一化流耦合层输出 `s=(0.2,−0.3,0.5)`，求 `log|det J|` 与 `|det J|`，并说明为何耦合层高效。

**解**：
① `ᾱₜ=Παₛ` → `(0.9, 0.81, 0.729, 0.6561, 0.5905)`；
`x₃=√0.729×2 + √(1−0.729)×0.5 ≈ 1.7076+0.2603 ≈ 1.9679`。
ᾱₜ 递减说明信号逐渐被噪声淹没，`t→∞` 时分布趋于 `N(0,I)`。
② `log|det J|=Σs=0.4`，`|det J|=e^{0.4}≈1.4918`。
因 Jacobian 是三角阵，行列式等于对角元素之积，**无需 O(d³) 的一般行列式计算**；逆变换也是解析的（`x₂=(y₂−t(y₁))⊙exp(−s(y₁))`），故采样与密度估计都高效。

### 综 18 三条推导链的综合辨析（第 2、7、10 章）

**题**：分别写出下列三条结论的推导要点：
① 逻辑回归的交叉熵来自哪里？牛顿法一步如何算？
② AdaBoost 的 `αₜ=½ln((1−εₜ)/εₜ)` 从何而来？
③ 为什么说「PCA 最大化投影方差」与「PCA 最小化重构误差」是同一问题？

**解**：
① 交叉熵是 Bernoulli 似然的负对数：`−log[ŷ^y(1−ŷ)^{1−y}]`。`∇L=Xᵀ(ŷ−y)`、`H=XᵀRX`（`R=diag(ŷ(1−ŷ))`），牛顿步 `w←w−H⁻¹∇L`。单样本 `x=1,y=1,w₀=0`：`ŷ=0.5`、`∇L=−0.5`、`H=0.25` → `w₁=2.0`。
② AdaBoost 是**指数损失 `exp(−yf)` 上的前向分步加法模型**：固定 `f_{t−1}` 后，样本权重 `wᵢ=exp(−yᵢf_{t−1})`；先解出使加权误差最小的 `hₜ`，再对 `α` 求导令零得 `−(1−ε)e^{−α}+εe^{α}=0` → `αₜ=½ln((1−εₜ)/εₜ)`。指数损失对错分样本惩罚随 `e^{|f|}` 增长，故 AdaBoost 对噪声敏感。
③ 最大化 `wᵀSw`（`‖w‖=1`）由拉格朗日条件得 `Sw=λw`，取最大特征值；最小化 `‖X−Xwwᵀ‖²_F = tr(S)−wᵀSw` 也是最大化 `wᵀSw`。二者都归结为协方差矩阵的前 m 个特征向量，最小重构误差为 `Σ_{j>m}λⱼ`。

::: tip 答题要点
这三条链的共同结构是「**先写出目标函数，再对参数求导/求极值**」——凡是课件只给结论的公式，几乎都能这样自己推出来。
:::

## 附录 A 公式速查

### A.1 基础与优化

| 项目 | 公式 |
| --- | --- |
| 经验风险 | `R̂(f)=(1/N)Σ L(f(xᵢ),yᵢ)`；结构风险 `R̂+λΩ(f)` |
| 偏差方差 | `Err = Bias² + Var + σ²` |
| 泛化界 | `R−R̂ ≤ √[(ln|H|+ln(2/δ))/(2N)]`（有限 H） |
| 贝叶斯 | `p(θ|D)=p(D|θ)p(θ)/p(D)` |
| MLE / MAP | `argmax Σlog p(xᵢ|θ)` / 加 `log p(θ)` |
| 熵 / 交叉熵 / KL | `H=−Σp log p`；`H(p,q)=−Σp log q`；`D_KL=Σp log(p/q)≥0` |
| 梯度下降 | `w ← w − η∇_w L`；动量 `v ← αv−ηg` |
| Adam 参数 | `η=0.001, β₁=0.9, β₂=0.999, ε=1e−8` |

### A.2 回归与分类

| 项目 | 公式 |
| --- | --- |
| 线性回归 | `y=wᵀx+b`；`L=½‖Xw−y‖²` |
| 闭式解 | `w*=(XᵀX)⁻¹Xᵀy`；岭 `+λI` |
| 正则 | L2 `+(λ/2)‖w‖²`；L1 `+λ‖w‖₁` |
| sigmoid | `σ(z)=1/(1+e⁻ᶻ)`，`σ′=σ(1−σ)`，最大值 0.25 |
| softmax | `p_k=exp(a_k)/Σⱼexp(aⱼ)` |
| 交叉熵 | `−Σ[y log ŷ+(1−y)log(1−ŷ)]`；`∇L=Xᵀ(ŷ−y)` |
| 朴素贝叶斯 | `p(C|x) ∝ p(C)Πⱼ p(xⱼ|C)` |
| LDA | 最大化类间散度/类内散度比 |

### A.3 评估

| 项目 | 公式 |
| --- | --- |
| Acc / P / R | `(TP+TN)/N`；`TP/(TP+FP)`；`TP/(TP+FN)` |
| F1 | `2PR/(P+R)=2TP/(2TP+FP+FN)` |
| FPR / TPR | `FP/(FP+TN)`；`TP/(TP+FN)` |
| K 折 CV | 轮流 1 折验证、K−1 折训练取平均 |
| 归一化 | min-max `(x−min)/(max−min)`；z-score `(x−μ)/σ` |

### A.4 核、树与集成

| 项目 | 公式 |
| --- | --- |
| 核条件 | Gram 矩阵对称半正定（Mercer） |
| 多项式核 | `(1+xᵀz)² → φ(x)` 六维展开；一般 `(γxᵀz+c)^d` |
| RBF 核 | `exp(−‖x−z‖²/(2σ²))` |
| SVM 原/对偶 | `min ½‖w‖²+CΣξ`；`max Σαᵢ−½Σαᵢαⱼyᵢyⱼk(xᵢ,xⱼ)` |
| 间隔 | `γ=2/‖w‖` |
| 熵 / 增益 | `H=−Σp log₂p`；`G=H(D)−H(D|A)`（取最大） |
| 增益率 / 基尼 | `GR=G/SplitInfo`；`Gini=1−Σp²`（取最小） |
| AdaBoost | `αₜ=½ln((1−εₜ)/εₜ)`；`wᵢ ← wᵢe^{−αₜyᵢhₜ}` |
| XGBoost | `w*=−G/(H+λ)`；`Gain=½[G_L²/(H_L+λ)+G_R²/(H_R+λ)−G²/(H+λ)]−γ` |

### A.5 神经网络与深度学习

| 项目 | 公式 |
| --- | --- |
| 前向 | `z^{(l)}=W^{(l)}a^{(l−1)}+b^{(l)}`，`a^{(l)}=φ(z^{(l)})` |
| 反向 | `δ^{(L)}=∇_a L⊙φ′(z^{(L)})`；`δ^{(l)}=(W^{(l+1)})ᵀδ^{(l+1)}⊙φ′(z^{(l)})` |
| 梯度 | `∂L/∂W^{(l)}=δ^{(l)}(a^{(l−1)})ᵀ` |
| ReLU / softmax | `max(0,z)` / `exp(aₖ)/Σexp(aⱼ)` |
| CNN 尺寸 | `⌊(H−K+2P)/S⌋+1`；参数 `K²C_inC_out+C_out` |
| RNN / LSTM | `hₜ=φ(W_xh xₜ+W_hh hₜ₋₁+b)`；`cₜ=f⊙cₜ₋₁+i⊙g` |
| 注意力 | `softmax(QKᵀ/√d_k)V`，复杂度 `O(n²d)` |
| BN / Dropout | 标准化 + γ、β；训练按 p 置零、推理全开 |

### A.6 无监督、强化与生成

| 项目 | 公式 |
| --- | --- |
| K-means | `J=ΣₙΣₖrₙₖ‖xₙ−μₖ‖²`；交替 E/M 步 |
| GMM / EM | `p(x)=ΣπₖN(x|μₖ,Σₖ)`；`γ(zₙₖ)=p(zₖ=1|xₙ)` |
| PCA / ICA | 协方差特征分解 / `x=As`，独立性 + 非高斯性 |
| 回报 | `Gₜ=ΣₖγᵏRₜ₊ₖ₊₁` |
| 贝尔曼 | `V^π(s)=E[R+γV^π(s′)]`；`V*(s)=maxₐE[R+γV*(s′)]` |
| Q-learning | `Q ← Q+α[r+γmaxₐ′Q(s′,a′)−Q]` |
| 值函数逼近 | `Δw=α(目标−预测)x(s)` |
| 策略梯度 | `∇J=E[Σ∇log π(a|s)·Gₜ]` |
| ELBO | `log p(x) ≥ E_q[log p(x|z)] − D_KL(q(z|x)‖p(z))` |
| 重参数 | `z=μ+σ⊙ε, ε~N(0,I)` |
| GAN | `min_G max_D E[log D(x)]+E[log(1−D(G(z)))]` |

| 模型 | 关键超参数 | 作用方向 | 训练/预测复杂度 |

### A.10 一页纸复习提纲（每章三条）

| 章 | 三条核心结论 |
| --- | --- |
| 1 | 泛化是目标；`Err=Bias²+Var+σ²`；NFL 说明必须按分布选模型 |
| 2 | 贝叶斯/MLE/MAP 一家亲；交叉熵与 KL 同源；`w←w−η∇L` 是所有深度训练的骨架 |
| 3 | 闭式解 `(XᵀX)⁻¹Xᵀy`；L1 稀疏 L2 收缩；正则等价于加先验 |
| 4 | 三种建模路线；sigmoid/softmax + 交叉熵；判别式不建 p(x|C) |
| 5 | 三分数据集；P/R/F1 与 PR-AUC；预处理必须放进 Pipeline |
| 6 | 最大间隔 `2/‖w‖`；对偶才能用核；Gram 半正定 + KKT 互补松弛 |
| 7 | 熵→增益→增益率→基尼；预/后剪枝；Bagging 降方差、Boosting 降偏差 |
| 8 | 非线性激活不可省；δ 递推是链式法则；ReLU/BN/残差/初始化治梯度问题 |
| 9 | 卷积局部+共享；尺寸公式 `⌊(H−K+2P)/S⌋+1`；注意力 `softmax(QKᵀ/√d)V` |
| 10 | K-means 交替 E/M 且局部最优；EM 似然单调不降；PCA 二阶、ICA 高阶 |
| 11 | `Gₜ=ΣγᵏR`；贝尔曼期望/最优；Q-learning off-policy、策略梯度 on-policy |
| 12 | ELBO = 重构 − KL；GAN 极小极大；扩散前向固定、反向学习 |

### A.11 推导索引（本轮深挖新增，按「目标 → 求导 → 结论」检索）

| 推导 | 起点 | 关键一步 | 结论 |
| --- | --- | --- | --- |
| 偏差-方差分解 | `E[(y−f̂)²]` | 插入 `±E f̂` 展开，交叉项为 0 | `Bias²+Var+σ²`（仅平方损失） |
| 泛化界 | Hoeffding + 有限 `\|H\|` | 一致收敛并集界 | `√[(ln\|H\|+ln(2/δ))/(2N)]` |
| 交叉熵 | Bernoulli 似然 | 取负对数 | `−[y log ŷ+(1−y)log(1−ŷ)]` |
| 牛顿/IRLS | `∇L=Xᵀ(ŷ−y)`、`H=XᵀRX` | `w←w−H⁻¹∇L` | 加权最小二乘迭代 |
| 正规方程 | `∇_w ½‖Xw−y‖²=0` | `Xᵀ(Xw−y)=0` | `w*=(XᵀX)⁻¹Xᵀy` |
| SVM 对偶 | 拉格朗日 `L=½‖w‖²−Σα[yf−1]` | `∂L/∂w=0 ⇒ w=Σαyx` | `max Σα−½Σααyy k` |
| KKT 互补 | `αᵢ(yᵢfᵢ−1)=0` | 约束取等才 `α>0` | 支持向量稀疏性 |
| hinge ↔ 软间隔 | `½‖w‖²+CΣmax(0,1−yf)` | 间隔外梯度恒 0 | 稀疏解的来源 |
| AdaBoost | 指数损失 + 前向分步 | 对 α 求导 `−(1−ε)e^{−α}+εe^{α}=0` | `α=½ln((1−ε)/ε)` |
| XGBoost | 二阶泰勒 + `Ω=γT+½λ‖w‖²` | 对叶权重求极值 | `w*=−G/(H+λ)` |
| 反向传播 | 链式法则 | `δ^{(l)}=(W^{(l+1)})ᵀδ^{(l+1)}⊙φ′` | `∂L/∂W=δ(a)ᵀ` |
| 卷积反向 | `y=Cx`（Toeplitz） | `∂L/∂x=Cᵀ∂L/∂y` | 转置卷积 / 尺寸 `(H−1)S−2P+K` |
| 注意力 | `QKᵀ/√d_k` | 逐行 softmax | `A V`，`O(n²d)` |
| PCA 等价性 | `max wᵀSw` ↔ `min ‖X−Xwwᵀ‖²` | 拉格朗日 `Sw=λw` | 前 m 个特征向量 |
| EM / ELBO | Jensen 不等式 | `q=p(z\|x)` 时界取等 | 似然单调不降 |
| 值迭代 | 贝尔曼最优算子 | γ-压缩映射 | 唯一不动点 `V*` |
| 策略梯度 | log-derivative trick | 减只依赖 s 的基线 | `∇J=E[∇logπ·A]` |
| VAE ELBO | `log E_q[p(x\|z)p(z)/q]` | Jensen | 重构项 − KL |
| GAN 最优 D | 对 `D(x)` 逐点求导 | `p_data/D=p_g/(1−D)` | `D*=p_data/(p_data+p_g)`，`2JS−2log2` |
| 扩散前向 | 高斯可加性 | `ᾱₜ=Παₛ` | `xₜ=√ᾱₜx₀+√(1−ᾱₜ)ε` |
| 归一化流 | 变量变换 | 三角 Jacobian | `log p_X=log p_Z+Σs` |

## 附录 B 易错点速查

1. 机器学习不等于深度学习，后者只是用深层神经网络的一个分支。
2. 目标是「在未见数据上泛化」，训练误差最低不代表模型最好。
3. 没有免费午餐定理：不存在对所有分布都最优的算法，选模型必须结合数据分布与归纳偏好。
4. 监督/无监督的区分在**是否有标签**，半监督、自监督、迁移学习不属于这三类中的任何一类。
5. 强化学习的反馈是延迟奖励，不是逐样本标签；目标是累计回报而非单步奖励。
6. 数据中发现的规律不等于因果规律，也不等于可迁移到分布变化后的场景。
7. 假设空间太小欠拟合、太大易过拟合；正则项 `Ω(f)` 体现偏好简单模型的归纳偏好。
8. 经验风险可算、期望风险不可算；二者差距随假设空间增大、样本减少而变大。
9. 偏差是系统性偏离真值，不是「模型有偏见」；方差是对训练集扰动的敏感度。
10. `Err = Bias² + Var + σ²` 中的噪声项 `σ²` 无法通过任何模型消除。
11. Bagging 主降方差、Boosting 主降偏差；深树配 Bagging、浅树配 Boosting。
12. 高斯分布 MLE 的方差除以 N（有偏），无偏样本方差才除以 N−1。
13. 似然 `p(D|θ)` 是 θ 的函数，不是 θ 的概率密度；MLE 给点估计、贝叶斯给分布。
14. MAP 等价于「带先验的正则化 MLE」，但完全贝叶斯需对后验积分做预测。
15. KL 散度非对称、不满足三角不等式，不是距离；方向交换会得到不同目标。
16. 交叉熵是「用 q 编码 p 的代价」，不是熵本身；真实分布确定时最小化它等价于最小化 KL。
17. 凸问题局部最优即全局最优；深度网络目标非凸，只能到局部极小或鞍点附近。
18. 学习率过大发散、过小收敛慢；损失下降不等于泛化变好。
19. 特征未标准化会让梯度下降震荡，且 SVM/KNN/神经网络/正则化都要求缩放。
20. 闭式解 `w*=(XᵀX)⁻¹Xᵀy` 在共线或 `d>N` 时奇异，须用伪逆或岭回归。
21. L1 产生稀疏解、L2 只缩小系数不为 0；正则项不含偏置且须先标准化。
22. 岭回归系数有偏（以偏差换方差），不能按普通 OLS 的标准误解释。
23. 逻辑回归做的是**分类**不是回归，输出是概率不是连续值。
24. 逻辑回归必须用交叉熵（凸），用平方损失会非凸且饱和时梯度极小。
25. `sigmoid(0)=0.5` 是决策边界；softmax 输出和为 1，逐个 sigmoid 不保证。
26. softmax 计算须减 `max(logits)` 防 `exp` 溢出。
27. 判别式与生成式的区别在**是否建模 p(x|C)**，不在能否输出概率。
28. 朴素贝叶斯假设特征条件独立，强相关时概率失真；须做拉普拉斯平滑防零概率。
29. 感知机只在线性可分时收敛，且不输出概率。
30. 准确率在类别极不平衡时毫无意义，应看 P/R/F1 与 PR-AUC。
31. 降低阈值会同时提高 TP 与 FP → 召回率升、精确率降。
32. F1 是 P 与 R 的调和平均，不是算术平均；对二者中较低者更敏感。
33. ROC-AUC 与阈值无关，但负样本极多时过于乐观，应看 PR-AUC。
34. 验证集用于调超参/早停，测试集只能最终一次性评估；反复看测试集调参即泄露。
35. 标准化/缺失填补/PCA/特征选择都必须在**训练折内**拟合，用 Pipeline 防泄露。
36. 时序数据必须按时间前向切分，随机 K 折会用未来信息预测过去。
37. 归一化（改特征尺度）与正则化（目标函数加惩罚）是完全不同的两件事。
38. 参数由训练得到（w、b），超参数由人设或交叉验证选（λ、K、η）。
39. SVM 最大化间隔等价于最小化 `½‖w‖²`，几何间隔 `γ=2/‖w‖`。
40. 只有 `αᵢ>0` 的支持向量决定解；软间隔中 αᵢ=C 的错分点也算支持向量。
41. 对偶问题才能把 `xᵢᵀxⱼ` 换成核函数；核必须使 Gram 矩阵半正定。
42. Sigmoid 型核在部分参数下不满足 Mercer 条件，不是合法核。
43. `C` 越大越不容忍误分类、间隔越窄、越易过拟合；RBF 的 γ 越大边界越曲折。
44. SVM 输出不是概率（需 Platt 校准），对特征缩放与缺失值都敏感。
45. 信息增益/增益率**取最大**，基尼指数**取最小**，方向相反。
46. ID3 偏袒取值多的特征（如「编号」），C4.5 用增益率惩罚之。
47. CART 是二叉树，分类用基尼、回归用平方误差；ID3/C4.5 是多叉树。
48. 预剪枝快但易欠拟合；后剪枝更可靠但计算开销大。
49. 决策树不稳定（数据微扰结构大变）、决策边界轴平行，这是集成学习要解决的。
50. 随机森林比 Bagging 多一层「随机选特征」去相关；可用 OOB 估计泛化误差。
51. AdaBoost 的 `εₜ` 必须 `<0.5`；`εₜ=0.5` 时 `αₜ=0`，该轮无贡献。
52. Boosting 对噪声/异常值敏感（错分样本被不断放大），且不能并行训练。
53. 若所有层都用线性激活，多层网络等价于单层线性回归。
54. Sigmoid 导数最大仅 0.25，是深层梯度消失的历史主因。
55. 反向传播只是链式法则的高效实现，不「创造」梯度；须做梯度检验排查实现错误。
56. 梯度检验时须关闭 Dropout 与 BN 随机性，且数值梯度只用于调试不能用于训练。
57. BN 在训练用批次统计量、推理用滑动平均，二者不同。
58. Dropout 只在训练启用，推理时全开并按概率缩放。
59. 残差连接 `y=F(x)+x` 提供梯度高速路，是训练上百层网络的关键。
60. 全零初始化导致神经元对称（学到相同特征），须用 Xavier/He 随机初始化。
61. 输出层与损失要配对：回归线性+MSE、二分类 sigmoid+BCE、多分类 softmax+CE。
62. 权重衰减与 L2 惩罚在 SGD 下等价，在 Adam 下不同（应改用 AdamW）。
63. 卷积层参数量与输入图像尺寸无关，计算量却与尺寸成正比。
64. 池化不改变通道数、无可训练参数；「same」填充可保持尺寸。
65. 卷积是平移等变的，池化只带来弱的平移不变性；旋转/尺度不变性靠数据增强。
66. RNN 不能并行（依赖上一步隐状态），Transformer 可并行但复杂度 O(n²)。
67. 自注意力不含顺序信息，必须补位置编码；解码器须加因果掩码防看到未来词。
68. 多头注意力不是模型集成，而是让不同子空间关注不同关系。
69. 注意力除以 `√d_k` 是为防止高维点积把 softmax 推入饱和区。
70. 自编码器把无监督重构转化为一种监督学习；瓶颈维小于输入维时近似非线性 PCA。
71. K-means 须预设 K、对初值与异常值敏感，且只收敛到局部极小。
72. K-means 假设球形且大小相近的簇；非凸形状应用 DBSCAN / 谱聚类。
73. 聚类无标签，不能用准确率评价；用轮廓系数或业务可解释性。
74. K-means 是 GMM 在协方差 `σ²I→0` 时的硬分配极限，EM 是软分配。
75. EM 只保证似然单调不降并收敛到局部极大，初值敏感、协方差需正则。
76. PCA 无监督最大化方差，LDA 有监督最大化类间/类内比，二者目标完全不同。
77. PCA 需标准化、成分互不相关但不保证独立；ICA 利用高阶统计量求独立分量。
78. 折扣因子 γ 小则短视、大则远视；持续性任务必须 `γ<1` 保证回报有界。
79. 值函数 V 度量状态好坏，动作值 Q 度量「状态下某动作」好坏，二者由策略联系。
80. Q-learning 是 off-policy（用 `maxₐ′Q`），SARSA 是 on-policy（用实际下个动作）。
81. Q-learning 的 TD 目标含「当前估计」故称自举；MC 需完整回合、方差大但无偏。
82. 值函数逼近的更新是「步长 × 预测误差 × 特征向量」，不是直接拟合回报。
83. 策略梯度是 on-policy；REINFORCE 方差大，Actor-Critic / PPO 用于降方差与稳更新。
84. VAE 优化的是**似然下界 ELBO**，不是精确似然；KL 项方向固定为 `q‖p`。
85. 重参数技巧把随机性移到无参数噪声，是 VAE 可反向传播的关键。
86. GAN 无显式似然、训练易模式崩塌；WGAN 用 Wasserstein 距离改善梯度。
87. 扩散的「前向加噪」固定且无参数，只有「反向去噪网络」需要学习。
88. 归一化流能算精确似然，但变换必须双射且 Jacobian 行列式可算、维度不变。
89. 生成模型评估不能只看「像不像」，常用 FID / IS；扩散质量高但采样慢。
90. 类别不平衡、公平性（分组指标）、隐私与可解释性应在方案设计阶段就考虑。
91. 复现四要素：随机种子、库版本、数据版本、代码与环境一致；截图代码不可直接复现。
92. 任何「模型提升」都要在独立测试集上验证，并报告指标方差与置信区间。
93. 偏差-方差可加分解只在**平方损失**下严格成立，对 0-1 损失或交叉熵不成立。
94. 值迭代每轮只做一步贝尔曼最优更新；策略迭代的「评估」必须跑到收敛，二者不可混写。
95. γ<1 使贝尔曼最优算子成为压缩映射，值迭代从任意初值收敛到唯一 V*；γ 越小收敛越快但越短视。
96. TD 目标含对下一状态的**估计**（自举）故有偏、方差小；MC 用实际回报故无偏、方差大。
97. DQN 的目标网络 `w⁻` 不参与梯度回传，只周期性复制；把它当可训练参数会让 TD 目标漂移。
98. Double DQN 解决的是 `max` 带来的系统性**过高估计**，不是梯度消失。
99. 策略梯度的基线只能依赖状态 s；若依赖动作会引入偏差并改变期望。
100. PPO 裁剪的是新旧策略**概率比**，不是梯度范数；同批数据可多轮小批量更新。
101. DQN 无法直接处理连续动作（无法对连续 a 取 max），这正是 DDPG/TD3/SAC 存在的原因。
102. VAE 的 ELBO 中 KL 方向固定为 `q_φ(z|x)‖p(z)`；交换成 `p‖q` 会变成另一类目标（前向 KL 偏质量覆盖）。
103. 后验坍缩时 `q_φ(z|x)=p(z)`（KL=0），解码器完全忽略隐变量；可用 KL 退火、β-VAE、free-bits 缓解。
104. GAN 的最优判别器为 `D*=p_data/(p_data+p_g)`，代回目标得 `2JS−2log2`，最优值约 −1.3863。
105. 当两分布支撑集不重叠时 JS 恒为 log2、生成器梯度消失；WGAN 用 Wasserstein 距离提供平滑梯度。
106. 扩散的前向加噪固定无参数、反向去噪才需学习；DDPM 采样需多步迭代，DDIM 可跳步加速。
107. 归一化流要求变换双射，故隐变量 z 与 x **维度相同**，不能像 VAE 那样任意降维。
108. 耦合层因 Jacobian 三角，`log|det J|=Σs`，无需计算一般行列式；逆变换也是解析的。
109. 转置卷积不是卷积的数学逆，只是梯度回传形式 / 可学习上采样；步长大于 1 易出现棋盘格伪影。
110. 归一化流虽能算精确似然，但似然高不等于生成质量更好；FID 比较必须在相同样本量与特征提取器协议下进行。
