## 第 1 章 函数、极限与连续（★★★）

### 1.1 函数的基本概念

![高等数学知识体系总览](/math/math-overview.svg)

![函数四要素、四性质与常见函数族](/math/math-function.svg)

| 概念 | 定义 / 判据 | 要点 |
| --- | --- | --- |
| 函数 | `y = f(x), x ∈ D` | **两要素**：定义域 D 与对应规则 f；二者完全相同才是同一函数 |
| 有界 | `∃M > 0, |f(x)| ≤ M` | 有界性依赖于所给区间（如 `1/x` 在 (0,1) 无界、在 [1,2] 有界） |
| 单调 | `x₁ < x₂ ⇒ f(x₁) ≤ f(x₂)` | 严格单调是反函数存在的充分条件 |
| 奇偶 | `f(−x) = −f(x)` / `f(−x) = f(x)` | 前提：定义域关于原点对称；奇函数若在 0 有定义则 `f(0)=0` |
| 周期 | `f(x+T) = f(x)` | `sin x, cos x` 周期 `2π`；`tan x` 周期 `π`；常数函数无最小正周期 |
| 反函数 | 一一对应才有反函数 | `dy/dx = 1/(dx/dy)`；原函数与反函数图像关于 `y=x` 对称 |
| 复合函数 | `f∘g` 要求 `R_g ⊆ D_f` | 分层拆解是链式求导的前提 |
| 初等函数 | 基本初等函数经有限次四则与复合、且能写成一个式子 | 在定义区间内连续；分段函数一般**不是**初等函数 |

::: danger 易错 · 函数
- 判定奇偶性**第一步**是检查定义域是否关于原点对称，否则直接判「非奇非偶」。
- `arcsin(sin x) ≠ x`（仅在 `[−π/2, π/2]` 成立）；`√(x²) = |x|`，不是 `x`；`ln(eˣ)=x` 但 `e^{ln x}=x` 需 `x>0`。
- 符号函数 `sgn x`、取整函数 `[x]`、狄利克雷函数、积分上限函数 `Φ(x)=∫ₐˣ f(t)dt` 都不是初等函数，但常考。
:::

### 1.2 极限的定义与性质

![极限定义、等价无穷小与两个重要极限](/math/math-limit.svg)

**ε–δ 定义**：`lim_{x→x₀} f(x) = A ⇔ ∀ε>0, ∃δ>0, 0<|x−x₀|<δ ⇒ |f(x)−A|<ε`。
数列版：`lim aₙ = A ⇔ ∀ε>0, ∃N, n>N ⇒ |aₙ−A|<ε`。
注意定义中 `x ≠ x₀`（去心），故 `f(x₀)` 可以无定义、也可以不等于 A —— 这正是可去间断点的来源。

| 性质 | 内容 |
| --- | --- |
| 唯一性 | 极限若存在必唯一 |
| 局部有界 / 保号 | `lim f = A > 0 ⇒` 去心邻域内 `f > 0`；反之由 `f ≥ 0` 只能得 `A ≥ 0` |
| 四则运算 | 各极限存在且分母极限非零时才可拆分；`∞ − ∞`、`0·∞` 不能直接拆 |
| 左右极限 | `lim_{x→x₀} f = A ⇔ f(x₀⁻) = f(x₀⁺) = A` |
| 夹逼准则 | `g ≤ f ≤ h` 且 `lim g = lim h = A ⇒ lim f = A` |
| 单调有界准则 | 单调有界数列必有极限（用于递推数列 `aₙ₊₁ = f(aₙ)`） |
| 两个重要极限 | `lim_{x→0} sin x / x = 1`；`lim_{x→∞}(1+1/x)ˣ = e`、`lim_{x→0}(1+x)^{1/x} = e` |

::: tip 工作例题 · 七类未定式的处理
- `0/0`：`lim_{x→0} sin 3x/(5x) = 3/5`（重要极限），`lim_{x→0}(eˣ−1−x)/x² = 1/2`（泰勒或洛必达）。
- `1^∞`：先取对数或用速算 `lim f^g = e^{lim g(f−1)}`；`lim_{n→∞}(1+2/n)ⁿ = e² ≈ 7.3891`（数值验证：n=10000 时 7.3876）。
- `∞−∞`：`tan x − sin x` 型不能逐项替换，`lim_{x→0}(tan x − sin x)/x³ = 1/2`（数值验证 0.500000）。
- `0·∞` 化为 `0/0`；`0⁰`、`∞⁰` 取对数；`∞/∞` 用洛必达或提最高阶。
:::

**常用等价无穷小**（`x→0`，**只能在乘除因子中替换**）：
`sin x ~ tan x ~ arcsin x ~ arctan x ~ ln(1+x) ~ eˣ−1 ~ x`；
`1−cos x ~ x²/2`；`(1+x)^α − 1 ~ αx`；`x − sin x ~ x³/6`；`tan x − x ~ x³/3`；`x − ln(1+x) ~ x²/2`。

::: danger 易错 · 等价无穷小
「加减项中替换」是最高频错误：`tan x − sin x` 若用 `sin x ~ x`、`tan x ~ x` 相减得 0，主阶被抵消，正确答案需展开到三阶（`x³/2`）。判定准则：替换后若结果的主阶未被抵消即可用，否则必须上泰勒。
:::

### 1.3 泰勒公式

![泰勒公式余项、五个麦克劳林展开与求极限](/math/math-taylor.svg)

`f(x) = Σ_{k=0}^{n} f⁽ᵏ⁾(x₀)(x−x₀)ᵏ/k! + Rₙ(x)`：
- **佩亚诺余项** `Rₙ = o((x−x₀)ⁿ)`：局部性质，用于求极限与判极值，只需 `n` 阶可导。
- **拉格朗日余项** `Rₙ = f⁽ⁿ⁺¹⁾(ξ)(x−x₀)ⁿ⁺¹/(n+1)!`：整体性质，用于误差估计与不等式证明，需 `n+1` 阶可导。

| 函数 | 麦克劳林展开（`x→0`） |
| --- | --- |
| `eˣ` | `1 + x + x²/2! + … + xⁿ/n! + o(xⁿ)` |
| `sin x` | `x − x³/3! + x⁵/5! − …` |
| `cos x` | `1 − x²/2! + x⁴/4! − …` |
| `ln(1+x)` | `x − x²/2 + x³/3 − … + (−1)ⁿ⁻¹xⁿ/n` |
| `(1+x)^α` | `1 + αx + α(α−1)x²/2! + …` |
| `arctan x` | `x − x³/3 + x⁵/5 − …` |

::: tip 工作例题 · 展开到几阶
分母是 `xᵐ`，就把分子展开到「首个非零项恰为 `xᵐ`」：
- `(eˣ−1−x)/x²`：`eˣ = 1+x+x²/2+o(x²)` ⇒ 分子 `= x²/2 + o(x²)` ⇒ 极限 `1/2`。
- `(tan x − sin x)/x³`：`tan x = x + x³/3`，`sin x = x − x³/6` ⇒ 差 `= x³/2` ⇒ 极限 `1/2`。
由展开式还可直接读出 `f⁽ⁿ⁾(0) = n!·aₙ`；判极值时看「首个非零偶数阶导数」。
:::

**补充 · 严格性说明**：`f` 有任意阶导数并不保证其泰勒级数收敛到 `f`（经典反例 `f(x)=e^{−1/x²}`（x≠0）、`f(0)=0`，在 0 处各阶导数全为 0）。收敛到原函数需拉格朗日余项趋于 0，即函数**解析**。教材多只给展开式，此处补足条件。

### 1.4 连续与间断点

| 类型 | 判据 | 例子 |
| --- | --- | --- |
| 第一类·可去 | 左右极限存在且相等，但 `≠ f(x₀)` 或无定义 | `sin x / x` 在 0 |
| 第一类·跳跃 | 左右极限存在但不等 | `sgn x` 在 0 |
| 第二类·无穷 | 至少一侧极限为 ∞ | `1/x` 在 0 |
| 第二类·振荡 | 极限不存在且不趋于 ∞ | `sin(1/x)` 在 0 |

**闭区间上连续函数的四性质**：有界性、最值定理、介值定理、零点定理（`f(a)f(b)<0 ⇒ ∃ξ, f(ξ)=0`）。这四条是第 3 章大量证明题的依据。

::: danger 易错 · 连续
- `f` 在 `x₀` 连续要求「极限存在 + 有定义 + 极限等于函数值」三条同时成立。
- 介值定理要求**闭区间上连续**；开区间或不连续时结论可能失效。
- 连续不一定可导（`|x|` 在 0）；可导必连续；导函数可以不连续（但导函数无第一类间断点，即达布定理）。
:::

## 第 2 章 导数与微分（★★★）

### 2.1 导数的定义与几何意义

![导数定义、几何意义与可导连续关系](/math/math-derivative.svg)

`f′(x₀) = lim_{Δx→0} [f(x₀+Δx) − f(x₀)]/Δx`，几何上是切线斜率 `tan α`，物理上是瞬时速度。
**微分** `dy = f′(x)dx`，且 `Δy = dy + o(Δx)` ——「以直代曲」是微元法的理论基础。

| 关系（一元） | 结论 |
| --- | --- |
| 可导 ⇔ 可微 | 等价（多元不再等价） |
| 可导 ⇒ 连续 ⇒ 极限存在 | 反向均不成立：`|x|` 在 0 连续不可导 |
| 可导 ⇔ 左导数 = 右导数（有限） | 分段点必须用定义算 |
| `f′` 未必连续 | 但由达布定理，`f′` 无跳跃间断 |

### 2.2 求导法则与特殊函数

| 类型 | 公式 |
| --- | --- |
| 四则 | `(uv)′ = u′v + uv′`；`(u/v)′ = (u′v − uv′)/v²` |
| 复合（链式） | `y=f(u), u=g(x) ⇒ y′ = f′(u)g′(x)`，多层复合逐层相乘 |
| 反函数 | `dx/dy = 1/y′`；`d²x/dy² = −y″/(y′)³` |
| 隐函数 | `F(x,y)=0 ⇒ dy/dx = −Fₓ/Fᵧ`（`Fᵧ≠0`） |
| 参数方程 | `dy/dx = ẏ/ẋ`；`d²y/dx² = (ẍÿ − ẋÿ̇)/ẋ³`（先对 t 求导再除 ẋ） |
| 对数求导 | `y=xˣ ⇒ ln y = x ln x ⇒ y′ = xˣ(ln x + 1)` |
| 高阶·莱布尼茨 | `(uv)⁽ⁿ⁾ = Σₖ C(n,k) u⁽ᵏ⁾ v⁽ⁿ⁻ᵏ⁾` |
| 常用 n 阶 | `(sin x)⁽ⁿ⁾ = sin(x+nπ/2)`；`(1/(x+a))⁽ⁿ⁾ = (−1)ⁿ n!/(x+a)ⁿ⁺¹` |

::: tip 工作例题 · 分段点与含绝对值因子
`f(x) = x² sin(1/x)`（x≠0）、`f(0)=0`：在 0 处 `f′(0) = lim x sin(1/x) = 0`（可导），但 `f′(x)=2x sin(1/x) − cos(1/x)` 在 0 处极限不存在 ⇒ **导函数不连续**。这是「可导但导函数不连续」的标准反例。
经典结论：`g(x)|x−a|` 在 `a` 处可导 ⇔ `g(a)=0`（此时导数为 0）。
:::

::: danger 易错 · 求导
- 分段函数分界点**必须用定义**求左右导数；直接对两侧表达式求导再代入，只在导函数连续时才等价。
- 参数方程二阶导数是 `(d/dt (dy/dx))/ẋ`，不是 `ÿ/ẍ`（最常见公式错误）。
- 隐函数求二阶导时，要对一阶结果再求导并把 `y′` 代回，不能把 `y` 当常数。
:::

## 第 3 章 微分中值定理与导数应用（★★★）

### 3.1 四大中值定理

![罗尔、拉格朗日、柯西与泰勒中值定理](/math/math-mvt.svg)

| 定理 | 条件 | 结论 |
| --- | --- | --- |
| 费马引理 | `f` 在 `x₀` 可导且取极值 | `f′(x₀)=0` |
| 罗尔 | `[a,b]` 连续、`(a,b)` 可导、`f(a)=f(b)` | `∃ξ∈(a,b)`, `f′(ξ)=0` |
| 拉格朗日 | `[a,b]` 连续、`(a,b)` 可导 | `f(b)−f(a) = f′(ξ)(b−a)` |
| 柯西 | `f,g` 满足上述条件且 `g′≠0` | `[f(b)−f(a)]/[g(b)−g(a)] = f′(ξ)/g′(ξ)` |
| 泰勒 | `n+1` 阶可导 | 带拉格朗日余项的 `n` 阶展开（`n=0` 退化为拉格朗日） |

**逻辑链**：罗尔（特殊）→ 拉格朗日（罗尔 + 辅助函数）→ 柯西（参数形式）→ 泰勒（高阶），而**柯西是洛必达法则的证明基础**。

::: tip 工作例题 · 辅助函数构造三步
证 `∃ξ: f′(ξ) + f(ξ)g′(ξ) = 0`：
① 把待证式看成某函数 `F` 的导数等于 0；② 乘积分因子 `e^{g(x)}` 得 `F(x)=e^{g(x)}f(x)`；③ 对 `F` 用罗尔定理。
常见模板：证 `f′(ξ)=k` ⇒ `F=f−kx`；证 `f′(ξ)/g′(ξ)=k` ⇒ 柯西；含 `f″` ⇒ 两次罗尔或对 `f′` 用拉格朗日；含积分 ⇒ 积分中值定理。
:::

**洛必达法则的四个前提**（常被忽略）：① 属 `0/0` 或 `∞/∞`；② 去心邻域内 `f′、g′` 存在且 `g′≠0`；③ `lim f′/g′` 存在或为 ∞；④ 若 `lim f′/g′` 振荡不存在则**法则失效**，须改用定义或泰勒。
反例：`lim_{x→∞}(x+sin x)/x = 1`，但 `f′/g′ = 1+cos x` 极限不存在，洛必达给不出结论。

### 3.2 单调性、凹凸性、极值与渐近线

![单调凹凸拐点、三类渐近线与作图流程](/math/math-application.svg)

| 判据 | 结论 |
| --- | --- |
| `f′>0` / `f′<0` | 单调递增 / 递减 |
| `f″>0` / `f″<0` | 图形凹（∪，下凸）/ 凸（∩，上凸） |
| `f″` 变号且曲线连续 | 该点为**拐点**（须写成坐标 `(x₀, f(x₀))`） |
| `f′(x₀)=0` 且 `f′` 变号 | 极值（一阶充分必要判别） |
| `f′(x₀)=0, f″(x₀)<0` / `>0` | 极大 / 极小；`f″=0` 时失效，须回到定义或更高阶 |

**三类渐近线**：
- 水平 `y = A`，若 `lim_{x→±∞} f(x) = A`；
- 铅直 `x = x₀`，若 `lim_{x→x₀} f(x) = ∞`（在无定义点、分段点找）；
- 斜 `y = ax+b`，`a = lim f(x)/x`，`b = lim[f(x)−ax]`（只需在水平不存在时求），且 `x→+∞` 与 `x→−∞` 要分别计算。

**曲率** `κ = |y″|/(1+y′²)^{3/2}`，曲率半径 `ρ = 1/κ`（直线 `κ=0`）。

::: danger 易错 · 导数应用
- 极值是**局部**概念、最值是**全局**概念；闭区间最值必须比较「驻点 + 不可导点 + 端点」。
- `f″(x₀)=0` 既非拐点的充分条件也非必要条件：`f=x⁴` 在 0 有 `f″=0` 但不是拐点；`f=x^{1/3}` 在 0 是拐点但二阶导不存在。
- 拐点是曲线上的**点**（要写坐标），极值点是 **x 值**；两者概念维度不同。
- 同一方向水平与斜渐近线至多各一条；若 `a` 不存在（且非 ∞）则无斜渐近线。
:::

**函数作图七步**：定义域与对称性 → 求 `f′, f″` 及其全部零点/不存在点 → 列表分段 → 判单调与极值 → 判凹凸与拐点 → 求渐近线 → 描特殊点连线。列表法（`+ / 0 / − / 不存在`）是最不易失分的格式。

## 第 4 章 不定积分（★★★）

### 4.1 原函数与基本公式

![三种主要积分法与三类常见可积函数](/math/math-integral.svg)

`∫f(x)dx = F(x) + C ⇔ F′(x)=f(x)`。**连续函数必有原函数**（积分上限函数就是一个）；但有第一类间断点的函数没有原函数（导函数无第一类间断点——达布定理）。

| 基本积分 | 结果 |
| --- | --- |
| `∫x^a dx` | `x^{a+1}/(a+1)+C` (`a≠−1`)；`a=−1` 时 `ln|x|+C` |
| `∫eˣdx`, `∫aˣdx` | `eˣ+C`, `aˣ/ln a+C` |
| `∫sin x dx`, `∫cos x dx` | `−cos x+C`, `sin x+C` |
| `∫dx/(1+x²)`, `∫dx/√(1−x²)` | `arctan x+C`, `arcsin x+C` |
| `∫sec x dx` | `ln|sec x + tan x|+C` |
| `∫dx/(a²+x²)`, `∫dx/√(a²−x²)` | `(1/a)arctan(x/a)+C`, `arcsin(x/a)+C` |
| `∫f′(x)/f(x)dx` | `ln|f(x)|+C`（最高频凑微分） |

### 4.2 三种主要积分法

**第一换元（凑微分）**：`∫f(φ(x))φ′(x)dx = ∫f(u)du`，关键是把被积式拆成「函数 × 其导数」。
**第二换元（变量代换）**：令 `x=ψ(t)` 单调可导，`∫f(x)dx = ∫f(ψ(t))ψ′(t)dt`，最后必须**回代**。

| 根式 | 代换 | 恒等式 |
| --- | --- | --- |
| `√(a²−x²)` | `x = a sin t` | `a²−x² = a²cos²t` |
| `√(a²+x²)` | `x = a tan t` | `a²+x² = a²sec²t` |
| `√(x²−a²)` | `x = a sec t` | `x²−a² = a²tan²t` |

**分部积分** `∫u dv = uv − ∫v du`，取 `u` 的优先级口诀「**反、对、幂、指、三**」（反三角 → 对数 → 幂 → 指数 → 三角），把容易求导的放在 `u`。
循环型（如 `∫eˣcos x dx`）需两次分部后解方程；递推型（如 `Iₙ=∫secⁿx dx`）建立递推公式。

### 4.3 三类常见可积函数

| 类型 | 方法 |
| --- | --- |
| 有理函数 `P(x)/Q(x)` | 先化为真分式（多项式除法）→ 分母因式分解 → 部分分式（含重根、二次不可约）→ 逐项积分 |
| 三角有理式 `R(sin x, cos x)` | 万能代换 `t=tan(x/2)`：`sin x = 2t/(1+t²)`，`cos x = (1−t²)/(1+t²)`，`dx = 2dt/(1+t²)`；有更简对称式时优先用 |
| 简单无理函数 | 根式整体代换：`∫R(x, ⁿ√(ax+b))dx` 令 `t=ⁿ√(ax+b)`；倒代换 `x=1/t` 处理高次分母 |

::: danger 易错 · 不定积分
- **不要漏 `+C`**；分段积分时各段常数须由连续性统一（否则原函数不连续）。
- 三角代换回代时用辅助直角三角形，别把 `t` 直接留在答案里。
- `e^{−x²}`、`sin x / x`、`1/ln x`、`√(1+k²sin²x)` 等**原函数不是初等函数**（刘维尔定理），不要硬算；它们靠级数、变限积分或数值方法处理（见第 5、12 章）。
- `∫1/x dx = ln|x| + C`，绝对值不能省。
:::

::: tip 工作例题 · 三个分部积分
```text
① ∫ x eˣ dx：取 u=x, dv=eˣdx ⇒ x eˣ − ∫ eˣdx = (x−1)eˣ + C
   验算：[(x−1)eˣ]′ = eˣ + (x−1)eˣ = x eˣ ✓
② ∫ ln x dx = x ln x − ∫ x·(1/x)dx = x ln x − x + C
③ ∫ x cos x dx = x sin x − ∫ sin x dx = x sin x + cos x + C
```
**验算习惯**：对结果求导，看是否回到被积函数（比重新积分快得多）。
:::

## 第 5 章 定积分与反常积分（★★★）

### 5.1 定义、性质与微积分基本定理

![黎曼和、微积分基本定理与简化技巧](/math/math-definite.svg)

`∫ₐᵇ f(x)dx = lim_{λ→0} Σ f(ξᵢ)Δxᵢ`（`λ=max Δxᵢ`）。几何上是曲边梯形的**代数面积**（x 轴下方为负）。
**可积的充分条件**：连续、或单调、或只有有限个第一类间断点；**可积的必要条件**：有界。

| 定理 | 内容 |
| --- | --- |
| 积分中值定理 | `f` 连续 ⇒ `∫ₐᵇ f dx = f(ξ)(b−a)` |
| 积分上限函数 | `Φ(x)=∫ₐˣ f(t)dt`；`f` 连续 ⇒ `Φ′(x)=f(x)`；`f` 可积 ⇒ `Φ` 连续（未必可导） |
| 变限求导通式 | `d/dx ∫_{α(x)}^{β(x)} f(t)dt = f(β)β′ − f(α)α′` |
| **牛顿–莱布尼茨** | `∫ₐᵇ f dx = F(b) − F(a)`，把求和极限化为原函数增量 |
| 含参变量 | 被积函数含 `x` 时须先换元把 `x` 提到积分号外，再求导 |

### 5.2 计算简化四技巧

::: tip 工作例题 · 三个必记积分
```text
① ∫₀^{π/2} sin²x dx = ∫₀^{π/2} cos²x dx = π/4 ≈ 0.785398
   （用 cos2x = 1−2sin²x，或华里士公式 I₂ = (1/2)·(π/2)）
② ∫₀¹ x eˣ dx = [(x−1)eˣ]₀¹ = 0 − (−1) = 1
③ ∫₀¹ dx/(1+x²) = arctan x |₀¹ = π/4
④ ∫₀^π x sin x dx = [−x cos x + sin x]₀^π = π
⑤ ∫₀^∞ e^{−x²} dx = √π/2 ≈ 0.886227（泊松积分，用二重积分极坐标证明）
```
:::

| 技巧 | 公式 / 说明 |
| --- | --- |
| 奇偶性 | 对称区间：`f` 奇 ⇒ 积分为 0；`f` 偶 ⇒ `2∫₀ᵃ f dx` |
| 周期性 | `∫ₐ^{a+T} f dx = ∫₀ᵀ f dx`；`∫₀^{nT} f dx = n∫₀ᵀ f dx` |
| 区间再现（King） | `∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx`；用于 `∫₀^{π/2} f(sin x, cos x)dx` 与 `∫₀^π x f(sin x)dx = (π/2)∫₀^π f(sin x)dx` |
| 华里士公式 | `Iₙ=∫₀^{π/2}sinⁿx dx = ∫₀^{π/2}cosⁿx dx`；`n` 偶 ⇒ `(n−1)!!/n!! · π/2`；`n` 奇 ⇒ `(n−1)!!/n!!`；`Iₙ = (n−1)/n · Iₙ₋₂` |

### 5.3 反常积分（广义积分）

| 类型 | 定义 | 收敛判据 |
| --- | --- | --- |
| 无穷区间 | `∫ₐ^∞ f dx = lim_{b→∞}∫ₐᵇ f dx` | `∫₁^∞ dx/xᵖ` 收敛 ⇔ `p > 1` |
| 无界函数（瑕积分） | 瑕点在端点/内部，须分段取极限 | `∫₀¹ dx/xᵖ` 收敛 ⇔ `p < 1` |

::: danger 易错 · 反常积分
- 两个 `p` 的收敛方向**相反**（无穷区间 `p>1`、瑕积分 `p<1`），是最高频记忆错误。
- 瑕点在区间**内部**时必须拆成两段分别判敛，只要有一段发散即整体发散；不能用「主值」冒充收敛。
- 比较判别法要求非负；一般函数用**绝对收敛**判据（`∫|f|` 收敛 ⇒ `∫f` 收敛）。
- 计算反常积分仍可用牛顿–莱布尼茨，但要在无穷/瑕点处取极限，不能把 ∞ 直接代入。
:::

**Γ 函数**（补充）：`Γ(s)=∫₀^∞ x^{s−1}e^{−x}dx (s>0)`，满足 `Γ(s+1)=sΓ(s)`、`Γ(n+1)=n!`、`Γ(1/2)=√π`。它是阶乘的连续延拓，也是 `∫₀^∞ e^{−x²}dx = √π/2` 的推导工具。

## 第 6 章 定积分的应用（★★）

### 6.1 微元法（元素法）

![微元法、几何与物理应用公式表](/math/math-app-integration.svg)

在 `[x, x+dx]` 上把所求量 `U` 的局部增量写成 `dU = f(x)dx`，要求 `ΔU − dU = o(dx)`，则 `U = ∫ₐᵇ f(x)dx`。核心思想是「以直代曲、以匀代变」，且微元必须**可加**。
标准流程：**选积分变量 → 写出微元 → 由区域定上下限 → 积分**。

| 几何量 | 直角坐标 | 极坐标 / 参数式 |
| --- | --- | --- |
| 平面面积 | `A=∫ₐᵇ|f−g|dx` | `A=½∫ₐᵝ r²(θ)dθ` |
| 旋转体体积（绕 x） | `V=π∫ₐᵇ f²(x)dx` | 绕 y 轴柱壳 `V=2π∫ₐᵇ x f(x)dx` |
| 已知截面 | `V=∫ₐᵇ A(x)dx` | — |
| 弧长 | `s=∫ₐᵇ√(1+y′²)dx` | `s=∫√(ẋ²+ẏ²)dt`；`s=∫√(r²+r′²)dθ` |
| 旋转曲面面积 | `S=2π∫ₐᵇ f(x)√(1+y′²)dx` | — |

**物理应用**：变力做功 `W=∫F(x)dx`；液体侧压力 `P=∫ρg h(x)w(x)dx`；质心 `x̄=∫x dm/∫dm`；函数平均值 `f̄=(1/(b−a))∫ₐᵇ f dx`；均方根 `√[(1/(b−a))∫f²dx]`（交流电有效值）。

::: tip 工作例题 · 三道几何题（已核算）
```text
① y=x² (0≤x≤1) 绕 x 轴：V = π∫₀¹ (x²)²dx = π∫₀¹x⁴dx = π/5 ≈ 0.628319
② y=sin x (0≤x≤π) 与 x 轴围成面积：A = ∫₀^π sin x dx = [−cos x]₀^π = 2
③ 星形线 x=a cos³t, y=a sin³t 全长 = 6a（a=1 时为 6）；
   第一象限弧长 = ∫₀^{π/2}3a sin t cos t dt = 3a/2，乘 4 得 6a
④ 抛物线 y=x² 在 [0,1] 的弧长 = ½[√5 + ½ ln(2+√5)]
```
:::

::: danger 易错 · 微元法
- 面积必须加绝对值（或先求交点分段），否则上下曲线交叉时正负抵消。
- 绕 y 轴旋转可用柱壳法或圆盘法，两者积分变量不同，别混用上下限。
- 弧长公式中 `√(1+y′²)` 不能写成 `1+y′`；物理量的单位与坐标系要一致。
:::

## 第 7 章 常微分方程（★★★）

### 7.1 一阶方程的分类解法

![微分方程分类决策树与标准解法](/math/math-ode.svg)

| 类型 | 标准形式 | 解法 |
| --- | --- | --- |
| 可分离变量 | `y′=f(x)g(y)` | `∫dy/g(y) = ∫f(x)dx + C` |
| 齐次方程 | `y′=φ(y/x)` | 令 `u=y/x ⇒ y′=u+xu′`，化为可分离 |
| 一阶线性 | `y′+P(x)y=Q(x)` | 积分因子 `e^{∫P dx}`；`y = e^{−∫P}[∫Q e^{∫P}dx + C]` |
| 伯努利 | `y′+Py=Qyⁿ (n≠0,1)` | 令 `z=y^{1−n}` 化为线性 |
| 全微分方程 | `M dx+N dy=0` 且 `∂M/∂y=∂N/∂x` | 求原函数 `u(x,y)=C`（偏积分法 / 曲线积分） |
| 可降阶 | `y″=f(x)` / `f(x,y′)` / `f(y,y′)` | 积两次 / 令 `p=y′` / 令 `p=y′`, `y″=p dp/dy` |

::: tip 工作例题 · 一阶线性
`y′+2y=eˣ`：积分因子 `e^{2x}`，两边乘后 `(e^{2x}y)′=e^{3x}`，
⇒ `e^{2x}y = ⅓e^{3x}+C` ⇒ **`y = ⅓eˣ + Ce^{−2x}`**。
验算：`y′+2y = ⅓eˣ − 2Ce^{−2x} + ⅔eˣ + 2Ce^{−2x} = eˣ` ✓
:::

### 7.2 高阶线性方程与常系数

**解的结构**：`n` 阶线性方程通解含 `n` 个独立任意常数；齐次解的线性组合仍是齐次解；**非齐次通解 = 齐次通解 + 一个特解**；两非齐次解之差是齐次解。

**二阶常系数齐次** `y″+py′+qy=0`，特征方程 `r²+pr+q=0`：

| 特征根 | 通解 |
| --- | --- |
| 两不等实根 `r₁≠r₂` | `C₁e^{r₁x}+C₂e^{r₂x}` |
| 二重根 `r` | `(C₁+C₂x)e^{rx}` |
| 共轭复根 `α±iβ` | `e^{αx}(C₁cos βx+C₂sin βx)` |

**非齐次特解（待定系数法）**：
- `f(x)=e^{λx}Pₘ(x)` ⇒ 设 `y*=xᵏ e^{λx}Qₘ(x)`，`k` 是 `λ` 作为特征根的重数（0/1/2）；
- `f(x)=e^{αx}[A cos βx+B sin βx]` ⇒ 设 `y*=xᵏ e^{αx}[C cos βx+D sin βx]`，`k` 由 `α+iβ` 是否为特征根决定。

::: tip 工作例题 · 三组方程
```text
① y″−3y′+2y=0 ⇒ r²−3r+2=0 ⇒ r=1,2 ⇒ y=C₁eˣ+C₂e^{2x}
② y″+4y=0 ⇒ r=±2i ⇒ y=C₁cos2x+C₂sin2x
③ y″+4y=sin x：设 y*=A sin x ⇒ −A sin x+4A sin x = 3A sin x = sin x
   ⇒ A=1/3 ⇒ y*=(1/3)sin x，通解 y=C₁cos2x+C₂sin2x+(1/3)sin x
④ 若右端改为 sin 2x，则与齐次解共振，须设 y*=x(A cos2x+B sin2x)
```
:::

**欧拉方程** `x²y″+pxy′+qy=f(x)`：令 `x=eᵗ`（即 `t=ln x`）化为常系数；齐次情形也可直接设 `y=xᵏ` 解指标方程。

::: danger 易错 · 微分方程
- 「齐次」一词有两义：`y′=φ(y/x)` 的齐次方程 ≠ 线性方程的齐次（`Q=0`），看上下文。
- 待定系数法漏乘 `xᵏ` 是最高频失分点：只要 `λ` 是特征根就必须乘。
- 可分离变量时除以 `g(y)` 会丢失 `g(y)=0` 对应的常数解，需单独补回。
- 初值问题要把常数用初始条件定出；通解中的常数个数必须等于方程阶数。
:::

## 第 8 章 向量代数与空间解析几何（★★★）

### 8.1 三种向量积

![三种积、平面与直线方程](/math/math-vector.svg)

| 运算 | 定义 | 性质与用途 |
| --- | --- | --- |
| 数量积 | `a·b = |a||b|cosθ = aₓbₓ+aᵧbᵧ+a_zb_z` | 结果是**标量**；夹角 `cosθ=a·b/(|a||b|)`；投影 `Prj_b a = a·b/|b|`；垂直 ⇔ `a·b=0` |
| 向量积 | `a×b = (aᵧb_z−a_zbᵧ, a_zbₓ−aₓb_z, aₓbᵧ−aᵧbₓ)` | 结果是**向量**，`⊥a` 且 `⊥b`（右手系）；`|a×b|` = 平行四边形面积；平行 ⇔ `a×b=0`；**反交换** `a×b=−b×a` |
| 混合积 | `[a b c] = (a×b)·c`（三阶行列式） | 绝对值 = 平行六面体体积；三向量共面 ⇔ 混合积 = 0；轮换不变、对换变号 |
| 方向余弦 | `cos α=aₓ/|a|` 等 | `cos²α+cos²β+cos²γ=1` |

::: tip 工作例题 · 三种积手算
`a=(1,2,−1)`，`b=(3,0,2)`：
`a·b = 3 + 0 − 2 = 1`；
`a×b = (2·2−(−1)·0, (−1)·3−1·2, 1·0−2·3) = (4, −5, −6)`；
`|a| = √(1+4+1) = √6 ≈ 2.449`；`cosθ = 1/(√6·√13) ≈ 0.1132`。
校验：`(a×b)·a = 4−10+6 = 0` 且 `(a×b)·b = 12+0−12 = 0` ✓（垂直于两者）。
:::

### 8.2 平面、直线与位置关系

| 对象 | 方程 | 关键量 |
| --- | --- | --- |
| 平面点法式 | `A(x−x₀)+B(y−y₀)+C(z−z₀)=0` | 法向量 `n=(A,B,C)` |
| 平面一般式 | `Ax+By+Cz+D=0` | `D=0` 过原点；缺某变量 ⇒ 平行于对应轴 |
| 直线对称式 | `(x−x₀)/m=(y−y₀)/n=(z−z₀)/p` | 方向向量 `s=(m,n,p)` |
| 直线参数式 | `x=x₀+mt, y=y₀+nt, z=z₀+pt` | 代入平面求交点最方便 |
| 直线一般式 | 两平面交线 | `s = n₁×n₂`（别把法向量当方向向量） |

**距离与夹角**：
- 点 `P₀` 到平面：`d = |Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)`；
- 两平面夹角：`cosθ = |n₁·n₂|/(|n₁||n₂|)`（取锐角）；
- 线面夹角：`sinθ = |s·n|/(|s||n|)`；两直线夹角用 `s₁·s₂`；
- 异面直线距离：`d = |[s₁ s₂ P₁P₂]| / |s₁×s₂|`。

::: tip 工作例题 · 点到平面距离
平面 `2x − y + 2z − 3 = 0`，法向量 `n=(2,−1,2)`，`|n|=3`。
点 `(0,0,0)`：`d = |−3|/3 = 1`。
（注意：点 `(1,1,1)` 满足 `2−1+2−3=0`，恰在平面上，距离为 0 —— 出题时容易误选此类点作例题。）
:::

**平面束**：过两平面交线的一切平面（除第二个平面本身）可写成 `(A₁x+B₁y+C₁z+D₁)+λ(A₂x+B₂y+C₂z+D₂)=0`，求「过已知直线且满足某条件」的平面时最省力。

### 8.3 曲面与空间曲线

![二次曲面标准方程、旋转曲面与截痕法](/math/math-surface.svg)

| 曲面 | 标准方程（`a,b,c>0`） | 截痕特征 |
| --- | --- | --- |
| 椭球面 | `x²/a²+y²/b²+z²/c²=1` | 各方向截痕为椭圆 |
| 单叶双曲面 | `x²/a²+y²/b²−z²/c²=1` | 水平截椭圆，含直线 |
| 双叶双曲面 | `x²/a²−y²/b²−z²/c²=1` | 沿 x 轴分两叶 |
| 椭圆锥面 | `x²/a²+y²/b²−z²/c²=0` | 过原点的直线族 |
| 椭圆抛物面 | `z = x²/a²+y²/b²` | 水平截椭圆 |
| 双曲抛物面（马鞍面） | `z = x²/a²−y²/b²` | 水平截双曲线 |
| 柱面 | 方程缺一个变量（如 `x²+y²=R²`） | 母线平行缺失变量的轴 |
| 球面 | `(x−x₀)²+(y−y₀)²+(z−z₀)²=R²` | — |

**旋转曲面**：`yOz` 面上 `f(y,z)=0` 绕 `z` 轴旋转 ⇒ 把 `y` 换成 `±√(x²+y²)`；绕 `y` 轴则把 `z` 换成 `±√(x²+z²)`。
**截痕法**：用 `z=k`、`x=k`、`y=k` 的平面去截，看截痕类型随 `k` 的变化，拼出整体形状。
**空间曲线**：一般式 = 两曲面 `F=0, G=0` 交线；参数式 `x=x(t), y=y(t), z=z(t)`（如圆柱螺线 `x=a cos t, y=a sin t, z=bt`）；在 `xOy` 面的投影由「消去 z 得 `H(x,y)=0`，再与 `z=0` 联立」得到。

::: danger 易错 · 空间解析几何
- `a×b` 反交换、`a·b` 交换；混合积是行列式，对换两列变号。
- 直线一般式中方向向量是两法向量的**叉积**；求线面夹角用 `sin`（不是 `cos`）。
- 曲面方程「缺变量」才是柱面；只含 `x²+y²` 形式且含 `z²` 的是旋转曲面，别混。
:::

## 第 9 章 多元函数微分学及其应用（★★★）

### 9.1 二重极限、偏导数与全微分

![偏导数、全微分、链式法则、方向导数与梯度](/math/math-multivariable.svg)

| 概念 | 定义 / 判据 |
| --- | --- |
| 二重极限 | `∀ε>0 ∃δ>0, 0<√((x−x₀)²+(y−y₀)²)<δ ⇒ |f−A|<ε`；要求**沿任意路径**趋于同一值 |
| 累次极限 | `lim_x lim_y f` 与 `lim_y lim_x f`；二者存在且不等 ⇒ 二重极限不存在（反之不成立） |
| 偏导数 | `fₓ(x₀,y₀)=lim [f(x₀+h,y₀)−f(x₀,y₀)]/h`（固定其余变量） |
| 全微分 | `Δz = AΔx+BΔy+o(ρ)`，`ρ=√(Δx²+Δy²)` ⇒ `dz=fₓdx+fᵧdy` |

**关系图（二元，与一元差别很大）**：

```text
偏导数连续  ⇒  可微  ⇒  连续  ⇒  二重极限存在
                  ⇓
              偏导数存在（且各方向导数存在）

反例：偏导数存在但「不连续」「不可微」都成立 —— 与一元「可导 ⇒ 连续」截然不同
```

::: danger 易错 · 多元微分
- 判定二重极限**不存在**：沿 `y=kx` 得依赖 `k` 的值，或沿 `y=x` 与 `y=x²` 得不同值，即可判否。但沿有限条路径都相同**不能**判存在。
- 偏导数存在 ⇏ 连续、⇏ 可微；可微才保证「沿任意方向的方向导数都存在且等于 `∇f·e`」。
- 二阶混合偏导 `fₓᵧ = fᵧₓ` 需要**连续**条件（克莱罗 / 施瓦茨定理），否则可能不等。
:::

### 9.2 复合、隐函数与几何应用

**链式法则**（先画变量关系图，"一分多合"）：
`z=f(u,v)`, `u=u(x,y)`, `v=v(x,y)` ⇒ `∂z/∂x = fᵤuₓ + f_vvₓ`，`∂z/∂y` 同理。
**一阶全微分形式不变性**：无论 `u,v` 是自变量还是中间变量，`dz = fᵤdu+f_vdv` 形式不变（求全微分与验算都靠它）。

**隐函数求导**：`F(x,y,z)=0` ⇒ `∂z/∂x = −Fₓ/F_z`、`∂z/∂y = −Fᵧ/F_z`（`F_z≠0`）；方程组 `F=G=0` 用雅可比行列式 `J = ∂(F,G)/∂(u,v) ≠ 0`，解线性方程组求各偏导。

**几何应用**：
- 曲面 `F(x,y,z)=0` 在点 `P₀` 的法向量 `∇F(P₀)`，切平面 `Fₓ(x−x₀)+Fᵧ(y−y₀)+F_z(z−z₀)=0`，法线 `(x−x₀)/Fₓ = (y−y₀)/Fᵧ = (z−z₀)/F_z`；
- 空间曲线 `r(t)=(x(t),y(t),z(t))` 的切向量 `r′(t₀)`，切线 `(x−x₀)/x′=(y−y₀)/y′=(z−z₀)/z′`，法平面 `x′(x−x₀)+y′(y−y₀)+z′(z−z₀)=0`。

### 9.3 方向导数、梯度与极值

**方向导数**（`f` 可微时）：`∂f/∂l = fₓcos α+fᵧcos β+f_z cos γ = ∇f·e_l`。
**梯度** `∇f=(fₓ,fᵧ,f_z)`：指向函数增长最快方向，`|∇f|` 是最大方向导数；负梯度是下降最快方向（梯度下降算法的数学来源）；梯度与等值面正交。

::: tip 工作例题 · 方向导数
`f=x²y+sin(xy)` ⇒ `fₓ=2xy+y cos(xy)`，`fᵧ=x²+x cos(xy)`。
在 `(0,1)`：`∇f=(1, 0)`。沿 `e=(1/√2, 1/√2)` 的方向导数 `= 1·(1/√2)+0 = 1/√2 ≈ 0.7071`；
最大方向导数 `=|∇f|=1`（沿 x 轴正向），最小 `=−1`（沿 x 轴负向）。
:::

![无条件极值、条件极值与拉格朗日乘数法](/math/math-extremum.svg)

| 判别 | 结论 |
| --- | --- |
| 无条件极值必要条件 | `fₓ=fᵧ=0`（驻点）或偏导不存在点 |
| 记 `A=fₓₓ, B=fₓᵧ, C=fᵧᵧ`，`Δ=AC−B²` | `Δ>0` 且 `A<0` 极大；`Δ>0` 且 `A>0` 极小；`Δ<0` 鞍点；`Δ=0` 失效 |
| 海森矩阵 | 正定 ⇒ 极小、负定 ⇒ 极大、不定 ⇒ 鞍点 |
| 条件极值 | `L=f+λφ`（多约束 `L=f+Σλᵢφᵢ`），解 `∇L=0`；几何含义 `∇f ∥ ∇φ` |

::: tip 工作例题 · 两组极值
```text
① f=x²+y² 在 (0,0)：A=C=2, B=0 ⇒ Δ=4>0 且 A>0 ⇒ 极小值 0
   f=xy 在 (0,0)：A=C=0, B=1 ⇒ Δ=−1<0 ⇒ 鞍点（不是极值点）
② 条件极值：min x²+y² s.t. x+y=1
   L=x²+y²−λ(x+y−1)，∂L/∂x=2x−λ=0, ∂L/∂y=2y−λ=0 ⇒ x=y
   代入约束 ⇒ x=y=1/2 ⇒ f_min = 1/4+1/4 = 1/2
③ f=xy s.t. x²+y²=1 ⇒ 极大 1/2（x=y=±1/√2）、极小 −1/2
```
:::

**闭区域最值流程**：① 内部驻点值；② 边界上的最值（代入边界化一元，或对边界再用拉格朗日）；③ 比较全部候选。依据是有界闭区域上连续函数必有最值（Weierstrass 定理）。

::: danger 易错 · 极值
- 驻点不一定是极值点（鞍点）；极值点也可能偏导不存在（如 `z=√(x²+y²)` 在原点取极小）。
- `Δ=0` 时二阶判别失效，须回到定义或看更高阶（如 `z=x⁴+y⁴` 与 `z=x⁴−y⁴`）。
- 拉格朗日乘数法给出的是**候选点**，`λ` 本身不是所求；含不等式约束时需另查边界与 KKT 条件。
:::

**补充 · 二元泰勒与最小二乘**：二元泰勒 `f(x₀+h,y₀+k) = f + (h∂ₓ+k∂ᵧ)f + ½(h∂ₓ+k∂ᵧ)²f + …`，是极值充分条件的证明基础；教材「最小二乘法」一节即令残差平方和对参数偏导为零，本质是本章的无条件极值。

## 第 10 章 重积分（★★★）

### 10.1 二重积分

![二重/三重积分、换序与极柱球坐标](/math/math-multiple-integral.svg)

`∬_D f(x,y)dσ = lim Σ f(ξᵢ,ηᵢ)Δσᵢ`；几何上是曲顶柱体的**代数体积**（`f≥0` 时为正）。

| 区域型 | 化为累次积分 |
| --- | --- |
| X 型 `a≤x≤b, φ₁(x)≤y≤φ₂(x)` | `∫ₐᵇ dx ∫_{φ₁}^{φ₂} f(x,y)dy` |
| Y 型 `c≤y≤d, ψ₁(y)≤x≤ψ₂(y)` | `∫_c^d dy ∫_{ψ₁}^{ψ₂} f(x,y)dx` |
| 极坐标 `x=r cosθ, y=r sinθ` | `∬ f(r cosθ, r sinθ) · r dr dθ`（**别漏雅可比 r**） |

**交换积分次序三步**：① 由原上下限写出区域不等式并画图；② 换一个视角重写不等式；③ 若区域非简单型则**分块**。

::: tip 工作例题 · 换序与极坐标
```text
① ∫₀¹dx ∫ₓ¹ f(x,y)dy = ∫₀¹dy ∫₀ʸ f(x,y)dx
   （区域为 0≤x≤y≤1 的三角形，换序后先 x 后 y）
② ∬_{x²+y²≤a²} e^{−(x²+y²)}dxdy = ∫₀^{2π}dθ ∫₀ᵃ e^{−r²} r dr
   = 2π · [−½e^{−r²}]₀ᵃ = π(1−e^{−a²})；a=1 ⇒ π(1−e⁻¹) ≈ 1.9859
③ 教材经典：∬_D e^{−y²}dxdy（D 由 y=x, y=1, x=0 围成）
   先对 y 积分不可行（e^{−y²} 无初等原函数），必须换序先对 x：
   ∫₀¹dy ∫₀ʸ e^{−y²}dx = ∫₀¹ y e^{−y²}dy = ½(1−e⁻¹)
④ 可分离：∬_{[a,b]×[c,d]} g(x)h(y)dxdy = (∫ₐᵇ g dx)(∫_c^d h dy)
   ⇒ ∬_{[0,1]²}(x+y)dxdy = ½+½ = 1
```
:::

**对称性**（先于计算使用）：若 D 关于 y 轴对称且 `f` 对 x 为奇 ⇒ 积分为 0、为偶 ⇒ 两倍；若 D 关于 `y=x` 对称，则 `∬_D f(x,y)dσ = ∬_D f(y,x)dσ`（轮换对称性，可把 `∬ f(x)/(f(x)+f(y))` 化为面积的一半）。

### 10.2 三重积分

| 坐标 | 变换 | 体积元 | 适用区域 |
| --- | --- | --- | --- |
| 直角 | — | `dx dy dz` | 一般；投影法（先 z）/ 截面法（先 xy） |
| 柱 | `x=r cosθ, y=r sinθ, z=z` | `r dr dθ dz` | 旋转体、含 `x²+y²` |
| 球 | `x=ρ sinφ cosθ, y=ρ sinφ sinθ, z=ρ cosφ` | `ρ² sinφ dρ dφ dθ` | 球体、锥体、含 `x²+y²+z²` |
| 一般换元 | `x=x(u,v,w)` 等 | `|J| du dv dw` | `J = ∂(x,y,z)/∂(u,v,w)` |

**φ 是与 z 轴正向的夹角**（`0≤φ≤π`），`θ∈[0,2π]`；常见错误是把 `sinφ` 写成 `cosφ`、或把 `φ` 当成与 `xOy` 面的夹角。

::: tip 工作例题 · 三重积分
```text
① ∭_{x²+y²+z²≤R²} 1 dV = 4πR³/3（R=1 ⇒ 4π/3 ≈ 4.18879）
② ∭_{上半球 x²+y²+z²≤1, z≥0} z dV
   = ∫₀^{2π}dθ ∫₀^{π/2}sinφ cosφ dφ ∫₀¹ ρ³ dρ
   = 2π · (1/2) · (1/4) = π/4 ≈ 0.785398
③ ∭_Ω (x²+y²) dV（Ω 为圆柱 x²+y²≤1, 0≤z≤1），柱坐标：
   ∫₀^{2π}dθ ∫₀¹ r³ dr ∫₀¹ dz = 2π · 1/4 = π/2
```
:::

**应用**：曲面面积 `A = ∬_{D_xy} √(1+zₓ²+zᵧ²) dxdy`（`z=z(x,y)`）；平面薄片质量 `M=∬ρ dσ`、质心 `x̄=∬xρ dσ/M`、转动惯量 `I_z=∬(x²+y²)ρ dσ`；万有引力按分量积分。

::: danger 易错 · 重积分
- 换序/换元后**上下限与雅可比必须同步改**；极坐标漏 `r`、球坐标漏 `ρ²sinφ` 最常见。
- 二重积分中值定理 `∬_D f dσ = f(ξ,η)·Area(D)` 要求 `f` 连续、`D` 闭连通。
- 被积函数含绝对值或分段时，必须按符号/分界把区域切开再积分。
:::

## 第 11 章 曲线积分、曲面积分与场论（★★★）

### 11.1 两类线积分与两类面积分

![两类线面积分、格林/高斯/斯托克斯公式与散度旋度](/math/math-field.svg)

| 类型 | 记号 | 与方向 | 计算要点 |
| --- | --- | --- | --- |
| 第一类（对弧长） | `∫_L f(x,y,z)ds` | 无关 | 参数化后代 `ds=√(ẋ²+ẏ²+ż²)dt`；下限须小于上限 |
| 第二类（对坐标） | `∫_L Pdx+Qdy+Rdz` | **有关**（反向变号） | 代入参数方程，起终点决定上下限（可上大下小） |
| 第一类面积分 | `∬_Σ f dS` | 无关（无方向） | 投影 + `dS = √(1+zₓ²+zᵧ²)dxdy` |
| 第二类面积分 | `∬_Σ P dydz+Q dzdx+R dxdy` | **与侧有关** | 投影到相应坐标面并按侧定正负；或合一投影法 |

**两类之间的联系**：`∫Pdx+Qdy = ∫(P cos α+Q cos β)ds`；`∬P dydz+Q dzdx+R dxdy = ∬(P cos α+Q cos β+R cos γ)dS`，其中 `(cos α, cos β, cos γ)` 是切向/法向的方向余弦。

### 11.2 三大公式

| 公式 | 表达式 | 条件 |
| --- | --- | --- |
| **格林** | `∮_L Pdx+Qdy = ∬_D (∂Q/∂x − ∂P/∂y)dxdy` | `L` 为正向（逆时针）分段光滑闭曲线，`P,Q` 在 `D` 上有一阶连续偏导 |
| **高斯** | `∯_Σ P dydz+Q dzdx+R dxdy = ∭_Ω(∂P/∂x+∂Q/∂y+∂R/∂z)dV` | `Σ` 取**外侧**闭曲面 |
| **斯托克斯** | `∮_Γ Pdx+Qdy+Rdz = ∬_Σ (rot A)·n dS` | `Γ` 与 `Σ` 的侧符合右手规则 |

**统一视角**：三者都是「**边界上的积分 = 内部某种导数的积分**」，即广义斯托克斯定理 `∫_{∂M} ω = ∫_M dω`；牛顿–莱布尼茨是它在区间 `[a,b]` 上的 1 维特例。

**路径无关与全微分求积**（单连通域内等价）：
`∂P/∂y = ∂Q/∂x` ⇔ `∮_L Pdx+Qdy = 0`（任意闭路）⇔ 积分与路径无关 ⇔ `Pdx+Qdy` 是某 `u(x,y)` 的全微分，且 `u(x,y)=∫_{(x₀,y₀)}^{(x,y)} Pdx+Qdy`（沿折线计算）。

**散度与旋度**：`div A = ∂P/∂x+∂Q/∂y+∂R/∂z`（标量，通量源强度）；`rot A = ∇×A`（向量，环流强度）；`∇(1/r)`、`∇·(r/r³)` 等恒等式在场论中常用。

::: tip 工作例题 · 三大公式
```text
① 格林求面积：取 P=−y/2, Q=x/2 ⇒ ∮_L (x dy − y dx)/2 = Area(D)
   ⇒ 单位圆上 ∮ x dy − y dx = 2π ≈ 6.28319
② 奇点陷阱：∮_{单位圆} (x dy−y dx)/(x²+y²) = 2π
   此处 P,Q 在原点无定义，不能直接套格林（会错得 0）；
   须挖去以原点为心的小圆 ε，在环形域用格林（旋度为 0）⇒ 等于小圆上的积分 2π
③ 高斯：∯_S x dydz+y dzdx+z dxdy = ∭_Ω 3 dV = 3V
   单位球 V=4π/3 ⇒ 4π ≈ 12.56637
④ div(x,y,z)=3；rot(−y,x,0)=(0,0,2)；∇(x²+y²+z²)=(2x,2y,2z)
```
:::

::: danger 易错 · 三大公式
- 非闭曲线要**补线**成闭、非闭曲面要**补面**成闭，补上的部分最后要减掉。
- 区域含奇点（分母为零、偏导不连续）必须**挖洞**，否则格林/高斯结论错误。
- 方向：格林逆时针为正、高斯外侧为正、斯托克斯与法向满足右手规则；取反则整体变号。
- 第一类积分与方向无关且可用对称性；第二类积分与方向/侧有关，先定向再计算。
:::

**补充 · 场论术语**：通量 `Φ=∬_Σ A·n dS`（高斯：通量 = 散度的体积分）；环流量 `Γ=∮_Γ A·dl`（斯托克斯：环流量 = 旋度通量）；`div A ≡ 0` 称无源场（沿任意闭曲面的通量为零），`rot A ≡ 0` 且在单连通域内称无旋场/保守场（存在势函数）。梯度场必无旋，无旋场在单连通域内必为梯度场。

## 第 12 章 无穷级数（★★★）

### 12.1 常数项级数

![判敛决策树、幂级数与傅里叶级数](/math/math-series.svg)

`Σuₙ` 收敛 ⇔ 部分和序列 `Sₙ = Σ_{k=1}^{n} uₖ` 收敛。**必要条件**：`lim uₙ = 0`（不满足立即发散；满足未必收敛，如调和级数）。

| 类型 | 审敛法 | 判据 |
| --- | --- | --- |
| 正项 | 比较 / 极限比较 | 与 `Σ1/nᵖ`（`p>1` 收敛）、几何级数 `Σqⁿ`（`|q|<1` 收敛）比 |
| 正项 | 比值（达朗贝尔） | `ρ=lim uₙ₊₁/uₙ`：`ρ<1` 收敛、`ρ>1` 发散、`=1` 失效 |
| 正项 | 根值（柯西） | `ρ=lim ⁿ√uₙ`，同上 |
| 正项 | 积分判别 | `uₙ=f(n)`，`f` 正递减 ⇒ `Σuₙ` 与 `∫₁^∞ f(x)dx` 同敛散 |
| 交错 | 莱布尼茨 | `uₙ` 单调递减且趋于 0 ⇒ 收敛，余项 `|rₙ| ≤ uₙ₊₁` |
| 一般 | 绝对收敛 | `Σ|uₙ|` 收敛 ⇒ `Σuₙ` 收敛；反之称条件收敛 |

**收敛级数的性质**：可逐项加减、乘常数、任意加括号；**绝对收敛可任意重排且和不变**，条件收敛重排可改变和甚至发散（黎曼重排定理）。

::: tip 工作例题 · 五个经典级数
```text
① 几何级数 Σ_{n=0}^∞ qⁿ = 1/(1−q)（|q|<1）；|q|≥1 发散
② p 级数 Σ1/nᵖ：p>1 收敛、p≤1 发散；Σ1/n 发散（调和级数）
③ 裂项 Σ_{n=1}^∞ 1/[n(n+1)] = Σ(1/n − 1/(n+1)) = 1
④ 交错调和 Σ(−1)^{n+1}/n = ln 2 ≈ 0.693147（条件收敛）
⑤ Σ(−1)^{n+1}/n² = π²/12 ≈ 0.822467（绝对收敛）
```
:::

### 12.2 幂级数与函数展开

`Σaₙ(x−x₀)ⁿ` 的**收敛半径** `R = lim |aₙ/aₙ₊₁|` 或 `R = 1/lim ⁿ√|aₙ|`；收敛区间 `(x₀−R, x₀+R)`，**端点必须单独判断**才得收敛域。

| 性质 | 内容 |
| --- | --- |
| 阿贝尔定理 | 在收敛区间内闭一致收敛；和函数在收敛区间内连续 |
| 逐项运算 | 可逐项求导、逐项积分，**收敛半径不变**（端点收敛性可能改变） |
| 和函数求法 | 逐项求导/积分化为几何级数求和，再积分/求导还原；注意 `S(0)` 定常数 |

::: tip 工作例题 · 和函数
```text
Σ_{n=0}^∞ xⁿ = 1/(1−x),  |x|<1
逐项求导：Σ_{n=1}^∞ n x^{n−1} = 1/(1−x)²
两边乘 x：Σ_{n=1}^∞ n xⁿ = x/(1−x)²
验算 x=1/2：右侧 = 0.5/0.25 = 2；前 50 项部分和 = 2.0000 ✓

Σ_{n=1}^∞ xⁿ/n = −ln(1−x),  −1≤x<1
（由 ∫₀ˣ 1/(1−t)dt 逐项积分得到；端点 x=−1 收敛、x=1 发散）
```
:::

**五个麦克劳林展开**（见第 1.3 节表），收敛域分别为：
`eˣ`、`sin x`、`cos x` 为 `(−∞,+∞)`；`ln(1+x)` 为 `(−1,1]`；`(1+x)^α` 依赖 α，一般 `(−1,1)`。

**补充 · 一致收敛**：函数项级数 `Σuₙ(x)` 的一致收敛性（魏尔斯特拉斯 M 判别法：`|uₙ(x)|≤Mₙ` 且 `ΣMₙ` 收敛）保证和函数连续、可逐项积分与逐项求导（还需导函数一致收敛）。这解释「为何幂级数能在收敛区间内任意逐项运算」，教材把它列为选学但逻辑上不可缺。

### 12.3 傅里叶级数

周期为 `2π` 的函数：
`f(x) ~ a₀/2 + Σ_{n=1}^∞ (aₙ cos nx + bₙ sin nx)`，
`aₙ = (1/π)∫_{−π}^{π} f(x)cos nx dx`，`bₙ = (1/π)∫_{−π}^{π} f(x)sin nx dx`。

**狄利克雷收敛定理**（教材核心）：若 `f` 在一个周期上连续或只有有限个第一类间断点，且只有有限个极值点，则级数收敛，且
- 在连续点收敛于 `f(x)`；
- 在间断点收敛于 `[f(x⁻)+f(x⁺)]/2`；
- 在端点 `±π` 收敛于 `[f(−π⁺)+f(π⁻)]/2`。

| 情形 | 展开形式 |
| --- | --- |
| `f` 奇（−π,π） | 正弦级数，只含 `bₙ`（`f(x)=x ⇒ x = 2Σ(−1)ⁿ⁺¹ sin nx / n`） |
| `f` 偶（−π,π） | 余弦级数，只含 `aₙ`（`f(x)=|x| ⇒ |x| = π/2 − (4/π)Σ cos(2k−1)x/(2k−1)²`） |
| `[0,π]` 上给定 | 作奇延拓得正弦级数、偶延拓得余弦级数 |
| 周期 `2l` | 把 `nx` 换成 `nπx/l`，系数中 `1/π` 换 `1/l` |

::: tip 工作例题 · 用傅里叶级数求数项级数的和
```text
x = 2Σ_{n=1}^∞ (−1)^{n+1} sin(nx)/n,  x∈(−π,π)
取 x=π/2：π/2 = 2(1 − 1/3 + 1/5 − 1/7 + …)
⇒ 1 − 1/3 + 1/5 − … = π/4 ≈ 0.785398 （莱布尼茨级数）

|x| = π/2 − (4/π)Σ_{k=1}^∞ cos((2k−1)x)/(2k−1)²,  x∈[−π,π]
取 x=0：0 = π/2 − (4/π)Σ1/(2k−1)² ⇒ Σ1/(2k−1)² = π²/8
```
:::

::: danger 易错 · 级数
- `lim uₙ = 0` 只是**必要**条件；调和级数是最经典反例。
- 比值/根值法 `ρ=1` 时**失效**，必须换比较、积分或拉比/高斯判别法（如 `Σ1/n`、`Σ1/n²` 都是 `ρ=1` 但敛散不同）。
- 交错级数用莱布尼茨判收敛，但**绝对收敛性要另判** `Σ|uₙ|`；「收敛」与「绝对收敛」不可混。
- 逐项求导/积分后收敛半径不变，但**端点**可能从收敛变发散（如 `Σxⁿ/n` 与 `Σxⁿ⁻¹`），必须重新检验。
- 傅里叶级数在间断点收敛到左右极限的平均值，**不是** `f(x)`；端点同理。
:::

## 典型计算题逐步演算（可照抄的解题格式）

> 每道题按「识别类型 → 选方法 → 逐步演算 → 验算」四步展开，代码块内是考场可直接复用的书写格式。

### 演 1 · 极限（七类未定式）· 第 1 章

```text
① lim_{x→0} sin(3x)/(5x)
   重要极限 sin u/u → 1：= lim (3/5)·sin(3x)/(3x) = 3/5 = 0.6
② lim_{x→0} (eˣ − 1 − x)/x²   （0/0）
   泰勒：eˣ = 1 + x + x²/2 + o(x²) ⇒ 分子 = x²/2 + o(x²) ⇒ 极限 = 1/2
③ lim_{x→0} (tan x − sin x)/x³   （0/0，加减型不可用等价无穷小直接替换）
   泰勒：tan x = x + x³/3 + o(x³)，sin x = x − x³/6 + o(x³)
   差 = x³/2 ⇒ 极限 = 1/2   （数值验证 x=1e−4 得 0.50000000）
④ lim_{n→∞} (1 + 2/n)ⁿ   （1^∞）
   取对数：n ln(1+2/n) ~ n·(2/n) = 2 ⇒ 极限 = e² ≈ 7.389056
⑤ lim_{x→∞} (x + sin x)/x
   = 1 + sin x/x → 1；洛必达会得 1+cos x（极限不存在）⇒ 此处洛必达失效
```

### 演 2 · 导数（分段点与隐函数）· 第 2 章

```text
① f(x)=x² sin(1/x) (x≠0), f(0)=0，求 f′(0)
   定义：f′(0)=lim_{x→0} [x² sin(1/x) − 0]/x = lim x sin(1/x) = 0（有界×无穷小）
   但 x≠0 时 f′(x)=2x sin(1/x) − cos(1/x)，x→0 无极限 ⇒ f′ 在 0 不连续
② x² + y² = 1 求 dy/dx 与 d²y/dx²
   隐函数：2x + 2y y′ = 0 ⇒ y′ = −x/y
   再求导：y″ = −(y − x y′)/y² = −(y + x²/y)/y² = −(x²+y²)/y³ = −1/y³
③ y = xˣ ⇒ ln y = x ln x ⇒ y′ = y(ln x + 1) = xˣ(ln x + 1)
```

### 演 3 · 中值定理与极值 · 第 3 章

```text
题：证明 f(x)=x³−3x 在 [0,1] 上满足拉格朗日定理，并求 ξ。
① 验证：多项式在 [0,1] 连续、(0,1) 可导 ✓
② f(1)=−2, f(0)=0 ⇒ [f(1)−f(0)]/(1−0) = −2
③ f′(x)=3x²−3 = −2 ⇒ 3x²=1 ⇒ x=1/√3 ∈ (0,1) ✓ ⇒ ξ=1/√3

题：求 f(x)=x³−3x²+1 的单调区间、极值与拐点。
① f′=3x²−6x=3x(x−2)，驻点 x=0,2
② 区间：(−∞,0) f′>0 增；(0,2) f′<0 减；(2,+∞) f′>0 增
③ 极大 f(0)=1，极小 f(2)=8−12+1=−3
④ f″=6x−6=0 ⇒ x=1；两侧 f″ 变号 ⇒ 拐点 (1, 1−3+1)=(1,−1)
```

### 演 4 · 不定积分（分部与换元）· 第 4 章

```text
① ∫ x eˣ dx：u=x ⇒ ∫x eˣdx = x eˣ − ∫eˣdx = (x−1)eˣ + C
   验算：[(x−1)eˣ]′ = eˣ+(x−1)eˣ = x eˣ ✓
② ∫ ln x dx = x ln x − ∫x·(1/x)dx = x ln x − x + C
③ ∫ dx/(x²+4) = (1/2)arctan(x/2) + C

   回代：= ½arcsin x + ½x√(1−x²) + C
```

### 演 5 · 定积分与反常积分 · 第 5 章

```text
① ∫₀^{π/2} sin²x dx = ∫₀^{π/2}(1−cos2x)/2 dx
   = [x/2 − sin2x/4]₀^{π/2} = π/4 ≈ 0.785398
② ∫₀¹ x eˣ dx = [(x−1)eˣ]₀¹ = 0 − (−1) = 1
③ ∫₀^π x sin x dx：区间再现 ⇒ I = (π/2)∫₀^π sin x dx = (π/2)·2 = π
④ 判敛：∫₁^∞ dx/xᵖ 收敛 ⇔ p>1；∫₀¹ dx/xᵖ 收敛 ⇔ p<1

   = ∫₀^{π/2}dθ∫₀^∞ e^{−r²}r dr = (π/2)·(1/2) = π/4 ⇒ I=√π/2
```

### 演 6 · 定积分应用（微元法）· 第 6 章

```text

   ds = √(ẋ²+ẏ²)dt = 3a|sin t cos t|dt
```

### 演 7 · 微分方程 · 第 7 章

```text
① y′+2y=eˣ ⇒ (e^{2x}y)′=e^{3x} ⇒ e^{2x}y=⅓e^{3x}+C ⇒ y=⅓eˣ+Ce^{−2x}
② y″−3y′+2y=0 ⇒ r²−3r+2=0 ⇒ r=1,2 ⇒ y=C₁eˣ+C₂e^{2x}
```

```text
① f=x²y+sin(xy)：fₓ=2xy+y cos(xy)，fᵧ=x²+x cos(xy)
```

### 演 10 · 重积分 · 第 10 章

```text
① 换序：∫₀¹dx∫ₓ¹ f dy （区域 0≤x≤y≤1）⇒ ∫₀¹dy∫₀ʸ f dx
② ∬_{D} e^{−y²}dxdy，D: 0≤x≤y≤1
   = ∫₀¹dy∫₀ʸ e^{−y²}dx = ∫₀¹ y e^{−y²}dy = ½(1−e⁻¹) ≈ 0.31606
③ ∬_{x²+y²≤a²} e^{−(x²+y²)}dxdy = 2π∫₀ᵃ r e^{−r²}dr = π(1−e^{−a²})
   a=1 ⇒ ≈ 1.985865
④ ∭_{上半球} z dV = ∫₀^{2π}dθ∫₀^{π/2}sinφ cosφ dφ∫₀¹ρ³dρ

⑤ ∭_{单位球} 1 dV = 4π/3 ≈ 4.188790
```

### 演 11 · 曲线曲面积分与三大公式 · 第 11 章

```text
① 单位圆 L（逆时针）：∮_L x dy − y dx
   参数 x=cos t, y=sin t ⇒ x dy−y dx = cos²t dt + sin²t dt = dt
   ⇒ 积分 = ∫₀^{2π}dt = 2π （= 2·Area，格林公式验证：∬_D 2 dxdy = 2π）
② 奇点陷阱：∮_{单位圆}(x dy−y dx)/(x²+y²)
   ∂Q/∂x−∂P/∂y = 0 但原点为奇点 ⇒ 不能直接得 0
   挖去半径 ε 小圆后由格林 ⇒ 等于小圆积分 = 2π
③ 高斯：∯_S x dydz+y dzdx+z dxdy = ∭_Ω 3 dV，单位球 ⇒ 3·(4π/3)=4π
④ div(x,y,z)=3；rot(−y,x,0)=(0,0,2)
⑤ 判路径无关：P=2xy, Q=x² ⇒ ∂P/∂y=2x=∂Q/∂x ⇒ 与路径无关
   原函数 u=∫Pdx = x²y+φ(y)，由 uᵧ=x²+φ′=Q ⇒ φ′=0 ⇒ u=x²y+C
```

### 演 12 · 级数 · 第 12 章

```text
① 判敛 Σ n/(2ⁿ)：比值 ρ=lim [(n+1)/2^{n+1}]/[n/2ⁿ] = 1/2 < 1 ⇒ 收敛
② 判敛 Σ 1/n²：p=2>1 ⇒ 收敛；Σ1/n：p=1 ⇒ 发散
③ 收敛半径 Σ xⁿ/n：R=lim |aₙ/aₙ₊₁| = lim (n+1)/n = 1
   端点 x=1 ⇒ Σ1/n 发散；x=−1 ⇒ Σ(−1)ⁿ/n 收敛 ⇒ 收敛域 [−1,1)
④ 和函数 Σ_{n=1}^∞ n xⁿ：由 Σxⁿ=1/(1−x) 逐项求导乘 x
   ⇒ x/(1−x)²（|x|<1）；验算 x=1/2 ⇒ 2
⑤ Σ1/[n(n+1)] = Σ(1/n−1/(n+1)) = 1 − lim 1/(N+1) = 1
⑥ Σ(−1)^{n+1}/n = ln2（条件收敛）；Σ(−1)^{n+1}/n² = π²/12（绝对收敛）
```

## 各章深挖专题（补充）

### 深 1 · 极限严格化的三个层次（第 1 章）

| 层次 | 内容 | 作用 |
| --- | --- | --- |
| 直观 | 「无限逼近」 | 建立直觉，但无法证明 |
| ε–δ / ε–N | 把「任意接近」量化为 `∀ε ∃δ` | 证明极限存在、唯一性、保号性 |
| 拓扑 | 邻域、聚点、完备性、柯西列 | 实数完备性等价于「单调有界必收敛」「柯西列必收敛」 |

**七种等价刻画**（补充）：`lim aₙ=A` ⇔ 任意子列收敛到 A（若有子列不收敛或收敛到别的值，则原数列不收敛）。判定发散常用「找两个子列极限不同」，如 `(−1)ⁿ`。
**Stolz 定理**（补充，考研常用）：`bₙ` 严格递增趋于 ∞ 时，`lim aₙ/bₙ = lim (aₙ₊₁−aₙ)/(bₙ₊₁−bₙ)`（离散版洛必达），用于 `lim (1+1/2+…+1/n)/ln n = 1` 一类题。

### 深 2 · 中值定理的证明链与反例（第 3 章）

```text
费马引理（极值点导数为 0）
   ↓ 加上 f(a)=f(b)
罗尔定理
   ↓ 构造 F(x)=f(x)−f(a)−[(f(b)−f(a))/(b−a)](x−a)
拉格朗日中值定理
   ↓ 参数化 (g(t), f(t)) 或构造含 g 的辅助函数
柯西中值定理
   ↓ 反复应用于余项
泰勒定理（拉格朗日余项）
```
**条件不可省的反例**：`f(x)=|x|` 在 `[−1,1]` 满足连续且 `f(−1)=f(1)`，但 0 处不可导 ⇒ 不存在 `f′(ξ)=0` 的点，可见「可导」条件不可去。

### 深 3 · 积分技巧体系：何时用哪个（第 4、5 章）

| 被积特征 | 首选方法 |
| --- | --- |
| 复合函数 × 内层导数 | 第一换元（凑微分） |
| 含 `√(a²±x²)`、`√(x²−a²)` | 三角代换 |
| 两个不同类函数相乘（幂×指/三/对/反三角） | 分部积分，按「反对幂指三」取 u |
| 有理分式 | 部分分式分解 |
| 三角函数有理式 | 万能代换（有对称性时优先用倍角/降幂） |
| 对称区间 | 先查奇偶性；三角积分可用区间再现 |
| `∫₀^{π/2} sinⁿx dx` | 华里士公式 |
| 变限积分求导 | 通式 + 先换元把参数提出 |

**不可积但要会处理的函数**：`∫e^{−x²}dx` 用级数展开或误差函数 `erf(x)`；`∫₀^{+∞} sin x/x dx = π/2`（狄利克雷积分，用含参积分或拉普拉斯变换）；`∫₀^{π/2} ln sin x dx = −(π/2)ln 2`（用区间再现与倍角）。

### 深 4 · 反常积分判敛的完整工具箱（第 5 章）

| 判别法 | 陈述 |
| --- | --- |
| 比较判别 | `0≤f≤g`，`∫g` 收敛 ⇒ `∫f` 收敛；`∫f` 发散 ⇒ `∫g` 发散 |
| 极限比较 | `lim f/g = c ∈ (0,∞)` ⇒ 同敛散；`c=0` 且 `∫g` 收敛 ⇒ `∫f` 收敛；`c=∞` 且 `∫g` 发散 ⇒ `∫f` 发散 |
| 柯西判别（p 判别） | `∫₁^∞ f(x)dx`：若 `lim xᵖ f(x) = c` 且 `p>1` ⇒ 收敛；`p≤1` 且 `c>0` ⇒ 发散。瑕积分换用 `lim (x−a)ᵖ f(x)`，`p<1` 收敛 |
| 绝对/条件收敛 | `∫|f|` 收敛 ⇒ `∫f` 收敛；反之称条件收敛（如 `∫₁^∞ sin x/x dx`） |
| Γ / B 函数 | `Γ(s)`、`B(p,q)=Γ(p)Γ(q)/Γ(p+q)`，把许多反常积分化为特殊函数值 |

### 深 5 · 线性微分方程解的结构（第 7 章）

`L[y]=y⁽ⁿ⁾+a₁(x)y⁽ⁿ⁻¹⁾+…+aₙ(x)y` 是**线性算子**，故：
- 齐次解集是 n 维线性空间（基 = 基本解组，朗斯基行列式 `W≠0` 判别线性无关）；
- 非齐次通解 = 齐次通解 + 任一特解；
- 叠加原理：`L[y]=f₁+f₂` 的解 = 对应两解之和。

**常数变易法**：已知齐次基本解 `y₁,y₂`，设特解 `y*=C₁(x)y₁+C₂(x)y₂`，解方程组 `C₁′y₁+C₂′y₂=0`、`C₁′y₁′+C₂′y₂′=f`，可处理一般（非常系数）二阶方程 —— 这是待定系数法失效时的通用手段。
**幂级数解法**（教材第十二章选学）：在常点附近设 `y=Σaₙxⁿ` 代入方程递推系数，是勒让德、贝塞尔方程的标准解法；欧拉公式 `e^{ix}=cos x+i sin x` 也由幂级数得到。

### 深 6 · 多元微分「四个概念」的反例库（第 9 章）

| 命题 | 真伪 | 反例 / 理由 |
| --- | --- | --- |
| 偏导存在 ⇒ 连续 | 假 | `f=xy/(x²+y²)`（(0,0) 补 0）：偏导存在但不连续 |
| 连续 ⇒ 偏导存在 | 假 | `f=|x|+|y|` |
| 各方向方向导数存在 ⇒ 可微 | 假 | 方向导数只沿直线，可微要求全增量线性逼近 |
| 偏导连续 ⇒ 可微 | 真 | 充分条件（教材标准定理） |
| 可微 ⇒ 偏导连续 | 假 | 见第 2 章 `x² sin(1/x)` 的一元类比，二元可构造类似例子 |
| 混合偏导恒相等 | 假 | 需连续条件；经典反例 `f=xy(x²−y²)/(x²+y²)` 在原点 `fₓᵧ≠fᵧₓ` |

### 深 7 · 重积分换序的通用算法（第 10 章）

① 从累次积分上下限写出不等式组；② 在 `xOy` 平面画出区域边界曲线并求交点；③ 用「穿线法」：对固定的 y 从左边界穿到右边界，读出 `x` 的上下限；④ 若穿线过程中边界函数发生变化（区域不是 Y 简单型），**按变化点分块**；⑤ 写出新的累次积分并检查端点。
**对称性优先级**：奇偶性 → 轮换对称 → 区域可加性 → 换元（极/柱/球）→ 直接积分。先化简再动笔是节省时间的关键。

### 深 8 · 三大公式的统一形式与场论恒等式（第 11 章）

广义斯托克斯定理 `∫_{∂M} ω = ∫_M dω` 在外微分语言下统一：
- `n=1`：牛顿–莱布尼茨（`∫_{[a,b]} dF = F(b)−F(a)`）；
- `n=2`：格林公式（平面区域边界是曲线）；
- `n=3`：高斯（体边界是闭曲面）、斯托克斯（曲面边界是闭曲线）——取决于取 2-形式还是 1-形式。

**常用场论恒等式**（补充）：`∇×(∇f)=0`（梯度场无旋）；`∇·(∇×A)=0`（旋度场无源）；`∇·(f A)=∇f·A+f∇·A`；`∇²f = ∇·(∇f)`（拉普拉斯算子）。这些是电磁学、流体力学方程的语言基础。

### 深 9 · 级数判敛法的强弱排序（第 12 章）

```text
必要条件（通项→0）→ 正项：比较/极限比较（最基础）
   → 比值 / 根值（对阶乘、指数型最有效；ρ=1 失效）
   → 积分判别、拉比判别、高斯判别（对 ρ=1 的临界情形）
交错：莱布尼茨（收敛）→ 再看 Σ|uₙ|（绝对 or 条件）
```
**根值强于比值**（补充）：由 `lim uₙ₊₁/uₙ = ρ ⇒ lim ⁿ√uₙ = ρ`，反之不然；故含 `n` 次幂的项优先用根值。
**阿贝尔 / 狄利克雷判别法**（补充）：处理 `Σaₙbₙ` 型，若 `Σaₙ` 部分和有界且 `bₙ` 单调趋于 0 ⇒ 收敛（狄利克雷）；这解释了交错级数判别的一般原理。

### 深 10 · 傅里叶级数与幂级数的对照（第 12 章）

| 维度 | 幂级数 | 傅里叶级数 |
| --- | --- | --- |
| 基函数 | `1, x, x², …`（幂函数） | `1, cos nx, sin nx`（三角函数，正交系） |
| 系数来源 | 泰勒系数 `f⁽ⁿ⁾(0)/n!`（局部信息） | 积分 `aₙ, bₙ`（**整体**信息，用正交性） |
| 收敛要求 | 函数解析 + 余项→0 | 狄利克雷条件（分段光滑，允许间断） |
| 适用范围 | 只能展开光滑解析函数 | 可展开有跳跃间断的周期函数 |
| 端点 | 收敛域端点单独判 | 间断点收敛到左右极限平均 |

**帕塞瓦尔等式**（补充）：`(1/π)∫_{−π}^{π} f² dx = a₀²/2 + Σ(aₙ²+bₙ²)`，是「能量守恒」在频域的表述，也是求 `Σ1/n⁴ = π⁴/90` 一类级数和的工具。

## 各章高频题型与解题套路

> 按 12 章列出「见到题目 → 识别类型 → 标准动作」，是考前快速检索用的操作手册。

### 第 1 章 · 函数极限连续

| 题型 | 标准动作 |
| --- | --- |
| 求 `0/0` 极限 | 先试等价无穷小（仅乘除）→ 加减结构或主阶抵消直接上泰勒 → 最后才洛必达 |
| 求 `1^∞` 极限 | 凑 `(1+α)^{1/α}` 或取对数；速算 `e^{lim g(f−1)}` |
| 递推数列极限 | 证有界（归纳）+ 证单调（作差/作商）⇒ 设极限 A 解 `A=f(A)`，注意验证 A 的合理性 |
| n 项和极限 | 夹逼准则（放缩）或定积分定义 `lim (1/n)Σf(k/n)=∫₀¹f dx` |
| 无穷小阶的比较 | 求 `lim α/β`：为 0 则 α 高阶、∞ 则低阶、常数 c≠0 则同阶、1 则等价 |
| 间断点分类 | 找所有可疑点（分母为 0、分段点、无定义点）→ 逐点算左右极限 → 归类 |
| 含参数的分段函数 | 由连续/可导条件列方程（连续：左右极限 = 函数值；可导：左右导数相等）求参数 |
| 证明方程有根 | 构造 `F(x)=f(x)−x` 或原函数，用零点定理；唯一性再用单调性 |

### 第 2 章 · 导数与微分

| 题型 | 标准动作 |
| --- | --- |
| 用定义求导 | 写差商 → 代入 → 化简（有理化、等价无穷小）→ 取极限；分段点必用定义 |
| 复合/隐函数/参数求导 | 画变量关系图；隐函数两边对 x 求导把 y 视为 x 的函数；参数方程二阶导先对 t |
| 幂指函数 `u(x)^{v(x)}` | 取对数或化为 `e^{v ln u}` |
| 高阶导数 / 求 `f⁽ⁿ⁾(0)` | 莱布尼茨公式、已知展开式系数、或递推 |
| 导数几何应用 | 切线 `y−f(x₀)=f′(x₀)(x−x₀)`，法线斜率 `−1/f′`；注意 `f′=0` 时法线竖直 |
| 含绝对值的可导性 | `g(x)|x−a|` 在 a 可导 ⇔ `g(a)=0` |

### 第 3 章 · 中值定理与导数应用

| 题型 | 标准动作 |
| --- | --- |
| 证 `∃ξ: F′(ξ)=0` | 构造 F → 验证罗尔三条件 → 结论（写清 ξ 在开区间） |
| 证含两个中值 `ξ,η` | 分别对两个函数用拉格朗日，或对同一函数在不同区间用中值定理 |
| 证不等式 | ① 移项构造 `F(x)` 证 `F′>0` 且 `F(a)≥0`；② 拉格朗日中值定理放缩；③ 泰勒展开 + 余项符号；④ 凹凸性（琴生不等式） |
| 讨论方程根的个数 | 求单调区间与极值 → 结合端点符号与零点定理分区间计数 |
| 求渐近线 | 无定义点查铅直；`±∞` 分别求水平；若无水平再求斜 |
| 最值应用题 | 设变量 → 建立目标函数 → 求导找唯一驻点 → 说明实际最值存在即得结论 |

### 第 4 章 · 不定积分

| 题型 | 标准动作 |
| --- | --- |
| 有理函数积分 | 多项式除法 → 分母因式分解 → 待定系数拆部分分式 → 逐项积分 |
| 三角有理式 | 先看能否用倍角/降幂/凑微分；否则万能代换 |
| 分部积分循环型 | 两次分部后出现原积分 ⇒ 移项解方程，`+C` 最后补 |

## 重要公式推导补遗

> 教材多以「给出公式」为主，这里补上几个最常被追问「为什么」的推导要点。

### 推 1 · 华里士公式的递推

设 `Iₙ = ∫₀^{π/2} sinⁿx dx`。分部取 `u=sin^{n−1}x, dv=sin x dx`：
`Iₙ = [−sin^{n−1}x cos x]₀^{π/2} + (n−1)∫₀^{π/2} sin^{n−2}x cos²x dx`
`= (n−1)∫ sin^{n−2}x(1−sin²x)dx = (n−1)(Iₙ₋₂ − Iₙ)`
⇒ `n Iₙ = (n−1)Iₙ₋₂` ⇒ **`Iₙ = (n−1)/n · Iₙ₋₂`**。
由 `I₀=π/2`、`I₁=1` 递推得偶/奇两套结果；令 `n=2` 得 `I₂=½·π/2 = π/4` ✓。

### 推 2 · 泊松积分与 Γ(1/2)

由综 3：`I² = ∬_{第一象限}e^{−(x²+y²)}dxdy = (π/2)∫₀^∞ e^{−r²}2r·(1/2)dr … = π/4` ⇒ `I=√π/2`。
换元 `t=x²`：`Γ(1/2)=∫₀^∞ t^{−1/2}e^{−t}dt = 2∫₀^∞ e^{−x²}dx = √π`；
由 `Γ(s+1)=sΓ(s)` 得 `Γ(n+1)=n!`、`Γ(3/2)=√π/2`，故 Γ 是阶乘的连续延拓。

### 推 3 · 牛顿–莱布尼茨 ⇒ 格林 ⇒ 高斯（同一思想）

```text
一维：∫ₐᵇ F′(x)dx = F(b) − F(a)          （区间内部导数的积分 = 边界上的值）
二维：∬_D (Qₓ − Pᵧ)dxdy = ∮_{∂D} Pdx+Qdy  （内部旋度 = 边界环流）
三维：∭_Ω div A dV = ∯_{∂Ω} A·n dS        （内部散度 = 边界通量）
三者都是「把内部相邻微元的贡献相互抵消，只剩边界」：
  分割区域后，相邻小区域的公共边界上方向相反、积分抵消。
```
**推论**：取 `P=−y/2, Q=x/2` ⇒ `Qₓ−Pᵧ=1` ⇒ `Area(D)=½∮(x dy−y dx)`（格林求面积公式）。

### 推 4 · 一阶线性方程的积分因子

`y′+P(x)y=Q(x)`。设存在 `μ(x)` 使 `(μy)′=μQ`，展开 `μy′+μ′y=μQ` 对比得 `μ′=μP` ⇒ `μ=e^{∫P dx}`。
于是 `(μy)′=μQ ⇒ μy=∫μQ dx + C`，即通解公式。这套「乘积分因子」也是综 2 中辅助函数构造的来源。

### 推 5 · 幂级数求和函数的通法

```text
求 S(x)=Σ_{n=1}^∞ n xⁿ：
  S(x)/x = Σ n x^{n−1} = (Σ xⁿ)′ = [1/(1−x) − 1]′ = 1/(1−x)²
  ⇒ S(x) = x/(1−x)²，|x|<1
求 S(x)=Σ xⁿ/n：
  S′(x)=Σ x^{n−1}=1/(1−x) ⇒ S(x)=−ln(1−x)+C；由 S(0)=0 ⇒ C=0
```
关键：**逐项求导把系数 `n` 消掉、逐项积分把分母 `n` 补上**，最后务必用 `S(0)` 定常数并单独检验端点。

### 推 6 · 傅里叶系数公式来自正交性

三角函数系 `{1, cos nx, sin nx}` 在 `[−π,π]` 上正交：
`∫_{−π}^{π} cos mx cos nx dx = πδₘₙ`（`m,n≥1`），`∫ sin mx sin nx dx = πδₘₙ`，`∫ sin mx cos nx dx = 0`，`∫_{−π}^{π}1 dx = 2π`。
两边同乘 `cos nx` 并在 `[−π,π]` 上逐项积分，除第 n 项外全为 0 ⇒ `aₙ=(1/π)∫ f cos nx dx`；常数为 `a₀/2` 正是为统一系数形式。

### 推 7 · 二元极值充分条件来自泰勒

在驻点 `(x₀,y₀)` 处 `fₓ=fᵧ=0`，二阶泰勒：
`Δf ≈ ½(A h² + 2B hk + C k²)`，这是关于 `(h,k)` 的二次型。
其正定 ⇔ `A>0` 且 `AC−B²>0` ⇒ `Δf>0` 恒成立 ⇒ 极小；负定 ⇔ `A<0` 且 `Δ>0` ⇒ 极大；`Δ<0` 时二次型不定 ⇒ 沿不同方向符号相反 ⇒ 鞍点。`Δ=0` 时二次项不足以判定，需更高阶。

### 推 8 · 欧拉公式 `e^{ix} = cos x + i sin x`

把 `e^z = Σ zⁿ/n!` 中令 `z=ix`，按偶次/奇次分组：
`e^{ix} = [1 − x²/2! + x⁴/4! − …] + i[x − x³/3! + x⁵/5! − …] = cos x + i sin x`。
取 `x=π` 得 `e^{iπ}+1=0`；由此复数可写 `z=re^{iθ}`，是常系数方程复根解 `e^{αx}(C₁cosβx+C₂sinβx)` 的来源。

## 综合例题精讲（跨章）

### 综 1 · 极限 → 导数 → 泰勒（第 1–3 章）

题：设 `f(x)` 在 `x=0` 二阶可导，`lim_{x→0} [f(x)/x + sin x/x²] = 1`，求 `f(0)`、`f′(0)`、`f″(0)`。

```text
① 通分：lim [x f(x) + sin x]/x² = 1（有限） ⇒ 分子必须为 O(x²)
② 若 f(0)≠0，则 x f(x) ~ f(0)x 而 sin x ~ x ⇒ 分子 ~ (f(0)+1)x
   要使其为 O(x²) 必须 f(0) = −1
③ 泰勒：f(x) = −1 + f′(0)x + ½f″(0)x² + o(x²)，sin x = x − x³/6 + o(x³)
   分子 = x[−1+f′(0)x+½f″(0)x²] + x + o(x²)
        = (f′(0)+½f″(0)x+…)x² + o(x²)  ⇒ 需 f′(0)=0
④ 极限 = ½f″(0) = 1 ⇒ f″(0) = 2
结论：f(0)=−1，f′(0)=0，f″(0)=2
```
**方法要点**：分式极限存在且分母为 `xᵐ` ⇒ 分子必须展开到 `xᵐ` 且低阶系数全为 0。这是「泰勒 + 待定系数」的标准套路。

### 综 2 · 积分上限函数与微分方程（第 2、5、7 章）

题：设 `f(x)` 连续且 `f(x) = eˣ + ∫₀ˣ (x−t)f(t)dt`，求 `f(x)`。

```text
① 拆开：f(x) = eˣ + x∫₀ˣ f(t)dt − ∫₀ˣ t f(t)dt
② 求导：f′(x) = eˣ + ∫₀ˣ f(t)dt + x f(x) − x f(x) = eˣ + ∫₀ˣ f(t)dt
③ 再求导：f″(x) = eˣ + f(x) ⇒ f″ − f = eˣ
④ 特征方程 r²−1=0 ⇒ 齐次解 C₁eˣ+C₂e^{−x}
   λ=1 是单特征根 ⇒ 设特解 y*=A x eˣ，代入 (−A·? ) 计算：
   y*′=A(1+x)eˣ, y*″=A(2+x)eˣ ⇒ y*″−y* = 2A eˣ = eˣ ⇒ A=1/2
⑤ f(x) = C₁eˣ + C₂e^{−x} + ½ x eˣ
⑥ 由原式 f(0)=e⁰=1；由 ② f′(0)=e⁰+0=1
   f(0)=C₁+C₂=1；f′=C₁eˣ−C₂e^{−x}+½(1+x)eˣ ⇒ f′(0)=C₁−C₂+½=1
   ⇒ C₁=3/4, C₂=1/4
结论：f(x) = ¾eˣ + ¼e^{−x} + ½x eˣ
```
**方法要点**：变限积分方程 → 求导化为微分方程 → 从原方程提取初始条件（这一步最易漏）。

### 综 3 · 二重积分 → 反常积分（第 5、10 章）

题：用二重积分计算泊松积分 `I = ∫₀^∞ e^{−x²}dx`。

```text
① I² = (∫₀^∞ e^{−x²}dx)(∫₀^∞ e^{−y²}dy) = ∬_{第一象限} e^{−(x²+y²)}dxdy
② 化极坐标：x=r cosθ, y=r sinθ, dxdy = r dr dθ，θ∈[0,π/2], r∈[0,∞)
③ I² = ∫₀^{π/2}dθ ∫₀^∞ e^{−r²} r dr = (π/2) · [−½e^{−r²}]₀^∞ = (π/2)(1/2) = π/4
④ I = √π/2 ≈ 0.886227（取正根）
```
**推广**：`∫_{−∞}^∞ e^{−x²}dx = √π`（高斯积分，概率论正态分布归一化常数的来源）；`Γ(1/2)=√π` 由此得。

### 综 4 · 曲线积分 → 级数（第 11、12 章）

题：由 `x = 2Σ(−1)ⁿ⁺¹ sin(nx)/n`（`x ∈ (−π, π)`）导出 `Σ1/(2k−1)² = π²/8`，并说明为何取 `x=π/2` 得 `π/4`。

```text
① 傅里叶级数逐项积分（在收敛区间内合法）：
   ∫₀ˣ t dt = 2Σ(−1)^{n+1}/n ∫₀ˣ sin nt dt
   x²/2 = 2Σ(−1)^{n+1}(1−cos nx)/n²
② 取 x=π：π²/2 = 2Σ(−1)^{n+1}(1−(−1)ⁿ)/n² = 4Σ_{k≥1} 1/(2k−1)²
   ⇒ Σ_{k≥1}1/(2k−1)² = π²/8 ✓
③ 原展开式取 x=π/2：π/2 = 2(1 − 1/3 + 1/5 − …) ⇒ 交错奇倒数和 = π/4
④ 帕塞瓦尔：由 |x| 的余弦级数也可得 Σ1/n² = π²/6
```
**方法要点**：傅里叶级数既能「求和函数」也能「求数项和」；逐项积分后收敛性变好（系数多除一个 n）。

### 综 5 · 多元极值 ↔ 条件极值 ↔ 经济学（第 3、9 章）

题：在 `x²+y²+z²=1` 下求 `f=xyz` 的最大值，并说明与微观经济学条件极值的关系。

```text
① L = xyz + λ(x²+y²+z²−1)
② ∂L/∂x = yz+2λx = 0；同理 xz+2λy=0、xy+2λz=0
③ 若 xyz≠0，三式乘 x,y,z 后相等 ⇒ 2λx²=2λy²=2λz² ⇒ x²=y²=z²=1/3
④ f_max = (1/√3)³ = 1/(3√3) ≈ 0.19245（取全正或两负一正）
⑤ 若 xyz=0 则 f=0，非最大
⑥ 经济学对应：效用 U(X,Y) 在预算约束 PxX+PyY=I 下最大化，
   拉格朗日条件即 MRS = Px/Py；λ 的边际解释为「收入的边际效用」
```
**方法要点**：条件极值求出的只是候选点，还要比较边界/退化情形（本题 `xyz=0`）。

### 综 6 · 三大公式的选择（第 10、11 章）

题：计算 `∯_Σ x³ dydz + y³ dzdx + z³ dxdy`，`Σ` 为球面 `x²+y²+z²=R²` 外侧。

```text
① 高斯公式：div A = 3x²+3y²+3z² = 3r²
② 原式 = ∭_Ω 3(x²+y²+z²)dV，用球坐标：
   = 3∫₀^{2π}dθ ∫₀^π sinφ dφ ∫₀^R ρ²·ρ² dρ
   = 3 · 2π · 2 · R⁵/5 = 12πR⁵/5
③ 校验 R=1、取 A=(x,y,z) 时原式 = 3V = 4π（与前面例题一致）✓
```
**选择规则**：闭曲面且偏导连续 ⇒ 高斯；闭曲线平面 ⇒ 格林；空间闭曲线 ⇒ 斯托克斯；非闭 ⇒ 先补面/补线；有奇点 ⇒ 挖洞。

### 综 7 · 幂级数解微分方程（第 7、12 章）

题：用幂级数求 `y′=y, y(0)=1` 的解。

```text
① 设 y = Σ_{n=0}^∞ aₙ xⁿ ⇒ y′ = Σ_{n=1}^∞ n aₙ x^{n−1}
② 代入：Σ_{n=1}^∞ n aₙ x^{n−1} = Σ_{n=0}^∞ aₙ xⁿ
   比较 xᵏ 系数：(k+1)a_{k+1} = a_k ⇒ a_{k+1} = a_k/(k+1)
③ 由 a₀ = y(0)=1 ⇒ aₙ = 1/n!
④ y = Σ xⁿ/n! = eˣ，收敛半径 R = ∞（比值 |aₙ/aₙ₊₁| = n+1 → ∞）
```
**意义**：把微分方程化为系数的递推关系；教材第十二章「微分方程的幂级数解法」即此，也是非初等函数（贝塞尔、勒让德）的定义方式。

### 综 8 · 答题模板：证明题四步法

面对「证明存在 ξ 使……」的中值定理证明题：
① **改写**：把待证式整理成 `F′(ξ)=0` 或 `F′(ξ)=k`，明确中值定理类型；
② **构造函数**：反推 `F`（含积分因子 `e^{g(x)}`、或 `f(x)−kx`、或两端点差的形式）；
③ **验证条件**：写出 `F` 在闭区间连续、开区间可导、端点值相等（罗尔）或直接引用拉格朗日/柯西；
④ **得出结论**：注明 `ξ∈(a,b)` 且属于**开区间**，并检查是否要用到零点定理/介值定理先定位中间点。
凡含 `f″`、`f‴` 的题目，考虑「对 `f′` 用中值定理」或「两次罗尔」；含积分的题目考虑积分中值定理或变限函数。

## 附录 B 易错点速查

1. 函数相同要求定义域与对应规则都相同，仅表达式化简相同不够（`x` 与 `x²/x`）。
2. 奇偶性判定的第一步是检查定义域是否关于原点对称。
3. `√(x²)=|x|`，`arcsin(sin x)` 只在主值区间等于 `x`。
4. 极限定义是「去心」邻域，`f(x₀)` 无定义或不等于极限都不影响极限存在。
5. `lim f = A > 0 ⇒` 附近 `f>0`；但 `f>0` 只能推出 `lim f ≥ 0`（严格不等号会丢失）。
6. 极限四则运算要求各极限存在且分母极限非零；`∞−∞`、`0·∞` 不能拆。
7. 无穷小是**变量**不是「很小的数」；0 是唯一为常数的无穷小。
8. 等价无穷小只能在**乘除因子**中替换；加减项替换前须确认主阶不抵消。
9. `tan x − sin x ~ x³/2`，不是 `0`；`x−sin x ~ x³/6`。
10. 洛必达只适用于 `0/0`、`∞/∞`，且 `lim f′/g′` 必须存在；`(x+sin x)/x` 是失效反例。
11. `1^∞` 未定式须取对数或用 `e^{lim g(f−1)}`，不能把底数与指数分别取极限。
12. 佩亚诺余项用于局部求极限，拉格朗日余项用于整体误差估计，二者不可混用。
13. 有任意阶导数 ≠ 泰勒级数收敛到原函数（`e^{−1/x²}` 是反例）。
14. 可去间断与跳跃间断同属第一类；无穷与振荡属第二类。
15. 介值定理与零点定理要求**闭区间上连续**，开区间结论可能失效。
16. 可导 ⇒ 连续、连续 ⇒ 极限存在；反向均不成立（`|x|` 是最简反例）。
17. 一元「可导 ⇔ 可微」，多元「可微 ⇒ 偏导存在」且反之不成立。
18. 导函数可以不连续，但由达布定理导函数没有第一类间断点。
19. 分段点求导必须用定义算左右导数，不能直接代两侧导函数。
20. 参数方程二阶导数要「先对 t 求导再除以 ẋ」，不是 `ÿ/ẍ`。
21. `∫1/x dx = ln|x|+C`，绝对值不可省；不定积分不要漏 `+C`。
22. 罗尔定理三条件（闭连续、开可导、端点值相等）缺一不可（`|x|` 在 `[−1,1]`）。
23. 拉格朗日中值定理的 `ξ` 属于**开区间** `(a,b)`。
24. 柯西中值定理是洛必达的证明基础，不要把二者当成同一件事。
25. `f′(x₀)=0` 只是极值的必要条件（可导时），驻点可能是鞍点。
26. 极值是局部概念、最值是全局概念；闭区间最值必须比较端点。
27. 拐点是曲线上的**点**（写坐标），`f″=0` 既非充分也非必要。
28. 水平/斜渐近线在 `x→+∞` 与 `x→−∞` 要分别求，结果可不同。
29. 同一方向水平与斜渐近线至多各一条；有水平线时不必再求斜线。
30. 第一换元不换变量、第二换元必须**回代**；三角代换别把 `t` 留在答案里。
31. 分部积分取 `u` 按「反、对、幂、指、三」；循环型需两次分部后解方程。
32. `e^{−x²}`、`sin x/x`、`1/ln x` 没有初等原函数，不要硬凑。
33. 有第一类间断点的函数没有原函数，但可能有定积分（可积 ≠ 有原函数）。
34. 积分上限函数 `Φ` 在 `f` 可积时连续，仅在 `f` 连续时可导。
35. 变限求导通式中下限项要带负号并乘 `α′(x)`。
36. 被积函数含积分上限变量 `x` 时，须先换元把 `x` 提到积分号外。
37. 对称区间上奇函数积分为 0、偶函数为两倍——前提是区间关于原点对称。
38. `∫₀^{π/2}sin²x dx = π/4`，不是 `π/2`；华里士公式奇偶情形系数不同。
39. `∫₁^∞x^{−p}dx` 收敛 `p>1`，`∫₀¹x^{−p}dx` 收敛 `p<1`，方向相反最易记反。
40. 瑕点在积分区间**内部**必须拆成两段，一段发散即整体发散。
41. 反常积分不能用「柯西主值」冒充收敛。
42. 面积公式要加绝对值（或先求交点分段），否则上下曲线交叉会抵消。
43. 弧长是 `∫√(1+y′²)dx`，不是 `∫(1+y′)dx`。
44. 绕 y 轴的柱壳法与圆盘法积分变量不同，上下限不可混用。
45. 微元法要求 `ΔU−dU=o(dx)`，即「以直代曲」的误差是高阶无穷小。
46. 「齐次方程 `y′=φ(y/x)`」与「线性齐次方程 `Q=0`」同名不同义。
47. 可分离变量时除以 `g(y)` 会丢失 `g(y)=0` 的常数解。
48. 一阶线性通解中积分因子是 `e^{∫P dx}`，符号写反会导致全题错误。
49. 特征根为重根时齐次解必须多乘 `x`；复根时别漏 `e^{αx}`。
50. 待定系数法的 `xᵏ` 因子：`λ` 是特征根的重数即 `k`，漏乘是最高频失分点。
51. 非齐次通解 = 齐次通解 + 一个特解；特解中不含任意常数。
52. 欧拉方程令 `x=eᵗ`；`x<0` 时用 `|x|=eᵗ`，别忽略定义域。
53. 初值问题要把全部常数用初始条件定出，常数个数等于方程阶数。
54. `a×b` 反交换、`a·b` 交换；混合积是对换行列式变号。
55. 直线一般式的方向向量是两平面法向量的**叉积**，不是其中之一。
56. 线面夹角用 `sinθ=|s·n|/(|s||n|)`，面面夹角用 `cos`。
57. 点到平面距离公式分母是法向量的模 `√(A²+B²+C²)`，不要漏根号。
58. 曲面方程缺一个变量才是柱面；含 `x²+y²` 且含 `z²` 的一般不是柱面。
59. 旋转曲面代换规则：绕 z 轴把 `y` 换成 `±√(x²+y²)`，别换错变量。
60. 二次曲面单叶/双叶由负号个数与右端符号共同决定。
61. 二重极限要求沿**任意路径**相同；有限条路径相同不能判存在。
62. 累次极限存在且不等 ⇒ 二重极限不存在；逆命题不成立。
63. 多元偏导数存在 ⇏ 连续、⇏ 可微；**偏导连续 ⇒ 可微**才是充分条件。
64. 方向导数定义式不要求可微；只有可微时才能用 `∇f·e_l`。
65. 梯度方向是增长最快方向，`−∇f` 是下降最快方向。
66. 二阶混合偏导相等需要**连续**条件（克莱罗定理），不保证时可能不等。
67. 隐函数求导要求 `F_z≠0`；方程组情形要求雅可比行列式 `J≠0`。
68. 曲面法向量是 `∇F`；切平面公式里的系数取**该点处**的偏导值。
69. `Δ=AC−B²>0` 时还要看 `A` 的符号；`Δ<0` 是鞍点；`Δ=0` 判别失效。
70. 极值点也可能偏导不存在（如 `z=√(x²+y²)` 在原点）。
71. 拉格朗日乘数 `λ` 不是所求；求出的是候选点，还要比较或结合实际判断。
72. 闭区域最值必须同时检查内部驻点与**整个边界**。
73. 二重积分换序后若区域不是 X/Y 简单型，必须分块。
74. 极坐标面积元是 `r dr dθ`，漏 `r` 是最高频错误。
75. 球坐标体积元 `ρ²sinφ dρ dφ dθ`，`φ` 是与 z 轴正向夹角（0 到 π）。
76. 三重积分「先二后一」与「先一后二」的截面/投影选择要看区域形状。
77. `∬_D e^{−y²}dxdy` 型积分必须换序（先对 x），否则原函数非初等。
78. 第一类线积分与方向无关（上下限须小到大）；第二类与方向有关（反向变号）。
79. 第一类面积分无侧向；第二类面积分必须先定侧再投影。
80. 格林公式要求闭曲线**正向**（逆时针）且区域内偏导连续。
81. 高斯公式要求闭曲面取**外侧**；取内侧整体变号。
82. 区域内有奇点必须挖洞，`(x dy−y dx)/(x²+y²)` 是经典反例（结果 2π 不是 0）。
83. 非闭曲线/曲面用公式前要补线/补面，并减去补上部分的贡献。
84. 路径无关四等价只在**单连通域**内成立，含洞区域须另外检验。
85. `div A=0` 称无源场、`rot A=0` 称无旋场；`∇·(∇×A)=0`、`∇×(∇f)=0`。
86. 级数收敛的必要条件是通项趋于 0；调和级数说明它不充分。
87. `p` 级数 `p>1` 收敛、几何级数 `|q|<1` 收敛，是两个最常用比较基准。
88. 比值/根值法 `ρ=1` 时失效（`Σ1/n` 与 `Σ1/n²` 都是 `ρ=1`）。
89. 根值判别强于比值判别；阶乘型用比值、`n` 次幂型用根值。
90. 交错级数莱布尼茨判收敛，但**绝对收敛性要另判**。
91. 绝对收敛可任意重排；条件收敛重排可改变和（黎曼定理）。
92. 幂级数收敛半径给出开区间，**端点必须单独判断**才得收敛域。
93. 逐项求导/积分后半径不变，但端点敛散可能改变。
94. 求和函数时别忘了由 `S(0)` 或极限确定积分常数。
95. 傅里叶级数在间断点收敛到左右极限的**平均值**，不是 `f(x)`。
96. 奇函数展开为正弦级数、偶函数为余弦级数；`[0,π]` 上需先作奇/偶延拓。
97. 周期 `2l` 时把 `nx` 换成 `nπx/l`，系数中 `1/π` 换成 `1/l`。
98. 一致收敛才保证和函数连续、可逐项积分与求导；逐点收敛不保证。
99. 所有计算题都应做一次交叉验算：积分结果求导、微分方程解代入原方程、级数和代入特值。
100. 中值定理证明题的 `ξ` 必须落在**开区间**；用零点定理时先验证端点异号。
101. 遇到「不存在 / 不成立」类命题，先想反例库（`|x|`、`x² sin(1/x)`、`sin(1/x)`、调和级数、鞍点）。
102. 单位与量纲要一致：物理应用题的面积、体积、功、压力不能混用变量。
103. 分段函数、含绝对值函数、含参数函数，一律先分情况讨论再计算。
104. 任何「等价」「充分必要」的表述都要检查逆命题；教材中大量定理只是充分条件。
