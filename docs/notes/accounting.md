## 第 1 章 总论

### 1.1 财务报告目标、基本假设与会计基础

| 项目 | 要点 |
| --- | --- |
| 财务报告目标 | 向使用者提供**决策有用**的信息，并反映管理层**受托责任**履行情况；我国两项并重 |
| 会计主体 | 界定**空间范围**；**法律主体必然是会计主体，会计主体不一定是法律主体**（如分公司、基金、合并集团） |
| 持续经营 | 可预见的将来按当前规模状态持续经营；是会计分期与历史成本计量的前提 |
| 会计分期 | 将持续经营划分为连续、间隔相同的期间；产生权责发生制与折旧摊销 |
| 货币计量 | 以货币计量，隐含币值稳定假设 |
| 会计基础 | **企业会计：权责发生制**；行政事业单位**预算会计：收付实现制**、**财务会计：权责发生制** |

### 1.2 会计信息质量要求（8 项）

| 要求 | 含义 | 易错点 |
| --- | --- | --- |
| 可靠性 | 以实际发生的交易为依据，如实反映、完整、无偏 | 不能以「谨慎」为由虚构费用或准备 |
| 相关性 | 与使用者经济决策相关，具预测价值、反馈价值 | 与重要性、及时性共同影响有用性 |
| 可理解性 | 清晰明了、便于理解使用 | 假定使用者具备一定会计与商业知识 |
| 可比性 | 同一企业**不同时期**纵向可比；不同企业**同一期间**横向可比 | 会计政策变更追溯调整，正是为了满足纵向可比 |
| 实质重于形式 | 按**经济实质**而非仅按法律形式核算 | 融资租赁、售后回购、附追索权票据贴现、结构化主体 |
| 重要性 | 重要事项单独、充分反映；次要事项可简化 | 取决于项目性质与金额大小，需职业判断 |
| 谨慎性 | **不高估资产或收益、不低估负债或费用** | **不得计提秘密准备**（谨慎性 ≠ 任意低估） |
| 及时性 | 及时确认、计量、报告，不提前也不延后 | 与可靠性需权衡 |

### 1.3 会计要素与计量属性

| 类别 | 要素 | 确认条件 |
| --- | --- | --- |
| 反映财务状况 | 资产、负债、所有者权益 | 符合定义 + 经济利益很可能流入/流出 + 金额能可靠计量 |
| 反映经营成果 | 收入、费用、利润 | 收入/费用按权责发生制确认；利润含收入减费用净额 + 直接计入当期损益的利得损失 |

| 计量属性 | 含义 | 典型应用 |
| --- | --- | --- |
| 历史成本 | 取得时实际支付的对价 | **一般默认**，最可靠 |
| 重置成本 | 当前市场条件下重新取得同样资产所需金额 | 盘盈固定资产 |
| 可变现净值 | 估计售价 − 至完工成本 − 销售费用 − 相关税费 | 存货期末计量 |
| 现值 | 未来现金流量按恰当折现率折现 | 资产减值、租赁负债、弃置费用 |
| 公允价值 | 市场参与者在计量日**有序交易**中出售资产收到/转移负债支付的价格（**脱手价格**） | 交易性金融资产、投资性房地产、FVOCI |

> **核心公式**：`资产 = 负债 + 所有者权益`；`利润 = 收入 − 费用 + 直接计入当期利润的利得 − 损失`

## 第 2 章 存货

### 2.1 初始计量

| 取得方式 | 成本构成 |
| --- | --- |
| 外购 | 购买价款 + 相关税费（关税、不能抵扣的税费）+ 运输费、装卸费、保险费、包装费、仓储费（**入库前**）、运输途中的合理损耗、挑选整理费 |
| 加工取得 | 采购成本 + 加工成本（直接人工、制造费用）+ 使存货达到当前场所状态发生的其他支出 |
| 投资者投入 | 按**投资合同或协议约定的价值**（不公允的除外） |
| 非货币性交换/债务重组等 | 见第 20、21 章 |

::: danger 易错 · 不计入存货成本的费用
① **非正常消耗**的直接材料、人工、制造费用 → 当期损益；② **入库后**的仓储费用 → 管理费用（生产过程必需的仓储除外）；③ 不能归属于使存货达到当前场所状态的其他支出；④ 商业企业采购过程中的**进货费用**金额较小的可直接计入销售费用。
:::

### 2.2 发出存货的计量

| 方法 | 要点 |
| --- | --- |
| 先进先出法 | 期末存货成本接近**现行市价**；物价上涨时会高估当期利润 |
| 移动加权平均法 | 每次收货后重算单位成本，实时性强但工作量大 |
| 月末一次加权平均法 | 月末一次计算，简便；**平时无法掌握发出与结存金额** |
| 个别计价法 | 适用于**不能替代使用、为特定项目专门购入或制造**的存货 |

> 存货发出的计价方法一经确定**不得随意变更**；属于会计政策变更的需追溯调整。结转成本时同步结转已计提的存货跌价准备。

### 2.3 期末计量与跌价准备

> **核心公式**：`可变现净值 = 估计售价 − 至完工时估计将要发生的成本 − 估计的销售费用 − 相关税费`

| 情形 | 可变现净值确定 |
| --- | --- |
| 直接出售的产成品/商品 | 估计售价 − 销售费用 − 相关税费 |
| 需加工的材料 | 所生产产成品的估计售价 − 至完工成本 − 销售费用 − 相关税费 |
| 为执行**销售合同**持有的存货 | 以**合同价**为售价基础；超过合同数量的部分用一般销售价格 |
| 材料减值判断 | **先看产成品是否减值**：产成品未减值 → 材料按成本计量；产成品减值 → 材料按可变现净值计量 |

| 处理 | 分录 / 规则 |
| --- | --- |
| 计提 | 借：资产减值损失　贷：存货跌价准备（**按单个存货项目**计提，可按类别合并的除外） |
| 转回 | 原减值影响因素消失时，**在原已计提金额内转回**：借：存货跌价准备　贷：资产减值损失 |
| 结转 | 发出存货时按比例结转跌价准备，冲减主营业务成本/生产成本 |

### 2.4 清查盘点

| 情形 | 处理 |
| --- | --- |
| 盘盈 | 按**重置成本**入账，冲减**管理费用**（借：存货　贷：待处理财产损溢 → 管理费用） |
| 盘亏/毁损 | 扣除残料价值、保险与过失人赔偿后：一般经营损失计入**管理费用**；**非常损失**计入**营业外支出**；对应的进项税额按规定转出 |

## 第 3 章 固定资产

### 3.1 确认与初始计量

| 项目 | 要点 |
| --- | --- |
| 定义 | 为生产商品、提供劳务、出租或经营管理而持有，**使用寿命超过一个会计年度**的有形资产 |
| 确认条件 | 经济利益很可能流入 + 成本能可靠计量 |
| 外购成本 | 购买价款、相关税费、使资产达到**预定可使用状态前**发生的运输费、装卸费、安装费、专业人员服务费等 |
| 一笔款项购入多项 | 按各项**公允价值比例**分配总成本 |
| 自行建造 | 工程物资 + 人工 + 应予资本化的借款费用 + 使达到预定可使用状态的必要支出；**试运行销售**按收入准则处理，不冲减成本 |
| 弃置费用 | 特殊行业（核电、石油等）按**现值**计入固定资产成本并确认**预计负债**，后续按实际利率法计入财务费用 |
| 分期付款购买 | 超过正常信用条件的，按**购买价款现值**入账，差额按实际利率法在信用期内摊销资本化/费用化 |

### 3.2 折旧

> **核心公式**：`应计折旧额 = 固定资产原价 − 预计净残值 − 已计提的固定资产减值准备`

| 项目 | 规则 |
| --- | --- |
| 空间范围 | **除已提足折旧仍继续使用的固定资产、单独计价入账的土地外，对所有固定资产计提折旧** |
| 时间范围 | **当月增加，当月不提、下月起提；当月减少，当月仍提、下月起停**；达到预定可使用状态即开始（未办竣工决算按暂估价计提，决算后调整原值但不追溯已提折旧） |
| 年限平均法 | 年折旧率 =（1 − 预计净残值率）÷ 预计使用寿命 |
| 工作量法 | 单位工作量折旧额 = 应计折旧额 ÷ 预计总工作量 |
| 双倍余额递减法 | 年折旧率 = 2 ÷ 预计使用寿命；**前期不扣残值**，最后两年改为直线法并扣除残值 |
| 年数总和法 | 年折旧率 = 尚可使用年限 ÷ 预计使用寿命的年数总和 |
| 复核 | 每年末复核使用寿命、预计净残值与折旧方法，变化按**会计估计变更**（未来适用法）处理 |


### 3.3 处置

| 情形 | 处理 |
| --- | --- |
| 出售、转让 | 通过「固定资产清理」归集，净损益计入**资产处置损益** |
| 报废、毁损 | 净损失计入**营业外支出**，净收益计入**营业外收入** |
| 盘亏 | 计入**营业外支出** |
| 持有待售 | 转入持有待售类别，按第 15 章计量，**停止计提折旧** |

## 第 4 章 无形资产

| 项目 | 要点 |
| --- | --- |
| 定义 | 企业拥有或控制的**没有实物形态的可辨认非货币性资产**；商誉因不可辨认**不属于**无形资产 |
| 内容 | 专利权、非专利技术、商标权、著作权、土地使用权、特许权等 |
| 外购成本 | 购买价款、相关税费及直接归属于使资产达到**预定用途**的支出 |
| 土地使用权 | 一般确认为无形资产；**用于建造对外出售的商品房**时计入存货成本；**用于出租或增值目的**时转为投资性房地产；外购房屋建筑物价款无法合理分配的，**全部作为固定资产** |
| 初始计量特殊 | 投资者投入按合同约定价值（不公允除外）；政府补助取得按公允价值或名义金额 |

### 4.2 内部研究开发支出

| 阶段 | 处理 |
| --- | --- |
| 研究阶段 | **全部费用化**（研究支出）→ 期末转入管理费用 |
| 开发阶段 | 满足 **5 个条件**才可资本化：①技术可行性；②具有完成并出售/使用的意图；③能证明产生经济利益的方式；④有足够技术、财务等资源支持完成；⑤支出能可靠计量 |
| 无法区分 | **全部费用化**，不得以后再转为资本化 |

> 分录：发生支出时借记「研发支出——费用化支出 / 资本化支出」；期末费用化部分转「管理费用」，资本化部分在达到预定用途时转「无形资产」。

### 4.3 后续计量与处置

| 使用寿命 | 摊销 | 减值测试 |
| --- | --- | --- |
| 有限 | 按**直线法**（一般）或产量法摊销，残值通常视为零；当月增加当月开始摊销、当月减少当月停止 | 出现减值迹象时测试 |
| **不确定** | **不摊销** | **每年末无论有无迹象均须减值测试** |

## 第 5 章 投资性房地产

### 5.1 范围与初始计量

| 属于 | 不属于 |
| --- | --- |
| 已出租的土地使用权、持有并准备增值后转让的土地使用权、**已出租的建筑物** | 自用房地产、作为存货的房地产、准备出租但尚未出租的土地使用权（部分例外）、以经营租赁方式租入再转租的建筑物（承租人不确认） |

> 部分自用、部分出租的房地产，能单独计量出售的，出租部分确认为投资性房地产；**不能单独计量的，全部作为自用/存货**。

### 5.2 后续计量与模式变更

| 项目 | 成本模式 | 公允价值模式 |
| --- | --- | --- |
| 后续计量 | 按期计提折旧/摊销，减值适用资产减值准则 | **不计提折旧摊销**，资产负债表日按公允价值调整，差额计入**公允价值变动损益** |
| 适用前提 | 一般情形 | 有确凿证据表明公允价值能**持续可靠取得**（通常需活跃市场同类房地产） |
| 模式变更 | **成本模式 → 公允价值模式允许**（作为会计政策变更，追溯调整） | **公允价值模式 → 成本模式禁止** |

### 5.3 转换与处置

| 转换方向 | 差额处理 |
| --- | --- |
| 成本模式下互转 | 按**账面价值**结转，**不产生差额**；对应科目对转（累计折旧/摊销一并结转） |
| 自用/存货 → 公允价值模式投资性房地产 | 公允价值 **< 账面价值**的差额计入**公允价值变动损益**；公允价值 **> 账面价值**的差额计入**其他综合收益**（处置时转其他业务成本） |
| 公允价值模式投资性房地产 → 自用/存货 | 以转换日公允价值作为新账面价值，差额计入**公允价值变动损益** |

> 处置时：其他业务收入 ← 实际收到价款；其他业务成本 ← 账面价值；同时将**公允价值变动损益、其他综合收益**转入其他业务成本（不影响营业利润总额，只重分类）。

::: danger 易错
成本模式转公允价值模式是**会计政策变更需追溯调整**，而「自用转投资性房地产」是**资产用途改变**，不是会计政策变更，两者不要混淆。
:::

## 第 6 章 长期股权投资与合营安排

### 6.1 范围与初始计量

| 类型 | 影响程度 | 后续计量 |
| --- | --- | --- |
| 对子公司投资 | **控制** | 成本法（个别报表），合并时调整为权益法 |
| 对合营企业投资 | **共同控制** | 权益法 |
| 对联营企业投资 | **重大影响**（通常持股 20%–50%） | 权益法 |
| 其他股权投资 | 无控制、共同控制或重大影响 | 按金融工具准则（第 13 章） |

| 取得方式 | 初始投资成本 |
| --- | --- |
| 支付现金（联营/合营） | 实际支付价款 + 直接相关费用、税金等必要支出；**不含**已宣告未发放的现金股利（单独作应收股利） |
| 发行权益性证券 | 所发行证券的**公允价值**；发行费用**冲减资本公积——股本溢价**，不计入投资成本 |
| 同一控制下控股合并（子公司） | 被合并方在**最终控制方合并报表中所有者权益的账面价值份额**（含最终控制方收购时形成的商誉）；差额调整**资本公积（资本溢价），不足冲减留存收益** |
| 非同一控制下控股合并（子公司） | **付出对价的公允价值**；中介费用计入**管理费用**，不计入投资成本；差额在个别报表不确认商誉（体现在合并报表） |

::: danger 易错 · 三种费用的归属
① 联营/合营投资的**直接相关费用** → 计入投资成本；② 企业合并的**中介费用**（审计、法律、评估等）→ **管理费用**；③ 发行权益性证券的**发行费用** → **冲减资本公积——股本溢价**。三者极易混淆。
:::

### 6.2 后续计量

| 方法 | 要点 |
| --- | --- |
| 成本法 | 除追加/收回投资外，账面价值一般不变；被投资单位宣告分派现金股利时确认**投资收益**（不再区分清算性股利） |
| 权益法 | 随被投资单位所有者权益变动调整账面价值，设置「投资成本 / 损益调整 / 其他综合收益 / 其他权益变动」四个明细 |

**权益法调整顺序**：
1. 比较初始投资成本与取得日**可辨认净资产公允价值份额**：成本 > 份额，差额为**内含商誉，不调整**；成本 < 份额，差额计入**营业外收入**并调增长投。
2. 按持股比例确认**净损益**（需按取得日公允价值调整被投资方净利润、抵销**未实现内部交易损益**）。
3. 按持股比例确认**其他综合收益**变动、`其他权益变动`（资本公积）。
4. 宣告现金股利 → 冲减「损益调整」；被投资方发生**超额亏损**时，依次冲减长投账面价值、长期应收款、确认预计负债（有义务时），**亏到零为限**，以后盈利反向恢复。

### 6.3 核算方法转换（高频主观题）

| 转换 | 个别报表处理要点 |
| --- | --- |
| 公允价值 → 权益法（追加投资） | 原股权按**转换日公允价值**重新计量，差额计入当期损益；再加上新增对价作为新初始成本，重新比较份额 |
| 权益法 → 成本法（非同控追加） | 按**原权益法账面价值 + 新增对价公允价值**作为初始成本，**不追溯调整** |
| 成本法 → 权益法（处置部分，丧失控制但仍重大影响） | 对剩余股权**追溯调整为权益法**（视同自取得时即采用权益法），调整留存收益与其他综合收益 |
| 成本法 → 公允价值（丧失控制且无重大影响） | 剩余股权按**丧失控制日公允价值**重新计量，差额计入**投资收益** |
| 权益法 → 公允价值（丧失重大影响） | 剩余股权按公允价值重新计量，原权益法下**其他综合收益、其他权益变动**按处置比例结转（其他综合收益按被投资方性质转损益或留存收益） |


### 6.4 合营安排

| 类型 | 判断 | 会计处理 |
| --- | --- | --- |
| **共同经营** | 共同控制该安排的**参与方享有与安排相关的资产权利、并承担负债义务**（通常无独立主体） | 确认自身享有的资产、负债、收入、费用份额 |
| **合营企业** | 仅对安排的**净资产**享有权利（通常通过单独主体） | **权益法**核算 |

> 判断顺序：先看是否有单独主体 → 再看法律形式、合同安排是否使参与方对资产/负债直接享有权利与义务 → 存在**任何一项**使其对净资产享有权利时，即为合营企业。

## 第 7 章 资产减值

### 7.1 范围与测试时点

| 适用（长期资产） | 不适用（有其他准则） |
| --- | --- |
| 对子公司/联营/合营的长期股权投资、成本模式计量的投资性房地产、固定资产、无形资产、商誉、生产性生物资产、油气资产等 | **存货**（跌价准备可转回）、**金融资产**（预期信用损失）、递延所得税资产、建造合同资产、公允价值模式投资性房地产等 |

> 出现减值迹象时测试；**商誉、使用寿命不确定的无形资产、尚未达到可使用状态的无形资产，每年末无论有无迹象均须测试**。

### 7.2 可收回金额

> **核心公式**：`可收回金额 = MAX(公允价值 − 处置费用, 预计未来现金流量现值)`；`减值损失 = 账面价值 − 可收回金额`

| 组成 | 要点 |
| --- | --- |
| 公允价值减处置费用净额 | 有序交易中的脱手价格减去可直接归属于处置的增量成本（**不含**财务费用与所得税费用） |
| 未来现金流量现值 | 以**资产的当前状况**为基础，**不包括**尚未承诺的重组、改良带来的现金流；含处置时收到/支付的净现金流；折现率为**税前**且反映当前市场货币时间价值与特定风险的利率 |
| 外币现金流 | 先按**外币**折现，再按折现日即期汇率折算 |

::: danger 易错 · 减值损失不得转回
本准则（CAS 8）确认的资产减值损失**在以后会计期间不得转回**。这与存货跌价准备、金融资产减值准备**可以转回**形成鲜明对照，是高频陷阱。
:::

### 7.3 资产组与商誉

| 项目 | 规则 |
| --- | --- |
| 资产组认定 | 以**能否独立产生现金流入**为依据，考虑管理层生产经营管理方式；**一经确定不得随意变更** |
| 减值分摊顺序 | 先抵减分摊至资产组的**商誉**账面价值 → 再按资产组中其他各项资产**账面价值比重**按比例抵减 |
| 分摊下限 | 抵减后各资产账面价值不得低于以下三者之**最高者**：公允价值减处置费用净额、预计未来现金流量现值、零；未分摊的减值再按比重二次分摊 |
| 商誉减值测试 | 将商誉账面价值自购买日起**分摊至相关资产组或资产组组合**；含**少数股东商誉**时需先**整体商誉还原**（全部商誉 = 母公司确认商誉 ÷ 持股比例），再比较可收回金额 |
| 总部资产 | 能合理分摊的按账面价值比重分摊至资产组；难以分摊的，先对不含总部资产的资产组测试，再把总部资产加入**更大的资产组组合**测试 |

## 第 8 章 负债

### 8.1 流动负债与增值税

| 项目 | 要点 |
| --- | --- |
| 短期借款 | 期限 1 年以内（含 1 年）；利息按权责发生制计提计入财务费用 |
| 应付票据 / 应付账款 | 带息应付票据期末计提利息；**确实无法支付的应付账款**转入营业外收入 |
| 应付股利 | 宣告分派现金股利时确认；股票股利**不作账务处理** |

**增值税（2026 年《增值税法》口径）**：

| 专栏 | 用途 |
| --- | --- |
| 应交税费——应交增值税（进项税额 / 销项税额 / 已交税金 / 进项税额转出 / 转出未交增值税等） | 一般计税方法下的日常核算 |
| ——简易计税 | 简易计税方法下的应纳税额 |
| ——转让金融商品应交增值税 | 金融商品转让按盈亏相抵后的余额计税 |
| ——代扣代交增值税 | 境外单位或个人在境内发生应税交易 |
| ——未交增值税 | 月末结转的应交未交/多交增值税 |

| 情形 | 处理 |
| --- | --- |
| 采购 | 借：存货/费用　借：应交税费——应交增值税（进项税额）　贷：银行存款等 |
| 销售 | 借：应收账款等　贷：主营业务收入　贷：应交税费——应交增值税（销项税额） |
| 进项不得抵扣 | **直接计入相关成本费用**；已抵扣后改变用途的，作**进项税额转出** |
| 不得抵扣范围 | 简易计税项目、免税项目、**非正常损失**项目、购进用于**集体福利或个人消费**的货物服务、**购进并直接用于消费**的餐饮服务/居民日常服务/娱乐服务对应的进项税额 |


### 8.2 消费税与非流动负债

| 情形 | 处理 |
| --- | --- |
| 直接对外销售应税消费品 | 计入**税金及附加** |
| 委托加工收回后**直接出售**（不高于受托方计税价格） | 受托方代收代缴的消费税计入**委托加工物资成本** |
| 委托加工收回后**用于连续生产应税消费品** | 计入**应交税费——应交消费税**借方，待最终销售时抵扣 |

| 债券 | 要点 |
| --- | --- |
| 一般公司债券 | 按**实际利率法**摊余成本计量；`应付债券——面值 / 利息调整`，利息调整按实际利率摊销 |
| **可转换公司债券** | 发行时**分拆**：先按不附转换权的同类债券**未来现金流量折现**确定**负债成分**公允价值，发行总价扣除负债成分后的余额为**权益成分**（其他权益工具）；发行费用按两者公允价值比例分摊 |
| 转股时 | 按债券账面价值 + 原计入其他权益工具的金额，转为**股本 + 资本公积——股本溢价** |
| 长期应付款 | 含应付融资租入固定资产租赁款、具有融资性质的延期付款购买资产价款（按现值入账，差额为未确认融资费用） |

## 第 9 章 职工薪酬

| 分类 | 内容 | 计量要点 |
| --- | --- | --- |
| 短期薪酬 | 工资奖金津贴补贴、职工福利费、社保（医疗/工伤/生育）与住房公积金、工会经费与职工教育经费、短期带薪缺勤、短期利润分享计划、非货币性福利等 | 在职工**提供服务的期间**确认为负债并计入当期损益或资产成本 |
| 离职后福利 | 设定提存计划、设定受益计划 | 见下 |
| 辞退福利 | 解除劳动关系补偿、鼓励自愿接受裁减 | **在不能单方面撤回解除计划 与 确认重组相关成本 两者孰早**确认，计入**管理费用**（不计入资产成本） |
| 其他长期职工福利 | 长期带薪缺勤、长期残疾福利、长期利润分享等 | 按设定受益计划的简化方法计量，但**重新计量变动计入当期损益**（不进 OCI） |

| 细分 | 规则 |
| --- | --- |
| **累积带薪缺勤** | 权利可结转下期 → **在提供服务当期就预计将行使的额外权利确认负债**（如年休假） |
| **非累积带薪缺勤** | 权利不结转 → **仅在实际缺勤期间**确认（如婚假、产假、病假） |
| 短期利润分享计划 | 满足「导致企业现在负有支付的现时义务 + 金额能可靠估计」时确认，且**义务应在报告期末后 12 个月内结清** |
| 非货币性福利 | 以自产产品发放：按**产品公允价值 + 增值税**计入相关成本费用，同时确认应付职工薪酬，并确认收入结转成本；以外购商品发放：按公允价值计入 |
| 设定提存计划 | 向独立基金缴存固定费用后**不再承担进一步义务** → 按应缴存金额计入当期损益或资产成本，**不确认精算损益** |
| **设定受益计划** | 四步：①确定当期服务成本与利息净额 → 计入当期损益；②重新计量设定受益计划净负债/净资产（精算利得损失、计划资产回报扣除利息、资产上限影响）→ 计入**其他综合收益且后续不转回损益**；③确定净负债/净资产；④期末列报 |

## 第 10 章 股份支付

### 10.1 基本概念

| 项目 | 要点 |
| --- | --- |
| 四个环节 | **授予日** → 可行权日 → 行权日 → 出售日；等待期＝授予日至可行权日 |
| 两种类型 | **权益结算**（授予权益工具，如限制性股票、股票期权）；**现金结算**（承担以股份为基础确定的负债，如模拟股票、现金股票增值权） |
| 可行权条件 | **市场条件**（如股价目标，已反映在授予日公允价值中，**不影响每期确认的费用金额**）；**非市场条件**（服务年限、业绩指标，通过**预计可行权数量**影响费用） |

### 10.2 确认与计量

| 类型 | 计量基础 | 等待期内每个资产负债表日 |
| --- | --- | --- |
| 权益结算 | 按**授予日**权益工具的**公允价值**（一经确定不再变动） | 借：管理费用等　贷：**资本公积——其他资本公积** |
| 现金结算 | 按**每个资产负债表日及结算日**负债的公允价值**重新计量** | 借：管理费用等　贷：**应付职工薪酬**；公允价值变动计入当期损益 |

> **核心公式**：`当期应确认费用 = 预计可行权数量 × 授予日单位公允价值 × 累计时间权重 − 以前期间累计已确认`

| 特殊情形 | 处理 |
| --- | --- |
| 立即可行权 | 授予日即按公允价值计入相关成本费用（权益结算贷资本公积、现金结算贷应付职工薪酬） |
| 条款**有利修改**（如降低行权价、增加数量） | 应确认**增加的公允价值**，视同自修改日起享受更好条件 |
| 条款**不利修改** | **仍按原条件继续确认**，视同修改从未发生 |
| 取消或结算 | 加速确认剩余等待期费用（**加速行权**），支付给职工的款项作为**权益回购**冲减所有者权益；现金结算则冲减负债 |
| 集团股份支付 | 结算企业以其**自身权益工具**结算的按权益结算；以现金或其他资产结算的按现金结算；接受服务企业**无结算义务**的按权益结算 |


## 第 11 章 借款费用

### 11.1 范围与资本化时点

| 项目 | 内容 |
| --- | --- |
| 借款费用范围 | 因借入资金发生的**利息**（含折价/溢价摊销）、**辅助费用**、**外币借款汇兑差额**；**不包括**发行权益性证券的融资费用 |
| 符合资本化条件的资产 | 需要经过**相当长时间**（通常 1 年以上）的购建或生产活动才能达到预定可使用或可销售状态的资产（存货、固定资产、投资性房地产等） |

| 时点 | 判断 |
| --- | --- |
| **开始资本化**（同时满足） | ①资产支出已经发生；②借款费用已经发生；③为使资产达到预定可使用/可销售状态所必要的购建或生产活动**已经开始** |
| **暂停资本化** | 发生**非正常中断**且中断时间**连续超过 3 个月** → 暂停，期间费用化 |
| **停止资本化** | 达到预定可使用或可销售状态；之后发生的借款费用计入当期损益 |



### 11.2 资本化金额的计量

> **核心公式**：
> `专门借款利息资本化金额 = 专门借款当期实际发生的利息 − 闲置借款资金的投资收益（或利息收入）`
> `一般借款利息资本化金额 = 累计资产支出超过专门借款部分的加权平均数 × 所占用一般借款的资本化率`
> `资本化率 = 所占用一般借款当期实际发生的利息之和 ÷ 所占用一般借款本金加权平均数`

| 项目 | 规则 |
| --- | --- |
| 资本化上限 | 每一会计期间利息与折价溢价摊销的资本化金额，**不得超过当期相关借款实际发生的利息与摊销额** |
| 辅助费用 | 金额较小的直接计入当期损益（财务费用）；金额较大的在资本化期间内资本化 |
| 外币专门借款汇兑差额 | **资本化期间内**的汇兑差额予以资本化；**除外币专门借款外的其他外币借款**汇兑差额一律费用化 |

## 第 12 章 或有事项

### 12.1 概念与确认

| 概念 | 是否确认 |
| --- | --- |
| **或有负债** | **不确认**：①过去的交易或事项形成的**潜在义务**，其存在须通过未来不确定事项证实；或②履行该义务**不是很可能**导致经济利益流出、或金额不能可靠计量的现时义务。仅需**披露**（极小可能导致流出除外） |
| **或有资产** | **不确认**：过去的交易形成的潜在资产；只有**基本确定**（可能性 > 95%）能收到时才确认为资产；很可能时披露 |
| **预计负债** | **确认**，需同时满足：①企业承担的**现时义务**；②履行该义务**很可能**（> 50% 且 ≤ 95%）导致经济利益流出；③金额能**可靠计量** |

### 12.2 最佳估计数与补偿

| 情形 | 最佳估计数 |
| --- | --- |
| 所需支出存在**连续区间**且各结果等可能 | **上、下限金额的平均数**（中间值） |
| 涉及**单个项目** | 按**最可能发生金额**确定 |
| 涉及**多个项目** | 按**各种可能结果及相关概率加权计算**（期望值） |
| 预期可获得补偿 | **基本确定**能收到时**单独确认为资产**（如其他应收款），**不得超过预计负债账面价值**；不得与预计负债抵销列示 |

> 资产负债表日对预计负债账面价值进行**复核**，有确凿证据表明不能反映当前最佳估计数的，按最新估计数调整。

### 12.3 具体应用

| 事项 | 要点 |
| --- | --- |
| 未决诉讼/仲裁 | 按预计损失确认预计负债；被告很可能胜诉的仅作披露；原告**不确认或有资产**（基本确定除外） |
| 产品质量保证 | 按历史保修率估计，借记销售费用；**保修期满**冲回多提部分 |
| **亏损合同** | 履行合同义务不可避免发生的成本**超过**预期经济利益的合同；`待执行合同变亏损合同`时，**先对标的资产计提减值**，无标的资产的部分确认预计负债；**违约金与履行合同损失孰低**计量 |
| **重组义务** | 只有**已对外正式公告且已制定详细、基本确定的重组计划**时才确认预计负债；仅与**未来持续经营**有关的支出**不得**确认 |

## 第 13 章 金融工具

![金融资产分类两步判断](/acc/acc-financial-assets.svg)


### 13.1 分类两步法

| 分类 | 业务模式 | 合同现金流量（SPPI） |
| --- | --- | --- |
| **以摊余成本计量（AC）** | 仅以收取合同现金流量为目标 | 通过（仅为本金 + 以未偿付本金为基础的利息） |
| **FVOCI（债务工具）** | 既收取合同现金流量又出售 | 通过 |
| **FVTPL** | 上述之外的其他业务模式，或未通过 SPPI | 不通过 / 不适用 |

| 指定（**一经作出，不得撤销**） | 内容 |
| --- | --- |
| 公允价值选择权 | 初始确认时若**能消除或显著减少会计错配**，可将本应归入 AC / FVOCI 的金融资产**不可撤销地指定为 FVTPL** |
| 非交易性权益工具 | 可**不可撤销地指定为 FVOCI**：股利收入计入当期损益，**处置时累计 OCI 转入留存收益，不得转入损益**；减值不适用 |


### 13.2 初始与后续计量

| 分类 | 初始计量 | 后续计量 |
| --- | --- | --- |
| FVTPL | 公允价值，**交易费用计入当期损益（投资收益）** | 公允价值变动计入**公允价值变动损益**；持有期间股利/利息计入投资收益 |
| AC | 公允价值 + **交易费用计入初始入账金额** | **实际利率法**摊余成本；利息收入 = 摊余成本 × 实际利率；计提**预期信用损失** |
| FVOCI（债务工具） | 公允价值 + 交易费用 | 公允价值变动计入**其他综合收益**；利息按实际利率法计入投资收益；**减值计入 OCI（不减少资产账面价值）**；处置时 OCI 转投资收益 |
| FVOCI（权益工具指定） | 公允价值 + 交易费用 | 公允价值变动计入 OCI；**股利**计入投资收益；不计提减值；处置时 OCI 转留存收益 |

> `摊余成本 = 初始确认金额 − 已偿还本金 ± 采用实际利率法摊销的累计差额 − 累计信用减值准备（仅金融资产）`

| 金融负债 | 后续计量 |
| --- | --- |
| 一般金融负债 | 摊余成本（实际利率法） |
| FVTPL 指定（消除会计错配） | 公允价值变动计入当期损益，**因自身信用风险变动引起的部分计入 OCI**（且后续不转损益） |

### 13.3 减值与重分类

| 阶段 | 信用风险特征 | 利息收入基础 | 预期信用损失 |
| --- | --- | --- | --- |
| 第一阶段 | 初始确认后信用风险**未显著增加** | **账面余额（总额）** × 实际利率 | **未来 12 个月**预期信用损失 |
| 第二阶段 | 信用风险**已显著增加**但无客观减值证据 | 账面余额 × 实际利率 | **整个存续期**预期信用损失 |
| 第三阶段 | 已发生**信用减值** | **摊余成本（净额）** × 实际利率 | 整个存续期预期信用损失 |

> 应收账款、合同资产、租赁应收款可采用**简化方法**：始终按整个存续期预期信用损失计量。分录：借：信用减值损失　贷：坏账准备 / 债权投资减值准备 / **其他综合收益——信用减值准备**（FVOCI 债务工具）。

| 重分类 | 规则 |
| --- | --- |
| 前提 | 仅当企业管理金融资产的**业务模式发生改变**（由外部或内部变化引起、对经营非常重要、可证明）时才重分类；**会计政策变更、意图改变、市场暂时变化均不构成** |
| 时点 | 自重分类日起**未来适用**，不追溯调整此前已确认的利得、损失或利息 |
| 权益工具 | 指定为 FVOCI 的权益工具**不得重分类**；FVTPL 指定亦不可撤销 |

### 13.4 金融负债与权益工具的区分

| 判断 | 结论 |
| --- | --- |
| 是否存在**无条件避免交付现金或其他金融资产**的合同义务 | 不能避免 → **金融负债**；能无条件避免 → **权益工具** |
| 以自身权益工具结算（非衍生工具） | 交付**可变数量**自身权益工具 → 负债；**固定数量** → 权益 |
| 以自身权益工具结算（衍生工具） | 满足「**固定换固定**」（以固定数量自身权益工具交换固定金额现金） → 权益；否则 → 负债 |
| 或有结算条款、结算选择权 | 存在仅在**发行方清算时**才发生的或有结算条款，且清算不受发行方控制或不确定会发生 → 可分类为权益 |
| 复合金融工具（可转债） | **先分拆负债成分**（不附转换权的未来现金流折现），**余额为权益成分** |
| 永续债/优先股 | 关键看**是否有强制付息义务、是否有到期日、是否可无条件递延**；可无条件递延且无到期日 → 权益 |

### 13.5 转移、套期与列报

| 项目 | 要点 |
| --- | --- |
| 终止确认判断 | ①收取现金流量的**合同权利终止**；或②转移了收取现金流量的权利且**几乎所有风险和报酬**已转移；③既未转移也未保留几乎所有风险报酬的，看是否**放弃控制** |
| 继续涉入 | 按继续涉入程度确认相关资产与负债（如附追索权贴现、金融资产证券化） |
| 套期会计三类 | **公允价值套期**（被套期项目因被套期风险形成的利得损失计入当期损益）、**现金流量套期**（有效部分计入 OCI，无效部分计入损益；后续在预期交易影响损益时转出）、**境外经营净投资套期**（有效部分计入 OCI，处置境外经营时转损益） |
| 套期关系 | 需满足被套期项目与套期工具**经济关系**、信用风险不占主导、**套期比率**合理，并作正式书面记录 |

## 第 14 章 租赁

### 14.1 租赁识别与租赁期

| 项目 | 要点 |
| --- | --- |
| 租赁识别 | 存在**已识别资产**（供应商**无实质性替换权**）+ 承租人有权**主导资产的使用**并**获得几乎全部经济利益** |
| 租赁期 | **不可撤销期间** + 合理确定将行使**续租选择权**的期间 + 合理确定**不行使终止选择权**的期间 |
| 分拆 | 合同含多项租赁或租赁与非租赁部分的，应**分拆**；承租人可按资产类别**简化处理**不分拆（但需按单独价格相对比例分摊对价） |

### 14.2 承租人会计处理

> **核心公式**：
> `租赁负债初始金额 = 尚未支付的租赁付款额按折现率折现的现值`
> `使用权资产 = 租赁负债初始金额 + 租赁期开始日及之前已支付的租金 + 初始直接费用 + 复原成本预计 − 已享受的租赁激励`

| 项目 | 内容 |
| --- | --- |
| 租赁付款额 | 固定付款额（扣除租赁激励）、实质固定付款额、取决于指数或比率的可变付款额、购买选择权行权价、终止租赁罚款、承租人提供的担保余值预计应付款项 |
| 折现率 | 优先采用**租赁内含利率**；无法确定时用**承租人增量借款利率** |
| 后续计量 | 租赁负债按**实际利率法**确认利息（财务费用/资本化）；使用权资产按**直线法**在「租赁期 vs 使用寿命孰短」内计提折旧，发生减值的计提减值准备 |
| 可变付款额 | **不取决于指数或比率**的（如按销售额提成）在实际发生时**计入当期损益**，不纳入租赁负债 |
| **简化处理** | **短期租赁**（租赁期 ≤ 12 个月且不含购买选择权）、**低价值资产租赁**（全新时价值较低）→ 可选**直线法**计入相关成本费用，不确认使用权资产与租赁负债 |
| 租赁变更 | 增加一项或多项资产使用权且对价与单独价格相当的，作为**单独租赁**；否则按变更日重新计量租赁负债，相应调整使用权资产（缩小范围的先按比例减少并确认损益） |

### 14.3 出租人会计处理

| 分类 | 判断（满足其一即为融资租赁） |
| --- | --- |
| **融资租赁** | ①租赁期届满转移所有权；②承租人**有购买选择权**且行权价显著低于公允价值；③租赁期占资产**使用寿命的大部分**（≥ 75%）；④租赁付款额现值**几乎相当于**资产公允价值（≥ 90%）；⑤资产性质特殊，只有承租人能使用 |
| **经营租赁** | 除融资租赁以外的租赁 |

| 类型 | 处理 |
| --- | --- |
| 融资租赁 | 终止确认租赁资产，确认**应收融资租赁款**（= 租赁投资净额，按租赁内含利率折现）；后续按实际利率法确认**利息收入** |
| 经营租赁 | 保留资产并计提折旧；租金按**直线法**或其他系统合理方法在租赁期内确认为**租金收入**；初始直接费用资本化并分摊 |

## 第 15 章 持有待售的非流动资产、处置组和终止经营

### 15.1 分类条件

| 条件 | 说明 |
| --- | --- |
| **可立即出售** | 资产（或处置组）在当前状态下即可立即出售，且仅受**此类资产出售的惯常条款**限制 |
| **出售极可能发生** | 企业已就出售计划作出**决议**、已签订**具有法律约束力的协议**、预计**自划分为持有待售类别起 1 年内**完成出售；已积极参与寻找买方、价格合理、不太可能重大变更或撤销 |


### 15.2 计量与列示

| 项目 | 规则 |
| --- | --- |
| 初始及后续计量 | 按**账面价值与公允价值减去出售费用后的净额孰低**计量；差额确认为**资产减值损失** |
| 减值转回 | 划分为持有待售后**公允价值减出售费用净额增加**的部分，可在**此前已确认的减值损失范围内转回**（但**商誉**减值不得转回） |
| 折旧/摊销 | **自划分为持有待售类别起停止计提折旧或摊销**；但处置组中的**负债利息及其他费用继续计提** |
| 计量例外 | 不适用本准则计量的：递延所得税资产、金融资产、以公允价值计量的投资性房地产、职工薪酬形成的资产等（按各自准则计量） |
| 报表列示 | 流动资产/负债中单列「**持有待售资产 / 持有待售负债**」；**不得相互抵销**；与终止经营相关的损益在利润表中**单独列示** |
| 持有待售的长期股权投资 | 已划分为持有待售的部分**停止权益法**，剩余部分继续权益法；全部划为持有待售时**整体停止权益法** |

### 15.3 终止经营

> **定义**：已被处置或被划归为持有待售，且**能够单独区分**的组成部分，并满足下列之一：①代表一项**独立的主要业务**或一个**主要单独经营地区**；②是拟对独立主要业务或经营地区进行处置的**一项相关联计划的一部分**；③是**专为转售而取得的子公司**。

| 列报 | 要求 |
| --- | --- |
| 利润表 | 将终止经营的**税后损益**与**处置损益**单独列示；比较期间数据**追溯重列**，把当期列作终止经营的部分在比较期间也重分类为终止经营 |
| 附注 | 披露终止经营的收入、费用、税前损益、所得税、税后损益、处置损益及现金流量等 |


## 第 16 章 所有者权益

| 项目 | 要点 |
| --- | --- |
| 实收资本/股本增加 | 投资者投入、资本公积转增、盈余公积转增、发放股票股利、可转债转股、债务转为资本等 |
| 实收资本减少 | 股份有限公司**回购股票**：回购时借「库存股」（按实际支付价款）；注销时按**面值**冲股本，差额依次冲**资本公积——股本溢价 → 盈余公积 → 未分配利润**；回购价低于面值的差额增加资本公积 |
| **其他权益工具** | 核算发行的**除普通股以外**归类为权益工具的金融工具（永续债、优先股、可转债权益成分）；持有方与发行方处理需对称 |
| 资本公积 | 资本溢价/股本溢价（可转增资本）、**其他资本公积**（权益结算股份支付、权益法下被投资单位其他权益变动） |
| 留存收益 | 盈余公积（法定 10%，累计达注册资本 50% 可不再提取）+ 未分配利润 |

### 16.2 其他综合收益（OCI）的两类归属

| 以后**不能重分类进损益** | 以后**满足条件时重分类进损益** |
| --- | --- |
| 重新计量设定受益计划变动额；权益法下被投资单位不能重分类进损益的 OCI 份额；**指定为 FVOCI 的非交易性权益工具**公允价值变动（处置时转**留存收益**）；企业自身信用风险变动引起的 FVTPL 金融负债公允价值变动 | 权益法下可重分类进损益的 OCI 份额；**FVOCI 债务工具**公允价值变动与减值准备；现金流量套期有效部分；外币报表折算差额；自用/存货转公允价值模式投资性房地产产生的**贷方差额**等 |

::: danger 易错
「不能重分类进损益」≠ 永远留在 OCI：指定为 FVOCI 的权益工具处置时应**直接转入留存收益**（不是损益，也不冲 OCI 后不管）；这是选择题高频陷阱。
:::

## 第 17 章 收入、费用和利润

![收入确认五步法](/acc/acc-revenue.svg)


### 17.1 确认与计量五步法

| 步骤 | 判断要点 |
| --- | --- |
| ① 识别与客户订立的合同 | 合同各方已批准并承诺履约；能明确各方权利义务；有明确支付条款；**具有商业实质**；**对价很可能收回**。不满足的，只有在「已收款且无可退回义务 / 已履约且无条件收款」时才能确认收入 |
| ② 识别单项履约义务 | 承诺向客户转让**可明确区分**商品或服务（能单独受益 + 与其他承诺可单独区分）；一系列实质相同且转让模式相同的承诺可合并为一项 |
| ③ 确定交易价格 | 考虑**可变对价**（按期望值或最可能金额估计，且计入**不超过累计已确认收入极可能不会发生重大转回**的金额）、**重大融资成分**、非现金对价、应付客户对价 |
| ④ 分摊交易价格 | 按各单项履约义务**单独售价的相对比例**分摊；合同折扣、可变对价一般按比例分摊（有确凿证据表明应分摊至特定义务的除外） |
| ⑤ 履行义务时确认收入 | **时段**履约（按履约进度）或**时点**履约（客户取得控制权时） |

| 时段履约（满足其一） | 时点履约的控制权迹象 |
| --- | --- |
| 客户在企业履约的同时**取得并消耗**利益；客户**控制在建商品**；企业产出**不可替代用途**且有权就**累计至今已履约部分**收取款项 | 企业就该资产享有**现时收款权**；客户已拥有**法定所有权**；已**实物占有**；客户已承担**所有权上的主要风险和报酬**；客户已**接受**该商品 |

### 17.2 合同资产负债与合同成本

| 项目 | 要点 |
| --- | --- |
| **合同资产** | 企业已向客户转让商品而**有权收取对价**，且该权利**还取决于时间流逝之外的其他因素**（如还需完成另一履约义务）；适用**减值（预期信用损失）** |
| **应收账款** | 仅取决于**时间流逝**的无条件收款权 |
| **合同负债** | 企业**已收或应收**客户对价而负有的**向客户转让商品**的义务（如预收款） |
| **合同取得成本** | 为取得合同发生的**增量成本**（如销售佣金），**预期能够收回**的资本化为资产；摊销期 ≤ 1 年的可简化计入当期损益 |
| **合同履约成本** | 与当前或预期取得合同直接相关、增加了未来履约资源、预期可收回；**不包括**与已履约部分相关的支出、无法区分的无关支出 |
| 摊销与减值 | 按与相关收入**相同的基础**摊销；账面价值高于「剩余对价 − 预计将发生的成本」时计提减值准备，**已计提减值不得转回** |

### 17.3 八类特定交易

| 交易 | 处理要点 |
| --- | --- |
| **附有销售退回条款** | 按**预期有权收取的对价**确认收入（预期不会退回部分）；预期退回部分确认为**预计负债**（退款负债），同时按预期将退回商品账面价值扣回收成本后确认**应收退货成本** |
| **附有质量保证条款** | **保证类**（保证商品符合既定标准）→ 按或有事项准则计提预计负债；**服务类**（提供额外服务）→ 作为**单项履约义务**分摊交易价格 |
| **主要责任人 vs 代理人** | 企业在转让前是否**控制**该商品：控制 → **主要责任人按总额**确认收入；不控制 → **代理人按净额**（佣金/手续费）确认。判断迹象：承担主要责任、承担存货风险、有自主定价权 |
| **附有客户额外购买选择权** | 提供**重大权利**的（如折扣超过通常水平）作为**单项履约义务**，分摊交易价格，在行使或失效时确认收入 |
| **授予知识产权许可** | 属于「**在某一时段**」履行的（如持续提供使用权的动态 IP）按时段确认；属于「**在某一时点**」的（静态 IP，提供使用权时点）按时点确认；**基于销售或使用的特许权使用费**在「后续销售或使用发生」与「履约义务完成」**孰晚**确认 |
| **售后回购** | 有义务/有权回购 → **融资交易**（不终止确认资产，收到的款项确认为金融负债，差额在回购期间计提利息）；**客户有重大经济动因行使**回购选择权同理；客户无该动因的，按**附销售退回条款**处理 |
| **客户未行使的权利** | 预收不可退回款项（如储值卡）：按客户行使权利的模式确认收入；企业**预期有权获得**未行使部分金额（breakage）时按比例确认，否则在**客户行使权利的可能性极低**时确认 |
| **无需退回的初始费** | 判断该初始费是否与**向客户转让某项已承诺商品**相关：相关 → 在转让该商品时确认收入；不相关（如仅为入会费）→ 作为**未来将转让商品的预付款**，在未来转让时确认 |

### 17.4 费用与利润

| 项目 | 内容 |
| --- | --- |
| 期间费用 | **销售费用、管理费用、研发费用、财务费用**；管理费用含聘请中介机构费、业务招待费、诉讼费等；研发费用含费用化研发支出 |
| 营业外收支 | **与日常活动无直接关系**的各项利得损失：非流动资产毁损报废损失、捐赠支出、盘亏损失、非常损失、罚款支出、政府补助（与日常活动无关的）等 |

> **核心公式**（按利润表顺序）：
> **营业利润** = 营业收入 − 营业成本 − 税金及附加 − 销售/管理/研发/财务费用 − 信用减值损失 − 资产减值损失 + 公允价值变动收益 + 投资收益 + 净敞口套期收益 + 其他收益 + 资产处置收益
> **利润总额** = 营业利润 + 营业外收入 − 营业外支出；**净利润** = 利润总额 − 所得税费用
> **综合收益总额** = 净利润 + 其他综合收益税后净额（后者分「不能重分类进损益」与「将重分类进损益」两类列示）

## 第 18 章 政府补助

| 项目 | 要点 |
| --- | --- |
| 定义与特征 | 企业**从政府无偿取得**货币性或非货币性资产；特征：**来源于政府的经济资源 + 无偿性** |
| 不属于 | 政府作为**所有者投入的资本**、政府购买服务支付的**对价**（按收入准则）、**增值税出口退税**（退回进项税额）、直接减征/免征/增加计税抵扣额等**不涉及资产直接转移**的税收优惠 |
| 分类 | **与资产相关**（用于购建或以其他方式形成长期资产）；**与收益相关**（除与资产相关之外） |
| 确认 | 同时满足「**能够满足政府补助所附条件**」+「**能够收到**」；按**权责发生制**确认 |

| 方法 | 与资产相关 | 与收益相关 |
| --- | --- | --- |
| **总额法** | 收到时确认**递延收益**，在资产使用寿命内按**合理、系统的方法**分期计入**其他收益**（与日常活动相关）或营业外收入 | 补偿**以后期间**费用 → 递延收益，在确认相关费用期间计入其他收益；补偿**已发生**费用 → 直接计入其他收益 |
| **净额法** | 冲减相关资产的**账面价值**，按扣减后的金额计提折旧/摊销 | 冲减相关成本费用或营业外支出 |

| 特殊情形 | 处理 |
| --- | --- |
| 综合性项目政府补助 | 能区分的分别处理；难以区分的**整体归类为与收益相关** |
| 政策性优惠贷款贴息 | 财政将贴息资金**拨付给贷款银行**：企业按实际发生利率（或按公允价值计量借款并差额计入递延收益摊销）；财政**直接拨付给企业**：冲减相关借款费用（净额法）或计入其他收益（总额法） |
| **政府补助退回** | 存在相关递延收益的：**冲减递延收益账面余额**，超出部分计入当期损益；**净额法**下曾冲减资产账面价值的，**调整资产账面价值**；属于前期差错的按**前期差错更正**追溯处理 |
| 列报 | 计入「**其他收益**」（与日常活动相关）或「营业外收入」；现金流量表列入**经营活动**现金流量 |

::: danger 易错
- **企业选择总额法或净额法属于会计政策**，应**一贯运用**，同类业务不得随意切换。
- 与资产相关的补助在**相关资产使用寿命结束前被出售、转让、报废或发生毁损**时，尚未分摊的递延收益余额应**一次性转入资产处置当期损益**，不再递延。
:::

## 第 19 章 所得税

![资产负债表债务法](/acc/acc-deferred-tax.svg)

### 19.1 计税基础

| 项目 | 计税基础 |
| --- | --- |
| **资产** | 企业收回资产账面价值过程中，计算应纳税所得额时按税法规定**可以自应税经济利益中抵扣的金额**（即未来可税前扣除金额） |
| **负债** | 负债的**账面价值 − 未来期间计算应纳税所得额时按税法规定可予抵扣的金额** |

| 常见资产/负债 | 账面价值 vs 计税基础 |
| --- | --- |
| 固定资产、无形资产 | 会计折旧/摊销年限、方法、减值准备与税法不同 → 产生暂时性差异 |
| 交易性金融资产 | 账面按**公允价值**、计税基础为**取得成本**，差额为应纳税/可抵扣暂时性差异 |
| 计提减值准备的资产 | 税法**不认可**未实际发生的减值 → 资产计税基础不变，形成**可抵扣**暂时性差异 |
| **预计负债** | 相关支出**实际发生时允许税前扣除** → 计税基础 = **0**（可抵扣差异）；若税法规定**不论是否实际发生都不允许扣除** → 计税基础 = 账面价值（无差异） |
| **合同负债 / 预收账款** | 税法规定**计入当期应纳税所得额** → 计税基础 = **0**；不计入当期应税所得 → 计税基础 = 账面价值 |
| **递延收益（政府补助）** | 若为**免税收入** → 计税基础 = 账面价值（无差异）；若为**应税收入**且已计入当期应税所得 → 计税基础 = **0** |
| 应付职工薪酬 | 超过税法规定标准**不得税前扣除**的部分 → 计税基础 = 账面价值（**不产生**暂时性差异） |
| 其他应付款（行政罚款、滞纳金） | 税法**永不允许扣除** → 计税基础 = 账面价值（**无差异，属于永久性差异**） |

::: danger 易错 · 永久性差异不确认递延所得税
国债利息收入免税、超标准业务招待费/职工福利费、行政性罚款与滞纳金等**永久性差异**，只影响当期应纳税所得额调整，**不产生递延所得税**。做题时先把永久性差异从账面价值/计税基础比较中剔除。
:::

### 19.2 暂时性差异与递延所得税

| 差异 | 判定 | 确认 |
| --- | --- | --- |
| **应纳税暂时性差异** | 资产账面 **>** 计税基础，或负债账面 **<** 计税基础 | 除例外情形外**一律确认递延所得税负债（DTL）** |
| **可抵扣暂时性差异** | 资产账面 **<** 计税基础，或负债账面 **>** 计税基础 | 以**很可能取得用来抵扣的应纳税所得额为限**确认递延所得税资产（DTA） |
| 特殊项目 | 未作为资产负债确认但税法允许**以后摊销**的费用（如超标的广告费）、**可抵扣亏损与税款抵减** | **视同**可抵扣暂时性差异，符合条件确认 DTA |

| 不确认 DTL 的例外 | 不确认 DTA 的情形 |
| --- | --- |
| ① **商誉的初始确认**（免税合并下商誉计税基础为 0）；② **非企业合并**且交易发生时**既不影响会计利润也不影响应纳税所得额**的初始确认差异；③ 与**子公司/联营/合营投资**相关，且投资企业**能控制转回时间**、该差异**可预见未来很可能不会转回** | 缺乏足够应纳税所得额；**可抵扣亏损**超出税法规定弥补期（一般 5 年，高新技术企业/科技型中小企业 **10 年**）的部分 |

### 19.3 计量与列报

> **核心公式**：
> `当期所得税 = 应纳税所得额 × 当期适用税率`，其中 `应纳税所得额 = 利润总额 ± 永久性差异 ± 暂时性差异变动`
> `递延所得税 = (期末 DTL − 期初 DTL) − (期末 DTA − 期初 DTA)`
> `所得税费用 = 当期所得税 + 递延所得税`

| 项目 | 规则 |
| --- | --- |
| 计量税率 | 按**暂时性差异预计转回期间**适用的税率；**税率变更**时对已确认 DTA/DTL 按新税率**重新计量**，影响一般计入当期所得税费用 |
| 是否折现 | **不折现** |
| 对应科目 | 与**直接计入所有者权益**的交易或事项、**企业合并**相关的递延所得税，计入**其他综合收益 / 商誉**（而非所得税费用） |
| DTA 复核 | 每个资产负债表日复核，**很可能无法获得足够应纳税所得额**时**减记** DTA 账面价值，以后很可能获得时**转回** |
| 列报 | DTA / DTL 一律列作**非流动**；与当期所得税资产/负债**在同一税务征管部门、同一纳税主体、具有法定抵销权且意图净额结算**时可**抵销列示** |

## 第 20 章 非货币性资产交换

| 项目 | 要点 |
| --- | --- |
| 认定 | 交易双方主要以**存货、固定资产、无形资产、长期股权投资等**非货币性资产进行的交换；涉及少量货币性资产（补价）时：`补价 ÷ 整个资产交换金额 < 25%` 视为非货币性资产交换（**支付补价方**用「补价 ÷（换出资产公允价值 + 补价）」，**收到补价方**用「补价 ÷ 换出资产公允价值」） |
| 不涉及的交易 | 与所有者或所有者以外方面的**非互惠转让**、**企业合并**中取得非货币资产、**债务重组**中以非货币资产偿债、发行**股票**取得非货币资产、以非货币资产**发放股利**等 |
| 商业实质（满足其一） | ①换入资产的未来现金流量在**风险、时间分布或金额**方面与换出资产**显著不同**；②换入资产与换出资产的**预计未来现金流量现值**不同，且差额相对于公允价值**重大** |

| 计量基础 | 适用条件 | 换入资产成本 | 损益 |
| --- | --- | --- | --- |
| **公允价值基础** | 该项交换**具有商业实质**，且换入或换出资产的**公允价值能够可靠计量** | `换出资产公允价值 + 应支付的相关税费 ± 补价`（有确凿证据表明换入资产公允价值更可靠的，按**换入资产公允价值**） | 换出资产**公允价值 − 账面价值**计入当期损益（视资产类型计入资产处置损益/主营业务收入等） |
| **账面价值基础** | 不同时满足上述两条件 | `换出资产账面价值 + 应支付的相关税费 ± 补价` | **不确认损益** |

| 多项资产交换 | 处理 |
| --- | --- |
| 公允价值基础 | 先确定**换入资产总成本**，再按各项换入资产**公允价值相对比例**（公允价值不能可靠计量时按**原账面价值相对比例**）分摊 |
| 账面价值基础 | 按各项换入资产的**原账面价值相对比例**分摊总成本 |


## 第 21 章 债务重组

### 21.1 定义与终止确认

> **定义**：在**不改变交易对手方**的情况下，经债权人和债务人协定或法院裁定，就清偿债务的**时间、金额或方式**重新达成协议的交易；涉及的债权债务是《金融工具确认和计量》准则规范的金融工具。

| 方式 | 终止确认判断 |
| --- | --- |
| 以资产清偿 / 债务转权益工具 | 债权人取得相关资产的控制权、债务人交付资产或权益工具解除现时义务 → 双方**一般均可终止确认** |
| 修改其他条款 | 需判断合同条款是否发生**实质性修改**（「10% 测试」：新条款下剩余现金流量现值按原实际利率折现，与原剩余现金流量现值相比**相差 ≥ 10%**，或定性因素重大）→ 是则终止确认原债权/债务并确认**新**金融资产/负债；否则仅**调整账面价值并确认利得或损失** |
| 组合方式 | 一般视为对全部债权合同条款作出实质性修改 → **整体终止确认**并按修改后条款确认新金融资产；债务人按各组成部分分别判断 |

### 21.2 以资产清偿债务

| 主体 | 计量 | 损益 |
| --- | --- | --- |
| **债务人** | 终止确认所清偿债务与转让资产 | `所清偿债务账面价值 − 转让资产账面价值` → 计入**其他收益——债务重组收益**（以金融资产清偿时用**投资收益**） |
| **债权人受让金融资产** | 按**受让金融资产的公允价值**初始计量 | `受让金融资产公允价值 − 放弃债权账面价值` → **投资收益** |
| **债权人受让非金融资产** | 按**放弃债权的公允价值 + 可直接归属于该资产的税费**（购买交易模式）确定成本 | `放弃债权公允价值 − 放弃债权账面价值` → **投资收益** |

| 债权人受让资产 | 成本构成 |
| --- | --- |
| 存货 | 放弃债权公允价值 + 使存货达到当前场所和状态的税金、运输费、装卸费、保险费等 |
| 固定资产 | 放弃债权公允价值 + 使资产达到**预定可使用状态前**可直接归属的税金、运输费、安装费、专业人员服务费等 |
| 无形资产 / 投资性房地产 | 放弃债权公允价值 + 可直接归属于使资产达到预定用途的相关税费 |
| 对联营/合营企业长投 | 放弃债权公允价值 + 可直接归属于该投资的相关税费 |


### 21.3 债务转权益工具与修改其他条款

| 情形 | 要点 |
| --- | --- |
| 债务人将债务转为权益工具 | 债务人按**所清偿债务账面价值**与**所发行权益工具确认金额**的差额计入当期损益（投资收益）；权益工具初始按**公允价值**计量，公允价值不能可靠计量时按所清偿债务的公允价值 |
| 债权人 | 取得股权按金融工具准则分类（FVTPL / 指定 FVOCI / 长投），按公允价值入账，差额计入投资收益 |
| 修改其他条款（债务人） | 实质性修改 → 终止确认原债务、按**新条款公允价值**确认新负债，差额计入投资收益；未实质修改 → 按原实际利率重新计算现值，差额调整当期损益 |

## 第 22 章 外币折算

### 22.1 记账本位币

| 项目 | 判断因素 |
| --- | --- |
| 一般企业 | ①该货币主要影响**商品和劳务的销售价格**；②主要影响**人工、材料及其他费用**；③**融资活动获得的货币**及保存经营所得价款使用的货币（通常以①②为主） |
| **境外经营** | ①境外经营对其所从事的活动是否拥有**很强的自主性**；②与企业交易是否在境外经营活动中**占有较大比重**；③境外经营活动产生的现金流量是否**直接影响**企业现金流量、是否可随时汇回；④境外经营产生的现金流量是否**足以偿还**其现有及可预期债务 |
| 变更 | 记账本位币一经确定**不得随意变更**；确需变更的，采用**变更当日即期汇率**将所有项目折算为新记账本位币，**折算差额计入当期损益（财务费用）**，并**追溯**比较报表 |

### 22.2 外币交易的会计处理

| 环节 | 处理 |
| --- | --- |
| 初始确认 | 按**交易发生日即期汇率**折算；汇率波动不大的可用**近似汇率**（通常为当期平均汇率，且需一贯运用） |
| **货币性项目**期末调整 | 按**期末即期汇率**折算，差额计入**财务费用——汇兑差额**（符合资本化条件的借款费用资本化） |
| 以**历史成本**计量的非货币性项目 | **不改变**记账本位币金额（仍按交易发生日汇率），不产生汇兑差额 |
| 以**公允价值**计量的非货币性项目 | 按**公允价值确定日**的即期汇率折算，差额计入**公允价值变动损益**（或 OCI） |
| 存货 | 以**期末即期汇率**折算可变现净值，再与记账本位币反映的成本比较，差额计入**资产减值损失** |
| 结算 | 结算日按当日汇率折算，与账面差额计入财务费用 |

### 22.3 外币财务报表折算

| 报表项目 | 折算汇率 |
| --- | --- |
| 资产、负债 | **资产负债表日即期汇率** |
| 所有者权益（除「未分配利润」） | **发生时的即期汇率** |
| 收入、费用 | **交易发生日即期汇率**或其**近似汇率** |
| 折算差额 | 计入**其他综合收益**（外币报表折算差额），在资产负债表所有者权益项下单独列示 |

> 处置境外经营（含**部分处置**丧失控制权、清算等）时，将与该境外经营相关的**外币报表折算差额**按处置比例**转入处置当期损益**；**不丧失控制权**的部分处置，相关差额应归属于**少数股东权益**，不转损益。

## 第 23 章 财务报告

### 23.1 财务报表列报基本要求

| 项目 | 要点 |
| --- | --- |
| 四表一注 | **资产负债表、利润表、现金流量表、所有者权益变动表 + 附注** |
| 列报基础 | 以**持续经营**为基础；评价涵盖报告期末起**至少 12 个月**；不满足持续经营的应披露并采用其他基础 |
| 一致性 | 财务报表项目的**列报**应当在各个会计期间**保持一致**，除非准则要求改变或经营性质发生重大变化 |
| 抵销 | **资产与负债、收入与费用不得相互抵销**，除非准则另有规定（如金融资产/负债满足法定抵销权且意图净额结算） |
| 重要性与汇总 | 重要项目**单独列报**；不重要的可汇总；**性质或功能不同**的项目应单独列报 |
| 比较信息 | 至少提供**上一可比期间**的比较数据；会计政策变更、差错更正等需追溯重列 |

### 23.2 资产负债表与利润表填列

| 报表 | 填列方法 |
| --- | --- |
| 资产负债表「期末余额」 | ①根据**总账科目余额**直接填列；②根据几个总账科目余额**计算**填列（如货币资金）；③根据**明细科目余额分析**填列（应收账款 = 应收明细借方 + 预收明细借方 − 坏账准备）；④根据总账与备抵科目**抵减后净额**填列；⑤综合运用（如存货需扣减跌价准备） |
| 流动性划分 | 预计在**正常营业周期中**变现/出售/耗用、主要为交易目的持有、预计在资产负债表日起 **1 年内**变现或清偿的列为流动；**营业周期超过 1 年**的企业可按营业周期划分 |
| 利润表「本期金额」 | 按各损益类科目**本期发生额**分析填列；「其他综合收益的税后净额」按两类归属分别列示 |
| 「上期金额」 | 按上年同期可比数据填列；发生会计政策变更或前期差错更正的需**追溯调整** |

### 23.3 现金流量表

| 类别 | 主要内容 |
| --- | --- |
| 经营活动 | 销售商品/提供劳务收到的现金、购买商品/接受劳务支付的现金、支付给职工的现金、缴纳税费、收到税费返还等 |
| 投资活动 | 购建与处置**长期资产**、取得与收回**投资**、取得投资收益收到的现金（**不含**属于经营活动的利息收入分类差异按准则判断） |
| 筹资活动 | 吸收投资、取得与偿还借款、分配股利利润或**偿付利息**支付的现金、支付的租赁负债本金与利息 |

> **易错**：**支付的各项税费**中，计入固定资产成本的契税/车辆购置税等属于**投资活动**；**收到的增值税出口退税**属于经营活动；**偿付利息**属于筹资活动（我国准则）；**取得子公司及其他营业单位支付的现金净额**属于投资活动。

## 第 24 章 会计政策、会计估计变更和差错更正

### 24.1 会计政策及其变更

| 项目 | 要点 |
| --- | --- |
| 会计政策 | 企业在会计确认、计量和报告中所采用的**原则、基础和会计处理方法**（如存货计价方法、投资性房地产后续计量模式、收入确认时点、合并政策） |
| 变更条件（满足其一） | ①**法律、行政法规或国家统一会计制度要求**变更；②变更后能提供更**可靠、更相关**的会计信息 |
| **不属于**政策变更 | ①本期发生的交易或事项与以前相比**具有本质差别**而采用新政策；②对**初次发生**或**不重要**的交易采用新政策 |
| 处理方法 | 国家有规定的按规定；无规定或累积影响数**能合理确定**的用**追溯调整法**；累积影响数**不能合理确定**的用**未来适用法** |

> **追溯调整法**：计算`会计政策变更累积影响数`＝按新政策对**最早可比期间期初留存收益**应有的金额 − 现有金额（考虑所得税影响但不考虑利润分配），调整**期初留存收益**（盈余公积、未分配利润）与其他相关项目，并**重列比较期间报表**。

### 24.2 会计估计及其变更

| 项目 | 要点 |
| --- | --- |
| 会计估计 | 对结果不确定的交易或事项以最近可利用信息为基础所作判断（如折旧年限与残值、坏账计提比例、固定资产弃置费用、公允价值估值技术） |
| 处理方法 | **未来适用法**：变更当期及以后期间适用，**不调整以前期间、不追溯、不重述比较报表** |
| 划分 | 涉及**确认、计量基础或列报项目**变更 → **会计政策变更**；仅涉及**金额/比例/年限**等估计数变更 → **会计估计变更**；**难以区分的按会计估计变更**处理 |

::: danger 易错
「投资性房地产**成本模式 → 公允价值模式**」是**会计政策变更（追溯调整）**；但「自用房地产**转为**投资性房地产」只是资产用途改变，**不是**政策变更。固定资产**折旧方法改变**属于**会计估计变更（未来适用）**，不是政策变更。
:::

### 24.3 前期差错更正

| 情形 | 处理 |
| --- | --- |
| **重要的**前期差错 | **追溯重述法**：调整**最早可比期间期初留存收益**及相关项目，重列比较报表；涉及损益的通过「**以前年度损益调整**」过渡，同时调整**递延所得税**与**盈余公积** |
| **不重要的**前期差错 | 直接调整**发现当期**的相关项目（不调整期初留存收益） |
| 披露 | 披露差错性质、对各期比较数据及期初留存收益的影响金额、更正方法 |

> 与第 25 章结合：**资产负债表日后期间发现的**报告年度差错属于**调整事项**；发现的**更早年度**差错仍按前期差错更正处理，但调整的是**报告年度报表**的期初数。

## 第 25 章 资产负债表日后事项

### 25.1 界定与区分

| 项目 | 要点 |
| --- | --- |
| 涵盖期间 | **资产负债表日次日 → 财务报告批准报出日**（董事会或类似机构批准报出之日；报出后又有重大修改的，需重新确定） |
| **调整事项** | 对**资产负债表日已经存在的情况**提供**新的或进一步证据**的事项 → **调整**报告年度财务报表（账务 + 报表） |
| **非调整事项** | 表明**资产负债表日后才发生**的情况的事项 → **不调整**报表，但重要的须在附注**披露**性质与财务影响估计 |
| 区分关键 | 看导致该事项的**情况在资产负债表日是否已存在**（如火灾发生在日后 = 非调整；日前的未决诉讼在日后结案 = 调整） |


### 25.2 调整事项的处理原则与四类情形

| 步骤 | 处理 |
| --- | --- |
| ① 涉及损益 | 通过「**以前年度损益调整**」科目核算，不直接计入当期损益 |
| ② 涉及利润分配 | 直接调整「**利润分配——未分配利润**」；同时调整**盈余公积** |
| ③ 不涉及损益与利润分配 | 直接调整相关资产、负债、所有者权益科目 |
| ④ 报表调整 | 调整报告年度**资产负债表期末数、利润表及所有者权益变动表本期数**；同时调整**附注**相关项目；涉及所得税的按第 19 章调整应交所得税/递延所得税 |

| 四类调整事项 | 处理 |
| --- | --- |
| （一）**诉讼案件结案** | 法院判决证实资产负债表日已存在现时义务 → 调整原确认的**预计负债**或确认新负债，差额计入以前年度损益调整 |
| （二）**取得减值确凿证据** | 表明某项资产在资产负债表日已减值或需调整原减值金额 → 补提资产减值准备（**注意减值不得转回的部分**） |
| （三）**进一步确定购入资产成本或售出资产收入** | 如日后收到供应商结算单据、确定销售退回数量 → 调整原暂估成本或收入 |
| （四）**发现财务报表舞弊或差错** | 按第 24 章前期差错更正追溯重述 |

### 25.3 与非调整事项的综合

| 情形 | 归类 |
| --- | --- |
| 日后**发生重大诉讼、自然灾害、火灾** | 非调整，附注披露 |
| 日后**发行股票/债券、巨额举债、企业合并或处置子公司** | 非调整，附注披露 |
| 日后**宣告分派现金股利/利润** | 非调整，**不确认为资产负债表日负债**，仅披露 |
| 日后**外汇汇率或资产价格发生大幅变动** | 一般非调整；但**汇率变动对资产负债表日已存在的外币货币性项目**的影响需按第 22 章处理 |
| 日后**销售退回**（对应报告年度已确认收入） | **调整事项**，冲减报告年度收入与成本 |


## 第 26 章 企业合并

### 26.1 界定与业务判断

| 项目 | 要点 |
| --- | --- |
| 企业合并界定 | 将两个或两个以上**单独的企业（主体）**合并形成一个**报告主体**的交易或事项；关键是**取得对业务的控制权** |
| **构成业务** | 需同时具备**投入**与**实质性加工处理过程**，且二者结合能**显著促进产出能力**；有产出并非必要条件 |
| **集中度测试**（可选简化） | 若所购资产组的**几乎全部公允价值**集中于**单项可辨认资产或一组类似资产**，可直接判定**不构成业务**（按资产购买处理，不产生商誉） |
| **不构成业务** | 取得资产组但仍需投入实质性加工过程的，按**购买资产**处理：按**相对公允价值**分摊购买价款，**不确认商誉、不确认递延所得税** |

| 方式 | 结果 |
| --- | --- |
| 控股合并 | 被合并方**保留法人资格**，形成长期股权投资，需编**合并报表** |
| 吸收合并 | 被合并方**注销**，其资产负债并入合并方账簿 |
| 新设合并 | 参与合并各方均注销，成立新主体 |

### 26.2 同一控制 vs 非同一控制

| 项目 | 同一控制下 | 非同一控制下 |
| --- | --- | --- |
| 判断 | 合并前后均受**同一方或相同多方最终控制**，且该控制**并非暂时性** | 除同一控制以外的企业合并 |
| 计量基础 | **账面价值**（被合并方在**最终控制方合并报表**中的账面价值份额，含最终控制方收购形成的商誉） | **购买法**：付出对价及取得的可辨认资产负债按**购买日公允价值** |
| 差额 | 调整**资本公积（资本溢价）**，不足依次冲减**盈余公积、未分配利润** | `合并成本 − 可辨认净资产公允价值份额`：**正差确认为商誉**，负差计入**营业外收入**（复核后） |
| 中介费用 | 计入**管理费用** | 计入**管理费用** |
| 合并报表 | 合并日需**恢复**被合并方合并前实现的留存收益（从资本公积转回）；合并利润表包含被合并方**整个报告期**的收入费用 | 购买日只编**合并资产负债表**；合并利润表只包含购买日**以后**被合并方的收入费用 |
| 或有对价 | 按或有事项准则判断是否确认预计负债/资产，差额调整**资本公积** | 符合资产/负债定义的按**购买日公允价值**计入合并成本；购买日后 **12 个月内**取得**购买日已存在情况**新证据的调整**商誉**，其余按金融工具/或有事项处理，不计入损益或计入损益视分类 |

## 第 27 章 合并财务报表

![合并报表：先调整、再抵销](/acc/acc-consolidation.svg)

### 27.1 合并范围以「控制」为基础

| 控制三要素 | 含义 |
| --- | --- |
| 拥有对被投资方的**权力** | 通过**表决权**或**实质性权利**（潜在表决权、决策权委托等）主导相关活动 |
| 因参与被投资方活动而享有**可变回报** | 回报随被投资方业绩而变化 |
| **有能力运用权力影响回报** | 权力与回报之间存在** linkages**（区分**主要责任人**与**代理人**，代理人不控制） |

| 豁免 | 内容 |
| --- | --- |
| **投资性主体** | 同时满足：①以向投资者提供**投资管理服务**为目的；②经营目的**仅为资本增值、投资收益或两者兼有**而持有投资；③**以公允价值**计量和评价几乎所有投资业绩。对**不为其投资活动提供相关服务**的子公司**不纳入合并**，按 FVTPL 计量；**提供相关服务**的子公司仍应合并 |

### 27.2 编制程序与四类抵销

| 步骤 | 内容 |
| --- | --- |
| ① 统一口径 | 统一**会计政策、会计期间、记账本位币**；对非同控子公司按**购买日公允价值**调整其个别报表 |
| ② 调整长投 | 将母公司对子公司的**成本法**结果**调整为权益法**（在合并工作底稿中，**不调整母公司个别账簿**） |
| ③ 抵销 | 长投↔所有者权益、投资收益↔利润分配、内部债权债务、内部交易未实现损益 |
| ④ 计算少数股东权益/损益 | 按**少数股东持股比例**计算；**逆流交易**未实现损益需在母公司与少数股东间**分摊** |

| 抵销类别 | 核心分录 |
| --- | --- |
| 长投 ↔ 子公司所有者权益 | 借：股本/实收资本、资本公积、盈余公积、未分配利润、商誉、其他综合收益　贷：长期股权投资、**少数股东权益** |
| 投资收益 ↔ 利润分配 | 借：投资收益（母公司）、**少数股东损益**、年初未分配利润　贷：提取盈余公积、对所有者的分配、年末未分配利润 |
| 内部债权债务 | 借：应付账款/应付票据/应付债券等　贷：应收账款/应收票据/债权投资等；同时抵销**坏账准备**与对应**递延所得税资产** |
| 内部商品交易 | 当期：借：营业收入　贷：营业成本、存货（未实现内部利润）；连续编报：借：年初未分配利润　贷：营业成本（上年未实现部分本期实现则调整） |
| 内部固定资产/无形资产交易 | 抵销原价中未实现损益，并**连续抵销**多计的折旧/摊销；期满清理当年改为调整**年初未分配利润与折旧费用** |


### 27.3 特殊交易与所得税影响

| 情形 | 处理 |
| --- | --- |
| 购买**少数股权**（不丧失控制权） | 个别报表按新增对价增加长投；合并报表中按**新增持股比例**计算应享有子公司自购买日持续计算的净资产份额，差额调整**资本公积（资本溢价）**，不足冲减留存收益 → **不产生商誉、不确认损益** |
| **不丧失控制权**处置部分股权 | 合并报表中处置价款与所处置净资产份额的差额**调整资本公积**，**不确认损益** |
| **丧失控制权**处置 | 剩余股权按**丧失控制权日公允价值重新计量**，`（处置对价 + 剩余股权公允价值）− 按原持股比例计算的原子公司净资产份额 − 商誉 + 原 OCI 等` 计入**投资收益**；原子公司相关 OCI 全部转入投资收益或留存收益 |
| 多次交易分步实现/分步处置 | 按「一揽子交易」判断：属于一揽子的作为**一项**交易处理，否则分别处理 |
| **所得税影响** | 内部交易抵销使集团**账面价值**改变而**计税基础**（个别报表口径）不变 → 按第 19 章确认**递延所得税资产/负债**，对应调整合并报表**所得税费用** |

## 第 28 章 每股收益

> **核心公式**：`基本每股收益 = 归属于普通股股东的当期净利润 ÷ 发行在外普通股的加权平均数`
> `发行在外普通股加权平均数 = 期初股数 + 当期新发股数 × 已发行时间 ÷ 报告期时间 − 当期回购股数 × 已回购时间 ÷ 报告期时间`

| 分子调整 | 归属于**普通股股东**的净利润＝净利润 − 优先股股利等（**累积优先股**股利无论是否宣告均扣除；**非累积**仅扣除已宣告部分） |
| --- | --- |
| 稀释 EPS 分子 | 基本 EPS 分子 + **可转换债券**本期已确认为费用的利息等的**税后影响额**（假设转换） |
| 稀释 EPS 分母 | 基本 EPS 分母 + **稀释性潜在普通股**转换为普通股的加权平均数 |

| 潜在普通股 | 稀释股数计算 |
| --- | --- |
| **可转换公司债券** | 假设转换增加的普通股股数（按转换比例），分子加回税后利息；**先算增量 EPS 与基本 EPS 比较**，只有具稀释性才纳入 |
| **认股权证、股份期权** | `增加的股数 = 拟行权认购股数 − 拟行权认购股数 × 行权价 ÷ 当期普通股平均市价`（国库券法） |
| 限制性股票（等待期内） | 按**资产负债表日尚未解锁**的限制性股票，比较假设解锁与按公允价值回购所需的股数，差额为稀释股数 |
| **稀释性判断** | 按**稀释程度从大到小**依次纳入，直到 EPS 不再下降（**反稀释**的潜在普通股一律排除） |

## 第 29 章 公允价值计量

| 项目 | 要点 |
| --- | --- |
| 定义 | **市场参与者**在**计量日**发生的**有序交易**中，出售一项资产所能收到或转移一项负债所需支付的价格（**脱手价格**） |
| 主要市场 / 最有利市场 | 优先使用**主要市场**（相关资产或负债交易量最大、活跃程度最高）；无主要市场时用**最有利市场**（考虑交易费用与运输费用后使出售资产收到的金额**最大化** / 转移负债支付的金额**最小化**）；**交易费用不属于公允价值调整项，运输费用属于** |
| 市场参与者 | 相互独立、熟悉情况、有能力且**自愿**（非强制清算）进行交易的买方和卖方 |

| 估值技术 | 说明 |
| --- | --- |
| **市场法** | 利用相同或类似资产/负债的**市场价格**及相关信息（如乘数法、矩阵定价） |
| **收益法** | 将未来金额（现金流、收入）折算为**现值**（现值技术、期权定价模型、多期超额收益法） |
| **成本法** | 反映当前**重置**该项资产服务能力所需的金额（现行重置成本，扣减物理/功能/经济贬值） |
| 选择 | 优先使用**可观察输入值最多**、与情况最相关的技术；变更估值技术按**会计估计变更**（未来适用）处理 |

| 层次 | 输入值 | 举例 |
| --- | --- | --- |
| **第一层次** | **活跃市场**上相同资产或负债**未经调整**的**报价**（最高优先级） | 交易所上市股票的收盘价 |
| **第二层次** | 除第一层次报价外**可观察**输入值（含活跃市场中类似资产报价、非活跃市场中相同或类似报价、利率曲线、隐含波动率等） | 债券估值、远期外汇 |
| **第三层次** | **不可观察**输入值（以市场参与者假设为基础、企业自身数据经调整） | 非上市股权、复杂衍生品、自建估值模型 |

> **层次取决于输入值而非估值技术**；存在不同层次输入值时，以**对整体计量有重大意义的最低层次**决定公允价值层次。

| 具体应用 | 要点 |
| --- | --- |
| 非金融资产 | 以**市场参与者**通过**最佳用途**（物理上可能、法律上允许、财务上可行）产生经济利益的能力为基础；企业**自用**与**出售给其他市场参与者**的最佳用途可能不同 |
| 负债与自身权益工具 | 假定在计量日**转移给市场参与者**，考虑**不履约风险**（含自身信用风险），且**不应包含**限制转移的条款影响 |
| 计量单元 | 按相关准则规定的**单项资产/负债或一组**确定；**不得**因企业持有大量相同头寸而作**大宗折价/溢价**调整 |

## 第 30 章 政府及民间非营利组织会计


### 30.1 政府会计：双功能、双基础、双报告

| 维度 | 预算会计 | 财务会计 |
| --- | --- | --- |
| 基础 | **收付实现制**（国务院另有规定的从其规定） | **权责发生制** |
| 要素 | **预算收入、预算支出、预算结余**（3 个） | **资产、负债、净资产、收入、费用**（5 个） |
| 等式 | `预算收入 − 预算支出 = 预算结余` | `资产 − 负债 = 净资产` |
| 报告 | **决算报告**（政府决算报告） | **财务报告**（资产负债表、收入费用表、现金流量表、附注） |
| 衔接 | 纳入部门预算管理的**现金收支**业务，在财务会计核算的**同时进行预算会计核算**（平行记账）；**不涉及现金收支**的业务仅作财务会计核算 |

| 特定业务 | 要点 |
| --- | --- |
| 财政拨款收支 | 财政**直接支付**：财务会计借「业务活动费用/库存物品等」贷「财政拨款收入」，预算会计借「事业支出」贷「财政拨款预算收入」；**授权支付**通过「零余额账户用款额度」核算，年末未使用额度**予以注销**（财政应返还额度） |
| 非财政拨款收支 | 事业收入、上级补助收入、附属单位上缴收入、经营收入等，按**收付实现制**确认预算收入 |
| 预算结转结余及分配 | 区分**结转资金**（当年预算已执行但未完成、下年继续按原用途使用）与**结余资金**（已完成或终止、剩余的）；按规定提取**专用基金**、缴纳所得税、提取职工福利基金后转入**非财政拨款结余分配** |
| 净资产 | **累计盈余、专用基金、权益法调整、本期盈余、本年盈余分配、无偿调拨净资产、以前年度盈余调整**等 |
| 资产业务 | 政府储备物资、公共基础设施、保障性住房、文物文化资产、**受托代理资产**等按特定规则计量；固定资产/无形资产**不计提减值**、按月计提折旧摊销 |


### 30.2 民间非营利组织会计

| 项目 | 要点 |
| --- | --- |
| 要素与等式 | 资产、负债、净资产、收入、费用；`资产 − 负债 = 净资产` |
| 净资产分类 | **限定性净资产**（受捐赠人/法律设置的时间或用途限制）、**非限定性净资产**；限制解除时由限定性转入非限定性 |
| **捐赠业务** | 按**公允价值**计量；附条件捐赠存在**需要偿还**的部分确认为**负债**；**劳务捐赠不予确认**（但应在附注披露）；**捐赠承诺（无条件）**在满足确认条件时确认 |
| **受托代理业务** | 组织仅起**中介**作用、无权力改变用途或受益人 → **确认受托代理资产与受托代理负债**（等额），**不确认收入与净资产**；这是与捐赠的核心区别 |
| 会费收入 | 按**权责发生制**在当期确认；预收以后年度会费确认为**预收账款** |
| 政府补助 | 与资产/收益相关分别处理；用于购建长期资产的通常确认为**限定性净资产**或递延收益 |
| 业务活动表 | 按**限定性 / 非限定性**分别列示收入、费用与净资产变动；**无利润表、无所有者权益变动表** |

| 27 | 永久性差异是否确认递延所得税 | **不确认**；只作当期纳税调整 |
| 28 | 免税合并商誉的递延所得税 | **不确认 DTL**（否则形成循环） |
| 29 | 非货币性资产交换账面价值基础 | **不确认损益**，按换出资产账面价值计量换入资产 |
| 30 | 债务重组债权人受让非金融资产的入账基础 | **放弃债权的公允价值 + 相关税费**（不是受让资产公允价值） |
| 31 | 外币非货币性项目期末是否调整 | 历史成本计量的**不调整**；公允价值计量的按**公允价值确定日**汇率 |
| 32 | 会计估计变更是否追溯 | **未来适用法**，不调整比较报表 |
| 33 | 折旧方法改变属于政策变更 | **会计估计变更** |
| 34 | 日后宣告分派现金股利 | **非调整事项**，不确认为资产负债表日负债，只披露 |
| 35 | 报告年度销售退回发生在日后期间 | **调整事项**，冲减报告年度收入成本 |
| 36 | 同一控制下合并利润表期间 | 包含被合并方**整个报告期**；非同控只含**购买日以后** |
| 37 | 购买少数股权是否产生商誉 | **不产生**，差额调整资本公积 |
| 38 | 送股/转增是否调整 EPS 分子 | **不调整分子**，只按调整后股数**重算所有列报期间分母** |
| 39 | 公允价值层次由什么决定 | 由**输入值层次**决定，不是估值技术；取**最低层次** |
| 40 | 民间非营利组织受托代理业务 | 确认**等额的受托代理资产与负债**，**不确认收入** |

> **小结**：会计的核心不是背分录，而是回答三个问题——**何时确认**（时点/时段、控制权、风险报酬）、**确认多少**（计量属性、公允价值、现值）、**进哪张表**（损益 / OCI / 权益、个别 / 合并）。把这三条主线串起来，30 章就是一个整体。
