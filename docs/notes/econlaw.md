## 第 1 章 法律基本原理

### 1.1 法的概念与特征（★）

法是由国家制定或认可并得到国家强制力保证实施的、反映由一定物质生活条件所决定的统治阶级意志的、赋予社会关系参加者权利与义务的社会规范的总称。

| 特征 | 要点 |
| --- | --- |
| 物质生活条件决定 | 法是统治阶级**整体意志**（非个别人/个别集团意志）；统治阶级不能任意立法，须服从经济条件 |
| 国家制定或认可 | 「制定」= 有权机关创制新规范；「认可」= 确认习惯、教义等既有规则具有法律效力；由此产生**权威性与统一性** |
| 国家强制力保证 | 以军队、警察、监狱等为后盾；但法的实施主要靠自觉守法和执行，强制力只在违法且应担责时动用 |
| 调整社会关系的行为规范 | 社会规范调整人与人关系；技术规范调整人与自然关系，但环保、食品安全、建筑质量等**社会技术规范**经国家制定或认可后也属法律规范 |
| 确定权利义务 | 权利、义务是法调整社会关系的基本表达形式；还包括国家机关依法执行公务时的**职权与职责** |

::: danger 易错 · 法与道德
法属**社会制度**范畴，道德属**社会意识形态**范畴；法强调权利义务平衡且由国家强制力保证实施，道德强调对他人和社会履行义务、靠舆论与内心信念维系。法是成文的道德、道德是内心的法律，但二者不能相互替代。
:::

### 1.2 法律体系与法的渊源（★★）

我国社会主义法律体系包含**七个法律部门**：宪法及宪法相关法、民法商法、行政法、经济法、社会法、刑法、诉讼与非诉讼程序法。

| 渊源 | 制定主体 | 效力与要点 |
| --- | --- | --- |
| 宪法 | 全国人大 | 根本大法，最高法律效力；一切法律、行政法规、地方性法规、规章均不得同宪法相抵触 |
| 法律 | 全国人大及其常委会 | 全国人大制定基本法律；常委会在闭会期间可作**部分补充和修改**，但不得同该法律的基本原则相抵触 |
| 行政法规 | 国务院 | 低于宪法和法律 |
| 地方性法规 | 地方人大及其常委会 | 不得与宪法、法律、行政法规相抵触；2023 年《立法法》修正对地方立法权限作了调整 |
| 部门规章 / 地方政府规章 | 国务院各部委 / 地方人民政府 | **不得设定减损公民、法人和其他组织权利或增加其义务的规范**；部门规章不得增加本部门权力、减少法定职责 |
| 司法解释 | 最高人民法院、最高人民检察院 | 应针对具体法律条文并符合立法目的；**其他审判、检察机关不得作出具体应用法律的解释** |

::: tip 教材名称辨析
本教材名为《经济法》，但这是「与市场经济活动相关的法律制度」的课程名称，**不是法律部门意义上**与民法商法、行政法并列的「经济法」部门。答题时不要据此判断法律部门归属。
:::

### 1.3 法律规范与法律关系（★★）

**法律规范逻辑结构**：假定（适用条件）→ 模式（可以 / 应当 / 禁止做什么）→ 后果（肯定式或否定式法律后果）。按行为模式分为授权性规范、命令性规范（「应当」「必须」）、禁止性规范（「不得」「禁止」）。

**法律关系三要素**：

| 要素 | 内容 |
| --- | --- |
| 主体 | 自然人（含个体工商户、农村承包经营户）、法人、非法人组织、国家（特定情形）；须同时具有**权利能力与行为能力** |
| 客体 | 物、行为、人格利益、智力成果（知识产权客体）、权利（如权利质权客体） |
| 内容 | 权利与义务；权利行使有界限，**不得滥用权利** |

**自然人民事行为能力**（高频客观题）：

| 类型 | 年龄 / 状态 | 效果 |
| --- | --- | --- |
| 完全民事行为能力 | ≥ 18 周岁；或 **≥ 16 周岁且以自己劳动收入为主要生活来源**（视为完全） | 可独立实施民事法律行为 |
| 限制民事行为能力 | ≥ 8 周岁的未成年人；不能完全辨认自己行为的成年人 | 可独立实施纯获利益或与其年龄、智力、精神健康状况相适应的行为；其他须法定代理人同意或追认 |
| 无民事行为能力 | < 8 周岁；完全不能辨认自己行为的成年人、未成年人 | 独立实施的民事法律行为**无效**，由法定代理人代理 |

**法律事实**：事件（不以当事人意志为转移，如出生、死亡、自然灾害、时效届满）与行为（以当事人意志为转移，含合法行为与违法行为）。

::: danger 易错 · 组织的能力
社会组织（法人、非法人组织）的权利能力与行为能力**同时产生、同时消灭、范围一致**，与自然人的「先有权利能力、后有行为能力」不同。
:::

### 1.4 全面依法治国与市场经济的法律调整（★）

- 坚持党的领导是社会主义法治的根本要求；社会主义市场经济本质上是**法治经济**。
- 到 2035 年，「基本建成法治国家、法治政府、法治社会」是发展总体目标之一。
- 《优化营商环境条例》要点：政务公开以公开为常态；**平等对待各类所有制和不同地区市场主体**；市场准入负面清单全国统一、各部门不得另设；目录清单之外的收费和保证金一律不得执行；营商环境评价不得影响市场主体正常生产经营、不得借评价牟利；行政强制措施应限定在必需范围内。

## 第 2 章 基本民事法律制度

### 2.1 民事法律行为概述（★★）

民事法律行为是民事主体通过**意思表示**设立、变更、终止民事法律关系的行为。核心是意思表示，不以是否合法为成立要件（合法与否影响效力）。

| 分类维度 | 类型与判断 |
| --- | --- |
| 意思表示数量 | 单方行为（撤销权行使、解除权行使、追认、遗嘱、捐助）、双方行为（合同）、多方行为（合伙协议、公司章程）、决议行为 |
| 是否需相对人 | 有相对人（合同、债务免除）与无相对人（遗嘱、抛弃所有权）；**并非所有单方行为都无相对人**——撤销权行使、追认等有相对人 |
| 成立要件 | 当事人、意思表示、标的；实践性行为（如定金合同、自然人借款）还须交付标的物 |
| 形式 | 书面、口头、其他形式（含推定与沉默，沉默仅在法律规定、当事人约定或符合交易习惯时视为意思表示） |

**意思表示生效**：有相对人的对话方式，相对人知道其内容时生效；非对话方式，到达相对人时生效；数据电文指定系统的进入该系统时生效，未指定的以相对人知道或应当知道进入其系统时生效。**撤回通知须在意思表示到达前或同时到达**。无相对人的意思表示，表示完成时生效（另有规定除外）。

::: tip 意思表示解释
有相对人的按所用词句，结合相关条款、行为性质与目的、习惯及诚信原则确定含义；无相对人的不能完全拘泥于词句，应探求行为人真实意思。
:::

### 2.2 民事法律行为的效力体系（★★★）

![民事法律行为的效力体系](/econlaw/el-civil-act.svg)

**有效要件**：行为人具有相应民事行为能力、意思表示真实、不违反法律行政法规的强制性规定且不违背公序良俗。当事人**超越经营范围**订立的合同，不得仅以超越经营范围为由认定无效。

| 效力类型 | 法定情形 | 法律后果 |
| --- | --- | --- |
| 无效 | 无民事行为能力人独立实施；虚假意思表示；恶意串通损害他人合法权益；违反强制性规定或违背公序良俗 | **自始、当然、确定无效**；法院/仲裁机构可主动认定；返还财产、折价补偿、赔偿损失 |
| 可撤销 | 重大误解；欺诈；胁迫；显失公平（一方利用对方处于危困状态、缺乏判断能力） | 撤销前有效；须由撤销权人请求**法院或仲裁机构**撤销；撤销后溯及行为开始时无效 |
| 效力待定 | 限制民事行为能力人超越能力范围实施；无权代理、超越代理权或代理权终止后代理 | 经法定代理人 / 被代理人追认后有效；拒绝追认则无效 |

**撤销权除斥期间**（不变期间，不适用中止、中断、延长）：

| 事由 | 起算 | 期间 |
| --- | --- | --- |
| 重大误解 | 知道或应当知道撤销事由 | **90 日** |
| 欺诈、显失公平 | 知道或应当知道撤销事由 | **1 年** |
| 胁迫 | 胁迫行为终止之日 | **1 年** |
| 所有事由的最长期间 | 民事法律行为发生之日 | **5 年** |

::: danger 易错 · 无效 vs 可撤销
无效行为任何人可主张、法院可主动认定、无时间限制；可撤销行为在撤销前有效，仅撤销权人可主张，且受除斥期间限制，逾期终局有效。另外「违反强制性规定」并非一律无效——若该强制性规定不导致无效（如旨在维护税收征管、对方无审查能力、认定无效显失公平），合同仍可有效。
:::

### 2.3 代理制度（★★★）

| 制度 | 要点 |
| --- | --- |
| 法定代理 | 依法律规定产生，主要服务于无 / 限制民事行为能力人 |
| 委托代理 | 依被代理人授权产生；授权委托书应载明代理人、事项、权限、期限并由被代理人签名盖章 |
| 无权代理 | 无代理权、超越代理权、代理权终止后仍实施；未经追认对被代理人不发生效力；相对人可催告**自收到通知之日起 30 日内**追认，未作表示视为拒绝；善意相对人有撤销权 |
| 表见代理 | 行为人无代理权但相对人**有理由相信**有代理权（如持有盖章空白合同书、长期交易惯例、被代理人明知而未否认），且相对人善意无过失 → 代理行为**有效**，被代理人承担责任后可向行为人追偿 |
| 自己代理 / 双方代理 | 原则上禁止；经被代理人同意或追认，或不损害被代理人利益时可有效 |
| 复代理 | 须经被代理人同意或追认；紧急情况下为保护被代理人利益可不经同意转委托 |
| 违法代理 | 代理人知道或应当知道代理事项违法仍实施，或被代理人知道代理行为违法未反对的，**双方承担连带责任** |

### 2.4 诉讼时效制度（★★★）

| 项目 | 规则 |
| --- | --- |
| 普通期间 | **3 年**，自权利人知道或应当知道权利受损害**且知道义务人**之日起算 |
| 最长保护期 | 自权利受损害之日起 **20 年**（不适用中止、中断；特殊情况法院可决定延长） |
| 分期履行 | 同一债务分期履行的，自**最后一期**履行期限届满之日起算 |
| 无 / 限制民事行为能力人对其法定代理人的请求权 | 自法定代理终止之日起算 |
| 未成年人遭性侵的损害赔偿请求权 | 自受害人**年满 18 周岁**之日起算 |
| 中止 | 时效期间**最后 6 个月内**发生不可抗力、无 / 限制民事行为能力人无法定代理人等障碍；自中止原因消除之日起满 **6 个月**届满 |
| 中断 | 权利人向义务人提出履行请求、义务人同意履行、提起诉讼或仲裁等；**重新起算** |
| 不适用 | 请求停止侵害、排除妨碍、消除危险；不动产物权及登记的动产物权的权利人请求返还财产；请求支付抚养费、赡养费、扶养费；依法不适用的其他请求权 |

::: danger 易错 · 诉讼时效 vs 除斥期间
诉讼时效届满仅消灭**胜诉权**（义务人可抗辩，债权本身不消灭），可中止 / 中断 / 延长，法院不得主动适用；除斥期间届满消灭的是**撤销权、解除权等形成权本身**，为不变期间，法院应主动审查。
:::

## 第 3 章 物权法律制度

### 3.1 物权法律制度概述（★★）

物权是权利人依法对特定的物享有**直接支配和排他**的权利，包括所有权、用益物权和担保物权。2020 年《民法典》颁布、2021 年 1 月 1 日起施行后，《物权法》同时废止，相关司法解释同步更新。

| 基本原则 | 内容 |
| --- | --- |
| 物权法定 | **种类法定 + 内容法定**：不得创设法律未规定的物权类型，也不得设定与法定物权相异的内容；司法解释与司法判例亦不得创设具有物权效力的权利类型 |
| 一物一权 | 一物之上只能成立一个所有权；但可有数个互不冲突的他物权（如同一物上多个顺位抵押权） |
| 公示公信 | 不动产以登记、动产以交付为公示方法；善意信赖公示而交易者受保护 |

::: danger 易错 · 物权法定违反的后果
约定「叔父对祖宅有优先购买权」因违反**种类法定**而不产生物权效力，叔父不能主张买卖无效、要求买受人返还房屋；但该约定在**合同法上仍可能有效**，可据此请求违约赔偿。设定「手表质权但不转移占有」因违反内容法定而无效。
:::

### 3.2 物权变动（★★★）

![物权变动规则与担保物权体系](/econlaw/el-property.svg)

| 情形 | 生效规则 |
| --- | --- |
| 不动产物权设立、变更、转让、消灭 | **登记生效**；未经登记不发生物权效力，但**不影响合同效力**（区分原则） |
| 土地承包经营权、地役权 | 合同生效时设立，**未经登记不得对抗善意第三人** |
| 动产物权 | **交付生效**（现实交付、简易交付、指示交付、占有改定） |
| 船舶、航空器、机动车等特殊动产 | 交付即变动，**未经登记不得对抗善意第三人** |
| 动产抵押 | 抵押合同生效时设立，未经登记不得对抗善意第三人 |
| 因人民法院 / 仲裁机构法律文书、征收决定、继承、合法建造拆除等 | **无需登记或交付**，法律文书 / 征收决定生效、继承开始、事实行为成就时即发生效力；但再行处分时须先办理登记 |

**不动产登记配套制度**：

| 制度 | 关键期限 / 效果 |
| --- | --- |
| 更正登记 | 权利人、利害关系人认为登记簿记载错误可申请；有证据证明错误或权利人书面同意更正的，登记机构应予更正 |
| 异议登记 | 申请人自异议登记之日起 **15 日内不起诉，异议登记失效**；异议登记不当造成权利人损害的，权利人可请求赔偿 |
| 预告登记 | 为保障将来实现物权；**自能够进行不动产登记之日起 90 日内未申请登记的，预告登记失效**；预告登记后未经权利人同意处分该不动产的，不发生物权效力 |
| 登记错误赔偿 | 因登记错误造成他人损害的，登记机构承担赔偿责任，之后可向造成错误的人追偿 |

### 3.3 所有权与共有（★★）

**共有**：按份共有（按份额享有权利、承担义务）与共同共有（基于夫妻、家庭等共同关系，不分份额）。

| 事项 | 规则 |
| --- | --- |
| 处分共有物 / 重大修缮、变更性质或用途 | 按份共有须经**占份额 2/3 以上**的按份共有人同意；共同共有须全体共同共有人同意（另有约定除外） |
| 共有物分割 | 可分割且不减损价值的实物分割；否则折价或拍卖、变卖价款分割；因分割造成其他共有人损害的应赔偿 |
| 按份共有人转让份额 | 其他共有人有**同等条件下的优先购买权**；共有份额在共有人之间内部转让、因继承遗赠等非交易方式转让时，不得主张优先购买 |
| 优先购买权行使期限 | 通知载明期间的按该期间（不得短于通知送达之日起 **15 日**）；未载明的为知道或应当知道最终同等条件之日起 **15 日** |
| 对外债务 | 共有人承担连带债务，超出自己份额清偿者有权向其他共有人追偿 |

**善意取得**（所有权、其他物权均可适用）：受让人**善意**（不知且不应知转让人无处分权）+ **合理价格**转让 + 已**登记或交付**（依标的物类型）。符合三要件即取得所有权，原所有权人可向无处分权人请求赔偿损失。

::: danger 易错 · 善意取得的例外
盗赃物、遗失物等**脱手物**原则上不适用善意取得，原权利人自知道或应当知道受让人之日起 **2 年内**有权请求返还；受让人通过拍卖或向具有经营资格的经营者购得的，原权利人须支付受让人所付费用。
:::

### 3.4 用益物权（★★）

| 类型 | 要点 |
| --- | --- |
| 土地承包经营权 | 合同生效时设立，登记对抗；耕地承包期 **30 年**（届满再延长 30 年）、草地 30~50 年、林地 30~70 年 |
| 建设用地使用权 | 出让 / 划拨；**登记生效**；住宅建设用地使用权期限届满自动续期 |
| 宅基地使用权 | 一户一宅，原则上不得单独抵押、不得向非本集体成员转让 |
| 居住权 | 以**合同或遗嘱**设立，须**登记生效**；原则上无偿、不得转让继承；设立居住权的住宅不得出租（另有约定除外） |
| 地役权 | 合同生效时设立，**登记对抗**；需役地转让时地役权一并转让，供役地转让时地役权对受让人有约束力（已登记则可对抗） |

### 3.5 担保物权（★★★）

| 项目 | 抵押权 | 质权 | 留置权 |
| --- | --- | --- | --- |
| 是否转移占有 | 不转移 | **转移占有 / 交付** | 债权人已**合法占有**债务人动产 |
| 设立 | 不动产登记生效；动产合同生效设立、登记对抗 | 动产质权交付时设立；权利质权有凭证交付、无凭证登记 | **法定**担保物权，符合要件即成立 |
| 客体 | 不动产、动产、权利 | 动产、可转让权利 | 仅限于**动产** |
| 典型考点 | 禁止抵押：土地所有权、宅基地 / 自留地等集体所有土地使用权（法律另有规定除外）、学校医院等公益设施、所有权权属不明或有争议的财产、依法被查封扣押监管的财产 | 流质条款无效：债务履行期届满前约定「到期不清偿则质押财产归债权人所有」的，只能依法就质押财产优先受偿 | 须**同一法律关系**（企业之间除外）；债权已届清偿期；给债务人 **≥ 60 日**履行宽限期（鲜活易腐等不易保管的动产除外） |

**同一物上多个担保物权的清偿顺序**：留置权 > 已登记抵押权（按登记先后）/ 未登记抵押权（按债权比例）> 质权（与未登记抵押权按设立先后）；动产抵押担保的主债权范围内，正常经营活动中已支付合理价款并取得抵押财产的买受人，抵押权人不得对抗（**正常经营买受人规则**）。

## 第 4 章 合同法律制度

### 4.1 合同基本理论与订立（★★）

《民法典》合同编共 19 章 526 条，2021 年 1 月 1 日起施行，继承并发展了 1999 年《合同法》。合同**相对性**是原则，例外包括：第三人利益合同、代位权与撤销权、买卖不破租赁、建设工程施工合同中实际施工人向发包人主张权利、单式联运区段承运人与总承运人连带责任等。

| 环节 | 规则 |
| --- | --- |
| 要约 | 内容**具体确定** + 表明经受要约人承诺即受约束；与要约邀请（拍卖公告、招标公告、招股说明书、债券募集办法、基金招募说明书、商业广告等）区分，商业广告内容符合要约条件的可构成要约 |
| 要约生效 | 对话方式：相对人知道内容时；非对话方式：到达相对人时；数据电文指定系统的进入系统时生效 |
| 要约撤回 | 撤回通知须在要约**到达之前或同时**到达 |
| 要约撤销 | 撤销意思表示须在受要约人作出承诺前到达；**不得撤销**：已确定承诺期限或明示不可撤销、受要约人有理由认为不可撤销并已为履行合同作合理准备 |
| 要约失效 | 被拒绝、被依法撤销、承诺期限届满未承诺、受要约人对内容作**实质性变更** |
| 承诺 | 由受要约人向要约人作出，在承诺期限内到达；以信件 / 电报作出的，承诺期限自信件载明日期或电报交发之日起算 |
| 承诺内容 | 对标的、数量、质量、价款或报酬、履行期限地点方式、违约责任、争议解决方法等的变更属**实质性变更**，构成新要约；非实质性变更除要约人及时反对或要约表明不得变更外，承诺有效 |
| 迟到承诺 | 超过承诺期限发出，或期限内发出但通常情形不能及时到达 → 新要约（要约人及时通知有效除外）；期限内发出且通常能及时到达、因其他原因迟到的，**除要约人及时通知不接受外，承诺有效** |
| 合同成立 | 承诺生效时成立；采用书面形式但一方已履行主要义务、对方接受时合同成立；法院能确定当事人名称、标的和数量的，一般认定合同成立 |

**格式条款**：提供方应遵循公平原则、以合理方式提示免除或减轻其责任等与对方有重大利害关系的条款并按要求说明；不合理免除或减轻自身责任、加重对方责任、限制对方主要权利，或排除对方主要权利的条款**无效**；对格式条款有两种以上解释的，作出**不利于提供方**的解释；格式条款与非格式条款不一致的，采用非格式条款。

::: tip 缔约过失责任
适用于合同**未成立、未生效、被撤销或无效**的情形：假借订立合同恶意磋商、故意隐瞒与订立合同有关的重要事实或提供虚假情况、泄露或不正当使用订立过程中知悉的商业秘密、其他违背诚信原则的行为。赔偿的是**信赖利益**，区别于违约责任的履行利益。
:::

### 4.2 合同效力與履行（★★★）

- **依法需办理批准手续生效**的合同，未办批准前合同未生效，但**报批义务条款及相关条款独立生效**；负有报批义务的一方不履行，对方可请求其承担违反该义务的责任。
- 法人的法定代表人或非法人组织负责人**超越权限**订立合同，除相对人知道或应当知道其超越权限外，该代表行为有效，合同对法人 / 非法人组织发生效力。
- **超越经营范围**订立的合同，不得仅以超越经营范围为由认定无效；应依《民法典》总则编与合同编判断。

**三大抗辩权**：

| 抗辩权 | 适用条件 |
| --- | --- |
| 同时履行抗辩权 | 双方互负债务、**没有先后履行顺序**，一方未履行或履行不符合约定，另一方有权拒绝其相应履行请求 |
| 先履行抗辩权 | 互负债务**有先后顺序**，先履行一方未履行或履行不符合约定，后履行一方有权拒绝其相应履行请求 |
| 不安抗辩权 | 应先履行一方有确切证据证明对方经营状况严重恶化、转移财产抽逃资金逃避债务、丧失商业信誉、丧失或可能丧失履行能力 → 可**中止履行并通知对方**；对方提供适当担保时应恢复履行；对方在合理期限内未恢复履行能力且未提供担保的，可解除合同 |

**情势变更**：合同成立后基础条件发生当事人在订立时无法预见、不属于商业风险的重大变化，继续履行对当事人一方明显不公平的，受不利影响方可请求**重新协商**；合理期限内协商不成，可请求法院或仲裁机构变更或解除合同。

### 4.3 合同的保全与担保（★★★）

| 制度 | 行使条件与效果 |
| --- | --- |
| 代位权 | 债务人怠于行使其债权或与该债权有关的从权利，影响债权人到期债权实现；债权人以**自己名义**向相对人请求履行，范围以到期债权为限；相对人对债务人的抗辩可向债权人主张 |
| 撤销权 | 债务人无偿处分财产权益（放弃债权、无偿转让等）或恶意延长到期债权履行期，影响债权实现 → 债权人可请求撤销；以明显不合理低价转让 / 高价受让、为他人债务提供担保且相对人知道或应当知道的，亦可撤销 |
| 撤销权期限 | 自债权人**知道或应当知道撤销事由之日起 1 年**内行使；自债务人行为发生之日起 **5 年**内未行使的，撤销权消灭 |

**保证**（高频易错）：

| 项目 | 规则 |
| --- | --- |
| 保证方式 | 一般保证（保证人享有**先诉抗辩权**）与连带责任保证 |
| 方式未约定或约定不明 | **按一般保证承担**（《民法典》第 686 条，与旧《担保法》推定连带保证相反，务必更新记忆） |
| 保证期间未约定或约定不明 | 为主债务履行期限届满之日起 **6 个月**；约定早于或等于主债务履行期的，视为没有约定 |
| 一般保证的债权人 | 须在**保证期间内**对债务人提起诉讼或仲裁；连带保证须在保证期间内请求保证人承担保证责任，否则保证人免责 |
| 保证期间性质 | **除斥期间**，不发生中止、中断、延长 |
| 定金 | 数额由当事人约定，但不得超过主合同标的额的 **20%**，超过部分不产生定金效力；给付方违约不得请求返还，收受方违约双倍返还；既约定违约金又约定定金的，守约方**择一适用** |

### 4.4 合同变更、转让与终止（★★）

- **债权转让**：通知债务人即对债务人生效（未通知对债务人不生效），**无需债务人同意**；从权利一并转让；债务人对让与人的抗辩、符合条件的抵销权可向受让人主张。
- **债务承担**：债务人将债务全部或部分转移给第三人的，**须经债权人同意**；新债务人可主张原债务人对债权人的抗辩。
- **合同解除**：约定解除、协商一致解除、法定解除（不可抗力致不能实现目的、预期违约、迟延履行经催告后合理期限仍未履行、其他违约致不能实现目的）；不定期持续履行合同可随时解除但应在合理期限前通知。
- **抵销**：法定抵销要求双方互负债务、标的物**种类品质相同**、债务已届清偿期（主动债权），依性质 / 约定 / 法律规定不得抵销的除外；抵销不得附条件或附期限，**通知到达对方时生效**。
- **提存**：债权人无正当理由拒绝受领、下落不明、死亡未确定继承人 / 丧失民事行为能力未确定监护人等，债务人可提存；标的物提存后**毁损灭失风险由债权人承担**，提存费用由债权人负担；债权人自提存之日起 **5 年**内不领取的，提存物扣除费用后归国家所有。

### 4.5 违约责任与典型合同（★★★）

| 规则 | 要点 |
| --- | --- |
| 继续履行 | 金钱债务无例外；非金钱债务法律上或事实上不能履行、债务标的不适于强制履行或履行费用过高、债权人在合理期限内未请求履行的除外 |
| 损失赔偿 | 相当于因违约造成的损失，包括合同履行后可获得的利益，但不得超过违约方**订立合同时预见到或应当预见到的**损失；守约方负有减损义务 |
| 违约金调整 | 约定违约金**低于**损失的可请求增加；**过分高于**损失（司法实践通常以超过损失 30% 为参考）的可请求适当减少 |
| 不可抗力 | 根据影响程度部分或全部免责（金钱债务迟延履行不因不可抗力免责）；迟延履行后发生不可抗力的，不免除责任；应及时通知并在合理期限内提供证明 |
| 违约责任与侵权责任竞合 | 受损害方有权**择一**请求 |

**典型合同要点**：

| 合同 | 关键规则 |
| --- | --- |
| 买卖 | 标的物毁损灭失风险**交付前由出卖人、交付后由买受人**承担（法律另有规定或当事人另有约定除外）；出卖人按约定交由承运人运输的在途标的物，风险自合同成立时由买受人承担；检验期间 / 合理期间内通知瑕疵，最长不超过收到标的物之日起 **2 年**（有质量保证期的适用质量保证期） |
| 租赁 | 租赁期限不得超过 **20 年**，超过部分无效；**6 个月以上**的租赁应采用书面形式，未采用且无法确定期限的视为不定期租赁；**买卖不破租赁**；承租人同等条件下有优先购买权（出租人出卖前应在合理期限内通知） |
| 赠与 | 一般赠与在权利转移前可撤销；**经公证或具有救灾、扶贫、助残等公益道德义务性质**的赠与合同不可撤销；法定撤销权自知道或应当知道撤销事由之日起 **1 年**内行使 |
| 借款 | 自然人之间借款合同**自提供借款时成立**（实践合同）；未约定利息或约定不明的视为**无息**；禁止高利放贷 |
| 承揽 | 承揽人应自己完成主要工作（另有约定除外）；定作人**随时解除**承揽合同，造成承揽人损失的应赔偿 |
| 建设工程 | 禁止发包人肢解发包、承包人转包与违法分包；实际施工人可突破相对性向发包人在**欠付工程款范围内**主张权利；建设工程价款就该工程折价或拍卖价款享有**优先受偿权** |

## 第 5 章 合伙企业法律制度

### 5.1 合伙企业概述（★★）

合伙企业是自然人、法人和其他组织依法在中国境内设立的**普通合伙企业**（全体普通合伙人承担无限连带责任）与**有限合伙企业**（至少 1 名普通合伙人承担无限连带责任 + 有限合伙人以认缴出资额为限承担责任）。

| 要点 | 规则 |
| --- | --- |
| 法律基础 | 《合伙企业法》（1997 年通过、2006 年修订）；登记依《市场主体登记管理条例》（2022 年 3 月 1 日施行） |
| 设立 | 须依法登记；合伙协议须**全体合伙人协商一致、以书面形式订立**；合伙人为自然人须具有完全民事行为能力 |
| 不得成为普通合伙人 | **国有独资公司、国有企业、上市公司、公益性的事业单位和社会团体**（但可作为有限合伙人） |
| 登记事项 | 名称、合伙类型、经营范围、主要经营场所、出资额、执行事务合伙人等；合伙协议、认缴或实缴出资数额 / 期限 / 方式应备案 |
| 变更登记 | 自作出变更决议、决定或法定变更事项发生之日起 **30 日内**申请 |
| 歇业 | 最长不得超过 **3 年**；歇业期间开展经营活动的视为恢复营业并应公示 |
| 虚假登记 | 撤销登记公示期 **45 日**；直接责任人自登记被撤销之日起 **3 年内**不得再次申请合伙企业登记 |

### 5.2 普通合伙企业（★★★）

| 事项 | 规则 |
| --- | --- |
| 出资 | 可用货币、实物、知识产权、土地使用权或其他财产权利，也可用**劳务**（评估办法由全体合伙人协商确定）；以非货币财产出资需评估的，由全体合伙人协商确定或委托法定评估机构 |
| 合伙财产 | 合伙人的出资、以合伙企业名义取得的收益等为合伙财产；**清算前不得请求分割**，除非本法另有规定 |
| 财产份额转让 | 向合伙人以外的人转让须**全体合伙人一致同意**（合伙协议另有约定除外）；同等条件下其他合伙人有优先购买权；内部转让通知其他合伙人即可 |
| 财产份额出质 | 须经**全体合伙人一致同意**；未经同意的行为无效，由此给善意第三人造成损失的由行为人依法赔偿 |
| 事务执行 | 全体合伙人共同执行，或委托 1 名 / 数名合伙人执行；执行事务合伙人应定期报告；其他合伙人有监督权、查阅账簿权、异议权与撤销委托权 |
| 需全体一致同意 | 改变名称、改变经营范围 / 主要经营场所、处分不动产或知识产权等财产权利、以合伙企业名义为他人提供担保、聘任合伙人以外的人担任经营管理人员（合伙协议另有约定除外） |
| 损益分配 | 按合伙协议约定 → 协商 → **按实缴出资比例** → 平均分配 / 分担；**合伙协议不得约定将全部利润分配给部分合伙人或由部分合伙人承担全部亏损** |
| 债务清偿 | 先以**合伙企业全部财产**清偿；不足部分由全体普通合伙人承担**无限连带责任**；合伙人超出自己份额清偿后有权向其他合伙人追偿 |
| 与合伙人个人债务 | 合伙人个人负债，债权人**不得代位行使**该合伙人在合伙企业中的权利（如事务执行权），也不得直接以债权抵销其对合伙企业的债务；但可申请法院强制执行该合伙人的财产份额（其他合伙人有优先购买权） |
| 入伙 | 除合伙协议另有约定外须**全体合伙人一致同意**并订立书面入伙协议；新合伙人对**入伙前**债务承担无限连带责任 |
| 退伙 | 自愿退伙（约定事由、全体同意、发生难以继续参加的事由、其他合伙人严重违约）、当然退伙（死亡、丧失偿债能力、被吊销执照等）、除名退伙（经其他合伙人一致同意）；退伙人对**退伙前原因**发生的债务承担无限连带责任 |
| 特殊普通合伙 | 以专业知识和专门技能提供有偿服务的专业服务机构（如会计师事务所）；一个合伙人因**故意或重大过失**造成合伙企业债务的，由其承担无限责任或无限连带责任，其他合伙人以财产份额为限承担责任；非因故意重大过失的债务仍由全体承担无限连带责任 |

::: danger 易错 · 会计师事务所责任
特殊普通合伙中，只有「故意或重大过失」致债的合伙人才单独承担无限责任，其余合伙人有限责任；但合伙企业的**执业风险基金、职业保险**仍应先用于偿付。一般过失造成的债务，全体合伙人仍承担无限连带责任。
:::

### 5.3 有限合伙企业（★★★）

| 项目 | 普通合伙人 | 有限合伙人 |
| --- | --- | --- |
| 人数 | 有限合伙企业由 **2~50 个**合伙人设立，至少应有 1 个普通合伙人 | 同左；仅剩有限合伙人的应解散，仅剩普通合伙人的转为普通合伙企业 |
| 责任 | 无限连带责任 | 以**认缴的出资额**为限承担责任 |
| 出资 | 可以劳务出资 | **不得以劳务出资** |
| 事务执行 | 执行事务、对外代表企业 | **不执行合伙事务、不得对外代表**；但参与决定普通合伙人入伙退伙、对企业经营管理提出建议、参与选择承办审计业务的会计师事务所、获取经审计的财务会计报告、对侵犯权益行为主张权利或提起诉讼等**不视为执行合伙事务** |
| 竞业与交易 | 不得自营或同他人合作经营与本企业相竞争的业务；除协议另有约定外不得同本企业进行交易 | **可以**自营或同他人合作经营竞争业务，也可同本企业进行交易（合伙协议另有约定除外） |
| 财产份额出质 | 须全体合伙人一致同意 | **可以**出质（合伙协议另有约定除外） |
| 表见普通合伙人 | — | 第三人有理由相信有限合伙人为普通合伙人并与其交易的，该有限合伙人**对该笔交易承担与普通合伙人同样的责任** |
| 入伙 / 退伙 | 入伙对入伙前债务承担无限连带责任 | 入伙以认缴出资额为限对**入伙前**债务承担责任；退伙对**退伙前原因**发生的债务，以其退伙时从企业取回的财产承担责任 |

### 5.4 解散与清算（★★）

解散事由：合伙期限届满全体决定不再经营、合伙协议约定的解散事由出现、全体合伙人决定解散、合伙人不具备法定人数满 **30 日**、合伙协议约定的合伙目的已实现或无法实现、依法被吊销营业执照责令关闭或撤销等。

清算人由**全体合伙人**担任；经全体合伙人过半数同意，可自解散事由出现之日起 **15 日内**指定 1 名或数名合伙人 / 委托第三人担任；逾期未确定的，债权人可申请法院指定。清算顺序：支付清算费用 → 职工工资、社会保险费用、法定补偿金 → 缴纳所欠税款 → 清偿债务 → 按约定 / 实缴出资比例 / 平均分配剩余财产。

::: tip 注销后责任
合伙企业注销后，原**普通合伙人**对合伙企业存续期间的债务仍应承担无限连带责任；有限合伙人以取回财产为限，一般不再承担。
:::

## 第 6 章 公司法律制度

### 6.1 公司概述与基本制度（★★★）

《公司法》1993 年通过、1994 年 7 月 1 日施行，最近一次全面修订由 2023 年 12 月 29 日十四届全国人大常委会第七次会议通过，**自 2024 年 7 月 1 日起施行**，本笔记按新法表述。

| 项目 | 有限责任公司 | 股份有限公司 |
| --- | --- | --- |
| 股东人数 | **1~50 人** | 发起人 1~200 人，其中**半数以上在中国境内有住所**（新法已允许 1 人发起设立） |
| 资本 | 注册资本 = 全体股东**认缴出资额** | 划分为等额股份；发起设立时注册资本为已发行股份的股本总额 |
| 责任 | 股东以认缴出资额为限，公司以全部财产独立承担责任 | 股东以认购股份为限 |
| 设立方式 | 发起设立 | 发起设立或**募集设立** |
| 股权 / 股份凭证 | 出资证明书 + 股东名册（**不是有价证券**） | 股票（纸面或电子簿记形式） |

**法人人格否认**：公司股东滥用公司法人独立地位和股东有限责任逃避债务，严重损害债权人利益的，应当对公司债务承担**连带责任**；股东利用其控制的两个以上公司实施前述行为的，各公司应对任一公司的债务承担连带责任（横向否认）；一人有限责任公司的股东不能证明公司财产独立于自己财产的，也承担连带责任。

::: danger 易错 · 新公司法五项高频变化
① 全体股东认缴出资须自公司成立之日起 **5 年内缴足**（法律、行政法规另有规定的从其规定）；② 公司不能清偿到期债务时，公司或已到期债权的债权人有权要求**已认缴但未届缴资期限的股东提前缴纳出资**（加速到期）；③ 董事会内可设**审计委员会**行使监事会职权，设审计委员会的可不设监事会 / 监事；④ 法定代表人由**代表公司执行公司事务的董事或经理**担任；⑤ 有限公司股东向外转让股权**不再要求「其他股东过半数同意」**（详见 6.5）。
:::

**出资形式**：货币、实物、知识产权、土地使用权、股权、债权等可依法转让的非货币财产（须评估作价，不得高估或低估）；**不得以劳务、信用、自然人姓名、商誉、特许经营权或设定担保的财产出资**。

**公司对外投资与担保**：公司可向其他企业投资，但除法律另有规定外不得成为对所投资企业债务承担**连带责任**的出资人（故国有独资公司、国有企业、上市公司不得成为普通合伙人）。为公司股东或实际控制人提供担保，须经**股东会决议**，该股东或受实际控制人支配的股东不得参加表决，由出席会议的其他股东所持**表决权过半数**通过。

### 6.2 公司组织机构（★★★）

![公司组织机构与决议规则](/econlaw/el-company.svg)

| 机构 | 组成与要点 |
| --- | --- |
| 股东会 | 权力机构；有限公司首次会议由出资最多的股东召集主持；定期会议按章程，**召开前 15 日通知**全体股东（章程另有约定或全体股东另有约定除外）；代表 **1/10 以上表决权**的股东、**1/3 以上**董事或监事会提议应召开临时会议 |
| 董事会 | 成员 **≥ 3 人**；规模较小或股东人数较少的公司可设 **1 名董事**（不设董事会），该董事可兼任经理；两个以上的国有出资公司可设外部董事；董事会决议须**全体董事过半数**通过 |
| 审计委员会 / 监事会 | 有限公司、股份公司均可在董事会中设置由董事组成的审计委员会行使监事会职权；**设审计委员会的可不设监事会或监事**；监事会成员 ≥ 3 人，含职工代表（比例 ≥ 1/3）且**董事、高管不得兼任监事** |
| 经理 | 由董事会决定聘任或解聘，对董事会负责；可依章程规定担任法定代表人 |
| 法定代表人 | 由代表公司执行公司事务的董事或经理担任；**担任法定代表人的董事或经理辞任的，视为同时辞去法定代表人**；法定代表人以公司名义从事民事活动的法律后果由公司承受，公司不得以章程或股东会限制对抗善意相对人 |

**决议规则**：

| 事项 | 通过标准 |
| --- | --- |
| 股东会普通决议 | 代表**过半数表决权**的股东通过（章程可规定更高比例） |
| 股东会特别决议 | 代表 **2/3 以上表决权**的股东通过：修改章程、增加或减少注册资本、公司合并 / 分立 / 解散 / 变更公司形式 |
| 有限公司表决权 | 按**出资比例**行使，章程另有规定的除外；「出资比例」是实缴还是认缴法无明文，章程宜明确 |
| 股份公司表决权 | 所持每一股份有一表决权（类别股除外），公司持有的本公司股份**没有表决权** |
| 累积投票制 | 股份公司选举董事、监事可依章程或股东会决议实行（控股股东控股比例 ≥ 30% 的应当实行，以充分反映中小股东意见） |
| 决议瑕疵 | 内容违反法律行政法规的**无效**；会议召集程序、表决方式违反法律行政法规或章程，或内容违反章程的，可自决议作出之日起 **60 日内**请求法院撤销（轻微瑕疵且无实质影响的不予撤销）；未召开会议 / 未表决等情形决议**不成立** |

### 6.3 股份有限公司的股份发行与转让（★★★）

| 事项 | 规则 |
| --- | --- |
| 同股同权 | 同类别每一股份具有同等权利，同次发行的同类别股份发行条件与价格相同，认购人每股支付相同价额 |
| 授权资本制 | 公司章程或股东会可**授权董事会在 3 年内决定发行不超过已发行股份 50% 的股份**，该董事会决议须经**全体董事 2/3 以上**通过；以非货币财产作价出资的仍须股东会决议，不得授权董事会 |
| 公开发行 | 须经国务院证券监督管理机构**注册**，公告招股说明书并附公司章程；由证券公司承销、银行代收股款 |
| 转让限制 | 股东转让股份应在依法设立的证券交易场所或按国务院规定的其他方式进行；**公开发行股份前已发行的股份，自上市交易之日起 1 年内不得转让** |
| 董监高转让限制 | 任职期间每年转让不得超过所持本公司同类股份总数的 **25%**；所持股份自上市之日起 1 年内不得转让；**离职后半年内**不得转让；另受窗口期限制（年报、半年报公告前 15 日内，季报、业绩预告、快报公告前 5 日内，重大事项发生至依法披露后 2 个交易日内等不得买卖） |
| 股东会会议前 | 召开股东会前 **20 日内**或决定分配股利的**基准日前 5 日内**，不得变更股东名册 |
| 公司回购本公司股份 | 减资回购须自收购之日起 **10 日内注销**；与持有本公司股份的其他公司合并、股东对合并分立决议持异议要求回购的，应在 **6 个月内**转让或注销；用于员工持股 / 股权激励、可转债、维护公司价值及股东权益而回购的，合计持有不得超过已发行股份总数的 **10%**，并应在 **3 年内**转让或注销；**公司不得接受本公司的股份作为质权标的** |

### 6.4 有限责任公司股权转让与国家出资公司（★★★）

::: danger 易错 · 新法已删除「过半数同意」
旧《公司法》要求股东向外转让股权须经其他股东**过半数同意**；**2024 年 7 月 1 日起施行的新《公司法》第 84 条已删除该要件**。现行规则：股东向股东以外的人转让股权，只需将转让的**数量、价格、支付方式和期限**等事项书面通知其他股东；其他股东在同等条件下有优先购买权，自接到书面通知之日起 **30 日内**未答复视为放弃；两个以上股东主张的，协商确定比例，协商不成按转让时各自出资比例行使。章程另有规定的从其规定。
:::

**异议股东股权回购请求权**（有限公司）：股东会决议「公司连续 5 年盈利且符合分配利润条件却连续 5 年不向股东分配利润」「公司合并、分立、转让主要财产」「营业期限届满或章程规定的其他解散事由出现，股东会决议修改章程使公司存续」时，投反对票的股东可请求公司按合理价格收购其股权；自决议通过之日起 **60 日内**未达成收购协议，可在 **90 日内**向法院起诉。新法另增：控股股东滥用权利严重损害公司或其他股东利益时，其他股东也有权请求公司回购。

**国家出资公司**：国家出资的国有独资公司、国有资本控股公司（含国有资本参股公司中的相关规则）适用特别规定；国有独资公司**不设股东会**，由履行出资人职责的机构行使股东会职权；董事会成员中应有**职工代表**（由职工代表大会选举产生）；国有独资公司的董事、高管未经履行出资人职责机构同意不得在其他企业兼职，董事长不得兼任经理（未经同意）。

### 6.5 公司财务会计与重大变更（★★）

| 项目 | 规则 |
| --- | --- |
| 法定公积金 | 分配当年税后利润时提取 **10%** 列入法定公积金；累计额为注册资本 **50% 以上**的可不再提取；法定公积金转为资本时，所留存该项公积金不得少于转增前注册资本的 **25%** |
| 弥补亏损顺序 | 先用任意公积金和法定公积金；仍不能弥补的，可按规定使用**资本公积金**；《公司法》已允许资本公积金依规定弥补亏损（旧法曾禁止，注意更新） |
| 利润分配 | 弥补亏损、提取法定公积金后，有限公司按**实缴出资比例**分取红利（全体股东另有约定除外），股份公司按持股比例（章程另有规定除外）；违法分配的股东须退还，给公司造成损失的股东及负有责任的董监高承担赔偿责任 |
| 减资 | 编制资产负债表及财产清单，自决议之日起 **10 日内通知债权人**、**30 日内在报纸上或国家企业信用信息公示系统公告**；债权人自接到通知起 **30 日内**、未接到通知自公告起 **45 日内**可要求清偿债务或提供担保 |
| 合并 / 分立 | 合并时各方签订合并协议、编制资产负债表及财产清单，同样 10 日通知、30 日公告；债权人有权要求清偿或担保；**合并前债务由存续 / 新设公司承继，分立前债务由分立后公司承担连带责任**（分立前与债权人另有书面约定的除外） |
| 增资 | 有限公司新增资本时股东有权优先按**实缴出资比例**认缴（全体股东另有约定除外） |

### 6.6 公司解散与清算（★★）

解散事由：章程规定营业期限届满或其他解散事由出现、股东会决议解散、合并或分立需要解散、依法被吊销营业执照 / 责令关闭 / 撤销、法院依股东请求判决解散（公司经营管理发生严重困难，继续存续会使股东利益受到重大损失，通过其他途径不能解决，持有 **10% 以上表决权**的股东可请求）。

| 环节 | 期限 / 规则 |
| --- | --- |
| 清算义务人 | **董事**为公司清算义务人，应在解散事由出现之日起 **15 日内**组成清算组；逾期不成立导致财产贬值流失的，承担赔偿责任 |
| 通知与公告 | 清算组成立之日起 **10 日内**通知债权人，并于 **60 日内**在报纸上或国家企业信用信息公示系统公告 |
| 债权申报 | 债权人自接到通知之日起 **30 日内**、未接到通知自公告之日起 **45 日内**申报 |
| 清偿顺序 | 清算费用 → 职工工资、社会保险费用和法定补偿金 → 所欠税款 → 公司债务 → 剩余财产按出资比例 / 持股比例分配 |
| 清算期间 | 公司存续但**不得开展与清算无关的经营活动**；财产在未按前款清偿前不得分配给股东 |
| 注销 | 清算结束制作清算报告，报股东会或法院确认，并报送登记机关申请注销登记 |

## 第 7 章 证券法律制度

### 7.1 证券法律制度概述（★★）

《证券法》确立**公开、公平、公正**与**自愿、有偿、诚实信用**原则；公开发行证券实行**注册制**，由国务院证券监督管理机构或其授权部门注册；证券交易场所、证券登记结算机构、证券服务机构各司其职。

| 原则 / 制度 | 要点 |
| --- | --- |
| 投资者适当性 | 证券公司应了解客户身份、财产与收入状况、证券投资经验和风险偏好，销售与投资者风险承受能力相匹配的产品；普通投资者与证券公司发生纠纷，证券公司应证明其行为符合法律法规，**举证责任倒置** |
| 信息披露 | 发行人及法律、行政法规规定的信息披露义务人应真实、准确、完整、及时、公平披露，不得有虚假记载、误导性陈述或重大遗漏；**简明清晰、通俗易懂**，同时向所有投资者公开披露 |
| 同股同权 | 同类别每一股份具有同等权利；同次发行的同类别股份每股发行条件与价格相同 |
| 公开征集股东权利 | 征集人应披露征集文件，不得以有偿或变相有偿方式征集；征集人可依规定自行或委托证券公司、证券服务机构征集 |

### 7.2 股票发行（★★★）

| 环节 | 规则 |
| --- | --- |
| 首次公开发行条件 | 具备健全且运行良好的组织机构、具有持续经营能力、最近 **3 年**财务会计报告被出具无保留意见审计报告、发行人及其控股股东 / 实际控制人最近 3 年不存在贪污贿赂侵占财产挪用财产或破坏社会主义市场经济秩序的刑事犯罪、经国务院批准的国务院证券监督管理机构规定的其他条件 |
| 注册程序 | 交易所**审核**发行上市申请文件（判断是否符合发行条件、上市条件和信息披露要求）→ 证监会**注册**（在规定期限内作出予以注册或不予注册决定）；证监会发现交易所审核意见依据不足可退回补充审核 |
| 发行文件 | 招股说明书须附公司章程；应载明发行股份总数、面值、募集资金用途、发行对象、承销方式等；**招股说明书有效期 6 个月**（自公开发行前最后一次签署之日起算） |
| 承销 | 由证券公司承销（代销或包销）；向不特定对象发行证券聘请承销团；**股票发行采用代销方式，代销期限届满向投资者出售的股票数量未达到拟公开发行股票数量 70% 的，为发行失败**，发行人应按发行价加算银行同期存款利息返还股票认购人 |
| 授权发行（公司法衔接） | 股东会可授权董事会 **3 年内**决定发行不超过已发行股份 **50%** 的股份，董事会决议须经全体董事 **2/3 以上**通过；以非货币财产作价出资的仍须股东会决议 |
| 发行新股决议事项 | 新股种类及数额、新股发行价格、新股发行的起止日期、向原有股东发行新股的种类及数额、发行无记名股票的其发行总数 |

### 7.3 公司债券发行与交易（★★）

- 公开发行公司债券须符合：具备健全且运行良好的组织机构、最近 **3 年平均可分配利润足以支付公司债券 1 年利息**、国务院规定的其他条件；募集资金须按公司债券募集办法所列用途使用，**不得用于弥补亏损和非生产性支出**（改变用途须经债券持有人会议决议）。
- 公开发行债券应经证监会注册，公告公司债券募集办法；债券募集办法应载明债券总额、票面金额、利率、还本付息期限与方式、担保情况、发行起止日期、净资产额、已发行尚未到期的债券总额、承销机构等。
- **可转换公司债券**：发行主体为上市公司，须符合公开发行新股条件与债券发行条件；债券持有人在转换期内有权按约定条件转换为股票；转换后发行人应在规定时间内办理变更登记。
- 债券持有人会议：对可能影响持有人利害关系的重大事项（改变募集资金用途、修改募集说明书、发行人减资合并分立解散或申请破产、保证人或担保物发生重大变化等）作出决议；会议决议对全体债券持有人有约束力。

### 7.4 股票公开交易与上市公司收购（★★★）

| 事项 | 规则 |
| --- | --- |
| 交易场所 | 依法公开发行的股票、公司债券及其他证券应在依法设立的证券交易所上市交易或在国务院批准的其他全国性证券交易场所交易 |
| 短线交易 | 上市公司持股 **5% 以上**股东、董监高，将其持有的该公司股票或其他具有股权性质的证券在**买入后 6 个月内卖出，或卖出后 6 个月内又买入**，所得收益归公司所有，董事会应收回；证券公司因购入包销售后剩余股票而持有 5% 以上股份等法定情形除外 |
| 权益变动披露 | 通过证券交易所交易持有或与他人共同持有一个上市公司已发行有表决权股份达到 **5%** 时，应在该事实发生之日起 **3 日内**向证监会、交易所报告并通知该公司予以公告，在该期限内不得再行买卖；其后所持比例**每增加或减少 5%**，应依规定报告公告，在该事实发生之日起至公告后 **3 日内**不得再行买卖（每增减 **1%** 亦应于次日通知并公告） |
| 要约收购 | 持股比例达到 **30%** 时继续增持的，应依法向该上市公司**全体股东**发出要约（全面或部分要约）；收购要约约定的收购期限不得少于 **30 日**、不得超过 **60 日**；在收购要约确定的承诺期限内，收购人**不得撤销**要约 |
| 收购完成后的锁定期 | 收购完成后，收购人持有的被收购上市公司股票在 **18 个月内**不得转让（在同一实际控制人控制的不同主体之间转让等法定情形除外） |
| 上市公司重大资产重组 | 须符合产业政策、环境保护、土地管理等规定，重组不构成同业竞争与显失公平的关联交易，履行董事会 / 股东会决议与信息披露义务，依法经证监会注册或交易所审核 |
| 退市 | 触及交易类、财务类、规范类、重大违法类强制退市情形的，由交易所依上市规则决定终止上市；主动退市须经股东会决议 |

### 7.5 证券欺诈的法律责任（★★★）

| 行为 | 认定与责任 |
| --- | --- |
| 虚假陈述 | 发行人、信息披露义务人披露的信息有虚假记载、误导性陈述或重大遗漏，致投资者损失的，发行人承担赔偿责任；**发行人的控股股东、实际控制人、董监高、保荐人、承销的证券公司、证券服务机构**与其承担连带赔偿责任（能证明自己没有过错的除外）——**过错推定 / 连带责任** |
| 内幕交易 | 证券交易内幕信息的**知情人**和**非法获取内幕信息的人**，在内幕信息公开前不得买卖该公司证券、泄露信息或建议他人买卖；内幕信息 = 对证券交易价格有重大影响的尚未公开的信息；给投资者造成损失的依法承担赔偿责任 |
| 操纵市场 | 禁止连续交易、约定交易、洗售（自买自卖）、蛊惑交易、抢帽子交易、利用虚假或不确定的重大信息诱导交易、对证券或证券发行人公开作出评价预测或投资建议并同步或先行买卖等；给投资者造成损失的依法赔偿 |
| 欺诈客户 | 证券公司及其从业人员违背客户真实意思表示、损害客户利益（如混合操作、诱导不必要的交易、挪用客户证券或资金、私自买卖客户账户证券等） |
| 行政与刑事 | 罚款、没收违法所得、市场禁入、撤销任职资格 / 许可；构成犯罪的依法追究刑事责任（欺诈发行、违规披露、内幕交易、操纵市场等） |

::: danger 易错 · 董监高责任与「过错推定」
虚假陈述民事赔偿中，发行人适用**无过错责任**；控股股东、实际控制人、董监高、保荐人、承销商、证券服务机构适用**过错推定**——须由被告举证证明自己已勤勉尽责、没有过错才能免责，而非由原告证明其有过错。
:::

## 第 8 章 企业破产法律制度

### 8.1 破产原因与申请受理（★★★）

《企业破产法》2006 年 8 月 27 日通过，自 **2007 年 6 月 1 日**起施行；适用于**企业法人**，合伙企业、个人独资企业等其他组织可参照适用清算程序（法律另有规定除外）。

**破产原因**：债务人**不能清偿到期债务**，并且**资产不足以清偿全部债务**或者**明显缺乏清偿能力**。相关当事人不得以对债务人债务负有连带责任的人未丧失清偿能力为由，主张债务人不具备破产原因。

![破产程序全流程与清偿顺序](/econlaw/el-bankruptcy.svg)

| 环节 | 规则 |
| --- | --- |
| 申请主体 | 债务人（可申请重整、和解、破产清算）、债权人（可申请重整、破产清算）、依法负有清算责任的人（公司已解散未清算或未在合理期限内清算完毕且资产不足以清偿债务时，应申请破产清算） |
| 申请材料 | 破产申请书 + 债务人不能清偿到期债务的证据；债务人申请还须提交财产状况说明、债务清册、债权清册、财务会计报告、职工安置预案及工资支付社保缴纳情况 |
| 补正告知 | 法院认为应补充补正材料的，应自收到破产申请之日起 **5 日内**告知；补正期间不计入受理期限 |
| 受理裁定 | 债权人提出申请的，法院自收到申请之日起 **5 日内**通知债务人；债务人有异议的应自收到通知之日起 **7 日内**向法院提出，法院应自异议期满之日起 **10 日内**裁定是否受理；债务人申请的，一般自收到申请之日起 **15 日内**裁定（特殊情况经上一级法院批准可延长 15 日） |
| 受理效力 | ① 对债务人财产的所有**个别清偿无效**；② 有关债务人财产的**执行程序应当中止**、保全措施应解除；③ 未审结的民事诉讼或仲裁中止，由管理人接管后继续；④ 债务人对个别债权人的债务清偿无效，但使债务人财产受益的除外；⑤ 双方均未履行完毕的合同，管理人有权决定**解除或继续履行**，并应及时通知对方（自受理之日起 **2 个月内**未通知或自收到对方催告之日起 **30 日内**未答复的，视为解除合同） |
| 通知与公告 | 法院应自裁定受理破产申请之日起 **25 日内**通知已知债权人并公告 |

### 8.2 管理人制度（★★）

管理人由法院指定，可由律师事务所、会计师事务所、破产清算事务所等社会中介机构或具备相关专业知识并取得执业资格的人员担任；**与本案有利害关系的不得担任**；法院可依债权人会议申请更换不宜履职的管理人。管理人报酬由法院确定，列入破产费用，由债务人财产**优先支付**。

管理人职责：接管债务人财产、印章和账簿文书；调查财产状况并制作报告；决定内部管理事务与日常必要开支；在第一次债权人会议召开前决定继续或停止营业；管理和处分财产；代表债务人参加诉讼仲裁或其他法律程序；提议召开债权人会议；拟订重整计划 / 和解协议 / 破产财产分配方案等。管理人应**勤勉尽责、忠实执行职务**，因故意或重大过失致损的依法承担赔偿责任。

### 8.3 债务人财产与破产撤销权（★★★）

债务人财产 = 破产申请受理时属于债务人的全部财产 + 受理后至程序终结前债务人取得的财产（含管理人追回的财产）。

| 制度 | 要件与效果 |
| --- | --- |
| 破产撤销权（受理前 **1 年内**） | ① 无偿转让财产；② 以明显不合理价格进行交易；③ 对没有财产担保的债务提供财产担保；④ 对未到期债务提前清偿；⑤ 放弃债权 —— 管理人有权请求法院予以撤销 |
| 破产撤销权（受理前 **6 个月内**） | 债务人已具备破产原因仍对个别债权人进行清偿的，管理人有权请求撤销；**个别清偿使债务人财产受益的除外**（如为维持正常生产经营必需的水电、为保全财产支付的必要费用） |
| 无效行为 | 为逃避债务而**隐匿、转移财产**，**虚构债务或承认不真实的债务** —— 自始无效，管理人有权追回 |
| 董监高非正常收入追回 | 债务人有破产原因时，董监高利用职权获取的非正常收入和侵占的企业财产，管理人应追回；因返还绩效奖金等形成的债权按**普通破产债权**清偿（职工平均工资部分可按职工债权顺序） |
| 取回权 | 财产不属于债务人的，权利人可通过管理人取回；**出卖人取回权**：受理时出卖人已将标的物发送、买受人尚未收到且未付清全部价款的，出卖人可取回在途标的物（管理人支付全部价款并要求交付的除外） |
| 别除权 | 对破产人的特定财产享有担保权的权利人，对该特定财产享有优先受偿权；未受偿部分转为普通债权，放弃优先受偿权的转为普通债权 |
| 破产抵销权 | 债权人在**破产申请受理前**对债务人负有债务的，可向管理人主张抵销；但债务人的债务人在受理后取得他人对债务人的债权、或已知债务人不能清偿仍对债务人负担债务 / 取得债权（法律规定或受理前 1 年内的原因除外）等情形**不得抵销** |
| 出资加速到期 | 法院受理破产申请后，债务人的出资人**尚未完全履行出资义务的**，管理人应要求其缴纳所认缴的出资，不受出资期限限制 |

::: danger 易错 · 撤销权期限起算
「1 年 / 6 个月」均从**法院裁定受理破产申请之日**向前倒推，而非从债务人出现破产原因或债权到期之日起算；且受理后管理人须主动审查并请求法院撤销，法院不会主动撤销。
:::

### 8.4 破产债权与债权人会议（★★）

- 法院受理破产申请后应确定债权申报期限，自发布公告之日起计算，**最短 30 日、最长 3 个月**；债权人未在期限内申报的，可在破产财产**最后分配前**补充申报（此前已进行的分配不再补充分配），但为审查申报产生的费用由补充申报人承担。
- **职工债权**（工资、医疗伤残补助抚恤费用、应划入个人账户的基本养老医疗保险费用、法定补偿金）**无需申报**，由管理人调查后列出清单并公示；职工对清单有异议可要求更正，管理人不予更正的可向法院起诉。
- 债权申报范围：受理前成立的无财产担保债权、有财产担保债权、未到期债权（视为到期，利息自受理之日起停止计息）、附条件附期限债权、诉讼仲裁未决债权、连带债权、保证人或其他连带债务人**因代替清偿或将来可能清偿而形成的求偿权**；**行政罚款、刑事罚金、惩罚性赔偿、破产申请受理后的债务利息、债权人参加破产程序所支出的费用**不属于破产债权。

| 债权人会议规则 | 内容 |
| --- | --- |
| 第一次会议 | 由法院召集，自债权申报期限届满之日起 **15 日内**召开 |
| 以后会议 | 法院认为必要时，或管理人、债权人委员会、**占债权总额 1/4 以上**的债权人向会议主席提议时召开；召开前 **15 日**通知已知债权人 |
| 一般表决 | 由出席会议的有表决权的债权人**过半数**通过，且其所代表的债权额占**无财产担保债权总额的 1/2 以上**（章程 / 法律另有规定的依其规定） |
| 重整计划分组表决 | 按担保债权、职工债权、税款债权、普通债权等分组；出席会议的同一表决组的债权人**过半数**同意且其所代表债权额占该组债权总额 **2/3 以上**，即为该组通过；各表决组均通过，重整计划即为通过 |
| 和解协议 | 由出席会议的有表决权的债权人**过半数**同意，且所代表债权额占**无财产担保债权总额 2/3 以上** |
| 债权人委员会 | 由债权人会议选任的债权人代表和 1 名债务人职工代表 / 工会代表组成，成员不超过 **9 人**，须经法院书面决定认可 |

### 8.5 重整、和解与破产清算（★★★）

| 项目 | 重整 | 和解 | 破产清算 |
| --- | --- | --- | --- |
| 申请主体 | 债务人、债权人、出资额占债务人注册资本 **1/10 以上**的出资人（仅可在法院受理破产申请后、宣告破产前申请） | **仅债务人**可直接申请（也可在法院受理破产申请后、宣告破产前申请） | 债务人、债权人、依法负有清算责任的人 |
| 期间效力 | 重整期间**担保权暂停行使**（担保物有损坏或价值明显减少可能、足以危害担保权人权利的，可请求法院恢复行使）；债务人经法院批准可自行管理财产和营业事务；出资人不得请求投资收益分配；董监高不得向第三人转让其持有的债务人股权（经法院同意除外） | 对债务人的特定财产享有担保权的权利人，自法院裁定和解之日起可以行使权利，和解协议对其无约束力 | 法院宣告破产后，管理人拟订破产财产变价方案与分配方案，经债权人会议讨论 / 法院裁定认可后执行 |
| 表决 | 分组表决，各组均通过；部分组未通过但符合法定条件的，债务人或管理人可申请**法院强制批准** | 债权人会议过半数 + 无财产担保债权总额 2/3 以上通过，并须经法院裁定认可 | 分配方案经债权人会议通过（或法院裁定）后由管理人执行 |
| 失败后果 | 重整期间出现经营状况继续恶化、欺诈 / 减少财产等情形，或重整计划未获通过 / 未获批准、债务人不执行计划的，法院应裁定**终止重整并宣告破产** | 和解协议未获通过 / 未获认可、债务人不能执行或不执行和解协议的，法院应裁定终止和解并宣告破产 | 破产财产分配完毕后，管理人提请法院裁定**终结破产程序**并办理注销登记 |

**破产财产清偿顺序**（前一顺位足额清偿后才有后一顺位；同一顺位不足按比例分配）：

1. **破产费用与共益债务**（由债务人财产随时清偿；财产不足以清偿全部时，先清偿破产费用；不足以清偿所有破产费用或共益债务的按比例）；
2. **职工债权**：所欠工资、医疗伤残补助抚恤费用，应划入职工个人账户的基本养老、基本医疗保险费用，以及法定补偿金；
3. **破产人欠缴的除前项以外的社会保险费用和所欠税款**；
4. **普通破产债权**。

::: tip 追加分配与保证责任
破产程序终结后 **2 年内**，发现有依法应当追回的财产或可供分配的其他财产的，债权人可请求法院按原分配方案**追加分配**；破产人的保证人和其他连带债务人，在破产程序终结后对债权人依破产清算程序未受清偿的债权，**仍应继续承担清偿责任**。
:::

**关联企业合并破产**：关联企业成员之间法人人格高度混同、区分各成员财产成本过高、严重损害债权人公平清偿利益时，法院可依申请裁定**实质合并**审理；各成员财产合并为统一的破产财产，成员之间的债权债务归于消灭，统一按法定顺序清偿。

## 第 9 章 票据与支付结算法律制度

### 9.1 支付结算概述（★★）

支付结算是单位、个人在社会经济活动中使用票据、银行卡、汇兑、托收承付、委托收款等结算方式进行货币给付及资金清算的行为；**未经中国人民银行批准，任何单位不得作为中介机构经营支付结算业务**。

| 基本原则 | 内容 |
| --- | --- |
| 恪守信用、履约付款 | 承担付款义务的一方应按约定的金额、时间和方式付款 |
| 谁的钱进谁的账、由谁支配 | 银行应依客户委托妥善办理结算，除法律另有规定外**不得为任何单位或个人查询、冻结、扣款**，不得停止单位、个人存款的正常支付 |
| 银行不垫款 | 银行只提供服务，不为结算当事人垫付资金 |
| 结算凭证要求 | 单位和银行名称应记全称；**金额、签发日期、收款人名称不得更改，更改的结算凭证银行不予受理**；票据金额须以中文大写和阿拉伯数字**同时记载且二者必须一致，不一致的票据无效** |

**银行结算账户**：基本存款账户（主办账户，工资、奖金支取只能通过该账户）、一般存款账户（可办理借款转存与归还等，**不得支取现金**）、专用存款账户、临时存款账户（**有效期最长不得超过 2 年**）。存款人主体资格终止、被撤销 / 吊销执照或迁址等，应在规定期限内向开户银行提出撤销申请；对 1 年内未发生收付活动且未欠开户银行债务的单位账户，银行应通知单位自发出通知之日起 **30 日内**办理销户，逾期视同自愿销户。

### 9.2 票据法律制度基础（★★★）

《票据法》1995 年 5 月 10 日通过、**1996 年 1 月 1 日**起施行（2004 年修正）；配套有《支付结算办法》（2024 年修正）、《电子商业汇票业务管理办法》（2024 年修正）、最高人民法院关于审理票据纠纷案件若干问题的规定（2020 年修正）。我国《票据法》所称票据仅指**汇票、本票、支票**三种。

| 性质 | 要点 |
| --- | --- |
| 文义证券 | 票据权利义务**完全依票据上记载的文字**确定，不得以票据文义之外的事项或票据外的证据变更、补充 |
| 要式证券 | 须依法定形式作成并记载法定事项，欠缺绝对必要记载事项的票据无效 |
| 无因证券 | 票据关系一经产生即与基础关系（买卖、借贷等）相分离，持票人行使权利一般无需证明基础关系；但**直接当事人之间**可以基础关系抗辩 |
| 设权 / 流通 / 提示 / 返还证券 | 票据权利因票据作成而创设，可依背书或交付转让，行使权利须提示票据，付款后须缴回票据 |

**票据权利**：付款请求权（**第一顺序**）与追索权（第二顺序，付款请求权未获实现或到期日前有法定情形时行使）。票据权利取得须**善意、支付对价、依法定方式**（背书连续）；因税收、继承、赠与可**无偿**取得，但其票据权利**不得优于前手**。

**票据抗辩限制**：票据债务人不得以自己与出票人之间或与持票人前手之间的抗辩事由对抗持票人，但**持票人明知存在抗辩事由而取得票据**的除外；票据债务人可以对**不履行约定义务的、与自己有直接债权债务关系的持票人**进行抗辩。

**票据丧失补救**：挂失止付（**临时**措施，非必经程序）→ 公示催告（向票据支付地基层法院申请）→ 普通诉讼。付款人自收到挂失止付通知书之日起 **12 日内**未收到法院止付通知书的，自第 13 日起挂失止付失效。

### 9.3 票据行为与汇票制度（★★★）

![票据行为、提示期限与权利时效](/econlaw/el-bill.svg)

| 票据行为 | 规则 |
| --- | --- |
| 出票 | 作成票据并交付收款人；汇票绝对必要记载事项：表明「汇票」字样、无条件支付的委托、确定的金额、付款人名称、收款人名称、出票日期、出票人签章 |
| 背书 | 转让背书须**连续**；背书不得附条件，**所附条件不具有票据效力**；部分背书（将金额部分转让或分别转让给数人）**无效**；出票人记载「不得转让」的，票据不得转让；背书人记载「不得转让」的，其后手再背书转让的，原背书人对后手的被背书人**不承担保证责任** |
| 承兑 | 仅**远期商业汇票**需要；付款人应自收到提示承兑的汇票之日起 **3 日内**承兑或拒绝承兑；承兑不得附条件，**附条件的视为拒绝承兑**；承兑后付款人成为承兑人，承担到期付款的**主债务人**责任 |
| 保证 | 保证人须为票据债务人以外的第三人；保证不得附条件，附条件的不影响对汇票的保证责任；未记载被保证人的，已承兑汇票以承兑人为被保证人、未承兑汇票以出票人为被保证人；保证人与被保证人对持票人承担**连带责任**；保证人清偿后可向被保证人及其前手行使追索权 |
| 付款 | 付款人须审查背书连续、提示付款人身份；付款人依法足额付款后全体票据债务人责任解除；**对定日付款、出票后定期付款或见票后定期付款的汇票，付款人在到期日前付款的，自行承担所产生的责任** |
| 追索 | 到期被拒绝付款，或到期日前被拒绝承兑 / 承兑人或付款人死亡逃匿 / 被依法宣告破产或因违法被责令终止业务活动的，持票人可追索；持票人应自收到被拒绝承兑或付款的有关证明之日起 **3 日内**通知其前手，前手应自收到通知之日起 3 日内通知其再前手；**未按期限通知并不丧失追索权**，但因延期通知给前手或出票人造成损失的，应赔偿损失（以汇票金额为限） |

**追索对象与金额**：汇票的出票人、背书人、承兑人和保证人对持票人承担**连带责任**；持票人可不按先后顺序、对其中任何一人 / 数人 / 全体行使追索权；被追索人清偿后，其责任解除并可向其他汇票债务人行使**再追索权**。

### 9.4 本票、支票与期限速查（★★★）

| 项目 | 汇票 | 银行本票 | 支票 |
| --- | --- | --- | --- |
| 当事人 | 出票人、付款人、收款人（三方） | 出票人（即付款人）、收款人（两方） | 出票人、付款银行、收款人 |
| 种类 | 银行汇票 / 商业汇票（商业承兑、银行承兑） | 定额 / 不定额，均为**见票即付** | 现金支票、转账支票、普通支票 |
| 绝对记载事项 | 见上 | 表明「本票」字样、无条件支付的承诺、确定金额、收款人名称、出票日期、出票人签章 | 表明「支票」字样、无条件支付的委托、确定金额、付款人名称、出票日期、出票人签章（**金额、收款人名称可由出票人授权补记**，未补记前不得背书转让和提示付款） |
| 提示付款期限 | 见票即付汇票：出票日起 **1 个月**；定日 / 出票后定期 / 见票后定期付款：到期日起 **10 日** | 出票日起 **2 个月** | 出票日起 **10 日**（异地使用的按中国人民银行另行规定） |
| 票据权利时效 | 持票人对出票人、承兑人：自票据**到期日起 2 年**（见票即付的自出票日起 2 年） | 持票人对出票人：自**出票日起 2 年** | 持票人对出票人：自**出票日起 6 个月** |
| 追索 / 再追索 | 持票人对前手追索权：自被拒绝承兑 / 付款之日起 **6 个月**；被追索人清偿或被起诉之日起对前手再追索权 **3 个月** | 同汇票 | 同汇票 |

::: danger 易错 · 三组期限不要混
「提示付款期限」是不行使即丧失对**前手**追索权的操作期限；「票据权利时效」是对**出票人 / 承兑人**权利的消灭时效；「追索权 6 个月 / 再追索 3 个月」是对**前手**的时效。支票提示付款 10 日、对出票人权利 6 个月，是历年高频陷阱。票据权利时效届满后，持票人仍可依民事法律关系请求出票人或承兑人返还与未支付票据金额相当的利益。
:::

### 9.5 非票据结算方式（★）

| 方式 | 要点 |
| --- | --- |
| 汇兑 | 汇款人委托银行将款项支付给收款人，分电汇、信汇；**汇款回单只能作为汇出银行受理汇款的依据，不能作为该笔汇款已转入收款人账户的证明** |
| 托收承付 | 办理结算的款项须是**商品交易及因商品交易而产生的劳务供应**款项；代销、寄销、赊销商品的款项不得办理；每笔金额起点 **1 万元**（新华书店系统 1 000 元）；承付期验单付款 **3 天**、验货付款 **10 天** |
| 委托收款 | 凭已承兑商业汇票、债券、存单等债务证明办理；同城、异地均可使用 |
| 国内信用证 | **不可撤销、不可转让**的跟单信用证，只限于转账结算、**不得支取现金**；有效期最长不超过 **6 个月** |
| 银行卡 / 预付卡 / 电子支付 | 银行卡按是否授信分信用卡与借记卡；预付卡不记名卡有效期不得少于 **3 年**；非银行支付机构须持牌经营，客户备付金集中存管 |

## 第 10 章 企业国有资产法律制度

### 10.1 概述与出资人职责（★★）

《企业国有资产法》2008 年 10 月 28 日通过，自 **2009 年 5 月 1 日**起施行。企业国有资产是国家对企业各种形式出资所形成的权益；国务院和地方人民政府分别代表国家履行出资人职责，实行政企分开、**社会公共管理职能与国有资产出资人职能分开**。

| 主体 | 认定 |
| --- | --- |
| 国家出资企业 | 国有独资企业、国有独资公司、国有资本控股公司、国有资本参股公司 |
| 控股股东 | 出资额占有限责任公司资本总额 **超过 50%**，或持股占股份有限公司股本总额 **超过 50%**；虽低于 50% 但依表决权足以对股东会决议产生重大影响的，也构成控股 |
| 关联方 | 本企业的董事、监事、高级管理人员及其近亲属，以及这些人员和其近亲属直接或间接控制的企业 |

**董监高任职与义务**：履行出资人职责的机构任免 / 建议任免国有独资企业的经理、副经理、财务负责人及其他高管，国有独资公司的董事长、副董事长、董事、监事会主席和监事，国有资本控股 / 参股公司的董事、监事人选；应具备良好品行、符合任职资格、有履职能力；**未经履行出资人职责机构同意，国有独资公司的董事长不得兼任经理**；未经股东会 / 股东大会同意，国有资本控股公司的董事长不得兼任经理；国有独资公司董事、高管不得在**其他企业**兼职，国有资本控股 / 参股公司董事、高管不得在**经营同类业务的其他企业**兼职。

**重大事项决策**：企业改制、与关联方交易、资产评估、国有资产转让、大额捐赠、为他人提供大额担保、增加或减少注册资本、合并分立解散申请破产等，须遵守法律行政法规及章程，由履行出资人职责机构决定或由股东会 / 股东大会、董事会决定；**企业改制须制定方案并经职工代表大会审议职工安置方案**，原企业不得向继续留用的职工支付经济补偿金。

::: danger 易错 · 与关联方交易
未经履行出资人职责的机构同意，国有独资企业、国有独资公司**不得**与关联方订立财产转让、借款、担保、共同出资设立企业等协议，也不得无偿向关联方提供资金、商品、服务或其他资产；国有资本控股 / 参股公司与关联方交易，依公司章程由股东会 / 股东大会或董事会决定时，**关联董事、关联股东不得参与表决**。
:::

### 10.2 产权登记与资产评估（★★）

| 制度 | 要点 |
| --- | --- |
| 产权登记范围 | 国有企业、国有独资公司、国有资本控股公司及其**直接或间接合计持股超过 50%** 的各级子企业、参股企业（按规定纳入产权登记范围） |
| 登记类型 | **占有产权登记**（新设、首次取得法人资格）、**变动产权登记**（名称、组织形式、级次、资本额、出资人等发生变化）、**注销产权登记**（解散、撤销、破产、转让全部产权等） |
| 时限 | 申请取得法人资格的企业应在办理工商注册登记前 **30 日内**申办占有产权登记；取得法人资格后 **30 日内**领取产权登记证；发生变动 / 注销情形的应自相关情形发生之日起规定期限内申办 |
| 应当评估 | 整体或部分改建为有限责任公司 / 股份有限公司、以非货币资产对外投资、合并分立破产解散、非上市公司国有股东股权比例变动、产权转让、资产转让置换、以非货币资产偿还债务、资产涉讼、收购非国有单位资产、接受非国有单位以非货币资产出资或抵债等 |
| 可以不评估 | 经各级人民政府或其国有资产监督管理机构批准，对企业整体或部分资产实施**无偿划转**；国有独资企业与其下属独资企业之间、或其下属独资企业之间的合并、资产（产权）置换和无偿划转 |
| 管理方式 | 资产评估项目实行**核准制与备案制**；经核准 / 备案的评估结果自评估基准日起 **1 年**内有效 |

### 10.3 企业国有资产交易管理制度（★★）

企业国有资产交易包括**企业产权转让**（转让所持子企业股权）、**企业增资**、**企业资产转让**；原则上应在依法设立的**产权交易机构**中公开进行，国家法律法规另有规定的从其规定。

| 环节 | 规则 |
| --- | --- |
| 审批 | 产权转让、增资须按企业章程和内部管理制度履行决策程序；因产权转让或增资致使国家**不再拥有所出资企业控股权**的，须报本级人民政府批准 |
| 审计与评估 | 产权转让、增资事项须**专项审计**并依规定进行资产评估，评估结果作为确定转让 / 增资价格的参考依据 |
| 信息披露 | 通过产权交易机构网站分阶段对外披露产权转让 / 增资信息，公开征集受让方 / 投资方；正式披露信息时间不得少于 **20 个工作日**；因产权转让导致实际控制权发生转移的，披露时间不得少于 **40 个工作日** |
| 首次挂牌价格 | 不得低于经核准或备案的**评估结果**；首次挂牌价格低于评估结果 **90%** 的应暂停挂牌，经转让批准单位书面同意后方可继续（具体比例依现行监管规则） |
| 受让方资格 | 不得设置明确指向性或违反公平竞争原则的条件；确需设置的，须经转让批准单位审核同意 |
| 结算 | 交易价款原则上**自合同生效之日起 5 个工作日内一次付清**；金额较大、一次付清确有困难的，可采取分期付款（首期付款不低于总价款的 **30%** 并在合同生效之日起 5 个工作日内支付，其余款项按同期银行贷款利率支付延期付款期间利息且付款期限不得超过 **1 年**） |
| 非公开协议方式 | 涉及主业处于关系国家安全、国民经济命脉的重要行业和关键领域，或承担重大专项任务、同一国家出资企业及其各级控股企业之间内部重组整合等法定情形，经国资监管机构批准或国家出资企业审议决策，可采取非公开协议转让 / 增资 |

## 第 11 章 反垄断法律制度

### 11.1 概述与相关市场界定（★★）

《反垄断法》2007 年 8 月 30 日通过、**2008 年 8 月 1 日**起施行，2022 年 6 月修正（**新增垄断行为的刑事责任**、完善平台经济规则、提高罚款力度）；最高人民法院 2012 年、2024 年先后发布垄断民事纠纷司法解释。

| 要点 | 内容 |
| --- | --- |
| 适用范围 | 中华人民共和国境内经济活动中的垄断行为；境外的垄断行为对境内市场竞争产生**排除、限制影响**的，亦适用（域外效力） |
| 相关市场界定 | 从**相关商品市场**与**相关地域市场**两方面，依据需求替代与供给替代分析；常用 **SSNIP 假定垄断者测试**：考察目标地域内相关商品能否**持久（一般 1 年）小幅（一般 5%~10%）涨价**而仍有利可图；还需考虑商品生产周期、使用期限、季节性、流行时尚性、知识产权保护期限等 |
| 平台经济 | 界定平台相关市场时需结合平台功能、商业模式、用户群体、多边市场特性；不得仅因经营者掌握数据、算法、技术或平台规则即认定具有市场支配地位 |
| 不适用 | 经营者依法行使知识产权的行为；农业生产者及农村经济组织在农产品生产、加工、销售、运输、储存等经营活动中实施的联合或协同行为（另有规定除外） |

### 11.2 垄断协议规制（★★★）

**横向垄断协议**（具有竞争关系的经营者之间，禁止）：固定或变更商品价格；限制商品生产数量或销售数量；分割销售市场或原材料采购市场；限制购买新技术、新设备或限制开发新技术、新产品；联合抵制交易；国务院反垄断执法机构认定的其他垄断协议。

**纵向垄断协议**（经营者与交易相对人之间，禁止）：**固定向第三人转售商品的价格**；**限定向第三人转售商品的最低价格**；国务院反垄断执法机构认定的其他垄断协议。

| 制度 | 规则 |
| --- | --- |
| 安全港 | 经营者能证明其在相关市场的**市场份额低于国务院反垄断执法机构规定的标准**，并符合其他条件的，纵向协议等可不予禁止；但对**固定或变更商品价格、限制产量、分割市场**等核心横向协议不适用 |
| 豁免 | 为改进技术 / 研究开发新产品、提高产品质量降低成本增进效率、提高中小经营者经营效率增强竞争力、实现节约能源保护环境救灾救助等社会公共利益、缓解销售量严重下降或生产明显过剩、保障对外贸易和对外经济合作中的正当利益、法律国务院规定的其他情形；经营者还须证明协议**不会严重限制相关市场竞争**且**能使消费者分享由此产生的利益** |
| 行业协会 | 不得组织本行业经营者达成、实施垄断协议；应加强行业自律、引导依法竞争 |
| 宽大制度 | 经营者主动向反垄断执法机构报告达成垄断协议的有关情况并提供**重要证据**的，可酌情**减轻或免除**对该经营者的处罚（按报告顺序与证据价值区分） |
| 轴辐协议 | 经营者不得组织其他经营者达成垄断协议，或为其他经营者达成垄断协议提供实质性帮助 |

::: danger 易错 · 协议无效的认定
经营者之间协议、行业协会章程 / 决议 / 决定等因违反《反垄断法》强制性规定而**无效**；即使部分条款无效，与该部分紧密关联、不具独立存在意义或便利垄断行为实施的其他条款，法院可依当事人主张一并认定无效。被认定无效后依《民法典》第 157 条返还财产 / 折价补偿 / 赔偿损失。
:::

### 11.3 滥用市场支配地位（★★★）

**市场支配地位推定**（可举证推翻）：一个经营者在相关市场的市场份额达到 **1/2**；两个经营者合计达到 **2/3**；三个经营者合计达到 **3/4**（后两种情形中市场份额**不足 1/10** 的经营者，不应当推定其具有市场支配地位）。认定因素还包括财力和技术条件、其他经营者对其依赖程度、进入相关市场难易程度等。

| 滥用行为 | 典型表现 |
| --- | --- |
| 不公平价格 | 以不公平的**高价销售**或以不公平的**低价购买** |
| 低于成本销售 | 没有正当理由，以低于成本的价格销售商品（鲜活、季节性、积压、清偿债务转产歇业等正当理由除外） |
| 拒绝交易 | 没有正当理由，拒绝与交易相对人进行交易、限定交易相对人只能与其交易或只能与其指定的经营者交易 |
| 限定交易 | 没有正当理由，限定交易相对人只能与其进行交易 / 不得与特定经营者交易（含平台「二选一」） |
| 搭售或附加不合理条件 | 没有正当理由搭售商品，或在交易时附加不合理交易条件 |
| 差别待遇 | 没有正当理由，对条件相同的交易相对人在交易价格等交易条件上实行差别待遇（大数据杀熟、对忠实客户与新手差异定价等需结合正当理由判断） |

### 11.4 经营者集中与行政垄断（★★）

| 项目 | 规则 |
| --- | --- |
| 集中情形 | 经营者合并；通过取得股权或资产取得对其他经营者的控制权；通过合同等方式取得控制权或能对其他经营者施加决定性影响 |
| 申报 | 达到国务院规定的申报标准的，经营者应事先向国务院反垄断执法机构申报，**未申报不得实施集中**；两个以上经营者被同一第三方控制或施加决定性影响的，判断是否构成集中时视为一个经济实体 |
| 审查 | 初步审查（自收到文件资料之日起 **30 日内**）→ 进一步审查（自决定之日起 **90 日内**，可依法延长不超过 **60 日**）；审查考虑参与集中经营者市场份额、市场 control 力、市场集中度、对上下游与市场进入技术进步、消费者及其他经营者、国民经济的影响等 |
| 处理结果 | 不予禁止（可附加剥离资产、开放网络 / 平台、许可关键技术、修改平台规则等**限制性条件**）、禁止集中；逾期未作出决定的，经营者可实施集中 |
| 未依法申报 / 违法实施 | 可责令停止实施集中、限期处分股份或资产、转让营业、采取其他必要措施恢复到集中前状态，并处罚款；对具有或可能具有排除限制竞争效果的，处上一年度销售额 **10% 以下**罚款，不具有排除限制竞争效果的处 **500 万元以下**罚款 |
| 行政垄断 | 行政机关及法律法规授权具有管理公共事务职能的组织不得：限定或变相限定单位 / 个人经营、购买、使用其指定的经营者提供的商品；实行地区封锁（对外地商品设定歧视性收费 / 检验 / 许可、阻碍外地商品进入或本地商品运出）；排斥或限制外地经营者参加本地招投标；以不平等待遇排斥 / 限制 / 强制外地经营者在本地投资或设分支机构；强制经营者从事垄断行为；制定含有排除限制竞争内容的规定 |

**调查与责任**：执法人员不得少于 **2 人**并出示证件，询问应制作笔录；涉嫌垄断行为的经营者承诺在认可期限内采取具体措施消除后果的，执法机构可决定**中止调查**；未履行承诺、作出中止决定所依据的事实发生重大变化或基于不完整 / 不真实信息作出的，应**恢复调查**。2022 年修正后，构成犯罪的依法追究**刑事责任**。垄断行为损害赔偿请求权的诉讼时效自原告知道或应当知道权益受损及义务人之日起算；向执法机构举报的，时效从举报之日起**中断**，执法机构认定构成垄断行为的，时效自原告知道该认定之日起**重新计算**。

## 第 12 章 涉外经济法律制度

### 12.1 外商投资法律制度（★★）

《外商投资法》及实施条例、最高人民法院司法解释、《外商投资信息报告办法》均自 **2020 年 1 月 1 日**起施行，原「外资三法」（中外合资经营企业法、中外合作经营企业法、外资企业法）同时废止；对施行前依「外资三法」设立的外商投资企业设置 **5 年过渡期**，可在过渡期内继续保留原企业组织形式等。

| 制度 | 要点 |
| --- | --- |
| 准入管理 | 国家实行**准入前国民待遇加负面清单**制度；负面清单之外的领域，按内外资一致原则管理，主管部门按与内资一致的条件和程序审核许可申请；负面清单由国务院发布或批准发布 |
| 平等适用 | 国家保障外商投资企业依法平等参与标准制定、政府采购（不得以所有制形式、组织形式、股权结构、投资者国别、产品或服务品牌等不合理条件实行差别 / 歧视待遇）；支持企业发展的政策应依法公开 |
| 产权保护 | 国家对外国投资者的投资**不实行征收**（特殊情况下依法律规定可征收或征用，须依法定程序并及时给予**公平、合理补偿**）；不得利用行政许可、检查、处罚等强制转让技术；保护商业秘密与个人信息，与履职无关人员不得知悉 |
| 资金进出 | 外国投资者在中国境内的出资、利润、资本收益、资产处置所得、知识产权许可使用费、依法获得的补偿或赔偿、清算所得等，可依法以人民币或外汇**自由汇入、汇出** |
| 信息报告 | 外国投资者、外商投资企业通过企业登记系统及国家企业信用信息公示系统报送投资信息，**无需逐项审批**（负面清单内需许可 / 备案的除外） |
| 安全审查 | 国家建立外商投资安全审查制度，对影响或可能影响国家安全的外商投资依法进行审查；审查决定为最终决定 |
| 政府守约 | 地方各级政府及有关部门应履行向外国投资者依法作出的**政策承诺**及依法订立的合同，不得以行政区划调整、政府换届、机构或职能调整及相关责任人更替为由违约毁约；因国家利益、社会公共利益需要改变政策承诺或合同约定的，应依法定权限程序进行并依法补偿 |
| 投诉机制 | 国家建立外商投资企业投诉工作机制，协调解决投资及经营中的问题；外商投资企业可申请协调，也可依法申请行政复议、提起行政诉讼 |

### 12.2 对外贸易法律制度（★★）

- 《对外贸易法》适用于**货物进出口、技术进出口和国际服务贸易**；国家实行统一的对外贸易制度，鼓励发展对外贸易，维护公平自由的贸易秩序；对外贸易经营者依法办理备案登记（部分情形除外）。
- **货物与技术进出口**：除法律行政法规另有规定外，国家准许货物与技术自由进出口；属于禁止进出口的不得进出口，属于限制进出口的实行配额、许可证等管理；进出口属于自由进出口的技术，应向国务院对外贸易主管部门或其委托机构办理**合同备案登记**。
- **贸易救济措施**：
  - **反倾销**：外国产品以低于正常价值的倾销方式进入中国市场，并对已建立的国内产业造成**实质损害或产生实质损害威胁**、或对建立国内产业造成实质阻碍的，可征收反倾销税（临时反倾销措施、价格承诺）；
  - **反补贴**：进口产品接受出口国（地区）政府**专向性补贴**并造成同类损害的，可征收反补贴税；
  - **保障措施**：某产品进口数量激增，对生产同类产品或直接竞争产品的国内产业造成**严重损害或严重损害威胁**的，可采取提高关税、数量限制等保障措施（**针对公平贸易条件下的进口激增**，不要求存在不公平做法）。
- 与对外贸易有关的知识产权保护、反垄断、反不正当竞争、贸易调查与救济、对外贸易促进等由主管部门依法实施。

### 12.3 外汇管理法律制度（★★）

| 项目 | 规则 |
| --- | --- |
| 经常项目 | 对经常性国际支付和转移**不予限制**，实行可兑换；境内机构、个人的外汇收入可按规定调回境内或存放境外，经常项目外汇支出凭有效单证以自有外汇支付或向经营结汇售汇业务的金融机构购汇支付 |
| 资本项目 | 资本项目外汇收入（直接投资、证券投资、外债等）应按规定办理登记 / 核准或备案，使用与结汇应遵守用途与比例限制；资本项目外汇及结汇资金**不得用于国家禁止的用途** |
| 个人外汇 | 个人结汇和境内个人购汇实行**年度便利化额度**（目前每人每年等值 **5 万美元**），凭本人有效身份证件办理；超过额度的凭真实性凭证办理 |
| 金融机构 | 经营结汇、售汇业务须经外汇管理机关批准；银行应按规定对交易单证的真实性及其与外汇收支的一致性进行合理审查 |
| 国际收支申报 | 境内机构、个人应按规定进行国际收支统计申报；外汇管理机关依法监督检查，可查询账户、查阅复制资料、申请法院冻结或查封 |
| 法律责任 | 逃汇、非法套汇、非法买卖外汇、未按规定申报或报送资料等，由外汇管理机关责令改正、警告、罚款；构成犯罪的依法追究刑事责任 |
