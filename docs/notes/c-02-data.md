# 第2章 数据与运算

## 2.1 计算机的存储规则

- 二进制：逢二进一，借一当二（0、1）
- 十进制：逢十进一，借一当十（0 ~ 9）
- 计算机内部所有数据都以二进制形式存储

## 2.2 数据类型

数据类型决定两件事：变量中能存储什么类型的数据（整数、小数、字符等）；存储空间的大小。

| 类别 | 类型 |
| --- | --- |
| 整数 | `short`、`int`、`long`（数值后缀 `L`，打印 `%ld`）、`long long`（C99，后缀 `LL`，打印 `%lld`） |
| 小数 | `float`、`double` |
| 字符 | `char` |

原文还给出：

- 内存中表达的形式：整数用二进制（补码）；浮点数用编码（符号位 + 指数 + 尾数）
- 浮点数表示范围更大，但存在精度限制

::: danger 订正 · 类型范围的排序
原笔记写「各类型所能表达数的范围（大致）：`char < short < int < float < double`」。这句话把**整型**和**浮点型**混在一条链里比较，是不成立的：

- 标准只保证整型内部 `char ≤ short ≤ int ≤ long ≤ long long`，以及浮点内部 `float ≤ double ≤ long double`；
- `float` 的数值范围约为 ±3.4×10³⁸，远大于 64 位整数（约 ±9.2×10¹⁸），所以 `int < float` 若指「数值上限」倒是对的，但 `float < double` 与前面的整型完全不是同一个维度；
- 更容易踩坑的是**精度**：`float` 只有约 7 位有效数字，无法精确表示所有 32 位 `int`。`int x = 16777217; float f = x;` 后 `f` 已经不等于 `x`。

正确记法：整型比「宽度与范围」，浮点比「范围与有效位数」，两者不要串成一条链。
:::

::: info 补充 · 别靠记忆，用标准头文件
`int` 到底是 2 字节还是 4 字节由实现决定。可移植的写法是：

```c
#include <limits.h>   /* INT_MAX, CHAR_BIT, LONG_MAX ... */
#include <stdint.h>   /* int8_t, int32_t, uint64_t, intptr_t ... */
#include <float.h>    /* FLT_MAX, DBL_EPSILON, FLT_DIG ... */
```

需要精确宽度（如网络协议、文件格式）时用 `int32_t` / `uint64_t`，输出可配合 `<inttypes.h>` 的 `PRId64` 等宏。
:::

## 2.3 sizeof

::: tip 定义
`sizeof` 是**静态**的：`sizeof` 的结果在编译期就确定了，运行期不会改变。
:::

- 语法：`sizeof(变量名/数据类型)`，返回所占的字节数
- 用 `%zu` 作占位符输出

```c
printf("%zu", sizeof(int));   /* 通常输出 4 */
```

::: warning 补充 · 一个例外
C99 的变长数组（VLA）是唯一 `sizeof` 在**运行期**求值的情况：`int a[n]; sizeof(a)` 等于 `n * sizeof(int)`。另外 `sizeof` 的操作数不求值，所以 `sizeof(i++)` 不会让 `i` 增加。
:::

## 2.4 整数运算与浮点数

- 两个整数的运算结果只能是整数（除法直接截断小数部分）
- 浮点数：带小数点的数值

::: danger 易错点
`5 / 2` 的结果是 `2` 而不是 `2.5`。要得到小数结果，至少一个操作数应是浮点数：`5.0 / 2`。

负数除法 C99 起**向零截断**（`-5 / 2 == -2`），取余的符号跟被除数一致（`-5 % 2 == -1`）；C89 之前是实现定义的。
:::

::: info 补充 · 溢出与浮点比较
- **有符号整数溢出是未定义行为**：`INT_MAX + 1` 不是"变成负数"，标准不保证结果，编译器可能直接优化掉相关判断。无符号整数溢出才有定义的回绕（模 2ⁿ）。
- **浮点数不要用 `==` 比较**：`0.1 + 0.2 != 0.3`。用 `fabs(a - b) < 1e-9`（需 `<math.h>`），并注意误差尺度应随数量级变化。
:::

## 2.5 运算符

**取余 `%`**：`7 % 3` 的结果是 `1`，只能对整数使用。

**复合赋值**：`+=`、`-=`、`*=`、`/=`、`%=`，如 `a += 5;` 等价于 `a = a + 5;`（但 `a` 只求值一次，对含副作用的表达式不等价）。

**递增递减 `++` / `--`**：

- `a++` 的值是 a 加 1 **以前**的值；`++a` 的值是 a 加了 1 **以后**的值；无论哪种写法，a 本身都已经加了 1
- `count++` 等效于 `count += 1`，等效于 `count = count + 1`

**比较运算符**：`==` 相等；`!=` 不相等；`>` 大于；`>=` 大于或等于；`<` 小于；`<=` 小于或等于。

- 比较结果成立则输出 1（真），不成立则输出 0（假）
- 判断是否相等（`==`、`!=`）的优先级比大小判断（`<`、`<=`、`>`、`>=`）**低**
- 连续的关系运算符从左到右进行

::: danger 易错点
`if (0 < x < 10)` 在 C 里**永远为真**（当 `x` 任意）：先算 `0 < x` 得到 0 或 1，再拿它和 10 比。必须写成 `if (0 < x && x < 10)`。

另一个高频错误：`if (x = 5)` 是赋值不是比较。写成 `if (5 == x)` 可以让编译器在漏写等号时报错。
:::

## 2.6 二进制负数与 unsigned

原笔记的思路：仿照十进制，用一个特殊的标志表示负数；取中间的数为 0，它左边是负数，右边是正数。

- **补码**：负数以补码形式存储
- 直观理解：一个字节（8 位）能表示 −128 ~ 127；在 0 的左边依次是 −1、−2、……
- `unsigned`：不以补码的形式看待这个数 —— 不能表达负数，但正数的范围扩大一倍
- 例题：`unsigned char` 表示 0 ~ 255，`signed char` 表示 −128 ~ 127

::: warning 订正 · 补码到底怎么算
原笔记写「补码和原码（源码）可以加出一个溢出的 1，两者互为凑满溢出的关系」，这个说法容易让人算错。准确定义是：

> 在 n 位下，负数 −x 的补码等于 **2ⁿ − x**；对正数 x 的二进制表示**按位取反再加一**就能得到它。

例如 8 位下 −5：5 是 `00000101`，取反 `11111010`，加一 `11111011`（= 251 = 256 − 5）。这样加法器无需区分正负，符号位也参与运算，这就是补码被采用的原因。
:::

::: info 补充 · char 的符号性
`char` 究竟是 `signed` 还是 `unsigned` **由实现决定**，不是标准规定的；`signed char` 与 `char` 也是不同类型。题目里「unsigned char 0~255」成立的前提是 `CHAR_BIT == 8`，虽然绝大多数平台如此，但标准只保证 `CHAR_BIT >= 8`。需要确定范围时请查 `<limits.h>` 的 `UCHAR_MAX`。
:::

## 2.7 整数与浮点的输入输出 · 输出进阶

- `%o` 用于输出八进制；`%x` 用于输出十六进制
- `%e` 或 `%E` 以科学计数法输出
- 输出精度：在 `%` 和 `f` 之间加上 `.n` 可以指定输出小数点后 n 位（输出时做四舍五入），如 `%.2f`
- `inf` 表示超过范围的浮点数（无穷）；`nan` 表示不存在的浮点数
- 带小数点的字面量是 `double`；`float` 需要 `f` 或 `F` 后缀表明身份，如 `3.14f`
- `fabs()`：求绝对值（需引入 `<math.h>`）

::: tip 提示
选择浮点类型：如果没有特殊需要，选 `double`。
:::

::: info 补充 · 格式宽度与标志
`%5d` 最小宽度 5、`%-5d` 左对齐、`%05d` 补零、`%.3f` 三位小数、`%+d` 强制显示符号。判断 `inf` / `nan` 用 `<math.h>` 的 `isfinite()`、`isnan()`，不要用 `==`。C23 新增 `%b` / `%B` 输出二进制整数。
:::

## 2.8 字符类型

`char`：字符的输入、输出与计算都按 ASCII 码进行。常用 ASCII 码：`'A'` 是 65，`'a'` 是 97，`'0'` 是 48。

**逃逸字符**：

| 字符 | 意义 | 字符 | 意义 |
| --- | --- | --- | --- |
| `\b` | 回退一格 | `\"` | 双引号 |
| `\t` | 到下一个表格位 | `\'` | 单引号 |
| `\n` | 换行 | `\\` | 反斜杠本身 |
| `\r` | 回车 | `\0` | 空字符（字符串结束） |

::: info 补充 · 大小写转换与字符判断
由 ASCII 的连续性可得 `ch - 'a' + 'A'` 把小写转大写、`ch - '0'` 把数字字符转数值。但判断字符类别请用 `<ctype.h>` 的 `isalpha()` / `isdigit()` / `tolower()`，并把参数转成 `unsigned char`，避免 `char` 为负时越界访问。
:::

## 2.9 类型转换

- **自动类型转换**：对于 `printf`，任何小于 `int` 的类型会被转换成 `int`；`float` 会被转换成 `double`。但 `scanf` 不会自动转换 —— `short` 输入要用 `%hd`
- **强制类型转换**（通常是转换成较大的类型）：格式 `(类型)值`

```c
int i = (int)3.14;   /* i == 3 */
```

- 强制转换类型的优先级高于四则运算

::: info 补充 · 整型提升的坑
「转换成较大的类型」这个说法不够准确。C 的**常用算术转换**有一套规则：先整型提升，再按「范围更大、能容纳另一方所有值」的原则选公共类型，还涉及有符号/无符号的优先级。典型陷阱：

```c
unsigned int u = 1;
int i = -2;
printf("%s\n", (i < u) ? "小于" : "不小于");  /* 输出「不小于」 */
```

`i` 被转换成 `unsigned int` 后变成一个很大的正数。混合有符号与无符号时，显式转换并打开 `-Wsign-compare` 告警最稳妥。
:::

## 2.10 逻辑类型与运算

```c
#include <stdbool.h>   /* 之后就可以使用 bool、true、false */
```

- 逻辑运算是对逻辑量进行的运算，结果只有 0 或 1
- 逻辑量是关系运算或逻辑运算的结果
- 优先级：`!` > `&&` > `\|\|`，例如 `!done && (count > MAX)`

| 运算符 | 描述 | 示例 | 结果 |
| --- | --- | --- | --- |
| `!` | 逻辑非 | `!a` | a 是 true 则结果为 false；a 是 false 则结果为 true |
| `&&` | 逻辑与 | `a && b` | a 和 b 都是 true 结果才为 true，否则为 false |
| `\|\|` | 逻辑或 | `a \|\| b` | a 和 b 都是 false 结果才为 false，否则为 true |

**运算符优先级总表**（由高到低）：

| 优先级 | 运算符 | 结合性 |
| --- | --- | --- |
| 1 | `()` | 从左到右 |
| 2 | `!` `+` `-` `++` `--`（单目） | 从右到左 |
| 3 | `*` `/` `%` | 从左到右 |
| 4 | `+` `-` | 从左到右 |
| 5 | `<` `<=` `>` `>=` | 从左到右 |
| 6 | `==` `!=` | 从左到右 |
| 7 | `&&` | 从左到右 |
| 8 | `\|\|` | 从左到右 |
| 9 | `=` `+=` `-=` `*=` `/=` `%=` | 从右到左 |

::: warning 订正 · 补全优先级表
原笔记的表中第 8 行（逻辑或 `\|\|`）在 PDF 里印成了空白，第 9 行条件运算符 `?:` 也没有列进来。完整顺序应为：`\|\|` 低于 `&&`，`?:` 又低于 `\|\|`、高于赋值。不确定时**一律加括号**，比背表可靠。
:::

**短路**：逻辑运算是自左向右进行的，如果左边的结果已经能够决定结果了，就不会做右边的计算。

- 对于 `&&`：左边是 false 时就不做右边了
- 对于 `\|\|`：左边是 true 时就不做右边了

::: danger 易错点
不要把赋值或复合赋值写进逻辑表达式（如 `a == 6 && b += 1`）—— 短路会让右边的赋值「有时执行、有时不执行」。短路也常被用来安全地写 `p != NULL && p->x > 0`。
:::

**条件运算符**：

```c
count = (count > 20) ? count - 10 : count + 10;
```

- `?` 前是条件，`?` 后是条件满足时的值，`:` 后是条件不满足时的值
- 与下面的 if-else 完全等价：

```c
if (count > 20) count = count - 10;
else            count = count + 10;
```

- 条件运算符的优先级只**高于**赋值，低于其他运算符

## 2.11 逗号运算

- 逗号用来连接两个表达式，并且以右边表达式的值作为整个表达式的结果
- 逗号的优先级是最低的
- 主要在 `for` 中使用：`for (i = 1, sum = 0; i <= 10; i++) { ... }`

::: tip 区分
调用函数时圆括号里的逗号是**标点符号**，不是运算。`f(a, b)` 传两个值；`f((a, b))` 是逗号运算，只传一个值（b 的值）。
:::
