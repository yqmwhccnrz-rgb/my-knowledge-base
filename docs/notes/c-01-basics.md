# 第1章 C语言入门基础

## 1.1 第一个 C 程序

```c
#include <stdio.h>

int main()
{
    printf("Hello, world!\n");
    return 0;
}
```

- 每个 C 程序从 `main` 函数开始执行
- 每条语句以分号 `;` 结尾，大括号 `{ }` 表示一个代码块
- `#include <stdio.h>` 引入标准输入输出库

::: info 补充 · main 与编译
标准规定的完整签名是 `int main(void)` 或 `int main(int argc, char *argv[])`；写成 `int main()` 在 C89～C17 里表示「参数未指定」，建议明确写 `void`。`return 0` 向操作系统报告「正常结束」，C99 起在 `main` 末尾省略 `return` 会默认返回 0。

命令行编译建议始终打开告警：`gcc -std=c11 -Wall -Wextra -o hello hello.c`。
:::

## 1.2 注释

1. 单行注释：`// 注释内容`
2. 多行注释：`/* 注释内容 */`
3. VS 快捷键：
   - 添加注释：`Ctrl + K`，`Ctrl + C`
   - 取消注释：`Ctrl + K`，`Ctrl + U`

::: tip 提示
注释是写给读代码的人（包括未来的自己）看的，编译器会直接忽略它们。复杂的逻辑一定要写注释 —— 但更重要的是解释**为什么**这么写，而不是重复代码在做什么。
:::

::: warning 补充 · 多行注释不能嵌套
`/* ... /* ... */ ... */` 会在第一个 `*/` 就结束，剩下的内容会变成代码并报错。想临时注释掉一整段含注释的代码，用 `#if 0 ... #endif` 更稳妥。
:::

## 1.3 关键字

`int`、`return` 等都是 C 语言的关键字（保留字），有固定含义，**不能用作变量名**。

::: info 补充 · 关键字随标准增加
C89 有 32 个关键字，C99 增加 `_Bool`、`_Complex`、`_Imaginary`、`inline`、`restrict`，C11 增加 `_Alignas`、`_Alignof`、`_Atomic`、`_Generic`、`_Noreturn`、`_Static_assert`、`_Thread_local`，C23 又加入 `true`、`false`、`nullptr`、`typeof` 等。写代码时避开这些名字即可，不必死记。
:::

## 1.4 常量

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 整型常量 | 正整数、负整数、零 | `18`、`-5`、`0` |
| 实型常量 | 所有带小数点的数字 | `0.93` 等同于 `.93`，`18.0` 等同于 `18.` |
| 字符常量 | 单引号引起来的字母、数字、符号 | `'a'`、`'1'`、`'+'` |
| 字符串常量 | 双引号引起来的内容 | `"hello"` |

::: info 补充 · 字面量的类型
带小数点的字面量默认是 `double`，写 `float` 要加后缀 `3.14f`；整数字面量默认是 `int`，超出范围会依次升级到 `long`、`long long`，可用 `18L`、`18LL`、`18U` 显式指定。`0x1F` 是十六进制，`0b1010` 是 C23 起支持的二进制写法。
:::

## 1.5 变量

**语法**：`数据类型 变量名;`

```c
int a = 10;
int b = 20;
int c = a + b;
```

- 一条语句可以定义多个变量：`int a, b, c;`（定义了三个变量）
- 变量只能保存一个值；同一作用域内变量名不允许重复定义
- 变量在使用之前一定要赋值（初始化）
- 变量定义的位置：C99 及以后的标准中任意位置均可定义；C89 要求变量定义在块的最前面，然后才能开始使用
- 变量的作用域范围一定要清楚（详见 4.7 本地变量）

::: danger 易错点 · 订正
原笔记写「未初始化的变量中存放的是内存残留的随机值，直接使用会产生不可预料的错误」。

更准确的说法是：**读取未初始化的自动变量属于未定义行为（UB）**。它不一定会给你一个"随机值" —— 编译器可以假定这种情况不会发生，从而删掉整段代码、让两个分支都走同一条路。局部变量一律在定义时初始化：

```c
int count = 0;      /* 好 */
int count;          /* 危险：后续任何读取都是 UB */
```
:::

## 1.6 输出 printf

`printf(参数1, 参数2);` —— 参数 1 是输出内容的最终样式（含占位符），参数 2 是填补的内容。

| 占位符 | 含义 |
| --- | --- |
| `%d` | 整型（`int`） |
| `%f` | 实型（`float` / `double` 输出均可） |
| `%lf` | 实型（`double`，主要用于 `scanf`） |
| `%c` | 字符型（`char`） |
| `%s` | 字符串 |
| `%zu` | `sizeof` 测量结果的占位符 |

```c
printf("%d", 18);   /* 以整型格式输出 18 */
```

::: warning 订正 · printf 里的 %lf
表格容易让人误以为「输出 `double` 要用 `%lf`」。实际上在 `printf` 中，可变参数里的 `float` 会被自动提升为 `double`，所以 **`%f` 就是输出 `double` 的占位符**；`%lf` 只是 C99 起被允许写、且与 `%f` 完全等价。

真正需要区分的是 `scanf`：`%f` 读入 `float*`，`%lf` 读入 `double*`，写错就是未定义行为。
:::

::: warning 补充 · 占位符不匹配是 UB
`printf("%d", 3.14)` 或 `printf("%zu", 1)` 这类类型不匹配，标准不保证任何结果，轻则输出乱码，重则崩溃。开启 `-Wall -Wextra` 后编译器会直接提示格式串问题。
:::

## 1.7 输入 scanf

- `scanf` 需要配合 `&` 取地址：`scanf("%d", &x);`
- 输入浮点数（`double`）时必须用 `%lf` 作占位符
- `scanf` 不会像 `printf` 那样自动做类型提升（详见 2.9）

::: danger 易错点
忘写 `&` 是最常见的运行时崩溃原因之一：`scanf("%d", x)` 会把 `x` 的**值**当成地址去写。`%s` 读入字符串时数组名本身已是地址，**不写** `&`。

另外要检查返回值：`if (scanf("%d", &x) != 1) { /* 输入非法 */ }`，否则输入字母时 `x` 保持未初始化状态。
:::

## 1.8 换行符

| 平台 | 换行符 |
| --- | --- |
| Windows | `\r\n` |
| Mac（早期） | `\r` |
| Linux / 现代 macOS | `\n` |

::: tip 提示
C 代码里统一写 `\n` 即可，编译器与运行环境会处理平台差异（现代 macOS 也用 `\n`）。文本模式下的标准库会自动完成与平台换行符的转换。
:::

## 本章补充 · C 标准版本速查

| 标准 | 常用称呼 | 与笔记相关的变化 |
| --- | --- | --- |
| C89 / C90 | ANSI C | 变量必须在块首定义；`void f()` 表示参数未知 |
| C99 | — | 变量可随处定义、`bool`（`<stdbool.h>`）、`long long`、`%zu`、变长数组、指定初始化 |
| C11 | — | 原子操作、`_Static_assert`、匿名结构/联合 |
| C17 | — | C11 的修订版，无新语言特性 |
| C23 | C2x | `true`/`false`/`nullptr` 成为关键字、`void f()` 等价于 `void f(void)`、`%b` 二进制输出 |

笔记里凡涉及「C99 ONLY」「传统 C」的地方，都可以对照这张表理解。
