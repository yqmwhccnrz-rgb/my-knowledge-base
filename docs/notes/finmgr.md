## 第 1 章 财务管理概述

### 1.1 财务管理的主要内容（★）

财务管理是对资金的管理，主体是公司制企业，基本原理也适用于其他营利组织。内容包括三大领域：

| 领域 | 客体/对象 | 关键决策 |
| --- | --- | --- |
| 长期投资 | 经营性长期资产（厂房、设备等）的直接投资 | 资本预算（现金流规模、时间、风险） |
| 长期筹资 | 长期资本（权益资本、长期债务资本） | 资本结构决策、股利分配决策 |
| 营运资本管理 | 流动资产与流动负债 | 营运资本投资政策、筹资政策 |

::: tip 直接投资 vs 间接投资
直接投资＝将现金直接投入经营性资产、继续控制实物资产（如建厂房）；间接投资＝将现金投给其他企业、由对方再投资（如买股票债券），投资者不直接控制经营性资产。对子公司的长期股权投资属于**经营性投资**，评价方法与直接投资相同。
:::

### 1.2 财务管理目标与利益相关者要求（★★）

| 目标观点 | 核心 | 主要局限 |
| --- | --- | --- |
| 利润最大化 | 利润代表新创财富 | 未考虑时间、投入资本、风险 |
| 每股收益最大化 | 利润与投入资本挂钩 | 仍忽视时间、风险；不同公司每股收益不可比 |
| **股东财富最大化**（教材采纳） | 增加股东财富＝股东权益市场增加值 | 是财务管理基本目标；资本市场有效且投资额不变时，股价最大化与之等价 |

**利益相关者协调**：与债权人的冲突（过度举债/高风险投资）→ 限制性条款、收回借款；与经营者的冲突（道德风险/逆向选择）→ 监督、激励；其他利益相关者（员工、客户、社区、政府）要求通过合约与法律保障。

::: danger 易错 · 目标口径
"公司目标""财务目标""财务管理目标"在教材中作为同义语使用。股价升降反映投资者对公司股权价值的评价，但**公司与股东之间的交易（如分派股利除权）影响股价不影响股东财富**。
:::

### 1.3 财务管理的基础概念和基本理论（★★）

五大基础理论：① 货币时间价值；② 风险与报酬（含投资组合理论、CAPM）；③ 价值评估理论；④ 风险评估理论；⑤ 资本结构理论。

### 1.4 金融工具与金融市场（★★）

| 金融工具 | 子类 |
| --- | --- |
| 固定收益证券 | 债券、优先股（收益固定） |
| 权益证券 | 普通股（收益不固定） |
| 衍生证券 | 期权、期货、互换、认股权证 |

**金融市场**：货币 vs 资本市场（期限 1 年）、债务 vs 股权、一级（发行）vs 二级（流通）、场内 vs 场外。

**有效资本市场**：
- 含义：价格能迅速反映信息。
- 程度：弱式（反映历史信息，技术分析无用）、半强式（反映公开信息，基本面分析无用）、强式（反映所有信息，内幕交易也无效）。
- 意义：有效市场下，财务决策应聚焦"现金流"而非"择时炒作"；管理者不能靠会计政策选择持续误导股价。

### 1.5 跨国财务管理（★）

外汇风险三类：交易风险、外币折算风险、经济风险。管理手段：远期合约、货币市场套期、提前/延后收付、分散经营。跨国筹资注意政治风险（购买保险、利用当地资源、评估时加成风险报酬）。

## 第 2 章 财务报表分析和财务预测

### 2.1 财务比率分析（★★★）

**短期偿债能力**：
| 比率 | 公式 | 说明 |
| --- | --- | --- |
| 营运资本 | 流动资产 − 流动负债 | 正数愈大越安全 |
| 流动比率 | 流动资产 ÷ 流动负债 | 营业周期短的行业较高 |
| 速动比率 | （流动资产 − 存货）÷ 流动负债 | 剔存货 |
| 现金比率 | （货币资金 + 交易性金融资产）÷ 流动负债 | 最强 |
| 现金流量比率 | 经营活动现金流量净额 ÷ 流动负债 | 动态偿债 |

**长期偿债能力**：资产负债率、产权比率、权益乘数（＝资产/权益＝1＋产权比率）、长期资本负债率、利息保障倍数（息税前利润/利息费用）、现金流量利息保障倍数、现金流量债务比。

**营运能力**（周转率＝周转额/资产）：应收账款、存货、流动资产、非流动资产、总资产周转率（次数＝营业收入/资产；天数＝365/次数）。

**盈利能力**：营业净利率、总资产净利率（＝营业净利率×总资产周转次数）、**权益净利率（ROE）**。

**市价比率**：
- 市盈率 PE ＝ 每股市价 ÷ 每股收益
- 市净率 PB ＝ 每股市价 ÷ 每股净资产
- 市销率 PS ＝ 每股市价 ÷ 每股营业收入

### 2.2 杜邦分析体系（★★★）

![杜邦分析体系（权益净利率分解）](/fin/fin-dupont.svg)

权益净利率 ＝ 营业净利率 × 总资产周转次数 × 权益乘数。杜邦体系将 ROE 拆为"获利能力 × 营运能力 × 偿债能力（财务杠杆）"三个驱动因素，便于跨公司比较短板。

::: danger 易错 · 杜邦局限性
传统杜邦未区分经营活动与金融活动，总资产含金融资产，会扭曲周转与杠杆含义。教材主推**管理用财务分析体系**替代。
:::

### 2.3 管理用财务报表（★★★）

**管理用资产负债表**：资产＝经营资产＋金融资产；负债＝经营负债＋金融负债；净经营资产＝净负债＋股东权益。
- 净经营资产 ＝ 经营资产 − 经营负债
- 净负债 ＝ 金融负债 − 金融资产

**管理用利润表**：净利润 ＝ 税后经营净利润 − 税后利息费用。
- 税后经营净利润 ＝ 税前经营利润 ×（1 − 税率）
- 税后利息费用 ＝ 利息费用 ×（1 − 税率）

**管理用财务分析体系**：
- 权益净利率 ＝ 净经营资产净利率 ＋ （净经营资产净利率 − 税后利息率）× 净财务杠杆
- 净经营资产净利率 ＝ 税后经营净利润 ÷ 净经营资产
- 杠杆贡献率 ＝ （净经营资产净利率 − 税后利息率）× 净财务杠杆

### 2.4 财务预测：销售百分比法（★★★）

**外部融资额** ＝ 预计经营资产增加 − 预计经营负债增加 − 预计利润留存
- 或：外部融资额 ＝（经营资产销售百分比 − 经营负债销售百分比）× 销售收入增加 − 预计净利润 ×（1 − 股利支付率）

**外部融资销售增长比** ＝ 外部融资额 ÷ 销售收入增加。当其为 0 时的增长率即为"内含增长率"（仅靠内部留存即可支撑的增长）。

**可持续增长率**：不增发新股、不改变经营效率与财务政策时，销售能达到的最大增长率：
- g\* ＝ 股东权益增长率 ＝ 留存收益率 × 期初权益净利率（或期末权益口径的等价变形）
- 基于管理用报表：g\* ＝ 营业净利率 × 净经营资产周转次数 × 净财务杠杆 × 利润留存率 ÷（1 − 该乘积）

::: tip 实际增长率 vs 可持续增长率
实际增长率 > 可持续增长率 → 资金短缺，需增加负债/权益或提高经营效率；反之资金闲置。管理用口径公式用于"不增发、保持当前政策"的情形。
:::

## 第 3 章 价值评估基础

### 3.1 利率（★）

| 理论 | 核心观点 |
| --- | --- |
| 无偏预期理论 | 长期利率是未来短期利率预期的平均 |
| 市场分割理论 | 各期限市场相互独立，利率由各自供需决定 |
| 流动性溢价理论 | 长期利率＝预期平均短期利率＋流动性溢价（教材倾向） |

名义利率 r ＝ 真实无风险利率 ＋ 通胀溢价 ＋ 违约风险溢价 ＋ 流动性溢价 ＋ 期限风险溢价。

### 3.2 货币时间价值（★★★）

| 项目 | 公式（利率 i，期数 n） |
| --- | --- |
| 复利终值 | F ＝ P ×（1＋i）ⁿ ＝ P ×（F/P，i，n） |
| 复利现值 | P ＝ F ÷（1＋i）ⁿ ＝ F ×（P/F，i，n） |
| 普通年金终值 | F ＝ A ×[（1＋i）ⁿ − 1]/i |
| 普通年金现值 | P ＝ A ×[1 −（1＋i）⁻ⁿ]/i |
| 预付年金 | 在普通年金基础上 ×（1＋i） |
| 递延年金 | 先算 m 期后 n 期的现值，再折现 m 期 |
| 永续年金现值 | P ＝ A ÷ i |

**报价利率与有效年利率**：有效年利率 EAR ＝（1 ＋ 报价利率/m）ᵐ − 1。

### 3.3 风险与报酬（★★★）

- 预期值 E（R）＝ ΣpᵢRᵢ；方差 σ² ＝ Σpᵢ（Rᵢ − E）²；标准差 σ ＝ √方差；变异系数 CV ＝ σ/E。
- 组合期望 ＝ 各证券期望加权；组合方差含协方差项：σₚ² ＝ ΣΣwᵢwⱼCov(Rᵢ,Rⱼ)。
- 相关系数 ρ 越低，分散化效果越好；ρ＝−1 可完全消除风险，ρ＝1 无效分散。
- **资本市场线 CML**：总风险（标准差）与报酬的关系，切点组合为市场组合。
- **β 系数**：系统风险度量，β＝Cov(Rᵢ,Rₘ)/σₘ²；组合 β 为个别 β 加权。
- **证券市场线 SML / CAPM**：Rᵢ ＝ R_f ＋ βᵢ（Rₘ − R_f）。截距为无风险利率，斜率为市场风险溢价。

::: danger 易错 · 系统风险 vs 非系统风险
非系统风险可通过组合分散，市场只对**系统风险（β）**给予补偿。CAPM 中个别资产或组合的"要求的必要报酬率"只与 β 有关，与总风险无关。
:::

### 3.4 债券、股票价值评估（★★★）

**债券价值** ＝ 各期利息现值 ＋ 本金现值（按必要报酬率折现）。债券价值与必要报酬率反向变动；溢价/折价/平价取决于票面利率与必要报酬率的关系。流通债券（非时点付息）需注意现金流与折现期匹配。

**普通股价值**：
- 固定增长模型：P₀ ＝ D₁ ÷（rₛ − g）＝ D₀（1＋g）÷（rₛ − g）
- 零增长：P₀ ＝ D ÷ rₛ
- 阶段性增长：分段折现
- 期望报酬率 rₛ ＝ D₁/P₀ ＋ g

**优先股**按固定股息用永续年金；**永续债**类似。

## 第 4 章 资本成本

### 4.1 资本成本的概念与应用（★★）

资本成本既是**筹资**的代价，也是**投资**的最低可接受报酬率（项目的资本成本取决于其系统风险）。应用：投资决策、筹资决策、营运资本管理、企业价值评估、业绩评价。

### 4.2 债务资本成本估计（★★★）

| 方法 | 适用 |
| --- | --- |
| 到期收益率法 | 有上市债券、交易活跃 |
| 可比公司法 | 无上市债券，找可比公司（同行业、同期限、同信用） |
| 风险调整法 | 无上市债券：债务成本 ＝ 政府债券收益率 ＋ 信用风险补偿率 |
| 财务困境调整 | 考虑违约后下调 |

::: tip 税后债务成本
利息可抵税，税后债务成本 ＝ 税前成本 ×（1 − 所得税税率）。
:::

### 4.3 普通股资本成本估计（★★★）

- **资本资产定价模型**：rₛ ＝ R_f ＋ β×（Rₘ − R_f）
- **股利增长模型**：rₛ ＝ D₁/P₀ ＋ g
- **债券收益率风险调整模型**：rₛ ＝ 债券税后成本 ＋ 风险溢价

### 4.4 加权平均资本成本（★★★）

WACC ＝ Σ（个别资本成本 × 权重）。

| 权重口径 | 说明 |
| --- | --- |
| 账面价值权重 | 易取得但偏离市场 |
| 实际市场价值权重 | 反映当前市价，随市价波动 |
| 目标资本结构权重 | 教材推荐，用于筹资决策 |

## 第 5 章 投资项目资本预算

### 5.1 投资项目评价方法（★★★）

![投资项目资本预算：决策方法与评价](/fin/fin-capbudget.svg)

| 方法 | 规则 | 注意 |
| --- | --- | --- |
| 净现值 NPV | NPV ≥ 0 可行 | 绝对数，反映财富增加额 |
| 内含报酬率 IRR | IRR ≥ 必要报酬率可行 | 与 NPV 结论可能冲突（非常规现金流、互斥项目规模/时限不同） |
| 回收期 | 小于基准回收期可行 | 未考虑时间价值（静态）或仅折现后（动态），忽视期满现金流 |
| 会计报酬率 | 大于要求可行 | 使用会计利润而非现金流，易误导 |

### 5.2 投资项目现金流量估计（★★★）

- 项目现金流＝**增量**现金流（区分相关/非相关）。
- 经营期营业现金流量 OCF 三种算法（等价）：
  - OCF ＝ 营业收入 − 付现成本 − 所得税
  - OCF ＝ 税后净利润 ＋ 折旧
  - OCF ＝（收入 − 付现成本）×（1 − T）＋ 折旧 × T（折旧抵税）
- 注意：折旧本身不是现金流，但折旧×税率是**抵税额**；机会成本、号损、营运资本垫支与收回都要计入；沉没成本、过去已发生费用不计入。

### 5.3 互斥项目的优选（★★）

- 投资额不同 → 用**差额分析法（ΔNPV）**或现值指数。
- 项目期限不同 → **共同年限法**（重置为相同寿命）或**等值年金法**（EAA＝NPV/年金现值系数）。
- 固定资产更新决策：比较**平均年成本（ACE）**＝ 总成本现值 ÷ 年金现值系数，选较小者；若新旧设备尚可使用年限不同，须用共同年限/EAA。

### 5.4 敏感分析（★）

- **最大最小法**：令 NPV＝0，反求某变量的临界值。
- **敏感程度法**：计算敏感系数 ＝ 目标值变动百分比 ÷ 变量变动百分比。

## 第 6 章 期权价值评估

### 6.1 期权类型与投资策略（★★）

| 类型 | 多头权利义务 |
| --- | --- |
| 看涨期权（买权） | 有权以执行价买入 |
| 看跌期权（卖权） | 有权以执行价卖出 |
| 保护性看跌期权 | 股票＋看跌，锁定最低价值、保留上行收益 |
| 抛补性看涨期权 | 股票＋卖看涨，牺牲上行、赚取期权费 |
| 对敲（跨式） | 同时买看涨和看跌，赌大幅波动 |

### 6.2 期权价值评估（★★★）

期权价值 ＝ 内在价值 ＋ 时间溢价。
- 看涨内在价值 ＝ max（股票市价 − 执行价，0）；看跌 ＝ max（执行价 − 股票市价，0）。
- 影响期权价值的主要因素：股价、执行价、到期期限、波动率（最重要正向因素）、无风险利率、红利。

**二叉树模型**：单期 u/d 上涨/下跌因子，风险中性概率 p ＝（1＋r − d）/（u − d），期权价值 ＝ [p×上行价值 ＋（1−p）×下行价值] ÷（1＋r）。

**布莱克—斯科尔斯模型（BS）**：需输入 S₀（股价）、X（执行价）、r_c（连续复利无风险利率）、t（到期时间）、σ（波动率），输出看涨期权价值 C₀；看跌由平价关系 P₀ ＝ C₀ ＋ X·e^(-rt) − S₀。

### 6.3 实物期权（★★）

扩张期权（看涨）、放弃期权（看跌）、时机选择期权。在 NPV 基础上追加期权价值：项目价值 ＝ NPV ＋ 期权价值。

## 第 7 章 企业价值评估

### 7.1 价值评估对象（★）

企业整体经济价值＝持续经营价值（核心）＋ 清算价值（破产时）。实体价值＝股权价值＋净债务价值。

### 7.2 现金流量折现模型（★★★）

![价值评估两大路径](/fin/fin-valuation.svg)

| 模型 | 现金流 | 公式（永续增长） |
| --- | --- | --- |
| 股利现金流量模型 | 股利 | 股权价值 ＝ Σ Dₜ/（1＋rₛ）ᵗ |
| 股权自由现金流 FCFE | 股权自由现金流 | 同上，用 FCFE 替代 D |
| 实体现金流 FCFF | 实体自由现金流 | 实体价值 ＝ Σ FCFFₜ/（1＋WACC）ᵗ；股权价值＝实体价值−净债务 |

- 永续增长模型：价值 ＝ 下一期现金流 ÷（折现率 − 增长率 g），要求 g < 折现率。
- 两阶段/三阶段：高速增长期逐期折现 ＋ 后续永续增长现值。
- FCFF ＝ 税后经营净利润 ＋ 折旧摊销 − 经营营运资本增加 − 资本支出。

### 7.3 相对价值模型（★★★）

| 模型 | 驱动因素 | 修正思路 |
| --- | --- | --- |
| 市盈率 P/E | 增长潜力 | 修正市盈率＝目标 P/E ÷（预期增长率×100） |
| 市净率 P/B | 净资产报酬、风险 | 修正市净率＝目标 P/B ÷（预期 ROE×100） |
| 市销率 P/S | 销售净利率 | 修正市销率＝目标 P/S ÷（预期销售净利率×100） |

目标企业价值 ＝ 可比企业平均乘数（或修正乘数）× 目标企业对应变量。

::: danger 易错 · 相对价值法的"可比"
市盈率法适用于连续盈利企业；市净率适用于净资产为正且 PB 较稳定的重资产企业；市销率适用于销售成本率较稳定的企业（如服务/零售）。亏损企业不宜用市盈率。
:::

## 第 8 章 资本结构

### 8.1 资本结构理论（★★★）

![资本结构理论演进](/fin/fin-mm.svg)

| 理论 | 核心结论 |
| --- | --- |
| 无税 MM | 资本结构不影响企业价值与 WACC（完美市场） |
| 有税 MM | 负债越多企业价值越大、WACC 越低（利息抵税） |
| 权衡理论 | 负债利益（税盾）与财务困境成本权衡，存在最优资本结构 |
| 代理理论 | 债务代理收益（约束管理者）与代理成本权衡 |
| 优序融资理论 | 融资偏好：内部留存 > 债务 > 股权（信息不对称） |

### 8.2 资本结构决策方法（★★）

| 方法 | 依据 |
| --- | --- |
| 资本成本比较法 | 选 WACC 最低的方案 |
| 每股收益无差别点法 | 令不同方案 EPS 相等，据 EBIT 与无差别点大小选债务或股权 |
| 企业价值比较法 | 选公司价值最大且 WACC 最低的方案（最全面） |

### 8.3 杠杆系数（★★★）

| 系数 | 公式 |
| --- | --- |
| 经营杠杆 DOL | ＝ 边际贡献 ÷ 息税前利润 ＝（EBIT＋F）/EBIT |
| 财务杠杆 DFL | ＝ EBIT ÷（EBIT − I） |
| 联合杠杆 DTL | ＝ DOL × DFL ＝ 边际贡献 ÷（EBIT − I） |

::: tip 杠杆含义
DOL 反映经营风险（固定成本越大越高）；DFL 反映财务风险（利息越大越高）；DTL 反映总风险，表示销售收入变动 1% 引起每股收益变动的百分点。
:::

## 第 9 章 长期筹资

### 9.1 长期债务筹资（★★）

- 长期借款：含保护性条款（一般性、例行性、特殊性）；成本较低、速度快，但限制多。
- 债券：发行价格由面值、票面利率、市场利率决定；偿还方式含到期偿还、提前偿还、赎回/回售；优点（筹资规模大、锁定成本）与缺点（财务风险高）。

### 9.2 普通股筹资（★★）

| 方式 | 要点 |
| --- | --- |
| 首次公开发行 IPO | 由证券公司承销，定价采用询价/竞价 |
| 配股 | 向原股东按比例低价配售，原股东有优先认购权 |
| 增发新股 | 公开增发或定向增发 |

::: danger 易错 · 股权再融资影响
配股/增发会稀释每股收益与股价（除权）；若发行价低于市价，原股东财富可能受损（除非参与配股）。评价时要比较"除权后股价与参与/不参与"的财富变化。
:::

### 9.3 混合筹资（★★）

| 工具 | 关键 |
| --- | --- |
| 优先股 | 固定股息、优先分配、通常无表决权；税后支付，无抵税 |
| 永续债 | "债"还是"股"看合同实质；利息可抵税 |
| 认股权证 | 与债券捆绑发行，稀释股权、降低票面利率 |
| 可转换债券 | 含转股权；票面利率低；转股后债务转权益；赎回/回售/转股价修正条款 |

可转债 vs 附认股权证债券：可转债转股权与债券不可分（转股后债券消失），附权证债券行权后债券仍存续。

### 9.4 租赁筹资（★★）

- 租赁原因：节税、降低交易成本、减少不确定性。
- 租赁决策：比较"租赁净现值"与"购买净现值"——租赁净现值＝租赁替代购买所增加的 NPV，大于 0 选租赁。
- 售后租回：资产出售同时租回，实质是抵押融资，售价与公允价值之差计入递延收益并分期摊销。

## 第 10 章 股利分配、股票分割与股票回购

### 10.1 股利理论与政策（★★）

| 理论 | 观点 |
| --- | --- |
| 股利无关论（MM） | 完美市场下股利政策不影响价值 |
| 股利相关论（"一鸟在手"、税差、客户效应、信号、代理） | 股利政策影响价值 |

**四种股利政策**：
- 剩余股利政策：先满足投资需求，余下分配（保持目标资本结构）。
- 固定/稳定增长股利政策：稳定信号，但现金流压力大。
- 固定股利支付率政策：按固定比例分配，波动大。
- 低正常股利加额外股利政策：灵活。

### 10.2 股票分割与回购（★★）

| 行为 | 对股价 | 对股本/权益 |
| --- | --- | --- |
| 股票分割 | 除权后下降（股数↑） | 股本不变、每股面值↓，权益总额不变 |
| 股票回购 | 通常提升股价 | 减少流通股、提升 EPS 与 ROE，现金流出 |

股票回购意义：替代现金股利、优化资本结构、传递股价低估信号；方式含公开市场、现金要约、协议。

## 第 11 章 营运资本管理

### 11.1 投资与筹资策略（★★）

| 策略 | 流动资产/短期资金来源 | 风险报酬特征 |
| --- | --- | --- |
| 适中型 | 匹配期限 | 风险报酬居中 |
| 保守型 | 较多流动资产 + 较少短期资金 | 风险低、收益低 |
| 激进型 | 较少流动资产 + 较多短期资金 | 风险高、收益高 |

### 11.2 现金管理（★★）

- **存货模式**：最佳现金持有量 C\* ＝ √(2×T×F/K)，最小相关成本 TC＝√(2×T×F×K)（T 年需求、F 交易成本、K 机会成本率）。
- **随机模式**：设定 H（上限）与 L（下限 R 回归线），H ＝ 3R − 2L，R 取决于机会成本、转换成本与方差。

### 11.3 应收账款管理（★★）

信用政策三要素：信用期间、信用标准（如 5C）、现金折扣政策。改变政策须用"边际收益（边际利润）− 边际成本（机会成本、坏账、收账费用）"决策。

### 11.4 存货管理（★★★）

**经济订货量基本模型**：
- Q\* ＝ √(2×K×D/K_c) （D 年需要量，K 每次订货变动成本，K_c 单位储存变动成本）
- 最小相关总成本 TC(Q\*) ＝ √(2×K×D×K_c)
- 最佳订货次数 ＝ D/Q\*；最佳周转天数 ＝ 365/次数

**扩展**：陆续供应（供应期）、保险储备（缺货成本与储存成本权衡定再订货点）、数量折扣（比较总价）。

### 11.5 短期债务管理（★★）

- 应付账款：免费信用、放弃现金折扣成本 ＝ 折扣率/(1−折扣率) × 360/(信用期−折扣期)。
- 短期借款：信用条件（周转信贷协定、补偿性余额、借款抵押、利率和偿还方式）。

## 第 12 章 成本管理会计的基础概念

### 12.1 成本概念与分类（★★）

| 分类标准 | 类型 |
| --- | --- |
| 计入成本对象方式 | 直接成本（直接材料、直接人工）、间接成本（制造费用分摊） |
| 经济用途（功能） | 生产成本（直接材料/人工/制造费用）、非生产成本（销售/管理费用） |
| 成本性态 | 固定成本、变动成本、混合成本（高低点法/回归法分解） |

::: tip 成本性态
固定成本（约束性/酌量性）不随产量变；变动成本随产量正比例变；混合成本可用高低点法分解：单位变动成本 b＝(高点成本−低点成本)/(高点业务量−低点业务量)，固定成本 a＝高点成本−b×高点业务量。
:::

### 12.2 成本管理会计原则（★）

成本效益原则、技术与行为因素原则、不同目的不同成本原则、相关性原则（决策用"相关成本"＝未来、差额、可避免）。

## 第 13 章 产品成本计算

### 13.1 生产费用的归集和分配（★★★）

![成本计算基本方法](/fin/fin-costmethod.svg)

- 材料/职工薪酬/外购动力：按受益对象直接计入或分配计入。
- 制造费用：按工时、机器小时等标准分配。
- 辅助生产费用分配：直接分配法、交互分配法、计划成本分配法、代数分配法。

**完工产品与在产品成本分配**：
| 方法 | 适用 |
| --- | --- |
| 不计算在产品成本 | 在产品数量很少 |
| 在产品成本按年初数固定 | 数量稳定 |
| 约当产量法 | 数量变动大（折合约当产量） |
| 定额成本/定额比例 | 定额管理基础好 |

**联产品/副产品**：联产品按实物量、售价、可变现净值等分配联合成本；副产品按可变现净值等扣除。

### 13.2 成本计算基本方法（★★★）

| 方法 | 适用 | 特点 |
| --- | --- | --- |
| 品种法 | 大量大批单步骤 | 按产品品种归集 |
| 分批法 | 单件小批 | 按批别归集，成本计算期与产期一致 |
| 分步法 | 大量大批多步骤 | 逐步结转（综合/分项）或平行结转 |

- **逐步结转分步法**：半成品成本随实物流转，需成本还原（综合结转时）。
- **平行结转分步法**：各步骤只核算本步发生的费用及应计入产成品的"份额"，不结转半成品成本，优点是不必逐步结转与还原，但无法提供各步骤半成品成本。

## 第 14 章 标准成本法

### 14.1 标准成本的制定（★★）

| 成本项目 | 标准成本 |
| --- | --- |
| 直接材料 | 用量标准 × 价格标准 |
| 直接人工 | 工时标准 × 工资率标准 |
| 变动制造费用 | 工时标准 × 分配率标准 |
| 固定制造费用 | 工时标准 × 固定费用分配率标准（产能基础） |

标准成本分理想/正常、现行/基本等类型。

### 14.2 成本差异分析（★★★）

| 成本 | 价差（价格差异） | 量差（数量差异） |
| --- | --- | --- |
| 直接材料 | 材料价格差异＝(实际价−标准价)×实际量 | 材料数量差异＝(实际量−标准量)×标准价 |
| 直接人工 | 工资率差异＝(实际工资率−标准)×实际工时 | 人工效率差异＝(实际工时−标准)×标准工资率 |
| 变动制造费用 | 耗费差异＝(实际分配率−标准)×实际工时 | 效率差异＝(实际工时−标准)×标准分配率 |
| 固定制造费用 | 二因素：耗费差异、能量差异 | 三因素：耗费、闲置能量、效率差异 |

::: danger 易错 · 固定制造费用差异
固定制造费用差异分解为"二因素"（耗费、能量）或"三因素"（耗费、闲置能量、效率）；注意能量差异＝预算−标准成本，闲置能量差异＝(产能工时−实际工时)×标准分配率，效率差异＝(实际工时−实际产量标准工时)×标准分配率。
:::

## 第 15 章 作业成本法和生命周期成本法

### 15.1 作业成本法（★★）

| 要素 | 含义 |
| --- | --- |
| 资源 | 耗费的成本源泉（材料、人工、折旧） |
| 作业 | 企业生产活动中的具体工作（单位/批次/产品/支持级） |
| 成本动因 | 驱动成本发生的因素（资源动因、作业动因） |

**两阶段分配**：① 资源成本 → 作业（按资源动因）；② 作业成本 → 成本对象（按作业动因）。强调因果关系的多维度动因，比传统单一工时分配更精确。

| 优点 | 局限性 | 适用条件 |
| --- | --- | --- |
| 更准确的产品/客户成本、支持作业管理 | 工作量大、成本动因选择主观 | 间接费用比重大、产品多样、自动化程度高 |

### 15.2 生命周期成本法（★）

覆盖产品从研发、设计、生产、营销到售后全周期的累计成本，早期设计阶段对成本影响最大（"上游"控制）。适用于研发密集型行业。

## 第 16 章 本量利分析

### 16.1 本量利一般关系（★★★）

![本量利分析（CVP）基本关系](/fin/fin-cvp.svg)

- 损益方程式：利润 ＝ 单价×销量 − 单位变动成本×销量 − 固定成本
- 边际贡献：单位边际贡献 ＝ 单价 − 单位变动成本；边际贡献率 ＝ 单位边际贡献/单价
- 利润 ＝ 销量×单位边际贡献 − 固定成本 ＝ 边际贡献总额 − 固定成本
- 假设：相关范围、线性、产销平衡、品种结构不变。

### 16.2 保本分析（★★★）

- 保本销售量 ＝ 固定成本 ÷ 单位边际贡献；保本销售额 ＝ 固定成本 ÷ 边际贡献率
- 盈亏临界点作业率 ＝ 保本销售量 ÷ 正常销售量
- 安全边际 ＝ 正常销量 − 保本销量；安全边际率 ＝ 安全边际 ÷ 正常销量
- 关系：利润 ＝ 安全边际 × 单位边际贡献；销售利润率 ＝ 安全边际率 × 边际贡献率

### 16.3 保利分析（★★）

目标利润销量 ＝（固定成本 ＋ 目标利润）÷ 单位边际贡献。考虑所得税时，目标利润用"税后利润÷(1−T)"换算为息税前口径。

### 16.4 多品种与敏感分析（★★）

- 多品种：加权平均边际贡献率 ＝ Σ（各产品边际贡献率 × 销售比重）；综合保本销售额 ＝ 固定成本 ÷ 加权平均边际贡献率。
- 敏感系数 ＝ 利润变动% ÷ 因素变动%；单价最敏感，固定成本最不敏感。

## 第 17 章 短期经营决策

### 17.1 决策基础：相关成本（★★）

| 相关成本 | 不相关成本 |
| --- | --- |
| 差额成本、边际成本、机会成本、可避免成本、可延缓成本、专属成本 | 沉没成本、历史成本、不可避免成本、共同成本、无差别成本 |

### 17.2 生产决策（★★）

| 决策类型 | 方法 |
| --- | --- |
| 差量分析 | 比较方案的差量收入与差量成本 |
| 边际贡献分析 | 比较边际贡献（注意专属/约束资源） |
| 亏损产品是否停产 | 只要能补偿变动成本且有剩余贡献就不应停产 |
| 特殊订货 | 是否有剩余产能、是否冲击正常价格 |
| 零部件自制或外购 | 比较相关成本（考虑专属固定成本与机会成本） |
| 约束资源最优利用 | 按"单位约束资源边际贡献"排序 |

### 17.3 定价决策（★★）

- 成本加成定价：价格 ＝ 成本×（1＋加成率）；完全成本加成 vs 变动成本加成。
- 市场定价、新产品撇脂/渗透定价。
- 有闲置能力时，只要追加订单价格 > 单位变动成本即可接受（不冲击现有市场）。

## 第 18 章 全面预算

### 18.1 预算编制方法（★★）

| 分类 | 方法 | 特点 |
| --- | --- | --- |
| 起点/增量 | 增量预算 / 零基预算 | 零基不依赖历史，从零论证 |
| 业务量适应 | 固定预算 / 弹性预算 | 弹性按多业务量水平编，差异分析更有用 |
| 期间 | 定期预算 / 滚动预算 | 滚动逐期向后延伸 |

### 18.2 营业预算与财务预算（★★）

**营业预算链**：销售预算（起点）→ 生产预算（生产＝销量＋期末存货−期初存货）→ 直接材料/直接人工/制造费用预算 → 成本预算 → 销售及管理费用预算 → **现金预算**（含资金筹措与运用）。

**财务预算**：利润表预算、资产负债表预算（由上述汇总）。

::: tip 现金预算
现金预算＝期初现金＋经营/投资现金流入 − 现金流出；低于最低余额需筹资，高于则还款/投资。它是营业预算与财务预算的桥梁。
:::

## 第 19 章 责任会计

### 19.1 责任中心（★★）

| 中心 | 考核指标 | 特点 |
| --- | --- | --- |
| 成本中心 | 责任成本、标准成本、预算差异 | 只控成本，无收入 |
| 利润中心 | 边际贡献、可控边际贡献、部门税前经营利润 | 控收入与成本 |
| 投资中心 | 投资报酬率 ROI、剩余收益 RI | 控收入、成本与资产 |

- ROI ＝ 部门经营利润 ÷ 部门平均总资产；RI ＝ 经营利润 − 平均总资产× 要求报酬率。
- RI 优点：不诱导放弃有利投资（克服 ROI 的"次优化"），更利于目标一致。

### 19.2 责任成本（★★）

责任成本以"责任中心"为归集对象，与产品成本（以产品为对象）口径不同；判别原则：谁负责、谁受益、谁承担。

### 19.3 内部转移价格（★★）

| 类型 | 适用 |
| --- | --- |
| 市场价格 | 存在活跃外部市场 |
| 协商价格 | 双方自愿协商（介于市价与成本间） |
| 变动成本加成 | 供应方能力不足、避免重复计算固定成本 |
| 全部成本加成 | 简单但可能扭曲决策 |
| 双重价格 | 买卖双方采用不同价格，激励双方 |

## 第 20 章 业绩评价

### 20.1 财务业绩与非财务业绩（★★）

财务业绩（如 ROE、ROI）滞后、易操纵；非财务业绩（客户、流程、创新）前瞻。应结合使用。

### 20.2 关键绩效指标法（KPI）（★★）

自上而下分解战略目标为可量化 KPI，注重结果与过程结合、长短结合。

### 20.3 经济增加值（EVA）（★★★）

- 基本 EVA ＝ 税后净营业利润（NOPAT） − 调整后资本 × 平均资本成本率
- 披露 EVA ＝ 净利润 ＋（利息支出＋研发费用调增）− 调整后资本 × 资本成本率（含会计调整项目，如研发费用资本化、营业外收支剔除、非经常性损益调整等）
- 差异化资本成本率：对不同产业/板块设定不同 WACC。

::: danger 易错 · EVA 调整
EVA 通过会计调整消除准则对决策信号的扭曲（如研发费用费用化会抑制创新投入，调整时将其加回并资本化）。计算时务必用"税后净营业利润"而非净利润加回利息的思路，并确认资本成本率的口径。
:::

### 20.4 平衡计分卡（★★★）

| 维度 | 关注 |
| --- | --- |
| 财务 | 股东视角（长短期战略平衡） |
| 顾客 | 客户价值与满意度 |
| 内部业务流程 | 关键流程与创新能力 |
| 学习与成长 | 员工、系统、文化 |

优点：平衡长短期、内外部、财务与非财务、结果与动因；缺点：指标多、工作量大、各指标权重难定。

### 20.5 绩效棱柱模型与标杆管理（★）

- 绩效棱柱：从利益相关者（投资者、客户、员工、监管、社区）需求出发，强调"利益相关者满意—贡献—战略—流程—能力"五面。
- 标杆管理：与内/外部最佳实践对比，分内部、竞争、职能、通用标杆；程序含计划—分析—整合—行动—评价。

## 附录 B 各章易错点速查

1. 股东财富最大化下，公司与股东间的交易（如除权）影响股价不影响股东财富。
2. 直接投资 vs 间接投资：对子公司长期股权投资属经营性投资。
3. 有效资本市场三程度：弱式（技术无用）、半强式（基本面无用）、强式（内幕也无效）。
4. 管理用报表："净经营资产＝净负债＋股东权益"，净利润＝税后经营净利润−税后利息费用。
5. 杜邦体系用总资产含金融资产会扭曲，主推管理用财务分析体系。
6. 可持续增长率是不增发、保持政策下的最大增长率，不等于实际增长率。
7. 货币时间价值中预付年金＝普通年金×(1＋i)；永续年金 P＝A/i。
8. CAPM 只对系统风险（β）补偿，总风险中的非系统风险可分散、不获补偿。
9. 债券价值与必要报酬率反向；流通债券折现期需与付息日对齐。
10. 债务资本成本用"税后"；风险调整法＝政府债收益率＋信用补偿率。
11. 普通股资本成本三种方法结果可能不同，依条件选用；WACC 推荐目标资本结构权重。
12. NPV 与 IRR 在非常规现金流或互斥项目上可能冲突，互斥项目用 ΔNPV 或 EAA。
13. OCF 三公式等价；折旧非现金流，但"折旧×T"是抵税额要计入。
14. 固定资产更新比平均年成本 ACE，年限不同须共同年限/EAA。
15. 期权价值＝内在价值＋时间溢价；波动率是最重要正向影响因素。
16. BS 模型中看跌期权由平价关系求得；实物期权价值＝NPV＋期权价值。
17. 企业价值评估 FCFF 折现用 WACC，FCFE 用 rₛ；股权价值＝实体价值−净债务。
18. 相对价值法要"可比"：亏损企业不宜用市盈率，重资产用市净率，高销售成本率用市销率。
19. 有税 MM：负债越多企业价值越大；权衡/代理/优序理论才承认最优结构。
20. EPS 无差别点法据 EBIT 与无差别点大小选债务或股权。
21. 经营杠杆来自固定成本，财务杠杆来自利息，联合杠杆＝二者乘积。
22. 配股/增发稀释 EPS 与股价；评价原股东财富须比较除权前后。
23. 可转债转股后债券消失，附认股权证债券行权后债券仍存续。
24. 租赁决策比"租赁净现值"与"购买净现值"。
25. 股票分割不改变权益总额，仅股数↑、面值↓；回购减少流通股、提升 EPS。
26. 现金存货模式 C*＝√(2TF/K)；随机模式 H＝3R−2L。
27. 经济订货量扩展：陆续供应、保险储备、数量折扣要分别处理。
28. 成本性态分解高低点法：b＝(高点−低点成本)/(高点−低点业务量)。
29. 辅助生产分配交互分配法要考虑相互提供服务。
30. 平行结转分步法不结转半成品成本、不还原；逐步综合结转需成本还原。
31. 固定制造费用差异二因素（耗费、能量）与三因素（耗费、闲置、效率）口径不同。
32. 作业成本法强调因果动因、两阶段分配；适用间接费用比重大且产品多样。
33. 本量利假设产销平衡、品种结构不变；多品种用加权平均边际贡献率。
34. 安全边际率×边际贡献率＝销售利润率；利润＝安全边际×单位边际贡献。
35. 亏损产品只要能补偿变动成本且有剩余贡献就不应停产。
36. 有闲置能力的特殊订货，价格 > 单位变动成本即可接受（不冲击现有价）。
37. 零基预算不依赖历史；弹性预算按多业务量编制，差异分析更有用。
38. 现金预算是营业预算与财务预算的桥梁，含资金筹措与运用。
39. 投资中心 RI 优于 ROI 之处在于避免"次优化"（放弃高 RI 项目）。
40. EVA 需会计调整（研发资本化等），资本成本率可差异化；用 NOPAT 而非净利润。
41. 平衡计分卡四维度：财务、顾客、内部流程、学习与成长。
