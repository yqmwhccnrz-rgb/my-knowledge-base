# C 语言基础知识点

这篇示例文章既是排版演示，也是[刷题页](../quiz.md)题库对应的知识点来源。后续可以让 AI 助手从这类笔记里自动整理出更多题目。

## 运算符与表达式

### 整数除法

两个整数相除会执行整数除法，小数部分直接截断，例如 `5 / 2` 的结果是 `2`。若希望得到 `2.5`，需要把其中一个操作数写成浮点形式，如 `5.0 / 2`。

### 短路求值

逻辑与 `&&` 在左侧为假时不再计算右侧；逻辑或 `||` 在左侧为真时不再计算右侧。这常用于把代价较大的判断放在后面。

## 指针与地址

指针变量存放的是地址。若 `int a = 10; int *p = &a;`，则 `p` 是 `a` 的地址，`*p` 是解引用后取出的值 `10`。

想在一个函数里修改调用方的变量，需要传入该变量的指针，因为 C 语言的参数默认是值传递，函数拿到的是副本。

## 数组与下标

数组下标从 0 开始。声明 `int arr[5];` 后，合法下标是 `0` 到 `4`；访问 `arr[5]` 属于越界，结果不可预期。

## 字符串与结束符

C 语言没有独立的字符串类型，用字符数组表示，并在末尾自动追加一个结束符 `\0`。因此 `"hello"` 看起来是 5 个字符，实际占用 6 个字节。

## 内存管理

`malloc` 申请的内存来自堆，使用完必须用 `free` 释放，两者要成对出现。忘记释放会造成内存泄漏；重复释放或释放后继续访问同样危险。

## 流程控制

`switch` 的每个 `case` 末尾通常要写 `break`。如果漏写，程序会继续执行下一个 `case` 的语句，这种行为叫贯穿（fall-through），有时是刻意利用，更多时候是 bug。
