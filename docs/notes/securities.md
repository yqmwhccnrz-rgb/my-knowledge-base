## 第1章 证券投资工具

**投资**是货币转化为资本的过程。投资目的有三：**本金保障、资本增值、经常性收益**。**风险**指"未来结果的不确定性或损失"，即个人和群体在未来获得收益和遇到损失的可能性以及对这种可能性的判断与认知。风险偏好三类：**风险规避、风险中立、风险爱好**。

![证券投资工具四大类](/sec/sec-instruments.svg)

### 1.1 债券（★★ 名词解释高频）

**债券**是一种金融契约、债权债务凭证。概念四层含义：发行人、购买人、发行人义务、法律效力。

| 要点 | 内容 |
| --- | --- |
| 四个基本要素 | 债券面值、票面利率、付息期、偿还期 |
| 四个特征 | 偿还性、流通性、安全性、收益性 |

**债券的八种分类角度**（简答常考"债券的种类"）：

| 分类角度 | 类型 |
| --- | --- |
| 是否约定利息 | 零息债券、附息债券、息票累积债券 |
| 券面形态 | 实物债券、凭证式债券、国家储蓄债券、记账式债券 |
| 发行主体 | 政府债券、金融债券、公司债券 |
| 有无担保 | 抵押债券、信用债券 |
| 能否转换 | 可转换债券、不可转换债券 |
| 利率是否固定 | 固定利率债券、浮动利率债券 |
| 能否提前偿还 | 可赎回债券、不可赎回债券 |
| 偿还方式 | 一次到期债券、分次到期债券 |

### 1.2 货币时间价值与债券收益率（★★★ 计算题）

**终值**是现在的资金在未来某时刻的价值；**现值**是未来某时刻的资金在现在的价值。计息方式分**单利**与**复利**。

| 公式 | 表达 |
| --- | --- |
| 单利终值 | <img class="fml" src="/formulas/7fee6640876315.png" alt="FV= P \times(1+ r \cdot n)" width="171" height="34"> |
| 复利终值 | <img class="fml" src="/formulas/9bcd49388af1d4.png" alt="FV= P \times(1+ r)^{n}" width="157" height="34"> |
| 复利现值 | <img class="fml" src="/formulas/906d424493be09.png" alt="PV= \frac{FV}{(1+ r)^{n}}" width="101" height="36"> |
| 债券收益率（基本公式） | (到期本息和 − 发行价) / (发行价 × 偿还期) × 100% |
| 出售者收益率 | (卖出价 − 发行价 + 利息) / (发行价 × 持有年限) × 100% |
| 购买者收益率 | (到期本息和 − 买入价) / (买入价 × 剩余年限) × 100% |
| 持有期间收益率 | (卖出价 − 买入价 + 利息) / (买入价 × 持有年限) × 100% |

**例**：某人以 95 元买入面值 100 元、票面利率 8% 的债券，持有 2 年后以 102 元卖出，期间共收利息 16 元。持有期间收益率 <img class="fml" src="/formulas/b4f4c1a7dc2e1b.png" alt="=\dfrac{102-95+16}{95\times 2}\times 100\%\approx 12.1\%" width="270" height="46">。

**债券筹资特点**：优点是资本成本低、有财务杠杆作用、属长期资金、筹资范围广金额大；缺点是财务风险大、限制性条款多、资金使用缺乏灵活性。

### 1.3 股票（★★★）

**股票**是股份有限公司筹集资本时向出资人发行的股份凭证，代表持有者对股份公司的**所有权**。三层含义：出资证明、股东身份证明、利润分配及剩余财产分配权证明。

| 要点 | 内容 |
| --- | --- |
| 五个特征 | 不可偿还性、参与性、收益性、流通性、价格波动性和风险性 |
| 按上市地点 | A股（境内人民币）、B股（境内外币）、H股（中国香港）、N股（纽约）、S股（新加坡） |
| 按代表权利 | 普通股、优先股 |

**普通股与优先股对比**（简答高频）：

| 维度 | 普通股 | 优先股 |
| --- | --- | --- |
| 表决权 | 有（参与公司经营决策） | 一般无 |
| 股利 | 不固定，随盈利波动，后于优先股分配 | 固定股息，优先于普通股分配 |
| 剩余财产 | 最后分配 | 优先于普通股受偿 |
| 风险收益 | 高风险高收益 | 风险较低、收益稳定，类似"债券化股票" |

**普通股股东主要权利**：经营参与权（投票表决）、股利分配权、剩余财产分配权、优先认股权（新股配售）、股份转让权、对公司账目和股东大会决议的查阅权。

**股票的内在价值**：股票**未来现金流量的现值**，又称理论价值。两大意义：① 作为定价依据；② 判断泡沫是否产生（历史案例：荷兰郁金香泡沫、日本 1980 年代末泡沫、2015 年中国股市异常波动）。

### 1.4 证券投资基金（★★ 名词解释）

**证券投资基金**是一种实行**组合投资、专业管理、利益共享、风险共担**的集合投资方式。

与股票、债券的区别：① 以股票债券为投资对象，是"投资的投资"；② 风险收益不同（基金介于股债之间，风险小于股票、收益一般高于债券）；③ 基金是组合投资、分散风险。

**五个特点**：集合理财、专业管理；组合投资、分散风险；利益共享、风险共担；严格监管、信息透明；独立托管、保障安全。

| 分类角度 | 类型 |
| --- | --- |
| 组织形式 | 契约型基金（信托契约，我国主流）、公司型基金（公司章程，如美国共同基金） |
| 基金单位是否可变 | 封闭式基金（固定规模、场内交易、可折溢价）、开放式基金（规模可变、按净值申购赎回） |
| 投资对象 | 股票基金、债券基金、货币市场基金 |
| 是否公开发行 | 公募基金（共同基金）、私募基金（对冲基金） |

**管理与托管分开原则**：基金**管理人**凭专业知识与经验进行投资决策、谋求资产增值；基金**托管人**是投资者权益的代表、基金资产的名义持有人（通常为商业银行），负责保管资产、监督管理人。

### 1.5 金融衍生工具（★★★）

产生必然性：为了**分散、减少和转移风险**。三类参与者：**对冲者**（保值者，规避转移风险）、**投机者**（制造风险并从中获利）、**套利者**（利用价差获利）。

**期货**：买卖双方签订的有约束力的购销合约，以事先约定价格在未来特定时间交割一定数量标的物。特点：合约标准化、交易所交易、交易所担保、可对冲平仓。要素包括交易品种、数量单位、最小变动价位、每日价格最大波动限制（涨跌停板）、合约月份、交易时间、最后交易日、交割时间与标准地点、保证金、手续费。

期货功能：① 吸引套期保值者锁定成本、规避现货价格波动风险；② 吸引投机者、增加市场流动性。期货交易特征：**双向性**（可做多做空）、**杠杆作用**（保证金交易）、**零和市场**（盈亏相抵，但大于负市场）。套利方法：跨交割月份套利、跨市场套利、跨商品套利。

**期权**：买方支付期权费后，拥有在未来一段时间内（美式）或特定日期（欧式）以约定价格（执行价格）买入或卖出标的物的**权利而非义务**。

| 构成因素 | 说明 |
| --- | --- |
| 执行价格 X | 事先约定的买卖价格 |
| 期权费 C/P | 购买或售出期权合约的价格（看涨用 C、看跌用 P） |
| 履约保证金 | 卖方缴纳 |
| 看涨/看跌 | 按买卖性质划分 |

分类：看涨期权与看跌期权（按性质）；欧式与美式（按履约时间，美式可在到期前任一天执行、欧式只能到期日执行）；场内与场外（按交易场所）；现货期权与期货期权（按标的资产）。

**期权与期货的关系**：① 均以买卖远期标准化合约为特征；② 期货价格影响期权执行价格与期权费的确定；③ 期货交易是期权交易的基础（期货期权的标的即期货合约）；④ 都可做多做空；⑤ 期权履约时买卖双方得到相应期货部位。

### 1.6 另类投资工具

**另类投资**指在股票、债券及期货等公开交易平台之外的投资方式，特点是**与传统投资相关性小**。分类：① 金融衍生品（资产支持证券 ABS、担保债务凭证 CDO、信用违约互换 CDS）；② 私募股权；③ 大宗商品（能源商品、基础原材料、农副产品）。

### 1.7 易错点

- 债券四特征记忆口诀"偿流安收"；股票五特征中**不可偿还性**是区别于债券的第一特征。
- 只有**股份有限公司**能发行股票，有限责任公司不能。
- 期权**买方**只有权利没有义务，最大损失是期权费；**卖方**收取期权费、承担义务，需缴保证金。
- 美式期权可在存续期内任何时点执行，**欧式只能到期日执行**；美式期权费一般高于同条件欧式。
- 封闭式基金在交易所按**市价**交易，可能出现折价/溢价；开放式基金按**单位净值**申购赎回。
- 期货是零和市场；期权市场买方亏损有限、卖方（裸卖看涨）理论亏损无限。
- H 股指在中国香港上市，不是"境外公司股"；B 股在境内上市、以外币计价交易。

## 第2章 证券市场

**证券市场**是股票、债券、证券投资基金、金融衍生工具等各种有价证券**发行和买卖的场所**。与一般商品市场的区别在四方面：交易对象（金融工具 vs 实物商品）、交易目的（资本增值 vs 使用价值）、价格实质（虚拟资本价格 vs 价值货币表现）、风险（更高更复杂）。

![证券市场体系](/sec/sec-market.svg)

### 2.1 实物资产与金融资产

社会物质财富最终取决于生产能力（土地、建筑、机械与知识）等**实物资产**；**金融资产**（股票、债券）是对实物资产所产生收入的索取权，本身不直接创造财富。金融资产三类：**固定收益型证券**（承诺固定或按公式计算的现金流）、**权益型证券**（代表公司所有权份额）、**衍生产品**（收益取决于其他资产价格）。

### 2.2 证券市场的功能与分类（★★★ 简答）

**基本功能**：筹资—投资、资本定价、资本配置。

| 分类角度 | 类型 |
| --- | --- |
| 市场功能 | 一级市场（发行市场）、二级市场（流通市场） |
| 上市条件 | 主板市场、二板市场（创业板） |
| 交易对象 | 股票市场、债券市场、基金市场、衍生品市场 |
| 组织形式 | 场内市场（交易所）、场外市场（OTC） |

**发展三阶段**：自由放任（17 世纪末—20 世纪 20 年代末）→ 法制建设（20 世纪 30 年代初—60 年代末，美国《证券法》1933、《证券交易法》1934）→ 迅速发展（20 世纪 70 年代至今）。

### 2.3 市场参与主体

| 主体 | 要点 |
| --- | --- |
| 证券发行人 | 公司（企业）、政府和政府机构（政府一般只发债券） |
| 证券投资人 | 机构投资者（政府机构、金融机构、企业和事业法人、各类基金）+ 个人投资者 |
| 中介机构 | 证券公司（按功能分证券经纪商、自营商、承销商）+ 证券服务机构（投资咨询、登记结算、财务顾问、资信评级、资产评估、会计师事务所、律师事务所） |
| 自律组织 | 证券交易所、证券业协会（我国按《证券法》）；证券登记结算机构实行行业自律管理 |
| 监管机构 | 中国证监会及其派出机构：国务院直属，集中统一监管 |

### 2.4 证券交易场所（★★）

**证券交易所**是经政府证券主管机关批准设立的集中进行证券交易的**有形场所**。功能：保证市场运行的连续性、实现资金有效配置、形成合理价格、减少证券投资的风险。

| 类型 | 会员制 | 公司制 |
| --- | --- | --- |
| 目的 | 不以营利为目的，会员自治自律 | 以营利为目的 |
| 收入 | — | 上市费 + 成交佣金 |
| 我国 | 上交所、深交所均为会员制 | — |

交易所成员：会员（股票经纪人即佣金经纪人、证券自营商、专业会员）；交易人进入交易所分为特种经纪人（大厅中心人物，充当其他经纪人代理人）和场内经纪人（佣金经纪人、独立经纪人）。

**场外交易市场**：在交易所之外进行证券买卖的市场，是多层次资本市场体系的重要组成部分。功能：拓宽融资渠道、改善中小企业融资环境；为不能上市交易的证券提供流通转让场所；提供风险分层的金融资产管理渠道。我国场外市场：**银行间债券市场、全国中小企业股份转让系统（新三板）、债券柜台交易市场**。

### 2.5 证券投资过程

个人投资者投资规划：① 投资准备（保险、现金储备先行）；② 按生命周期阶段筹划投资策略；③ 生命周期投资目标（近期：付房租、买车、旅行等短期购买目标；长期：财务独立、退休保障）。

投资决策的目标是**投资收益最大化**（组合的风险收益特征给投资者带来最大满足）。过程从了解风险偏好开始 → 确立投资政策（**投资目标、投资规模、投资对象**三要素 + 投资策略措施）→ 投资限制（风险承受能力、流动性、投资期限）→ **客户分析是证券决策过程的第一步**。

### 2.7 证券市场监管

监管定义：证券管理机关运用**法律的、经济的以及必要的行政手段**，对证券的募集、发行、交易等行为及中介机构行为进行监督与管理。我国监管机构为**中国证监会及其派出机构**；监管内容：信息披露管理、金融行为监管、金融机构监管、外国参与者监管、银行与货币监管。

金融危机与监管改革（美国线索）：30 年代大萧条 → 证券监管法案（1933《证券法》、1934《证券交易法》）；70 年代 →《证券投资者保护法》；上市公司丑闻 →《萨班斯—奥克斯利法案》（2002）；2008 年金融危机 →《多德—弗兰克法案》。除政府立法监管外，**自我约束**（行业自律）也是重要内容。

### 2.8 易错点

- 一级市场是发行市场、二级市场是流通市场；**二级市场的价格是一级市场定价的参照**，两者互为条件。
- 我国沪深交易所是**会员制**（不以营利为目的），不要误记为公司制。
- 上证综指按**发行量**（总股本）加权；上证180、沪深300 按**调整股本**（分级靠档）加权。
- 政府发行证券的品种一般**只限于债券**，政府不发股票。
- 证券公司按功能分经纪商、自营商、承销商；自营商为自己买卖、经纪商替客户买卖。
- 修正平均股价的两条路线：调整股价法调"分子"（还原股价），修正除数法调"分母"（变动除数）。
- 客户分析是投资决策过程的**第一步**；投资政策三要素是目标、规模、对象。

## 第3章 证券投资基本分析

基本分析的路径是**自上而下**：宏观经济 → 产业（行业）→ 公司。

### 3.1 宏观经济分析（★★★ 简答高频）

影响证券市场价格的宏观因素五类：**宏观经济因素**（周期性波动等规律性因素 + 政策因素）、**政治因素**（政局稳定与否、首脑更换、罢工、产油国动乱）、**法律因素**（法律不健全的市场更具投机性、震荡剧烈）、**军事因素**（军事冲突破坏正常交易）、**文化与自然因素**（文化传统决定储蓄投资心理；自然灾害影响生产经营）。

**宏观经济因素是基础因素**的三个理由：① 影响是**全局性**的（产业/区域因素只影响板块、公司因素只影响个股，宏观影响几乎每只证券）；② 影响是**基础性**的；③ 影响是**长期性**的（政治军事事件不具备持续性）。

**经济周期四阶段与股市**（经济繁荣证券价格上涨、衰退下跌）：

| 阶段 | 经济与市场表现 |
| --- | --- |
| 萧条 | 经济下滑至低谷，百业不振，证券价格低位徘徊 |
| 复苏 | 公司经营好转、业绩上升、债信提高，股价开始回升 |
| 繁荣 | 业绩不断提升、增资扩产，股价大幅上扬；但有识之士已开始悄悄卖出，多空力量渐变 |
| 衰退 | 更多投资者抛出证券，市场完成中长期筑顶，形成向下趋势 |

**宏观经济政策对证券市场的影响**：

| 政策 | 工具 | 效应 |
| --- | --- | --- |
| 货币政策 | 存款准备金率、贴现率（再贴现率）、公开市场业务等 | **直接、迅速**影响证券市场。宽松（降准、降再贴现率、央行买债）→ 证券价格上涨；紧缩相反 |
| 财政政策 | 政府购买、转移支付、调整税率 | **持久但较缓慢**。扩张 → 总需求增加 → 公司业绩提升 + 居民收入增加 → 证券价格上涨；紧缩相反。税率提高抑制股价，降低或免税助推股价 |
| 汇率政策 | — | **从结构上**影响。汇率上升（本币贬值）→ 出口型企业股价涨、进口型企业跌；汇率下跌（本币升值）→ 资本流入、国内证券需求增加、价格上涨 |

**判断经济周期阶段的三种方法**：

| 方法 | 要点 |
| --- | --- |
| 经济指标分析 | **先行指标**（峰谷先于经济周期，预示未来）：货币供应量、股价指数、房屋建造许可证批准数、机器设备订单数；**同步指标**（与经济周期同步，反映现状）：实际 GNP、失业率；**滞后指标**（峰谷滞后约半年）：银行短期商业贷款利率、工商业未偿还贷款、生产成本、物价指数 |
| 计量经济模型 | 内生变量（模型本身说明，因变量）、外生变量（模型外决定，自变量）、参数（常数与常系数，反映自变量与因变量间相对稳定的比例关系）、随机误差 |
| 概率预测 | 用概率论方法，在一定置信水平下预测未来宏观经济变量水平 |

### 3.2 产业分析（★★★）

产业分析内容：**产业基本特性分析、产业生命周期分析、产业结构分析**。证监会行业分类：按经审计并公开披露的合并报表数据，上市公司分为 19 大类。

**产业生命周期四阶段**：

| 阶段 | 特征 | 投资风险收益 |
| --- | --- | --- |
| 初创（幼稚）期 | 新技术、新产品，高投入高失败率 | 高风险，收益不确定 |
| 成长期 | 需求扩大、技术渐成熟、利润快速增长 | 风险仍高但收益可观 |
| 成熟期 | 市场饱和、竞争格局稳定、利润平稳 | 风险降低、收益稳定 |
| 衰退期 | 需求萎缩、企业退出 | 收益下降 |

按与宏观经济周期关系，产业分为**成长型产业**（运动状态与经济周期无关，如新兴产业）、**周期型产业**（与周期高度相关，如钢铁、建材、汽车）、**防御型产业**（不受周期影响，如食品、公用事业）。

**市场结构四种类型**：完全竞争、不完全竞争（垄断竞争）、寡头垄断、完全垄断——划分依据：交易者数量、产品差异程度、进入限制、价格决策形式、市场信息通畅程度。

**波特五力模型**（决定产业整体获利水平）：

| 五力 | 要点 |
| --- | --- |
| 潜在进入者的威胁 | **进入壁垒**是门槛：壁垒越低，新竞争者越多，产业成长率与获利率受损 |
| 购买方的议价能力 | 取决于购买方规模、产业内公司数量、信息取得难易、产品标准化程度 |
| 供应商的议价能力 | 供应行业由几家大公司控制、供应稀缺、无替代品竞争、供应品是重要投入要素、产品有差异性、购买方转换费用高时，供应商议价力强 |
| 替代产品的威胁 | 替代品决定产业利润**上限**（"上盖"）；替代品的价格—性能选择越有吸引力，产业利润压得越紧 |
| 现有竞争者的威胁 | 决定因素：产业成长性、生产能力集中程度、产品差异性与顾客转换成本、固定成本相对可变成本的比率 |

### 3.3 公司财务分析（★★★ 计算 + 名词解释）

**主要财务比率**：

| 比率 | 公式 | 含义 |
| --- | --- | --- |
| 资产负债率 | 负债总额 / 资产总额 | 资本结构与信用风险的重要参照 |
| 流动比率 | 流动资产 / 流动负债 | 短期偿债能力（一般认为 2 左右较适宜） |
| 速动比率（酸性测试） | (流动资产 − 存货) / 流动负债 | 更进一步的变现能力（一般认为 1 左右较适宜） |
| 利息保障倍数 | 息税前利润 EBIT / 利息费用 | 偿付借款利息的能力 |
| 存货周转率 | 营业成本 / 平均存货 | 经营效率；周转天数 = 365 / 周转率 |
| 应收账款周转率 | 营业收入 / 平均应收账款 | 收账速度 |
| 固定资产周转率 | 营业收入 / 平均固定资产净值 | 固定资产利用效率 |
| 总资产周转率 | 营业收入 / 平均总资产 | 整体资产运营效率 |

**杜邦分解**（★★★ 简答高频）：**净资产收益率 ROE = 销售净利率 × 总资产周转率 × 财务杠杆（权益乘数）**。其中销售净利率取决于经营管理，总资产周转率取决于投资管理，财务杠杆取决于融资政策——通过三个比率的分析了解企业经理人员在何种程度上贯彻了公司的各项战略。

**现金流量分析**：现金流量分三类——**经营活动**（创造收益的主营业务及不属于投资/融资的其他业务）、**投资活动**（处理长期资产及其他投资）、**筹资活动**（引起权益资本及借款规模和结构变化的业务）。编制方法：**直接法**（按现金收支主要类别反映）与**间接法**（以净利润为起算点调整非现金项目）；**我国采用直接法**。

七个分析要点：① 经营现金流为负（可能是快速成长期的大量前置投入，也可能是经营亏损或营运资本管理不力）；② 经营现金流与净收益的巨大差额（应收账款剧增——权责发生制下销售即确认收入；投资收益及营业外收入变化不影响经营现金流）；③ 经营现金流小于利息支付额（偿债风险）；④ 投资现金流流向是否与企业战略一致；⑤ 投资资金来源依赖内源还是外源融资；⑥ 是否有自由现金流及其分配；⑦ 筹资来源是股票、短期负债还是长期负债。

### 3.4 公司价值分析（★★★）

**公司基本分析**：① 公司概况（所处产业、主营业务、产品生命周期、客户、供给、组织与技术水平、营销战略）；② 竞争对手分析（增长目标、产品结构、市场分布、市场地位、组织结构）；③ 竞争地位分析用 **SWOT**：优势 S 与劣势 W 是**内部因素**（S：竞争态势、资金、形象、技术、规模经济、质量、份额、成本、广告；W：设备老化、管理混乱、缺少关键技术、研发落后、资金短缺、产品积压），机会 O 与威胁 T 是**外部因素**（O：新产品、新市场、新需求、壁垒解除、对手失误；T：新竞争者、替代品增多、市场紧缩、政策变化、经济衰退、客户偏好改变、突发事件）。

**经济区位分析**三注意：区位自然条件及基础条件、区位内政府相关政策、区位内经济特色。

**价值链分析**：企业创造价值的过程分解为一系列互不相同又互相关联的价值增值活动。五种**基本活动**：内部后勤、生产作业、外部后勤、市场销售、服务。用途：寻找企业在特定价值环节上的竞争优势并长期保持。

**三种基本竞争战略**：成本领先战略（总体成本低于对手，获同行业平均以上利润）、差异化战略（产品/服务/形象与众不同）、聚焦战略（主攻特定顾客群、细分区段或地区市场）。

**公司竞争优势分析**：企业资源 = 有形资产（资产负债表上唯一体现的资源：房地产、生产设施、原材料）+ 无形资产（声望、品牌、文化、技术知识、专利商标、经验）+ 组织资本。资源价值判断三标准：**稀缺性、持久性、不可替代性**。**核心能力**四特性：**有价值、异质性、扩展性、动态性**——是能为企业进入各类市场提供潜在机会、借助最终产品为顾客认定、不易被竞争者模仿的能力。

**公司估值两类方法**：

| 方法 | 核心理念 | 具体模型 |
| --- | --- | --- |
| 绝对估值法 | 股票是未来预期现金流以合理贴现率贴现的现值；关键在现金流预测与贴现率确定 | 股利贴现模型 DDM、自由现金流贴现模型 DCF、剩余收入贴现模型 |
| 相对估值法（乘数估值法） | 对未来获利预期相同的资产应支付相同价格：公司价值 = 价值驱动因素 × 乘数 | 市盈率 P/E、市净率 P/B 等 |

**股利贴现模型 DDM**（补全公式，课件仅有文字）：

一般式：<img class="fml" src="/formulas/924dcd0274b459.png" alt="P_{0}= \sum \frac{D_{i}}{(1+k)^{i}}" width="112" height="37">（D_i 为第 i 期股利，k 为必要收益率）。

| 变体 | 公式 | 适用 |
| --- | --- | --- |
| 零增长模型 | <img class="fml" src="/formulas/854a623a2c2e38.png" alt="P_{0}= \frac{D}{k}" width="64" height="34"> | 股利恒定（优先股近似） |
| 戈登增长模型（稳定增长） | <img class="fml" src="/formulas/164447c5b844db.png" alt="P_{0}= \frac{D_{1}}{k- g}" width="77" height="36">，要求 g < k | 股利以固定比率 g 永续增长 |

**例**：某公司预期明年每股股利 1.2 元，股利稳定增长率 5%，必要收益率 11% → <img class="fml" src="/formulas/faaa00442a6a56.png" alt="P_{0}= \frac{1.2}{0.11- 0.05}=20\,\text{元}" width="170" height="35">。若市价 16 元，则被低估、应买入。

DDM 的四个局限：不适于无股利发放历史或无明确股利政策的公司；不适于股利与收益无直接关系的公司；无交易历史的公司难以用 CAPM 估计必要收益率（贴现率缺失）；股利发放不稳定的公司难以适用。

**自由现金流贴现法 DCF**：公司价值 = 未来自由现金流按 WACC 贴现；股权价值 = 公司价值 − 净债务。优点：理论上最完善、估值接近内在价值、充分反映经营战略、受市场短期及周期性变化影响小。缺点：方法复杂工作量大、估值区间范围大结果可用性有限、较难捕捉短期盈利机会。

**相对估值法**优缺点：优点是易于计算快捷高效、采用当前市价提高了估值准确性、是少数股权投资的最佳估值方法；缺点是难以找到完全一致的可比公司、估值受市场影响大、会计政策选择影响结果、单一年度盈余不能反映发展潜力。

**市盈率** = 股价 / 每股收益（理论价值与每股收益之比），分静态市盈率（用上年 EPS）与动态市盈率（用预测 EPS）。**市净率** = 股价 / 每股净资产，反映市场对上市公司净资产经营能力的溢价判断。

### 3.5 易错点

- 宏观因素对证券市场的影响是**基础性、全局性、长期性**的；政治军事事件影响剧烈但不持久。
- 先行指标预示未来（股价指数本身是先行指标！），同步指标反映现状，滞后指标滞后约半年。
- 货币政策影响**直接迅速**，财政政策影响**持久而缓慢**，汇率政策从**结构**上影响——三个定语不可互换。
- 汇率上升 = 本币**贬值**（直接标价法），利好出口型企业。
- 替代品威胁决定产业利润的**上限**；进入壁垒抵御的是**潜在进入者**。
- SWOT 中 S、W 是内部因素，O、T 是外部因素，切勿混位。
- 资产负债表上体现的唯一资源是**有形资产**；核心能力强调"不易模仿"（异质性）。
- DDM 要求 **g < k**，否则级数发散、模型失效。
- 我国现金流量表用**直接法**编制（间接法作为补充资料）。

## 第4章 证券投资技术分析

![技术分析核心图式](/sec/sec-technical.svg)

### 4.1 技术分析概述（★★）

**技术分析**：通过分析证券市场的**市场行为**，对价格未来变化趋势进行预测。市场行为三内容：**价格**的高低和变化、伴随的**成交量**、经过的**时间**（价、量、时），其中**价格的变化最重要**。市场行为四要素：价、量、时、**空**——价和量是最基本的表现，时间和空间是市场潜在能量的表现。

**三大假设（理论基础）**：

| 假设 | 地位 | 含义 |
| --- | --- | --- |
| 市场行为包括一切信息 | 技术分析的**基础** | 影响股价的每一因素（内在与外在）都反映在市场行为中，不必关心具体因素是什么 |
| 价格沿趋势波动并保持趋势 | **最根本、最核心** | 股价变动按规律进行、有保持原运动方向的惯性，才有必要找出价格变动规律 |
| 历史会重演 | 从统计学和心理学考虑 | 价格波动可能存在规律（统计验证）；人的买卖行为受心理制约，出现规律性现象 |

**技术分析方法分类**：技术指标、支撑压力、形态、K线、波浪理论、循环周期（六类）。

**局限性与注意事项**：① 用多个而不是一个技术分析方法同时判断；② 过去的结论要不断修正、经实践验证后才能放心使用；③ 对技术分析的期望不要超过其力所能及的范围。

**相关理论**：随机漫步理论、循环周期理论、相反理论（当大多数人看多时市场往往见顶，反之见底）。

### 4.2 道氏理论

主要原理四条：① 市场价格指数可以解释和反映市场的大部分行为；② 市场波动三种趋势——**主要趋势**（价格波动大方向，持续时间长）、**次要趋势**（主要趋势中的调整和回撤）、**短暂趋势**（次要趋势中的调整）；三者最大区别是**时间长短和波动幅度大小**；③ 交易量在确定趋势中起重要作用；④ **收盘价是最重要的价格**。评价：对大势（主要趋势）研判作用较大，对次要和短暂趋势分析作用不大，**可操作性较差**。

### 4.3 K线理论（★★）

K 线记录某股票某时间段（如一天）的价格变动：**阳线（红）**收盘 > 开盘；**阴线（绿/黑）**收盘 < 开盘；由实体 + 上影线 + 下影线构成（最高价、最低价在影线端点）。K 线图源于**日本米市商人**。短线分析用 5/15/30/60 分钟 K 线，日常分析用日线、周线、月线。

**单根 K 线含义**（11 种）：

| 形态 | 特征与含义 |
| --- | --- |
| 大阳线（光头光脚红线） | 最高=收盘、最低=开盘，无影线；强烈涨势、供不应求 |
| 大阴线 | 最高=开盘、最低=收盘；强烈跌势、恐慌抛售 |
| 先跌后涨型 | 带下影线的红实体；买方力量大（实体长于下影线买方实力很大） |
| 下跌抵抗型 | 带下影线的黑实体，开盘价即最高价；实体短于影线时后市买方可能反攻 |
| 上升阻力型 | 带上影线的红实体，开盘价即最低价；实体短于影线且在高价区时后市看跌 |
| 先涨后跌型 | 带上影线的黑实体，收盘即最低价；卖方占优，买方"套牢" |
| 反转试探型Ⅰ | 上下都带影线的红实体；大涨后出现=高档震荡（量大可能跌），大跌后出现=可能反弹 |
| 反转试探型Ⅱ | 上下都带影线的黑实体；含义与Ⅰ对称 |
| 十字线 | 只有上下影线、没有实体；买卖双方势均力敌；上下影线等长的"转机线"在高/低价位意味着反转 |
| "┴"型（空胜线）/ "T"型（多胜线） | 开盘=收盘；空胜线在高价区行情可能下跌，T 型在低价区行情将回升 |
| "一"型（四价合一） | 开收高低价相同，交易冷清、冷门股常见 |

**K 线组合**：锤头线、吊颈线、启明星、黄昏之星、曙光初现、乌云盖顶、红三兵、三只乌鸦、乌云飞刀、东方红太阳升、空方炮等。

### 4.4 支撑压力理论（★★）

**趋势**就是价格（市场）的波动方向，三种：上升、下跌、水平。

**支撑线**（抵抗线）：阻止或暂时阻止价格下跌、甚至带来回升的价格区域，是**谷底的横向切线**。**压力线**（阻力线）：压制或暂时压制价格上涨、甚至带来回落的价格区域，是**峰顶的横向切线**。

作用：① 暂时阻止股价向某方向运动（趋势未根本改变）；② 彻底阻止（趋势逆转）。可从投资者心理、成本及获利程度角度理解：支撑处多头增仓、空头补仓、新多介入；压力处空头抛空、多头减仓、新空介入。

**支撑与压力的相互转化**：被**有效突破**后作用互换（压力变支撑、支撑变压力）。有效突破判断：① 收盘价突破的距离越远越确实（关注 3%、5%、10% 价位）；② 突破后的交易时间（有人认为**三日有效**）。有效性判断三因素：价格在此区域**停留的时间**、此区域累积**成交量的大小**、此区域**距离目前的长短**。支撑/压力区的判断：价格成交密集区、相对与绝对高低价位、整数关、趋势线/轨道线/黄金分割线等切线处。

**趋势线**：通过两个高峰或低谷连成的直线。上升趋势线连接**依次提高的低点**，起**支撑**作用；下降趋势线连接**依次降低的高点**，起**压力**作用。有效性：被触及的次数、斜率（**45 度线**相当重要）、时间跨度。突破后效力转化（上升线被破变阻力、下降线被破变支撑）；**向上突破必须有较大成交量配合才有效**。

**轨道线**（通道线/管道线）：得到趋势线后，过第一个峰或谷作趋势线的平行线。上升轨道线起压力作用、下降轨道线起支撑作用。与趋势线相反：**轨道线被突破后趋势不逆转而是进一步强化**；另一作用是趋势逆转的警报（价格未触及轨道线且距离较远，可能是逆转前兆）。先有趋势线后有轨道线，**趋势线重于轨道线**。

**黄金分割线**：基于黄金分割率的切线组。数字：0.191、0.382、0.618、0.809；1.191、1.382、1.618、1.809；2、2.191、2.382、2.618、2.809 等。上涨行情选起涨点乘以 1 以上的数字画阻力线；下跌行情选起跌点乘以 1 以下的数字画支撑线。**0.382、0.618、1.382、1.618 最重要**。

**百分比线**：基于心理因素，按波段起点终点和百分比数字画出。数字基础：1/8、2/8、3/8、4/8、5/8、6/8、7/8、1/3、2/3、1 共 10 个；其中 **1/2、1/3、2/3** 三条最重要。

### 4.5 形态理论（★★）

价格运动的基本特点：平衡 → 打破平衡 → 新平衡 → 再打破 → 再寻新平衡。形态两大类型：**反转形态**与**整理形态**。

**反转形态**：

| 形态 | 要点 |
| --- | --- |
| 双重顶（M头） | 量价皆呈"M"形。过程：创新高后回档成第一峰 → 支撑反弹量缩、前高附近第二次下跌成第二峰 → 有效突破上升趋势线（**第一卖点**）→ 有效突破两峰间低谷的水平线即**颈线**（形态确立，**第二卖点**；回抽为第三卖点）。**量度跌幅 = 最高峰与颈线的垂直距离** |
| 双重底（W底） | 与双重顶相反；颈线突破时**必须有较大成交量配合** |
| 头肩顶 | 左肩（量价配合创新高回档）→ 头部（量放大创新高后二次下跌）→ 右肩（量萎缩、在前高附近第三次下跌）。突破上升趋势线=第一卖点；突破颈线（过两谷底的直线）=形态确立；量度跌幅=头到颈线垂直距离；回抽=第四卖点 |
| 头肩底 | 与头肩顶相反，颈线突破需放量 |
| 圆弧顶/底 | 圆弧底：低价区、耗时长（几个月甚至更久）、能量大，多为**中长期底部**；股价缓跌缓升呈圆弧形，成交量先减后增；末期迅速上扬突破、量显著放大、很少回档；结束位置常出现平台再突破。圆弧顶：高价区、常见于绩优股（主力高位慢慢派发）；末期缓跌到一定程度引起恐慌，出现**跳空缺口或大阴线** |

**整理形态**（持续形态）：

| 形态 | 要点 |
| --- | --- |
| 对称三角形 | 两条聚拢的趋势线（上压力、下支撑）；至少四个转折点；量能逐步萎缩；持续时间较短；突破位置一般在横向宽度的 **1/2 到 3/4 处**（靠近顶点意义不强）；突破后沿原趋势运行，理论幅度=三角形底边距离 |
| 上升三角形 | 上升趋势中的整理：上趋势线水平、下趋势线上倾（底部不断抬高，向上意愿强） |
| 下降三角形 | 下降趋势中的整理：上趋势线下倾、下趋势线水平（反弹高度不断降低，向下意愿强）。实际更多见**楔形**（分析意义相同）；喇叭形、钻石形是三角形的变形，往往属**反转形态** |
| 矩形（箱形） | 两条水平趋势线，股价横向运动；量能逐步减少；有效突破后理论幅度=两线间距离；可能演变为反转形态即**三重顶（底）**；短线可下轨吸纳、上轨抛出 |
| 旗形 | 两条上倾或下斜的平行趋势线；出现前有**旗杆**（价格快速变动）；持续时间短；形成前和突破后量大、形成中萎缩；突破后理论幅度=**旗杆高度** |
| 楔形 | 股价在两条**收敛**直线间变动，成交量逐渐递减 |

### 4.6 波浪理论（★★ 名词解释）

**主要内容**：完整上升或下降周期由 **8 浪**组成（5 浪推动 + 3 浪调整）；基本 8 浪结构与波浪规模大小无关；完整周期的波浪数目是**斐波那契数列**数字；任何浪都可细分、小浪可合并成大浪；根据当前价格在 8 浪结构中的位置指导投资行为。股价移动三种形式：原始移动、次级移动、日常移动，分别决定大、中、小趋势。

**波浪的规模层次**：超级循环（约 50 年）→ 循环（10 年）→ 基本波动（1—4 年）→ 次级波动（约 6 个月）→ 短期波动（约 6 周）。浪数依次为 2、8（上升5+下降3）、34（上升21+下降13）、144（上升89+下降55）、610（上升377+下降233）——均为斐波那契数。

**推动波四规律**（同一级循环中）：① 浪 2 绝不低于（上升浪）浪 1 的起点；② 浪 1、3、5 中**浪 3 不能最短**；③ 任一浪成为延长浪时，其余两浪的持续时间及幅度趋于一致；④ 浪 4 的底不可低于浪 1 的顶（上升浪）。

### 4.8 易错点

- 三大假设中"市场行为包括一切信息"是**基础**，"价格沿趋势波动"是**最根本、最核心**。
- 道氏理论认为**收盘价**最重要；对大势研判有用，但可操作性较差。
- 上升趋势线起**支撑**作用、下降趋势线起**压力**作用，不要颠倒。
- 轨道线被突破→趋势**强化**；趋势线被突破→趋势可能**逆转**。两者方向相反。
- WMS 是"倒着读数"的：80 以上超卖（该买），与 KD 的 80 以上超买正好相反。
- 双重顶/头肩顶的量度跌幅都从**颈线**起算；底部形态颈线突破必须放量，顶部形态跌破颈线可无量。
- 喇叭形、钻石形是三角形变形，但属于**反转**形态而非整理形态。
- 浪 3 不能最短，但浪 5 可以失败（终点低于浪 3 终点）。
- 黄金分割最重要的四个数：0.382、0.618、1.382、1.618；百分比线最重要的三条：1/2、1/3、2/3。

## 第5章 证券组合管理

![马科维茨有效边界与风险分散](/sec/sec-portfolio.svg)

### 5.1 组合管理概述（★★）

**证券组合**：个人或机构投资者所拥有的由股票、债券以及衍生金融工具等多种有价证券构成的投资集合。组合管理带来一次投资管理理念上的革命：重点应是**资产之间的相互关系及组合整体的风险收益特征**；必要性在于降低风险、实现收益最大化。

**证券投资风险**的经济内涵：最终财富事前看可能产生一个以上结果（不确定性）。按来源分九类：市场风险、偶然事件风险、贬值风险、破产风险、流通风险、违约风险、利率风险、汇率风险、政治风险。按性质分两类：**系统性风险**（市场共同因素引起，不可分散）与**非系统性风险**（个别因素引起，可通过多元化分散）。

**证券组合七种基本类型**（按投资目标）：

| 类型 | 目标 |
| --- | --- |
| 避税型 | 避税（如市政债券组合） |
| 收入型 | 当期收入最大化（高息债、优先股） |
| 增长型 | 资本增值最大化（成长股） |
| 收入—增长型 | 兼顾（均衡型） |
| 货币市场型 | 货币市场工具，安全性高 |
| 国际型 | 海外证券分散国别风险 |
| 指数化型 | 复制指数，消极管理 |

**组合管理五步骤**：① 确定组合管理目标（收入/增长/均衡 + 具体收益率水平）；② 制定组合管理政策（投资范围 + 客户要求 + 监管限制）；③ 构建证券组合（取决于投资策略：积极进取型、消极保守型、混合型）；④ 修订组合资产结构（剔除或增加证券）；⑤ 业绩评估。

**理论发展脉络**：1952 年马科维茨系统提出现代组合理论 → 1963 年其学生夏普建立**单一指数模型**（计算简化）→ 60 年代初期研究组合模型如何影响证券估值，导致 **CAPM** 产生 → 1973 年布莱克与斯科尔斯以无套利均衡分析及动态股价波动模拟为基础提出 **B-S 期权定价模型** → 21 世纪后重心转向科学选择资产、确定最佳资产组合。

### 5.2 马科维茨模型（★★★ 计算题）

**前提假设**四条：① 每一种投资可由一种预期收益的可能分布来代表；② 投资者都利用预期收益的波动来估计风险；③ 投资者仅以预期收益和风险为依据决策——同一风险水平上偏好收益较高者、同一收益水平上偏好风险较小者；④ 投资者在一定时期内总是追求收益最大化。

**理性投资者行为特征**：追求收益最大化 + 厌恶风险，综合反映为**追求效用最大化**。

**有效边界**：既满足同等收益水平下风险最小、又满足同等风险水平上收益最高的资产组合的集合，即可行集曲线的**上半部分**；MVP 表示所有组合中风险最小的组合（最小方差组合）。

**核心贡献**：组合的风险**不取决于各别资产风险的平均值，而是各资产的协方差**——资产间的相关关系。资产完全不相关时，组合风险随资产数量增加而消失；现实中资产大多不完全正相关，协方差成为组合方差的决定因素，而**协方差（系统性部分）不能靠多元化降低**。引入无风险资产后，无风险资产与风险资产的组合线是一条**直线**（资本配置线）。

### 5.3 易错点

- 组合风险取决于**协方差**而非个别风险的平均；多元化只能消除非系统性风险。
- 完全正相关的两资产**不能**组成方差为零的组合（只有完全负相关且权重恰当时才能）。
- A 与 B 协方差为正时，A 实际收益高于预期 → 对 B 的合理预期是**也可能高于预期**（正相关同向变动）。
- 最小方差组合（MVP）在有效边界的最左端；**有效边界只是上半部分**，下半部分不符合理性选择。
- 卖空资产权数为负；组合权数之和恒等于 1。
- 单一指数模型是**统计模型**（收益率对市场指数回归），CAPM 是**均衡模型**，两者形式相似但含义不同。

### 6.1 资本资产定价模型 CAPM（★★★ 计算 + 简答）

**CAPM 要解决的问题**：当投资者都采用马科维茨组合选择理论时，资产的均衡价格如何在风险与收益的权衡中形成（市场均衡状态下资产价格如何依风险而定）。

**十条假设**：① 所有投资者都依据马科维茨模型选择组合（都用预期收益率和标准差、决策过程一样）；② 投资期限相同、行为短视；③ 对信息分析处理方法相同，具有**同质期望**；④ 资本市场完全：无税负、无交易成本；⑤ 资产无限可分；⑥ 投资者风险厌恶（其他条件相同时选标准差小的组合）；⑦ 投资者永不满足（其他条件相同时选预期收益高的组合）；⑧ 存在无风险利率，所有投资者可按此利率**不受限制地借入或贷出**；⑨ 完全竞争：投资者众多、单个投资者是价格接受者；⑩ 信息充分、免费、立即可得。

**资本市场线 CML**：无风险资产与市场组合 M 的连线，代表市场均衡条件下的**有效边界**。

含义：① 有效组合的期望收益与标准差存在简单**线性关系**；② E(r_P) 由两部分构成—<img class="fml" src="/formulas/4857f1bbef2211.png" alt="- r_{f}" width="37" height="33"> 是资金的时间价值（即期消费的价格），风险溢价是对承担风险的奖励；③ 斜率 <img class="fml" src="/formulas/eee3dfd1414678.png" alt="\frac{E(r_{M})-r_{f}}{\sigma_{M}}" width="68" height="35"> 是**风险的价格**（每增加一单位风险获得的收益奖励）。CML 实际上是均衡条件下对**有效组合**的定价。

**证券市场线 SML**：同质期望下所有投资者的 CML 是同一条线，共同选择的风险组合就是包含市场所有风险资产的**市场组合**。由此得 CAPM 基本形式：

以预期收益为纵轴、β 为横轴的图形即 SML——以 r_f 为起点的射线，斜率为 <img class="fml" src="/formulas/83203ff0e1a96c.png" alt="E(r_{M})- r_{f}" width="96" height="33">（市场组合风险溢价），适于**所有**风险资产的收益—风险关系。**合理定价的证券一定落在 SML 上**；位于 SML 上方 = 收益补偿超过风险 = **低估（买入）**；下方 = **高估（卖出）**；偏离表明市场处于非均衡状态。

**CML 与 SML 的区别**（★★★ 简答必考）：

| 维度 | CML | SML |
| --- | --- | --- |
| 横轴（风险度量） | σ_P 标准差（**总风险**） | β（**系统性风险**，对市场组合方差的贡献度） |
| 适用对象 | 仅**有效组合**（无风险资产与市场组合再组合） | **任何**资产或组合（含单个证券、无效组合） |
| 均衡含义 | 有效组合的收益—风险线性关系 | 均衡定价关系；偏离即定价错误 |

**CAPM 两个结论**：① 收益由两部分组成——时间补偿 r_f 与风险补偿 <img class="fml" src="/formulas/2d7d03950f0064.png" alt="[E(r_{M})- r_{f}]" width="106" height="33">；② **并非承担的所有风险都获补偿，只有系统性风险获得补偿**（非系统性风险可分散、市场不予奖励）。

**β 的含义与计算**（补全）：<img class="fml" src="/formulas/d765aebf9b7d80.png" alt="\beta_{i}= \frac{\operatorname{Cov}(r_{i},r_{M})}{\sigma_{M}^{2}}= \rho_{iM} \times \sigma_{i} \sigma_{M}" width="225" height="37">。β=1 与市场同步；β>1 激进（放大市场波动）；β<1 防守。组合的 β 是成分 β 的加权平均。

### 6.2 套利定价理论 APT（★★★）

**研究思路**：假设资产收益率与**未知数量的未知因素**相联系；核心思想：对充分多元化的大组合，只需**几个共同因素**就可解释风险补偿的来源及影响程度；每个投资者都想用套利组合在不增加风险的情况下增加收益，但**有效均衡市场中不存在无风险套利机会**（套利行为使价格恢复均衡）。若投资者对预期收益和市场敏感性估计相同，**具有相同因素敏感性的证券或组合必然要求相同的预期收益率**。

**因素模型**：统计模型，把经济周期、技术革新、劳动力成本、原材料等主要经济因素视为宏观经济指示器，假定其变化影响整个证券市场、是证券相关性的经济来源；这些变量非预期变化 → 市场收益率非预期变化。分单因素模型与多因素模型。

**推导逻辑**：① 有效市场均衡时不存在无风险套利机会；② 高度多元化组合只有几个共同因素需要补偿。

### 6.4 易错点

- CML 只对**有效组合**成立、横轴是 σ；SML 对**一切资产**成立、横轴是 β——考试最爱在此设陷阱。
- 证券市场线上方 = 价格**低估**（预期收益高于均衡要求），应买入；下方 = 高估应卖出。
- CAPM 只补偿**系统性风险**；β 度量的是资产对市场组合方差的贡献。
- APT 基于**无套利**而非市场均衡；套利组合"三特征"要能默写：不花自己的钱、无因素敏感性、正预期收益。
- APT 不指定因素是什么、有几个（与 CAPM 唯一市场因素不同）。
- 期权时间价值随到期日临近而**衰减**；内在价值为零的期权（虚值）全部是时间价值。

## 第7章 量化投资、大数据分析和智能投顾

### 7.1 量化投资（★ 名词解释）

**量化投资**：运用严密的数量方法和严格的程序进行分析来打败市场、获得高于市场收益的投资方式。一般操作流程：确定投资证券 → 找到能预测收益率的信息并量化处理 → 预测未来收益率（α）→ 构建最优投资头寸 → 信息变化时及时调整 → 获得期望超额收益。

**核心概念链**（基于 CAPM 回顾）：基准组合 B；**积极收益** = 组合收益 − 基准收益；**积极风险**（跟踪误差）= 积极收益的标准差；**残余收益（α）**= 组合收益 − CAPM 预期收益；残余风险 = 残余收益的标准差（特质风险）。

### 7.2 信息比率 IR（★★ 计算）

**IR = (年化)平均残余收益 / (年化)残余风险**——单位残余风险对应的平均残余收益。

| 概念 | 含义 |
| --- | --- |
| 后验 IR | 用历史数据计算的已实现平均残余收益与残余风险之比 |
| 前瞻 IR | 每承担单位年化残余风险能获得的年化残余收益的**预期值** |

应用：残余边界；量化投资的目标——**增加值 VA 最大化**（VA = 残余收益 − λ×残余风险²的权衡，最优化配置头寸）。

**α 预测的经验法则（基本定律）**：前瞻 IR ≈ <img class="fml" src="/formulas/52b2dd41a9c708.png" alt="IC \times \sqrt{BR}" width="95" height="33">（IC 为信息系数即预测值与实际值的相关系数，BR 为独立预测次数/广度）。应用：股票消息 → 上涨/下跌预测 → 买卖消息 → 前瞻信息比率；**z 评分**（标准化评分）把原始信号转换为期望残余收益。

### 7.3 大数据与智能投顾（★）

可用于金融投资分析的典型大数据源：**社交网络数据、电子商务数据、泛搜索引擎数据、媒体数据**；分析工具——**机器学习算法**。

**智能投顾业务流程五步**：客户画像 → 投资组合建议 → 交易执行 → 投资组合再平衡 → 收益报告。主要特征：**自动化、个性化、以长期财富为目标**；系统内置量化资产配置策略。

### 7.4 易错点

- 信息比率的分母是**残余风险**（特质风险），夏普比率的分母是**总风险**（σ），特雷诺的分母是 β——三者勿混。
- 经验法则 <img class="fml" src="/formulas/4689f2f553fd26.png" alt="IR \approx IC \times \sqrt{BR}" width="142" height="33">：预测准确度与广度共同决定信息比率，"多做独立预测"本身就能提升 IR。
- 智能投顾的核心特征是自动化 + 个性化 + **长期**财富目标，不是短线择时。

## 第8章 投资组合管理业绩评价模型

### 8.1 业绩评价概述

基本目的：① 评价投资计划实现投资目标的程度（投资经理业绩好坏）；② 确定业绩来自**技巧还是运气**。收益率计算：将评价期分为若干子期间，先算子期间收益率再平均。三种平均方法：**算术平均收益率、货币加权收益率（内部收益率，受资金进出时点影响）、时间加权收益率（不受资金进出影响，评价经理能力首选）**。业绩衡量必须在**风险调整后**进行，并确定适当的投资基准。

**M² 测度**：把组合通过杠杆调整到与市场组合相同的风险水平后比较收益，纠正投资者只看原始业绩的倾向，鼓励同时注意风险因素。
**M³ 测度**：M² 只按收益波动定义风险、未考虑组合与基准风险的相关性；M³ 在考虑相关性的基础上改进 M²。

**多因素整体业绩评估**：股票收益受多因素影响 → 组合收益同样受这些因素影响 → 用**多因素模型**（如 APT/法马-弗伦奇）代替单因素模型评估绩效，避免把因素暴露误判为经理能力。

### 8.3 时机选择与证券选择能力（★★）

**市场时机把握**：经理预期牛市时采取更进取的策略（更多资金投风险资产），预期熊市时更多投无风险资产。评价：若市场好时组合业绩更好、市场差时收益也相对高（已事先调仓），说明具备时机选择能力。以市场组合超额收益为横轴、组合超额收益为纵轴，散点回归中引入二次项（T-M 模型：γ>0 说明有择时能力）或分段回归（H-M 模型）。

**法马业绩分解**：组合收益分解为四部分——① 无风险资产收益 r_f；② 投资者事前愿意承受风险所获补偿（风险溢价：目标 β 对应部分）；③ 经理人**把握市场时机**能力对应的收益（择时风险补偿）；④ 经理人**选择股票**能力对应的收益（选股净选择性收益）。

**费尔森和斯卡特（1996）条件模型**：考虑经理人会利用已知的股利、收益等**公开信息**调整投资策略从而影响基金预期收益率；这些信息可以预测股票未来收益，也可以预测市场风险溢价。

**经典文献**：Treynor(1965)、Sharpe(1966)、Jensen(1968) 是里程碑；Chang & Lewellen(1985)、Connor & Korajczyk(1986) 用 APT 度量基金业绩；Grinblatt & Titman、Malkiel(1995) 作实证分析。

### 8.5 易错点

- 夏普比率用 <img class="fml" src="/formulas/275516ecc7dc2b.png" alt="\sigma" width="18" height="33">（总风险）、特雷诺用 <img class="fml" src="/formulas/5ed80e3e4d7b8f.png" alt="\beta" width="18" height="34">（系统风险）、詹森用 **CAPM 差值**（绝对 α）、信息比率用**非系统风险**——四个分母是本节最大考点。
- 组合已充分分散（只是大组合的一小部分）→ 用特雷诺/詹森；组合是投资者的**全部资产** → 用夏普。
- 詹森指数是**绝对**指标，可能为正可能为负；大于零才优于市场。
- 时间加权收益率不受客户资金进出的影响，适合评价**经理**能力；货币加权收益率反映**投资者**实际体验。
- 业绩评价必须先做**风险调整**并选好**基准**，否则原始收益没有可比性。

## 第9章 债券组合管理

### 9.1 债券定价理论（★★★ 计算题）

**债券价值 = 未来现金流入的现值**（内在价值/理论价格）。计算简单债券价值四步骤：① 选择适当贴现率；② 计算所有利息的现值之和；③ 计算本金的现值；④ 两个现值相加。

**基本公式**（补全）：附息债券 <img class="fml" src="/formulas/b3f9b6dacb05b3.png" alt="P= \sum \frac{C}{(1+y)^t}+ \frac{F}{(1+y)^n}" width="171" height="36">（C 为每期息票、F 面值、y 到期收益率、n 期数）；零息债券 <img class="fml" src="/formulas/415fe8a38dcbcb.png" alt="P= \frac{F}{(1+y)^n}" width="88" height="36">。

**复杂情形**：一年付息多次（用 y/2、2n 期）；期限不足一年；两个付息日之间购买——涉及**净价与应计利息**（全价 = 净价 + 应计利息）。

**价格与面值的三种关系**（★★★ 必背）：

| 票面利率 vs 贴现率 | 价格 vs 面值 | 名称 |
| --- | --- | --- |
| 票面利率 < 适当贴现率 | 价格 < 面值 | **折价债券** |
| 票面利率 = 适当贴现率 | 价格 = 面值 | **平价债券** |
| 票面利率 > 适当贴现率 | 价格 > 面值 | **溢价债券** |

影响债券价格的因素：**适当贴现率**（反向）与**时间**；此外债券的现金流可能不确定（浮动利率、含权债）。

### 9.2 利率期限结构（★★ 简答）

**利率期限结构**：某一时点上同期限差异的债券收益率与到期期限之间的关系（收益率曲线）。四大传统理论：

| 理论 | 核心观点 | 解释的曲线形状 |
| --- | --- | --- |
| 无偏预期理论 | 长期利率等于预期未来短期利率的几何平均 | 上倾=预期利率上升，下倾=预期下降 |
| 流动性偏好理论 | 投资者偏好短期，持有长期债需**流动性溢价** | 解释曲线上倾为主 |
| 特定期限偏好理论 | 不同投资者有偏好的期限区间，跨区间需补偿 | 各种形状（分段版流动性溢价） |
| 市场分割理论 | 各期限市场完全分割，利率由各自供求决定 | 各种形状 |

**例（课件原题，即期与远期利率）**：面值 100 元的 1 年期零息债券价格 94 元、2 年期零息债券价格 88 元。
- 1 年即期利率：<img class="fml" src="/formulas/352f4e9b0a0033.png" alt="\frac{100}{94}- 1=6.38\%" width="131" height="33">；2 年期零息到期收益率：<img class="fml" src="/formulas/67970811134cc6.png" alt="\left(\frac{100}{88}\right)^{\frac{1}{2}}- 1=6.60\%" width="157" height="36">
- 第 2 年远期利率 <img class="fml" src="/formulas/661467e37ee8d7.png" alt="f_{2}= \frac{(1.0660)^{2}}{1.0638}- 1=6.82\%" width="202" height="35">
- 若无偏预期理论成立，新发 2 年期国债（面值 100、年息票率 10%）第 1 年末的预期价格 = 第 2 年现金流 110 按预期 1 年期利率折现：<img class="fml" src="/formulas/9805b9d4f241e6.png" alt="\frac{110}{1+f_{2}}=102.98\,\text{元}" width="133" height="35">，预期到期收益率 = <img class="fml" src="/formulas/c3451360b69ffa.png" alt="\frac{110}{102.98}- 1=6.82\%" width="147" height="33">（即远期利率）。

### 9.3 久期与凸度（★★★ 计算 + 名词解释）

**久期（Duration）**：债券现金流的加权平均到期时间，权重为各期现金流现值占比；衡量债券价格对利率变动的敏感度。麦考利久期 <img class="fml" src="/formulas/5a60b8b6bd9588.png" alt="D= \sum \frac{t \times PV(CF_{t})}{P}" width="138" height="33">。

**价格波动近似**（补全）：<img class="fml" src="/formulas/98ac28f242f401.png" alt="\frac{\Delta P}{P} \approx- D \times \frac{\Delta y}{1+y}" width="133" height="35">；修正久期 D* = D/(1+y)，则 <img class="fml" src="/formulas/0d58d7debbb2fc.png" alt="\frac{\Delta P}{P} \approx- D* \times \Delta y" width="139" height="33">。

**久期三规则**：① 其他因素不变，**票面利率越低，久期越长**；② **到期收益率越低，久期越长**；③ 一般来说**到期时间越长，久期越长**（其他因素不变）。

**债券的价格波动与久期成比例，而不是与到期时间成比例。**

**凸度（Convexity）**：价格—收益率曲线弯曲程度的度量；久期只是线性近似，凸度对大幅利率变动作二阶修正：<img class="fml" src="/formulas/df302f98a3f61f.png" alt="\frac{\Delta P}{P}\approx -D\,\Delta y+\frac{1}{2}C(\Delta y)^{2}" width="203" height="33">。凸度对投资者总是有利的（利率大跌时价格涨得更多、大涨时跌得更少），凸度大的债券更有价值。

**例（课件习题）**：息票率 8%（年末付息）、期限 5 年、按面值发行的债券：发行价=面值（票面利率=贴现率 8%）→ 平价发行；久期 <img class="fml" src="/formulas/60af96aa8655b7.png" alt="D= \frac{\sum t \times PV(CF_{t})}{100}=4.31\,\text{年}" width="208" height="33">（可逐年计算：各期现金流 8,8,8,8,108 按 8% 折现加权）。若投资者期望到期收益率为 10% > 票面利率 8% → **不能按面值发行**，须折价：P = 8×年金系数(10%,5) + 100/1.1⁵ = 8×3.7908 + 62.09 ≈ **92.42 元**。

**债券组合的利率风险对冲（久期套保，课件原题）**：休斯持有 10 万元债券组合、久期 9 年；6 月份国债期货现价 108 元、可交割券久期 8.8 年。对冲需**卖空**期货合约数 N = (组合价值 × 组合久期) / (期货价格 × 交割券久期 × 合约面值/100)。设每手面值 100 元：<img class="fml" src="/formulas/123358f14ef9f4.png" alt="N= \frac{100000 \times 9}{108 \times 8.8}" width="105" height="34"> **94.7 → 卖空约 95 手**，使组合久期归零，规避 6 个月内利率上升风险。

### 9.4 可转换债券定价（★★）

**可转换债券**：集债券和股票特点于一体的**混合型证券**，以公司债券形式发行，持有者可在到期日前以一定条件转换成公司股票。主要条款：**票面利率、转换价格、转换比率、转换期限、赎回条款、回售条款**。转换比率 = 债券面值 / 转换价格。

**可转债价值三部分**：普通债券价值（纯债价值：作为普通债券的现金流现值）、转换价值（= 转换比率 × 当前股价）、期权价值（转股权的时间价值）。

**可转债价值 = max(普通债券价值, 转换价值) + 期权价值**

定价方法：二叉树定价法。赎回条款保护发行人（股价过高时强制赎回促转股），回售条款保护投资者（股价过低时可卖回给发行人）。

### 9.5 易错点

- 票面利率与贴现率的大小关系决定折价/平价/溢价——方向不要记反（票面低→折价）。
- 久期是**加权平均回收时间**且衡量利率敏感性；价格波动与**久期**成比例而非与到期时间成比例。
- 票面利率越低、到期收益率越低、期限越长 → 久期越长（三规则同向记忆）。
- 凸度修正项恒为正贡献（½C(Δy)²），对投资者有利。
- 无偏预期理论下：**远期利率 = 预期未来即期利率**；流动性偏好理论下远期利率高于预期即期利率（含溢价）。
- 可转债价值取 max(纯债价值, 转换价值) 再加期权价值——是"孰高 + 期权"，不是三者相加。
- 两个付息日之间买入债券：付**全价**（净价 + 应计利息），但报价用净价。
