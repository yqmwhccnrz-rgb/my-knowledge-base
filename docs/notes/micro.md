- **核心内容**：以「**稀缺资源的配置**」为主线——先建立价格如何由供求决定（第 2 章），再分别刻画两个决策主体：消费者（第 3 章效用最大化）与生产者（第 4、5 章生产与成本），然后把两者放到不同市场结构中求均衡（第 6、7 章），并把分析扩展到要素市场（第 8 章）、整个经济体的效率与福利（第 9 章）、策略性互动（第 10 章），最后讨论市场为何失灵及如何矫正（第 11 章）。重点抓三条线：① **边际分析**（MR=MC、MU/P 相等、VMP=w、MRS=MRT，几乎所有结论都是「边际收益 = 边际成本」的变体）；② **均衡与比较静态**（外生变量变动 → 曲线平移 → 新均衡）；③ **效率与福利**（帕累托最优、总剩余、无谓损失）。

## 第 1 章 引论（★★）

### 1.1 稀缺、选择与机会成本

![微观经济学体系与循环流量图](/micro/micro-overview.svg)

| 概念 | 定义 | 要点 |
| --- | --- | --- |
| 稀缺性 | 相对于人的无限欲望，资源总是有限的 | 经济学产生的前提；稀缺 ≠ 贫穷 |
| 选择 | 因稀缺而必须决定「生产什么、如何生产、为谁生产」 | 三个基本经济问题 |
| 机会成本 | 把既定资源用于某种用途所放弃的**其他用途中的最大收益** | 是「放弃的最高价值」，不是所有放弃值之和；含显性与隐性 |
| 生产可能性边界 PPF | 充分就业与技术既定下，两种产品的最大产出组合轨迹 | 边界上有效率、内部无效率、外部不可达；向外凸因机会成本递增 |
| 边际分析 | 比较「再多一单位」的增量收益与增量成本 | 微观经济学最核心的方法，贯穿全部 11 章 |

::: tip 工作例题 · PPF 与机会成本递增
设经济只生产面包 X 与机器 Y，PPF 上的组合为 `(X, Y)`：`(0, 20) → (1, 18) → (2, 14) → (3, 8) → (4, 0)`。
从 0 到 1 单位 X 的边际转换率 `MRT = |ΔY/ΔX| = 2`，依次为 `2、4、6、8`，**递增**。
原因：要素并非同质地适合两种用途，先转出的是最适合 X 生产的资源。
PPF 外凸 ⇔ 机会成本递增 ⇔ MRT 递增；若两部门要素比例完全相同，PPF 为直线（机会成本不变）。
:::

::: danger 易错 · 引论
- 机会成本**必须为"最大"的那一项**：同时放弃 A(收益 10)、B(收益 6)、C(收益 3)，选 A 的机会成本是 6，不是 19。
- PPF 上的点都**有效率**（帕累托有效的生产端），但"哪一点最好"需要需求/偏好信息，属规范判断。
- 沉没成本**不是**机会成本：已付出且不可收回的支出不影响边际决策（"覆水难收"）。
- 会计成本只记实际支出；经济成本 = 显成本 + 隐成本（含自有资本利息、自有劳动工资、正常利润）。
:::

### 1.2 研究方法与两类命题

| 方法 | 含义 | 例子 |
| --- | --- | --- |
| 实证分析 | 回答「是什么」，可检验、不含价值判断 | 「最低工资提高 10% 会使该群体就业下降约 X%」 |
| 规范分析 | 回答「应该是什么」，含价值判断 | 「政府应该提高最低工资」 |
| 均衡分析 | 研究经济变量相互作用达到相对静止的状态 | 供求均衡、厂商均衡、一般均衡 |
| 静态 / 比较静态 / 动态 | 某一时点 / 比较新旧两个均衡 / 考察调整路径与时间 | 需求右移前后 P、Q 对比属比较静态；蛛网模型属动态 |
| 个量分析 | 微观研究单个消费者、厂商、市场（总量分析属宏观） | 单个商品价格 vs 一般物价水平 |
| 经济模型 | 用假设抽象掉次要因素，保留主要关系 | 「其他条件不变」（ceteris paribus）是前提而非结论 |

- **理性人假定**：行为特征通常表述为完整性（能对任意两组合排序）、传递性（A≻B、B≻C ⇒ A≻C）、自利选择（在约束下选最偏好者）。它是**分析起点**而非对现实的完整描述，行为经济学正是检验与修正它。
- **微观 vs 宏观**：微观研究个体决策与单个市场价格（价格理论），宏观研究总产出、就业、物价与国际收支（国民收入理论）；二者共同的基石是稀缺与选择，但微观的加总并不自动等于宏观结论（合成谬误）。

::: tip 补充 · 现代视角
课件以"理性人 + 均衡 + 边际"为骨架。补充三点：① **看不见的手**：在完全竞争且无外部性时，个体自利行为经价格协调可实现资源有效配置（福利经济学第一定理的直觉，见第 9 章）；② **激励**：人们会对成本—收益的变化作出系统反应，政策设计必须预判行为调整（如限价引发排队、补贴引发过度生产）；③ **产权与制度**：交易成本为正时，制度安排本身决定资源配置效率（科斯、诺斯），这也是第 11 章政策分析的基础。
:::

## 第 2 章 需求、供给和均衡价格（★★★）

### 2.1 需求、供给与需求定理

![供求曲线与均衡、曲线移动对照](/micro/micro-supply-demand.svg)

| 项目 | 需求 | 供给 |
| --- | --- | --- |
| 定义 | 一定时期内、各种可能价格下**愿意且能够**购买的数量 | 一定时期内、各种可能价格下**愿意且能够**出售的数量 |
| 函数 | `Qd = f(P, I, Pr, T, Pe, N, …)` | `Qs = g(P, 投入价格, 技术, 税收, 预期, 厂商数, …)` |
| 定理 | 其他条件不变，`P↑ ⇒ Qd↓`（向右下倾斜） | 其他条件不变，`P↑ ⇒ Qs↑`（向右上倾斜） |
| 例外 | 吉芬品、炫耀性商品（凡勃伦商品） | 劳动供给向后弯曲、土地总供给垂直 |
| 图形变动 | **需求量的变动**：沿曲线移动（仅 P 变） | **供给量的变动**：沿曲线移动（仅 P 变） |
| 曲线平移 | **需求的变动**：收入、相关品价格、偏好、预期、买者人数 | **供给的变动**：技术、投入品价格、税补、预期、卖者人数 |

::: danger 易错 · 需求/供给
- 「需求量增加」与「需求增加」是两回事：前者是价格下降的结果（点沿曲线移动），后者是整条曲线右移。
- 替代品价格↑ ⇒ 本品需求↑（`eXY > 0`）；互补品价格↑ ⇒ 本品需求↓（`eXY < 0`）。
- 预期**未来**价格上涨：当前需求↑（提前购买）、当前供给↓（囤货待涨），二者都推高现价。
- 需求定理的深层原因是替代效应与收入效应（第 3 章），**不是**"边际效用递减"这一句话能直接推出的（基数效用论可导出，但需附加货币边际效用不变的假设）。
:::

### 2.2 均衡价格与比较静态

**均衡**：`Qd(P*) = Qs(P*)`，此时既无过剩也无短缺，价格没有进一步变动的趋势。

::: tip 工作例题 · 均衡求解与价格管制
`Qd = 50 − 2P`，`Qs = −10 + 3P`：
`50 − 2P = −10 + 3P ⇒ 5P = 60 ⇒ P* = 12`，`Q* = 26`。

- **支持价格** `P = 15`（高于均衡，如农产品保护价）：`Qd = 20`，`Qs = 35` ⇒ **过剩 15**，政府须收购或限产，否则出现黑市降价。
- **限制价格** `P = 8`（低于均衡，如租金管制）：`Qd = 34`，`Qs = 14` ⇒ **短缺 20**，需配给/排队，并催生寻租与黑市。
- 两者都是**价格不能自由出清市场**的结果，故产生非价格配置机制与效率损失。
:::

| 外生冲击 | 需求 | 供给 | 均衡 P | 均衡 Q |
| --- | --- | --- | --- | --- |
| 收入↑（正常品） | 右移 | 不变 | ↑ | ↑ |
| 投入品价格↑ | 不变 | 左移 | ↑ | ↓ |
| 技术进步 | 不变 | 右移 | ↓ | ↑ |
| 需求↑且供给↑ | 右移 | 右移 | **不定** | ↑ |
| 需求↑且供给↓ | 右移 | 左移 | ↑ | **不定** |

::: danger 易错 · 比较静态
同时移动时**必有一个变量方向不确定**，必须画图比较两条新曲线的相对位移大小，不能凭直觉断言。表格中的「不定」是高频考点。
:::

### 2.3 弹性（本章最重要）

![五种弹性与总收益关系、两类弹性公式](/micro/micro-elasticity.svg)

| 弹性 | 定义式 | 符号与含义 |
| --- | --- | --- |
| 需求价格弹性 | `Ed = −(dQ/dP)·(P/Q)`（点）；`Ed = −(ΔQ/ΔP)·[(P₁+P₂)/2]/[(Q₁+Q₂)/2]`（弧/中点） | 通常取绝对值；`>1` 富有、`=1` 单位、`<1` 缺乏 |
| 需求收入弹性 | `eI = (ΔQ/Q)/(ΔI/I)` | `>0` 正常品（`>1` 奢侈品）；`<0` 低档品 |
| 需求交叉弹性 | `eXY = (ΔQx/Qx)/(ΔPy/Py)` | `>0` 替代品；`<0` 互补品；`≈0` 无关 |
| 供给价格弹性 | `eS = (ΔQ/Q)/(ΔP/P)` | 时间越长越大；土地等固定供给 `eS = 0` |

**弹性与总收益 TR = P·Q**：`dTR/dP = Q(1 − |Ed|)`。

| 弹性 | 涨价 | 降价 | 典型商品 |
| --- | --- | --- | --- |
| `|Ed| > 1` | TR ↓ | TR ↑（薄利多销） | 奢侈品、有近替代品 |
| `|Ed| = 1` | 不变 | 不变（TR 极大） | 分界点 |
| `|Ed| < 1` | TR ↑ | TR ↓（谷贱伤农） | 必需品、农产品 |

::: tip 工作例题 · 弧弹性与总收益
`P: 5 → 4`，`Q: 20 → 30`：
`Ed = (10/1) × [(5+4)/2] / [(20+30)/2] = 10 × 4.5/25 = 1.8 > 1`（富有弹性）。
`TR: 5×20 = 100 → 4×30 = 120`，降价增收 ✓ 与理论一致。

**点弹性**：`Q = 50 − 2P`，`dQ/dP = −2`：
`P=5 ⇒ Q=40, Ed=2×5/40=0.25`；`P=12.5 ⇒ Q=25, Ed=1`；`P=20 ⇒ Q=10, Ed=4`。
可见**同一条线性需求曲线上弹性处处不同**：上半段富有、中点单位、下半段缺乏；`P=25` 为纵截距（choke price），`Q→0` 时 `Ed→∞`。
:::

**影响需求价格弹性的因素**：替代品可得性（首要）、支出占收入比重、必需程度、时间跨度、市场定义宽窄（"食品"缺乏弹性，"某品牌饼干"富有弹性）。

### 2.4 价格政策与税收归宿

![支持价格、限制价格与税收楔子](/micro/micro-policy-price.svg)

::: tip 工作例题 · 单位税归宿（无关性定理）
`Qd = 50 − 2P`，`Qs = −10 + 3P`，原均衡 `P* = 12`。对**卖方**每单位征税 `t = 4`：
卖方实得 `Ps = Pd − 4`，故 `Qs = −10 + 3(Pd − 4) = 3Pd − 22`。
`50 − 2Pd = 3Pd − 22 ⇒ Pd = 14.4`，`Ps = 10.4`，`Q = 21.2`。

- 消费者负担 `14.4 − 12 = 2.4`；生产者负担 `12 − 10.4 = 1.6`；比例 `3 : 2`。
- 供给斜率 3、需求斜率绝对值 2 ⇒ 需求相对更陡（更缺乏弹性），消费者承担 `3/(3+2) = 60%`。
- 若改为对**买方**征同样的税，均衡 `Pd、Ps、Q` 完全相同 —— 税负归宿与"向谁征收"无关，只由相对弹性决定。
:::

::: danger 易错 · 弹性与政策
- 谷贱伤农：农产品需求缺乏弹性，丰收（供给右移）使价格大跌、TR 下降 ⇒ 需保护价或储备调节。
- 蛛网模型（补充）：若生产者按上期价格决定本期产量，供给弹性大于需求弹性时价格波动**发散**（需 `|eS| < |Ed|` 才收敛）。课件未展开，属动态分析。
- 税收的**超额负担**（无谓损失）随税额平方增长；弹性越大，扭曲越严重。
:::

## 第 3 章 消费者选择（★★★）

### 3.1 基数效用论与边际效用分析

| 概念 | 表达式 | 说明 |
| --- | --- | --- |
| 总效用 | `TU = U(X)` | 消费一定量商品获得的满足总和 |
| 边际效用 | `MU = dTU/dX` | 每增加一单位消费带来的效用增量 |
| 边际效用递减规律 | `dMU/dX < 0` | 在一定时间内、其他商品消费不变，连续增加某商品消费，其 MU 递减 |
| 消费者均衡（单商品） | `MU/P = λ` | `λ` 为货币的边际效用（假定不变） |
| 消费者均衡（多商品） | `MUx/Px = MUy/Py = … = λ` | 且预算约束 `ΣPi·Xi = I` |

- **推导**：若 `MUx/Px > MUy/Py`，把一元钱从 Y 移到 X 可增加总效用 ⇒ 尚未均衡；调整直到相等。这就是"等边际原则"。
- **由 MU 递减推导需求曲线**：`MU/P = λ` 且 `λ` 不变 ⇒ `P` 下降时须 `MU` 下降才重新相等，而 `MU` 下降要求 `X` 增加 ⇒ 需求曲线向右下倾斜。
- **消费者剩余 CS** = 愿意支付总额 − 实际支付总额 = 需求曲线以下、价格线以上的面积。

::: danger 易错 · 基数效用
- 边际效用递减**不是**"总效用递减"：只要 `MU > 0`，TU 仍递增，只是增速放缓；`MU = 0` 时 TU 最大；`MU < 0` 时 TU 才下降。
- 货币边际效用不变是**简化假设**；严格地说收入变化会改变 `λ`，这正是收入效应的来源。
- 基数效用假定效用可测量、可加总，现实中难以成立 ⇒ 序数效用论用无差异曲线绕开它，但**两者给出相同的均衡条件**。
:::

### 3.2 序数效用论：无差异曲线与预算线

![无差异曲线、预算线与消费者均衡](/micro/micro-indifference.svg)

**无差异曲线四性质**：① 完备性 + 传递性（偏好可排序）；② 通常凸向原点（`MRSxy` 递减）；③ 离原点越远效用越高；④ 任意两条不相交。

**边际替代率** `MRSxy = −dY/dX = MUx/MUy`：消费者愿意为多得一单位 X 而放弃的 Y 的数量。

**预算线** `Pxx + Pyy = I` ⇒ `y = I/Py − (Px/Py)x`；斜率 `−Px/Py`（市场允许的交换比率），截距 `I/Px`、`I/Py`。

| 变动 | 预算线变化 |
| --- | --- |
| 收入 I ↑（价格不变） | 平行外移（斜率不变） |
| Px ↓（I、Py 不变） | 绕纵截距向外旋转（更平坦） |
| 所有价格同比例 ↑ | 平行内移（实际收入下降） |
| I 与所有价格同比例 ↑ | 不变（无货币幻觉） |

**消费者均衡（内点解）**：
`MRSxy = Px/Py` 且 `Pxx + Pyy = I`
即「主观愿意交换的比率 = 客观能够交换的比率」，几何上为无差异曲线与预算线相切。

::: tip 工作例题 · 柯布–道格拉斯效用
`U = XY`，`I = 100`，`Px = 2`，`Py = 5`：
`MRS = MUx/MUy = Y/X = Px/Py = 0.4 ⇒ Y = 0.4X`。
代入 `2X + 5(0.4X) = 4X = 100 ⇒ X* = 25`，`Y* = 10`，`U* = 250`。

**通式**：`U = X^α Y^β` 时 `X* = [α/(α+β)]·I/Px`，`Y* = [β/(α+β)]·I/Py`。
即每种商品的**支出份额恒等于其效用指数占比**，与价格、收入无关（这是 C-D 需求函数最重要的性质，也是计量中常用它的原因）。

**角点解**：完全替代 `U = aX + bY`（无差异曲线为直线）时，若 `a/b > Px/Py` 则全部买 X；完全互补 `U = min(aX, bY)`（L 形）时，最优必在折点 `aX = bY`，此时**不满足相切条件**。
:::

### 3.3 价格变化、收入变化与需求曲线

![价格消费线、收入消费线与恩格尔曲线](/micro/micro-income-price.svg)

| 曲线 | 定义 | 用途 |
| --- | --- | --- |
| 价格消费线 PCC | `Px` 变动（I、Py 不变）时各均衡点的轨迹 | 逐点读出 (P, X) ⇒ **个人需求曲线** |
| 收入消费线 ICC | `I` 变动（价格不变）时各均衡点的轨迹 | 判断正常品/低档品；ICC 为过原点直线 ⇔ 所有 `eI = 1` |
| 恩格尔曲线 | 由 ICC 转画的「收入 I — 需求量 X」关系 | 必需品（凹）、奢侈品（凸）、低档品（向后弯） |

- **市场需求曲线** = 所有个人需求曲线**水平加总**（同一价格下把数量相加），加总后通常更平坦、更富有弹性。
- **恩格尔定律**：收入越低，食品支出占消费总支出的比重（恩格尔系数）越高。

### 3.4 替代效应与收入效应（本章难点）

![希克斯与斯勒茨基分解、吉芬品判定](/micro/micro-substitution.svg)

**总效应（价格效应）= 替代效应 + 收入效应**。

| 分解法 | 补偿标准 | 补偿预算线 | 特点 |
| --- | --- | --- | --- |
| 希克斯 | 保持**原效用水平 U₀** | 与新预算线平行、与原无差异曲线相切 | 对应补偿变量 CV、等价变量 EV，用于福利度量 |
| 斯勒茨基 | 保持**原消费组合可负担** | 过原均衡点 A、与新预算线平行 | `ΔI = (P₁ − P₀)X₀`，可直接观测，导出可测的斯勒茨基方程 |

**斯勒茨基方程**（连续形式）：`∂X/∂Px = ∂Xh/∂Px − X·(∂X/∂I)`
即「价格总效应 = 替代效应（希克斯需求，恒为负）+ 收入效应」。无穷小价格变动下两种分解收敛。

::: tip 工作例题 · 两种分解的完整手算
`U = XY`，`I = 100`，`Py = 5`，`Px` 从 `2` 降到 `1`：

- 起点 A：`X₀ = I/(2Px) = 25`，`Y₀ = 10`，`U₀ = 250`；终点 C：`X₁ = 100/(2×1) = 50`，`Y₁ = 10` ⇒ **总效应 +25**。
- **希克斯补偿**：新价格比 `Px/Py = 1/5`，切点条件 `Y/X = 1/5 ⇒ Y = X/5`；保持 `XY = 250 ⇒ X²/5 = 250 ⇒ Xh = √1250 ≈ 35.355`。
  ⇒ 替代效应 `35.355 − 25 = +10.355`，收入效应 `50 − 35.355 = +14.645`。
- **斯勒茨基补偿**：买得起原组合所需收入 `I′ = 1×25 + 5×10 = 75`；`Xs = 75/(2×1) = 37.5`。
  ⇒ 替代效应 `37.5 − 25 = +12.5`，收入效应 `50 − 37.5 = +12.5`。
- 两种分解都满足「总效应 = 25」，且替代效应恒与价格反向、收入效应对正常品加强它。
:::

| 商品类型 | 收入效应方向 | 与替代效应关系 | 需求曲线 |
| --- | --- | --- | --- |
| 正常品 | 与价格反向 | 同向叠加 | 向右下倾斜（斜率较大） |
| 低档品 | 与价格同向 | 部分抵消 | 仍向右下倾斜但更陡 |
| **吉芬品** | 与价格同向 | **绝对值超过替代效应** | 向右上倾斜（极罕见） |

::: danger 易错 · 替代与收入效应
- **替代效应恒为负**（与价格反向），这是希克斯需求曲线必然向下倾斜的原因；吉芬品只能靠收入效应"反超"，故吉芬品**必定是低档品**，但低档品不一定是吉芬品。
- 吉芬品需同时满足：低档 + 支出占收入比重大 + 缺乏替代品（爱尔兰土豆 famine 是常被引用的历史案例，实证上争议很大）。
- 价格下降时斯勒茨基补偿收入 `ΔI` 为**负**（要拿走购买力），价格上升时为正；符号别反。
- 显示偏好理论（补充）：若在购买力可负担 A 时选择了 B，则 B 显示偏好于 A；由此可在**不知效用函数**的情况下推导需求定律，是比基数/序数更弱的前提。
:::

### 3.5 不确定性与风险（课件第 3.7 节）

| 风险态度 | 效用函数 | `EU` 与 `U(EW)` | 例子 |
| --- | --- | --- | --- |
| 风险厌恶 | `U'' < 0`（凹，边际效用递减） | `EU < U(EW)` | `U = √W`、`U = ln W` |
| 风险中性 | `U'' = 0`（线性） | `EU = U(EW)` | 只比较期望值 |
| 风险偏好 | `U'' > 0`（凸） | `EU > U(EW)` | 赌博、彩票 |

- **期望效用** `EU = p·U(W₁) + (1−p)·U(W₂)`；**确定性等价** `CE` 满足 `U(CE) = EU`；**风险溢价** `= E(W) − CE`（为规避风险愿意放弃的期望收入）。

::: tip 工作例题 · 风险溢价
`U(W) = √W`，`p = 0.5`，`W₁ = 100`，`W₂ = 400`：
`EU = 0.5×10 + 0.5×20 = 15`；`E(W) = 250`，`U(EW) = √250 ≈ 15.811 > 15` ⇒ 风险厌恶。
`CE = EU² = 225`，**风险溢价 = 250 − 225 = 25**：此人最多愿花 25 买"确定得到 225"，以替代这场期望值 250 的赌局。
这也解释了保险：风险厌恶者愿支付高于精算公平保费的金额来消除风险。
:::

**补充**：课件只给期望效用框架，未展开**前景理论**（卡尼曼–特沃斯基：参照点依赖、损失厌恶、概率权重），以及**逆向选择/道德风险**（放到第 11 章）；阿莱悖论与圣彼得堡悖论说明期望效用并非描述性理论。

## 第 4 章 生产函数（★★★）

### 4.1 基本概念与短期生产三阶段

![TP、AP、MP 与生产三阶段](/micro/micro-production.svg)

| 概念 | 表达式 | 说明 |
| --- | --- | --- |
| 生产函数 | `Q = f(L, K, …)` | 一定技术下，最大产出与要素投入量的关系 |
| 短期 / 长期 | 至少一种要素固定 / 所有要素可变 | 不是日历时间，而是**调整能力**；不同行业长短不同 |
| 固定 / 可变投入 | `K̄` 固定 / `L` 可变 | 短期分析的基础 |
| 总产量 | `TP = Q(L)` | 可变要素带来的总产出 |
| 平均产量 | `AP = TP/L` | 原点向 TP 曲线连线斜率 |
| 边际产量 | `MP = dTP/dL` | TP 曲线切线斜率 |

**边际报酬递减规律**：技术给定、其他要素不变时，连续增加某可变要素，其 MP 最终递减。两个前提缺一不可。

::: tip 工作例题 · 短期生产函数全表
`Q = 10L − L²`（K 固定）：

| L | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 10 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| TP | 9 | 16 | 21 | 24 | 25 | 24 | 21 | 0 |
| AP | 9 | 8 | 7 | 6 | 5 | 4 | 3 | 0 |
| MP | 9 | 7 | 5 | 3 | 1 | −1 | −3 | −9 |

`AP = 10 − L`，`MP = 10 − 2L`；`L = 5` 时 `MP = 0`、`TP` 最大 = 25；`L > 5` 进入第Ⅲ阶段（MP 为负，投入越多产量越少）。
连续设定下 `MP = AP` 发生在 `L = 0`（该函数退化特例），典型三次型 `Q = 24L + 6L² − L³/3` 的 `AP` 最大在 `L = 9`、`MP = 0` 在 `L ≈ 13.75`，三阶段更清晰。
:::

**生产三阶段**：
- 第Ⅰ阶段（`0 → AP 最大`）：AP 递增、MP > AP，固定要素相对过多 ⇒ 增加可变要素总能提高效率，**不应停在此区**。
- 第Ⅱ阶段（`AP 最大 → MP = 0`）：AP、MP 均递减但 MP > 0，**唯一合理生产区域**；具体最优点须结合产品价格与要素价格（利润最大化）。
- 第Ⅲ阶段（`MP < 0`）：总产量下降，非理性区域。

::: danger 易错 · 生产
- `MP = AP` 处 AP 最大；`MP = 0` 处 TP 最大；`MP < 0` 时 TP 下降。三个"交点"别记混。
- 边际报酬递减 ≠ 规模报酬递减：前者短期、至少一种要素固定；后者长期、所有要素同比例变动（4.3 节）。
- 技术进步使整条 TP、MP 曲线**上移**，属曲线平移而非沿曲线移动，不构成对边际报酬递减规律的反例。
:::

### 4.2 长期生产：等产量线与最优要素组合

![等产量线、等成本线、扩展线与规模报酬](/micro/micro-isoquant.svg)

| 工具 | 方程 / 定义 | 斜率 |
| --- | --- | --- |
| 等产量线 | `f(L,K) = Q₀` | `−MRTS(LK) = −MPL/MPK`（递减 ⇒ 凸向原点） |
| 等成本线 | `C = wL + rK` ⇒ `K = C/r − (w/r)L` | `−w/r` |
| 最优组合 | `MRTS(LK) = w/r` ⇔ `MPL/w = MPK/r = 1/MC` | 切点 |
| 扩展线 | 各等成本线—等产量线切点的轨迹 | 要素价格不变时的长期扩张路径 |

**两组对偶问题**：给定产量求最小成本 ⇔ 给定成本求最大产量，二者给出同一阶条件。这也是第 5 章成本函数与生产函数对偶性的来源。

**特例**：
- 完全替代（线性生产函数 `Q = aL + bK`）：等产量线为直线，一般取**角点解**（比较 `a/w` 与 `b/r`）。
- 里昂惕夫固定比例（`Q = min(L/a, K/b)`）：L 形等产量线，最优在直角顶点 `L/a = K/b`，不满足相切条件。
- 柯布–道格拉斯 `Q = AL^αK^β`：`MRTS = (α/β)(K/L)`；`α`、`β` 分别为 L、K 的**产出弹性**。

### 4.3 规模报酬与生产函数齐次性

`f(λL, λK)` 与 `λf(L,K)` 比较（`λ > 1`）：

| 类型 | 条件 | C-D 情形 | 等产量线表现 |
| --- | --- | --- | --- |
| 递增 | `f(λL,λK) > λQ` | `α + β > 1` | 等产量线沿射线越来越密 |
| 不变 | `= λQ` | `α + β = 1` | 等间距 |
| 递减 | `< λQ` | `α + β < 1` | 越来越疏 |

- **齐次函数**：若 `f(λL,λK) = λⁿ f(L,K)`，则为 n 次齐次，n 即规模报酬次数；C-D 函数是 `(α+β)` 次齐次。
- **欧拉定理**：n 次齐次函数满足 `n·Q = MPL·L + MPK·K`；`n = 1`（不变规模报酬）时 `Q = MPL·L + MPK·K`，即**产品分配净尽定理**（第 8 章边际生产力分配论的依据）。

::: tip 补充 · 技术进步的分类（希克斯/哈罗德/索洛中性）
课件只提"技术进步使等产量线向内移动"。补充：若技术进步使 MRTS 不变（等产量线沿射线平移）为**希克斯中性**；若使资本—产出比不变为哈罗德中性；若使劳动—产出比不变为索洛中性。中性技术进步只改变生产函数的效率项 A，不改变要素边际产量之比。CES 生产函数 `Q = A[δL^ρ + (1−δ)K^ρ]^{1/ρ}` 统一了 C-D（`ρ→0`）、完全替代（`ρ=1`）、里昂惕夫（`ρ→−∞`），替代弹性 `σ = 1/(1−ρ)` 为常数。
:::

## 第 5 章 成本（★★★）

### 5.1 成本的基本概念与利润口径

| 概念 | 定义 | 要点 |
| --- | --- | --- |
| 机会成本 | 要素用于本用途所放弃的最高其他用途收益 | 经济学的成本口径 |
| 显成本 | 实际货币支出（工资、原料、租金） | 会计记录的成本 |
| 隐成本 | 自有要素的机会成本（自有资金利息、业主自身劳动工资） | 会计不记，经济决策必记 |
| 正常利润 | 企业家才能的报酬，属隐成本 | 经济利润为零时企业仍获正常利润 |
| 会计利润 | `TR − 显成本` | 通常大于经济利润 |
| 经济利润（超额利润） | `TR − (显成本 + 隐成本)` | 决策用；为零是长期均衡标志 |
| 沉没成本 | 已支出且不可收回 | 不影响边际决策，但会计上仍是成本 |

::: tip 工作例题 · 三种利润
某人辞职创业：原年薪 12 万，自有店面若出租可得 6 万，投入自有资金 50 万（年利率 3% ⇒ 利息 1.5 万）；全年营业收入 60 万，显成本（原料、雇工）38 万。
- 会计成本 = 38 万 ⇒ **会计利润 = 22 万**。
- 隐成本 = 12 + 6 + 1.5 = 19.5 万 ⇒ 经济成本 = 57.5 万 ⇒ **经济利润 = 2.5 万**（仍值得继续经营）。
- 若营业收入降到 55 万，经济利润 = −2.5 万，虽然账面仍赚 17 万，理性决策是回去上班。
:::

### 5.2 成本最小化与生产—成本对偶

![七条短期成本曲线与三个交点](/micro/micro-cost.svg)

**成本最小化问题**：
`min wL + rK  s.t. f(L,K) = Q₀`
拉格朗日一阶条件 ⇒ `MPL/w = MPK/r = λ`，其中 `λ = 1/MC`，即**拉格朗日乘子就是边际成本的倒数**。
**产量最大化问题**（给定 C）给出同一条件 —— 这就是第 4 章的**对偶关系**。

由生产函数可反解成本函数：`C(Q; w, r)`；短期存在固定成本，长期全部可变。
**谢泼德引理**（补充）：`∂C/∂w = L*`（条件要素需求），把成本函数对要素价格求偏导即可得要素需求。

### 5.3 短期成本曲线族（七条）

| 曲线 | 定义 | 形状 |
| --- | --- | --- |
| TFC | 总不变成本 | 水平线，与产量无关 |
| TVC | 总可变成本 | 随 Q 递增，先以递减速率后以递增速率上升 |
| STC | `TFC + TVC` | TVC 上移 TFC |
| AFC | `TFC/Q` | 直角双曲线，单调递减趋近 0 |
| AVC | `TVC/Q` | U 形 |
| AC (SAC) | `STC/Q = AFC + AVC` | U 形；与 AVC 的垂直距离 = AFC，随 Q 缩小 |
| SMC | `dSTC/dQ = dTVC/dQ` | U 形；与 TFC 无关 |

**三个必考交点**：
1. `SMC` 从下方穿过 `AVC` 的**最低点**；
2. `SMC` 从下方穿过 `AC` 的**最低点**；
3. `AC` 最低点在 `AVC` 最低点的**右上方**（因 AFC 仍在下降，把 AC 最低点推后）。

**生产—成本对偶**：`MP` 递增 ⇔ `MC` 递减；`MP` 最大 ⇔ `MC` 最小；`AP` 最大 ⇔ `AVC` 最小。数学上 `AVC = w/AP(L)`、`MC = w/MP(L)`（单一可变要素、工资 w 给定时）。

::: tip 工作例题 · 七条曲线的完整数值表
`STC = Q³ − 6Q² + 15Q + 100`（TFC = 100）：
`TVC = Q³−6Q²+15Q`，`AVC = Q²−6Q+15`，`AC = AVC + 100/Q`，`SMC = 3Q²−12Q+15`。

| Q | TVC | STC | AFC | AVC | AC | SMC |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 10 | 110 | 100.00 | 10.00 | 110.00 | 6 |
| 2 | 14 | 114 | 50.00 | 7.00 | 57.00 | 3 |
| 3 | 18 | 118 | 33.33 | **6.00** | 39.33 | **6** |
| 4 | 28 | 128 | 25.00 | 7.00 | 32.00 | 15 |
| 5 | 50 | 150 | 20.00 | 10.00 | **30.00** | **30** |
| 6 | 90 | 190 | 16.67 | 15.00 | 31.67 | 51 |

- `Q = 3`：`AVCmin = 6 = SMC`（SMC 穿 AVC 最低点 ✓）。
- `Q = 5`：`ACmin = 30 = SMC`（SMC 穿 AC 最低点 ✓），且 5 > 3 印证 AC 最低点在右上方。
- `Q = 2`：`SMC = 3` 最小，对应 `MP` 最大的产量。
:::

### 5.4 长期成本曲线

![长期成本包络线、规模经济与范围经济](/micro/micro-cost-long.svg)

| 曲线 | 定义 | 性质 |
| --- | --- | --- |
| LTC | 长期生产每个产量的**最低**总成本 | 由扩展线导出（LTC 是所有 STC 的下包络） |
| LAC | `LTC/Q` | 所有 SAC 的**包络线**，U 形；`SAC ≥ LAC`，只在切点相等 |
| LMC | `dLTC/dQ` | 过 LAC 最低点；与对应 SAC 的 SMC 在切点产量处相等 |

**相切位置**：LAC 下降段与 SAC 最低点**左侧**相切；LAC 上升段与 SAC 最低点**右侧**相切；仅 LAC 最低点与某一 SAC 最低点重合。

| 概念 | 判据 | 成因 |
| --- | --- | --- |
| 规模经济 | LAC 随 Q 下降 | 专业化、设备不可分性、副产品利用、融资与采购优势 |
| 规模不经济 | LAC 随 Q 上升 | 管理层级过多、协调与信息传递成本 |
| 范围经济 | `C(Q₁,Q₂) < C(Q₁,0) + C(0,Q₂)` | 共享投入、渠道、品牌与技术（多产品） |
| 学习效应 | 平均成本随**累计**产量下降 | 干中学，动态效应而非规模效应 |

::: danger 易错 · 成本
- 长期**没有固定成本**：所有要素都可变，`LTC(0) = 0`；短期 TFC 是"沉没"意义上的固定。
- 规模报酬（技术，实物量、齐次性）≠ 规模经济（成本，含要素价格变化）；前者是后者的**充分非必要**条件之一。
- `LAC` 是包络线而非所有 SAC 最低点的连线（只有在 LAC 最低点处才与 SAC 最低点重合）。
- 边际成本与固定成本无关；`SMC` 上升段才是短期供给曲线（第 6 章）。
:::

## 第 6 章 完全竞争市场（★★★）

### 6.1 市场类型与完全竞争四条件

![完全竞争厂商短期均衡五种情形与两条临界线](/micro/micro-perfect-comp.svg)

| 市场类型 | 厂商数 | 产品差别 | 价格控制力 | 进入难度 | 典型行业 |
| --- | --- | --- | --- | --- | --- |
| 完全竞争 | 很多 | 无差别 | 无（价格接受者） | 很容易 | 部分农产品、标准化大宗商品 |
| 垄断竞争 | 很多 | 有差别 | 有一些 | 比较容易 | 餐饮、服饰、零售 |
| 寡头 | 少数 | 有/无差别 | 相当程度 | 比较困难 | 钢铁、汽车、石油、通信 |
| 垄断 | 唯一 | 无相近替代品 | 很大（但受需求约束） | 极难 | 公用事业、专利药 |

**完全竞争四条件**：大量买者与卖者（每个个体份额可忽略）、产品完全同质、要素完全自由流动、信息完全。
⇒ 单个厂商面对**水平的需求线**：`P = AR = MR = d`，只能决定产量。

### 6.2 利润最大化与短期均衡

`π(Q) = TR(Q) − STC(Q)` ⇒ 一阶条件 `dTR/dQ = dSTC/dQ`，即 **`MR = MC`**；
二阶条件要求 `MC` 处于**上升段**（否则该点是利润最小点）。

**五种短期均衡结果**：

| 价格区间 | 利润 | 厂商决策 |
| --- | --- | --- |
| `P > ACmin` | `π > 0` 超额利润 | 继续生产，新厂商将进入 |
| `P = ACmin` | `π = 0`（**收支相抵点**） | 继续生产，只获正常利润 |
| `AVCmin < P < ACmin` | `π < 0` 但亏损最小 | **继续生产**（能补全部可变成本并分摊部分固定成本） |
| `P = AVCmin` | `π = −TFC`（**停止营业点/关门点**） | 生产与不生产无差别 |
| `P < AVCmin` | 亏损 > TFC | 立即停产，损失限于 TFC |

::: tip 工作例题 · 短期均衡、盈亏与关门决策
`STC = Q² + 4Q + 36`（`SMC = 2Q + 4`，`AC = Q + 4 + 36/Q`，`AVC = Q + 4`）。
- `P = 20`：`2Q + 4 = 20 ⇒ Q* = 8`；`TR = 160`，`STC = 132` ⇒ **π = 28**。
- 收支相抵：`AC` 最小 ⇒ `dAC/dQ = 1 − 36/Q² = 0 ⇒ Q = 6`，`ACmin = 16`。
- 关门价格：`AVC = Q + 4` 递增，下确界为 4（严格设 U 形时应取 AVCmin）。
- `P = 14`：`Q = 5`，`TR = 70`，`STC = 81` ⇒ **亏 11**；但 `AVC = 9 < 14` ⇒ **继续生产**（比停产亏 36 好得多）。
:::

**两条重要曲线**：
- **厂商短期供给曲线** = `SMC ≥ AVCmin` 的上升段（每一价格对应利润最大产量）。
- **行业短期供给曲线** = 各厂商短期供给曲线的**水平加总**；与市场需求共同决定短期行业均衡。

### 6.3 长期均衡与行业长期供给曲线

![长期零利润均衡与三种行业长期供给曲线](/micro/micro-longrun.svg)

**长期调整机制**：短期 `π > 0` ⇒ 新厂商进入 ⇒ 行业 S 右移 ⇒ P 下降 ⇒ 单厂商需求线下移；`π < 0` ⇒ 退出 ⇒ P 回升。同时厂商调整工厂规模（沿 LAC 选最优 SAC）。

**长期均衡条件**：
`P = MR = LMC = SMC = LACmin = SACmin` ⇒ **经济利润 = 0**。
既是"资源配置效率"（`P = MC`）又是"生产效率"（在 LAC 最低点生产）。

| 行业类型 | 要素价格随行业扩张 | LS 形状 | 长期价格 |
| --- | --- | --- | --- |
| 成本不变 | 不变（行业是要素市场小买主） | 水平 | 回到原 P |
| 成本递增 | 上升（要素稀缺、外部不经济） | 右上倾斜 | 上升（最常见） |
| 成本递减 | 下降（外在经济） | 右下倾斜 | 下降（罕见） |

::: danger 易错 · 长期均衡
- "零利润"指**经济利润**为零，正常利润已计入隐成本，企业并非不赚钱。
- 需求增加在**成本不变行业**的长期只增加厂商数量与总产量，价格不变；短期先涨后回落。
- 长期均衡条件中的 `LMC = LACmin` 是因为 LMC 必过 LAC 最低点；`SMC = SACmin` 同理，且两个最低点重合于最优规模点。
- 完全竞争厂商**有**供给曲线；不完全竞争厂商（垄断、垄断竞争、寡头）**没有**唯一的供给曲线，因为价格与产量不再一一对应（取决于需求曲线形状与对手反应）。
:::

### 6.4 消费者剩余、生产者剩余与市场福利

| 概念 | 定义 | 图形 |
| --- | --- | --- |
| 消费者剩余 CS | 愿意支付 − 实际支付 | 需求曲线以下、价格线以上 |
| 生产者剩余 PS | 实际收入 − 愿意接受的最低报酬 | 价格线以下、SMC 曲线以上；`PS = π + TFC` |
| 总剩余 | `CS + PS` | 完全竞争均衡时**最大** |

**为什么 `P = MC` 是效率条件**：`P` 反映消费者对最后一单位的社会评价，`MC` 反映生产它的社会成本。`P > MC` 说明还有互利交易未完成（应增产）；`P < MC` 说明资源耗费超过评价（应减产）。只有相等时总剩余最大。

**无谓损失 DWL**：任何使成交量偏离竞争均衡的干预（税收、配额、垄断、价格管制）都会损失一部分本可实现的互利交易，损失面积常用三角形 `½·ΔQ·ΔP` 计算。

::: tip 补充 · 福利分析的两条现代注解
① **哈伯格三角形与寻租**：传统垄断福利分析只算 DWL 三角形；塔洛克指出厂商为获取并维持垄断地位会投入真实资源（游说、诉讼、超额产能），这部分**寻租成本**可能远大于三角形，是第 11 章反垄断讨论的基础。
② **总剩余最大化 ≠ 分配合意**：竞争均衡有效率但可能极不平等，福利经济学第二定理说明可通过一次总付再分配改变分配而不损效率（第 9 章）。
:::

## 第 7 章 不完全竞争市场（★★★）

### 7.1 垄断：均衡、弹性与福利损失

![垄断均衡、无谓损失与价格歧视](/micro/micro-monopoly.svg)

| 项目 | 完全竞争厂商 | 垄断厂商 |
| --- | --- | --- |
| 需求曲线 | 水平 `P = AR = MR` | 向右下倾斜（= 市场需求曲线），`MR < P` |
| 均衡条件 | `P = MR = MC` | `MR = MC`，再由需求曲线定 `P` |
| 供给曲线 | SMC 上升段存在 | **不存在**（同一 P 可对应不同 Q，取决于需求弹性） |
| 长期利润 | 0 | 可长期保持正利润（存在进入壁垒） |
| 效率 | `P = MC`，有效率 | `P > MC`，有 DWL |

**线性需求的 MR**：`P = a − bQ ⇒ TR = aQ − bQ² ⇒ MR = a − 2bQ`。
MR 与需求曲线纵截距相同、斜率是 2 倍、横截距是一半。

**MR、P 与弹性的关系**：
`MR = P(1 − 1/|Ed|)` ⇒ **勒纳指数** `L = (P − MC)/P = 1/|Ed|`。

::: danger 易错 · 勒纳指数
- 由 `L = 1/|Ed|` 知垄断者**绝不会在 `|Ed| < 1` 处生产**：此时 `MR < 0` 而 `MC ≥ 0`，减产提价可同时增收降本。
- 勒纳指数衡量**市场势力**（0 到 1），不是垄断程度本身：完全竞争 `L = 0`；需求弹性越小，`L` 越大、加成越高。
- `L` 大不代表利润大（还取决于平均成本与销量），也不必然代表社会福利损失更大（可能有规模经济）。
:::

::: tip 工作例题 · 垄断均衡与无谓损失完整计算
`P = 100 − 2Q`，`MC = 20`（常数，TFC = 0）：
- `MR = 100 − 4Q = 20 ⇒ Qm = 20`，`Pm = 60`，`π = (60−20)×20 = 800`。
- `CS = ½×(100−60)×20 = 400`；`|Ed| = (1/2)(P/Q) = (1/2)×3 = 1.5`，`L = 40/60 = 2/3 = 1/1.5` ✓。
- 竞争结果：`P = MC = 20 ⇒ Qc = 40`；**DWL = ½×(60−20)×(40−20) = 400**。
- 一般式（线性需求 `P = a − bQ`、`MC = c`）：`Qm = (a−c)/(2b)`，`Pm = (a+c)/2`，`|Ed| = (a+c)/(a−c)`。
:::

**垄断的三个成因**：独家控制关键资源、政府管制/专利与特许、自然垄断（LAC 在相关产量范围内递减）。
**自然垄断的管制难题**：边际成本定价 `P = MC` 有效但 `P < AC` 会亏损（需补贴）；平均成本定价 `P = AC` 不亏损但产量仍低于有效水平；此外还有回报率管制（易诱发 A-J 效应：过度投资资本）。

### 7.2 价格歧视

**三条件**：① 厂商有市场势力；② 能识别（或让消费者自我选择出）不同支付意愿；③ 能有效阻止套利转售。

| 类型 | 别名 | 做法 | 福利结果 |
| --- | --- | --- | --- |
| 一级 | 完全价格歧视 | 每单位按消费者保留价格出售 | 产量达竞争水平、**无 DWL**，但 CS 全被厂商占有 |
| 二级 | 数量歧视 / 菜单定价 | 按消费量分段定价、两部定价、捆绑 | 通过自我选择榨取部分 CS |
| 三级 | 群体定价 | 按可观察特征分割市场（学生票、地区定价） | `MR₁ = MR₂ = MC` |

**三级价格歧视定价法则**：
`P₁(1 − 1/|E₁|) = P₂(1 − 1/|E₂|) = MC` ⇒ **需求弹性小的市场定价更高**。

::: tip 工作例题 · 三级价格歧视（含统一定价对比）
市场1 `P₁ = 100 − 2Q₁`，市场2 `P₂ = 80 − Q₂`，`MC = 20`（常数）：
- `MR₁ = 100 − 4Q₁ = 20 ⇒ Q₁ = 20, P₁ = 60`；`|E₁| = (100+20)/(100−20) = 1.5`。
- `MR₂ = 80 − 2Q₂ = 20 ⇒ Q₂ = 30, P₂ = 50`；`|E₂| = (80+20)/(80−20) ≈ 1.667`。
- 验算：`60×(1−1/1.5) = 20`，`50×(1−1/1.667) = 20` ✓；弹性较小的市场1 定价更高 ✓。
- `π = (60−20)×20 + (50−20)×30 = 800 + 900 = 1700`。
- **统一定价**：总需求 `Q = (100−P)/2 + (80−P) = 130 − 1.5P`，`π = (P−20)(130−1.5P)`，求导 `130 − 1.5P − 1.5(P−20) = 0 ⇒ P = 53.33`，`π ≈ 1666.67`。
- 结论：可分割且弹性不同时，**价格歧视提高利润**（1700 > 1666.67）；但若两市场弹性相同，歧视无收益。
:::

### 7.3 垄断竞争

| 特征 | 内容 |
| --- | --- |
| 条件 | 大量厂商、**产品有差别**（垄断力来源）、进出较容易 |
| 两条需求曲线 | **主观需求曲线 d**：自己降价而对手不跟随时，弹性大、较平坦；**客观需求曲线 D**：全体同时调整时，市场份额不变、较陡 |
| 短期均衡 | `MR = MC`，可盈利可亏损（与垄断类似） |
| 长期均衡 | 自由进入使 d 左移直到与 LAC **相切** ⇒ `π = 0`，且 `MR = LMC` |
| 效率 | `P > LMC` 且产量**低于 LAC 最低点** ⇒ 存在**过剩产能**；但换来产品多样化（是权衡而非纯损失） |

**非价格竞争**：产品差异化、品牌、质量、服务、广告。广告的信息性作用（降低搜寻成本）与劝说性作用（制造虚假差别）需区分。

### 7.4 寡头：四个经典模型

![古诺反应曲线与四种寡头模型比较](/micro/micro-oligopoly.svg)

| 模型 | 决策变量 | 时序 | 均衡（P = a − Q、MC = 0） | 结论 |
| --- | --- | --- | --- | --- |
| 卡特尔 / 垄断 | 总产量 | 合谋 | `Q = a/2, P = a/2` | 总利润最大，但不稳定（有欺骗动机） |
| 古诺 | 产量 | 同时 | `Q = 2a/3, P = a/3` | 反应函数交点 = 纳什均衡 |
| 斯塔克尔伯格 | 产量 | 先后 | `Q = 3a/4, P = a/4` | **先动优势**：领导者产量、利润均大于跟随者 |
| 伯特兰 | 价格 | 同时 | `P = MC = 0, Q = a` | **伯特兰悖论**：两家即达竞争结果 |

::: tip 工作例题 · 课件原题（P = 18 − Q、MC = 0）
`π₁ = [18 − (Q₁+Q₂)]Q₁`，`∂π₁/∂Q₁ = 18 − 2Q₁ − Q₂ = 0` ⇒ 反应函数 `Q₁ = 9 − Q₂/2`；对称 `Q₂ = 9 − Q₁/2`。
联立 ⇒ `Q₁ = Q₂ = 6`，`Q = 12`，`P = 6`，`π₁ = π₂ = 36`。

- **通式**：`P = a − bQ`、`MC = c` 时 `Qi = (a−c)/(3b)`，n 家同质寡头 `Q = n(a−c)/[(n+1)b]`；`n→∞` 时 `Q→(a−c)/b`（竞争结果），`n = 1` 时回到垄断。
- **斯塔克尔伯格**（1 为领导）：把 `R₂ = 9 − Q₁/2` 代入 ⇒ `π₁ = (9 − Q₁/2)Q₁`，求导得 `Q₁ = 9`，`Q₂ = 4.5`，`P = 4.5`，`π₁ = 40.5 > π₂ = 20.25`（先动优势）。
- **卡特尔**：`Q = 9, P = 9`，总利润 81，各 40.5 > 古诺的 36 ⇒ 合谋有吸引力，但单方偷偷增产可获益 ⇒ 卡特尔天然不稳定（第 10 章囚徒困境）。
:::

**伯特兰悖论的破解**：产品差别（差异化的价格竞争不再导致 `P = MC`）、产能约束（埃奇沃斯悖论）、重复博弈（合谋可持续）、信息不完全。

**斯威齐弯折需求曲线**（补充）：假设"跟跌不跟涨" ⇒ 需求曲线在现行价格处出现折点，MR 曲线出现**间断**；只要 MC 的变动落在间断区内，价格与产量都不变 ⇒ 解释**价格刚性**。批评：它解释价格为何不动，却未说明现行价格本身如何形成。

::: danger 易错 · 市场比较
- 长期经济利润：完全竞争 = 0、垄断竞争 = 0、寡头 ≥ 0、垄断 ≥ 0（关键在**进入壁垒**而非厂商数量）。
- 效率排序（产量由大到小、价格由低到高）：完全竞争 > 垄断竞争 > 寡头 > 垄断；但产品多样化使垄断竞争的福利判断不能只看过剩产能。
- 古诺与斯塔克尔伯格的**均衡都是纳什均衡**，后者是动态博弈的子博弈精炼均衡（逆向归纳）。
:::

## 第 8 章 生产要素价格的决定（★★★）

### 8.1 引致需求与要素使用原则

![向后弯曲劳动供给、要素原则与洛伦兹曲线](/micro/micro-factor.svg)

**引致需求（派生需求）**：厂商对要素的需求不是为要素本身，而是因为它能生产可出售的产品 ⇒ 要素需求取决于产品需求与要素的边际生产力（课件称"间接需求"）。

| 概念 | 表达式 | 说明 |
| --- | --- | --- |
| 边际产品 | `MP = dQ/dL` | 要素的实物边际产量 |
| 边际产品价值 | `VMP = P·MP` | 完全竞争产品市场下使用要素的"边际收益" |
| 边际收益产品 | `MRP = MR·MP` | 一般式；产品市场完全竞争时 `MR = P` ⇒ `MRP = VMP` |
| 边际要素成本 | `MFC = dC/dL` | 完全竞争要素市场下 `MFC = w` |
| **要素使用原则** | `VMP = w`（`P·MP = w`） | 一般式 `MRP = MFC` |

**推导**：`π(L) = P·Q(L) − wL`，`dπ/dL = P·MP(L) − w = 0 ⇒ P·MP = w`。与第 6 章 `MR = MC` 完全等价，只是把决策变量从 Q 换成了 L。

::: danger 易错 · 要素需求曲线
- 单个厂商的要素需求曲线是 **VMP 曲线的下降段**（MP 递减部分），但**不是全部 VMP 曲线**（上升段不满足二阶条件）。
- 市场要素需求曲线 **≠ 单个厂商需求曲线简单水平加总**：所有厂商同时增雇劳动会增产 ⇒ 产品价格 P 下降 ⇒ 各厂商 VMP 曲线下移 ⇒ 市场需求曲线比简单加总**更陡**（课件 8.3 节专门讨论此点）。
- 卖方垄断产品市场：`MRP = MR·MP < P·MP = VMP`，故垄断厂商雇用更少要素（这是对垄断的另一重效率批评）。
- 要素市场买方垄断（ monopsony ）：`MFC > w`，均衡 `MRP = MFC` ⇒ 雇用量与工资均低于竞争水平。
:::

::: tip 工作例题 · VMP = w
`Q = 10L − L²`，产品价格 `P = 5` ⇒ `MP = 10 − 2L`，`VMP = 50 − 10L`。
- `w = 40 ⇒ L = 1`；`w = 30 ⇒ L = 2`；`w = 20 ⇒ L = 3`。
- 把 `w` 当作自变量，`L = 5 − 0.1w` 即为该厂商的要素需求函数（向下倾斜）。
:::

### 8.2 劳动供给与工资决定

**时间配置模型**：把 16 小时可支配时间在"工作（收入）"与"闲暇"之间分配。预算约束 `C = w(16 − H) + 非劳动收入`，无差异曲线在 (闲暇 H, 消费 C) 平面上，切点条件为闲暇对消费的边际替代率等于工资 `w`（工资是闲暇的机会成本）。

| 效应 | 工资上升时 | 对劳动供给 |
| --- | --- | --- |
| 替代效应 | 闲暇变贵 ⇒ 少享闲暇 | 劳动供给 ↑ |
| 收入效应 | 实际收入上升 ⇒ 多享「正常品」闲暇 | 劳动供给 ↓ |

⇒ 工资较低时替代效应占优，劳动供给随工资上升；工资超过临界值后收入效应占优 ⇒ **向后弯曲的劳动供给曲线**。

**市场均衡工资**：劳动市场需求（所有厂商 VMP 加总、修正）与劳动供给（所有个人供给加总）交点决定。
**补充**：工会、最低工资、效率工资、补偿性工资差别、人力资本与教育信号、劳动市场歧视都会使实际工资偏离竞争基准；最低工资的就业效应在竞争性模型（减少就业）与买方垄断模型（可能同时提高工资与就业）中结论相反。

### 8.3 地租、利息、利润与欧拉定理

| 要素 | 报酬 | 关键结论 |
| --- | --- | --- |
| 土地 | 地租 | 就**全社会**而言土地供给固定（垂直供给曲线）⇒ 地租完全由需求决定，且地租是「剩余」而非成本决定价格 |
| 资本 | 利息 / 利率 | 跨期选择：家庭在现期与未来消费间取舍，均衡利率使储蓄 = 投资；利率是「等待」的报酬 |
| 企业家才能 | 正常利润 | 计入隐成本；创新与风险承担带来超额利润（熊彼特、奈特） |
| 经济租 | 超出要素机会成本（保留价格）的报酬 | 供给越缺乏弹性，租越大；地租是特例，明星高薪、牌照价值都是租 |

**准租金**：短期固定要素的报酬，其数量在短期固定，类似地租；长期可调整后消失（与 TFC 概念对应）。

**欧拉定理 / 产品分配净尽**：规模报酬不变（`n = 1` 齐次）+ 完全竞争时
`Q = MPL·L + MPK·K`，两边乘 P 得 `TR = wL + rK` ⇒ 总收入恰好按边际生产力分配殆尽，经济利润为零。
若规模报酬递增，`MPL·L + MPK·K > Q`（不够分）；递减则 `< Q`（有剩余）。这为第 6 章「完全竞争长期零利润」提供了生产函数层面的证明。

### 8.4 洛伦兹曲线与基尼系数

**洛伦兹曲线**：横轴为人口累计百分比（按收入由低到高排序），纵轴为收入累计百分比；45° 线为绝对平等线，曲线越弯曲越不平等。

**基尼系数** `G = A/(A+B)`，A 为 45° 线与洛伦兹曲线之间的面积，B 为洛伦兹曲线以下面积；`0 ≤ G ≤ 1`。

::: tip 工作例题 · 梯形法算基尼系数
5 等分组的收入份额依次为 `5%、10%、15%、25%、45%` ⇒ 累计收入份额 `0.05, 0.15, 0.30, 0.55, 1.00`。
用梯形法求洛伦兹曲线下面积（每组宽 0.2）：
`B = 0.2×[(0+0.05)/2 + (0.05+0.15)/2 + (0.15+0.30)/2 + (0.30+0.55)/2 + (0.55+1.00)/2] = 0.2×1.55 = 0.31`。
`A = 0.5 − 0.31 = 0.19` ⇒ **`G = 0.19/0.5 = 0.38`**。
也可用等价公式 `G = 1 − (1/n)·Σ(2·Σ... )` 快速验证；注意分组数越多、算出的 G 越精确，同一数据不同分组口径不可直接比较。
:::

::: danger 易错 · 分配
- 基尼系数反映的是**相对**不平等，对同比例的收入整体平移不敏感；也不能反映组内差异与收入流动性，需配合分位数比、泰尔指数、贫困率一起看。
- 地租「由需求决定」只对**总量固定**的土地成立；对某一具体用途而言，土地供给是向上倾斜的（可从其他用途转入），此时地租仍影响配置。
- 经济租与准租金不是"超额利润"的同义词：前者属要素报酬，后者是短期固定要素报酬。
:::

## 第 9 章 一般均衡论和福利经济学（★★★）

### 9.1 局部均衡与一般均衡

![埃奇沃思盒、帕累托最优三条件与福利函数](/micro/micro-welfare.svg)

| 项目 | 局部均衡 | 一般均衡 |
| --- | --- | --- |
| 分析范围 | 单个产品/要素市场（假定其他价格不变） | 所有市场同时、相互依赖地出清 |
| 代表 | 马歇尔供求分析 | 瓦尔拉斯体系；阿罗–德布鲁证明存在性 |
| 关键洞察 | 简单、可操作 | 一个市场的外生冲击会通过替代品、要素价格传导到其他市场 |

**一般均衡的存在性问题**：是否存在一组价格，使所有商品与要素的供给都等于需求？在凸偏好、凸技术、无外部性等条件下，用不动点定理可证明存在（阿罗–德布鲁）；**存在 ≠ 唯一 ≠ 稳定**（多重均衡、均衡的稳定性与调整过程是独立问题）。

**瓦尔拉斯法则**（补充）：所有市场超额需求的价值之和恒为零 ⇒ 若有 n−1 个市场出清，第 n 个必出清；因此只需 n−1 个独立方程，货币只决定价格水平（古典二分法）。

### 9.2 帕累托最优与三个边际条件

| 概念 | 定义 |
| --- | --- |
| 帕累托改进 | 使至少一人变好、且无人变坏的变动 |
| 帕累托最优（经济效率） | 已不存在任何帕累托改进空间的状态 |
| 契约曲线 | 埃奇沃思盒中所有无差异曲线（或等产量线）切点的轨迹 |

**三个必要条件**（完全竞争 + 凸性下同时也是充分条件）：

| 条件 | 公式 | 工具 | 含义 |
| --- | --- | --- | --- |
| 交换最优 | `MRS(A,XY) = MRS(B,XY)` | 交换的埃奇沃思盒、契约曲线 VV′ | 任意两消费者对任意两商品的边际替代率相等 |
| 生产最优 | `MRTS(C,LK) = MRTS(D,LK)` | 生产的埃奇沃思盒 | 任意两生产者对任意两要素的边际技术替代率相等 |
| 生产与交换最优 | `MRS(XY) = MRT(XY)` | 生产可能性边界 PPF | 消费端愿意交换的比率 = 生产端能够转换的比率 |

**边际转换率** `MRT(XY) = |dY/dX| = MCx/MCy`，即 PPF 切线斜率（递增因机会成本递增）。

**完全竞争为何自动满足三条件**：所有消费者面对同一价格比 `Px/Py`，各自最优化使 `MRS = Px/Py` ⇒ 条件 1；所有厂商面对同一要素价格比 `w/r`，使 `MRTS = w/r` ⇒ 条件 2；`P = MC` 使 `Px/Py = MCx/MCy = MRT` ⇒ 条件 3。这正是「看不见的手」的严格表述。

::: danger 易错 · 帕累托
- 帕累托最优点**有无穷多个**（UU′ 效用可能性边界上每一点都是），"哪一个最好"须引入社会福利函数，属价值判断。
- 帕累托最优是**效率**概念，不含公平；极不平等的分配也可能是帕累托最优。
- 「有人变好、有人变坏」的变动**不能**用帕累托标准比较，需用卡尔多–希克斯补偿标准（潜在帕累托改进：受益者理论上能补偿受损者）。
:::

### 9.3 社会福利函数与福利经济学两定理

| 社会福利函数 | 形式 | 立场 |
| --- | --- | --- |
| 加法型（功利主义） | `W = U_A + U_B` | 最大化总效用之和 |
| 乘法型（纳什积） | `W = U_A · U_B` | 兼顾总量与分配 |
| 罗尔斯型（最大最小） | `W = min(U_A, U_B)` | 最大化最差者效用 |
| 弹性型 / 一般式 | `W = [Σ αᵢ Uᵢ^ρ]^{1/ρ}` | `ρ` 刻画不平等厌恶程度 |

**福利经济学第一定理**：在完全竞争、无外部性、无公共物品、信息完全、凸性等条件下，竞争均衡是帕累托有效的（效率）。
**福利经济学第二定理**：任意帕累托有效分配，都可以通过「**一次总付（lump-sum）再分配** + 完全竞争市场」来实现 ⇒ **效率与公平可以分离**。

::: danger 易错 · 两定理的边界
- 第二定理要求一次总付税（不扭曲相对价格）；现实中的所得税、商品税会扭曲激励，故"先分配后市场"在实践中打折扣。
- 第一定理的前提一旦被破坏（外部性、公共物品、信息不对称、市场势力），竞争均衡就不再有效 —— 这正是第 11 章"市场失灵"的理论定位。
- 阿罗不可能定理：满足无限制定义域、帕累托原则、无关备选项独立性、非独裁等公理的社会选择规则**不存在** ⇒ 无法仅由个人偏好"民主地"加总出一致的社会排序。
:::

## 第 10 章 博弈论初步（★★★）

### 10.1 基本概念与支付矩阵

![囚徒困境支付矩阵、划线法与混合策略](/micro/micro-game.svg)

| 概念 | 定义 |
| --- | --- |
| 参与人 / 策略 / 支付 | 决策主体 / 完整的行动方案 / 各策略组合下的收益 |
| 支付矩阵 | 两个参与人、各两个策略的完全信息静态博弈的标准表示 |
| 条件策略 | 给定对方某一策略时，自己的最优策略 |
| 占优策略 | 无论对方选什么都最优的策略（占优均衡必是纳什均衡，反之不成立） |
| **纳什均衡** | 策略组合中，任何参与人**单独**改变策略都不会获益 |
| 混合策略 | 以一定概率随机选择纯策略；均衡时各方使对方在纯策略间无差异 |

**条件策略下划线法**（课件给出的方法）：
① 把支付矩阵拆成甲、乙两张表；
② 在甲的表中，对乙的**每一列**找出甲的最大支付并画线；
③ 在乙的表中，对甲的**每一行**找出乙的最大支付并画线；
④ 合并两表，**双方都画线**的格子即为纯策略纳什均衡。

### 10.2 囚徒困境与寡头合作的不稳定性

支付矩阵（单元格为「甲, 乙」，取自课件的寡头合作/不合作博弈精神，数值为便于说明的标准示例）：

| 甲 \ 乙 | 坦白（不合作） | 抵赖（合作） |
| --- | --- | --- |
| **坦白** | `−8, −8` | `1, −20` |
| **抵赖** | `−20, 1` | `−1, −1` |

- 无论乙选什么，甲选「坦白」都更好（占优策略）；乙同理 ⇒ 唯一纳什均衡 `(坦白, 坦白) = (−8, −8)`。
- 但 `(抵赖, 抵赖) = (−1, −1)` 使**双方都更好**（帕累托优于均衡）⇒ **个体理性导致集体非理性**。
- 这正是第 7 章**卡特尔不稳定**、价格战、军备竞赛、公地悲剧的统一解释。

### 10.3 均衡的存在性、唯一性、稳定性与最优性

| 性质 | 结论 |
| --- | --- |
| 存在性 | 纯策略纳什均衡**可能不存在**（如猜硬币）；但纳什定理保证**有限博弈必存在混合策略均衡** |
| 唯一性 | 可能唯一，也可能多重（如性别战有两个纯策略均衡 + 一个混合策略均衡） |
| 稳定性 | 均衡未必稳定；偏离后能否回到均衡取决于动态调整 |
| 最优性 | 纳什均衡**未必帕累托最优**（囚徒困境即反例） |

::: tip 工作例题 · 混合策略纳什均衡（性别战）
支付矩阵：`(芭蕾, 芭蕾) = (2, 1)`，`(拳击, 拳击) = (1, 2)`，不一致时 `(0, 0)`。
设甲以概率 `p` 选"芭蕾"。要使乙**无差异**：
乙选芭蕾的期望 `= 1·p + 0·(1−p) = p`；乙选拳击的期望 `= 0·p + 2(1−p) = 2 − 2p`。
令 `p = 2 − 2p ⇒ p = 2/3`。
同理设乙以概率 `q` 选芭蕾，使甲无差异：`2q = 1·(1−q) ⇒ q = 1/3`。
⇒ 混合策略均衡为「甲 (2/3, 1/3)、乙 (1/3, 2/3)」，各人期望支付 `2/3`。
**要点**：混合策略均衡中，参与人选择自己的概率是为了**让对方无差异**，而不是让自己期望支付最大。
:::

::: danger 易错 · 博弈
- 纳什均衡 ≠ 占优均衡 ≠ 帕累托最优；三者是不同维度。
- 「占优」是逐格比较，「纳什」是"给定对方策略"的单方偏离检验，划线法本质就是后者。
- 零和博弈支付之和恒为常数，`maximin = minimax`（冯·诺依曼）；变和博弈（囚徒困境）不适用。
- 混合策略中概率由**对方的支付**决定，若误用自己的支付求解会得到错误答案（最经典的失分点）。
:::

**补充 · 动态博弈与重复博弈**：
- **子博弈精炼纳什均衡（SPNE）**：用**逆向归纳**从最后一个子博弈往前解，剔除**不可置信威胁**（如"你进入我就打价格战"在事后并不最优）。
- **有限次重复**囚徒困境：由逆向归纳，最后一期无未来惩罚 ⇒ 每期都背叛（连锁店悖论）。
- **无限次重复 / 贴现率足够高**：「以牙还牙」「冷酷战略」可维持合作（民间定理），条件是 `δ ≥ (背叛收益 − 合作收益)/(背叛收益 − 惩罚收益)`。这为第 7 章卡特尔的长期维持提供了条件。
- **不完全信息博弈**：贝叶斯纳什均衡（海萨尼转换，用"自然"先选择类型）；信号博弈与分离/混同均衡连接第 11 章的信号传递。

## 第 11 章 市场失灵和微观经济政策（★★★）

### 11.1 四类市场失灵总览

![四类市场失灵、庇古税与信息不对称](/micro/micro-failure.svg)

| 类型 | 表现 | 效率后果 | 主要矫正工具 |
| --- | --- | --- | --- |
| 不完全竞争 | 垄断、寡头、进入壁垒 | `P > MC`，产量不足、DWL | 反托拉斯法、价格/回报率管制、放松准入 |
| 外部影响 | 私人成本/收益 ≠ 社会成本/收益 | 负外部性过量生产、正外部性生产不足 | 庇古税/津贴、企业合并、科斯产权、可交易许可证 |
| 公共物品 | 非排他 + 非竞争 ⇒ 搭便车 | 私人自愿供给不足甚至为零 | 政府供给、成本—收益分析、偏好显示机制 |
| 不完全信息 | 逆向选择、道德风险 | 市场萎缩、次品驱逐良品、契约失灵 | 信号传递、甄别、强制披露、声誉与制度设计 |

### 11.2 垄断、寻租与管制

- **垄断低效率**：`P > MC` 产生哈伯格三角形 DWL；此外还有 X-非效率（缺乏竞争压力导致管理松懈）与寻租成本。
- **寻租理论**（塔洛克、克鲁格）：为获得并维持垄断地位（牌照、配额、关税保护）而进行的**非生产性**竞争，耗费真实资源。总社会损失可接近甚至超过全部垄断租金，远大于传统 DWL 三角形。
- **管制方式**：递增成本行业的价格上限、递减成本（自然垄断）的边际成本定价（需补贴）/平均成本定价/特许投标；反托拉斯法针对合谋、排他性交易与滥用支配地位。

### 11.3 外部影响与科斯定理

| 概念 | 表达式 |
| --- | --- |
| 私人边际成本 | `MPC` |
| 边际外部成本/收益 | `ME`（负外部性为正成本） |
| 社会边际成本 | `MSC = MPC + ME` |
| 社会最优 | `MSB = MSC`（而非 `MPB = MPC`） |

::: tip 工作例题 · 庇古税完整计算
设 `MSB = MPB = 100 − 2Q`，`MPC = 2Q + 10`，每单位负外部性 `ME = 6`（常数）：
- **私人均衡**：`100 − 2Q = 2Q + 10 ⇒ Q = 22.5`（过量生产）。
- **社会最优**：`100 − 2Q = 2Q + 10 + 6 ⇒ 4Q = 84 ⇒ Q* = 21`。
- **庇古税** `t = ME(Q*) = 6`：厂商面对 `MPC + t`，自行选择 `Q = 21` ⇒ 分散决策实现社会最优。
- 校验：`MSB = 100 − 42 = 58`；`MSC = 2×21 + 10 + 6 = 58` ✓。
- 若 `ME` 随产量变化（如 `ME = 2Q`），则最优税额应取**最优产量处**的边际外部成本，而非常数。
:::

**科斯定理**：只要**产权明确**且**交易成本为零（或足够低）**，无论初始产权判给哪一方，私人谈判都能达到社会最优产量（帕累托有效）；初始产权只影响**收入分配**，不影响资源配置（科斯中性）。

::: danger 易错 · 科斯定理
- 「产权归谁不影响产量」**只在交易成本为零时成立**；现实中交易成本（搜寻、谈判、履约、人数众多导致的搭便车与策略性要价）常常很高 ⇒ 需要庇古税、管制或可交易许可证。
- 科斯定理不是"政府不该管"的同义词，而是强调**制度与交易成本**决定哪种安排更有效。
- 外部性internal化还有「企业合并」（把外部成本内化为同一企业成本）与「可交易排污权」（总量控制 + 市场配置，兼有确定性与成本有效性）两条路径。
- 有效率的污染量通常**不是零**：把 `MSC = MSB` 的产量找出来，而不是全面禁止。
:::

### 11.4 公共物品与公共资源

| 分类 | 排他性 | 竞争性 | 典型 | 问题 |
| --- | --- | --- | --- | --- |
| 私人物品 | 有 | 有 | 面包、衣服 | 市场可有效供给 |
| 公共物品 | 无 | 无 | 国防、灯塔、基础研究 | 搭便车 ⇒ 私人供给不足 |
| 公共资源（共同资源） | 难 | 有 | 公海渔场、公共牧场 | 公地悲剧 ⇒ 过度使用 |
| 俱乐部物品（准公共品） | 有 | 无（未拥挤时） | 收费公路、有线电视 | 拥挤后产生竞争性 |

**公共物品最优条件（萨缪尔森条件）**：`Σᵢ MRSᵢ = MRT`
私人物品是「各人 MRS 相等并等于 MRT」，公共物品因**所有人同时消费同一单位**，应把各人的边际评价**纵向相加**。

::: tip 工作例题 · 是否应增加公共物品
两人对公共物品 G 相对私人物品 X 的边际替代率分别为 `MRS_A = 3`、`MRS_B = 2`，经济的 `MRT = 4`。
`ΣMRS = 5 > MRT = 4` ⇒ 社会愿意放弃 5 单位 X 换取 1 单位 G，而实际只需放弃 4 单位 ⇒ **应增加 G 的供给**，直到 `ΣMRS = MRT`。
:::

**搭便车与偏好显示**：由于非排他，个人有低估自己真实支付意愿的激励 ⇒ 需投票机制、林达尔均衡（个性化税收价格）、克拉克–格罗夫斯机制等偏好显示设计；多数投票可能出现投票悖论（孔多塞），与阿罗不可能定理相连。

### 11.5 信息不完全与信息不对称

| 问题 | 发生时点 | 隐藏的是 | 经典例子 | 矫正 |
| --- | --- | --- | --- | --- |
| 逆向选择 | **签约前** | 信息（类型） | 旧车市场"柠檬"、健康保险 | 信号传递（质保、文凭、品牌）、甄别（合同菜单）、强制披露、第三方认证 |
| 道德风险 | **签约后** | 行动 | 投保后疏于防范、经理偷懒 | 免赔额、共保、绩效工资、监督、声誉 |
| 委托—代理 | 持续 | 行动与努力 | 股东—经理、雇主—雇员 | 激励相容契约、股权激励、相对绩效评价 |

- **柠檬市场**（阿克洛夫）：买者只愿按平均质量出价 ⇒ 高质量卖方退出 ⇒ 平均质量进一步下降 ⇒ 恶性循环，市场可能完全崩溃。
- **信号传递**（斯宾塞）：高质量者以低成本发出难以模仿的信号（教育、质保）；有效分离均衡要求信号成本与类型负相关（**单交叉条件**）。
- **甄别**（罗斯柴尔德–斯蒂格利茨）：信息劣势方提供合同菜单让对方自我选择。

### 11.6 政府失灵与政策边界

政府干预本身也有成本：信息不足（不知道真实的 MSC/MSB）、寻租与俘获、官僚低效、政策时滞、公共选择困境（投票悖论、多数暴政、利益集团集中收益 vs 分散成本）。
⇒ 判断标准不是"市场是否失灵"，而是**比较市场失灵的损失与政府干预的成本**；很多情形更适合用「可交易许可证」「信息披露」「明晰产权」这类**市场友好型**工具替代直接命令—控制。

::: danger 易错 · 市场失灵
- 市场失灵指**资源配置偏离帕累托最优**，不等于"价格太高"或"企业赚钱太多"。
- 外部性、公共物品、信息问题是第一定理**前提失效**，因此竞争均衡不再有效；垄断则是价格接受假设失效。
- 信息不完全（处处存在）与信息**不对称**（一方比另一方知道得多）不同，后者才产生逆向选择与道德风险。
- 「公共物品必须由政府生产」是错的：**提供（融资）**与**生产**可以分离，政府购买/外包私人生产很常见。
:::

## 各章深挖专题（补充）

### 深 1 · 需求函数背后的对偶结构（第 3 章）

马歇尔需求 `x(p, I)` 与希克斯需求 `xʰ(p, U)` 是同一偏好关系的两种表示：

| 问题 | 目标 | 值函数 | 需求 |
| --- | --- | --- | --- |
| 效用最大化 | `max U(x) s.t. p·x ≤ I` | 间接效用 `v(p, I)` | 马歇尔需求 `x(p, I)` |
| 支出最小化 | `min p·x s.t. U(x) ≥ U` | 支出函数 `e(p, U)` | 希克斯需求 `xʰ(p, U)` |

**四个恒等式**：
- `e(p, v(p,I)) = I` 与 `v(p, e(p,U)) = U`（互为反函数）；
- **罗伊恒等式** `xᵢ(p,I) = −(∂v/∂pᵢ)/(∂v/∂I)`：由间接效用函数可反求需求；
- **谢泼德引理** `xᵢʰ(p,U) = ∂e(p,U)/∂pᵢ`：由支出函数可反求补偿需求；
- **斯勒茨基矩阵** `∂xᵢ/∂pⱼ = ∂xᵢʰ/∂pⱼ − xⱼ·∂xᵢ/∂I`：第 3.4 节分解的一般（多商品）形式；该矩阵**对称且半负定**，是需求理论可检验的核心约束。

::: tip 工作例题 · C-D 效用的三个函数
`U = XY`（或 `U = X^α Y^{1−α}`）：
- 马歇尔需求 `X = I/(2Px)`、`Y = I/(2Py)`；
- 间接效用 `v = I²/(4PxPy)`；
- 支出函数 `e(p,U) = 2√(U·PxPy)`；
- 验算罗伊恒等式：`−(∂v/∂Px)/(∂v/∂I) = [I²/(4Px²Py)]/[2I/(4PxPy)] = I/(2Px) = X` ✓。
:::

### 深 2 · 弹性的三个高阶结论（第 2、7 章）

1. **线性需求上的弹性分布**：`P = a − bQ`，`|Ed| = (1/b)(P/Q) = P/(a − P)`。纵截距 `|Ed|→∞`、中点 `P = a/2` 处 `|Ed| = 1`、横截距 `|Ed| = 0`。所以"需求曲线陡 = 缺乏弹性"只在**同一坐标系、同一价格处**成立，跨图比较必须看弹性而非斜率。
2. **总收益与边际收益**：`MR = P(1 − 1/|Ed|)` ⇒ `|Ed| > 1` 时 `MR > 0`（降价增收）、`|Ed| = 1` 时 `MR = 0`（TR 极大）、`|Ed| < 1` 时 `MR < 0`（降价减收）。这条式子把第 2 章与第 7 章接了起来。
3. **税负归宿一般式**：单位税 `t` 下 `dPd/dt = eS/(eS + |Ed|)`、`dPs/dt = −|Ed|/(eS + |Ed|)`（以弹性表示）。**弹性较小（更陡）的一方承担更多**；`eS → ∞` 时全部转嫁给消费者，`|Ed| → 0` 时亦全部由消费者承担。

::: tip 工作例题 · 弹性形式的归宿验算
沿用 2.4 例题：均衡 `P*=12, Q*=26`，`|Ed| = (1/2)·(12/26)·2 = 12/13 ≈ 0.923`（注意 `dQ/dP = −2`），`eS = 3·(12/26) = 18/13 ≈ 1.385`。
`dPd/dt = 1.385/(1.385+0.923) = 0.6` ⇒ `ΔPd = 4×0.6 = 2.4` ✓ 与方程解一致。
（用斜率比 `3 : 2` 更快，但弹性形式可推广到非线性曲线。）
:::

### 深 3 · 补偿变化 CV、等价变化 EV 与消费者剩余（第 3、6 章）

| 度量 | 定义 | 价格下降时 |
| --- | --- | --- |
| 补偿变化 CV | 价格变动后，为**维持原效用**所需的收入补偿 | `CV = e(p₀,U₀) − e(p₁,U₀)` |
| 等价变化 EV | 价格变动**前**，等效于该价格变动的收入变化 | `EV = e(p₀,U₁) − e(p₁,U₁)` |
| 消费者剩余 CS | 需求曲线下的面积（马歇尔需求积分） | 介于 CV 与 EV 之间（拟线性偏好时三者相等） |

- 关系：价格下降时 `CV ≤ ΔCS ≤ EV`（对正常品）；差异来自**收入效应**。收入效应越小（拟线性效用、支出占比小），用 CS 近似福利变化越准确。
- 政策评估含义：税收、补贴、价格管制的福利分析，严格应用 CV/EV；初等教材常用 CS 三角形作近似。

### 深 4 · 生产—成本对偶的严格推导（第 4、5 章）

`L = wL + rK + λ(Q₀ − f(L,K))` ⇒ 一阶条件 `w = λ·MPL`、`r = λ·MPK` ⇒ `MPL/w = MPK/r = 1/λ`。
由包络定理 `dC*/dQ = λ` ⇒ **`λ = MC`**，故 `MPL/w = MPK/r = 1/MC`。
`C(Q) = min{wL + rK : f(L,K) ≥ Q}` 关于 `(w,r)` 是一次齐次、凹函数；由谢泼德引理 `∂C/∂w = L*(Q,w,r)`。

**成本函数的形状由生产函数决定**：规模报酬递增（`α+β>1`）⇒ `LAC` 递减；不变 ⇒ `LAC` 水平；递减 ⇒ `LAC` 递增。短期 U 形 SAC 则来自"至少一种要素固定 + 边际报酬递减"。

::: tip 工作例题 · 由 C-D 生产函数解成本函数
`Q = L^{0.5}K^{0.5}`，`MRTS = K/L = w/r ⇒ K = (w/r)L`；代入 `Q = L√(w/r) ⇒ L = Q√(r/w)`，`K = Q√(w/r)`。
`C = wL + rK = Q√(wr) + Q√(wr) = 2Q√(wr)` ⇒ `LAC = LMC = 2√(wr)`（常数，规模报酬不变）。
验算要素价格齐次性：w、r 同乘 2 ⇒ C 乘 2 ✓。
:::

### 深 5 · 完全竞争福利最大化的数学证明（第 6、9 章）

设社会总剩余 `W(Q) = ∫₀^Q P(x)dx − C(Q)`（`P(x)` 为反需求函数）。
`dW/dQ = P(Q) − MC(Q) = 0 ⇒ P = MC` ⇒ 竞争均衡使 W 最大；`d²W/dQ² = P′(Q) − MC′(Q) < 0`（需求递减、MC 递增）保证极大。
因此 `P = MC` 不是"假设"，而是**福利最大化的一阶条件**；任何造成 `Q ≠ Q*` 的干预都产生 `DWL = ∫_{Q*}^{Q}[P(x) − MC(x)]dx`，线性近似即 `½·|ΔQ|·|ΔP|`。

### 深 6 · 多工厂垄断与加成定价（第 7 章）

- **多工厂垄断**：把总产量分配到各工厂使 `MC₁(Q₁) = MC₂(Q₂) = … = MR(Q总)`（不是各厂 MC 相等就完事，还要共同等于总 MR）。
- **加成定价法则** `P = MC·|Ed|/(|Ed| − 1)`：由 `L = 1/|Ed|` 整理即得；`|Ed|→∞` 时 `P→MC`（竞争），`|Ed|→1⁺` 时加成趋于无穷（受需求约束不可实现）。
- **两部定价**（补充）：入场费 = 全部消费者剩余，使用费 = MC ⇒ 可在无 DWL 的同时榨取全部剩余；是二级价格歧视的极限形式，常见于游乐园、软件订阅、水电基本费。

### 深 7 · 古诺 n 家推广与合谋维持条件（第 7、10 章）

`P = a − bQ`，n 家同质、`MC = c`：
对称均衡 `Qi = (a−c)/[(n+1)b]`，`Q = n(a−c)/[(n+1)b]`，`P = (a + n·c)/(n+1)`，`πᵢ = (a−c)²/[(n+1)²b]`。
- `n = 1` ⇒ 垄断；`n → ∞` ⇒ `P → c`（竞争），说明**厂商数量本身即可逼近竞争结果**（无需假设完全信息的价格接受行为）。
- **勒纳指数** `(P−c)/P = 1/(n·|Ed|市场)`（古诺情形）：市场集中度越高，加成越大（HHi 指数的理论基础）。

**重复博弈中合谋可持续条件**：设合作单期收益 `πC`、背叛单期收益 `πD`、惩罚期收益 `πN`，贴现因子 `δ`。
冷酷战略下合谋可持续 ⇔ `πC/(1−δ) ≥ πD + δ·πN/(1−δ)` ⇔ `δ ≥ (πD − πC)/(πD − πN)`。
⇒ 贴现率越低（越有耐心）、背叛收益越小、惩罚越严厉、市场越透明，卡特尔越稳定。这解释了为什么**频繁小幅、公开报价、需求稳定**的行业更易合谋。

### 深 8 · 边际生产力分配与欧拉定理（第 8 章）

规模报酬不变（1 次齐次）时，欧拉定理 `Q = MPL·L + MPK·K`。完全竞争下 `w = P·MPL`、`r = P·MPK` ⇒ `P·Q = wL + rK` ⇒ 总收入恰好分尽，`π = 0`。
- 若 `α+β > 1`（递增），`MPL·L + MPK·K > Q` ⇒ 按边际产量支付会**超支**（不可能长期维持），需有超额利润以外的解释（如固定要素、外部经济）。
- 若 `α+β < 1`，则有剩余可归固定要素或企业家才能。
- **功能分配 vs 规模分配**：前者是工资/利润/地租在国民收入中的份额（本章），后者是个人/家庭间的收入分布（洛伦兹、基尼）。二者不可混用。

### 深 9 · 一般均衡存在性与两定理的证明思路（第 9 章）

- **存在性**：把价格向量归一化到单纯形（Σpᵢ = 1），定义超额需求映射 `z(p)`；由瓦尔拉斯法则 `p·z(p) = 0`、连续性、边界条件，用**布劳威尔/角谷不动点定理**证明存在 `p*` 使 `z(p*) ≤ 0`（阿罗–德布鲁）。
- **第一定理**（反证）：若均衡分配非帕累托有效，则存在另一可行分配使所有人更好且至少一人严格更好 ⇒ 该分配对至少一人超预算 ⇒ 与其在预算约束下已最优矛盾。
- **第二定理**（分离超平面）：帕累托有效分配对应的总需求束与总生产束可用一个超平面分离，该超平面的法向量即**支持价格**；把初始禀赋按该价格作一次总付再分配后，竞争均衡恰好实现该分配。
- **局限**：非凸性（自然垄断、公共物品）、外部性、递增规模报酬、信息不对称都会使上述证明失效。

### 深 10 · 混合策略到机制设计（第 10、11 章）

- **混合策略的存在性**：纳什定理（1950）—— 每个有限策略式博弈至少存在一个（纯或混合）纳什均衡；证明同样用不动点定理。
- **贝叶斯纳什均衡**：不完全信息下，参与人类型 `θᵢ` 由"自然"按先验分布抽取，策略是「类型 → 行动」的映射，均衡是给定他人策略与信念时期望支付最优。
- **机制设计**（反向博弈论）：给定想要的社会结果，设计博弈规则使自利参与人在均衡中自觉实现它。核心约束为**激励相容 IC**（说真话/按规则行动是最优）与**参与约束 IR**（参与不比退出差）。应用：拍卖设计（VCG）、公共物品偏好显示（克拉克税）、最优税制、频谱拍卖。
- **显示偏好与显示原理**：任何贝叶斯均衡结果都可由一个「代理人如实报告类型」的直接机制实现 ⇒ 只需在直接机制中寻找最优，大幅简化问题。

### 深 11 · 外部性三类政策工具的比较（第 11 章）

| 工具 | 信息要求 | 价格 vs 数量 | 适用 |
| --- | --- | --- | --- |
| 庇古税 | 需知最优产量处的 ME | 定**价格**，产量不确定 | 边际损害曲线较平坦、需稳定预期 |
| 可交易许可证（总量控制） | 需知最优总排放量 | 定**数量**，价格由市场决定 | 环境容量有硬阈值、边际损害陡峭 |
| 命令—控制（统一技术标准） | 最低 | 直接规定技术/排放 | 信息极缺、监测困难，但成本有效性最差 |

**魏茨曼价格 vs 数量规则**（补充）：不确定性下，若边际损害曲线比边际减排成本曲线陡，数量工具（许可证）更优；反之价格工具（税）更优。碳税与碳交易之争即由此展开。
**庇古税与双重红利**：税收收入可用于削减扭曲性所得税，从而获得"改善环境 + 降低税制超额负担"的第二重收益（但第二红利是否在一般均衡中成立有争议）。

### 深 12 · 对理性人假定的检验与行为经济学（第 1 章）

课件以理性人（完备性、传递性、自利）为起点。补充现代修正：
- **前景理论**：价值函数以**参照点**定义、损失厌恶（损失的痛约为等量收益的 2 倍）、概率权重非线性（高估小概率）⇒ 解释保险与彩票同时被购买、禀赋效应、现状偏好。
- **有限理性**（西蒙）：满意化而非最优化、启发式与偏差（锚定、可得性、代表性）、框架效应。
- **时间不一致**：双曲贴现导致拖延与承诺需求（对应重复博弈中的自我控制）。
- **社会偏好**：最后通牒博弈、公共品博弈实验显示公平互惠动机系统性存在。
- **对政策的含义**：默认选项（助推）、信息呈现方式、损失框架会显著改变行为，故"激励"设计必须基于**真实**行为模型而非理想化理性人。

## 典型计算题逐步演算（可照抄的解题格式）

> 本章把高频计算题按「已知 → 方程 → 求解 → 验算」四步完整展开，代码块内是可直接复用的演算格式。

### 演 1 · 供求均衡与价格管制（第 2 章）

```text
已知：Qd = 50 − 2P，Qs = −10 + 3P
① 均衡：50 − 2P = −10 + 3P
         60 = 5P  →  P* = 12
         Q* = 50 − 2×12 = 26
   验算：Qs = −10 + 3×12 = 26 = Qd ✓
② 支持价 P = 15：Qd = 20，Qs = 35 → 过剩 15
③ 限制价 P = 8 ：Qd = 34，Qs = 14 → 短缺 20
④ 若需求右移为 Qd = 60 − 2P：
         60 − 2P = −10 + 3P → P* = 14，Q* = 32（P、Q 同升）
```

### 演 2 · 弧弹性、点弹性与总收益（第 2 章）

```text
已知：P₁ = 5, Q₁ = 20；P₂ = 4, Q₂ = 30
① 中点公式：Ed = −(ΔQ/ΔP) × [(P₁+P₂)/2] / [(Q₁+Q₂)/2]
   ΔQ = +10, ΔP = −1 → −(10/−1) = 10
   Pm = 4.5, Qm = 25
   Ed = 10 × 4.5/25 = 1.8   （富有弹性）
② TR₁ = 5×20 = 100，TR₂ = 4×30 = 120 → 降价增收 ✓
③ 点弹性（Q = 50 − 2P，dQ/dP = −2）：
   P = 10 → Q = 30 → Ed = 2×10/30 = 0.667
   P = 12.5 → Q = 25 → Ed = 1（TR 极大 = 312.5）
   P = 20 → Q = 10 → Ed = 4
   结论：线性需求上半段富有弹性、下半段缺乏弹性
```

### 演 3 · 效用最大化（序数 + 基数两条路）（第 3 章）

```text
已知：U = XY，I = 100，Px = 2，Py = 5
【序数法】MRSxy = MUx/MUy = Y/X
   Y/X = Px/Py = 2/5 = 0.4  →  Y = 0.4X
   代入预算：2X + 5(0.4X) = 4X = 100  →  X* = 25
   Y* = 0.4×25 = 10，U* = 250
   验算支出：2×25 + 5×10 = 100 ✓
【基数法】MUx/Px = MUy/Py → Y/2 = X/5 → 5Y = 2X → Y = 0.4X（同上）
   此时 λ = MUx/Px = 10/2 = 5
【通式】U = X^α Y^β → X* = [α/(α+β)]·I/Px = 0.5×100/2 = 25 ✓
```

### 演 4 · 希克斯 / 斯勒茨基分解（第 3 章）

```text
已知：U = XY，I = 100，Py = 5，Px：2 → 1
① 起点 A：X₀ = 100/(2×2) = 25，Y₀ = 100/(2×5) = 10，U₀ = 250
② 终点 C：X₁ = 100/(2×1) = 50，Y₁ = 10 → 总效应 ΔX = +25
③ 希克斯补偿（保持 U₀ = 250，新价格比 Px/Py = 1/5）：
   Y/X = 1/5 → Y = X/5；XY = X²/5 = 250
   Xh = √1250 = 35.355
   替代效应 = 35.355 − 25 = +10.355
   收入效应 = 50 − 35.355 = +14.645
   校验：10.355 + 14.645 = 25 ✓
④ 斯勒茨基补偿（买得起原组合）：
   I′ = 1×25 + 5×10 = 75
   Xs = 75/(2×1) = 37.5
   替代效应 = +12.5，收入效应 = 50 − 37.5 = +12.5
⑤ 分解方向：正常品 ⇒ 两效应同号，需求曲线向下倾斜
```

### 演 5 · 短期成本七条曲线（第 5 章）

```text
已知：STC = Q³ − 6Q² + 15Q + 100（TFC = 100）
① TVC = Q³ − 6Q² + 15Q
② AFC = 100/Q；AVC = Q² − 6Q + 15；AC = AVC + 100/Q
③ SMC = dSTC/dQ = 3Q² − 12Q + 15
④ AVC 最小：dAVC/dQ = 2Q − 6 = 0 → Q = 3
   AVCmin = 9 − 18 + 15 = 6；SMC(3) = 27 − 36 + 15 = 6 ✓（相等）
⑤ AC 最小：AC = Q² − 6Q + 15 + 100/Q
   试 Q = 5：AC = 25 − 30 + 15 + 20 = 30；SMC(5) = 75 − 60 + 15 = 30 ✓
⑥ 数值表（Q=1..6）：
   AFC  100.00 50.00 33.33 25.00 20.00 16.67
   AVC   10.00  7.00  6.00  7.00 10.00 15.00
   AC   110.00 57.00 39.33 32.00 30.00 31.67
   SMC    6.00  3.00  6.00 15.00 30.00 51.00
⑦ 结论：SMC 先穿 AVCmin(Q=3)，再穿 ACmin(Q=5)，ACmin 在右上方
```

### 演 6 · 完全竞争短期均衡与停业决策（第 6 章）

```text
已知：STC = Q² + 4Q + 36，P = 20（水平需求线）
① SMC = 2Q + 4 = MR = P = 20 → Q* = 8
② TR = 20×8 = 160；STC = 64 + 32 + 36 = 132 → π = 28
③ AC = Q + 4 + 36/Q → dAC/dQ = 1 − 36/Q² = 0 → Q = 6，ACmin = 16
④ AVC = Q + 4（递增），关门价格取 AVC 下界 4
⑤ 若 P = 14：Q = 5，TR = 70，STC = 25+20+36 = 81 → 亏 11
   停产亏 TFC = 36；继续生产亏 11 < 36 ⇒ 继续生产
   验证：P = 14 > AVC = 9 ⇒ 能覆盖全部可变成本 ✓
⑥ 若 P = 3 < 4 ⇒ 停产，亏损限于 36
```

### 演 7 · 垄断均衡、勒纳指数与 DWL（第 7 章）

```text
已知：P = 100 − 2Q，MC = 20（TFC = 0）
① TR = 100Q − 2Q² → MR = 100 − 4Q
② MR = MC：100 − 4Q = 20 → Qm = 20，Pm = 100 − 40 = 60
③ π = (60 − 20)×20 = 800
④ |Ed| = (1/b)(P/Q) = (1/2)(60/20) = 1.5
   L = (P−MC)/P = 40/60 = 2/3 = 1/1.5 ✓
⑤ 竞争基准：P = MC = 20 → Qc = (100−20)/2 = 40
⑥ CS = ½×(100−60)×20 = 400
   DWL = ½×(60−20)×(40−20) = 400
⑦ 通式校验：Qm = (a−c)/(2b) = 80/4 = 20 ✓；Pm = (a+c)/2 = 60 ✓
```

### 演 8 · 古诺与斯塔克尔伯格（第 7 章）

```text
已知：P = 18 − (Q₁+Q₂)，MC₁ = MC₂ = 0
【古诺】
① π₁ = [18 − Q₁ − Q₂]Q₁
   ∂π₁/∂Q₁ = 18 − 2Q₁ − Q₂ = 0 → R₁：Q₁ = 9 − Q₂/2
② 对称 R₂：Q₂ = 9 − Q₁/2
③ 联立：Q₁ = 9 − (9 − Q₁/2)/2 = 4.5 + Q₁/4
         (3/4)Q₁ = 4.5 → Q₁ = Q₂ = 6
④ Q = 12，P = 6，π₁ = π₂ = 6×6 = 36
⑤ 通式 Qi = (a−c)/[(n+1)b] = 18/(3×1) = 6 ✓
【斯塔克尔伯格（1 领导）】
⑥ 把 R₂ 代入：π₁ = [18 − Q₁ − (9 − Q₁/2)]Q₁ = (9 − Q₁/2)Q₁
   dπ₁/dQ₁ = 9 − Q₁ = 0 → Q₁ = 9，Q₂ = 4.5，Q = 13.5，P = 4.5
   π₁ = 40.5，π₂ = 20.25（先动优势）
【卡特尔】Q = 9，P = 9，总π = 81（各 40.5，但有背叛动机）
```

### 演 9 · 三级价格歧视（第 7 章）

```text
已知：P₁ = 100 − 2Q₁，P₂ = 80 − Q₂，MC = 20
① MR₁ = 100 − 4Q₁ = 20 → Q₁ = 20，P₁ = 60
② MR₂ = 80 − 2Q₂ = 20 → Q₂ = 30，P₂ = 50
③ |E₁| = (a+c)/(a−c) = 120/80 = 1.5
   |E₂| = 100/60 = 1.667
   P₁(1−1/E₁) = 60×(1/3) = 20 = MC ✓
   P₂(1−1/E₂) = 50×0.4 = 20 = MC ✓
   |E₁| < |E₂| ⇒ P₁ > P₂（弹性小者价高）✓
④ π = (60−20)×20 + (50−20)×30 = 800 + 900 = 1700
⑤ 统一价：Q = (100−P)/2 + (80−P) = 130 − 1.5P
   π = (P−20)(130−1.5P)；dπ/dP = 160 − 3P = 0 → P = 53.33
   π ≈ 1666.67 < 1700 ⇒ 歧视提高利润 ✓
```

### 演 10 · 庇古税与社会最优（第 11 章）

```text
已知：MSB = MPB = 100 − 2Q，MPC = 2Q + 10，ME = 6
① 私人均衡：100 − 2Q = 2Q + 10 → 4Q = 90 → Q = 22.5
② 社会最优：100 − 2Q = 2Q + 10 + 6 → 4Q = 84 → Q* = 21
③ 庇古税 t = ME(Q*) = 6
   厂商面对 MPC + 6：100 − 2Q = 2Q + 16 → Q = 21 ✓
④ 校验社会最优：MSB = 100 − 42 = 58；MSC = 42 + 10 + 6 = 58 ✓
⑤ DWL（私人过量生产）= ½ × ME × (22.5 − 21) = ½×6×1.5 = 4.5
⑥ 税收收入 = t × Q* = 6×21 = 126
```

### 演 11 · 基尼系数（第 8 章）

```text
已知：5 等分组收入份额 5, 10, 15, 25, 45（单位 %）
① 累计收入：0.05, 0.15, 0.30, 0.55, 1.00
② 洛伦兹曲线下面积（梯形，组宽 0.2）：
   B = 0.2 × [ (0+0.05)/2 + (0.05+0.15)/2 + (0.15+0.30)/2
              + (0.30+0.55)/2 + (0.55+1.00)/2 ]
     = 0.2 × [0.025 + 0.100 + 0.225 + 0.425 + 0.775]
     = 0.2 × 1.55 = 0.31
③ A = 0.5 − 0.31 = 0.19
④ G = A/(A+B) = 0.19/0.5 = 0.38
⑤ 等价算法：G = 1 − 2B = 1 − 0.62 = 0.38 ✓
```

### 演 12 · 混合策略纳什均衡（第 10 章）

```text
已知性别战：(芭蕾,芭蕾)=(2,1)，(拳击,拳击)=(1,2)，不一致=(0,0)
① 设甲以 p 选芭蕾，乙以 q 选芭蕾
② 令乙无差异（用【乙】的支付！）：
   乙选芭蕾 = 1×p + 0×(1−p) = p
   乙选拳击 = 0×p + 2×(1−p) = 2 − 2p
   p = 2 − 2p → 3p = 2 → p = 2/3
③ 令甲无差异（用【甲】的支付）：
   甲选芭蕾 = 2×q + 0×(1−q) = 2q
   甲选拳击 = 0×q + 1×(1−q) = 1 − q
   2q = 1 − q → q = 1/3
④ 均衡：甲(2/3, 1/3)，乙(1/3, 2/3)
   甲期望支付 = 2×(2/3)(1/3) = 4/9（错配概率 4/9）
   易错警示：第②步必须用乙的支付 1 和 2，不能用甲的 2 和 1
```

## 综合例题精讲（跨章）

### 综 1 · 从供求到弹性到税收归宿（第 2 章全链条）

`Qd = 50 − 2P`，`Qs = −10 + 3P`。
① 求均衡：`P* = 12, Q* = 26`。
② 在均衡点求点弹性：`|Ed| = 2×(12/26) = 12/13 ≈ 0.923`，`eS = 3×(12/26) = 18/13 ≈ 1.385`。
③ 征收单位税 `t = 4`：`Pd = 14.4, Ps = 10.4, Q = 21.2`；消费者负担 `2.4`、生产者负担 `1.6`。
④ 税收收入 `= 4 × 21.2 = 84.8`；`DWL = ½ × t × (26 − 21.2) = ½ × 4 × 4.8 = 9.6`；`CS + PS` 减少 `84.8 + 9.6 = 94.4`。
⑤ 若改为对买方征税，`Pd、Ps、Q` 不变（仅名义报价口径改变）⇒ 归宿无关性。
⑥ 若需求变为 `Qd = 60 − 2P`（需求右移），重复 ①–④ 可验证：**弹性越小的一方始终承担更多**。

### 综 2 · 消费者均衡 → 价格变化 → 分解（第 3 章全链条）

`U = XY`，`I = 100`，`Py = 5`。
① 初始 `Px = 2`：`X₀ = 25, Y₀ = 10, U₀ = 250`。
② `Px` 降到 1：`X₁ = 50, Y₁ = 10` ⇒ 总效应 `+25`。
③ 希克斯分解：`Xh = √1250 ≈ 35.36` ⇒ 替代效应 `+10.36`、收入效应 `+14.64`。
④ 斯勒茨基分解：补偿收入 `I′ = 75`，`Xs = 37.5` ⇒ 替代效应 `+12.5`、收入效应 `+12.5`。
⑤ 由 PCC 描出需求曲线：`X = I/(2Px) = 50/Px`（双曲线），其**点弹性恒为 1**（C-D 效用的性质）。
⑥ 计算 CV：新价格下达到 U₀ 的支出 `e(p₁,U₀) = 2√(250×1×5) = 2√1250 ≈ 70.71`；原支出 100 ⇒ `CV = 100 − 70.71 = 29.29`（价格下降最多可拿走 29.29 而维持原效用）。

### 综 3 · 生产 → 成本 → 完全竞争均衡（第 4–6 章）

`Q = 10L − L²`，`w = 2`，`TFC = 36`，产品市场完全竞争 `P = 5`，`K` 固定。
① 由生产函数反解（取 MP > 0 段）：`L = 5 − √(25 − Q)`。
② `TVC = wL = 10 − 2√(25−Q)`；`STC = 46 − 2√(25−Q)`（Q ≤ 25）。
③ `SMC = dSTC/dQ = 1/√(25−Q)`（递增，验证边际报酬递减 ⇒ MC 递增）。
④ 均衡 `SMC = P = 5` ⇒ `√(25−Q) = 0.2` ⇒ `Q* ≈ 24.96`，`L* ≈ 4.8`。
⑤ 与第 8 章要素原则互相验证：`VMP = P·MP = 5(10−2L) = w = 2 ⇒ L = 4.8` ✓。
⑥ **结论**：`MR = MC`（产量视角）与 `VMP = w`（要素视角）是同一个利润最大化问题的两种写法，答案必须一致 —— 这是检验计算是否正确的最快方法。

### 综 4 · 成本函数 → 短期均衡 → 停业决策（第 5–6 章）

`STC = Q³ − 6Q² + 15Q + 100`。
① `SMC = 3Q² − 12Q + 15`，`AVC = Q² − 6Q + 15`，`AC = AVC + 100/Q`。
② `AVCmin = 6`（Q=3）⇒ **关门价格 6**；`ACmin = 30`（Q=5）⇒ **收支相抵价格 30**。
③ `P = 20`（介于二者之间）：`3Q²−12Q+15 = 20 ⇒ 3Q²−12Q−5 = 0 ⇒ Q = (12+√204)/6 ≈ 4.38`；
   `TR = 87.6`，`STC ≈ 4.38³ − 6×4.38² + 15×4.38 + 100 ≈ 134.7` ⇒ 亏损约 47.1；停产亏 TFC = 100 ⇒ **继续生产**。
④ `P = 5 < 6` ⇒ 停产，亏损限于 100。
⑤ 长期若可调整规模使 `LACmin < P`，则厂商继续经营；否则退出行业。

### 综 5 · 垄断 → 价格歧视 → 福利（第 6、7 章）

`P = 100 − 2Q`，`MC = 20`。
① 垄断：`Q = 20, P = 60, π = 800, CS = 400, DWL = 400`。
② 竞争：`Q = 40, P = 20, CS = ½×80×40 = 1600, DWL = 0`。
③ 完全价格歧视：`Q = 40`，`CS = 0`，`π = 1600`，`DWL = 0`（有效率但分配极端）。
④ 三级歧视（分割为 `P₁=100−2Q₁`、`P₂=80−Q₂`）：`π = 1700` > 统一定价的 1666.67。
⑤ **政策含义**：反垄断关注的不只是价格高低，而是产量损失（DWL）与寻租；但完全价格歧视说明"厂商拿走全部剩余"与"有效率"可以并存 ⇒ 效率与分配必须分开评判（第 9 章）。

### 综 6 · 古诺 → 卡特尔 → 重复博弈（第 7、10 章）

`P = 18 − Q`，`MC = 0`，两家。
① 古诺：`Q₁ = Q₂ = 6`，`P = 6`，`π₁ = π₂ = 36`。
② 卡特尔：`Q = 9`，`P = 9`，总利润 81，各 40.5。
③ 单方背叛：对方产 4.5 时，己方最优 `Q = (18−4.5)/2 = 6.75`，`P = 6.75`，`π = 45.56 > 40.5` ⇒ 有欺骗动机 ⇒ 一次性博弈中卡特尔不可维持。
④ 无限次重复、冷酷战略：`δ ≥ (πD − πC)/(πD − πN) = (45.56 − 40.5)/(45.56 − 36) ≈ 0.53` ⇒ 当贴现因子足够大（足够看重未来）时合谋可维持。
⑤ 现实对应：行业协会公开报价、最惠国条款、频繁交易与信息透明都在提高 `δ` 或降低 `πD`，正是反垄断执法关注的行为。

### 综 7 · 要素市场 → 分配 → 基尼（第 8 章）

设 5 等分组劳动收入份额 `5%、10%、15%、25%、45%`。
① 洛伦兹点 `(0.2,0.05) … (1,1)`；梯形面积 `B = 0.31` ⇒ `G = 0.38`。
② 若政府按比例所得税（各组同税率）并**等比例**转移支付 ⇒ 洛伦兹曲线不变、`G` 不变（比例税不改变相对份额）。
③ 若改为累进税 + 定向转移，低组份额上升 ⇒ 曲线上移、`G` 下降。
④ 用第 8 章分配论解释：工资差异来自 `VMP = P·MP` 与人力资本、补偿性差别、工会与市场势力；用第 11 章解释：信息不对称（教育信号）与歧视会造成同工不同酬。

### 综 8 · 外部性 → 庇古税 → 科斯（第 11 章）

`MSB = 100 − 2Q`，`MPC = 2Q + 10`，`ME = 6`。
① 私人 `Q = 22.5`，社会最优 `Q* = 21`，`DWL = ½×6×(22.5−21) = 4.5`（外部成本造成的过量生产损失）。
② 庇古税 `t = 6` ⇒ 厂商自选 `Q = 21`；税收收入 `6×21 = 126`，其中 `4.5` 对应消除的净损失，其余为转移。
③ 科斯方案：若产权归居民且交易成本为零，厂商最多愿付 `ME×Q` 与居民谈判，最终产量同样是 21；若产权归厂商，居民付费减产亦达 21（**产量与初始产权无关，分配不同**）。
④ 若受影响居民达 10 万人（交易成本高、搭便车）⇒ 科斯谈判失败，需庇古税或可交易许可证。

### 综 9 · 公共物品 → 投票 → 政府失灵（第 9、11 章）

三人 A/B/C 对某公共项目评价 `MRS = (3, 2, 1)`，`MRT = 4`，项目成本按人头均摊每人 `4/3 ≈ 1.33`。
① 萨缪尔森条件：`ΣMRS = 6 > 4` ⇒ **应建**。
② 若按多数投票且各自只比较私人收益与分摊：A(3>1.33)、B(2>1.33) 赞成，C(1<1.33) 反对 ⇒ 2:1 通过（本例恰好一致）。
③ 若成本均摊改为每人 2.5：A 赞成、B/C 反对 ⇒ **多数投票否决了有效率的项目**（收益集中、成本分散偏误）。
④ 对称地，成本集中而收益分散的项目易被过度否决；收益集中而成本分散（如补贴）易被过度通过 ⇒ 公共选择中的系统性偏差，是政府失灵的重要来源。

### 综 10 · 答题模板：政策评价四步法

面对任何"评价某项政策"的简答/论述题，按四步组织：
① **定基准**：写出无干预时的竞争均衡（`Qd = Qs` 或 `P = MC`），算出 `P*、Q*` 与 `CS、PS`；
② **画冲击**：判断政策使哪条曲线平移或制造楔子（税/补贴/限价/配额/外部性），求新 `P、Q`；
③ **算福利**：逐项列出 `ΔCS、ΔPS、政府收入/支出、Δ外部成本`，求总剩余变化与 DWL；
④ **论分配与前提**：说明谁受益谁受损、政策依赖的信息与交易成本假设、可能的替代工具（科斯产权、可交易许可证、信息披露）。
用这一模板可覆盖第 2、6、7、11 章绝大多数综合题。

### 接 1 · 微观与计量经济学 / 宏观经济学的接口

| 接口 | 微观提供的 | 后续课程如何使用 |
| --- | --- | --- |
| 需求函数 | `Q = f(P, I, …)`、弹性、C-D 需求 | 计量经济学把需求函数写成待估计方程 `ln Q = α + β ln P + γ ln I + u`，`β` 即价格弹性、`γ` 即收入弹性；用工具变量解决价格内生性（供求同时决定） |
| 生产函数 / 成本函数 | `Q = AL^αK^β`、C(Q)、对偶性 | 用企业数据估计 α、β 检验规模报酬；超越对数成本函数（Translog）估计替代弹性 |
| 消费者理论 | 斯勒茨基方程、显示偏好 | 用需求系统（AIDS、QUAIDS）估计并检验对称性与齐次性约束 |
| 市场结构 | 勒纳指数、古诺加成 | 产业组织实证（NEIO 方法）由价格—成本边际推断市场势力；反垄断相关市场界定用 SSNIP 测试（依赖需求弹性） |
| 福利 | CS/PS/CV/EV/DWL | 成本—收益分析、政策评估；宏观经济学的代表性个体模型把微观最优条件加总 |
| 博弈论 | 纳什均衡、机制设计 | 拍卖设计、契约理论、信息经济学；宏观的货币政策时间不一致性（基德兰德—普雷斯科特）本质是与公众的重复博弈 |
| 不确定性 | 期望效用、风险溢价 | 资产定价、保险经济学；CAPM 的风险—收益权衡建立在风险厌恶之上 |

::: danger 易错 · 别把微观结论直接搬到其他课程
- 微观中的"均衡"通常是**局部均衡、静态**；宏观的 IS-LM、AD-AS 涉及总量与价格水平，微观需求曲线（单个商品，相对价格）与宏观总需求曲线（所有商品，物价水平）**不是同一条曲线**，不能简单加总。
- 计量估计出的"需求曲线"可能混杂了供给移动（联立内生性），直接用 OLS 回归价格与数量会得到有偏甚至符号错误的弹性 —— 这正是需要工具变量的原因。
:::

### 接 2 · 微观经济学的实证方法（补充）

课件以理论推演为主，现代经济学同样重视**因果识别**。五个常用框架与微观理论的对应：

| 方法 | 核心思想 | 微观对应 |
| --- | --- | --- |
| 随机对照实验 RCT | 随机分配处理，消除选择偏差 | 直接检验激励反应、公共品博弈、助推效果 |
| 双重差分 DID | 处理组与对照组的前后差异之差 | 评估最低工资、税收、管制政策的价格/就业效应 |
| 断点回归 RD | 利用阈值附近的准随机分配 | 价格管制边界、补贴资格线附近的弹性估计 |
| 工具变量 IV | 用只通过内生变量影响结果的外生变动 | 供求联立下的需求/供给弹性识别 |
| 结构估计 | 直接估计偏好/技术参数，再反事实模拟 | 由 C-D 效用反推需求；模拟合并、税收、价格歧视的福利效应 |

**因果推断对理论的挑战**：理论给出"价格上升需求下降"（其他条件不变），实证中必须设法构造这个"其他条件不变"，即解决**内生性**（遗漏变量、反向因果、测量误差）。这也是站内「计量经济学笔记」与「Python 数据挖掘笔记」的用武之地。

### 接 4 · 三条贯穿全书的主线（收束）

1. **同一条一阶条件的不同外衣**：`MUx/Px = MUy/Py`（消费者）、`MPL/w = MPK/r`（生产者）、`MR = MC`（厂商）、`VMP = w`（要素）、`MRS = MRT`（社会）—— 本质都是「把一单位资源从 A 挪到 B 已无净收益」。
2. **同一套比较静态方法**：外生冲击 → 识别哪条曲线/约束移动 → 求新均衡 → 比较新旧 → 再做福利分解。第 2、6、7、8、11 章全部复用。
3. **同一对张力：效率 vs 分配**：完全竞争有效率（第 6、9 章）但分配可能不平等（第 8 章），市场势力与外部性损害效率（第 7、11 章），政策同时改变二者。答题时永远先问"效率如何"，再问"谁得谁失"。

## 附录 A 公式与结论速查

### A.1 供求、弹性与政策（第 1–2 章）

| 项目 | 公式 / 结论 |
| --- | --- |
| 均衡 | `Qd(P*) = Qs(P*)` |
| 机会成本 | 放弃的其他用途中的**最大**收益；`PPF` 斜率 = `MRT = |ΔY/ΔX|` |
| 需求点弹性 | `Ed = −(dQ/dP)(P/Q)`（常取绝对值） |
| 需求弧弹性（中点） | `Ed = −(ΔQ/ΔP)·[(P₁+P₂)/2]/[(Q₁+Q₂)/2]` |
| 收入 / 交叉 / 供给弹性 | `eI = (ΔQ/Q)/(ΔI/I)`；`eXY = (ΔQx/Qx)/(ΔPy/Py)`；`eS = (ΔQ/Q)/(ΔP/P)` |
| 弹性与总收益 | `dTR/dP = Q(1 − |Ed|)`；`|Ed| > 1` 降价增收 |
| 线性需求弹性 | `P = a − bQ ⇒ |Ed| = (1/b)(P/Q) = P/(a−P)` |
| 税负归宿 | `dPd/dt = eS/(eS + |Ed|)`；弹性小者承担多；与向谁征收无关 |
| 税收 DWL | `½·t·ΔQ`（线性近似） |

### A.2 消费者理论（第 3 章）

| 项目 | 公式 |
| --- | --- |
| 基数效用均衡 | `MUx/Px = MUy/Py = … = λ`，`ΣPiXi = I` |
| 序数效用均衡 | `MRSxy = MUx/MUy = Px/Py`，且 `Pxx + Pyy = I` |
| 预算线 | `y = I/Py − (Px/Py)x` |
| C-D 需求 | `U = X^αY^β ⇒ X* = [α/(α+β)]I/Px`，`Y* = [β/(α+β)]I/Py` |
| 斯勒茨基方程 | `∂X/∂Px = ∂Xʰ/∂Px − X·(∂X/∂I)`（总 = 替代 + 收入） |
| 希克斯补偿 | 保持 `U₀`；斯勒茨基补偿 `ΔI = (P₁−P₀)X₀` |
| 罗伊恒等式 | `xᵢ = −(∂v/∂pᵢ)/(∂v/∂I)`；谢泼德引理 `xᵢʰ = ∂e/∂pᵢ` |

### A.3 生产与成本（第 4–5 章）

| 项目 | 公式 |
| --- | --- |
| 产量三量 | `AP = TP/L`，`MP = dTP/dL`；`MP = AP` 处 AP 最大；`MP = 0` 处 TP 最大 |
| 最优要素组合 | `MRTS(LK) = MPL/MPK = w/r` ⇔ `MPL/w = MPK/r = 1/MC` |
| C-D 生产 | `Q = AL^αK^β`；`α+β > 1 / = 1 / < 1` ⇒ 递增 / 不变 / 递减规模报酬 |

| 成本 | `STC = TFC + TVC`；`AC = AFC + AVC`；`SMC = dSTC/dQ` |

### A.4 市场结构与定价（第 6–7 章）

| 项目 | 公式 |
| --- | --- |
| 利润最大化 | `MR = MC`，且 MC 处于上升段 |

| 短期供给曲线 | `SMC` 在 `AVCmin` 以上的上升段 |

| MR 与弹性 | `MR = P(1 − 1/|Ed|)` ⇒ 勒纳指数 `L = (P−MC)/P = 1/|Ed|` |
| 加成法则 | `P = MC·|Ed|/(|Ed|−1)` |

| 项目 | 公式 |

| 见到 | 立即想到 |
| --- | --- |
| "求均衡价格/数量" | `Qd = Qs` 解方程，再代回验算 |
| "弹性" | 先判断是点还是弧；线性需求用 `|Ed| = (1/b)(P/Q)` |

| "寡头均衡" | 先写反应函数（对对手变量求导），再联立 |
| "要素需求" | `P·MP = w`；可与 `MR = MC` 互相验算 |
| "帕累托最优" | 三条件；竞争下 `Px/Py = MRS = MRT` |
| "博弈求解" | 划线法找纯策略；无纯策略时令对方无差异求混合概率 |
| "外部性政策" | `MSB = MPC + ME`；`t = ME(Q*)`；再讨论科斯前提 |
| "公共物品该不该建" | `ΣMRS` 与 `MRT` 比较 |

## 附录 B 易错点速查

1. 机会成本是放弃的**最大**收益，不是所有放弃收益之和；沉没成本不计入。
2. 稀缺 ≠ 贫穷；PPF 上的点都有效率，"哪一点最优"需需求信息。
3. 实证命题可检验，规范命题含价值判断；"应该"二字通常标志规范分析。
4. 微观用个量分析，宏观用总量分析；微观结论简单加总未必成立（合成谬误）。
5. 「需求量变动」是沿曲线移动，「需求变动」是整条曲线平移，考试高频。
6. 需求曲线右移 + 供给曲线右移 ⇒ Q 必增、P 不定；反向移动 ⇒ P 定、Q 不定。
7. 支持价格必须**高于**均衡价才有效；限制价格必须**低于**均衡价才有效。
8. 弹性无量纲、线性需求上处处不同；斜率有量纲、线性需求上恒定，二者不可混。
9. 弧弹性用中点公式，避免涨价与降价得出两个不同的值。
10. `|Ed| > 1` 时降价增收；`|Ed| < 1` 时降价减收（谷贱伤农）；`=1` 时 TR 极大。
11. 垄断者绝不在 `|Ed| < 1` 的区间生产（`MR < 0`）。
12. 税负归宿与"向谁征税"无关，只取决于相对弹性；缺乏弹性的一方多承担。
13. 蛛网模型收敛条件是 `|eS| < |Ed|`，不是相反。
14. 边际效用递减不等于总效用递减；`MU = 0` 时 TU 最大。
15. 无差异曲线凸向原点源于 MRS 递减，与边际效用递减不是同一条假设。
16. 完全替代（直线 IC）与完全互补（L 形 IC）通常取角点解，**不满足相切条件**。
17. 均衡条件是 `MRS = Px/Py`（主观 = 客观），不是"花光收入"这一条就够。
18. C-D 效用下各商品支出份额恒定，与价格、收入无关。
19. 收入—消费线为过原点直线 ⇔ 所有商品收入弹性为 1，不是 0。
20. 市场需求曲线是个人需求的**水平**加总（同价格加数量），不是垂直加总。
21. 替代效应**恒与价格反向**；只有收入效应才可能反超它。
22. 吉芬品必定是低档品；低档品不一定是吉芬品。
23. 希克斯补偿保持效用、斯勒茨基补偿保持购买力；价格下降时补偿收入为负。
24. 混合策略中概率由**对方的支付**决定（令对方无差异），不是自己的支付。
25. 期望效用框架下 `U'' < 0` 才是风险厌恶；`EU < U(EW)` 是其等价判据。
26. 风险溢价 = `E(W) − CE`，不是 `E(W) − EU`（量纲不同）。
27. 边际报酬递减的两前提：技术给定 + 其他要素不变；技术进步是曲线平移，不构成反例。
28. `MP = AP` 处 AP 最大；`MP = 0` 处 TP 最大；`MP < 0` 时 TP 下降。
29. 第Ⅱ生产阶段是唯一合理生产区间，但最优点还要结合产品价格与要素价格。
30. 规模报酬是技术/实物概念，规模经济是成本概念，二者不可等同。
31. 范围经济看**多产品联合生产**，学习效应看**累计产量**，都与单一产品规模扩张不同。
32. 等产量线斜率是 `−MRTS`，等成本线斜率是 `−w/r`；切点条件 `MRTS = w/r`。
33. 欧拉定理要求规模报酬不变（1 次齐次）；递增时按边际产量支付会超支。
34. 经济成本 = 显成本 + 隐成本；正常利润属于隐成本，经济利润为零时企业仍在赚钱。
35. 会计利润通常**大于**经济利润；决策只看经济利润。
36. 长期没有固定成本，`LTC(0) = 0`；短期 TFC 与产量无关。
37. `SMC` 与 TFC 无关（固定成本的导数为零）。
38. `SMC` 分别穿过 `AVC` 与 `AC` 的最低点，`ACmin` 对应产量更大。
39. `AC − AVC = AFC`，随 Q 增大而缩小但永不为零。
40. `LAC` 是 SAC 的**包络线**，不是 SAC 最低点的连线（只在 LAC 最低点重合）。
41. 规模报酬递增 ⇒ LAC 递减；但 LAC 递减也可能来自要素价格下降（外在经济）。
42. 完全竞争厂商面对水平需求线，`P = AR = MR`；垄断厂商 `MR < P`。
43. `MR = MC` 是一切厂商的均衡条件；`P = MC` 只在完全竞争下成立。
44. 利润最大化还需二阶条件（MC 上升段），否则可能是利润最小点。
45. 亏损时**不一定停产**：只要 `P ≥ AVCmin` 就应继续生产。
46. 收支相抵点 `P = ACmin` 高于停止营业点 `P = AVCmin`，别记反。
47. 短期供给曲线是 `SMC` 在 `AVCmin` 以上的**上升**段，不是整条 SMC。
48. `PS = π + TFC`，亏损时生产者剩余仍可为正。
49. 完全竞争长期均衡 `π = 0` 指经济利润；正常利润仍存在。
50. 成本不变行业的长期供给曲线水平，需求增加只改变厂商数量与总产量。
51. 不完全竞争厂商**没有供给曲线**（价格与产量不再一一对应）。
52. 线性需求下 MR 与 D 纵截距相同、横截距为其一半，斜率是 2 倍。
53. 勒纳指数 `L = 1/|Ed|` 衡量市场势力，不等于利润率，也不等于 DWL 大小。
54. 一级价格歧视**无 DWL** 但消费者剩余全被占有 ⇒ 有效率与分配公平是两回事。
55. 三级价格歧视要求市场可分割、无套利、弹性不同；弹性小的市场价格更高。
56. 若两个市场需求弹性相同，价格歧视不会带来额外利润。
57. 垄断竞争长期 `π = 0`，但 `P > LMC`、产量低于 LAC 最低点（过剩产能）。
58. 主观需求曲线 d 比客观需求曲线 D **更平坦**（对手不跟随降价）。
59. 古诺是产量竞争、伯特兰是价格竞争；同质品伯特兰均衡 `P = MC`（悖论）。
60. 斯塔克尔伯格有先动优势；其均衡仍是纳什均衡（且是子博弈精炼的）。
61. 古诺 n 家：n→∞ 时 P→MC，n=1 时回到垄断；n 越大加成越小。
62. 卡特尔不稳定源于单方背叛动机，本质是囚徒困境；重复博弈可缓解。
63. 斯威齐弯折需求曲线解释价格刚性，但**不解释**现行价格如何形成。
64. 要素需求是**引致需求**，其强度取决于产品需求与要素边际产量。
65. 单个厂商要素需求曲线是 VMP 的**下降段**，不是整条 VMP 曲线。
66. 市场要素需求曲线比单个厂商需求曲线的水平加总**更陡**（因产品价格随总产量下降）。
67. 产品市场卖方垄断时 `MRP = MR·MP < VMP`，要素雇用量少于竞争情形。
68. 向后弯曲劳动供给：低工资替代效应占优，高工资收入效应占优。
69. 地租对全社会（土地总量固定）由需求决定；对特定用途，供给仍可向上倾斜。
70. 经济租是要素报酬超出机会成本的部分；准租金是短期固定要素报酬。
71. 功能分配（要素份额）≠ 规模分配（人际收入分布），基尼系数属后者。
72. 基尼系数对同比例收入平移不敏感，也不能反映收入流动性与组内差异。
73. 洛伦兹曲线越接近 45° 线越平等；`G = A/(A+B)`，别把 A、B 弄反。
74. 一般均衡存在 ≠ 唯一 ≠ 稳定；瓦尔拉斯法则使独立方程数比市场数少 1。
75. 帕累托最优有无穷多个，本身不含分配公平判断。
76. 帕累托标准要求"无人变坏"；有人受益有人受损的变动须用卡尔多–希克斯标准。
77. 交换最优 `MRS` 相等；生产最优 `MRTS` 相等；综合最优 `MRS = MRT`。
78. `MRT = MCx/MCy` 是 PPF 斜率；完全竞争下 `Px/Py = MRT`。
79. 福利第一定理的前提（无外部性、无公共物品、完全竞争、凸性）缺一不可。
80. 福利第二定理要求**一次总付**再分配，现实中的扭曲性税收会破坏结论。
81. 阿罗不可能定理说明不存在满足全部合理公理的社会偏好加总规则。
82. 功利主义 `ΣU`、罗尔斯 `min U` 可能给出完全不同的政策建议。
83. 纳什均衡是"单方无偏离动机"，占优均衡是"无论对方如何都最优"；后者必是前者。
84. 纯策略均衡可能不存在或不唯一；有限博弈必存在混合策略均衡（纳什定理）。
85. 囚徒困境说明纳什均衡**未必帕累托最优**；个体理性可致集体非理性。
86. 划线法中：甲表按**乙的列**找甲的最大支付，乙表按**甲的行**找乙的最大支付。
87. 有限次重复囚徒困境由逆向归纳得每期都背叛；无限次且 `δ` 足够大才可能合作。
88. 子博弈精炼用逆向归纳剔除**不可置信威胁**；不可用于静态博弈。
89. 零和博弈 `maximin = minimax`；囚徒困境是变和博弈，不适用。
90. 市场失灵指偏离帕累托最优，不等于价格高或企业利润多。
91. 负外部性下私人产量**高于**社会最优；正外部性下私人产量**低于**社会最优。
92. 庇古税应等于**最优产量处**的边际外部成本，若 ME 随 Q 变化就不能取常数。
93. 科斯定理的"产权归属不影响产量"以交易成本为零为前提；人数众多时往往失效。
94. 有效率的污染量通常不为零；目标是 `MSB = MSC` 而非全面禁止。
95. 公共物品最优是 `ΣMRS = MRT`（**纵向相加**），私人物品是 `MRS` 相等。
96. 公共物品非排他 + 非竞争 ⇒ 搭便车；公共资源难排他但有竞争性 ⇒ 公地悲剧。
97. "公共物品必须由政府生产"错误：提供（融资）与生产可以分离。
98. 逆向选择在**签约前**（隐藏信息），道德风险在**签约后**（隐藏行动）。
99. 信号传递由信息优势方发出；甄别由信息劣势方提供合同菜单。
100. 信息不完全普遍存在，只有信息**不对称**才导致逆向选择与道德风险。
101. 政府干预的正当性来自"市场失灵损失 > 干预成本"的比较，而非市场失灵本身。
102. 多数投票可能否决有效率的项目（收益分散、成本集中），也会过度通过利益集中项目。
103. 克莱姆法则之外的通用检验：政策题的 `CS + PS + 政府收支 + 外部成本` 四项必须逐项列出。
104. 任何"曲线平移"题都要先画图，再判断哪个变量方向不确定，不能凭直觉。
105. 所有计算题都应做一次**交叉验算**：`MR = MC` 与 `VMP = w`、`TR − TC` 与 `PS − TFC` 应一致。
106. 单位一定要带：弹性无量纲，斜率、MC、CS/PS 有量纲；混淆会直接暴露概念不清。
107. 边际量是「**再增加一单位**」带来的增量，不是总量除以数量的平均值（AP/AC）。
108. "其他条件不变"（ceteris paribus）是几乎所有定理的前提，答题时点明可避免失分。
