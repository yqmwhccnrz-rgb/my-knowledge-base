## 导论 金融概述

**金融**是货币资金的融通：从内涵看，它是服务于人类生产与消费过程、在**不确定环境**中进行的货币资金流通与**资源跨期配置**。广义金融泛指一切与货币、信用、资金融通相关的经济活动，狭义金融专指货币资金的融通（黄达对广义与狭义金融作了经典划分）。

### 0.1 金融的四个特征

| 特征 | 说明 |
| --- | --- |
| 交易对象 | 流动性较高的**金融资产**（不是粮食、钢铁等一般商品） |
| 交易基础 | **信用** |
| 行为动机 | 金融资源的**跨期优化配置** |
| 决策核心 | **收益—风险的权衡** |

### 0.2 金融系统的构成与功能

金融系统由四类要素构成：**金融机构、金融市场、金融工具、金融制度安排**。金融功能分层如下：

| 层次 | 功能 |
| --- | --- |
| 基本功能 | **资金融通**、支付结算 |
| 核心功能 | **资源配置**（功能最集中的体现） |
| 延伸功能 | 信息创造（金融资产价格提供前瞻性预期信息）、财富管理、风险管理 |
| 政策与导向功能 | 宏观调控、金融普惠、绿色金融 |

**资源配置效率**：宏观层面关注稀缺资源能否流向**最能产生价值的地方**；微观层面关注经济参与者如何最优满足自身需求。金融机构发挥该功能主要通过**创新金融工具、把货币转化为资本（吸收存款并发放贷款）、缓解金融资源稀缺性**三条途径。

宏观调控功能主要通过**货币政策、财政政策与金融监管政策**的传导实现。

### 0.3 易错点

- 金融交易的基础是**信用**，对象是**金融资产**；「金融仅指银行存贷款业务」过于狭窄。
- 金融的**核心功能是资源配置**，基本功能是资金融通与支付结算；信息创造、金融普惠不是核心功能。
- 金融系统四要素是机构、市场、工具与制度；「金融监管」属于制度安排的一部分，不是并列的第五要素。
- 资金融通、支付结算是基本功能，资源配置是核心功能，金融普惠与绿色金融是功能延伸。

## 第1章 货币与货币制度

![货币制度演变与构成要素](/finance/fin-monetary-system.svg)

### 1.1 货币的起源与形态演变

**货币**是固定地充当**一般等价物**的特殊商品。马克思认为货币是商品经济内在矛盾发展的产物，是商品价值形式演变的必然结果——「金银天然不是货币，但货币天然是金银」。

| 形态 | 含义 | 特点 |
| --- | --- | --- |
| 实物货币 | 作为交易媒介的价值与作为商品的价值基本一致 | **足值货币**，既是商品又是货币，具有双重身份 |
| 金属货币 | 以金银等金属铸币充当货币 | 仍属实物货币；价值稳定、可分割、易保存，但受产量限制 |
| 代用货币 | 由政府或银行发行、代替金属货币执行职能的纸制货币 | **不足值**，可按规定兑换金属货币 |
| 信用货币 | 以信用为保证、通过信用程序发行，充当流通手段与支付手段 | **不与任何金属挂钩**，不能兑现，靠国家信用与法偿力流通 |

信用货币的具体形式：**辅币**（本位币以下的小额货币，用于日常零星交易与找零）、**纸币**（国家发行并依靠国家权力强制行使货币职能）、**银行存款货币**（可开支票/转账的活期存款）、**电子货币与数字货币**。

> 数字货币：区块链是许多数字货币使用的支持技术之一；去中心化数字货币**没有中央银行发行与背书**，交易记录可追踪而非完全匿名，价格波动主要来自市场供求。我国的数字人民币（e-CNY）是**法定货币的数字化形态**，与去中心化加密货币性质不同。

### 1.2 货币的职能（★）

| 职能 | 含义 | 是否需要现实货币 | 典型例子 |
| --- | --- | --- | --- |
| 价值尺度 | 表现和衡量商品价值 | **只需观念上的货币** | 商品标价 |
| 流通手段 | 充当商品交换的媒介 | 需要现实货币，但**不必足值** | 一手交钱一手交货、餐馆付账 |
| 支付手段 | 清偿债务、单方面价值转移 | 需要现实货币 | 赊销还款、纳税、发工资、交房租水电费 |
| 价值贮藏 | 保存购买力 | 需要现实货币 | 储蓄、持有现金 |
| 世界货币 | 在国际市场充当一般等价物 | 需要现实货币 | 国际结算、外汇储备 |

**辨析**：钱货两讫是流通手段；先交货后付款（或先付款后交货）产生债权债务关系时才是支付手段。价值尺度发生在交易**之前**的标价环节，不需要真的拿出钱。

### 1.3 货币制度的内涵与构成要素

**货币制度**简称「币制」，是一个国家以**法律形式**确定的该国货币流通结构、体系与组织形式。

| 构成要素 | 说明 |
| --- | --- |
| 货币材料（币材） | 用来充当货币的物质，是币制的**最基本要素**，决定币制性质 |
| 货币单位 | 包括货币单位的**名称**与单位货币的**价值**（含金量/币值） |
| 通货的铸造、发行与流通 | 通货指流通中的现金，含**本位币**（主币）与**辅币**；规定本位币与辅币的铸造、发行、偿付与流通程序 |
| 货币准备（发行准备） | 黄金、外汇等储备，用于稳定币值、调节流通与国际支付 |
| 法定支付能力 | 无限法偿（本位币）与有限法偿（辅币）的规定 |

### 1.4 货币制度的演变（★）

演变主线：**银本位制 → 金银复本位制 → 金本位制 → 不兑现的信用货币制度**。

| 制度 | 核心特征 | 备注 |
| --- | --- | --- |
| 银本位制 | 以白银为本位币材料 | 最早出现，银价波动大 |
| 金银复本位制 | 金、银同时为法定币材 | 分**平行本位制、双本位制、跛行本位制**；双本位制下出现「劣币驱逐良币」 |
| 金本位制 | 以黄金作为本位币材料 | 见下表三种类型 |
| 不兑现信用货币制度 | 纸币不与黄金挂钩、不能兑换 | 当今各国通行的制度 |

**格雷欣法则（劣币驱逐良币）**：在金银复本位制下，当法定比价与市场比价背离时，实际价值被高估的「劣币」充斥流通，实际价值被低估的「良币」被熔毁、收藏或输出，退出流通。

### 1.5 金本位制的三种类型

| 类型 | 流通与兑换规则 | 特点 |
| --- | --- | --- |
| 金币本位制 | 金币自由铸造、自由熔化、自由输出入，银行券可自由兑换金币 | 最典型、最稳定的金本位；自动调节国际收支（价格—铸币流动机制） |
| 金块本位制 | 不铸造、不流通金币，纸币按**规定限额**兑换金块 | 又称「富人本位」，兑换有最低金额门槛 |
| 金汇兑本位制 | 本国货币挂钩另一金本位国货币，通过外汇间接兑换黄金 | 又称「虚金本位」，依附性强 |

### 1.6 不兑现信用货币制度的特点（★）

1. 纸币发行**不再受黄金准备限制**，由**国家垄断发行**，国家赋予纸币**无限法偿能力**。
2. 纸币通过**信用程序**投入流通，发行反映国家对社会公众的**负债**。
3. 纸币流通制度实质上是一种**管理货币制度**，货币量由货币当局主动调节。
4. **银行存款与法偿货币**都是流通中的货币，发挥相同的货币职能（存款货币同样计入货币供应量）。

### 1.7 易错点

- 货币的本质是**一般等价物**，不是「特殊商品」或「特殊等价物」；价值尺度是唯一可用观念货币执行的职能。
- 执行流通手段**不要求足值**（纸币可行），但**要求是现实的货币**。
- 「劣币驱逐良币」属于**金银复本位制**，与单一银本位、金本位无关。
- 金块本位制仍可兑换黄金，只是有**限额**；金汇兑本位制只能**间接**通过外汇兑换。

## 第2章 信用

### 2.1 信用的内涵与构成

**信用**是以**偿还本金和支付利息**为条件的借贷行为，是价值运动的特殊形式（所有权不转移、只让渡使用权）。构成要素：债权人与债务人、时间间隔（期限）、信用工具、利率。

金融与信用的关系：**金融交易的基础是信用**；金融行为动机是稀缺资源的跨期优化配置；金融决策核心是**收益—风险的权衡**；金融的核心功能是**资源配置**。

### 2.2 主要信用形式对比（★）

| 形式 | 定义 | 主体 / 客体 | 主要特点 |
| --- | --- | --- | --- |
| 商业信用 | 企业之间以**赊销商品、预付货款**等形式提供的信用 | 主体是企业；客体是**商品资本** | 与产业资本动态一致；受企业资本规模、方向、期限限制；是信用制度的基础 |
| 银行信用 | 银行及其他金融机构以**货币形态**向社会与个人提供的信用 | 主体是金融机构；客体是货币资金 | **间接信用**；规模大、期限灵活、接受性广、可控性强；基本形式是吸收存款与发放贷款 |
| 国家信用 | 国家（政府）作为债务人举债的信用 | 主体是政府 | 用于弥补财政赤字、筹措特定支出、调节经济；典型工具是公债与国库券 |
| 消费信用 | 面向消费者满足消费需求的信用 | 企业/银行 → 个人 | 分期付款、消费贷款、信用卡 |
| 民间信用 | 民间个人之间、非正规金融的借贷 | 个人/小微企业 | 灵活但利率高、风险大、缺乏监管 |

**商业信用的形式**：赊购与赊销、预付货款、分期付款。
**银行信用的特点**：间接信用、以货币形态提供、期限灵活、广泛接受性、可控性强（广义含非银行金融机构，狭义仅指银行）。

### 2.3 国家信用的形式与作用

| 形式 | 说明 |
| --- | --- |
| 公债 | **长期负债**，期限一般在一年以上，甚至十年以上 |
| 国库券 | **短期负债**，一年以下居多，常见 1 个月、3 个月、6 个月 |
| 专项负债 | 指明用途的债券，如国家重点建设债券 |
| 财政透支或借款 | 公债、国库券、专项债券仍不能弥补赤字时，余下赤字向银行透支或借款 |

**作用**：① 动员国民收入、弥补财政赤字的重要工具；② 筹措资金用于特定支出的重要形式；③ 调节经济、稳定经济发展的重要手段。

### 2.4 信用工具（金融工具）

**定义**：以书面形式发行和流通、借以保证债权人或投资人权利，用来证明资金供求双方**债权债务关系**的合法凭证。也称金融工具，是重要的金融资产和金融市场主要交易对象。

**构成五要素**：面值、到期日、期限、利率、利息支付方式。

| 四大特征 | 含义 |
| --- | --- |
| 偿还性 | 一般载明到期偿还的义务与期限（股票、永久债券除外） |
| 收益性 | 能定期或不定期带来收益，是提供信用的目的 |
| 风险性 | 为获得收益必须承担本金与收益损失的可能（信用风险、市场风险） |
| 流动性 | 可在市场上流通转让、随时转换为现金的能力 |

四者关系：**收益性与风险性通常正相关**，二者与**流动性**存在替代——流动性越强、安全性越高的资产，收益率一般越低。

### 2.5 直接金融与间接金融

| 项目 | 直接金融 | 间接金融 |
| --- | --- | --- |
| 资金路径 | 资金供给者 → 资金需求者（直接） | 资金供给者 → 金融中介 → 资金需求者 |
| 典型工具 | 股票、公司债券、政府债券 | 银行存款、贷款、可转让大额存单 |
| 信用关系 | 双方直接建立债权债务 | 两层信用关系，中介承担信用风险 |
| 信息成本 | 资金供给方自行搜集信息 | 由金融中介专业化处理，节约交易成本 |

> 金融机构产生的**根本原因**是商品经济与货币的发展，**直接原因**是节约交易成本、缓解信息不对称。

### 2.6 易错点

- 商业信用的客体是**商品资本**，银行信用的客体是**货币资金**；银行信用是**间接**信用。
- 国库券是**短期**负债、公债是**长期**负债，不要颠倒。
- 信用工具四特征里，「流动性」指变现能力，不是「偿还期限」。
- 股票无偿还性（无到期日），但仍有收益性、风险性与流动性。

## 第3章 利息与利息率

![利率期限结构与收益率曲线](/finance/fin-yield-curve.svg)

### 3.1 利息、利率与利率种类

**利息**是借款人因使用借入资金而支付给贷款人的报酬，是利润（剩余价值）的一部分。**利率**是利息率的简称，指**借贷期内所获得的利息额与借贷资本的比率**：

**利率 = 利息 ÷ 本金 × 100%**

| 划分标准 | 种类 |
| --- | --- |
| 借贷主体/业务方向 | 存款利率、贷款利率 |
| 是否随市场调整 | 固定利率、浮动利率 |
| 是否剔除物价因素 | **名义利率、实际利率** |
| 期限长短 | 长期利率、短期利率 |
| 在利率体系中的地位 | 基准利率、一般利率、优惠利率 |
| 决定方式 | 市场利率、官定（法定）利率、公定（行业自律）利率 |

**基准利率**是利率体系的核心，其他利率参照它确定；我国目前以 **LPR（贷款市场报价利率）** 为贷款定价主要参考，货币市场以 **DR007** 等为重要观测指标。

### 3.2 实际利率与收益率计算（★ 计算题）

设名义利率为 **r**、实际利率为 **i**、通货膨胀率为 **π**。

| 公式 | 表达 | 说明 |
| --- | --- | --- |
| 费雪简化式 | **i ≈ r − π** | 通胀较低时近似成立，最常用 |
| 费雪精确式 | **1 + r = (1 + i)(1 + π)**，即 **i = (1 + r)/(1 + π) − 1** | 通胀较高时必须用此式 |
| 单利终值 | **FV = P(1 + r·n)** | P 为本金，n 为期数 |
| 复利终值 | **FV = P(1 + r)ⁿ** | 利息再投资 |

**例**：名义利率 8%、通胀率 3% → 精确实际利率 = **1.08 / 1.03 − 1 ≈ 4.85%**；简化式给出 5%，偏差约 0.15 个百分点。通胀越高，简化式偏差越大。

**投资收益率（补全）**：

| 指标 | 公式 | 用途 |
| --- | --- | --- |
| 当期收益率 | **i_c = C / P**（年息票 ÷ 市价） | 债券当期现金回报 |
| 持有期收益率 HPR | **(期末价格 − 期初价格 + 期间收益) / 期初价格** | 衡量持有期间的总回报 |
| 到期收益率 YTM | 使未来现金流现值等于当前市价的贴现率 | 债券投资比较的标准口径 |

**例**：以 95 元买入一年后按 100 元兑付并付息 5 元的债券，HPR = **(100 − 95 + 5) / 95 ≈ 10.53%**。

> 名义利率为**负**或低于通胀时，实际利率为负，储蓄者购买力受损，会刺激当期消费与实物资产投资。

### 3.3 利率决定理论（★ 简答）

| 理论 | 核心观点 | 利率由什么决定 |
| --- | --- | --- |
| 马克思利率决定理论 | 利息是剩余价值的一部分，利率取决于平均利润率与借贷资本供求 | 平均利润率是上限，>0 且 < 平均利润率 |
| 古典利率理论（实际利率论） | 利率是「储蓄（等待）的报酬」，属实物经济变量 | 投资（资金需求）与储蓄（资金供给）的交点 |
| 流动性偏好理论（凯恩斯） | 利率是放弃流动性偏好的报酬，纯货币现象 | 货币供给（央行外生）与货币需求（三动机）的交点 |
| 可贷资金理论 | 综合实物与货币因素 | 可贷资金供给（储蓄 + 货币供给增量）与需求（投资 + 货币窖藏） |
| IS-LM 模型 | 产品市场与货币市场同时均衡 | IS 曲线与 LM 曲线交点，同时决定利率与收入 |

### 3.4 利率的功能

| 层面 | 功能 |
| --- | --- |
| 宏观 | 积聚社会资金；调节资金供求；优化资源配置；稳定货币流通；平衡国际收支 |
| 微观 | 对微观主体的激励作用（收益引导储蓄与投资）；约束作用（利息构成成本）；社会财富合理分配 |

### 3.5 利率的风险结构与期限结构（★）

**风险结构**：期限相同、风险 / 流动性 / 税收待遇不同的金融工具利率之间的差异。违约风险越高、流动性越差，利率越高（风险溢价）。

**期限结构**：**不同期限债券之间的利率关系**，用**收益率曲线**描绘。三个典型事实：

1. 期限不同的债券，利率随时间**一起波动**（同向性）；
2. 短期利率低时，收益率曲线**向右上方倾斜**；短期利率高时，曲线**向右下方倾斜**（倒挂）；
3. 收益率曲线**几乎总是向右上方倾斜**。

| 形态 | 含义 | 常见解释 |
| --- | --- | --- |
| 向上倾斜（正常） | 长期利率 > 短期利率 | 预期短期利率上升，或存在正的流动性升水 |
| 水平 | 长短期利率接近 | 预期短期利率基本不变 |
| 向下倾斜（倒挂） | 长期利率 < 短期利率 | 预期未来短期利率显著下降，常被视作衰退信号 |

**三种期限结构理论**：

| 理论 | 核心假设 | 能否解释「几乎总是右上倾斜」 |
| --- | --- | --- |
| 预期假说 | 长期利率 = 期限内各期预期短期利率的平均值；不同期限债券**完全可替代** | 只能解释形状随预期变化，解释不了事实 3 |
| 分割市场理论 | 不同期限市场**相互独立、完全不可替代**，利率由各自供求决定 | 能解释（长期债券需求弱、风险大 → 利率高），但解释不了事实 1 的同向波动 |
| 期限选择与流动性升水理论 | 投资者偏好短期债券，长期债券须支付**正的期限（流动性）升水** | **能解释全部三个事实**，是主流解释 |

### 3.6 易错点

- 精确费雪式是 **i = (1 + r)/(1 + π) − 1**，不是 **r − π**；分母是 (1 + π) 不是 (1 − π)。
- 收益率曲线**倒挂**指长期利率低于短期利率，不等于「利率下降」。
- 流动性偏好理论中货币供给由央行**外生**决定，利率是**货币现象**；古典理论中利率是**实物现象**（储蓄与投资）。
- 预期假说假定长短期债券完全替代，分割市场理论假定完全不替代，期限选择理论介于两者之间。

## 第4章 金融市场

![金融市场的资金融通流程](/finance/fin-market-flow.svg)

### 4.1 金融市场的定义与分类

**金融市场**是提供资金融通、进行金融资产交易的场所、机制与规则的总和——既包括有形的交易所，也包括无形的场外交易网络。基本要素：交易主体（资金供给者、需求者、中介、监管者）、交易对象（金融工具）、交易价格（利率、汇率、收益率）、交易组织方式。

| 划分标准 | 类别 | 关键区分 |
| --- | --- | --- |
| 融资期限 | **货币市场**（≤1 年）、**资本市场**（>1 年） | 短期资金融通 vs 中长期资本配置 |
| 交易层次 | **一级市场**（发行市场）、**二级市场**（流通市场） | 新证券首次发售 vs 已发行证券转让 |
| 市场结构 | 批发市场、零售市场 | 单笔金额与参与者是否为机构 |
| 交易场所 | **场内市场**（交易所）、**场外市场**（OTC） | 集中撮合 vs 分散询价 |
| 交割时间 | 现货市场、期货（衍生品）市场 | 即时交割 vs 约定未来交割 |
| 交易标的 | 货币、债券、股票、外汇、黄金、衍生品市场 | — |

> 一级市场把储蓄转化为投资，二级市场提供**流动性**与**价格发现**，二者相辅相成；「二级市场又叫发行市场」是常见错误。

### 4.2 金融市场的运作流程（★ 图）

- **直接金融**：资金需求者在证券市场上发行股票或债券，资金**直接**从供给者流向需求者。只形成一层债权债务（或所有权）关系，资金供给方自行承担风险、自行搜集信息。
- **间接金融**：先由银行等金融机构把资金供给者的资金**集中**起来，再由机构以贷款等形式分配给资金需求者。形成两层信用关系，金融机构承担信用风险并完成**期限转换、规模转换与风险转换**。

资金流向、证券流向与信息流向见上图。金融中介存在的根本原因是商品经济与货币的发展，直接原因是**节约交易成本、缓解信息不对称**。

### 4.3 货币市场的主要子市场

| 子市场 | 交易对象 | 期限与特点 |
| --- | --- | --- |
| 同业拆借 | 金融机构之间调剂准备金头寸 | 隔夜至数月，无抵押、凭信用、金额大 |
| 回购协议 | 以证券为质押的短期资金融通 | 多为隔夜与 7 天以内，有担保、风险低 |
| 票据市场 | 商业票据的承兑、贴现、转贴现、再贴现 | 与企业短期贸易融资相连 |
| 国库券市场 | 政府发行的短期债券 | 几乎无信用风险，是基准利率的重要参照 |
| 大额可转让定期存单（CD） | 银行发行的可转让定期存款凭证 | 面额固定、可在二级市场转让 |

**辨析**：货币市场工具必须是**一年以内**的短期工具（如 6 个月期国库券）；股票、20 年期公司债属资本市场。可转让大额存单由银行发行，属于**间接**金融工具。

### 4.4 同业拆借市场（★ 名词解释）

**内涵**：金融机构之间以货币借贷方式相互融通**短期资金**的行为，主要用于调剂法定准备金头寸。

**形成**：产生于**存款准备金政策**的实施——商业银行准备金多余或不足需要相互调剂；随中央银行业务与商业银行业务发展而发展。

**特点**：

1. 融资期限**短**（多为隔夜、1—7 天）；
2. 交易手续**简便**，多数无抵押、凭信用进行；
3. 交易金额**大**，属批发市场，参与者主要是金融机构；
4. 利率由双方**协商决定、随行就市**，对市场资金供求极为敏感（如我国的 SHIBOR、DR007）。

### 4.5 回购协议（★ 补全）

![回购协议的资金与证券流向](/finance/fin-repo.svg)

**基本原理**：资金融入方（正回购方）把证券**出售**给资金融出方（逆回购方）取得资金，同时约定在未来某日按**约定价格买回**同一笔证券。形式上是一买一卖两笔交易，实质是**以证券为质押的短期抵押融资**；回购价与售出价之差即利息，对应**回购利率**。

**资金与证券流向**（见上图）：
1. 首期：正回购方交付证券 → 获得资金；逆回购方支付资金 → 取得证券；
2. 到期：正回购方按约定价（本金 + 利息）返还资金 → 收回证券；逆回购方交回证券 → 收回本息。

**种类**：

| 划分标准 | 类型 | 区别 |
| --- | --- | --- |
| 到期日性质 | 约定日期回购、无固定到期日回购 | 后者可由任一方随时终止 |
| 债券处置权 | **封闭式回购**、**开放式回购** | 封闭式下质押债券冻结、买方不得动用；开放式下买方可在回购期内卖出或再质押该债券，到期只需归还同等数量同种债券 |

**与同业拆借比较**：回购有证券作质押，信用风险**低于**信用拆借，因而回购利率通常略低；回购也是央行公开市场操作最常用的工具之一。

### 4.6 票据市场：贴现、转贴现与再贴现

| 业务 | 交易双方 | 含义 |
| --- | --- | --- |
| 贴现 | 企业 ↔ 商业银行 | 持票人把未到期票据转让给银行，银行扣除贴现息后支付余额 |
| 转贴现 | 商业银行 ↔ 商业银行 | 银行间转让未到期票据，调剂头寸；因交易对手信用更高，转贴现率一般**低于**企业贴现率 |
| 再贴现 | 商业银行 ↔ **中央银行** | 央行买入票据投放基础货币，再贴现率是一项货币政策工具 |

### 4.7 易错点（市场部分）

- 一级市场 = 发行市场，二级市场 = 流通市场；新三板（含原精选层）依托股转系统，属**场外**资本市场。
- 同业拆借是**信用**交易、无抵押；回购协议是**有质押**的交易，两者不能混淆。
- 贴现是企业与银行、转贴现是银行与银行、再贴现是银行与央行，主体层级依次升高。
- 开放式回购赋予买方债券处置权，风险与管理要求高于封闭式回购。

### 4.8 资本市场：股票与债券

| 项目 | 股票 | 债券 |
| --- | --- | --- |
| 权利性质 | 所有权凭证（股东） | 债权债务凭证（债权人） |
| 期限 | 无到期日，不可退股 | 有到期日，还本付息 |
| 收益 | 股利 + 资本利得，不固定 | 利息，通常事先约定 |
| 清偿顺序 | 破产清算时**最后** | 优先于股票 |
| 风险 | 高 | 相对低（国债几乎无信用风险） |

**普通股 vs 优先股**：普通股有表决权、选择管理者与优先配股权，股利从**税后利润**支付、董事会宣告前不构成公司债务；优先股以**放弃表决权**换取固定股息与**优先分配剩余财产**，公司权利更少。按股东权利划分是普通股/优先股，记名与无记名、面额与无面额是按票面记载方式划分。

**股利贴现模型（DDM）**：股票内在价值等于未来股利的现值之和；零增长模型 **P₀ = D / r**，固定增长（戈登）模型 **P₀ = D₁ / (r − g)**，其中 r 为必要收益率、g 为股利增长率（须满足 r > g）。市场价格围绕内在价值波动，**并不总是相等**。

### 4.9 外汇市场与汇率制度（补全）

**汇率**是一国货币以另一国货币表示的价格。

| 标价法 | 含义 | 数值上升的含义 |
| --- | --- | --- |
| 直接标价法（我国采用） | 1 单位外币 = 若干本币，如 1 美元 = 7.20 元人民币 | **本币贬值、外币升值** |
| 间接标价法 | 1 单位本币 = 若干外币 | 本币升值、外币贬值 |

报价有买入价、卖出价与中间价，买卖价差是做市商收益；按交割时间分即期汇率与远期汇率，远期升贴水主要由**利率平价**决定。

**汇率决定理论（补全）**：

| 理论 | 核心结论 |
| --- | --- |
| 购买力平价（PPP） | 长期汇率由两国物价水平之比决定，一价定律是基础 |
| 利率平价（IRP） | 远期升贴水约等于两国利率之差，高利率货币远期贴水 |
| 国际借贷（收支）说 | 汇率由外汇供求决定，而供求来自国际收支 |
| 资产市场说 | 把汇率视为资产价格，受预期、利率与货币供给影响 |

**汇率制度**：固定汇率制、浮动汇率制，以及介于其间的**有管理的浮动汇率制**。

**我国人民币汇率制度改革（★ 材料分析）**：

1. **1994 年**：官方汇率与外汇调剂市场汇率**并轨**，实行以市场供求为基础的、单一的、有管理的浮动汇率制；
2. **2005 年 7 月 21 日**：不再单一盯住美元，改为**以市场供求为基础、参考一篮子货币进行调节、有管理的浮动汇率制度**；
3. **2015 年「8·11 汇改」**：完善中间价报价机制，强调上日收盘价与供求因素；
4. 此后引入**逆周期因子**，用于对冲外汇市场的顺周期羊群行为、平抑汇率超调。

> 2005 年后人民币**不是**「单一盯住美元」，也不是完全自由浮动；现行制度是有管理的浮动。

**汇率变动的影响**：本币贬值 → 出口商品外币价格下降、出口竞争力上升，进口成本与输入型通胀压力上升，外债负担加重；本币升值则相反。

### 4.10 金融衍生品与定价（补全）

| 工具 | 定义 | 关键特点 |
| --- | --- | --- |
| 远期 | 约定未来某日按约定价格买卖标的资产 | 场外、非标准化、有信用风险 |
| 期货 | 交易所标准化的远期合约 | 保证金、每日结算、可平仓 |
| 期权 | 支付权利金取得**未来按约定价买入/卖出的权利**（无义务） | 买方风险有限、收益无限；按行权时间分**欧式、美式、修正美式** |
| 互换 | 双方按约定条件在未来**定期交换现金流** | 常见利率互换、货币互换 |

**无套利定价**：在有效市场里，两个未来现金流完全相同的组合，当前价格必须相等，否则存在无风险套利。远期合约价值 = 现货价格 − 交割价现值；期权常用**二项式模型**（风险中性概率 + 无风险利率贴现）与 Black-Scholes 模型定价。

**影响期权价格的四个主要因素**：执行价格、标的价格波动率、无风险利率、距到期日时间（另加标的价格与股利）。波动率越大、期限越长，期权价值越高。

**有效市场假说（EMH）**：证券价格**充分反映所有可获得的信息**。分弱式（反映历史交易信息）、半强式（反映全部公开信息）、强式（含内幕信息）三层次。推论：弱式有效下技术分析无法持续获得超额收益；半强式有效下基本面分析也无法持续跑赢市场。

**风险分类**：

- **系统性风险**（不可分散）：利率、经济衰退、政策、国际摩擦等影响整个市场的因素；
- **非系统性风险**（可分散）：单个公司经营、技术泄露、诉讼等个别事件。

金融衍生工具既能**套期保值、转移风险**，也会因杠杆**放大风险**，不能笼统说「只是放大了风险」。

### 4.11 易错点（资本市场与汇率）

- 直接标价法下数值变大是**本币贬值**；判断题常把方向写反。
- 优先股在盈利分配与破产清算时优先于普通股，但**表决权少于**普通股。
- 欧式/美式期权的划分依据是**行权时间**，不是权利性质、标的资产或执行价格与市价的关系。
- 央行加息、经济衰退、贸易摩擦属系统性风险；单个公司事件属非系统性风险。
- 股票市场价格围绕内在价值波动，不等于内在价值。

## 第5章 金融机构

![我国金融机构体系](/finance/fin-institutions.svg)

### 5.1 金融机构的产生与分类

- **根本原因**：商品经济与货币的发展；
- **直接原因**：节约交易成本、缓解信息不对称，完成期限与规模的转换。

| 划分标准 | 类别 |
| --- | --- |
| 能否创造货币、交易媒介与支付手段 | **银行金融机构** vs **非银行金融机构** |
| 融资活动特点 | **直接金融机构**（证券公司等） vs **间接金融机构**（商业银行等） |
| 资金来源 | **存款性金融机构** vs **非存款性金融机构** |

### 5.2 我国金融机构体系（补全）

| 层次 | 主要机构 | 说明 |
| --- | --- | --- |
| 监管与货币当局 | 中国人民银行、国家金融监督管理总局、中国证监会 | 央行制定与执行货币政策、维护金融稳定；监管机关分业监管 |
| 政策性银行 | 国家开发银行、中国进出口银行、中国农业发展银行 | **政府设立、不以盈利为目的**，服务国家产业政策 |
| 商业银行 | 大型国有商业银行、股份制银行、城商行、农商行、村镇银行 | 吸收公众存款、发放贷款、办理结算，是存款货币创造的主体 |
| 非银行金融机构 | 证券、保险、信托、金融租赁、财务公司、资产管理公司、基金公司 | 不吸收公众活期存款，不参与存款派生 |

**政策性银行**由政府设立、不以盈利为目的，按国家产业政策投融资，对**货币扩张影响最小**（不吸收公众存款）。

### 5.3 常见非银行金融机构辨析

| 机构 | 主营 | 易混点 |
| --- | --- | --- |
| 证券公司 | 有价证券承销、经纪与自营 | 证券交易所是**交易场所**，不是经营机构 |
| 保险公司 | 承保可保的纯粹风险 | 股价下跌属投机风险，**不可保** |
| 信托投资公司 | 受人之托、代人理财 | 财产权转移，与委托代理不同 |
| 金融租赁公司 | 以**融资租赁**为主 | 融物与融资结合，区别于经营租赁 |
| 财务公司 | 由企业集团**内部成员单位**出资，为集团成员服务 | 不面向社会公众 |
| 金融资产管理公司 | 1999 年信达、华融、长城、东方四家成立 | 设立目的是处置国有银行不良资产 |
| 投资银行 | 承销、并购顾问 | **不吸收公众存款**，属非存款类 |

### 5.4 易错点

- 商业银行的**实收资本**通过发行股票筹集；吸收存款、发行金融债形成的是**负债**。
- 资产管理公司（1999）与政策性银行（1994）成立时间与职能不同，不要张冠李戴。
- 保险公司、证券公司、信托、贷款公司都属非存款类金融机构，但分属不同监管条线。

## 第6章 商业银行

### 6.1 定义与性质

**商业银行**是经营货币信用业务的**特殊金融企业**。

1. 与一般工商企业相同：拥有业务经营所必需的自有资本，大部分来自股票发行，以盈利为目标；
2. 与一般工商企业不同：经营对象是**货币资金**，经营方式以借贷为主，社会责任与对宏观经济的影响显著更大；
3. 与其他金融机构不同：能**吸收活期存款并创造存款货币**，是唯一具备存款派生能力的机构。

### 6.2 资本构成与管理（补全）

**资本充足率 = 资本 / 风险加权资产**，是银行监管的核心指标。

| 资本层次（巴塞尔 III / 我国《商业银行资本管理办法》） | 主要构成 |
| --- | --- |
| 核心一级资本 | 实收资本或普通股、资本公积、盈余公积、一般风险准备、**未分配利润**、少数股东资本可计入部分 |
| 其他一级资本 | 优先股、永续债（无固定期限资本债券）及其溢价 |
| 二级资本 | 二级资本工具（次级债）及其溢价、超额贷款损失准备 |

**辨析**：未分配利润、资本公积、注册资本属于**自有资本**；发行普通金融债、吸收存款、发行大额存单属于**负债**。送股、资本公积转股本只是权益内部结转，**不改变资本总量**；派现与大额费用支出会减少留存收益、压低核心资本。

### 6.3 业务体系

| 类别 | 内容 | 是否进资产负债表 |
| --- | --- | --- |
| 负债业务 | 吸收存款、发行大额存单、同业拆入、向央行再贴现/再贷款 | 是（负债方） |
| 资产业务 | 发放贷款、购买国债与央行票据、票据贴现、同业拆出、准备金存款 | 是（资产方） |
| **中间业务** | 结算（汇兑）、代理（代收代付）、银行卡、基金托管、咨询顾问 | **否**，不列入表内，不影响资产负债总额，但影响当期损益 |
| **表外业务（或有债权债务）** | 担保类、承诺类、金融衍生类 | 否，但存在或有风险，可能转化为表内资产负债 |

> 复习资料对「中间业务」的定义即：**不列入资产负债表、不影响资产负债总额、但影响当期损益**的经营活动。

### 6.4 贷款分类

| 划分维度 | 类别 |
| --- | --- |
| 是否有担保 | 信用贷款、担保贷款、票据贴现 |
| 用途 | 工商业贷款、消费者贷款 |
| 质量（五级分类） | **正常、关注、次级、可疑、损失** |

后三类（次级/可疑/损失）合称**不良贷款**；五级分类以**借款人还款能力**为核心，而非仅看是否逾期。

### 6.5 经营三原则及关系（★）

| 原则 | 含义 |
| --- | --- |
| 安全性 | 尽量避免不确定因素影响，保证资金安全与稳健经营 |
| 流动性 | 随时满足客户提现与借款人正常贷款需求 |
| 盈利性 | 尽可能追求盈利最大化 |

**关系**：盈利性是**目标**，安全性是**保障**，流动性是**前提**。安全性与流动性**正相关**（流动性强的资产风险小），但二者与盈利性**存在矛盾**——流动性越强、安全性越好的资产，收益率通常越低；高盈利资产往往流动性差、风险大。三性需在动态中权衡统一。

### 6.6 资产负债管理理论的演进（★）

| 阶段 | 代表理论 | 核心思想 |
| --- | --- | --- |
| 资产管理 | 商业贷款理论 → 资产转化理论 → 预期收入理论 | 侧重资产方，通过调节资产结构保证流动性；贷款应自偿、资产应可转让、还款看预期收入 |
| 负债管理 | 存款理论、购买理论 | 通过主动负债（同业拆入、发行 CD）满足流动性，不必大量持有低收益流动资产 |
| 资产负债综合管理 | 缺口管理、久期管理 | 同时管理资产与负债的利率敏感性、期限结构，统筹三性 |
| 资产负债外管理 | 表外业务与中间业务 | 通过不进表内的业务拓展收益、分散风险 |

### 6.7 易错点

- 中间业务**不进资产负债表**，但会形成非利息收入；表外或有业务虽不进表，却有转化为真实资产负债的可能。
- 三性中安全性与流动性正相关，与盈利性此消彼长；「流动性越高盈利性越强」是错的。
- 转贴现（银行间）信用等级更高，转贴现率一般**低于**企业贴现率。
- 五级分类按还款能力划分，「关注」仍属正常类贷款范畴之外的可收回类，后三类才是不良。

## 第7章 中央银行

![中央银行职能与资产负债表结构](/finance/fin-central-bank.svg)

### 7.1 性质与三大职能（★）

**性质**：中央银行既是**特殊的金融机构**，又是**管理金融事务的国家机关**——不面向企业与个人办理业务，不以盈利为目的。

| 职能 | 具体内容 |
| --- | --- |
| **发行的银行** | 垄断货币发行权；遵循垄断发行、经济发行、弹性发行原则，避免财政发行引发通胀 |
| **银行的银行** | ① 集中存款准备金；② 充当**最后贷款人**（再贷款、再贴现）；③ 组织全国清算、提供清算设施 |
| **政府的银行** | 制定与实施货币政策；监督管理金融业；代理国库、代理国债发行与兑付；向政府融通资金；保管国际储备；代表政府参与国际金融组织与活动；为政府决策提供建议 |

**辨析**：「最后贷款人」最能体现「银行的银行」；「发行货币」属「发行的银行」；代理国库属「政府的银行」。世界上**瑞典银行成立最早**，但**英格兰银行**最早全面发挥中央银行职能。

### 7.2 中央银行制度的类别

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 单一型（一元式/二元式） | 国家单独设立专司央行职能的机构 | 我国实行**一元式**，中国人民银行统一行使职能 |
| 复合型 | 央行职能与商业银行业务由同一家机构兼办 | 计划经济时期常见 |
| 准中央银行型 | 没有完整央行，由多个机构分掌职能 | 中国香港地区、新加坡（历史上） |
| 跨国型 | 多国共同设立统一央行 | 欧洲中央银行、西非国家中央银行 |

**中国人民银行资本属于国家所有**，不吸收企业与个人存款。

### 7.3 中央银行业务与资产负债表（补全）

**法定业务范围**：垄断货币发行；集中存款准备金；办理再贷款与再贴现；公开市场买卖有价证券；代理国库；经营黄金外汇业务；组织协调清算；代理政府发行兑付国债；统计调查与公布金融数据；稽核检查审计；会计核算；法律允许的其他业务。

| 资产负债表（简化） | 主要项目 |
| --- | --- |
| **资产（资金运用）** | 国外资产（外汇、黄金、特别提款权）、对政府债权、对其他存款性公司债权（再贷款、再贴现、MLF/SLF）、持有证券、固定资产 |
| **负债（资金来源）** | **储备货币（基础货币）**：流通中现金 + 金融机构存款准备金；政府存款；发行债券；自有资金 |

**关键恒等式**：资产 = 负债 + 自有资本；**基础货币是中央银行负债**。央行资产扩张（买入证券、发放再贷款）会等额投放基础货币；资产收缩（卖出证券）则回笼基础货币。

**业务分类**：银行性业务（形成资金来源与运用，其中货币发行、存款准备金、再贷款、再贴现、证券买卖、外汇经营反映在表内；清算、统计、稽核等不进表内）与管理性业务（统计调查、稽核检查等）。

### 7.4 中央银行的独立性

**独立性**指央行履行职责时，法律赋予或实际拥有的权力、决策与行动的**自主程度**。集中反映在央行与**政府**的关系上：一方面应与政府保持一定独立性，避免为财政赤字融资而牺牲物价稳定；另一方面又不能完全脱离政府，须与财政政策协调配合。因此独立性只能是**相对的**。

### 7.5 易错点

- 流通中现金与准备金都是**央行负债**；央行持有的证券、贴现贷款是**资产**。
- 中央银行不经营企业存款、个人存款；集中存款准备金属于负债业务。
- 货币发行原则不含「财政发行」，财政发行是通胀诱因。
- 央行独立性是**相对**的，不是绝对独立，也不是完全依附政府。

## 第8章 货币需求

### 8.1 货币需求的内涵

**货币需求**是指社会各部门在既定的收入、利率与财富约束下，**愿意且能够**以货币形式持有资产的需求。两个缺一不可的基本要素：**持有货币的愿望** + **持有货币的能力**。

| 概念对 | 区分 |
| --- | --- |
| 货币需要 vs 货币需求 | 「需要」是无限的主观愿望；「需求」是有支付能力约束的、有购买力保证的有效需求 |
| 微观 vs 宏观货币需求 | 微观从个体资产配置出发；宏观从一国经济总体所需的货币量出发 |
| 名义 vs 实际货币需求 | 名义需求按当前价格计；实际需求剔除物价因素，等于名义需求 / 价格水平 |

### 8.2 货币需求的影响因素（★）

| 因素 | 影响方向 | 机理 |
| --- | --- | --- |
| 收入水平与收入时间间隔 | 收入越高、**间隔越长** → 货币需求**越大** | 交易规模与两次收入之间的持币需求 |
| 市场利率 | **负相关** | 利率是持有货币的机会成本，利率越高越倾向于持有生息资产 |
| 汇率与预期 | 本币贬值预期 → 持币需求下降 | 转向外币资产 |
| 商品经济发达程度、信用制度 | 越发达 → 货币需求**越少** | 转账结算、信用工具替代现金 |
| 价格水平 | 正相关 | 同量交易需要更多名义货币 |
| 货币流通速度 | **负相关** | V 越快，完成同量交易所需货币越少 |
| 心理预期与偏好 | 不确定 | 影响流动性偏好与资产组合 |

**易错**：利率上升会**提高**持有货币的机会成本（不是降低）；收入间隔越长，货币需求**增加**。

### 8.3 传统货币数量论（★ 补全对比）

| 项目 | 现金交易说（费雪） | 现金余额说（剑桥，马歇尔/庇古） |
| --- | --- | --- |
| 公式 | **MV = PT** | **M = kPy** |
| 强调的货币职能 | **交易媒介** | **价值贮藏**（资产） |
| 分析视角 | 宏观：流通中货币量、交易总量与流通速度 | 微观：个体在货币与其他资产间的**资产选择** |
| 关键变量 | V（由制度技术决定，短期稳定） | k（人们愿以货币持有的收入比例，受利率、财富、偏好影响） |
| 结论 | V、T 短期稳定 → **货币量决定物价水平** | 货币需求取决于收入与持币意愿，已隐含机会成本思想 |

两式在 P、T(y)、V = 1/k 对应时可相互转换；现金余额说把货币需求同个体决策联系起来，是凯恩斯货币需求理论的重要源头。

### 8.4 凯恩斯的流动性偏好理论（★）

凯恩斯认为货币具有**最高流动性**，人们持有货币实质是对流动性的偏好。三大动机：

| 动机 | 含义 | 决定因素 |
| --- | --- | --- |
| 交易动机 | 保证日常交易顺利而保留货币 | 收入（正相关） |
| 预防（谨慎）动机 | 应付意外支出而持有货币 | 收入、不确定性 |
| 投机动机 | 等待未来有利时机在债券市场投机 | **利率（负相关）** |

**总需求函数**：**L = L₁(Y) + L₂(r)**，L₁ 为交易与预防需求（收入的增函数），L₂ 为投机需求（利率的减函数）。

- 预期利率**上升** → 债券价格将下跌 → 抛售债券、持有货币；
- 预期利率**下降** → 债券价格看涨 → 买入债券、减少持币；
- **流动性陷阱**：利率极低时，人们预期利率只会回升（债券价格只会下跌），货币需求弹性趋于无穷，央行增发的货币被全部吸收，货币政策失效。

### 8.5 货币需求理论的后续发展（补全）

| 理论 | 贡献 |
| --- | --- |
| 鲍莫尔平方根公式 | 把存货管理引入交易性货币需求，证明交易需求也**受利率影响**，且与收入的平方根成正比 |
| 惠伦立方根公式 | 预防性货币需求同样存在规模经济与利率弹性 |
| 托宾资产选择理论 | 用均值—方差框架解释投资者在货币与风险资产间的**分散持有** |
| 弗里德曼现代货币数量论 | 货币需求是**恒久收入**（长期平均收入）与总财富、人力/非人力财富比例、各资产预期收益率与偏好的**稳定函数**，主张「单一规则」 |

> 弗里德曼强调的是**恒久收入与总财富**，不是当期实际收入；这与凯恩斯强调当期收入与利率不同。

### 8.6 易错点

- MV = PT 是费雪现金交易方程式；M = kPy 是剑桥现金余额方程式，别互换。
- 收入与货币需求正相关、利率与货币需求负相关；但**收入获取的时间间隔**也是正相关。
- 流动性陷阱发生在利率**极低、预期只升不降**时，不是「预期利率下降」时。
- 对凯恩斯理论作发展的是鲍莫尔、惠伦、托宾；现金余额说**早于**凯恩斯。

## 第9章 货币供给

![存款派生与货币乘数](/finance/fin-money-creation.svg)

### 9.1 货币层次与计量（★）

| 层次 | 构成 | 性质 |
| --- | --- | --- |
| M0 | 流通中现金（通货 C） | 流动性最强 |
| M1（狭义货币） | **M0 + 企业活期存款 D** | 现实购买力 |
| M2（广义货币） | **M1 + 定期存款 + 储蓄存款 T**（我国还含其他存款） | 现实 + 潜在购买力 |
| M3（流动性口径） | M2 + 其他短期流动性资产 Dn | 更宽口径 |

**划分依据是金融资产的流动性（变现能力）**，不是安全性。

### 9.2 存款货币的创造（★ 补全）

**两个基本前提**：① **部分准备金制度**（银行只须保留一定比例准备金，其余可贷出）；② **非现金结算（转账）制度**（贷款以存款形式回流银行体系）。

**派生过程**（设原始存款 100 万、法定准备金率 rd = 20%）：

| 轮次 | 收到存款 | 上缴准备金 20% | 可贷出 |
| --- | --- | --- | --- |
| 第 1 轮 | 100.00 | 20.00 | 80.00 |
| 第 2 轮 | 80.00 | 16.00 | 64.00 |
| 第 3 轮 | 64.00 | 12.80 | 51.20 |
| … | … | … | … |
| 合计 | **500.00** | **100.00** | 400.00 |

存款总额 D = 100 / 0.2 = 500 万元，**派生存款 = 500 − 100 = 400 万元**；全部准备金恰等于原始存款 100 万元，形成平衡。所以派生存款能力与**原始存款成正比、与法定准备金率成反比**。

### 9.3 存款乘数的四种情形（★ 补全公式）

设 rd 为活期存款法定准备金率、e 为超额准备金率（E/D）、c 为现金漏损率（C/D）、t 为定期存款比率（T/D）、rt 为定期存款法定准备金率。

| 情形 | 存款乘数 d | 存款总额 |
| --- | --- | --- |
| 简单情形（无漏损、无超额准备金） | **d = 1 / rd** | ΔD = ΔR × (1/rd) |
| 有超额准备金 | **d = 1 / (rd + e)** | ΔD = ΔR / (rd + e) |
| 再有现金漏损 | **d = 1 / (c + rd + e)** | ΔD = ΔR / (c + rd + e) |
| 再有定期存款 | **d = 1 / (c + rd + e + rt·t)** | ΔD = ΔR / (c + rd + e + rt·t) |

分母每多一项，乘数就**变小**——漏损、超额准备金与定期存款准备金都会削弱派生能力。

### 9.4 基础货币、货币乘数与货币供给量（★ 计算）

**基础货币（高能货币）B = 流通中通货 C + 商业银行存款准备金 R**（法定 + 超额）。它是**中央银行的负债**，也是商业银行派生存款的基础。

**货币供给量 Ms = 基础货币 B × 货币乘数 m**

以 M1 为例：**m = (1 + c) / (c + rd + e + rt·t)**，其中分子含公众持有的通货。结论：

- 央行能**直接控制**基础货币 B 与法定准备金率 rd；
- **通货比率 c** 主要由公众持币行为决定，**超额准备金率 e** 由商业银行经营决策决定，**定期存款比率 t** 由存款人决定，三者央行**不能直接控制**；
- 因此货币供给既有外生性，也有**内生性**；若视为内生变量，货币当局只能有限调节，货币政策作用受限。

### 9.5 央行资产负债变动与准备金（补全）

| 央行操作 | 准备金 / 基础货币 |
| --- | --- |
| 买入证券、买入外汇黄金、发放再贷款与贴现贷款 | **增加**（资产扩张，投放基础货币） |
| 卖出证券、收回再贷款 | **减少**（资产收缩，回笼基础货币） |
| 政府存款增加 | 减少（负债结构变化，准备金转为政府存款） |

**例**：央行向商业银行出售 100 元国债，商业银行以准备金支付，银行体系准备金**减少 100 元**；美联储发放 10 亿元贴现贷款，则基础货币**增加 10 亿元**。

### 9.6 易错点

- 「派生存款」是派生出来的部分（400 万），不等于存款总额（500 万）；乘数 = 存款总额 / 原始存款。
- 通货比率取决于**公众**行为，超额准备金率取决于**商业银行**行为，法定准备金率由**央行**规定，三者别混。
- 货币层次按**流动性**划分，不是按安全性。
- 政策性银行不吸收公众存款、不参与存款派生，对货币扩张影响最小；央行影响最大。

## 第10章 通货膨胀与通货紧缩

### 10.1 定义

- **通货膨胀**：在一定时期内**一般物价水平持续、普遍上涨**的经济现象（不是个别商品一次性涨价），其实质是货币供给超过货币需求、单位货币购买力下降。
- **通货紧缩**：物价总水平**持续下跌**，常伴随货币供应量减少、经济衰退与失业上升。

### 10.2 通货膨胀的分类（★）

| 划分标准 | 类型 |
| --- | --- |
| 价格上涨速度 | **温和型**（个位数）、**奔腾型**（两位数至三位数）、**超级型**（恶性通胀） |
| 成因 | **需求上拉型**、**成本推动型**、**混合型**、**结构型** |
| 市场机制作用 | **公开型**（物价直接上涨）、**隐蔽型**（价格管制下表现为短缺、排队、黑市） |
| 通胀预期 | **预期型**、**非预期型** |

### 10.3 度量指标

| 指标 | 衡量对象 |
| --- | --- |
| 消费物价指数 CPI | 居民生活消费品与服务的价格变动，最常用 |
| 批发物价指数 PPI | 工业品出厂 / 生产资料价格，是 CPI 的先行指标 |
| GDP 折算（平减）指数 | 全部最终产品与服务的价格，覆盖面最广 |

### 10.4 成因与效应（补全）

| 成因 | 机理 |
| --- | --- |
| 需求拉上 | 总需求超过总供给，「过多货币追逐过少商品」 |
| 成本推动 | 工资、原材料与能源价格上涨推高成本，引发工资—物价螺旋 |
| 结构型 | 部门间生产率与开放度差异，落后部门为攀比工资而涨价 |
| 货币型 | 货币供给长期超过实际产出增长（「通货膨胀无论何时何地都是一种货币现象」） |

**效应**：非预期通胀造成**财富再分配**（债务人受益、债权人受损，固定收入者受损）、扭曲相对价格与资源配置、增加不确定性；温和通胀对产出可能有短期刺激，恶性通胀则严重破坏经济秩序。

### 10.5 通货膨胀的治理（★）

| 思路 | 具体措施 |
| --- | --- |
| **紧缩性财政政策** | 削减政府预算、限制公共事业投资（减少政府支出以降低赤字）；降低转移支付与福利开支；增税；发行公债弥补收支差额；开征特别消费税 |
| **紧缩性货币政策** | 在公开市场**卖出**政府债券回笼货币；提高贴现率与再贴现率；**提高法定准备金比率**；直接提高利率、紧缩信贷 |
| **收入政策** | 制定工资—物价指导线限制上涨；工资管制；以纳税为基础的收入政策 |
| **供给（供应）政策** | 减税（降低边际税率）、削减福利开支、稳定币值、放松管制精简规章，让企业扩大商品供给 |

记忆主线：**压需求（财政 + 货币）→ 管收入（工资物价）→ 增供给（减税松绑）**。

### 10.6 通货紧缩

成因：总需求不足、货币供给收缩、产能过剩、债务—通缩循环。危害：实际债务负担上升、企业利润下滑、投资与消费推迟、失业增加。治理以**扩张性财政与货币政策**为主，并配合结构性改革与预期管理。

### 10.7 易错点

- 通胀是**一般物价持续普遍上涨**，单件商品涨价或一次性调价不算。
- 治理通胀时央行应**卖出**证券、**提高**法定准备金率与再贴现率；方向写反是高频失分点。
- GDP 平减指数覆盖面最广，CPI 只覆盖居民消费品篮子。

## 第11章 货币政策

![货币政策目标、工具与传导机制](/finance/fin-monetary-policy.svg)

### 11.1 含义与特征

**货币政策**是中央银行为实现既定经济目标，运用各种工具控制、调节**货币供应量与利率水平**，进而影响宏观经济的方针与措施的总和。

三个特征：① **宏观经济政策**；② 主要是**间接调节**经济运行的政策；③ 调节**社会总需求**的需求管理政策。

### 11.2 最终目标与中介目标（★）

| 层次 | 内容 |
| --- | --- |
| **最终目标** | **物价稳定（首要目标）**、充分就业、经济增长、国际收支平衡 |
| **近期（操作）目标** | 基础货币、短期利率、存款准备金 |
| **远期（中介）目标** | 货币供应量、长期利率（社会融资规模、贷款规模属数量型监测指标） |

中介目标须满足**可测性、可控性、相关性、抗干扰性**。最终目标之间存在冲突：物价稳定与充分就业短期存在菲利普斯曲线权衡，经济增长与国际收支平衡也可能矛盾。

**辨析**：物价稳定是把通胀控制在较低且可预期的水平，**不是价格固定不变**；充分就业指消除周期性失业，仍存在摩擦性与结构性失业（自然失业率），**不是失业率为零**。

### 11.3 货币政策工具（★）

| 类别 | 具体工具 |
| --- | --- |
| **一般性工具（三大法宝）** | **法定存款准备金政策、再贴现政策、公开市场操作** |
| 选择性工具 | 消费者信用控制、证券市场信用控制、不动产信用控制、优惠利率、进口保证金制度 |
| 直接信用控制 | 信贷配给、流动性比率、利率上限、直接干预 |
| 间接信用控制 | 道义劝告、窗口指导 |
| 结构性（我国创新）工具 | 支农再贷款、支小再贷款、定向降准、MLF/TMLF、PSL、碳减排支持工具、专项再贷款 |

### 11.4 三大一般性工具对比（★ 高频）

| 工具 | 含义 | 特点 | 局限 |
| --- | --- | --- | --- |
| **法定存款准备金政策** | 央行调整法定准备金比率，影响商业银行信用创造能力，进而调节货币供应量 | **最猛烈**、对所有银行平等、效果快速有力 | 作用过于猛烈、缺乏弹性，**不宜日常微调**；频繁调整会冲击银行经营 |
| **再贴现政策** | 央行制定与调整再贴现率，影响商业银行信贷规模与市场利率 | 短期利率、官定利率、标准（最低）利率；有告示效应与结构调节功能 | **被动性强**（取决于商业银行是否来贴现）、主动权不完全在央行 |
| **公开市场操作** | 央行在公开市场买进/卖出有价证券（主要是政府短期债券），投放或回笼基础货币 | **主动性、灵活性、时效性、市场化**；可微调、可逆转、可日常操作 | 需发达且有足够深度的证券市场、央行需较强独立性与资金实力、需其他工具配合 |

**公开市场操作有效运作的三个条件**：① 央行具有较高独立性与足以调控整个金融市场的资金实力；② 金融市场相当发达、证券种类齐全并达到一定规模；③ 有其他政策工具的配合。

### 11.5 传导机制（补全）

主线：**政策工具 → 操作目标（基础货币、短期利率）→ 中介目标（货币供应量、长期利率）→ 最终目标（物价、就业、产出、国际收支）**。

主要渠道：利率渠道（利率→投资与消费）、信贷渠道（银行可贷资金）、资产价格渠道（托宾 q、财富效应）、汇率渠道（利率→资本流动→汇率→净出口）、预期渠道。

**我国利率走廊与价格型调控（补全）**：以 **SLF（常备借贷便利）利率为上限**、超额准备金利率为下限，通过 **MLF（中期借贷便利）** 提供中期基础货币并引导中期利率，公开市场 7 天逆回购利率为短期政策利率；贷款端以 **LPR（贷款市场报价利率）** 为主要定价参考，LPR 在 MLF 利率基础上加点形成。SLO 是短期流动性调节工具，PSL 为抵押补充贷款，主要服务政策性项目。

### 11.6 货币政策规则（补全）

| 规则 | 主张 |
| --- | --- |
| 相机抉择 | 央行根据经济形势灵活调整政策 |
| **单一规则**（弗里德曼） | 货币供应量按固定比率稳定增长，反对相机抉择 |
| 泰勒规则 | 按通胀缺口与产出缺口设定政策利率 |
| 通胀目标制 | 公开宣布通胀目标值并以此锚定预期 |

### 11.7 易错点

- 一般性工具只有三个；支农再贷款、定向降准属**结构性**工具，不是一般性工具。
- 法定准备金政策**最猛烈、缺乏弹性**，不是「作用温和、适合日常操作」；公开市场操作才适合日常微调。
- 再贴现政策的主要局限是**被动性强**，不是作用过猛。
- 基础货币是央行**负债**；存款准备金 = 法定 + 超额准备金。
- 我国 1984 年人民银行专门行使央行职能时正式建立法定存款准备金制度。
