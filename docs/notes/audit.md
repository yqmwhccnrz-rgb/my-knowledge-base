## 第 1 章 审计概述

### 1.1 审计的概念与保证程度

财务报表审计是指注册会计师对财务报表**是否在所有重大方面按照适用的财务报告编制基础编制**发表审计意见。其目的是提高财务报表的可信赖程度，**不涉及为财务报表使用者如何利用信息提供建议**，也不能减轻管理层或治理层的责任。

| 维度 | 合理保证（审计） | 有限保证（审阅） |
| --- | --- | --- |
| 目标 | 将审计风险降至可接受的低水平，以**积极方式**表述结论 | 将审阅风险降至可接受水平，但风险高于审计，以**消极方式**表述结论 |
| 结论措辞 | 「我们认为，财务报表在所有重大方面……公允反映」 | 「我们没有注意到任何事项使我们相信……未按照……编制」 |
| 程序 | 检查、观察、询问、函证、重新计算、重新执行、分析程序等全套 | 以询问和分析程序为主 |
| 证据量 | 多 | 少 |

::: danger 易错 · 合理保证不是绝对保证
合理保证是**高水平的保证**，但不是绝对保证。原因在于审计存在固有限制：财务报告的性质（涉及判断与估计）、审计程序的性质（管理层可能不提供完整信息、舞弊可能精心策划）、抽样与内部控制的固有局限、审计证据多为**说服性而非结论性**。因此「注册会计师对财务报表不存在重大错报提供绝对保证」「审计能发现所有舞弊」都是错误表述。
:::

### 1.2 审计要素

审计业务（鉴证业务）的五个要素：**三方关系人**、**鉴证对象（财务报表）**、**标准（适用的财务报告编制基础）**、**审计证据**、**审计报告**。

| 要素 | 要点 |
| --- | --- |
| 三方关系 | 注册会计师、**责任方（管理层，对编制财务报表负责）**、**预期使用者**。治理层对监督财务报告过程负责 |
| 财务报表 | 整套财务报表，含资产负债表、利润表、现金流量表、所有者权益变动表及附注 |
| 编制基础 | 企业会计准则等；**适当性**看是否可理解、相关、可靠、完整、能为预期使用者获取 |
| 审计证据 | 注册会计师为得出结论所获取的信息；充分性（数量）与适当性（质量） |
| 审计报告 | 书面，含审计意见；**口头报告不构成审计结论** |

::: tip 三方关系易混点
责任方与预期使用者可能来自同一企业（如治理层），但**不能因为同属一方就取消三方关系**；管理层既是责任方也可能是预期使用者之一，但对财务报表承担责任的角色不可转移给注册会计师。
:::

### 1.3 审计目标与认定

**总体目标**：①对财务报表整体是否不存在由于舞弊或错误导致的重大错报获取合理保证，并出具包含审计意见的审计报告；②按照审计准则的规定，根据审计发现对财务报表出具报告并与管理层和治理层沟通。

管理层认定是连接「风险 → 程序」的枢纽。现行准则按**交易和事项及相关披露**、**期末账户余额及相关披露**、以及**列报与披露**三个层次描述认定，考试常沿用经典的两分法：

| 层次 | 认定 | 含义与典型程序方向 |
| --- | --- | --- |
| 各类交易、事项及相关披露 | 发生 | 已记录的交易真实发生过（从账簿追查至凭证，查**高估**） |
| | 完整性 | 已发生的交易均已记录（从凭证追查至账簿，查**低估**） |
| | 准确性 | 金额与数据已恰当记录 |
| | 截止 | 交易记录于正确的会计期间 |
| | 分类 | 交易记录于恰当的账户 |
| 期末账户余额及相关披露 | 存在 | 资产、负债在资产负债表日确实存在 |
| | 权利和义务 | 被审计单位拥有或控制权利、承担义务 |
| | 完整性 | 应当记录的余额均已记录 |
| | 准确性、计价和分摊 | 金额恰当，已考虑减值、摊销等 |
| | 分类 | 余额归入恰当科目 |
| 两个层次共有 | 列报与披露 | 事项已按编制基础恰当列报、披露，含**披露的完整性、准确性、可理解性** |

::: danger 易错 · 方向决定程序
「存在 / 发生」查**高估**（从账到证），「完整性」查**低估**（从证到账）。应收账款函证主要验证**存在**，不能有效证明**完整性**；应付账款审计的重点恰是**完整性**（查找未入账负债）。这两个方向每年必考。
:::

### 1.4 审计基本要求

| 要求 | 要点 |
| --- | --- |
| 遵守职业道德 | 诚信、客观公正、独立性、专业胜任能力和勤勉尽责、保密、良好职业行为 |
| 职业怀疑 | 以质疑的思维方式评价证据，对相互矛盾的证据、对文件记录可靠性产生疑问的情形保持警觉；**不能假定管理层诚实或不诚实**，应作中性假设 |
| 专业判断 | 贯穿重要性、风险评估、程序性质时间范围、证据评价、意见形成各环节；判断须记录于底稿 |
| 审计证据 | 获取充分、适当的证据作为意见的基础 |
| 按准则执业 | 遵守中国注册会计师审计准则；**准则未规定的情形由专业判断处理** |
| 质量管理 | 项目层面按第 1121 号准则实施质量管理，事务所层面按第 5101 号准则建立体系 |

### 1.5 审计风险

![审计风险模型与重大错报风险分解](/audit/au-risk.svg)

**审计风险**是指财务报表存在重大错报而注册会计师发表不恰当审计意见的可能性。审计风险取决于**重大错报风险（RMM）**和**检查风险（DR）**：在既定的可接受审计风险下，二者呈反向关系。

| 概念 | 归属 | 能否控制 |
| --- | --- | --- |
| 重大错报风险 | 被审计单位及其环境固有，存在于**审计前** | 注册会计师只能识别和评估，不能控制或降低 |
| 认定层次 RMM | 可分解为**固有风险 × 控制风险** | 固有风险受不确定性、复杂性、主观性、变化、管理层偏向等固有风险因素影响 |
| 检查风险 | 审计程序未能发现单项或汇总重大错报的可能性 | 可通过程序性质、时间安排、范围与人员配置加以控制 |

::: danger 易错 · 三个常见错法
①「固有风险和控制风险由注册会计师确定」——错，只能**评估**；②「重大错报风险越低，所需审计证据越多」——错，应越少；③审计风险模型中的**检查风险与实质性程序直接相关**，控制测试本身并不直接降低检查风险，而是通过支持「控制有效」的评估间接影响所需实质性程序的性质时间范围。
:::

### 1.6 审计过程

见本章开头的流程图：初步业务活动 → 制定审计计划 → 风险评估 → 风险应对 → 完成审计工作 → 出具审计报告。**风险评估是全程的起点和主线**，计划并非一次性工作，随审计进程不断更新与修订。

### 1.7 注册会计师审计的执业责任

| 责任主体 | 责任 |
| --- | --- |
| 管理层 | 按适用编制基础编制财务报表、设计执行维护必要的内部控制、向注册会计师提供必要工作条件与全部信息 |
| 治理层 | 监督财务报告过程 |
| 注册会计师 | 按准则计划和实施审计、获取合理保证、出具报告并沟通；**不因利用专家或内部审计工作而减轻责任** |

::: tip 易错 · 责任不可转移
「注册会计师对财务报表的编制负责」「审计意见是对被审计单位持续经营能力的保证」「管理层可因注册会计师审计而免除编制责任」均为错误表述。审计意见只是对财务报表**是否不存在重大错报**提供合理保证。
:::

## 第 2 章 职业道德基本原则和解决职业道德问题的基本思路

### 2.1 职业道德基本原则

| 原则 | 要点 | 常见陷阱 |
| --- | --- | --- |
| 诚信 | 诚实守信、公正无私，不得与明知含有重大虚假或误导性陈述的信息产生关联 | 「只要管理层提供了声明就可以不追查矛盾证据」——错 |
| 客观公正 | 不因偏见、利益冲突或他人的不当影响而损害专业或业务判断 | 接受不当礼品、为迎合客户而修改结论 |
| 独立性 | 审计等鉴证业务的前提，含**实质上的独立**与**形式上的独立**；详见第 3 章 | 只做到内心独立而第三方看来存在利害关系，仍不合格 |
| 专业胜任能力和勤勉尽责 | 持续获取并保持专业胜任能力；按准则认真、全面、及时执业；使客户知悉专业服务的固有局限 | 「承接不具备胜任能力的业务后边做边学即可」——错 |
| 保密 | 不得擅自披露执业中获知的涉密信息，也不得为自己或第三方利益使用 | 见 2.2 的合法例外 |
| 良好职业行为 | 遵守法律法规，避免任何可能损害职业声誉的行为；宣传不得夸大、不得贬低同行 | 以「保证通过审计」招揽业务 |

### 2.2 保密义务的边界

下列情形**披露或使用涉密信息不违反保密原则**：①法律法规允许且经客户或雇主授权；②法律法规**要求**披露（如接受依法实施的检查、向法院或监管机构提供证据）；③职业准则或法律法规**要求或允许**且无需授权（如事务所质量检查、行业监管、为维护自身合法权益在法律程序中披露）。

::: tip 判断顺序
「法律法规要求」＞「客户授权」＞「职业准则允许」。披露前应先评估是否必要、披露范围是否限于必要信息，并尽可能先告知客户；**不得因客户拒绝授权而拒绝履行法律法规要求的披露义务**。
:::

### 2.3 职业道德概念框架

概念框架不是一张禁止清单，而是一套**问题解决流程**：

| 步骤 | 动作 |
| --- | --- |
| ① 识别 | 识别可能对遵循基本原则产生不利影响的事项或情形 |
| ② 评价 | 判断不利影响的严重程度是否**超出可接受水平**（考虑影响的性质、程度、涉及人员与持续时间） |
| ③ 应对 | 消除不利影响，或采取防范措施将其降低至可接受水平 |
| ④ 退出 | 若无法消除或降低至可接受水平，则**拒绝或终止**具体业务、解除业务约定，必要时解除客户关系 |

若多个事项叠加，须评价**累积影响**；涉及利益冲突时还应考虑是否向相关各方披露并取得同意。

### 2.4 五类不利影响

| 类别 | 典型情形 |
| --- | --- |
| 自身利益 | 在客户拥有经济利益、依赖单一客户收费、逾期收费长期未收、或有收费、承接业务时存在变相贷款担保、担心失去客户 |
| 自我评价 | 先替客户设计或实施了财务系统／内控／会计处理，再对该结果实施审计；项目组成员近期曾任客户董监高；事务所代编报表又审计 |
| 过度推介 | 推介客户立场到损害客观性的程度，如为客户的股票发行或某项交易作公开背书、代为推销客户股份 |
| 密切关系 | 项目组成员与客户的董事、高管存在主要近亲属关系；长期合作产生过度熟稔、接受贵重礼品或超规格招待 |
| 外在压力 | 客户以更换事务所、削减收费、起诉相威胁；受到不恰当的时间压力或要求缩减必要程序 |

::: danger 易错 · 威胁与情形的对应
「低价揽客后为节省成本减少程序」属于**自身利益**（而非外在压力）；「客户威胁不付款则换所」属于**外在压力**；「事务所先做内控咨询再审计该内控」属于**自我评价**。分类题必须先定位「谁的利益受到影响」。
:::

### 2.5 防范措施与冲突解决

防范措施分三个层面：**职业准则、法律法规规定的**（如轮换、独立性要求、项目质量复核）；**客户内部的**（如治理层参与选聘、客户有胜任人员参与决策）；**事务所自身的**（如独立性政策与培训、项目组外复核、合伙人轮换、分离咨询与审计团队、设立信息屏障）。

解决职业道德冲突的推荐流程：先与内部相关人员或治理层沟通 → 咨询行业协会、监管机构或法律顾问 → 记录争议实质、讨论过程与最终决定 → 若仍无法解决，拒绝或退出并说明（法律法规禁止说明的除外）。

::: tip 记录也是义务
「讨论过但没有形成书面记录」在质量检查与法律纠纷中会被视为**未执行防范措施**。概念框架每一步的判断、咨询对象、结论与理由都应写入底稿或事务所档案。
:::

### 2.6 具体运用速查

| 场景 | 处理 |
| --- | --- |
| 利益冲突 | 同时为存在直接竞争或诉讼关系的客户提供服务时，评价影响并可能需取得各方同意、设置信息屏障，必要时拒绝其中一方 |
| 第二意见 | 应客户要求就另一会计师已处理的事项提供意见时，须向原会计师索取必要信息并征得客户同意；信息受限时应说明意见的局限 |
| 礼品和招待 | 评价性质、价值与意图；**明显不重大且属正常礼节**可接受，超出则拒绝或退回 |
| 逾期收费 | 长期（尤其超过一年）未收的审计费实质上等同于向客户提供贷款，可能构成**自身利益**威胁；通常应在支付前暂停后续服务 |
| 或有收费 | 审计等鉴证业务**不得采用或有收费**；非鉴证业务采用时须评价并防范 |
| 客户违法 | 先了解事实与法律后果、与治理层沟通，必要时咨询并考虑解除业务约定或向外部报告 |

### 2.7 非执业会员

在企事业单位中工作的会员同样适用概念框架，常见威胁为**外在压力**（被要求编制虚假报表、隐瞒信息）与**自身利益**（奖金、股权、晋升与业绩挂钩）。处理方式：与直属上级、更高层或治理层沟通 → 咨询 → 记录 → 必要时辞职并向监管机构报告。

## 第 3 章 审计业务独立性要求

### 3.1 基本概念与适用范围

独立性包括**实质上的独立**（内心状态，能不受损害专业判断的影响而行动）与**形式上的独立**（在理性第三方看来不存在损害独立性的关系或利益）。二者缺一不可。

| 概念 | 含义 |
| --- | --- |
| 审计客户 | 接受审计服务的实体；对集团审计，包括集团母公司及其**关联实体** |
| 关联实体 | 控制客户／被客户控制／与客户同受控制，或具有重大经济利益关系的实体；独立性要求通常**延伸适用**到关联实体 |
| 公众利益实体 | 上市实体，以及法律法规规定或因其业务性质、规模、员工数量而具有重大公众利益的实体；适用更严格规则 |
| 网络事务所 | 旨在通过合作实现共同战略、共享资源／品牌／质量体系／客户资源的一组事务所；独立性要求及于**网络内各事务所** |
| 关键审计合伙人 | 项目合伙人、项目质量复核人员，以及对重大事项作出关键决策或判断的其他合伙人 |

::: danger 易错 · 关联实体与网络
「只要不直接持有母公司股份就独立」——错，持有审计客户**控制的子公司**的重大经济利益同样不独立；「独立性只需项目组遵守」——错，事务所、网络事务所、合伙人及其主要近亲属都在约束范围内。
:::

### 3.2 收费

| 情形 | 规则 |
| --- | --- |
| 逾期收费 | 长期（尤其超过一年）未收取的审计费用，实质上相当于向客户提供了**贷款**，构成自身利益威胁；一般应在收取逾期款项前不继续提供服务 |
| 或有收费 | 审计业务**禁止**或有收费；因监管机构或法院确定的收费不属于或有收费 |
| 收费依赖度 | **公众利益实体**：收费占比超过或可能超过 **15%** 须向治理层沟通；连续两个会计年度超过 15% 时，须在第二年度发表意见前由**其他会计师事务所**实施相当于项目质量复核的「发表审计意见前复核」，否则应终止该审计业务。**非公众利益实体**：连续 **5 年**占比超过或可能超过 **30%**，须在第五年度发表意见前由其他事务所实施复核 |
| 低价揽客 | 报价明显低于正常水平须能证明已投入足够资源与时间、不缩减必要程序，否则损害专业胜任与勤勉尽责 |

::: tip 与「外在压力」区分
收费依赖、逾期收费是**自身利益**；客户以「不降费就换所」施压才是**外在压力**。两者防范措施不同：前者靠披露与外部复核，后者靠沟通、记录与必要时解除约定。
:::

### 3.3 经济利益

| 主体 | 禁止情形 |
| --- | --- |
| 事务所／网络事务所 | 在审计客户中拥有**直接经济利益**或**重大间接经济利益** |
| 项目组成员及其主要近亲属 | 同上；即使金额不大，直接经济利益也无「不重大」豁免 |
| 与项目合伙人同处一办公室的其他合伙人及其近亲属 | 通常限于其**直接**经济利益或重大间接经济利益，且须评价 |
| 退休合伙人 | 若仍与客户保持重大联系或收取与事务所业绩挂钩的福利，仍须评价 |

处置方式：在**承接审计业务之前或产生利益关系之前**处置全部直接经济利益、处置间接经济利益至不重大；若无法处置，则拒绝或解除业务。通过**继承、馈赠、企业合并**等被动取得的经济利益，须尽快处置或在处置前由项目组外的注册会计师复核已完成的工作。

::: danger 易错 · 间接利益的「重大」判断
「间接经济利益只要金额小就一律不影响独立性」不准确：须评价是否**重大**；而**直接经济利益无论金额大小一律禁止**。此外，通过共同基金等投资工具持有且无法影响投资决策的间接利益，通常可按「不重大」处理，但须能证明无控制与影响能力。
:::

### 3.4 贷款担保、商业关系、家庭和私人关系

| 事项 | 规则 |
| --- | --- |
| 贷款与担保（事务所／项目组成员） | 从**银行或类似金融机构**的审计客户取得贷款，须按正常程序、条件与条款，且金额不重大；从**非金融机构**客户取得贷款或为其提供担保，通常产生无法降至可接受水平的自身利益威胁 → 禁止 |
| 存款与银行账户 | 按正常商业条件在作为银行的审计客户开立存款或支票账户，一般不损害独立性 |
| 商业关系 | 与客户或其管理层共同开办企业、捆绑销售、互相作为主要供应商或客户等重大商业关系 → 禁止；按正常商业条件购买商品且金额不重大者除外 |
| 家庭和私人关系 | 项目组成员的**主要近亲属**担任审计客户董事、高级管理人员，或所处职位能对财务报表施加重大影响 → 禁止，须调离该项目；其他近亲属／密切个人关系须评价并防范 |
| 礼品和招待 | 超出正常礼节与明显不重大范围的，须拒绝；否则视为密切关系或自身利益威胁 |

### 3.5 与审计客户之间的人员交流

| 情形 | 规则 |
| --- | --- |
| 项目组成员近期曾任客户董事、高管或能对报表施加影响的员工 | 在**涵盖其任职期间的财务报表**审计中不得参与；通常须经过规定的冷却期间 |
| 事务所合伙人／员工离职后加入审计客户任董监高 | 须评价其对事务所与项目组的影响，及时与治理层沟通，必要时调整项目组、由项目组外人员复核 |
| 客户董事／高管加入事务所 | 在其对客户具有影响力的期间内，不得让其参与该客户的审计业务 |
| 「旋转门」 | 关键审计合伙人加入审计客户担任董监高等职务，须有冷却期并立即向事务所报告、与治理层沟通 |

### 3.6 与审计客户长期存在业务关系

长期由同一批关键审计合伙人服务于同一审计客户，会产生**密切关系**与**自身利益**威胁。

| 措施 | 要点 |
| --- | --- |
| 关键审计合伙人轮换 | 对**公众利益实体**，任何人员担任项目合伙人（含其他签字注册会计师）、项目质量复核人员、其他关键审计合伙人的**累计时间不得超过 5 年**；任职期结束后须轮换并遵守冷却期，冷却期内不得再参与该客户审计、不得担任项目质量复核人员或向项目组提供咨询 |
| 冷却期（按离任前所任职务确定） | 项目合伙人 **连续 5 年**；项目质量复核人员 **连续 3 年**；其他关键审计合伙人 **连续 2 年**；相继担任多项职责累计满 5 年的，按最长冷却期执行 |
| 任职期内角色变动 | 项目合伙人卸任后 **2 年内不得**担任同一业务的项目质量复核人员（自我评价威胁） |
| 事务所连续服务 | 为同一公众利益实体连续执行审计业务达到 **10 年或以上**，须评价独立性影响并在事务所层面采取防范措施（扩大轮换范围、第二轮／外部质量复核、与治理层书面沟通等） |
| 累计计算 | 不同职务的任职时间**累计计算**；只有不再担任这些职务达到一个连续期间（至少等于其适用冷却期）后，累计期间才可清零重新计算 |

::: tip 与「项目质量复核」联动
轮换、冷却期与项目质量复核都属于事务所质量管理体系中「治理和领导层」「资源」「业务执行」要素的落地措施；违反轮换要求本身即构成违反独立性要求，须按 3.9 处理。
:::

### 3.7 为审计客户提供非鉴证服务

**总原则**：不得承担**管理层职责**（作出决策、设计与实施内控、代编财务报表、决定会计政策、批准交易等）。一旦承担管理层职责，产生的自我评价威胁**无法降至可接受水平**，没有防范措施可用。

| 服务类型 | 是否允许 | 关键条件 |
| --- | --- | --- |
| 承担管理层职责（代编报表、代做账务、审批交易、设计并实施内控） | **禁止** | 无防范措施 |
| 会计与记账服务（日常、机械性、技术性） | 有限允许 | 对公众利益实体客户通常禁止；非公众利益实体须由客户管理层作出全部判断与决策、配备胜任人员、事务所以独立团队提供并接受复核 |
| 内部审计服务外包、财务信息系统设计与实施 | 对公众利益实体客户一般禁止 | 不得涉及与财务报告内控重大相关的部分，不得代行内审职能 |
| 估值服务 | 有限允许 | 若估值结果对财务报表有重大影响且涉及高度主观性，通常产生不可接受的自我评价威胁；可由客户另聘专家或由项目组外团队复核 |
| 税务服务（申报、税务筹划、税务争议支持） | 有限允许 | 不得为客户代言或承担管理层职责；筹划方案须由客户决策，涉及重大判断的须由项目组外人员复核 |
| 诉讼支持、法律咨询、招聘高管、公司财务顾问 | 有限允许或禁止 | 招聘董监高等能对报表施加重大影响的人员、为客户承销或推介证券通常禁止 |

::: danger 易错 · 「有防范措施就没问题」是错的
自我评价威胁并非总能被防范措施化解。**只要承担管理层职责，或提供的服务结果构成审计对象且涉及重大主观判断**，结论通常是「不得提供」。答题时先判断「是否存在无法降至可接受水平的威胁」，再谈防范措施。
:::

### 3.8 影响独立性的其他事项

- **诉讼或纠纷**：事务所与审计客户之间存在重大诉讼，会产生自身利益与外在压力威胁，须评价并考虑解除约定。
- **前任注册会计师**：接受委托前必须沟通，了解是否存在不应接受委托的事项；后任不得在未经前任答复前默认「无问题」。
- **记录与沟通**：独立性相关的识别、评价、防范措施、每年独立性确认，均须形成书面记录并与治理层沟通。

### 3.9 违反独立性要求时的措施

| 步骤 | 动作 |
| --- | --- |
| ① 立即处置 | 终止、暂停或消除产生违反的利益关系或活动（如处置经济利益、调离人员、停止非鉴证服务） |
| ② 评价严重性 | 评价违反的性质、持续时间、涉及人员与业务期间，以及是否影响已出具的意见 |
| ③ 沟通 | 及时与治理层、项目合伙人、事务所负责人及必要的监管机构沟通 |
| ④ 补救 | 视情况由项目组外的注册会计师／网络外事务所复核已完成工作，或重新执行部分审计程序 |
| ⑤ 结论 | 若无法将威胁降至可接受水平，应**解除业务约定**；对已出具的报告考虑撤回或采取法律允许的其他措施 |
| ⑥ 记录 | 完整记录违反事实、评价过程、沟通对象、采取的措施与最终结论 |

::: tip 易错 · 不要「先出报告再补救」
违反独立性要求时**不能以「安排外部复核」直接替代**所有处置；须先终止或消除违反本身，再评价是否需要复核，且复核必须在**报告出具之前**完成。
:::

## 第 4 章 审计证据

![审计证据的充分性与适当性](/audit/au-evidence.svg)

### 4.1 审计证据的性质

**审计证据**是注册会计师为得出审计结论、形成审计意见所使用的**所有信息**，包括：①构成财务报表基础的**会计记录**所含信息；②从被审计单位内部或外部**其他来源**获取的信息（如询证函回函、分析师报告、竞争对手信息、专家工作、治理层会议纪要）；③通过自己实施分析程序、重新计算等形成的信息。

::: danger 易错 · 两类信息缺一不可
「没有会计记录，审计工作将无法进行」；「仅有会计记录，可能无法识别重大错报（如未入账负债、关联方、舞弊）」。二者是叠加关系，不是相互替代。管理层依据会计记录编制财务报表是其责任，注册会计师**应当测试会计记录**并获取用作审计证据的其他信息。
:::

| 维度 | 判断要点 |
| --- | --- |
| 充分性 | 数量；与评估的重大错报风险同向、与证据质量反向；**仅靠增加数量无法弥补质量缺陷** |
| 适当性 | 质量；＝**相关性**＋**可靠性**，二者缺一不可 |
| 相关性 | 必须与拟测试的**认定**和审计目标对应；与「完整性」相关的目标，取得「真实性/存在」的证据即为不相关 |
| 可靠性 | 外部独立来源＞内部；内控有效时内部证据更可靠；直接获取＞间接或推论；文件原件＞口头、传真或复印件；不同来源相互印证更可靠 |

若不同来源或不同性质的证据**相互不一致**，或对被审计单位生成、维护信息的相关控制可靠性存疑，注册会计师应当**扩大审计程序范围直到不一致得到解决**，并针对相关账户余额或交易类型得出结论。

### 4.2 七种审计程序

| 程序 | 适用对象 | 证据力提示 |
| --- | --- | --- |
| 检查（记录或文件、实物资产） | 凭证、合同、实物；检查实物资产主要验证**存在**，不能证明权利与计价 | 检查记录文件的可靠性取决于来源与内控 |
| 观察 | 人员正在执行的活动或程序 | 仅限观察时点，且被观察时行为可能改变 |
| 询问 | 内部或外部知情人员 | 书面或口头答复**本身不足以**测试认定，须与其他证据印证 |
| 函证 | 第三方 | 从被询证者直接获取的**书面或电子形式**答复，可靠性较高 |
| 重新计算 | 准确性 | 检查记录或文件中数据的准确性 |
| 重新执行 | 控制运行有效性 | 注册会计师独立执行被审计单位的控制程序 |
| 分析程序 | 财务/非财务数据间可预期关系 | 见 4.4 |

### 4.3 函证

| 要点 | 结论 |
| --- | --- |
| 决策 | 应当考虑所审计的**认定**及可能影响函证可靠性的因素；以往审计经验（回函率、以往错报）、函证方式、被询证者的客观性等 |
| 管理层授权 | 询证函通常应包含被审计单位管理层的授权，否则被询证者可能不愿或不能回函 |
| 过程控制 | 注册会计师**对发函、跟函、回函全过程保持控制**；由被审计单位代发代收的回函不构成有效证据 |
| 积极式 | 要求被询证者必须回函，或确认所列信息是否正确，或填列所要求的信息；未提供证据可靠性更高 |
| 消极式 | 仅在被询证者**不同意**所列信息时回函；证据力较弱，**只有当**重大错报风险评估为低水平、涉及大量余额较小的账户、预期不存在大量偏差、预期被询证者会认真对待函证等条件**同时满足**时才可使用 |
| 未回函 | 实施**替代程序**获取相关认定的证据；若无法获取，考虑对意见类型的影响 |
| 不函证 | 若不对应收账款等实施函证，注册会计师**应当在审计工作底稿中说明理由**，并说明如何在无函证情况下获取充分适当证据 |
| 不符事项 | 调查差异原因，评价是否表明存在错报或舞弊，并考虑对其他认定的影响 |

::: tip 补充 · 银行函证与应收账款函证
对**银行存款、借款及与金融机构往来的其他重要信息**，注册会计师应当向金融机构函证，除非有充分证据表明这些项目不重要且相关重大错报风险很低（此时也须在底稿说明理由）。对**应收账款**，准则要求函证，除非有充分证据表明应收账款不重要，或函证很可能无效。两者都是主观题常考的「应当＋例外＋记录理由」三段式。
:::

### 4.4 分析程序

| 阶段 | 是否必须 | 目的 |
| --- | --- | --- |
| 风险评估 | **必须** | 了解被审计单位及其环境，识别异常关系、未预期差异与可能的重大错报风险 |
| 实质性程序 | 可选（作为实质性分析程序） | 与细节测试结合，减少细节测试工作量 |
| 临近审计结束的总体复核 | **必须** | 在已收集证据基础上评价报表整体合理性，判断是否存在尚未发现的重大错报，决定是否追加程序 |

用作实质性分析程序须满足：数据间存在**稳定的可预期关系**、可获得可靠数据、建立的期望值足够精确（设定可接受的差异阈值）。当数据关系不稳定、管理层可随意调整数据、或仅实施分析程序不足以应对风险评估结果时，应改用或补充细节测试。分析程序**不适用于控制测试**。

## 第 5 章 审计抽样方法

![审计抽样在控制测试与细节测试中的应用](/audit/au-sampling.svg)

### 5.1 审计抽样的相关概念

审计抽样须**同时具备三个特征**：①对具有审计相关性的总体中**低于百分之百**的项目实施测试；②**所有抽样单元都有被选取的机会**（不得存有偏见）；③可以根据样本结果**推断总体**特征。

| 情形 | 是否属于审计抽样 |
| --- | --- |
| 对某类交易或账户余额中低于 100% 的项目选取样本并据以推断总体 | 是 |
| 100% 检查（总体由少量大额项目构成、或存在特别风险且 100% 检查恰当） | 否 |
| 选取特定项目（大额、高风险、超过某金额的全部项目） | 否，结论**不能推断总体** |
| 仅实施询问、观察、分析程序，不拟对总体得出结论 | 否 |

::: danger 易错 · 总体的适当性与完整性
教材两个经典反例：①为测试「所有发运商品均已开单」的控制，从**已开单项目**中抽样，永远发现不了该控制偏差——总体不包含「已发运未开单」项目；②从**档案**中选取付款证明，除非确信所有付款证明都已归档，否则不能对该期间全部付款证明得出结论。抽样前必须先确认总体在**内容与涉及时间**两方面均适当、完整。
:::

### 5.2 抽样风险与非抽样风险

| 测试类型 | 影响**效果**（更危险） | 影响**效率** |
| --- | --- | --- |
| 控制测试 | **信赖过度风险**（控制实际无效却评估为有效，导致程序不足、发表不恰当意见） | 信赖不足风险（控制实际有效却评估为无效，导致多做无用程序） |
| 细节测试 | **误受风险**（总体存在重大错报却认为没有） | 误拒风险（总体无重大错报却认为有） |

抽样风险可通过**扩大样本量、分层**降低；非统计抽样虽无法精确测定抽样风险，也**必须**考虑并将其降至可接受水平。非抽样风险来自选错程序、误解证据、人为疏忽、舞弊串通等，与样本量无关，只能靠**适当的指导、监督和复核**、仔细设计程序、遵守质量管理政策来降低。

### 5.3 样本设计与选取

| 环节 | 要点 |
| --- | --- |
| 确定样本规模（控制测试） | 可接受的**信赖过度风险**越低、可容忍偏差率越低、预计总体偏差率越高 → 样本越大；业务量很大时**总体规模影响可忽略** |
| 确定样本规模（细节测试） | 可接受的**误受风险**越低、可容忍错报越低、预计总体错报越高、总体变异性越大 → 样本越大；可按「总体账面金额 × 保证系数 ÷ 可容忍错报」公式法或分层后确定 |
| 选样方法 | 简单随机选样、系统选样（须防周期性偏差）、随意选样（**不能用于统计抽样**）、分层、货币单元抽样（PPS／MUS） |
| 分层 | 降低每一层变异性、提高效率；适合细节测试，可对不同风险的层采用不同程序 |
| 货币单元抽样 | 以货币单元为抽样单元，项目被选取概率与其金额成正比，适合测试**高估**；不适合测试低估或负余额、零余额 |

### 5.4 评价样本结果

- **控制测试**：计算样本偏差率并推断总体偏差率，与可容忍偏差率比较；须调查偏差的**性质与原因**，不能只看比率；若认为控制不可依赖，应改为主要依赖实质性程序。
- **细节测试**：根据样本错报推断总体错报，与可容忍错报比较；若推断错报接近或超过可容忍错报，**不能接受该总体**，须要求管理层更正、扩大程序或考虑意见类型。
- 无论样本结果是否表明错报总额超过可容忍错报，注册会计师都应当要求管理层**记录已发现的事实错报**（明显微小的除外）。
- 对未测试的项目（如选取特定项目之外的部分）仍须评价其可能存在的错报风险，不能默认「没问题」。

## 第 6 章 审计计划

### 6.1 初步业务活动

在**审计业务开始前**，注册会计师应当开展三项初步业务活动：

| 序号 | 内容 | 目的 |
| --- | --- | --- |
| ① | 针对保持客户关系和具体审计业务实施相应的质量管理程序 | 确认具备胜任能力、资源与时间，客户诚信可接受 |
| ② | 评价遵守相关职业道德要求（**含独立性**）的情况 | 识别并处置利益冲突与独立性威胁 |
| ③ | 就审计业务约定条款与被审计单位达成一致意见 | 按第 1111 号准则签订或修改业务约定书 |

**执行审计工作的前提**是管理层**认可并理解**其承担的责任：按适用编制基础编制财务报表（含公允列报与披露）、设计执行维护必要的内部控制、向注册会计师提供必要的工作条件（含**不受限制地接触**其认为必要的内部人员与资料、允许获取额外信息、允许与治理层无限制沟通）。

::: danger 易错 · 管理层不认可责任的后果
若管理层不认可其责任，或**不同意提供书面声明**（第 1341 号准则），注册会计师将视为**不能获取充分、适当的审计证据**，承接此类审计业务是不恰当的（法律法规另有规定的除外）。这不是「多要一份声明就好」的程序瑕疵，而是直接影响能否承接。
:::

业务约定书应包括：财务报表审计的目标与范围、注册会计师的责任、管理层的责任、指出编制基础、拟出具报告的预期形式与内容（必要时说明可能与实际不同），以及关于审计固有限制与内部审计、专家利用、前任注册会计师沟通等条款。**连续审计**时仍须评价是否需要修订条款并重新签订。

### 6.2 总体审计策略与具体审计计划

| 层次 | 内容 |
| --- | --- |
| 总体审计策略 | ①确定审计业务的特征以界定**审计范围**；②明确审计业务的**报告目标**，计划时间安排与所需沟通的性质；③根据职业判断确定**审计方向**（重要性、重大错报风险较高领域、内控有效性评价、重大变化）；④考虑初步业务活动结果、以往经验，确定执行业务所需**资源**的性质、时间安排和范围 |
| 具体审计计划 | 比总体策略更详细：①**风险评估程序**（了解单位及其环境、编制基础、内控体系各要素，识别评估重大错报风险）；②**进一步审计程序**（性质、时间安排、范围）；③其他审计程序（期后事项、书面声明、关联方、持续经营等） |

计划是**持续、动态、不断修正**的过程，贯穿整个审计，而非一次性的期初文件；项目合伙人与项目组关键成员应当参与计划与讨论，并把计划的重大修改及其理由记录于底稿。

### 6.3 重要性

| 层次 | 定义与应用 |
| --- | --- |
| 财务报表整体重要性 | 制定总体审计策略时确定；常用「选定基准 × 百分比」，基准选择考虑使用者关注的项目、报表要素、被审计单位性质与所处生命周期、融资方式、波动性 |
| 特定交易类别、账户余额或披露的重要性水平 | 当某些特定类别的错报虽低于整体重要性，但合理预期将影响使用者经济决策时，须确定一个或多个较低金额 |
| 实际执行的重要性 | **低于**整体重要性，旨在使未更正与未发现错报的**汇总数**超过整体重要性的可能性降至适当低水平；风险越高取值越低（教材示例：以整体重要性的 50% 作为营业收入项目的实际执行重要性） |
| 明显微小错报临界值 | 低于该金额的错报**不需要累积**；「明显微小」**不等同于「不重大」**，数量级远小于重要性；若不确定是否明显微小，就不能视为明显微小 |

::: tip 补充 · 别把经验百分比当硬性结论
准则**未规定**实际执行重要性必须取整体重要性的某个固定区间，也未规定明显微小错报必须按某个百分比计算；二者都是**职业判断**的结果，取决于风险、以前年度错报、内控有效性与管理层偏向等因素。答题时若题目要求计算，以题目给出的比例为准；若问「应当如何确定」，回答「职业判断＋考虑风险」而非背诵区间。
:::

**审计过程中应当修改重要性**的情形：审计过程中情况发生重大变化、获取了新信息、通过实施进一步程序对被审计单位及其经营的了解发生变化。修改后须重新评价已实施程序的充分性，并考虑对审计意见的影响。

错报按来源分为**事实错报**（毋庸置疑）、**判断错报**（管理层与注册会计师对会计估计、政策选择判断不一致）、**推断错报**（由审计抽样推断出的总体错报）；三类均须累积（明显微小的除外）。

## 第 7 章 风险评估

### 7.1 风险评估程序与信息来源

**应当实施**的风险评估程序：①**询问**管理层和被审计单位内部其他合适人员（不同层级、不同部门，含内部审计人员、治理层）；②**分析程序**；③**观察和检查**（经营场所、厂房设备、文件记录、内部控制手册、报告、管理层与治理层会议纪要）。

::: danger 易错 · 证据的无偏性
设计和实施风险评估程序时，**不应当偏向于获取佐证性的审计证据，也不应当排斥相互矛盾的审计证据**。风险评估程序本身**不足以**为发表审计意见提供充分、适当的审计证据，必须由其引出进一步审计程序。
:::

应当了解的三个方面：①被审计单位及其环境（行业状况、法律环境与监管环境、性质、目标战略及相关经营风险、财务业绩的衡量与评价）；②适用的**财务报告编制基础**（含会计政策选择与变更、披露要求）；③**内部控制体系各要素**。三个方面相互关联，须综合考虑，并用职业判断确定了解的程度。

**项目组内部讨论**：项目合伙人和项目组其他关键成员应当讨论财务报表发生重大错报（尤其因**舞弊**导致）的可能性，强调在整个审计过程中保持职业怀疑；项目合伙人应确定向未参与讨论的成员通报哪些事项。需要信息技术或其他特殊技能时，专家也可参与讨论。

### 7.2 内部控制体系各要素

| 要素 | 了解重点 |
| --- | --- |
| 控制环境 | 治理与管理职能、诚信与道德价值、对胜任能力的重视、治理层参与、管理层的理念与经营风格、组织结构与权责划分、人力资源政策 |
| 风险评估过程 | 被审计单位如何识别经营风险、估计重要性、评估发生可能性并决定应对措施 |
| 与财务报告相关的信息系统与沟通 | 交易如何发起、记录、处理与报告；重大事项的沟通渠道；财务报表编制流程 |
| 控制活动 | 授权与批准、核对与调节、复核、职责分离、绩效指标、信息处理控制（一般控制与应用控制） |
| 对控制的监督 | 持续监督、单独评价、内部审计与缺陷报告机制 |

::: tip 「了解」与「测试」的区别
**了解内部控制**评价的是控制的**设计是否适当、是否已得到执行**（只需少量样本甚至穿行测试）；**控制测试**评价的是控制在**整个期间运行的有效性**（需要足够样本）。了解了控制不等于测试了控制，不能据此直接减少实质性程序。
:::

### 7.3 识别与评估重大错报风险

识别与评估应在**财务报表层次**和**各类交易、账户余额及披露的认定层次**分别进行，并确定：

| 特殊情形 | 处理 |
| --- | --- |
| **特别风险** | 由舞弊导致的风险、管理层**凌驾于控制之上**的风险、异常或超出正常经营过程的重大关联方交易、涉及高度不确定性的会计估计、重大非常规交易；须评价相关控制的**设计并确定是否得到执行**，拟依赖时实施控制测试 |
| **仅通过实质性程序无法应对的风险** | 常见于高度自动化、日常交易大量依赖信息系统且无人工干预的情形；此时**必须实施控制测试**，否则无法获取充分适当证据 |
| 管理层凌驾于控制之上 | 属**特别风险**，无论以往经验如何都应当实施：测试日常及期末**会计分录和其他调整**、复核会计估计是否存在偏向、评价异常重大交易的商业理由 |

::: danger 易错 · 特别风险不能只靠实质性程序
「特别风险只要多做细节测试即可」是错的：特别风险须专门评价相关控制，且**必须实施实质性程序**；若属于仅通过实质性程序无法应对的风险，还**必须实施控制测试**。另外，风险评估是持续过程，获取新证据后应更新评估并相应修改计划的程序。
:::

## 第 8 章 风险应对

### 8.1 财务报表层次重大错报风险的总体应对措施

| 措施 | 说明 |
| --- | --- |
| 强调职业怀疑 | 向项目组强调在收集和评价证据时保持职业怀疑的必要性 |
| 人员配置 | 指派更有经验或具有特殊技能的审计人员，或利用专家工作 |
| 督导复核 | 对指导、监督项目组成员并复核其工作的性质、时间安排和范围作出调整 |
| 不可预见性 | 在选择进一步审计程序时融入更多不可预见因素 |
| 总体修改 | 对拟实施程序的**性质、时间安排和范围**作总体修改，如更多在期末而非期中实施、扩大范围、获取更具说服力的证据 |

增加不可预见性的典型做法：对**未事先通知**的盘点地点实施存货监盘（但不告知具体程序内容）、改变函证日期（提前或推迟截止日）、测试以前未曾函证过的**零余额、负余额或低于以往设定金额**的账户、对关联方销售追加程序、使用计算机辅助审计技术复核销售及客户账户、向以前未函证的供应商直接函证应付账款。

### 8.2 认定层次的进一步审计程序

三者中**性质最重要**，且性质、时间安排和范围都应当与评估的认定层次风险具备**明确的对应关系**。

| 维度 | 选择 |
| --- | --- |
| 性质 | 控制测试／实质性程序、细节测试／实质性分析程序；风险越高，程序越应具有针对性、证据越应具说服力 |
| 时间安排 | 期中或期末；风险越高越倾向于**期末或接近期末**实施 |
| 范围 | 样本量、观察次数、地点数量；风险越高范围越大 |

### 8.3 控制测试

**应当实施控制测试**的两种情形：①在**拟信赖**控制运行有效性的情况下（预期内部控制运行有效，拟据此减少实质性程序）；②**仅实施实质性程序不能提供充分、适当证据**时（必须实施）。若认为测试控制不符合**成本效益原则**，可不拟信赖控制、主要依赖实质性程序，但须始终考虑「缺乏控制时，仅靠实质性程序能否获取充分适当证据」。

| 要点 | 结论 |
| --- | --- |
| 测试对象 | 控制在**整个拟信赖期间**的运行有效性，而非某一时点 |
| 证据来源 | 询问（不足以单独证明）、观察、检查、重新执行；组合使用 |
| 期中测试 | 若仅在期中测试，须获取**剩余期间**控制运行情况的补充证据，并考虑期中后控制是否发生变化 |
| 利用以前年度证据 | 控制自上次测试后**未发生变化**且**不属于为减轻特别风险而设计的控制**时，可运用职业判断确定是否在本期测试及测试间隔，但**每三年至少测试一次**；每次审计仍须从中选取**足够数量**的控制测试，不得把全部拟信赖控制的测试集中于一次审计而在之后两次不测试。旨在减轻**特别风险**的控制**不得依赖以前年度证据**，每年都须在本期测试 |
| 自动化控制 | 若信息技术**一般控制**有效、程序未发生变更，自动化控制具有一贯性，可在证明其一贯运行后缩小测试范围（基准比较策略） |

::: danger 易错 · 一般控制无效时的连锁结论
若信息技术一般控制存在缺陷，注册会计师**不能信赖**依赖该系统的自动化编辑检查、自动过账等应用控制按设计发挥作用——此时不能靠「多测几个应用控制样本」补救，应转向实质性程序。
:::

### 8.4 实质性程序

**无论评估的重大错报风险结果如何**，注册会计师都应当针对**所有重大类别的交易、账户余额和披露**实施实质性程序。它包括：①对各类交易、账户余额和披露的**细节测试**；②**实质性分析程序**。

| 情形 | 要求 |
| --- | --- |
| 特别风险 | 应当实施实质性程序，且程序须**专门应对**该风险；仅实施实质性分析程序通常不足，应结合细节测试 |
| 在期中实施 | 需对剩余期间实施进一步实质性程序或结合控制测试，使风险降至可接受水平 |
| 管理层不可信赖 | 不能仅依赖管理层声明、内部生成证据，应转向外部证据 |
| 小型被审计单位 | 可能缺少可识别的控制活动，方案以实质性程序为主，但仍须考虑「仅靠实质性程序能否获取充分适当证据」 |

## 第 9 章 信息技术对审计的影响

### 9.1 信息技术带来的变化与风险

自动化系统以程序完成交易的创建、记录、处理与报告，并把信息保存为电子数据，由此产生：①**审计线索改变**（处理逻辑与中间过程对用户不可见，传统经验难以移植）；②**权限与数据安全**（安全控制无效会增加非授权访问、数据被篡改的风险）；③**数据丢失或无法访问**（系统瘫痪、备份缺失）；④大量交易环境下用户无法识别并更正处理错误。

### 9.2 三类控制

| 类别 | 内容 | 审计意义 |
| --- | --- | --- |
| **信息技术一般控制** | 保证信息系统安全、对整个信息系统及外部环境实施的控制：程序开发、程序变更、程序和数据访问、计算机运行 | 是**自动化信息处理控制**可靠的前提；一般控制无效，则不能信赖自动化应用控制 |
| **信息处理控制（应用控制）** | 在业务流程层面嵌入系统的自动化或半自动化控制，如编辑检查、科目映射、顺序编号检查、合理性校验、异常报告 | 需与一般控制一并评价；可借助「一贯性」减少测试样本 |
| **公司层面信息技术控制** | IT 治理、IT 战略与组织、风险与合规管理、管理层对 IT 的监督 | 影响整体控制环境和 IT 风险偏好 |

注册会计师应当**清楚记录**信息技术一般控制与关键自动化信息处理控制、与公司层面信息技术控制之间的关系，否则无法说明为何可以信赖自动化控制。

### 9.3 计算机辅助审计技术与数据分析

计算机辅助审计技术（CAAT）用于：重新计算与重新执行、抽查与全量测试、异常交易筛选、账龄分析表准确性验证、系统生成报告的可靠性验证（须评价报告所用数据的完整性与准确性）。

**数据分析**在风险评估、实质性程序与总体复核三个阶段均可使用，典型步骤为：明确目标与所需数据 → 获取并验证数据的完整性与可靠性 → 建立模型／期望值 → 执行分析并识别异常 → 调查异常并形成审计结论。使用电子表格时须评价其公式、版本与变更控制，否则结果不可靠。

### 9.4 不同信息技术环境与舞弊风险

对商业软件与自行研发系统的复杂程度评估重点不同：商业软件看系统复杂程度、实施与运行所需的配置与接口、供应商支持；自研系统看架构复杂度、距上一次系统架构变更的时间、开发文档与变更管理、人员依赖。

运用信息技术识别舞弊风险的典型手段：分析日志与权限分配、筛查异常时段或非授权用户的会计分录、识别与关联方或异常账户的资金往来、比对交易数据与业务数据的不一致。**数据分析发现的是异常，不是舞弊结论**，仍须实施进一步程序取证。

## 第 10 章 销售与收款循环审计

### 10.1 主要业务活动、单据与关键控制

| 业务活动 | 关键单据 | 关键控制 |
| --- | --- | --- |
| 接受客户订购单 | 客户订购单、销售单 | 销售单须经**授权审批**（赊销信用须由信用部门批准） |
| 批准赊销信用 | 信用审批表 | 信用额度与账龄监控；不得由销售人员自行批准 |
| 按销售单供货、装运 | 发运凭证、装箱单 | 发货须凭经批准的销售单；发运凭证**连续编号** |
| 向客户开具账单 | 销售发票、价目表 | 销售价格、条件、运费、折扣**必须经审批**；发票内容与销售单、发运凭证一致 |
| 记录销售与收款 | 收入／应收账款明细账、日记账 | 主营业务收入和应收账款记账人员**不得经手货币资金**；销售人员避免接触销货现款 |
| 销售退回、折扣折让 | 贷项通知单 | 须经授权审批并附验收证明 |
| 坏账核销与计提 | 坏账核销审批表、减值测算表 | 核销须经适当审批；减值估计由**管理层复核和批准** |
| 应收票据 | 票据登记簿 | 取得和贴现须由**保管票据以外的主管人员**书面批准 |

::: danger 易错 · 职责分离
「企业应当分别设立办理销售、发货、收款的部门（或岗位）」是销售与收款循环最基本的控制；若同一人既记账又经手货币资金，或销售与收款由一人办理，直接影响**发生**与**完整性**认定的可信赖程度，注册会计师不能依赖相关控制。
:::

### 10.2 重大错报风险

营业收入**发生**（虚构收入、提前确认）、**完整性**（少记、隐瞒）、**截止**（跨期）、**准确性**（折扣、退货、可变对价）；应收账款**存在**与**计价和分摊**（坏账准备计提不足）；关联方交易与异常大额交易；合同资产与合同负债的列报。

### 10.3 营业收入与应收账款的实质性程序

| 程序 | 要点 |
| --- | --- |
| 明细表核对 | 获取／编制主营业务收入、应收账款明细表，复核加计正确并与总账、明细账合计数核对相符 |
| 分析程序 | 本期与上期、月度／分产品毛利率波动、收入与销量／产能／税费／运费的匹配、与行业数据比较 |
| 检查原始凭证 | 核对销售合同、客户订单、销售发票、发运凭证、客户签收／验收记录，评价**收入确认时点**；**通常不能将开发票日期作为收入确认日期** |
| 双向追查 | 从发运凭证追查至明细账（查**完整性**）；从明细账追查至发运凭证与发票（查**发生**）。仅从账簿追至凭证只能发现多记，无法发现漏记 |
| 截止测试 | 检查资产负债表日前后若干天的发运与开票记录，复核资产负债表日前后的销售和发货水平是否异常，关注开票日早于或晚于收入可确认日的情形 |
| 函证 | 结合应收账款／合同资产函证，**选择客户函证本期销售额**；不函证须在底稿说明理由 |
| 退回与折让 | 检查期后销售退回、折扣与折让；附有质量保证条款的销售须评价该质量保证是否构成**单项履约义务** |
| 期后事项 | 检查有无未取得客户认可、期后大额退回或款项长期未收回的情况 |
| 坏账准备 | 复核账龄分析表、评价预期信用损失模型与假设、检查核销审批、检查期后回款 |

::: tip 补充 · 延伸检查程序
若识别出**收入真实性存在重大异常情况**且通过常规程序无法获取充分适当证据，注册会计师应考虑实施「延伸检查」：访谈上下游客户与供应商、实地走访经营场所、核查物流与资金流、查询工商／海关／税务等外部信息。设计时须充分考虑被审计单位与被访谈对象**串通舞弊**的可能性，程序的性质、时间安排和范围须与评估的风险对应。若延伸检查必要但受条件限制无法实施，或实施后仍不足以获取充分适当证据，应当考虑**审计范围是否受限**及其对意见类型的影响，或解除业务约定。
:::

## 第 11 章 采购与付款循环审计

### 11.1 业务活动与关键控制

请购（请购单）→ 订购（订购单，供应商选择与价格须审批）→ 验收（验收单，**连续编号**，由独立于采购与仓储的部门编制）→ 储存 → 确认与记录负债／资产（**三单匹配**：订购单、验收单、卖方发票）→ 审批付款（付款凭单）→ 支付与记录（出纳执行、会计记账）。不相容职务须分离：请购与审批、采购与验收、付款审批与执行、记账与出纳。

### 11.2 重大错报风险与审计重心

本循环的核心风险是**低估**：少计应付账款、费用或负债，隐瞒未入账采购；此外还有虚构采购、预付款长期挂账、固定资产与在建工程资本化不当、关联方交易未披露。

::: danger 易错 · 完整性方向
应付账款审计的重点是**完整性**，不是存在。从应付账款明细账追查至凭证只能查出「多记」，查不出「未入账负债」；必须从**原始凭证（验收单、供应商发票、期后付款记录）追查至明细账**。
:::

### 11.3 查找未入账负债的实质性程序

| 程序 | 要点 |
| --- | --- |
| 期后付款检查 | 检查资产负债表日**后若干天**的付款凭证、银行对账单与现金支出，追查至对应的验收单与应付账款记录，看是否应归属于本期 |
| 未匹配单据 | 检查期末已验收但尚未收到发票、或已收到发票但未入账的**未匹配凭证**，关注暂估应付账款 |
| 供应商函证 | 向主要供应商函证余额，且应包含**余额较小甚至为零**但本期交易量大的供应商——从询证对象中更容易发现未入账负债 |
| 明细表核对与分析 | 复核加计并与总账核对；分析应付账款周转率、与存货及采购额的匹配、长期挂账与**借方余额**（可能需重分类为预付账款） |
| 固定资产与在建工程 | 检查权属文件、本期增减的授权与验收、折旧政策与计算的一致性、减值迹象、**在建工程达到预定可使用状态的转固时点**与利息资本化 |
| 关联方与异常交易 | 检查大额或异常供应商的工商背景、交易商业理由与定价公允性 |

实务提示：控制测试与实质性程序可结合设计，检查某一凭证时争取一次完成对该凭证的全部相关测试，避免重复；但这**不意味着**审计实务可以省略某一类必要程序。

## 第 12 章 生产与存货循环审计

### 12.1 业务活动与关键控制

计划和安排生产（生产通知单）→ 发出原材料（**领料单须经生产主管批准**，仓库管理员凭批准后的领料单发料）→ 生产产品（产量与工时记录）→ 核算产品成本（材料／人工／制造费用分配表、成本计算单）→ 储存产成品（入库单，装运须持经核准的发运凭证）→ 发出产成品（出库单）→ 盘点与减值。

| 控制 | 要求 |
| --- | --- |
| 职责分离 | 验收、仓储、生产、财务相互分离；**每一组盘点人员应包括仓储部门以外的其他部门人员**，不能由负责保管存货的人员单独盘点 |
| 盘盈盘亏 | 提出账务调整建议，经仓储经理、生产经理、财务经理和总经理**复核批准**后入账 |
| 货龄分析 | 定期编制**存货货龄分析表**，由管理人员复核以确定滞销存货与跌价风险 |
| 成本制度 | 建立健全成本会计制度，将生产控制与成本核算结合，成本分配方法一致且有复核 |

### 12.2 重大错报风险与存货监盘

存货领域是**财务舞弊易发领域**；常见风险：虚构存货（存在）、漏记（完整性）、跌价准备计提不充分（**准确性、计价和分摊**）、成本归集与分摊错误、期末截止错误、残次冷背存货未识别。

| 监盘要点 | 结论 |
| --- | --- |
| 是否必须 | **应当实施**存货监盘，除非**不可行**（如存放地点对注册会计师安全构成威胁、存货性质特殊无法清点）。**不得以检查成本高、难以实施为由不实施** |
| 不可行时 | 实施**替代程序**（检查期后出售或使用记录、检查采购与生产记录、函证第三方保管）；若仍不能获取充分适当证据，考虑对意见类型的影响 |
| 监盘内容 | 评价管理层的盘点指令与程序 → **观察**盘点执行 → **检查**存货 → 实施**双向抽盘**（盘点表→实物查存在；实物→盘点表查完整性） |
| 非资产负债表日盘点 | 实施倒推／前推程序，检查盘点日至资产负债表日之间的**出入库记录** |
| 第三方保管 | 向第三方**函证**或亲自／委托监盘；不能仅凭被审计单位提供的确认函 |
| 专家 | 存货容易辨认、数量容易清点则**无需专家**；特殊存货（矿石、化工、珠宝）可利用专家，但**不减轻注册会计师的责任** |
| 计价与截止 | 测试单位成本与计价方法一致性、复核可变现净值与跌价准备、抽取期末前后入库单／出库单做**截止测试** |

::: tip 与控制测试的关系
存货监盘是证实「**存在**」认定不可替代的实质性程序；即使控制测试结果显示存货控制「拟获取保证程度」为高，也不能据此取消监盘。相反，若存货相关控制薄弱，底稿中「拟从控制测试中获取的保证程度」应显示为「无」，方案转向实质性程序为主。
:::

## 第 13 章 货币资金审计

### 13.1 内部控制共同要求

货币资金**流动性最强**，是财务舞弊易发高发领域。企业通常应当共同遵循：①建立**岗位责任制**（不相容职务分离，出纳不得兼任稽核、会计档案保管与收入费用债权债务账目登记）；②严格**授权审批**（审批人在授权范围内审批、不得越权，对不符合规定的支付申请**拒绝批准**）；③按程序办理支付（申请 → 审批 → **财务部门再次复核** → 出纳付款）；④票据与**印章分开专人保管**；⑤由**会计主管复核**银行存款余额调节表、库存票据盘点表。

### 13.2 重大错报风险

虚构银行存款或资金被关联方占用、未入账收支与账外资金、挪用与「蚂蚁搬家」式转出、**存贷双高**、定期存款质押或受限资金未披露、未达账项长期挂账、外币折算与利息收入异常。

### 13.3 实质性程序

| 程序 | 要点 |
| --- | --- |
| **库存现金监盘** | 突击盘点，宜在营业前或营业终了；由出纳盘点、注册会计师**监盘**并编制现金盘点表；同时检查有无未入账借条、白条抵库 |
| **银行函证** | 向**本期所有存过款的银行**（含零余额、本期已注销账户）函证存款、借款、担保质押、票据、未决诉讼等；注册会计师控制发函与回函全过程，评价回函可靠性 |
| 银行存款余额调节表 | 取得并检查调节表；由注册会计师**自行编制或重新计算**更可靠；逐项核实未达账项真实性、期后入账情况，重点追查长期未达账项与「已收未入账」 |
| 银行对账单 | 检查**原件**，必要时亲自到银行取得或直接从银行电子系统获取，防止被篡改 |
| 大额资金流水 | 检查大额收支的对手方、商业理由与关联方关系；关注资金闭环、期后快速转出、与经营规模不匹配的往来 |
| 分析与披露 | 复核利息收入与存款规模的匹配、外币折算汇率、受限资金与质押披露、现金及现金等价物的列报 |
| 截止测试 | 抽取期末前后的收付款凭证与银行流水，检查是否记入正确期间 |

::: danger 易错 · 银行函证的「应当」
「银行存款余额小或账户已注销，就不必函证」是错的：函证范围取决于**本期是否发生过业务及相关重大错报风险**，而非余额大小；不函证须有充分证据表明项目不重要且风险很低，并在底稿说明理由。此外，**仅凭银行对账单复印件**不能替代函证。
:::

## 第 14 章 对舞弊和法律法规的考虑

### 14.1 责任划分与舞弊风险因素

**治理层和管理层对防止或发现舞弊负有主要责任**；注册会计师的责任是，在按审计准则执行审计工作时，对财务报表整体是否**不存在由于舞弊或错误导致的重大错报获取合理保证**。舞弊与错误的区别在于导致财务报表发生错报的行为是**故意**还是非故意。

| 舞弊类型 | 典型手段 |
| --- | --- |
| 编制虚假财务报告 | 虚构收入、操纵会计估计与准备金、提前／延后确认、隐瞒负债与关联方、晦涩难懂的披露使事项无法被正确理解 |
| 侵占资产 | 挪用资金、虚构员工或供应商、盗取存货、篡改付款收款记录 |

舞弊风险因素通常归为三类：**动机或压力、机会、态度或借口**（舞弊三角）。识别时还应关注管理层或员工行为／生活方式的异常变化、管理层过度关注股价或业绩目标、内控缺陷、与异常交易对手的安排、售后责任与产品保证等线索。

::: danger 易错 · 期望差距
「注册会计师应当发现所有舞弊」「审计后不存在舞弊即说明审计质量合格」均错。由于审计固有限制（尤其管理层串通、伪造文件、管理层凌驾于控制之上），注册会计师**不能对财务报表整体不存在重大错报获取绝对保证**。
:::

### 14.2 必须实施的程序与特别风险

| 程序 | 要点 |
| --- | --- |
| 项目组讨论 | 项目组成员之间讨论财务报表因舞弊发生重大错报的可能性；项目合伙人确定向未参与讨论的成员通报哪些事项 |
| 询问 | 向管理层、治理层（除非治理层全部成员参与管理）、内部审计人员及内部其他人员询问是否知悉**任何影响财务报表的实际、涉嫌或指控的舞弊**；不同对象询问内容不同 |
| 评价舞弊风险 | 将识别出的舞弊风险**评估为特别风险**，评价相关控制的设计并确定是否得到执行 |
| **管理层凌驾于控制之上** | 属特别风险，无论以往经验如何都应当：①测试日常会计核算及期末编制财务报表过程中作出的**会计分录和其他调整**；②复核会计估计是否存在**偏向**；③对超出正常经营过程的异常重大交易评价其**商业理由** |
| 应对与评价 | 通过人员配置、职业怀疑、增加不可预见性作总体应对；针对认定层次调整程序性质、时间安排和范围；评价证据一致性并考虑对其他领域的影响 |

### 14.3 法律法规的考虑

| 类别 | 注册会计师责任 |
| --- | --- |
| 直接影响财务报表**金额和披露**的法律法规（如税法、财务报告编制基础相关法规） | 获取充分、适当的审计证据 |
| 其他法律法规（经营许可、环保、劳动、行业监管等） | 仅实施**有限程序**：向管理层和治理层（如适用）询问被审计单位是否遵守、检查与许可证颁发机构或监管机构的往来函件 |

识别出**违反或怀疑违反法律法规**时：了解该行为的性质及其发生的环境、获取进一步信息以评价对财务报表的可能影响 → 与适当层级管理层沟通，必要时与治理层沟通 → 评价对审计意见、其他报告责任的影响 → 考虑法律法规要求是否须向监管机构或执法机关报告、是否解除业务约定并完整记录。若因管理层或治理层**阻挠**而无法获取充分适当证据，应当根据审计范围受限程度发表**保留意见或无法表示意见**。

## 第 15 章 审计沟通

### 15.1 与治理层沟通

| 项目 | 要点 |
| --- | --- |
| 主要目的 | 就注册会计师与财务报表审计相关的责任、计划的审计范围和时间安排、审计中发现的重大问题，以及独立性等事项与治理层清晰沟通；明确各自责任、及时告知与治理层监督责任相关的事项 |
| 沟通对象 | 治理结构中的**适当人员**（如审计委员会、董事会）；治理结构未被清楚界定且被审计单位未指定对象时，应**尽早与审计委托人商定**；特殊事项应运用职业判断是否需与其他对象沟通 |
| 沟通内容 | ①注册会计师的责任（含 1504 号准则适用时沟通关键审计事项的责任、对哪些事项可能构成关键审计事项的初步判断）；②计划的审计范围和时间安排（含拟如何应对重大错报风险、重大审计判断）；③审计中发现的重大问题（重大错报风险较高的领域、特别风险、涉及管理层判断的重大不确定性、重大审计判断、意见分歧、重大困难、内控重大缺陷）；④**独立性**及相关防范措施；⑤补充事项 |
| 形式与时间 | 重大事项通常**书面沟通**；口头沟通须记录内容与对象；沟通应当**及时**，计划的审计范围和时间安排宜在审计早期沟通 |
| 补充事项 | 准则**不要求**注册会计师设计程序专门识别与治理层沟通的补充事项，但已注意到且按职业判断认为与治理层责任相关的，应予沟通 |

::: tip 沟通不转移责任
与治理层沟通既**不减轻**注册会计师按准则执行审计、形成意见的责任，也**不减轻**管理层编制财务报表、治理层监督财务报告过程的责任；治理层参与沟通不影响其监督职责。
:::

### 15.2 前任与后任注册会计师的沟通

| 环节 | 要求 |
| --- | --- |
| 时点 | **接受委托之前**，后任应当主动与前任沟通；这是必要程序，不能因客户不同意而省略 |
| 询问内容 | ①是否发现管理层存在**诚信**方面的问题；②前任与管理层在**重大会计、审计事项**上存在的意见分歧；③向治理层通报过的**内部控制重大缺陷**；④导致被审计单位**变更会计师事务所**的原因 |
| 前任答复 | 在**取得客户授权**后及时、充分答复；未获授权或法律法规禁止披露时，应告知后任其无法答复 |
| 后任评价 | 评价答复的充分性；**未获答复或答复不充分**时，应谨慎考虑是否接受委托，并考虑通过其他途径了解情况 |
| 接受委托后 | 可查阅前任审计工作底稿（是否允许由前任自主决定）；结合期初余额审计（第 18 章）评价对本期的影响 |
| 发现上期可能存在重大错报 | 后任应提请被审计单位告知前任并安排**三方会谈**；若前任无法参加或问题未解决，考虑对本期意见、解除业务约定及向监管机构咨询 |

## 第 16 章 注册会计师利用他人工作

### 16.1 利用内部审计人员的工作

利用的前提：内部审计职能在被审计单位中具有**客观性**、执行人员具备**专业胜任能力**、采用**系统、规范的方法**（含质量控制）。**不得利用**的情形：内部审计活动与财务报表审计不相关、其客观性不足、或注册会计师认为利用内部审计工作不足以减少应实施的审计程序。

| 限制 | 说明 |
| --- | --- |
| 主观性高的领域不宜利用 | 涉及重大判断、重大错报风险较高、会计估计与公允价值、舞弊风险评估、管理层凌驾等，通常应由注册会计师亲自实施 |
| 直接协助 | 在注册会计师的**指导、监督和复核**下可由内部审计人员提供直接协助，但不得让其承担管理层职责、作出重大判断，且须满足客观性与胜任能力要求 |
| 评价其工作 | 检查其计划与执行是否适当、工作底稿与报告是否充分、结论是否与其工作一致、异常事项是否得到妥善处理 |
| 责任不变 | 注册会计师对**发表审计意见**以及确定审计程序的性质、时间安排和范围**独自承担责任**，利用内部审计工作**不能减轻**该责任 |

### 16.2 利用专家的工作

专家指在**会计或审计以外**领域具有专长的个人或组织（估值、精算、法律、工程、地质、环境、IT 等），分为注册会计师的专家与管理层的专家。

| 步骤 | 要点 |
| --- | --- |
| 决定是否利用 | 考虑事项的性质与重要性、重大错报风险、所需专长、可获得的其他证据 |
| 评价专家 | 了解其专长领域，评价**胜任能力、专业素质和客观性**；管理层专家的客观性须特别评价 |
| 了解其工作 | 就工作范围、目标、各自责任、沟通方式与时间、保密要求达成一致（通常书面） |
| 评价其工作 | 评价所使用**源数据**的相关性完整性与可靠性、所用**假设与方法**的适当性及与编制基础的一致性、结果的合理性及与其他审计证据的一致性 |
| 结论 | 若专家工作不足以获取充分适当证据，追加程序或考虑对意见的影响；**不因利用专家而减轻注册会计师责任** |

审计报告**一般不提及**专家的工作；法律法规要求提及时，须说明该提及不减轻注册会计师的责任。发表**非无保留意见**时，若指明原因涉及专家工作，可在形成意见的基础部分说明，但须先取得专家同意或按法律法规处理。

## 第 17 章 对集团财务报表审计的特殊考虑

### 17.1 基本概念与责任

| 概念 | 要点 |
| --- | --- |
| 集团／组成部分 | 集团至少拥有一个以上组成部分；子公司、合营联营、分支机构、某一产品或劳务（或一组）、某一地区均可视为组成部分 |
| 重要组成部分 | **因规模**：超过集团项目组选定基准的某一比例（教材示例为 **15%**）；**因风险**：因特定性质或情况，很可能包含导致集团财务报表发生重大错报的风险 |
| 集团项目组 | 对集团财务报表审计及据此出具报告负责；**集团项目合伙人及其所在事务所对集团审计意见负全部责任，不因利用组成部分注册会计师的工作而减轻**，并对项目质量承担总体责任 |
| 组成部分注册会计师 | 基于集团项目组的要求，对组成部分财务信息执行相关工作并报告；其独立性、胜任能力、所处监管环境与沟通能力均须由集团项目组了解 |

### 17.2 重要性与应对措施

| 层次 | 规则 |
| --- | --- |
| 集团财务报表整体重要性 | 由集团项目组确定，用于形成集团审计意见 |
| 组成部分重要性 | **由集团项目组为各重要组成部分确定**，且必须**低于**集团整体重要性，使各组成部分未更正与未发现错报汇总后不超过集团整体重要性；**不得由组成部分注册会计师自行确定** |
| 实际执行的重要性、明显微小临界值 | 同样由集团项目组按组成部分情况确定 |
| 仅实施集团层面分析程序的不重要组成部分 | 也需设定重要性，以判断分析程序能否提供充分适当证据 |

| 组成部分类型 | 应当实施的工作 |
| --- | --- |
| 因**规模**重要的组成部分 | 使用**该组成部分重要性**，对组成部分财务信息实施审计 |
| 因**风险**重要的组成部分 | 审计与该重大错报风险相关的特定账户余额、交易类别或披露；或针对该风险实施特定的审计程序 |
| 不重要的组成部分 | 在**集团层面实施分析程序**即可（除非识别出导致集团层面重大错报风险的迹象） |

### 17.3 合并过程、沟通与证据评价

集团项目组应当了解集团层面控制与合并过程（含合并调整、重分类、内部交易抵销、外币折算、统一会计政策），测试合并过程并评价组成部分注册会计师就**期后事项**与合并调整所通报的信息。

与组成部分注册会计师沟通须明确：拟执行工作的性质范围与时间、独立性要求、适用的准则与重要性、需通报的事项（舞弊、内控缺陷、未更正错报、审计范围受限）及沟通时限。

::: danger 易错 · 证据不足的后果
集团项目组应当**评价**组成部分注册会计师工作的充分性；若认为工作不充分，须确定需要实施哪些**追加程序**（可亲自实施或要求组成部分注册会计师实施）。若仍**未能获取充分、适当的审计证据**作为形成集团审计意见的基础，集团项目合伙人应当评价该情况及未更正错报对**集团审计意见**的影响——不能因「问题出在组成部分」就只在局部反映。
:::

## 第 18 章 其他特殊项目审计

### 18.1 会计估计和相关披露

| 环节 | 要点 |
| --- | --- |
| 风险识别评估 | 了解编制基础对估计与披露的要求、管理层**如何识别**需要作出估计的事项、**如何作出**估计（方法、假设、数据、模型、专家、控制）、**估计不确定性**的程度、是否存在管理层偏向；不确定性高、复杂或主观性强的估计通常构成**特别风险** |
| 应对策略（三选一或组合） | ①测试**管理层如何作出**会计估计以及所依据的数据、假设与方法（利用截至审计报告日已发生的事项与证据）；②测试与会计估计相关的**控制运行有效性**；③作出注册会计师的**点估计或区间估计**并据以评价管理层估计（区间须足够窄） |
| 特别风险附加要求 | 评价相关控制的**设计并确定是否得到执行**、实施**实质性程序**、获取充分适当证据评价估计合理性 |
| 评价与声明 | 评价披露的充分性、估计对不确定性的敏感性、是否存在**管理层偏向**的迹象；获取关于重大会计估计的**书面声明** |

### 18.2 关联方审计

关联方关系与交易可能不按正常商业条款进行，且易被用于操纵财务报表，因此**识别本身就是目标**。

| 程序 | 要点 |
| --- | --- |
| 项目组讨论与询问 | 询问管理层关联方清单及其变化、当期关联方交易的性质与目的、为识别与披露关联方而建立的控制 |
| 检查记录与文件 | 股东会／董事会纪要、重大合同与协议、银行流水与大额资金往来、工商登记与股权结构、对外投资、担保与承诺、异常交易对手的背景 |
| 保持警觉 | 在检查重大交易或安排时，始终考虑是否存在**此前未识别或未披露**的关联方；**不能仅凭管理层声明或已实施常规程序就默认不存在** |
| 发现未披露关联方 | 立即追加程序识别关系与交易、重新评价舞弊风险及相关控制、与治理层沟通、评价对审计意见的影响 |
| 超出正常经营过程的重大关联方交易 | 检查合同或协议、评价**商业理由**（是否可能为虚构或减少错报）、评价是否经适当授权与批准、检查资金流与担保 |
| 书面声明 | 要求管理层（及治理层，如适用）书面声明已披露**全部**关联方关系与交易、已按编制基础作出恰当会计处理与披露 |

### 18.3 考虑持续经营假设

| 情形 | 对审计报告的影响 |
| --- | --- |
| 运用持续经营假设**适当**，但存在重大不确定性且财务报表已**充分披露** | 发表**无保留意见**，并在报告中增加以「**与持续经营相关的重大不确定性**」为标题的**单独部分**：提醒使用者关注附注披露，说明存在可能导致对持续经营能力产生重大疑虑的重大不确定性，并明确**该事项不影响发表的审计意见** |
| 存在重大不确定性但**未充分披露** | 根据重大性与广泛性发表**保留意见或否定意见** |
| 运用持续经营假设**不适当** | **否定意见** |
| 管理层拒绝作出评估、拒绝延长评估期间或拒绝提供相关书面声明 | 评价审计范围受限程度，考虑**保留／无法表示意见**，并与治理层沟通 |

风险评估至少应包括：识别是否存在导致对持续经营能力产生重大疑虑的事项或情况（财务、经营、其他方面），评价管理层的评估（涵盖期间**自财务报表日起不少于十二个月**）及其应对计划的可行性，实施追加程序（现金流量预测复核、借款协议与展期安排、期后事项、股东或第三方支持承诺），并考虑是否存在此前未识别的重大不确定性。

### 18.4 首次接受委托时对期初余额的审计

**目标**：①确定期初余额是否包含对本期财务报表产生重大影响的错报；②上期期末余额是否已正确结转至本期，或已按要求作出重述；③会计政策是否**一贯运用**或变更是否恰当处理与披露。

| 程序 | 说明 |
| --- | --- |
| 查阅前任底稿 | 在取得客户授权、评价前任独立性与专业胜任能力后查阅；前任是否允许由其自主决定 |
| 利用本期程序 | 本期收款情况可为期初应收账款的**存在**提供证据；本期对存货的测试可部分支持期初存货 |
| 专门程序 | 监盘部分存货并倒推至期初、测试期初固定资产原价与累计折旧、检查期初负债的期后结算、复核期初会计估计（减值、预计负债）的追溯 |
| 结论 | 若**不能获取**有关期初余额的充分适当证据 → 对本期财务报表发表**保留意见或无法表示意见**；若期初余额存在对本期产生重大影响的**错报**且未正确结转／披露 → **保留或否定意见** |
| 上期为非无保留意见 | 评价导致非无保留意见的事项是否已解决；若仍未解决且对本期财务报表重大或可能产生重大影响，应对**本期**财务报表发表非无保留意见 |

## 第 19 章 完成审计工作

### 19.1 累积与评价错报

注册会计师应当**累积**审计过程中识别出的错报，**除非错报明显微小**；并应及时将累积的所有错报（即超过明显微小临界值的）与**适当层级管理层**沟通，要求更正。适当层级管理层指有责任和权限对错报进行评价并采取必要行动的人员。

若管理层**拒绝更正**部分或全部错报，注册会计师应当了解其不更正的理由，并在评价未更正错报影响之前**重新评估重要性**，考虑错报单独或汇总起来对财务报表是否重大（定量＋定性）、以前年度未更正错报对本期的影响、以及错报对未来期间的潜在影响。

::: tip 与「明显微小」的边界
「明显微小」**不等同于「不重大」**，其数量级远小于重要性；若对某一错报是否明显微小存在任何不确定，就**不能**将其视为明显微小。定性重要的错报（如影响是否满足债务契约、影响盈亏临界点、涉及舞弊或关联方）即使金额很小，也不能仅因低于临界值而忽略。
:::

### 19.2 复核与意见分歧

审计工作的复核包括**项目组内部复核**（由经验较丰富的成员指导、监督和复核经验较缺乏成员的工作）与作为事务所质量管理措施实施的**项目质量复核**（如适用）。项目组内部、项目组与项目质量复核人员或提供咨询的其他人员之间就重大会计和审计事项存在的**意见分歧**，必须在得出结论并出具报告之前解决并完整记录。

### 19.3 期后事项的三个时段

| 时段 | 区间 | 注册会计师责任 |
| --- | --- | --- |
| 第一时段 | 财务报表日 → **审计报告日** | **主动识别**：应当设计和实施审计程序，获取充分适当证据，确定所有需调整或披露的事项均已识别；但**不需要**对之前已实施程序并已得出满意结论的事项追加程序 |
| 第二时段 | 审计报告日 → **财务报表报出日** | **被动识别**：审计报告日后**没有义务**针对财务报表实施任何审计程序；若知悉某事实，且该事实若在报告日已知悉可能导致修改财务报表或审计报告，须与管理层讨论、确定报表是否需要修改 |
| 第三时段 | 财务报表报出日之后 | **没有义务**实施任何审计程序；若知悉在审计报告日**已存在**的事实，仍须与管理层讨论并评价财务报表是否需要修改 |

第二时段的处理路径：管理层同意修改财务报表 → 实施必要程序并出具**新的审计报告**（新报告日期不得早于修改后财务报表的批准日，可增加强调事项段或其他事项段说明修改原因）；不同意修改且报告尚未提交 → 按非无保留意见处理或解除业务约定；报告已提交 → 通知治理层不要报出财务报表，必要时采取防止使用者信赖该报告的措施并征询法律意见。

::: danger 易错 · 审计报告日的条件
审计报告日**不应早于**注册会计师获取充分、适当审计证据（**包括管理层认可其对财务报表的责任且已批准财务报表的证据**）并在此基础上形成审计意见的日期；实务中审计报告日与**财务报表批准日**通常为同一日。同时，适用的**项目质量复核**也必须在项目合伙人签署报告之前完成——两个条件都要满足，不能只看其中一个。
:::

### 19.4 书面声明

书面声明是**必要的审计证据**，但**本身并不能**为财务报表任何特定认定提供充分、适当的审计证据。

| 要点 | 结论 |
| --- | --- |
| 签署时点 | 在管理层签署书面声明前，注册会计师**不能发表审计意见，也不能签署审计报告** |
| 日期 | 应当**尽量接近**对财务报表出具审计报告的日期，**但不得晚于**审计报告日 |
| 涵盖期间 | 应当涵盖审计报告针对的**所有财务报表和期间** |
| 内容 | 管理层责任（编制报表、内控、提供信息与不受限制接触）、财务报表编制与公允反映、已披露全部信息与交易、舞弊与涉嫌舞弊、违反或涉嫌违反法律法规、关联方关系与交易、**会计估计**、持续经营、期后事项、未更正错报等 |
| 可靠性存疑 | 若对其他证据的充分性或书面声明的可靠性有疑虑，须实施追加程序；若管理层**拒绝提供**针对某项必要事项的声明，且其他证据不足以支持，注册会计师**不能获取充分适当审计证据**，应考虑对审计意见的影响（通常为无法表示意见）或解除业务约定 |

## 第 20 章 审计报告

![审计意见类型判断与审计报告要素](/audit/au-report.svg)

### 20.1 形成审计意见

注册会计师应当评价根据审计证据得出的结论，确定是否已就财务报表整体**不存在由于舞弊或错误导致的重大错报**获取合理保证。评价内容包括：未更正错报单独或汇总是否重大、财务报表是否在所有重大方面按适用的财务报告编制基础编制（含**公允反映**）、会计政策的选择与运用是否恰当、会计估计是否合理、信息是否相关可靠可比可理解、披露是否充分、以及财务报表整体是否恰当列报。

### 20.2 非无保留意见的判断

| 导致非无保留意见的事项的性质 | 影响重大但不具有广泛性 | 影响重大且具有广泛性 |
| --- | --- | --- |
| 财务报表**存在重大错报** | **保留意见** | **否定意见** |
| **无法获取充分、适当的审计证据**（范围受限） | **保留意见** | **无法表示意见** |

**广泛性**指错报或可能存在的错报对财务报表的影响不限于特定要素、账户或项目；或虽限于特定项目但代表（或可能代表）财务报表的相当大部分；或就披露而言对使用者理解财务报表至关重要。判断顺序是先看**重大性**（定量通常以财务报表整体重要性为参考，同时作定性判断），再看**广泛性**。

::: danger 易错 · 三个高频错法
①「保留意见 = 有小问题」——错，保留意见针对的是**重大**事项，只是**不具广泛性**；②「强调事项段可以替代保留意见」——错，强调事项段**绝不能**代替应当发表的非无保留意见；③「无法表示意见时也可以沟通关键审计事项」——错，无法表示意见的报告中**不得**沟通关键审计事项。另外，若不能获取合理保证且保留意见不足以实现向预期使用者报告的目的，应当出具**无法表示意见**或在法律法规允许时解除业务约定。
:::

### 20.3 关键审计事项（第 1504 号）

| 要点 | 结论 |
| --- | --- |
| 适用 | 对**上市实体**财务报表审计（法律法规另有规定的从其规定） |
| 定义 | 注册会计师根据职业判断认为对**本期财务报表审计最为重要**的事项，从与治理层沟通的事项中选取 |
| 选取考虑 | 评估的重大错报风险较高领域或识别出的**特别风险**；涉及管理层判断的高度不确定性重大会计估计；当期重大交易或事项对审计的影响 |
| 沟通内容 | 说明该事项为何被认定为关键审计事项、在审计中**如何应对**（概述所实施程序的性质、时间安排与范围及结果，不逐条罗列），并可指向财务报表相关披露 |
| 边界 | 不是对个别事项单独发表意见，**不能替代**非无保留意见，**不能替代**管理层应作的披露，也不是对持续经营能力的保证 |
| 不沟通的情形 | 法律法规禁止公开披露，或在极罕见情形下沟通带来的负面后果超过公众利益好处（须记录理由）；**无法表示意见**时不沟通 |

### 20.4 强调事项段与其他事项段（第 1503 号）

| 段落 | 适用条件 | 指向 |
| --- | --- | --- |
| **强调事项段** | 该事项已在财务报表中**恰当列报或充分披露**，且对使用者理解财务报表至关重要 | 明确指出所强调的事项及其在报表中的披露位置；**不影响审计意见** |
| **其他事项段** | 该事项**未在财务报表中列报或披露**，但与使用者理解**审计工作、注册会计师责任或审计报告**相关 | 说明事项性质；不影响审计意见 |
| 「与持续经营相关的重大不确定性」 | 假设适当但存在重大不确定性且已充分披露 | 按第 1324 号单设**专门部分**，不属于强调事项段；明确说明该事项不影响审计意见 |

典型强调事项：重大诉讼或监管行动的未来结果存在不确定性、提前应用对财务报表有广泛影响的新会计准则、财务报表日后发生的重大事项、特大灾害对被审计单位财务状况的重大影响。

### 20.5 比较信息与其他信息

**比较信息**：若为对应数据，须评价上期比较信息是否与本期报表列报口径一致、会计政策是否一贯运用或变更是否已恰当处理与披露；上期财务报表由前任注册会计师审计或未经审计时，按准则在其他事项段说明；若上期导致非无保留意见的事项**仍未解决**且对本期重大，应对本期财务报表发表非无保留意见。

**其他信息**：指年度报告中包含的、除财务报表和审计报告以外的财务或非财务信息。注册会计师应当**阅读**其他信息并考虑其是否与财务报表或审计过程中了解到的情况存在重大不一致或似乎存在重大错报，但**不对其他信息发表意见或提供任何保证**。

| 情形 | 处理 |
| --- | --- |
| 其他信息存在重大错报、需修改**其他信息** | 管理层同意修改 → 在必要程序完成前不提交报告；不同意 → 与治理层沟通并要求更正，考虑在报告中说明该未更正错报、不提交报告或解除业务约定 |
| 需修改**财务报表**（说明是报表存在错报） | 按非无保留意见规则处理 |
| 报告日之后才取得部分或全部其他信息 | 及时阅读并按上述原则处理 |

::: tip 补充 · 结论隔离
**其他信息的重大错报不导致对财务报表发表非无保留意见**——财务报表本身不存在重大错报时，审计意见不因年报其他章节出错而改变。反过来，若为形成审计意见所需的信息在其他信息中被错误表述，则须评价其对财务报表的影响。
:::

## 第 21 章 审计工作底稿

### 21.1 目的与编制要求

审计工作底稿是注册会计师对**制定的审计计划、实施的审计程序、获取的相关审计证据以及得出的审计结论**作出的记录。编制要求的核心判据是：应当使**未曾接触该项审计工作的有经验的专业人员**能够清楚了解①实施审计程序的性质、时间安排和范围；②实施审计程序的结果和获取的审计证据；③审计中遇到的重大事项和就此得出的结论，以及作出的重大专业判断。

底稿还用于：便于项目组计划和执行审计、履行指导监督与复核的责任、证明按准则和法律法规计划执行了审计、便于项目质量复核与事务所质量管理体系的监控、便于监管检查、保留对未来审计具有持续重要意义的事项。

::: danger 易错 · 底稿不能代替什么
审计工作底稿**不能代替被审计单位的会计记录**；审计程序核对表、清单只是辅助工具，**不能代替**注册会计师针对具体情况作出的专业判断。草稿、错误文本、重复文件记录、已被取代的初步意见等**不直接构成审计结论和意见**的材料通常不予保留，但**函证程序底稿（询证函及回函、不符事项分析）与存货监盘底稿（盘点表、抽盘记录）必须完整归档**。
:::

### 21.2 归档、修改与保存

| 事项 | 规则 |
| --- | --- |
| **归档期限** | 审计工作底稿归档期限为**审计报告日后 60 天内**；未能完成审计业务的，为**审计业务中止后的 60 天内**；针对同一财务信息出具两个或多个不同报告的，视为**不同业务**分别归档 |
| 归档后的事务性整理 | 可加盖印章、签名、编制索引、删除或废弃被取代的草稿、对已归档底稿作交叉索引等 |
| 归档后修改或增加底稿 | 无论性质如何，均须记录①修改或增加的理由；②修改或增加的时间与人员、复核的时间与人员 |
| **保存期限** | 自**审计报告日**起至少保存 **10 年**；未能完成业务的，自**业务中止日**起至少保存 10 年；保存期届满前**不得删除或废弃**任何工作底稿 |
| 所有权与保密 | 底稿所有权属于**会计师事务所**；事务所须对其实施保密与访问控制；客户不当然有权查阅全部底稿，但监管检查、法律程序、行业检查等依法可以调阅 |

可持续信息鉴证等其他鉴证业务的工作底稿适用同类规则：归档期限为**鉴证报告日后 60 天内**（未完成业务为中止后 60 天内），自鉴证报告日／业务中止日起**至少保存 10 年**。

## 第 22 章 企业内部控制审计

### 22.1 概念与基准日

内部控制审计中，注册会计师对**财务报告内部控制的有效性**发表意见；对审计过程中注意到的**非财务报告内部控制的重大缺陷**，在内部控制审计报告中增加「**非财务报告内部控制重大缺陷描述段**」予以披露。

**内部控制审计基准日**是指评价内部控制在某一时日是否有效所涉及的基准日，也是被审计单位评价基准日，即**最近一个会计期间的截止日**。注册会计师**不可能**对企业内部控制在某个「期间段」内的有效性发表意见，只能对基准日这一**时点**的有效性发表意见；但为此必须获取内部控制在基准日之前**一段足够长的期间内**有效运行的证据。

::: tip 整合审计
内部控制审计与财务报表审计通常**有机整合**：控制测试所涵盖的期间应尽量与财务报表审计中拟依赖的控制测试期间一致，工作成果可相互利用。但两者**发表意见的对象不同**——一个针对财务报表，一个针对基准日财务报告内部控制的有效性——因此同一项控制缺陷对两份报告的影响须分别评价。
:::

### 22.2 自上而下的方法与测试控制有效性

自上而下的路径：**财务报表层次整体风险 → 企业层面控制 → 重大账户、列报及相关认定 → 业务流程／应用系统／交易层面的控制 → 识别拟测试的控制 → 测试设计与运行有效性**。

| 有效性 | 含义 | 缺陷类型 |
| --- | --- | --- |
| **设计有效性** | 控制的设计能否实现预期控制目标；控制是否针对相关认定、由适当人员执行 | **设计缺陷**：设计不适当，即使正常运行也难以实现控制目标 |
| **运行有效性** | 控制是否按设计意图运行，执行人员是否获得必要授权并具备胜任能力 | **运行缺陷**：设计适当但未按设计运行，或执行人员缺乏授权／胜任能力 |

测试方法为询问（不足以单独证明）、观察、检查与**重新执行**的组合；应当**在每一年度中测试内部控制**，**不得采用「每三年至少对控制测试一次」的做法**——自动化控制在满足特定条件下，才可采取与基准相比较的策略。信息技术一般控制是自动化应用控制可靠的前提；企业层面控制测试覆盖控制环境、风险评估、信息与沟通、监督、反舞弊与期末财务报告流程。

### 22.3 内部控制缺陷评价与沟通

| 等级 | 定义 |
| --- | --- |
| **重大缺陷** | 内部控制中存在的、可能导致**不能及时防止或发现并纠正财务报表重大错报**的一项控制缺陷或多项控制缺陷的组合 |
| **重要缺陷** | 严重程度**不如重大缺陷**，但足以引起负责监督被审计单位财务报告的人员关注 |
| **一般缺陷** | 除重大缺陷、重要缺陷之外的其他缺陷 |

评价时须考虑：缺陷导致错报的可能性、潜在错报的金额与性质、是否存在**补偿性控制**、多项缺陷的累积影响，以及缺陷与财务报表认定的关联。对**重大缺陷和重要缺陷**（含非财务报告内部的重大缺陷与重要缺陷），应当以**书面形式**与治理层和管理层沟通，且书面沟通应当在**出具内部控制审计报告之前**进行；若认为审计委员会和内部审计机构对内部控制的监督无效，应就此以书面形式**直接与董事会沟通**。

### 22.4 内部控制审计报告

| 情形 | 意见类型 |
| --- | --- |
| 财务报告内部控制在基准日按适用框架保持了**有效**的内部控制 | **无保留意见** |
| 存在一项或多项**重大缺陷** | **否定意见** |
| 审计范围受到限制，未能获取充分适当证据 | **无法表示意见**，并说明范围受限情况 |

报告中还应包含：管理层对内部控制的责任段、注册会计师责任段、内部控制**固有局限**的说明、非财务报告内部控制重大缺陷描述段（如适用）、基准日、事务所签名盖章与报告日期。

::: danger 易错 · 内控审计没有「保留意见」
内部控制审计中一旦识别出**重大缺陷**，结论就是**否定意见**，没有「重大但不具广泛性 → 保留意见」这一档；这是与财务报表审计报告最常被混淆的地方。此外，非财务报告内部控制的重大缺陷是**披露**事项，不改变对财务报告内部控制发表的审计意见。
:::

## 第 23 章 企业可持续信息鉴证

### 23.1 保证程度与业务要素

可持续信息鉴证的目的是获取充分、适当的**鉴证证据**，得出鉴证意见并出具鉴证报告，以增强可持续信息使用者对该信息的信赖程度。三方关系为鉴证者、责任方（管理层／治理层）与预期使用者；鉴证对象是可持续信息，标准是适用的**披露标准**。

| 维度 | 合理保证 | 有限保证 |
| --- | --- | --- |
| 风险 | 将鉴证业务风险降至**可接受的低水平** | 降至可接受水平，但**风险高于合理保证** |
| 结论方式 | **积极方式** | **消极方式** |
| 程序与证据 | 充分、多样 | 较为有限，以**询问和分析程序**为主 |
| 保证的意义 | 高水平 | 仍应提供**有意义的保证**，即很可能能够增强预期使用者的信赖程度 |

可以对全部可持续信息获取同一种保证程度，也可以**对部分信息获取合理保证、对另一部分获取有限保证**，但须在鉴证报告中清楚区分并说明。

### 23.2 承接、保持与计划

承接或保持须评价：是否具备相应**专业胜任能力与资源**（可持续信息常涉及环境、社会、治理等非财务专长）、管理层是否认可并理解其责任、**披露标准是否适当且为预期使用者可获取**、鉴证对象能否被识别与一致地计量或评价、是否存在重大的**范围限制**、以及职业道德与独立性要求能否满足。若管理层施加的范围限制将导致无法获取充分适当证据，且法律法规不允许解除，应考虑对鉴证结论的影响。

计划工作包括制定总体鉴证策略与具体计划、确定**重要性**（可持续信息须同时考虑定量与定性因素，某些信息虽金额不重大但对使用者决策重要）、项目组内部讨论与保持职业怀疑、决定是否利用专家及组成部分鉴证者。

### 23.3 风险评估与应对

风险评估须了解企业及其环境（含价值链、业务模式、可持续发展战略）、适用的披露标准、可持续信息的编制流程与相关控制（数据来源、计量方法、估计与假设、信息系统），并识别和评估重大错报风险（含舞弊风险）。典型的固有风险因素包括：计量方法与披露标准尚不成熟、数据来自价值链上下游或第三方、大量估计与前瞻性信息、主观判断与管理层偏向。

应对措施包括总体应对与进一步程序：询问、检查、观察、函证、重新计算、重新执行、分析程序、利用专家工作等；**有限保证下程序的性质、时间安排和范围明显更少**，但足以提供有意义的保证。无论何种保证程度，鉴证者在计划和执行业务时都应当保持职业怀疑。

### 23.4 完成鉴证工作与出具报告

完成阶段应当：评价已识别错报（含定性与披露错报）、评价期后事项、获取书面声明、复核工作底稿与评价证据的充分性适当性、解决意见分歧并形成鉴证结论。

| 报告要点 | 结论 |
| --- | --- |
| 结论表述 | 合理保证用积极方式，有限保证用消极方式；须与所适用的保证程度一致，并指明对应的信息范围 |
| 非无保留结论 | 存在重大错报（保留／否定）或无法获取充分适当证据（保留／无法表示结论）；按重大性与广泛性判断 |
| 书面声明 | 必要证据，但本身不充分；日期应当**尽量接近鉴证报告日但不得晚于**；声明内容应覆盖可持续信息报告日后发生的、按披露标准需调整或披露的事项 |
| 声明不足 | 若管理层拒绝提供且其他证据不足，须考虑无法表示结论或解除业务约定 |
| 底稿 | 归档为鉴证报告日后 **60 天内**；自鉴证报告日／业务中止日起**至少保存 10 年** |
| 质量管理 | 按事务所质量管理体系执行，符合条件时实施项目质量复核；鉴证业务同样受独立性与职业怀疑要求约束 |

## 第 24 章 会计师事务所业务质量管理

![质量管理体系、项目质量复核与独立性](/audit/au-quality.svg)

### 24.1 质量管理体系的目标与八要素

质量管理体系按《会计师事务所质量管理准则**第 5101 号——业务质量管理**》设计、实施和运行，在两方面提供**合理保证**：①事务所及其人员按照适用法律法规和职业准则履行职责并据此执行业务；②事务所和项目合伙人出具**适合具体情况**的业务报告。项目层面另按《中国注册会计师审计准则**第 1121 号——对财务报表审计实施的质量管理**》执行。

| # | 要素 | 落地要点 |
| --- | --- | --- |
| ① | 会计师事务所的**风险评估程序** | 设定质量目标 → 识别和评估质量风险 → 设计和实施应对措施；动态、迭代、随变化更新 |
| ② | **治理和领导层** | 主要负责人对质量承担最终责任；质量文化、组织架构与权责划分、资源投入、合伙人考核与问责，质量优先于商业利益 |
| ③ | **相关职业道德要求** | 独立性年度确认、轮换与冷却期、违反独立性时的处置与沟通记录、职业道德培训 |
| ④ | **客户关系和具体业务的接受与保持** | 评价客户诚信、事务所胜任能力与资源、收费合理性、独立性；对存疑客户不予承接或解除 |
| ⑤ | **业务执行** | 项目组指导监督与复核、咨询、意见分歧解决、项目质量复核、底稿管理 |
| ⑥ | **资源** | 人力资源（招聘、培训、晋升、考核）、技术资源（方法论、工具、IT）、知识资源，以及外部服务提供商 |
| ⑦ | **信息与沟通** | 内部质量信息传递、与外部沟通、投诉与举报渠道、向治理领导层报告质量事项 |
| ⑧ | **监控和整改过程** | 持续监控与周期性评价、缺陷的**根因分析**、制定并跟踪整改措施、评价整改效果 |

::: danger 易错 · 第六个要素是「资源」
教材列示的第六项要素是**「资源」**，涵盖人力、技术与知识资源，不要与「业务执行」等要素混淆。八个要素应当**有效衔接、互相支撑、协同运行**，并由事务所在**全所范围（含分所、分部）统一实施**。体系须结合本所及其业务的性质与具体情况「量身定制」，不机械执行准则、不照搬其他事务所的政策程序。
:::

### 24.2 项目质量复核

| 项目 | 结论 |
| --- | --- |
| **适用业务** | ①**上市实体财务报表审计业务**；②法律法规要求实施项目质量复核的审计业务或其他业务；③事务所认为为应对一项或多项质量风险有必要实施项目质量复核的业务 |
| 复核人员 | 事务所中实施项目质量复核的合伙人或类似职位人员，或由事务所**委派实施项目质量复核的外部人员**；必须**独立于项目组** |
| 与项目组内部复核的区别 | ①**主体不同**：独立于项目组 vs 项目组内部（通常含多个复核层级）；②**业务范围不同**：仅适用于上述三类业务 vs 所有业务；③**内容与深度不同**：聚焦重大判断、疑难或争议事项、得出的结论及底稿是否支持该结论 |
| 时点与记录 | 应在项目合伙人**签署审计报告之前完成**；未完成不得出具报告；复核意见、分歧及其解决须记录于底稿；复核**不减轻**项目组责任 |

### 24.3 对财务报表审计实施的质量管理（第 1121 号）

项目合伙人对**整个审计项目的质量承担总体责任**，应当：为项目营造重视质量的文化氛围；确认项目组整体具备适当的胜任能力与时间；对审计工作实施充分的指导、监督与复核（经验较丰富者复核较缺乏者）；确保重大疑难事项得到适当咨询、意见分歧得到解决；评价是否已获取充分适当的审计证据以支持结论；在签署审计报告**之前**确认与质量管理相关的责任已履行。

::: tip 三层责任串联
**事务所层面**（5101 号八要素）提供体系与资源 → **项目层面**（1121 号，项目合伙人）保证具体业务执行质量 → **独立复核**（项目质量复核）在报告出具前对重大判断把关。独立性要求（第 3 章）与轮换冷却期贯穿三层，任何一层缺失都不能以「其他层做得到位」替代。
:::

| 仅通过实质性程序无法应对的风险 | **必须实施控制测试** | 7、8 |
| 实质性程序 | 对**所有重大类别**的交易、账户余额和披露均须实施，**无风险高低豁免** | 8 |
| 集团重要组成部分（因规模） | 教材示例：超过选定基准 **15%** 的组成部分 | 17 |
| 组成部分重要性 | 由**集团项目组**确定，且必须**低于**集团财务报表整体重要性 | 17 |
| 持续经营评估涵盖期间 | 自财务报表日起**不少于 12 个月** | 18 |
| 期后事项三时段 | 财务报表日 → 审计报告日 → 财务报表报出日 → 报出日后 | 19 |
| 审计报告日 | **不早于**获取充分适当证据（含管理层认可责任并批准财务报表）并形成意见之日；实务中与财务报表批准日同日 | 19 |
| 书面声明日期 | **尽量接近但不得晚于**审计报告日；管理层签署前不得发表意见或签署报告 | 19 |
| 审计工作底稿归档 | 审计报告日后 **60 天内**；未完成业务为业务中止后 **60 天内** | 21 |
| 审计工作底稿保存 | 自审计报告日／业务中止日起**至少 10 年** | 21 |
| 鉴证业务底稿 | 归档 **60 天内**；自鉴证报告日／业务中止日起**至少保存 10 年**；书面声明日期不得晚于鉴证报告日 | 23 |
| 内部控制审计基准日 | **最近一个会计期间的截止日**（对**时点**有效性发表意见，非期间段） | 22 |
| 内部控制缺陷 | **重大缺陷 / 重要缺陷 / 一般缺陷**三级；存在重大缺陷 → **否定意见** | 22 |
| 缺陷书面沟通 | 重大、重要缺陷须**书面**沟通，且须在**出具内部控制审计报告之前** | 22 |
| 质量管理体系 | **八个要素**，按第 **5101 号**准则设计实施运行；项目层面按第 **1121 号**准则 | 24 |
| 项目质量复核 | 上市实体等**三类业务**适用；须在项目合伙人**签署审计报告之前**完成 | 24 |

## 附录 B 各章易错点速查

1. 合理保证是高水平保证但**不是绝对保证**，审计不能发现所有舞弊。
2. 审计不改变管理层与治理层的责任，也不为使用者提供如何利用信息的建议。
3. 三方关系中责任方与预期使用者可能同属一方，但三方关系依然成立。
4. 「存在／发生」查高估（账→证），「完整性」查低估（证→账），方向决定程序。
5. 重大错报风险只能**评估**不能控制；检查风险才能通过程序控制。
6. 重大错报风险评估越高，所需审计证据越多，而非越少。
7. 职业道德基本原则是**六项**（含独立性），不是五项。
8. 保密义务的例外：法律法规要求、客户授权、职业准则要求或允许。
9. 概念框架是「识别 → 评价 → 应对 → 退出」四步，不是直接套禁止清单。
10. 低价揽客后缩减程序属**自身利益**；客户以换所相威胁属**外在压力**。
11. 独立性须**实质**与**形式**同时具备，只做到内心独立不够。
12. 独立性要求延伸至关联实体、网络事务所与项目组成员的主要近亲属。
13. **直接经济利益无论金额大小一律禁止**；间接经济利益须评价是否重大。
14. 逾期收费长期未收实质等同于向客户提供贷款；审计业务**禁止或有收费**。
15. 承担管理层职责产生的自我评价威胁**无法降至可接受水平**，没有防范措施可用。
16. 关键审计合伙人累计任职不得超过 5 年；冷却期按角色为 5 年 / 3 年 / 2 年。
17. 违反独立性时须先**终止或消除违反本身**，再评价是否需要外部复核，复核须在报告日前完成。
18. 充分性不能弥补适当性缺陷；相关性错配时证据再多也无效。
19. 不同来源证据相互不一致时，应**扩大程序范围直至不一致得到解决**。
20. 询问本身不足以测试认定；观察只能证明观察时点的情况。
21. 函证须由注册会计师**控制发函与回函全过程**；被审计单位代收的回函不构成有效证据。
22. 消极式函证的四项条件须**同时满足**，证据力弱于积极式。
23. 银行函证应覆盖本期所有存过款的银行（含零余额、已注销账户）；不函证须在底稿说明理由。
24. 应收账款函证主要验证**存在**，不能证明完整性；应付账款审计重点恰是**完整性**。
25. 分析程序**不适用于控制测试**；风险评估与总体复核阶段必须实施。
26. 抽样三特征缺一不可；选取特定项目（大额、高风险）的结论**不能推断总体**。
27. 总体的适当性与完整性优先于样本量：从已开单项目抽样查不出「已发运未开单」。
28. **信赖过度、误受**影响审计效果，比信赖不足、误拒更危险。
29. 非统计抽样也必须考虑抽样风险并将其降至可接受水平，只是无法精确测定。
30. 非抽样风险与样本量无关，只能靠指导、监督、复核与程序设计降低。
31. 初步业务活动在**业务开始前**完成；管理层不认可责任或拒绝提供书面声明时不宜承接。
32. 总体审计策略与具体审计计划不是一次性文件，须随审计进程持续更新。
33. 实际执行的重要性**低于**整体重要性；准则未规定固定百分比，属职业判断。
34. 「明显微小」**不等于**「不重大」；不确定时不能视为明显微小。
35. 错报分事实错报、判断错报、推断错报，三类均须累积（明显微小除外）。
36. 风险评估程序**不应偏向佐证性证据，也不应排斥矛盾证据**。
37. 了解内部控制 ≠ 控制测试：前者看设计与是否执行，后者看整个期间的运行有效性。
38. 风险评估程序本身**不足以**为发表审计意见提供充分适当的审计证据。
39. 项目组讨论须由项目合伙人与关键成员参与，强调舞弊可能性与职业怀疑。
40. 特别风险须专门评价相关控制的设计与执行，且**必须实施实质性程序**。
41. 管理层凌驾于控制之上属特别风险：测试会计分录、复核估计偏向、评价异常交易商业理由。
42. 仅通过实质性程序无法应对的风险，**必须实施控制测试**。
43. 一般控制无效时不能信赖自动化应用控制，不能靠「多测几个应用控制样本」补救。
44. 增加不可预见性不等于告知客户具体程序，可对未事先通知的地点实施监盘。
45. 控制测试针对**整个拟信赖期间**；期中测试须补充剩余期间的证据。
46. 财报审计中，未变化且非特别风险的控制可**每三年至少测试一次**（每次审计仍须测试足够数量）；减轻特别风险的控制不得依赖以前年度证据、每年都测；**内控审计**须每一年度测试，不得采用「每三年一次」。
47. 实质性程序对所有重大类别交易、账户余额与披露**无豁免**。
48. 收入确认时点**通常不能以开发票日期为准**。
49. 双向追查：账→证查发生，证→账查完整性；只做前者无法发现少记。
50. 应付账款重点查未入账负债；向余额较小或为零的主要供应商函证更有效。
51. 存货监盘**应当实施**，不得以检查成本高、难以实施为由省略。
52. 监盘不可行时实施替代程序；仍不足以取证则考虑对意见类型的影响。
53. 监盘须双向抽盘；盘点日非资产负债表日时须检查其间出入库记录。
54. 存货容易辨认、数量易清点则无需专家；利用专家**不减轻**注册会计师责任。
55. 银行函证范围取决于本期是否发生业务及相关风险，而非余额大小。
56. 银行存款余额调节表由注册会计师自行编制或重新计算更可靠。
57. 舞弊责任：治理层与管理层负**主要责任**；注册会计师只对整体不存在重大错报获取合理保证。
58. 对不直接影响报表金额与披露的法律法规，仅实施询问与检查往来函件等**有限程序**。
59. 因管理层或治理层阻挠无法获取充分适当证据 → 保留或无法表示意见。
60. 与治理层沟通**不减轻**注册会计师、管理层与治理层各自的责任。
61. 接受委托**前必须**与前任注册会计师沟通；未获答复应谨慎考虑是否接受委托。
62. 利用内部审计或专家的工作，均**不减轻**注册会计师对审计意见的责任。
63. 集团项目合伙人对**集团审计意见负全部责任**，不因利用组成部分注册会计师而减轻。
64. 组成部分重要性由**集团项目组**确定，且必须低于集团整体重要性。
65. 集团审计证据不足须评价对**集团意见**的影响，不能只在组成部分层面反映。
66. 关联方不能仅凭管理层声明或常规程序，就默认不存在未识别、未披露的关联方。
67. 持续经营适当但有重大不确定性且充分披露 → **无保留意见＋单独部分**，且明确不影响意见。
68. 重大不确定性未充分披露 → 保留或否定；运用持续经营假设不适当 → **否定意见**。
69. 首次审计不能获取期初余额充分适当证据 → 保留或无法表示意见。
70. 上期非无保留意见事项未解决且对本期重大 → 对**本期**报表仍发表非无保留意见。
71. 书面声明签署前不能发表意见或签署报告；书面声明本身**不构成充分适当证据**。
72. 期后事项第二、第三时段注册会计师**没有义务**针对财务报表实施任何审计程序。
73. 审计报告日不早于获取充分适当证据并形成意见之日；项目质量复核须在签署前完成。
74. 保留意见针对的是**重大但不具广泛性**的事项，不是「小问题」。
75. 强调事项段**不能替代**非无保留意见；持续经营重大不确定性另设单独部分。
76. 关键审计事项不能替代非无保留意见或管理层披露；**无法表示意见时不得沟通**。
77. 其他信息的重大错报**不导致**对财务报表发表非无保留意见。
78. 底稿归档 **60 天**、保存**至少 10 年**；归档后修改须记录理由、时间人员与复核人员。
79. 内控审计只对**基准日时点**有效性发表意见，但需基准日前足够长期间的运行证据。
80. 内控审计存在重大缺陷 → **否定意见**，没有「保留意见」这一档。
81. 重大／重要缺陷须**书面**沟通，且在出具内部控制审计报告**之前**完成。
82. 有限保证以消极方式表述、程序较少，但仍须提供**有意义的保证**。
83. 可持续信息鉴证的书面声明日期尽量接近但**不得晚于**鉴证报告日。
84. 质量管理八要素第六项是「**资源**」；体系须量身定制、全所（含分所）统一实施。
85. 项目质量复核适用于上市实体等三类业务，须在签署报告前完成，且**不减轻**项目组责任。
