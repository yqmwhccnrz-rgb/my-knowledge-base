## 第1章 利息度量

**利息**是借款人为获得资金使用权向贷款人支付的款项：对借款人是成本，对贷款人是推迟消费的补偿。三种解释：资金是稀缺资源须付成本；出借资金推迟当期消费应获补偿；资金作为生产要素参与成果分配。

本章符号表（全书通用）：

| 符号 | 含义 |
| --- | --- |
| a(t) | 累积函数：时刻 0 的 1 单位本金在时刻 t 的价值 |
| a⁻¹(t) | 贴现函数：时刻 t 的 1 单位本金在时刻 0 的价值 |
| i | 实际利率（有效利率）：1 单位本金一个时期末产生的利息 |
| d | 实际贴现率 |
| i⁽ᵐ⁾ / d⁽ᵐ⁾ | 每年复利/贴现 m 次的名义利率、名义贴现率 |
| δ | 利息力（连续复利）；δ(t) 为时刻 t 的利息力 |
| v | 贴现因子，v = 1/(1+i) = 1−d |

### 1.1 累积函数与实际利率（★★★）

**累积函数 a(t)** 是期初 1 单位本金在时刻 t 的累积值，是一切利息度量工具的母体。三条性质：

1. a(0) = 1；
2. a(t) 通常递增（利息非负；投资亏本时可能递减）；
3. 连续计息时 a(t) 连续。

**金额函数**：期初本金为 A(0) 时，A(t) = A(0)·a(t)；反之 a(t) = A(t)/A(0)。利息额 I(t) = A(t) − A(0)。

**实际利率**（effective rate of interest）：1 单位本金在一个时期末赚取的利息金额。

- 时期 (t−1, t) 的实际利率：iₜ = [a(t) − a(t−1)] / a(t−1) = [A(t) − A(t−1)] / A(t−1)
- 第一期：i = a(1) − 1，故 a(1) = 1+i
- 实际利率产生的利息只能在**期末一次性支付**

**例 1**（教材例 1-1）：累积函数 a(t) = 1.2ᵗ + 0.05t，求 t=2 时的 500 万元在 t=3 时的价值。
解：从 t=2 到 t=3 的价值比 = a(3)/a(2) = (1.728+0.15)/(1.44+0.10) = 1.878/1.54，故 500×1.878/1.54 = **609.74 万元**。
（要点：不同时刻之间换算资金价值一律用 a(t₂)/a(t₁) 这个比值。）

### 1.2 单利与复利（★★★ 辨析高频）

| 项目 | 单利 | 复利 |
| --- | --- | --- |
| 累积函数 | a(t) = 1+it（线性） | a(t) = (1+i)ᵗ（几何级数） |
| 利息是否再生息 | 否 | 是（自动再投资） |
| 实际利率 iₜ | i/[1+i(t−1)]，随 t **递减** | 恒等于 i（**一致性**） |
| 分段投资 | 段数越多利息越多（缺陷） | 与分段无关 |
| 0<t<1 | 累积值 > 复利 | — |
| t>1 | 累积值 < 复利 | — |
| t=0 或 1 | 两者相等 | 两者相等 |

利率较低且期限不足 1 年时可用单利近似复利：(1+i)ᵗ ≈ 1+it。

**例 2**：借款 20 000 元，4 年后还 25 249.54 元，求年复利利率。
解：20000(1+i)⁴ = 25249.54 → (1+i)⁴ = 1.262477 → **i = 6%**。

**计息天数规则**（t = 投资天数 / 一年天数）：

| 规则 | 投资天数 | 一年天数 | 特点 |
| --- | --- | --- | --- |
| 实际/365 | 实际天数 | 365 | 精确 |
| 实际/360（银行家规则） | 实际天数 | 360 | 利息最大 |
| 30/360 | 每月按 30 天 | 360 | 利息最小；360(Y₂−Y₁)+30(M₂−M₁)+(D₂−D₁)，另有 4 条日期调整细则 |

**例 3**：2014-6-14 存 10 000 元，2015-2-7 取出，年单利 8%。实际天数 238：
- 实际/365：10000×0.08×238/365 = **521.6 元**
- 实际/360：10000×0.08×238/360 = **528.9 元**
- 30/360：天数 = 360×1+30×(2−6)+(7−14) = 233，利息 = **517.8 元**

### 1.3 贴现函数与实际贴现率（★★★）

**贴现函数** a⁻¹(t) = 1/a(t)，用于求现值。单利贴现函数 (1+it)⁻¹；复利贴现函数 (1+i)⁻ᵗ = (1−d)ᵗ。

**实际贴现率**（effective rate of discount）：一定时期内产生的利息与**期末累积值**之比（注意定义仍用累积函数）：

- dₜ = [a(t) − a(t−1)] / a(t)；复利下 d = i/(1+i) = iv
- 期初的 1−d 元期末累积为 1 元 → a(t) = (1−d)⁻ᵗ
- i = d/(1−d)

**利率 vs 贴现率**：利率以本金（期初值）为计算基础，贴现率以累积值（期末值）为计算基础。换算：利率 = 贴现率/(1−贴现率)。

**四大等价关系**（简答高频，务必背熟）：

1. d = i·v（实际贴现率 = 实际利率的现值）
2. i − d = id（利率与贴现率之差 = 它们的乘积）
3. d = 1 − v
4. i = d/(1−d)，d = i/(1+i)

**数值范围**：i ∈ (0, +∞)，d ∈ (0, 1)；i→∞ 时 d→1。利率增大时贴现率增长幅度越来越小。

**单贴现率**：a⁻¹(t) = 1−dt（0 ≤ t < 1/d），应用有限；贴现期不足 1 年时单贴现现值 > 复贴现现值，超过 1 年时相反；使用单贴现率时**贴现期不能超过 1/d**。

**例 4**：一年期零息债券面值 100 元、发行价 90 元。利率 = 10/90 = 11.11%，贴现率 = 10/100 = 10%。

### 1.4 名义利率与名义贴现率（★★★）

**名义利率 i⁽ᵐ⁾**：一年复利 m 次（或多年复利一次）的利率；每 1/m 年的实际利率为 i⁽ᵐ⁾/m。**只说"名义利率 12%"没有意义，必须说明复利次数**。

核心等价方程（一切换算的总纲）：

> **1 + i = (1 + i⁽ᵐ⁾/m)ᵐ = (1 − d⁽ⁿ⁾/n)⁻ⁿ = e^δ**

- i = (1 + i⁽ᵐ⁾/m)ᵐ − 1；i⁽ᵐ⁾ = m[(1+i)^(1/m) − 1]
- 名义利率的另一解释：在 1/m 年区间内**与复利等价的单利利率**：1 + i⁽ᵐ⁾/m·(1/m)·m = (1+i)^(1/m) 意义下的单利等价
- k 年复利一次的名义利率 = 每年复利 m = 1/k 次的情形，公式依然成立

**名义贴现率 d⁽ᵐ⁾**：度量不足一年的一个时间区间内的实际贴现率，每 1/m 年实际贴现率为 d⁽ᵐ⁾/m。

- d = 1 − (1 − d⁽ᵐ⁾/m)ᵐ；d⁽ᵐ⁾ = m[1 − (1−d)^(1/m)]

**名义利率与名义贴现率互换**：

- (1 + i⁽ᵐ⁾/m)ᵐ = (1 − d⁽ⁿ⁾/n)⁻ⁿ（总纲）
- 同频次时：i⁽ᵐ⁾/m − d⁽ᵐ⁾/m = i⁽ᵐ⁾d⁽ᵐ⁾/m²，即 1/i⁽ᵐ⁾ − 1/d⁽ᵐ⁾ = 1/m
- **等价时恒有名义利率 > 名义贴现率**（利率期末付、贴现率期初收）

**单调性结论**（选择题高频）：

- 名义利率给定 → 复利次数越多，年实际利率**越大**（极限 e^δ）
- 名义贴现率给定 → 贴现次数越多，年实际贴现率**越小**

**例 5**：2000 元按每年复利 4 次的年名义利率 6% 投资 2.5 年。
解法一：季度实际利率 1.5%，共 10 个季度：2000×1.015¹⁰ = **2321.08 元**。
解法二：年实际利率 = 1.015⁴−1 = 6.1364%，2000×1.061364^2.5 = **2321.08 元**。

**银行存款利率就是名义利率**：3 个月期 1.8% 意味着季度实际利率 0.45%，等价年利率 1.812%；3 年期 3.69% 意味着 3 年实际利率 11.07%，等价年利率 3.562%。规律：期限 < 1 年时名义利率 < 等价实际利率；期限 > 1 年时名义利率 > 等价实际利率，且期限越长差异越大。

### 1.5 利息力（★★★ 计算高频）

**利息力 δ(t)**（force of interest，连续复利）：资本在**每一时点**上的利息增长强度：

- δ(t) = a′(t)/a(t) = [ln a(t)]′ = A′(t)/A(t)
- 累积函数反推：**a(t) = exp(∫₀ᵗ δ(s)ds)**
- 复利下 δ = ln(1+i) 为常数；i = e^δ − 1
- 单利下 δ(t) = i/(1+it)，随 t 递减
- δ = lim i⁽ᵐ⁾ = lim d⁽ᵐ⁾（m→∞），即利息力是名义利率/名义贴现率的共同极限
- δ 是常数 ⟹ i 常数；反之不成立（i 是时期平均强度，δ 是时点强度）

**贴现力**：δ(t) = −[a⁻¹(t)]′/a⁻¹(t)；可证**贴现力 = 利息力**（时点概念，期初期末重叠），实务中只用利息力。

**六者换算总表**（知道任意一个可求其余）：

| 已知 | i | d | v | δ |
| --- | --- | --- | --- | --- |
| i | — | i/(1+i) | 1/(1+i) | ln(1+i) |
| d | d/(1−d) | — | 1−d | −ln(1−d) |
| v | 1/v−1 | 1−v | — | −ln v |
| δ | e^δ−1 | 1−e^−δ | e^−δ | — |

**等价工具数值大小关系**（m<n）：**d ≤ d⁽ⁿ⁾ ≤ d⁽ᵐ⁾ ≤ δ ≤ i⁽ᵐ⁾ ≤ i⁽ⁿ⁾ ≤ i**
记忆：支付越早数值越小——贴现率年初预收最小，利率年末支付最大，利息力连续居中；复利/贴现次数越多越靠近 δ。

**例 6**：金额函数 A(t) = 8t²+2t+100，求 t=0.5 的利息力。
解：δ(t) = A′(t)/A(t) = (16t+2)/(8t²+2t+100)，δ(0.5) = 10/103 = **9.71%**。

**例 7**：投资者 A 按单利 10% 计息，投资者 B 按利息力 δ(t) = t/120 + k 计息，第 4 年末到第 8 年末两人利息相等，求 k。
解：A 的利息 = 1.8X−1.4X = 0.4X；B 的利息 = X(e^(∫₄⁸δ) − 1) = X(e^(24/120+4k) − 1) = X(e^(0.2+4k)−1)。
令 0.4 = e^(0.2+4k) − 1 → e^(0.2+4k) = 1.4 → 4k = ln1.4 − 0.2 = 0.1365 → **k ≈ 0.0341**（教材例 1-22 中 k = 1/120 × 相应形式，方法一致：分段积分 + 令利息相等）。

### 1.6 利率概念辨析（★★ 简答）

**本书 vs 经济学中的"实际/名义利率"完全是两码事**：

| 语境 | 实际利率 | 名义利率 |
| --- | --- | --- |
| 本书（精算） | 每度量期复利一次的利率 | 一期内复利多次/多期复利一次 |
| 经济学 | 扣除通胀后的利率 r | 未扣除通胀的利率 i |

经济学关系（费雪方程）：**1+i = (1+r)(1+π)**，近似 i ≈ r + π（实际利率 ≈ 名义利率 − 通胀率）。预期通胀率 > 名义利率时贷款人实际获得负利息收入。

### 1.7 易错点

- 单利**不满足一致性**：实际利率随时间递减、分段投资会多赚利息；复利满足一致性。
- 实际贴现率定义的分母是**期末累积值**不是期初本金——d = iv 而非 d = i。
- 名义利率/名义贴现率**必须与复利（贴现）次数配对**，单独一个数字无意义。
- i⁽ᵐ⁾ 与 d⁽ᵐ⁾ 等价时 **i⁽ᵐ⁾ > d⁽ᵐ⁾** 恒成立。
- 复利次数 m 增大：等价年实际利率 i **增大**、年实际贴现率 d **减小**（方向相反，常考选择题）。
- 单贴现率只能用于 t < 1/d 的期限，否则现值为负。
- δ 为常数 ⟺ 复利；i 为常数 ⇏ δ 为常数。

## 第2章 等额年金

**年金**（annuity）：一系列付款或收款。六种分类（名词解释常考）：

| 分类角度 | 类型 |
| --- | --- |
| 支付时间金额是否确定 | 确定年金 / 风险年金（如终身生存年金） |
| 支付期限 | 定期年金 / 永续年金（无到期日债券利息、优先股股息） |
| 支付周期 | 每年一次 / 每季 / 每月 / 连续年金 |
| 支付时点 | 期初付（annuity-due）/ 期末付（annuity-immediate） |
| 首次支付时间 | 即期年金 / 延期年金 |
| 付款金额 | 等额年金 / 变额年金 |

![年金公式树](/int/int-annuity.svg)

### 2.1 年金现值（★★★ 全书地基）

**期末付定期年金**（n 期，每期末付 1 元）：

> **aₙ = v + v² + ⋯ + vⁿ = (1 − vⁿ)/i**

证明思路：写出现值和，两边乘 (1+i) 相减（等比数列错位相减）。

**恒等式 iaₙ + vⁿ = 1** 的经济解释：期初 1 元本金 = 每期利息 i 的现值 iaₙ + 期末收回本金的现值 vⁿ。

**期初付定期年金**（每期初付 1 元）：

> **äₙ = (1 − vⁿ)/d = (1+i)·aₙ = 1 + a₍ₙ₋₁₎**

（期初付比期末付每笔都提前一期，故乘 (1+i)；n 次期初付款 = 时刻 0 的 1 元 + 后 n−1 次期末付款。）

**期末付永续年金**：a∞ = 1/i（n→∞ 的极限）。经济含义：期初存 1/i 元，本金不动可永远每期末取出 1 元利息。
**期初付永续年金**：ä∞ = 1/d = (1+i)/i。

**例 8**：一笔年金 20 年内每年末付 4，另一笔 10 年内每年末付 5，现值相等，求投资翻番所需年数 n。
解：4a₂₀ = 5a₁₀ → 4(1−v²⁰) = 5(1−v¹⁰)，令 x = v¹⁰：4x²−5x+1 = 0 → x = 1/4（x=1 舍去）→ v¹⁰ = 0.25，i = 0.25^(−1/10)−1 = 14.87%。翻番：(1+i)ⁿ = 2 → **n = 5**。

**例 9**：永续年金由 A、B、C、D 分享，A 得前 n 次、B 得第 2 个 n 次、C 得第 3 个 n 次、D 得之后全部。已知 PV_C : PV_D = 1，求 PV_B : PV_D。
解：PV_C = v²ⁿ·aₙ，PV_D = v³ⁿ/i。由 v²ⁿaₙ = v³ⁿ/i 及 aₙ = (1−vⁿ)/i 得 vⁿ(1−vⁿ) = vⁿ·…解得 vⁿ = 0.5。PV_B : PV_D = vⁿaₙ/(v³ⁿ/i) = (1−vⁿ)vⁿ/v³ⁿ·… = **2**（教材例 2-4：比值 = (1−vⁿ)/vⁿ·vⁿ⁻³ⁿ 化简后代入 vⁿ=0.5 得 2）。

### 2.2 年金终值（★★★）

> **sₙ = aₙ(1+i)ⁿ = [(1+i)ⁿ − 1]/i**（期末付）
> **s̈ₙ = sₙ(1+i) = [(1+i)ⁿ − 1]/d**（期初付）= s₍ₙ₊₁₎ − 1

永续年金**没有终值**（发散）。

**恒等式 (1+i)ⁿ = 1 + i·sₙ** 的解释：期初 1 元的终值 = 每期利息的终值 + 期末收回的本金。

**例 10**：前 5 年每年末存 2 万，后 5 年每年末存 4 万，i = 5%，求第 10 年末累积值。
解：拆成「2 万的 10 年年金 + 2 万的延期 5 年 5 年年金」：2s₁₀ + 2s₅ = 2×12.5779 + 2×5.5256 = **36.21 万元**。

**例 11**：每年初存 1000 元共 20 年，单利 i 计息时第 20 年末累积 28 400 元；求按同利率复利计息的累积值。
解：单利累积值 = 1000[20 + i(1+2+⋯+20)] = 20000 + 210000i = 28400 → i = 4%。
复利：1000·s̈₂₀ = 1000 × (1.04²⁰−1)/0.04 × 1.04 = **30 970 元**。

### 2.3 现值与终值的关系（★★）

| 关系 | 公式 |
| --- | --- |
| 终值 = 现值累积 n 期 | sₙ = aₙ(1+i)ⁿ；aₙ = sₙ(1+i)⁻ⁿ |
| 倒数关系（期末付） | 1/aₙ = 1/sₙ + i |
| 倒数关系（期初付） | 1/äₙ = 1/s̈ₙ + d |

倒数关系的记忆：1/aₙ − 1/sₙ = i，即「现值倒数减终值倒数等于利率」。

### 2.4 年金在任意时点上的值（★★★）

三种情形，**无需新公式**，全靠拆解：

1. **支付期开始前**（延期年金）：ₘ|aₙ = vᵐ·aₙ = a₍ₘ₊ₙ₎ − aₘ；期初付：ₘ|äₙ = vᵐ·äₙ；延期永续：ₘ|a∞ = vᵐ/i
   - m 可以为**任意正实数**（非整数延期照样用 vᵐ）
2. **支付期限内任意时点 t**：拆成「前段付款的终值 + 后段付款的现值」
3. **支付期结束后任意时点**：先求终值再往后累积

**例 12**：贷款年利率 8%，前 10 年不还，第 11–20 年每年末还 2000 元，求本金。
解：2000·₁₀|a₁₀ = 2000×v¹⁰×a₁₀ = 2000×0.46319×6.7101 = **6216 元**；
或 2000×(a₂₀−a₁₀) = 2000×(9.8181−6.7101) = **6216 元**。

**例 13**：贷款年利率 6%，每年末还 20 000 元共 10 年，求第 5 年零 3 个月末一次付清的金额。
解：20000×(s₅+a₅)×1.06^0.25 = 20000×(5.6371+4.2124)×1.0147 = **199 880 元**。

### 2.5 每年支付 m 次的等额年金（★★★）

设每年总付款额为 1，分 m 次支付（每次 1/m）。**核心结论：付款时间提前 ⟹ 价值上升为 i/i⁽ᵐ⁾ 倍**：

| 类型 | 现值 | 终值 |
| --- | --- | --- |
| 期末付 m 次 | aₙ⁽ᵐ⁾ = (1−vⁿ)/i⁽ᵐ⁾ = (i/i⁽ᵐ⁾)·aₙ | sₙ⁽ᵐ⁾ = [(1+i)ⁿ−1]/i⁽ᵐ⁾ = (i/i⁽ᵐ⁾)·sₙ |
| 期初付 m 次 | äₙ⁽ᵐ⁾ = (1−vⁿ)/d⁽ᵐ⁾ = (i/d⁽ᵐ⁾)·aₙ | s̈ₙ⁽ᵐ⁾ = [(1+i)ⁿ−1]/d⁽ᵐ⁾ = (i/d⁽ᵐ⁾)·sₙ |
| 永续 | a∞⁽ᵐ⁾ = 1/i⁽ᵐ⁾；ä∞⁽ᵐ⁾ = 1/d⁽ᵐ⁾ | — |

- äₙ⁽ᵐ⁾ = (1+i)^(1/m)·aₙ⁽ᵐ⁾
- **注意**：公式假设「每年付款总额为 1」；若每次付 X 元、每年 m 次，则年总额为 mX，现值 = mX·aₙ⁽ᵐ⁾
- 期末付年金分 m 次支付后价值上升（付款提前）；期初付分 m 次后价值**下降**为 i/d⁽ᵐ⁾ 倍相对期末——方向别搞反

**例 14**：50 万贷款 5 年内按月等额偿还，年实际利率 6%，求每月还款额。
解：月实际利率 j = 1.06^(1/12)−1 = 0.004868；500000 = X·a₆₀⌐ⱼ → X = **9629.62 元**。
（用 aₙ⁽ᵐ⁾ 公式：500000 = 12X·a₅⁽¹²⁾，结果相同。）

**例 15**：每月初存 1000 元，年实际利率 5%，求 5 年末累积值。
解：12000·s̈₅⁽¹²⁾ = 12000×(i/d⁽¹²⁾)×s₅ = 12000×(0.05/0.04889)×5.5256 = **67 813.74 元**。

### 2.6 连续支付的等额年金（★★★）

每年付款总额为 1、连续支付（m→∞，i⁽ᵐ⁾→δ）：

> **āₙ = (1 − vⁿ)/δ = (i/δ)·aₙ  s̄ₙ = [(1+i)ⁿ − 1]/δ = (i/δ)·sₙ  ā∞ = 1/δ**

积分推导：时刻 t 付 dt 元，现值 ∫₀ⁿ vᵗdt = (1−vⁿ)/δ。

**支付频率与价值**：每年付款总额不变时，支付次数越多——期末付年金现值**越大**（平均付款时间提前）；期初付年金现值**越小**（平均付款时间推迟）；两者都收敛到连续年金。

**例 16**：i = 10%，每年支付 1 元的 20 年期年金现值随支付频率变化：
每年 1 次 8.5136 → 每季 8.8265 → 每月 8.8971 → 每天 8.9313 → 连续 8.9325（= a₂₀×i/δ = 8.5136×0.1/ln1.1）。

**例 17**：年实际贴现率 5%，第 5 年末到第 7 年末之间每年连续支付 1000 元，求第 2 年末的现值。
解：d = 0.05 → v = 0.95，δ = −ln0.95。现值 = 1000·ā₂·v³ = 1000×(1−0.95²)/(−ln0.95)×0.95³ = **1629.73 元**。

### 2.7 价值方程及其应用（★★★ 方法论）

**价值方程**（equation of value）：基于「现金流入现值 = 现金流出现值」建立的方程。年金问题三变量——现值/终值、支付次数 n、利率 i——知二求一。

- 求 n：解析解 n = ln[…]/ln(1+i)，结果常非整数 → 处理「最后一次非正规付款」：
  - 提前到前一期末付：金额最小
  - 按理论时间（非整数）付：居中
  - 推迟到下一期末付：金额最大
- 求 i：高次方程无解析解，用 EXCEL RATE 函数 / 单变量求解 / 插值法
- EXCEL 对照：PV、FV、PMT、RATE、NPER；IRR/XIRR、NPV/XNPV

**例 18**：20 万元存基金，每年末领 1 万，年收益率 4.5%，能领多久？
解：20 = 1×aₙ → (1.045)⁻ⁿ = 0.1 → n = 52.31 年。前 52 年每年领 1 万 + 第 53 年领小额 W：
- 第 53 年内第 114 天领：W = **3067 元**；提前到第 52 年末：X = **3025 元**；推迟到第 53 年末：Y = **3161 元**
- 若收益率 ≥ 5%，可无限期领取（1/0.05 = 20 万正好是永续年金现值）

### 2.8 易错点

- aₙ 与 äₙ 差一个 (1+i) 因子；sₙ 与 s̈ₙ 同理——先判断期初还是期末付。
- aₙ⁽ᵐ⁾ 公式中「每年总付款 = 1」的隐含假设，代入实际金额时别忘乘 m。
- 永续年金没有终值；延期非整数期照样用 vᵐ。
- 倒数关系 1/aₙ = 1/sₙ + i 中是 **+i**（期末付）；期初付是 **+d**。
- 计算任意时点价值时，先画现金流图再拆分，不要硬套公式。

## 第3章 变额年金

变额年金 = 付款金额有规律变化的年金。两大类：**离散变额**（算术级数递增/递减、几何级数复递增）与**连续变额**。核心方法：**任何变额年金都可以拆成「等额年金 ± 标准变额年金」的组合**。

### 3.1 递增年金（★★★）

**期末付标准递增年金** (Ia)ₙ：第 1 期末付 1、第 2 期末付 2、…、第 n 期末付 n：

> **(Ia)ₙ = (äₙ − nvⁿ)/i**

证明：现值和 = v+2v²+⋯+nvⁿ，乘 (1+i) 错位相减 → i(Ia)ₙ = äₙ − nvⁿ。
分解视角：(Ia)ₙ = aₙ + v·a₍ₙ₋₁₎ + v²a₍ₙ₋₂₎ + ⋯ + vⁿ⁻¹a₁（n 个延期等额年金之和）。

**终值**：(Is)ₙ = (1+i)ⁿ(Ia)ₙ = (s̈ₙ − n)/i

**期初付**：(Iä)ₙ = (1+i)(Ia)ₙ = (äₙ − nvⁿ)/d；(Is̈)ₙ = (s̈ₙ − n)/d

**递增永续年金**（对 (äₙ − nvⁿ)/i 取极限，nvⁿ → 0）：

> **(Ia)∞ = ä∞/i = (1+i)/i² = 1/(id)  (Iä)∞ = (1+i)(Ia)∞ = (1+i)²/i² = 1/d²**

**通用递增年金拆解模板**（教材例 3-1 模式，考试最常考）：
第 1 期付 P、每期递增 Q 的 n 期年金 = **P′ 元等额年金 + Q 元标准递增年金**，其中 P′ = P − Q：
现值 = (P−Q)·aₙ + Q·(Ia)ₙ

**例 19**：20 年期年金第 1 年末付 650、以后每年递增 50（末次 1600），i = 6%，求现值。
解：拆成 600 元等额年金 + 50 元标准递增年金：
600a₂₀ + 50(Ia)₂₀ = 600×11.4699 + 50×(ä₂₀−20v²⁰)/0.06，其中 ä₂₀ = 12.1581、v²⁰ = 0.3118：
= 6882 + 50×(12.1581−6.236)/0.06 = 6882 + 50×98.70 = 6882 + 4935 = **11 817 元**（教材例 3-1 值）。

**例 20**：递增年金第 1 年末付 300、每次递增 20、末次 600，i = 5%，求最后支付时点的终值。
解：次数 n = (600−300)/20+1 = 16。拆成 280 元等额 + 20 元递增：
280s₁₆ + 20(Is)₁₆ = 280×23.6575 + 20×(s̈₁₆−16)/0.05 = 6624.10 + 20×24.8404 = **10 160.26 元**。

### 3.2 递减年金（★★★）

**期末付标准递减年金** (Da)ₙ：第 1 期末付 n、第 2 期末付 n−1、…、第 n 期末付 1：

> **(Da)ₙ = (n − aₙ)/i**

证明一：递增 + 递减 = 每期 (n+1) 的等额年金 → (Da)ₙ = (n+1)aₙ − (Ia)ₙ。
证明二：分解成 n 个不同期限的等额年金之和。

- 终值：(Ds)ₙ = (1+i)ⁿ(Da)ₙ = [n(1+i)ⁿ − sₙ]/i
- 期初付：(Dä)ₙ = (1+i)(Da)ₙ = (n−aₙ)/d；(Ds̈)ₙ = [n(1+i)ⁿ − sₙ]/d

**例 21**：10 年期递减年金第 1 年初付 100、以后每年减 10（第 10 年初付 10），i = 6%，求第 10 年末终值。
解：10×(Ds̈)₁₀ = 10×[10×1.06¹⁰ − s̈₁₀]/0.06 = 10×(17.9085−13.1808)/0.06 = **835.22 元**。

**山形年金**（先增后减，1,2,…,n,n−1,...,1 共 2n−1 期）：现值 = (Ia)ₙ + vⁿ(Da)₍ₙ₋₁₎ = **aₙ·äₙ**（教材例 3-7 优美结论，证明题考点）。

### 3.3 复递增年金（★★★）

付款按**几何级数**增长：第 1 期末付 1，以后每年按 r 增长（第 t 期末付 (1+r)ᵗ⁻¹）。

**期末付复递增年金现值**：

> **(Ca)ₙ = [1 − (1+j)⁻ⁿ]/[(1+r)·j]，其中 j = (i−r)/(1+r)（净利率）**

- 推导：每笔现金流除以 (1+i)ᵗ 后成为按 j 贴现的等额年金；(1+r)v = 1/(1+j)
- **r = i 时：(Ca)ₙ = n/(1+i)**（每笔现值都是 1/(1+i)）
- 期初付：(Cä)ₙ = (1+i)(Ca)ₙ = [1−(1+j)⁻ⁿ]/j·(1+r)/(1+r) → **(Cä)ₙ = (1+i)/(1+r)·(Ca)ₙ**
- **复递增永续年金存在条件：i > r**，此时 (Ca)∞ = 1/(i−r)（由公式取极限）；期初付 (Cä)∞ = (1+i)/(i−r)

**例 22**：10 年期期末付年金第 1 年末付 1000、每年增长 5%，i = 11.3%，求现值。
解：j = (0.113−0.05)/1.05 = 0.06。PV = 1000×[1−1.06⁻¹⁰]/(1.05×0.06) = 1000×7.3601/1.05 = **7009.61 元**。

**例 23**：永续年金从第 2 年末开始首次支付 5000、每年增长 5%，i = 8%，求现值。
解：先算第 2 年末价值 5000/(0.08−0.05) = 166 667，再贴现：PV = 166667×1.08⁻² = **142 890 元**（教材 142 889.8）。

### 3.4 每年支付 m 次的变额年金（★★）

与等额年金同样的放大规律：

- 每年 m 次期末付变额年金 = **(i/i⁽ᵐ⁾) × 每年 1 次期末付变额年金**
- 每年 m 次期初付变额年金 = **(i/d⁽ᵐ⁾) × 每年 1 次期初付变额年金**
- 连续支付变额年金 = **(i/δ) × 每年 1 次期末付变额年金**

即 (Ia)ₙ⁽ᵐ⁾ = (i/i⁽ᵐ⁾)(Ia)ₙ、(Da)ₙ⁽ᵐ⁾ = (i/i⁽ᵐ⁾)(Da)ₙ、(Ca)ₙ⁽ᵐ⁾ = (i/i⁽ᵐ⁾)(Ca)ₙ，期初付把 i⁽ᵐ⁾ 换成 d⁽ᵐ⁾；连续支付（上划线）把系数换成 i/δ：
(Iā)ₙ = (āₙ−nvⁿ)/δ、(Dā)ₙ = (n−āₙ)/δ、(Cā)ₙ = (i/δ)(Ca)ₙ。

**例 24**：第 1 年每月末付 2000、第 2 年每月末付 2100、…、第 10 年每月末付 2900，i = 5%，求现值。
解：每年付款总额 = 12×(1900+100t)，拆成「1900×12 元等额 + 100×12 元递增」，再乘 m 次支付放大因子 i/i⁽¹²⁾ = 0.05/0.04889 = 1.0227：
PV = 1.0227×[22800×a₁₀ + 1200×(Ia)₁₀] = 1.0227×[22800×7.7217 + 1200×39.375] = **228 373 元**（教材例 3-12）。

### 3.5 连续变化现金流（★★ 压轴计算）

注意区分两类符号（横线位置不同，含义完全不同）：

**（一）连续支付的变额年金**（每年付款额离散变化、年内连续支付，只有 a 上有横线）——由 3.4 的极限规律「连续 = 每年 1 次 × i/δ」直接得到：

> **(Iā)ₙ = (i/δ)(Ia)ₙ = (äₙ − nvⁿ)/δ**（第 1 年连续付 1、第 2 年连续付 2、…）
> **(Dā)ₙ = (i/δ)(Da)ₙ = (n − aₙ)/δ**（第 1 年连续付 n、…、第 n 年连续付 1）
> **(Cā)ₙ = (i/δ)(Ca)ₙ**；连续支付递增永续：**(Iā)∞ = (i/δ)(Ia)∞ = (1+i)/(iδ) = ä∞/δ**

**（二）连续递增/递减年金**（付款**率**也随时间连续变化，I、a 上都有横线）——积分求得：

> **(Īā)ₙ**（时刻 t 付款率为 t）：= ∫₀ⁿ t·e^(−δt)dt = **(āₙ − nvⁿ)/δ**
> **(Īs̄)ₙ** = ((1+i)ⁿ − 1 − nδ)/δ²（现值累积 n 年）
> **连续递增永续：(Īā)∞ = 1/δ²**
> **(D̄ā)ₙ**（时刻 t 付款率为 n−t）：= n·āₙ − (Īā)ₙ = **n·āₙ − (āₙ − nvⁿ)/δ**

**一般连续现金流**（付款期 [a,b]，付款率 p(t)，利息力 δ(t)）——终极公式：

> **PV₀ = ∫ₐᵇ p(t)·exp[−∫₀ᵗ δ(s)ds]·dt**
> **FV_c = ∫ₐᵇ p(t)·exp[∫ₜᶜ δ(s)ds]·dt**

**例 25**：付款期 [0, 0.5]，p(t) = 10t+3，δ(t) = 0.2t+0.06，求现值。
解：∫₀^0.5 (10t+3)e^(−0.1t²−0.06t)dt。令 u = −0.1t²−0.06t，则 du = −(0.2t+0.06)dt = −2(0.1t+0.03)dt，注意 10t+3 = 100(0.1t+0.03)：
PV = −50∫e^u du = −50[e^(−0.055)−1] = **2.68 元**（教材例 3-22，凑微分是关键技巧）。

**例 26**：10 年期年金时刻 t 付款率 9t+6，δ = 9%，求现值。
解：i = e^0.09−1 = 9.4174%。付款率 9t 是连续递增部分、6 是连续等额部分：PV = 9(Īā)₁₀ + 6ā₁₀，其中 ā₁₀ = (1−1.094174⁻¹⁰)/0.09 = 6.5937，(Īā)₁₀ = (ā₁₀ − 10v¹⁰)/δ = (6.5937−10×1.094174⁻¹⁰)/0.09 = 28.0886。PV = 9×28.0886+6×6.5937 = **292.36 元**。

### 3.6 易错点

- 递增年金 (Ia)ₙ 公式分子是 **äₙ**（期初付年金）不是 aₙ——最常见的符号错误。
- 非标准递增（首期 P、递增 Q）先拆成 (P−Q) 等额 + Q 标准递增，不要硬套。
- 复递增年金 r = i 时公式退化为 n/(1+i)（分母 j = 0 不能用一般式）。
- 复递增**永续**年金只有 i > r 时现值才存在（收敛条件）。
- 连续支付符号上划线含义：a 上横线 = 连续支付；I 上横线 = 连续递增（付款率连续变化）；(Iā) 两者都有 = 连续支付且连续递增。
- 一般现金流积分时 δ(t) 分段函数要分段积分；变上限积分别丢负号。

## 第4章 收益率和收益分配

![收益率体系](/int/int-yield.svg)

### 4.1 收益率与净现值（★★★）

**收益率**（yield rate / 内部报酬率 IRR）：使**资金流入现值 = 资金流出现值**的利率；等价定义：使**净现值 NPV = 0** 的利率。

**净现值**：NPV(i) = Σ Rₜvᵗ（Rₜ 为时刻 t 的净现金流，流入为正流出为负）。

- NPV 是利率的**减函数**（常规情况下）：利率越高 NPV 越小
- 决策规则：收益率 ≥ 投资者要求的最低收益率（≈ 筹资利率）⟹ 项目可行；NPV ≥ 0 ⟹ 可行
- 收益率法与净现值法结论一致

**多重收益率**：现金流符号改变多次时，NPV(i)=0 可能有多个解（如净流入 −10000, +21500, −11550 有 5% 和 10% 两个收益率）。此时 NPV 不再是单调函数，收益率法与净现值法都失效 → 改用**修正收益率**。

**收益率唯一性两准则**（简答高频）：

1. **准则一**：资金净流入只改变过一次符号 → 收益率唯一
2. **准则二**：按该收益率计算的资金净流入累积值**始终为负、直到最后一期才为零** → 该收益率唯一（准则一失效时用）

**收益率不存在**：方程解为虚数时（如净流入 −10000, +20000, −11550），只能画 NPV 曲线判断——若 NPV 恒 < 0 则放弃投资。

**例 27**：项目初始投资 3000 万，第 2 年初追加 1000 万，第 1 年末收入 2000 万、第 2 年末收入 4000 万，收益率形如 1/n，求 n。
解：−3000 + 1000v + 4000v² = 0 → 4v²+v−3 = 0 → v = 3/4（负根舍）→ 1+i = 4/3，i = 1/3 → **n = 3**。

### 4.2 币值加权收益率（★★★ 计算高频）

**币值加权收益率**（dollar-weighted rate of return）= IRR，衡量**投资者个人**的实际收益（受本金增减时机影响）。

精确方程：A₀(1+i) + Σ Cₜ(1+i)^(1−t) = A₁（Cₜ 为时刻 t 的新增投资，可为负）

**近似公式**（用单利近似不足一期的复利）：

> **i ≈ I / [A₀ + Σ Cₜ(1−tₜ)]**，其中 I = A₁ − (A₀ + ΣCₜ) 为当期利息收入

- 分母是**按计息时间加权的平均本金余额**
- 若再假设新增投资平均发生在期中（t=0.5）：i ≈ 2I/(A₀+A₁−I)（更粗糙）

**例 28**：期初余额 100 万；4 月 1 日投入前余额 120 万…（教材例 4-4：期初 100，4/1 取出 20，9/1 存入 30，期末 120）
解：I = 120 − (100−20+30) = 10。加权本金（30/360 规则）= 100 − 20×(8/12) + 30×(4/12) = 96.67。i ≈ 10/96.67 = **10.53%**；精确解（XIRR，实际/365）= **10.547%**。

### 4.3 时间加权收益率（★★★ 概念辨析高频）

**时间加权收益率**（time-weighted rate of return）：扣除资金增减影响、在**本金恒定**基础上计算的收益率，衡量**基金经理**业绩。

做法：每次新增投资**前**对基金估值，把投资期切成 n+1 个子区间：

> **1 + i = (1+j₁)(1+j₂)⋯(1+jₙ₊₁)**，jₖ = Aₖ′/(Aₖ₋₁+Cₖ₋₁) − 1

**两法对比**（简答必考）：

| | 币值加权 | 时间加权 |
| --- | --- | --- |
| 衡量对象 | 投资者个人收益 | 基金经理业绩 |
| 受申赎时机影响 | 是 | 否 |
| 数据要求 | 只需期初期末 + 现金流 | 每次申赎前都要估值（成本高） |
| 低点加仓的投资者 | 收益率被拉高 | 不受影响 |

**例 29**（教材例 4-8 精髓）：A 基金 2013 年 1000→2000 万（+100%），2014 年初新增 2 亿后 22000→22000 万（0%）；两年时间加权 = √(2×1)−1 = **41.4%**，但币值加权只有 **4.5%**（大资金恰好买在「不涨」的年份）。B 基金相反：时间加权 3.9% < 币值加权 15.6%。**结论：市场低迷时追加投资会拉低币值加权收益率；时间加权收益率才反映经理真实水平**。

### 4.4 再投资与修正收益率（★★★）

**再投资风险**：利息再投资利率 j ≠ 原投资利率 i 时，实际总收益被拉低（j < i 时）。

- 期初投 1 元、n 年、利率 i、利息按 j 再投资：终值 = **1 + i·sₙ⌐ⱼ**；年平均收益率 z = (1+i·sₙ⌐ⱼ)^(1/n) − 1
- j = i 时退化为复利 (1+i)ⁿ
- 每年末付 1 元的 n 年年金、利息按 j 再投资：终值 = **n + i(Is)₍ₙ₋₁₎⌐ⱼ**（本金序列 n 元 + 利息构成递增年金）

**修正收益率 MIRR**（modified internal rate of return）：项目收入再投资利率 ≠ 筹资利率时使用（也用于多重收益率场景）：

> **(1+MIRR)ⁿ = 流入按再投资利率 j 计算的累积值 ÷ 流出按筹资利率计算的现值**

**例 30**：期初投 10 000，以后 3 年每年末收入 4000。IRR = 9.7%；若收入只能按 5% 再投资：10000(1+MIRR)³ = 4000s₃⌐₀.₀₅ = 12 610 → MIRR = **8.04%**。（EXCEL：=MIRR({-10000,4000,4000,4000}, 0, 5%)）

**例 31**（债券比较）：债券 A 5 年期利率 8%、债券 B 8 年期利率 7%，均到期一次还本付息。A 到期后 3 年再投资利率需 > **5.354%** 才优于 B：(1.08)⁵(1+i)³ = (1.07)⁸。**期限不同的项目比较必须考虑再投资利率**。

### 4.5 收益分配（★★ 概念）

多投资者共享基金收益的两种方法：

| 方法 | 规则 | 适用环境 |
| --- | --- | --- |
| **组合方法** | 所有投资者按基金**平均收益率**分配，不论投资早晚 | 利率平稳/**下降**期（平均收益率高于当前市场利率，吸引新投资者） |
| **投资年度方法** | 新增投资头几年按**投资年度利率**（与投入年份挂钩，对角线元素）分配；超过一定年数（如 5 年）后改按**组合利率** | 利率**上升**期（新资金拿到高利率，吸引新投资者） |

投资年度利率表读法：上标 = 投资发生年度，上标+下标 = 分配收益年度；组合利率 = 相应各投资年度利率的几何平均。

### 4.6 易错点

- 收益率 = IRR = 使 NPV=0 的利率，三个说法是一回事。
- 净现值 NPV 函数**不含**期初现金流、XNPV **必须含**期初现金流；IRR 对应规则现金流、XIRR 对应不规则日期。
- 多重收益率时**收益率法和净现值法都失效**，用 MIRR。
- 币值加权近似公式的分母是「加权平均本金」：期初本金权重 1，时刻 t 新增权重 (1−t)。
- 时间加权收益率必须**在每次新增投资发生前**估值，新增投资本身不参与子区间收益率计算。
- 比较期限不同的项目：短期限项目的再投资收益必须计入。

## 第5章 债务偿还方法

两种基本方法：**分期偿还法**（amortization，每期还款含利息+部分本金）与**偿债基金法**（sinking fund，每期只付利息+往基金存钱，到期基金还本）。

![债务偿还双轨制](/int/int-loan.svg)

### 5.1 等额分期偿还（★★★ 计算题主力）

贷款本金 L₀、期限 n、利率 i、每年末等额偿还 R：

| 量 | 公式 |
| --- | --- |
| 每期偿还额 | **R = L₀/aₙ** |
| 第 k 期利息 | **Iₖ = iLₖ₋₁ = R(1 − v^(n−k+1))**（逐期递减） |
| 第 k 期偿还本金 | **Pₖ = R·v^(n−k+1)**（等比递增，公比 1+i） |
| 第 k 期末本金余额（过去法） | **Lₖ = L₀(1+i)ᵏ − R·sₖ** |
| 第 k 期末本金余额（将来法） | **Lₖ = R·a₍ₙ₋ₖ₎** |

- **过去法 vs 将来法等价**；未来付款额和次数已知时用将来法简便，否则用过去法
- Pₖ₊₁ = Pₖ(1+i)：每期偿还本金按 (1+i) 递增
- 利息总额 = nR − L₀；每 1 元还款额对应的「利息/本金比」= (n−aₙ)/aₙ，是期限 n 的**增函数且加速增长**
- 贷款期限越长，利息总额相对本金越多（i=10% 时 n≈15.38 年利息总额恰好等于本金）

**分期偿还表**（构造题模板）：年份 | 还款额 R | 当年利息 iLₖ₋₁ | 偿还本金 R−利息 | 期末余额

**例 32**：10 万元贷款 5 年、i=6%、每年末等额偿还。R = 100000/a₅ = 100000×0.06/(1−1.06⁻⁵) = **23 739.64 元**。第 3 年：利息 = 23739.64×(1−1.06⁻³) = 3807.38，本金 = 19 932.26，余额 L₃ = R·a₂ = **43 524.08 元**。

**例 33**（利率中途变化）：10 万元保险金按月领取 25 年，月利率由年实际 8% 换算；10 年后利率升到 10%，求每月可多领多少。
解：原月领 R₁ = 100000/a₃₀₀⌐₀.₀₀₆₄₃₄ = 753.42；过去法算 10 年末余额 L₁₂₀ = 100000×1.006434¹²⁰ − 753.42×s₁₂₀ = 80 183.27；新月利率 0.007974，R₂ = 80183.27/a₁₈₀ = 840.63 → 每月多领 **87.21 元**。

### 5.2 等额偿债基金（★★★）

贷款利率 i、偿债基金利率 j（通常 j < i）、期限 n：

| 量 | 公式 |
| --- | --- |
| 每期付息 | I = i·L₀（**恒定**） |
| 每期向基金存款 | **D = L₀/sₙ⌐ⱼ** |
| 每期付款总额 | R = iL₀ + L₀/sₙ⌐ⱼ |
| 第 k 期末贷款净额 | **Lₖ = L₀ − D·sₖ⌐ⱼ** |

**核心结论**：

- **j = i 时偿债基金法 ≡ 分期偿还法**：iL₀ + L₀/sₙ = L₀/aₙ（用 1/aₙ = 1/sₙ + i），且 L₀−Dsₖ = Ra₍ₙ₋ₖ₎
- j < i 时偿债基金法总付款**更大**（等价于以更高利率借款）
- **等价分期利率近似**：r ≈ i + 0.5(i − j)（基金平均余额约为本金一半，每元损失 (i−j) 的利息差）

**例 34**：10 万贷款 5 年、贷款利率 10%、基金利率 8%。D = 100000/s₅⌐₀.₀₈ = 100000/5.8666 = **17 045.65**；年总付款 = 10000+17045.65 = **27 045.65** > 分期偿还法的 26 379.75。第 2 年末净额 = 100000 − 17045.65×s₂⌐₀.₀₈ = **64 545.06 元**。

**例 35**（两笔贷款等价）：贷款一（偿债基金法：i=6%，j=5%）与贷款二（分期偿还，利率 r）等价时：10000×0.06 + 10000/s₅⌐₀.₀₅ = 10000/a₅⌐ᵣ → r = **6.552%**（近似公式给 6.5%）。

### 5.3 变额分期偿还（★★）

每期还款额 Rₜ 不等：L₀ = Σ Rₜvᵗ。最常见**等额本金偿还法**：每期本金相等 → 利息递减 → 总还款额**逐期递减**。

**负偿还**：当期还款 < 当期应付利息时，差额**资本化**（本金余额增加），按贷款利率计息。变额分期偿还中负偿还可与正偿还同样处理（直接代入方程）。

**例 36**：贷款 5 年、i=6%，还款依次 20000/18000/16000/14000/12000。
解：拆成 10000 等额 + 2000 递减：L₀ = 10000a₅ + 2000(Da)₅ = 10000×4.2124 + 2000×(5−4.2124)/0.06 = 42124 + 26253 = **68 377.33 元**。第 3 年利息 = 0.06×L₂，L₂ = 10000a₃+2000(Da)₃ = 26730+10000×… = 37 630 → I₃ = **2257.80**，P₃ = 16000−2257.80 = **13 742.20 元**。

### 5.4 变额偿债基金（★★ 难点）

每期总还款 Rₜ 变化 → 每期存款 = Rₜ − iL₀ 变化。

**贷款本金公式**：L₀ = Σ Rₜ(1+j)^(n−t) / [1 + i·sₙ⌐ⱼ] = ΣRₜvⱼ^(n−t)… 变形：

> **L₀ = Σ Rₜ(1+j)⁻ᵗ / [1 + (i−j)·aₙ⌐ⱼ]**（分子按基金利率贴现，分母修正贷款利率与基金利率之差）

**关键陷阱——负储蓄**：若某期还款 < 应付利息，向基金储蓄为**负**（从基金取钱 = 增加贷款本金）。此时**负储蓄必须按贷款利率 i 资本化，而不能按基金利率 j 计息**！处理方法：先跳过负储蓄期，从基金能正常积累的第一期起建立价值方程，反推出该期初的本金余额，再往前推原始本金。（与变额分期偿还中「负偿还可直接代方程」形成对比——考试最爱考这个差别。）

### 5.5 易错点

- 分期偿还法利息逐期**递减**、本金逐期**递增**、总额恒定；等额本金法总额**递减**。
- 过去法/将来法算出的余额相同，选计算量小的。
- Pₖ₊₁/Pₖ = 1+i（偿还本金等比数列）——选择题常用。
- 偿债基金法每期**付息恒定**（iL₀），与分期偿还的递减利息不同；但扣除基金自身利息收入后「净利息」也是递减的，两法本质等价（j=i 时）。
- j = i ⟺ 两法等价；j < i ⟹ 偿债基金法更贵。
- 等价利率近似 r ≈ i + 0.5(i−j) 只对「基金平均余额 ≈ 本金一半」的情形成立。
- 变额偿债基金的负储蓄按**贷款利率**资本化（不是基金利率）——最容易错的点。

## 第6章 债券价值分析

**金融市场分类**（名词解释）：债务市场（债券）vs 股权市场（股票，剩余权益索取权在后）；货币市场（≤1 年短期债务工具，流动性高）vs 资本市场（>1 年）；一级市场（发行新证券，投资银行协助）vs 二级市场（流通已发行证券，提供流动性和价格发现）。

**债券分类**：按付息方式——零息债券（贴现发行、面值偿还）/ 附息债券（定期付息票）；按期限——短（≤1 年）/ 中（1–10 年）/ 长（>10 年）；按发行主体——国债（无违约风险）/ 地方政府债 / 公司债（担保债券、信用债券、垃圾债券——评级低于 BBB 的投机级）。

![债券定价与利率风险](/int/int-bond-risk.svg)

### 6.1 债券定价四大公式（★★★ 计算核心）

符号：P 价格、i 到期收益率（YTM）、F 面值、C 偿还值（通常 C=F）、r 息票率、rF 每期息票收入、g = rF/C 修正息票率、n 付息次数、i꜀ = rF/P 当期收益率。

| 公式 | 表达式 | 适用场景 |
| --- | --- | --- |
| **基本公式** | P = rF·aₙ + C·vⁿ | 万能 |
| **溢价公式** | **P = C[1 + (g−i)aₙ]** | 判断溢价/折价最方便 |
| **基价公式** | P = G + (C−G)vⁿ，G = rF/i | 基价 G 是「产生与息票等额的周期收益所需投资」；i = rF/G |
| **Makeham** | P = (g/i)(C−K) + K，K = Cvⁿ | 分期偿还债券（拆成多个子债券，g 相同时 P = (g/i)(ΣC−ΣK)+ΣK） |

**价格性质**（简答高频）：

- P 是 i 的**减函数**：收益率越高价格越低
- P 是 i 的**凸函数**（下凸）：收益率下降时价格加速上升、上升时减速下降——**同样幅度的收益率变化，涨价幅度 > 下跌幅度**，对投资者有利
- 可赎回债券在低收益率区间可能**上凸**（对投资者不利）
- 平价发行（P=C=F）⟺ i = r；n→∞ 时当期收益率 = 到期收益率
- 当期收益率 i꜀ = rF/P 与到期收益率**同向变化**；期限越长越接近 YTM

### 6.2 溢价、折价与账面值（★★★）

- **溢价** = P − C = C(g−i)aₙ（g > i 时）；**折价** = C − P（g < i 时，即负溢价）
- **账面值**（book value）：按购买时收益率计算的投资余额。V₀ = P；Vₙ = C
  - 将来法：**Vₜ = C[1+(g−i)a₍ₙ₋ₜ₎]** = rF·a₍ₙ₋ₜ₎ + Cvⁿ⁻ᵗ
  - 过去法：Vₜ = P(1+i)ᵗ − rF·sₜ
  - 递推：**Vₜ = Vₜ₋₁(1+i) − rF**
- 账面值 ≠ 市场价格：账面值基于**固定**的到期收益率，不随市场利率变化
- **溢价分摊**（amortization of premium）：每期息票收入超过应得利息（iVₜ₋₁）的部分 = Vₜ₋₁ − Vₜ = C(g−i)v^(n−t+1)，逐期**递增**；溢价逐期摊入息票，账面值从 P 递减到 C
- **折价累积**（accumulation of discount）：应得利息超过息票的部分，账面值从 P 递增到 C；折价累积 = 负的溢价分摊
- 溢价债券：实得息票 > 应得利息；折价债券：实得息票 < 应得利息

**例 37**：面值 1000、息票率 6%、3 年期、YTM 5%。P = 1000[1+(0.06−0.05)a₃] = 1000×(1+0.01×2.7232) = **1027.23 元**（溢价 27.23）。第 1 年：应得利息 = 1027.23×0.05 = 51.36，实得息票 60，溢价分摊 8.64，年末账面值 **1018.59**；第 2 年分摊 9.07 → 1009.52；第 3 年分摊 9.52 → 1000。分摊之和 = 溢价总额。

**例 38**：同上但 YTM 8% → P = **948.46**（折价 51.54）；账面值 948.46 → 964.34 → 981.49 → 1000（折价累积 15.88/17.15/18.52）。

### 6.3 任意时点的价格与账面值（★★）

两个息票日之间（0<t<1，P₀ 为上一息票日价格）：

- **价格**（含应计息票，全价）：**Pₜ = (1+i)ᵗ·P₀**；或从下一息票日反推 Pₜ = (1+i)^(t−1)(rF+P₁)
- 下一息票日价格：P₁ = P₀(1+i) − rF
- **账面值** = 价格 − 应计息票收入，三种方法：

| 方法 | 公式 | 特点 |
| --- | --- | --- |
| 理论方法 | Vₜ = (1+i)ᵗP₀ − rF[(1+i)ᵗ−1]/i | 累积与息票都按复利，最精确 |
| 半理论方法 | Vₜ = (1+i)ᵗP₀ − t·rF | 息票按单利、累积按复利 |
| 实践方法 | Vₜ = (1+ti)P₀ − t·rF | 全按单利，最简单、应用最广 |

三法结果非常接近，在息票日完全相等。价格呈**阶梯形**上升（息票支付日跌落），账面值**平滑**变化。

### 6.4 可赎回债券（★★★ 概念+计算）

**可赎回债券**（callable bond）：含赎回条款，发行人有权在特定条件下按约定赎回价提前回购。赎回条款**有利于发行人**（利率下降时赎回旧债、发低息新债，降低融资成本；解除限制性条款；调整资产结构），因此可赎回债券预期收益率**较高**、价格**较低**（相比不含赎回条款的同类债券）。通常有赎回保护期（5–10 年），赎回价通常 ≥ 面值（高出的部分约为 1 年利息）。

**定价原则**：投资者愿意支付的最高价格 = **所有可能赎回时点上的最低价格**（发行人会在对自己最有利 = 对投资者最不利的时点赎回）。

- 若各赎回时点偿还值 C 相同：**g > i 时期限越短价格越低**（选最早赎回日）；**g < i 时期限越长价格越低**（选到期日）
- 赎回价不同则逐点计算取最小；可能赎回时点无穷多时用溢价公式分析单调性

**例 39**：面值 1000、息票率 12%、8 年期、保护期 5 年；第 5/6/7 年末赎回价 1050/1030/1010、到期偿还 1000；要求收益率 10%。
解：P₅ = 1050+(120−105)a₅ = 1106.86；P₆ = 1030+(120−103)a₆ = 1104.04；P₇ = 1010+(120−101)a₇ = **1102.50**（最低）；P₈ = 1106.70。投资者最高出价 **1102.50 元**——若按 1106.70 买而发行人第 7 年赎回，实际收益率只有 9.92% < 10%。

### 6.5 易错点

- 溢价公式中 g = rF/C 是**修正息票率**（除以偿还值 C），息票率 r 除以面值 F——C ≠ F 时两者不同。
- 溢价分摊额逐期**递增**（不是递减）：C(g−i)v^(n−t+1) 中 t 越大 v 的幂越小。
- 账面值基于购买时 YTM 固定不变，**市场价格**才随利率波动。
- 分期偿还债券用 Makeham 公式的前提：拆分后各子债券 **g 相同**。
- 可赎回债券取「最低价」而非「最高价」——站在**投资者保护**角度。
- g > i（溢价债）时发行人倾向**早赎回**；g < i（折价债）时倾向**不赎回**（拖到期）。
- 两个息票日之间的「价格」含应计利息（全价/脏价），账面值 = 价格 − 应计息票。

## 第7章 利率风险管理

利率风险 = 债券价格因收益率波动而产生的不确定性。度量工具：**久期**（一阶敏感度）与**凸度**（二阶修正）。原理同样适用于任何已知现金流的资产/负债及整个公司。

### 7.1 麦考利久期（★★★）

**麦考利久期 Dᴹ**（Macaulay duration）：现金流到期时间的**加权平均数**，权数 = 各现金流现值占总现值的比重：

> **Dᴹ = Σ t·Rₜ(1+i)⁻ᵗ / P = Σ t·Rₜe^(−δt) / P(δ) = −P′(δ)/P(δ)**

- 是**时间**概念（单位：年），也等于「价格对利息力的单位变化速率」
- Dᴹ 越大 → 价格对利率越敏感 → 利率风险越高
- 到期时间只能粗糙衡量利率风险：同期限的零息债券比附息债券风险大（加权回收时间更长）

**典型值**（选择题高频，均基于年实际收益率 i）：

| 现金流 | 麦考利久期 Dᴹ |
| --- | --- |
| n 年零息债券 | **n** |
| n 年期等额分期偿还贷款 | **(1+i)/i − n/[(1+i)ⁿ−1]**（与本金、还款额无关，只取决于 n、i） |
| 期末付永续年金 | **(1+i)/i = 1/d** |
| 期初付永续年金 | **1/i**（现值 ä∞=(1+i)/i，用 Dᴹ=−P′(δ)/P 求导即得） |
| n 年期平价附息债券（r=i） | **äₙ = (1−vⁿ)/d**（教材式 7.12） |

**性质**：

- Dᴹ 是收益率的**减函数**（dDᴹ/dδ = −σ² < 0，σ² 为现金流时间方差）——收益率越高久期越小
- 期限越长久期**不一定**越大：低息票率+高收益率的长期债券，久期可能先升后降（教材图 7-2 反例：息票率 5%、收益率 15%，超过约 20 年后久期反而下降）
- 息票率越高久期越小（递减速度放缓）

**例 40**：3 年期债券面值 1000、息票率 10%、年收益率 10%（平价）。
Dᴹ = (1×90.91 + 2×82.64 + 3×826.45)/1000 = **2.74 年**。平价债券（r=i）可直接用 ä₃ = (1−1.1⁻³)/d = **2.74**。

**例 41**：15 年期按月等额偿还贷款，每月复利一次年名义利率 12%（月利率 1%，n=180）。
用教材式 Dᴹ = (1+i)/i − n·vⁿ/(1−vⁿ)：v¹⁸⁰ = 1.01⁻¹⁸⁰ ≈ 0.1683，代入得 101 − 180×0.1683/0.8317 ≈ **64.5 月 ≈ 5.4 年**（教材值 64.97 月，中间值取整导致的小差异，方法一致）。

### 7.2 修正久期（★★★ 计算高频）

**修正久期 D**（modified duration）：价格关于**名义收益率 y** 的单位变化速率（强度概念，非时间）：

> **D = −P′(y)/P(y) = Dᴹ/(1 + y/m)**（m 为年复利次数；y = i 时 D = Dᴹ/(1+i)）

- D 越大 → 价格波动越大 → 利率风险越大
- **价格近似**：ΔP/P ≈ −D·Δy（收益率变化 Δy 用基点表示，1 bp = 0.01%）
- m→∞ 时 D → Dᴹ（麦考利久期是修正久期的连续复利极限）
- D 也是收益率的减函数
- 基于不同收益率口径（名义 vs 实际）的修正久期**数值不同、含义不同**，必须说明口径

**例 42**：2 年期零息债券，i⁽¹²⁾ = 12%。Dᴹ = 2。
基于名义收益率：D = 2/(1+0.12/12) = **1.98**；基于年实际收益率 12.68%：D = 2/1.1268 = **1.77**。

**例 43**：债券价格 115.92、YTM 7%、修正久期 8.37，YTM 升到 7.05% 时价格 ≈ 115.92×(1 − 8.37×0.0005) = 115.92×(1−0.42%) = **115.43 元**（精确值还要加凸度修正）。

**n 年期期末付复递增年金**（增长率 r，净利率 j = (i−r)/(1+r)）的修正久期：D = [1/j − n(1+j)⁻ⁿ/(1−(1+j)⁻ⁿ)]/(1+i)（教材式 7.18，考频低，理解链式求导思路即可）。

### 7.3 有效久期（★★）

现金流**不确定**（可赎回债券等利率敏感型资产）时无法解析求导，用**割线斜率**近似：

> **Dᴱ = (P₋ − P₊) / (2·P₀·Δy)**

P₊/P₋ = 收益率升/降 Δy 后的价格。用 Δδ 代替 Δy 则近似的是麦考利久期。

**例 44**：可赎回债券 P₀=100，收益率 ±100bp 时 P₊=95.87、P₋=104.76。
Dᴱ = (104.76−95.87)/(2×100×0.01) = **4.445**。收益率升 50bp 时价格 ≈ 100×(1−4.445×0.005) = **97.78 元**（只用久期；加凸度修正后 97.86）。

### 7.4 凸度家族（★★★）

**凸度 C**（convexity）：价格关于名义收益率的**二阶导数**与价格之比，度量久期线性近似的误差：

> **C = P″(y)/P(y) = Σ t(t+1)Rₜv^(t+2)/[P·(1+y/m)²]**；m=1 时 **C = Σt(t+1)Rₜ(1+i)⁻ᵗ⁻²/P**

**麦考利凸度 Cᴹ**：基于利息力，= 现金流时间**平方的加权平均**：Cᴹ = P″(δ)/P(δ) = Σt²Rₜe^(−δt)/P

三个重要关系（计算题跳板）：

1. **Cᴹ = (Dᴹ)² + σ²**（σ² 为现金流时间方差）⟹ Cᴹ ≥ (Dᴹ)²
2. **C = (Dᴹ + Cᴹ)(1+i)⁻²**（用麦考利久期凸度算凸度的捷径）
3. n 年零息债券：Dᴹ = n、Cᴹ = n²、**C = n(n+1)(1+i)⁻²**

**有效凸度**：Cᴱ = (P₊ + P₋ − 2P₀)/(P₀·(Δy)²)

**例 45**：10 年期年金每年末付 1、i=5%。P = a₁₀ = 7.7217；修正久期 D = 4.86；C = Σt(t+1)v^(t+2)/P = 274.91/7.72 = **35.61**；Cᴹ = Σt²vᵗ/P = 263.72/7.72 = **34.16**。
验证关系式 C = (Dᴹ+Cᴹ)(1+i)⁻²：Dᴹ = D(1+i) = 5.10，(5.10+34.16)/1.1025 = 39.26/1.1025 = **35.6** ✓。

**例 46**：期初付永续年金（i 常数）：P(δ) = ä∞ = 1/(1−e^(−δ))。令 x = v = e^(−δ)，则 P = 1/(1−x)：
- 一阶：Dᴹ = −P′(δ)/P = **1/i**
- 二阶：P″(δ) = x(1+x)/(1−x)³ → **Cᴹ = x(1+x)/(1−x)² = v(1+v)/d² = (2+i)/i²**

验证 Cᴹ = (Dᴹ)² + σ²：σ² = v/d²（如 i=5% 时 Cᴹ = 820、(Dᴹ)² = 400、σ² = 420 ✓）。

### 7.5 久期凸度的应用：价格变化估计（★★★）

泰勒展开保留二阶项：

> **ΔP/P ≈ −D·Δy + ½·C·(Δy)²**（名义收益率口径：修正久期 + 凸度配对）
> **ΔP/P ≈ −Dᴹ·Δδ + ½·Cᴹ·(Δδ)²**（利息力口径：麦考利久期 + 麦考利凸度配对）

**久期与凸度的配对使用**（简答易错）：用名义收益率就配「修正久期+凸度」；用利息力就配「麦考利久期+麦考利凸度」；现金流不确定就配「有效久期+有效凸度」。

**例 47**：15 年期债券面值 1000、息票率 11%、YTM 12%。P = 110a₁₅+1000v¹⁵ = **931.89**；Dᴹ = 7220.86/931.89 = **7.75**；D = 7.75/1.12 = **6.92**；C = 69585.71/931.89 = **74.67**。
YTM 升 50bp 到 12.5%：真实价格 900.51（−3.37%）；只用久期：−6.92×0.005 = −3.46%（低估）；久期+凸度：−3.46% + ½×74.67×0.005² = −3.46%+0.093% = **−3.37%** ✓（几乎精确）。

**组合久期/凸度** = 各成分以**市值为权**的加权平均：D = Σ(Pₖ/P)Dₖ。
**久期的局限**（简答）：假设收益率曲线平坦且只平移；实际上短端波动大于长端、曲线可能扭曲（短升长降），组合久期失效，必须定期再调整。

**理想债券**：久期小 + 凸度大——凸度对投资者**总是有利**（涨得多跌得少），久期是双刃剑。

### 7.6 免疫策略（★★★ 简答 + 计算）

**Redington 免疫**三条件（负债给定、调整资产，使盈余 S = PV(A) − PV(L) 在利率微小变动时不减少）：

1. **PV(A) = PV(L)**（现值相等）
2. **D(A) = D(L)**（久期相等 ⟹ S′(y) = 0）
3. **C(A) > C(L)**（凸度更大 ⟹ S″(y) > 0，S 取极小值 0）

泰勒展开：S(y+Δy) ≈ S + Δy·S′ + ½(Δy)²S″ = 0 + 0 + 正项 > 0 ⟹ 利率无论微升微降盈余都增加。
**前提**：收益率曲线平坦且只发生**微小平移**；久期凸度随时间漂移，需**定期再调整**；条件三若总能满足意味着无风险套利，实践中很难。

**例 48**（教材例 7-20 精髓）：负债 200 万、10 年后到期、利率 6%（D_L = 10，麦考利凸度 = 100）。三种债券：A（10 年、息票 6.7%、Dᴹ=7.67）、B（15 年、息票 6.988%、Dᴹ=10、Cᴹ=126.5）、C（30 年、息票 5.9%、Dᴹ=14.64）。
- 只有 **B 满足久期匹配**（Dᴹ=10）且 Cᴹ=126.5 > 100 → 无论利率升降第 10 年末累积值 ≥ 358.17 万（免疫 ✓）
- 利率降到 5% 时：A 累积 350.49 万（不足！）、B 358.61、C 376.04
- **A+C 组合**：66.5%A + 33.5%C 使组合久期 = 7.67p+14.64(1−p) = 10，组合凸度 = 0.665×68.73+0.335×318.11 = **152.27 > B 的 126.5** → 免疫能力更强（杠铃策略优于子弹策略）

**完全免疫**（full immunization）：收益率曲线发生**任意大小**的平移时盈余都不减少。三条件：

1. PV(A) = PV(L)
2. D(A) = D(L)
3. **负债到期时间 t 夹在两笔资产到期时间之间：t−a < t < t+b**

（满足完全免疫 ⟹ 必满足 Redington 免疫：单笔负债 σ²=0、两笔资产 σ²>0 ⟹ Cᴹ(A) = t²+σ² > t² = Cᴹ(L)。）

**例 49**：10 年末负债 2000 万，持有 5 年期零息债（到期值 620.92 万）+ 15 年期零息债（到期值 1610.51 万），i=10%。
验证：PV(A) = 620.92/1.1⁵ + 1610.51/1.1¹⁵ = 400.0+371.1 = 771.09 万 = PV(L) = 2000/1.1¹⁰ ✓；Dᴹ(A) = 10 ✓；5<10<15 ✓ → **完全免疫**。利率升到 12%：盈余 = +2.6 万 > 0（利率任意变动盈余都增加）。

### 7.7 现金流配比（★★）

**现金流配比**（cash flow matching / dedication）：对每笔未来负债安排**相同到期时间、相同金额**的资产逐一匹配。

- 优点：无需不断调整组合（免疫需要动态再平衡）
- 缺点：限制投资选择灵活性；找不到匹配资产就只能放弃
- 有各期限零息债券时最简单；只有附息债券时**从最长期限负债开始倒序配比**：先买足匹配最远负债的债券，扣除其全部现金流（含中途息票），再配比次远负债，递推至全部匹配

**例 50**（教材例 7-22）：负债（万元）：第 1–5 年 4090/6790/3550/36550/5250。可选：2 年期 20% 息票、4 年期 10%、5 年期 5%（面值均 100）。
- 第 5 年末负债 5250 ÷ 5 年债到期现金流 105 = **50 万份** 5 年期债（其息票每年 250 抵减前 4 年负债）
- 剩余负债最远在第 4 年末 36300 ÷ 110 = **330 万份** 4 年期债（息票每年 3300）
- 剩余最远第 2 年末 3240 ÷ 120 = **27 万份** 2 年期债 → 全部配比完成

### 7.8 易错点

- 麦考利久期是**时间**、修正久期是**强度**；D = Dᴹ/(1+y/m)，m=1 时 D = Dᴹ/(1+i)。
- 久期匹配必须**口径一致**：名义收益率配修正久期，利息力配麦考利久期。
- 零息债券：Dᴹ = n（到期时间）但 D = n/(1+i)^…（按口径折算）；C = n(n+1)/(1+i)²。
- 期限长 ≠ 久期大（低息票 + 高收益率的超长期债券久期可能回落）。
- 凸度对投资者永远有利；「久期小 + 凸度大」是最理想组合。
- Redington 免疫第三条件是 C(A) **>** C(L)（严格大于）；完全免疫第三条件是**时间夹逼**。
- 完全免疫 ⟹ Redington 免疫，反之不然。
- 现金流配比从**最长期限**负债开始倒推，不是从最短。
- 免疫是时点状态，久期随时间和利率漂移 → 必须定期再调整。

| 账面值 | 按购买时收益率计算的投资余额，Vₜ = Vₜ₋₁(1+i) − rF |
| 溢价分摊 | 每期息票超过应得利息的部分，逐期递增，冲减账面值 |
| 基价 G | 产生与息票等额周期收益所需的投资，G = rF/i |
| Makeham 公式 | P = (g/i)(C−K)+K，适合分期偿还债券 |
| 可赎回债券 | 发行人有权按约定价格提前赎回，价格取各赎回日最低价 |
| 麦考利久期 | 现金流到期时间的现值加权平均，= −P′(δ)/P |
| 修正久期 | 价格对名义收益率的单位变化速率，= Dᴹ/(1+y/m) |
| 有效久期 | 现金流不确定时用割线斜率近似的久期 (P₋−P₊)/(2P₀Δy) |
| 凸度 | 价格对收益率的二阶导数与价格之比，度量线性近似误差 |
| 麦考利凸度 | 现金流时间平方的加权平均 = (Dᴹ)²+σ² |
| 基点 | 0.01%，100 bp = 1% |
| Redington 免疫 | 现值相等 + 久期相等 + 资产凸度更大，抵御微小利率平移 |
| 完全免疫 | 前两条件 + 负债到期日夹在两笔资产到期日之间，抵御任意平移 |
| 现金流配比 | 每笔负债匹配同期限同金额资产，从最长期限倒序配置 |
