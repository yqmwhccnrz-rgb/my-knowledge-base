# 计量经济学笔记

::: info 笔记概要
- **所属课程**：计量经济学（经济学类 / 统计学类等专业核心基础课）。
- **核心内容**：以「经典线性回归模型」为主线——用经济理论提出可检验的假设，用数据估计参数，用统计推断判断关系是否显著，再检验模型假定是否被破坏、如何修正，最后延伸到时间序列、联立方程、面板数据与离散选择等非标准情形。重点抓三条线：① **模型与假定**（总体回归函数、六大古典假定、高斯-马尔可夫定理）；② **估计与检验**（OLS/ML/GMM、t / F / Wald / LM / LR、置信区间与 p 值）；③ **诊断与对策**（异方差、自相关、多重共线性、内生性各自的后果、检验统计量、修正方法）。

## 第 1 章 绪论

### 1.1 什么是计量经济学（★★）

计量经济学（Econometrics）＝**经济理论 + 数学 + 统计推断**，用数据给经济关系以「经验内容」。三个经典定义可作对照：

| 来源 | 定义要点 |
| --- | --- |
| 萨缪尔森等（1954） | 对经济关系给出经验内容 |
| 戈德伯格（1964） | 把经济理论、数学与统计推断应用于经济现象分析的社会科学 |
| 现代教材通行表述 | 以经济理论为先验、以数据为证据，对经济关系进行**估计、检验与预测**的方法论 |

与相关学科的区别：**数理经济学**用数学表述理论但不接触数据；**经济统计学**描述与整理数据但不检验理论；**计量经济学**则把二者连接起来——先将理论写成可检验的**随机**模型，再用样本推断总体参数。

::: tip 为什么模型必须有随机扰动项 u
经济行为不可能被少数几个变量完全解释，必须留一个 `u` 容纳：① 被省略的次要因素；② 测量误差；③ 人类行为的随机性；④ 函数形式的近似误差；⑤ 模型设定误差。正因 `u` 随机，`Y` 也是随机变量，才需要统计推断——这也是计量经济学区别于确定性数学模型的根本点。
:::

### 1.2 计量经济学方法论（★★★）

传统方法论八步：
```text
① 理论/假设陈述 → ② 建立数学模型（含随机项） → ③ 建立计量经济模型
→ ④ 获取数据 → ⑤ 估计参数 → ⑥ 假设检验（经济/统计/计量经济检验）
→ ⑦ 模型诊断与修正 → ⑧ 用于预测或政策评价
```

| 检验层次 | 检验什么 | 常用工具 |
| --- | --- | --- |
| 经济意义检验 | 系数符号、大小是否符合理论（如需求斜率应为负） | 与经济理论对照 |
| 统计检验 | 拟合优度、参数与方程显著性 | R²、t、F、置信区间 |
| 计量经济检验 | 古典假定是否成立 | 异方差/自相关/多重共线性/内生性检验 |
| 模型稳定性与外推 | 结构是否稳定、能否预测 | Chow 检验、递归残差、样本外预测 |

::: tip 现代研究范式的转变
传统框架「先设定模型、再检验」。现代应用计量更强调 **研究设计（design-based）**：先明确**识别策略**与反事实，再谈估计。核心问题是「这个系数能否被解释为因果效应」，而不只是「显著性星号有几颗」。因此需要掌握潜在结果框架（RCM）、随机对照试验（RCT）、双重差分（DID）、断点回归（RDD）、工具变量（LATE）、合成控制等（详见 5.5 节与 5.7 节）。
:::

### 1.3 数据类型（★★★）

| 类型 | 定义 | 例子 | 主要注意点 |
| --- | --- | --- | --- |
| 横截面数据 | 同一时点、多个个体 | 某年 500 户家庭消费调查 | 异方差常见；个体异质性 |
| 时间序列数据 | 同一个体、多个时期 | 1990–2025 年 GDP | 自相关、非平稳、趋势/季节 |
| **面板数据** | 同一批个体、多个时期 | 4 个产业 × 20 年投资额 | 个体效应、组内/组间变异 |
| 混合数据 pooled | 不同时点不同个体（个体不固定） | 多期独立抽样 | 不能当面板用固定效应 |

![计量经济学方法论与数据类型](/econ/econ-overview.svg)

::: tip 工作示例 · 需求函数的估计与预测
某商品需求函数估计结果为 `Q̂ = 76.05 − 3.88P`，问 `P = 4.50` 时的需求量预测值。

```text
Q̂ = 76.05 − 3.88 × 4.50 = 76.05 − 17.46 = 58.59
```
延伸：斜率 `−3.88` 表示价格每上升 1 个单位，需求量平均减少 3.88 个单位；若 `P` 与 `Q` 的单位分别是「元/件」与「万件」，则要看 elasticity 才便于跨商品比较：`ε = (dQ/dP)·(P/Q) = −3.88 × 4.50/58.59 ≈ −0.298`，即价格上升 1%，需求量约下降 0.30%（缺乏弹性）。**注意**：预测只能给出点估计，严格报告还需给预测区间（第 3 章）。
:::

### 1.4 模型、软件与工作流（★★）

- 常见软件：EViews / Stata（教学与实证研究主流）、R（`lm`、`plm`、`fixest`）、Python（`statsmodels`、`linearmodels`）、SAS / SPSS、Gretl。
- 一个可复现的实证流程：数据清洗与描述统计 → 散点图与相关系数 → 设定基准模型 → OLS 估计并报告**系数、标准误、t 值、p 值、R²、n** → 诊断检验 → 稳健性（换设定/换样本/换估计量）→ 结果解释（区分**相关**与**因果**）。
- 报告规范：系数下方括注标准误或 t 值，用 `* / ** / ***` 标注显著性并注明阈值，报告使用的标准误类型（普通 / 异方差稳健 / 聚类稳健）。

::: danger 易错 · 绪论
- 计量经济学**不是**「用统计软件跑回归」：理论设定、识别与诊断比点一个按钮重要得多。
- 「模型通过 t 检验」不等于「模型正确」：可能存在内生性、误设定、样本选择偏差，这些都不会体现在 t 值上。
- 混合数据 ≠ 面板数据：只有**同一批个体**在多个时期都被观测到才是面板，否则不能用固定效应估计量。
:::

## 第 2 章 计量经济分析的统计学基础

### 2.1 概率、随机变量与常用分布（★★）

| 概念 | 定义 / 结论 |
| --- | --- |
| 期望 `E(X)` | 随机变量分布的集中位置；`E(aX+b)=aE(X)+b` |
| 方差 `Var(X)` | `E[(X−E(X))²]`；`Var(aX+b)=a²Var(X)` |
| 协方差 `Cov(X,Y)` | 共变程度；独立 ⇒ 协方差为 0，**反之不成立** |
| 相关系数 `ρ` | `Cov(X,Y)/(σ_X σ_Y) ∈ [−1,1]`，只度量**线性**相关 |
| 条件期望 | `E(Y|X)` 是回归分析的数学核心（总体回归函数即条件均值） |

| 分布 | 由谁构造 | 在计量中的用途 |
| --- | --- | --- |
| 标准正态 `N(0,1)` | — | 大样本下 z 检验、渐近推断 |
| χ²(m) | m 个独立标准正态平方和 | LM 检验、Wald/LR 检验、方差检验 |
| t(m) | `Z / sqrt(χ²(m)/m)` | **单个系数显著性检验**（小样本、未知 σ） |
| F(m, n−k−1) | `(χ²(m)/m)/(χ²(df)/df)` | **多个线性约束的联合检验**、整体显著性 |

::: tip 三大抽样分布的关系
`Z ∼ N(0,1)`、`V ∼ χ²(m)` 且独立 → `t = Z/√(V/m) ∼ t(m)`；`U ∼ χ²(m)`、`V ∼ χ²(r)` 独立 → `F = (U/m)/(V/r) ∼ F(m,r)`。由此可得两个常用结论：**`t²(m) = F(1, m)`**（单系数 t 检验与 F 检验等价），以及 `m·F(m,·) → χ²(m)`（大样本下 LM/Wald/LR 都渐近服从 χ²）。
:::

### 2.2 抽样分布、估计量的性质（★★★）

估计量是样本的函数，因而是**随机变量**，有自己的分布（抽样分布）。

| 性质 | 含义 | 数学表达 |
| --- | --- | --- |
| 无偏性 | 抽样分布均值等于真值（小样本性质） | `E(θ̂) = θ` |
| 有效性 | 在同类中方差最小 | `Var(θ̂) ≤ Var(θ̃)` |
| 最小均方误差 | 兼顾偏差与方差 | `MSE = Var + Bias²` |
| **一致性** | 样本增大时依概率收敛到真值（大样本性质） | `plim θ̂ = θ` |
| 渐近正态 | 大样本下可近似用正态分布做推断 | `√n(θ̂−θ) → N(0, V)` |

![抽样分布、置信区间与假设检验](/econ/econ-inference.svg)

::: danger 易错 · 无偏 ≠ 一致，有效 ≠ 无偏
- **无偏是小样本性质**，与 n 无关；**一致是大样本性质**。无偏但不一致的例子：`θ̂ = X₁`（用第一个观测估计均值，无偏但方差不随 n 缩小）；有偏但一致的例子：样本方差用 `1/n` 而非 `1/(n−1)`（有偏，但 n→∞ 时偏差消失）。
- 「有效性」必须在**同类估计量**（如都是线性无偏）内比较；有偏估计量方差可以更小（岭回归、LASSO 正是用偏差换方差）。
- 中心极限定理给的是**估计量的渐近分布**，不是「样本数据的分布变成正态」。
:::

### 2.3 参数估计与区间估计（★★）

| 方法 | 思想 | 例子 |
| --- | --- | --- |
| 矩估计 MM | 用样本矩替代总体矩 | `μ̂ = X̄` |
| **最小二乘 OLS** | 使残差平方和最小 | 第 3 章 |
| **极大似然 MLE** | 使观测样本出现概率最大 | Logit/Probit、GARCH |
| 广义矩 GMM | 让样本矩条件尽可能接近 0 | 动态面板、工具变量 |

**置信区间**：`θ̂ ± 临界值 × se(θ̂)`。95% 置信度的正确含义是「**反复抽样**构造的区间中约 95% 会覆盖真值」，不是「真值以 95% 概率落在这个已算出的区间里」（频率学派下真值固定、区间随机）。

::: tip 工作示例 · 均值区间估计
`n=25`，样本均值 `X̄=10`，已知总体标准差 `σ=2`：
```text
se(X̄) = σ/√n = 2/5 = 0.4
95% CI = 10 ± 1.96 × 0.4 = [9.216, 10.784]
若 σ 未知、样本标准差 s=2，改用 t(24) 临界值 2.064：
95% CI = 10 ± 2.064 × 0.4 = [9.174, 10.826]（略宽）
```
n 越大区间越窄（精度 ∝ 1/√n）：要把宽度减半，样本量需增到 4 倍。
:::

### 2.4 假设检验（★★★）

| 概念 | 内容 |
| --- | --- |
| 原假设 H₀ / 备择 H₁ | 通常把「想推翻的」放 H₀（如 `β=0`）；检验只在 H₀ 成立时构造抽样分布 |
| 第一类错误 | H₀ 为真却拒绝，概率 = **显著性水平 α**（常取 0.05 / 0.01 / 0.10） |
| 第二类错误 | H₀ 为假却未拒绝，概率 = β；`1−β` 称检验功效（power） |
| **p 值** | H₀ 成立时，观测到「当前这么极端或更极端」结果的概率；`p < α` 则拒绝 |
| 拒绝域 | 双侧 `|t| > t_{α/2}`；单侧 `t > t_α` 或 `t < −t_α` |
| 检验流程 | 设 H₀/H₁ → 选统计量与其分布 → 定 α 与临界值 → 算统计量 → 比较或看 p 值 → 用**经济语言**下结论 |

::: tip p 值与置信区间的对偶
- 双侧检验在 α 水平拒绝 H₀: `β=β₀` ⟺ `β₀` 落在 `(1−α)` 置信区间**之外**。
- 「不拒绝 H₀」≠「接受 H₀ 为真」，只表示**证据不足**（尤其小样本、功效低时）。
- 「统计显著」≠「经济显著」：n 很大时微小系数也能 p<0.001，需同时看效应大小与置信区间。
- 多重检验会抬高整体第一类错误率（20 个无关变量平均会「显著」1 个），应做 Bonferroni / FDR 校正或预先注册假设。
:::

::: tip 常用临界值速查
`z: 1.645(单侧5%) / 1.96(双侧5%) / 2.576(双侧1%)`
`χ²: 3.84(df=1,5%) / 5.99(df=2,5%) / 7.81(df=3,5%)`
`t: 2.064(df=24,双侧5%) / 3.182(df=3,双侧5%) / 1.96(df→∞)`
`F(1, df)=t²(df)`；`F(2,26,5%)≈3.37`，`F(3,26,5%)≈2.98`。
:::

::: tip 工作示例 · 检验功效计算
设 `θ̂ ∼ N(θ, 1)`，双侧检验 `H₀: θ=0`，α=0.05（拒绝域 `|θ̂| > 1.96`），真实 `θ=2`：
```text
功效 = P(θ̂ > 1.96 | θ=2) + P(θ̂ < −1.96 | θ=2)
     = P(Z > −0.04) + P(Z < −3.96) = 0.5160 + 0.00004 ≈ 0.516
```
含义：真效应为 2 个标准误时，重复抽样仍有约 **48% 的概率检不出来**（第二类错误）。要提高到 80%，需 `θ ≈ 2.8` 个标准误（即把样本量约增到 2 倍）——**「不显著」经常只是样本不够**。
:::

## 第 3 章 双变量线性回归模型

### 3.1 总体回归函数与样本回归函数（★★★）

| 概念 | 表达式 | 说明 |
| --- | --- | --- |
| 总体回归函数 PRF | `Y_i = β₀ + β₁X_i + u_i` | `E(Y_i|X_i) = β₀+β₁X_i`，β 是**未知常数**，u 是总体扰动 |
| 样本回归函数 SRF | `Ŷ_i = β̂₀ + β̂₁X_i` | β̂ 是**估计量/估计值**（随机变量） |
| 残差 | `e_i = Y_i − Ŷ_i` | e 是 u 的**估计**，二者不可混用：`u` 不可观测、`e` 可计算 |

「双变量」指只有**一个解释变量 + 一个被解释变量**（不含常数项），又称一元 / 简单线性回归。

![OLS 最小二乘原理与拟合](/econ/econ-ols.svg)

### 3.2 古典（高斯-马尔可夫）假定（★★★）

| # | 假定 | 数学表达 | 被破坏的后果 |
| --- | --- | --- | --- |
| A1 | 参数线性 | `Y = β₀ + β₁X + u` | 需改用非线性最小二乘 / 变换 |
| A2 | X 非随机（或与 u 不相关） | `Cov(X_i, u_i) = 0` | **内生性 → 有偏且不一致**（第 5 章） |
| A3 | 扰动项零均值 | `E(u_i|X) = 0` | 截距有偏；常数项可吸收非零均值 |
| A4 | **同方差** | `Var(u_i|X) = σ²` | 系数仍无偏但**不再有效**，标准误错 |
| A5 | **无自相关** | `Cov(u_i,u_j)=0 (i≠j)` | 标准误错、t/F 失效 |
| A6 | 解释变量有变异、无完全共线 | `Var(X)>0`，n > 参数个数 | 无法识别 |
| （可选 A7） | 正态性 `u ∼ N(0,σ²)` | — | 小样本精确 t/F 推断依赖它；大样本可用渐近正态替代 |

![高斯-马尔可夫假定与 BLUE](/econ/econ-gm.svg)

::: tip 高斯-马尔可夫定理
在 A1–A6 成立时，OLS 估计量是 **BLUE**：**B**est（方差最小）、**L**inear（Y 的线性组合）、**U**nbiased（无偏）、**E**stimator。即「在所有线性无偏估计量中方差最小」。
注意三点：① 定理**不要求正态性**（正态性只用于小样本精确检验）；② 「最佳」仅限**线性无偏**类，有偏估计量（岭回归）方差可以更小；③ 一旦 A2/A4/A5 被破坏，BLUE 结论不再成立。
:::

### 3.3 OLS 估计量的推导（★★★）

最小化 `Σe_i² = Σ(Y_i − β̂₀ − β̂₁X_i)²`，对两个参数求偏导并令为 0，得**正规方程**：

```text
ΣY_i = nβ̂₀ + β̂₁ΣX_i
ΣX_iY_i = β̂₀ΣX_i + β̂₁ΣX_i²
```
解得（小写字母表示离差 `x_i = X_i − X̄`）：

```text
β̂₁ = Σx_i y_i / Σx_i² = Sxy / Sxx = Cov(X,Y)/Var(X)
β̂₀ = Ȳ − β̂₁X̄
```
**OLS 的数值性质**（无论假定是否成立）：① 回归线过样本均值点 `(X̄, Ȳ)`；② `Σe_i = 0`（含截距时）；③ `Σe_iX_i = 0`（残差与解释变量不相关）；④ `Ȳ = Ŷ̄`；⑤ `SST = SSR + SSE`（总平方和 = 解释平方和 + 残差平方和）。

### 3.4 拟合优度与估计量方差（★★★）

```text
R² = SSR/SST = 1 − SSE/SST ∈ [0,1]（含截距且用 OLS 时）
Var(β̂₁) = σ²/Sxx，  Var(β̂₀) = σ²(1/n + X̄²/Sxx)
σ̂² = SSE/(n−2)   ← 用 n−2 是因为估计了两个参数（无偏估计）
se(β̂₁) = √(σ̂²/Sxx)
```
`R²` 高不代表模型正确、也不代表因果；`R²` 低不代表模型无用（横截面微观数据 `R²=0.1` 很常见）。

::: tip 补充考点 · 一元回归中 R² = r²
一元回归的决定系数恰等于 X 与 Y 的**样本相关系数的平方**：`R² = r_{XY}²`。因此 `r_{XY} = ±√R²`，符号与 `β̂₁` 一致（如 `R²=0.81`、斜率为负 ⇒ `r = −0.9`）。这也解释了为什么对 X、Y 做标准化（z 分数）后，回归斜率就等于相关系数。多元回归中此等式不再成立，`R²` 应理解为拟合值 `Ŷ` 与 `Y` 的相关系数的平方。
:::

### 3.5 区间估计、t 检验与 F 检验（★★★）

```text
t = (β̂₁ − β₁,H0) / se(β̂₁)  ∼  t(n−2)
95% CI = β̂₁ ± t_{0.025}(n−2) · se(β̂₁)
单解释变量时 F = t²（检验 H₀: β₁=0 等价于整体显著性检验）
```

::: tip 工作示例 · OLS 全套手算（务必自己复算一遍）
样本 `n=5`：`X = [1,2,3,4,5]`，`Y = [2,4,5,7,9]`。

```text
① 均值：X̄ = 3， Ȳ = 5.4
② 离差平方与交叉积：
   Sxx = (−2)²+(−1)²+0²+1²+2² = 10
   Sxy = (−2)(−3.4)+(−1)(−1.4)+0(−0.4)+1(1.6)+2(3.6) = 17.0
③ 估计：β̂₁ = 17/10 = 1.7， β̂₀ = 5.4 − 1.7×3 = 0.3
   Ŷ = 0.3 + 1.7X
④ 拟合与残差：
   X :  1     2     3     4     5
   Ŷ :  2.0   3.7   5.4   7.1   8.8
   e :  0.0   0.3  −0.4  −0.1   0.2
⑤ 平方和：SSE = 0+0.09+0.16+0.01+0.04 = 0.30
          SST = 29.20，SSR = 28.90
   R² = 28.90/29.20 = 0.9897   调整 R² = 0.9863
⑥ 方差与检验：σ̂² = 0.30/3 = 0.10
   se(β̂₁) = √(0.10/10) = 0.10
   t = 1.7/0.10 = 17.0  (> t₀.₀₂₅(3)=3.182，强烈拒绝 H₀: β₁=0)
   95% CI = 1.7 ± 3.182×0.10 = [1.382, 2.018]
   F = t² = 289
⑦ 预测：X=6 时 Ŷ = 0.3 + 1.7×6 = 10.5
```
**检查点**：残差和 `0+0.3−0.4−0.1+0.2 = 0` ✓；回归线过 `(3, 5.4)` ✓。
:::

### 3.6 预测：均值预测与个别值预测（★★）

| 类型 | 对象 | 标准误 |
| --- | --- | --- |
| 均值预测 | `E(Y|X₀)` | `se_mean = σ̂√(1/n + (X₀−X̄)²/Sxx)` |
| 个别值预测 | 单个 `Y₀` | `se_ind = σ̂√(1 + 1/n + (X₀−X̄)²/Sxx)` |

个别值预测区间**更宽**（多了扰动项自身的不确定性 `σ²`）。两者都在 `X₀ = X̄` 处最窄，`X₀` 离样本中心越远区间越宽；**样本外远推**风险很大（函数形式可能已变）。

::: danger 易错 · 一元回归
- `u` 与 `e` 不同；`Var(β̂)` 公式里的 `σ²` 是**扰动项方差**，要用 `SSE/(n−2)` 估计，不是 `SSE/n`。
- 「σ̂² 无偏」用 n−2；MLE 估计用 n（有偏但一致）。
- `R²` 不能跨不同被解释变量（如线性模型 vs 对数模型）直接比较；加变量 `R²` 只增不减，故多元要用调整 R²。
- t 检验显著只说明「线性关联显著」，不能推出「X 导致 Y」。
:::

### 3.7 OLS 无偏性与一致性的证明范式

**无偏性推导**（一元、X 非随机、`E(u_i)=0`）：
```text
β̂₁ = Σx_iY_i/Sxx = Σx_i(β₀+β₁X_i+u_i)/Sxx
    = β₁ + Σx_iu_i/Sxx                （用 Σx_i=0、Σx_iX_i=Sxx）
E(β̂₁) = β₁ + Σx_i E(u_i)/Sxx = β₁  ✓
Var(β̂₁) = Var(Σx_iu_i)/Sxx² = σ²Sxx/Sxx² = σ²/Sxx   （用同方差 + 无自相关）
```
可见**无偏性只需 A2/A3**，而 `Var(β̂₁)=σ²/Sxx` 还须 A4/A5。

**一致性**（X 随机但严格外生时）：
```text
plim β̂₁ = β₁ + plim[(1/n)Σx_iu_i]/plim[(1/n)Σx_i²] = β₁ + Cov(X,u)/Var(X)
```
因此只要 `Cov(X,u)=0` 就一致；这也直接给出**内生性偏误** `plim β̂₁ − β₁ = Cov(X,u)/Var(X)`。

## 第 4 章 多元线性回归模型

### 4.1 模型与偏回归系数（★★★）

```text
Y_i = β₀ + β₁X₁ᵢ + β₂X₂ᵢ + … + β_kX_{ki} + u_i
```
`β_j` 是**偏回归系数**：在**保持其它解释变量不变（ceteris paribus）**的前提下，`X_j` 变动 1 单位对 `Y` 的影响。这正是多元回归相对一元回归的核心价值——把「混杂因素」从相关关系中剥离出来。

::: tip 工作示例 · 遗漏变量如何造成偏误
真实模型 `Y = β₀ + β₁X₁ + β₂X₂ + u`，但只回归 `Y` 对 `X₁`，则
`plim β̃₁ = β₁ + β₂ · δ₁`，其中 `δ₁` 是 `X₂` 对 `X₁` 回归的斜率（辅助回归系数）。
偏误方向 = `sign(β₂) × sign(Corr(X₁,X₂))`。
经典例子：估计「教育回报率」时遗漏「个人能力」（与教育正相关、且提高工资）→ `β₁` **向上偏误**；解决办法是加入能力代理变量、用双胞胎数据固定效应，或用工具变量（义务教育法、学校距离）。
:::

### 4.2 矩阵形式与估计（★★★）

```text
y = Xβ + u        (X 为 n×(k+1) 矩阵，第一列全 1)
β̂ = (X′X)⁻¹X′y   ← 要求 X′X 可逆，即无完全多重共线且 n > k+1
Var(β̂) = σ²(X′X)⁻¹，  σ̂² = e′e/(n−k−1)
e = y − Xβ̂ = My（M = I − X(X′X)⁻¹X′ 为「残差制造者」矩阵）
```

### 4.3 拟合优度、信息准则与整体显著性（★★★）

| 指标 | 公式 | 用途 |
| --- | --- | --- |
| 调整 R² | `R̄² = 1 − (1−R²)(n−1)/(n−k−1)` | 惩罚加变量；**可能为负**；可比较同被解释变量模型 |
| 整体 F | `F = (R²/k)/[(1−R²)/(n−k−1)] ∼ F(k, n−k−1)` | 检验 H₀: `β₁=…=β_k=0` |
| AIC / SC(BIC) | `ln(SSE/n) + 2(k+1)/n` / `… + (k+1)ln(n)/n` | 越小越好；SC 对变量个数惩罚更重 |
| 约束 F | `[(SSE_r − SSE_u)/q] / [SSE_u/(n−k−1)] ∼ F(q, n−k−1)` | q 个线性约束的联合检验 |

**三大检验原理**（大样本渐近等价，小样本可能不同）：`Wald`（只估无约束模型，看约束离 0 多远）、`LM / 得分检验`（只估约束模型，看得分是否接近 0，`LM = nR²_aux`）、`LR`（两者都估，比较似然值 `2(lnL_u − lnL_r)`），三者均渐近 `∼ χ²(q)`。一般 `Wald > LR > LM`。

::: tip 工作示例 · 约束 F 检验与调整 R²
无约束模型 `n=30, k=3, R²_u=0.86`；施加 `q=2` 个约束后 `R²_r=0.62`。

```text
F = [(0.86−0.62)/2] / [(1−0.86)/(30−3−1)]
  = 0.12 / (0.14/26) = 0.12/0.0053846 = 22.29
F₀.₀₅(2,26) ≈ 3.37 → 拒绝约束，说明被排除的两个变量联合显著
R̄² = 1 − (1−0.86)×29/26 = 1 − 0.1562 = 0.8438
整体 F = (0.86/3)/(0.14/26) = 53.24 > F₀.₀₅(3,26)≈2.98 → 方程整体显著
```
注意：单个 t 都不显著但整体 F 显著，常是**多重共线性**的信号（第 5 章）。
:::

### 4.4 虚拟变量与函数形式（★★★）

| 设定 | 模型 | 解释 |
| --- | --- | --- |
| 截距虚拟变量 | `Y = β₀ + δD + β₁X + u` | `D=1` 组相对基准组截距差 δ |
| 斜率虚拟变量（交互） | `Y = β₀ + β₁X + δ(D·X) + u` | 两组斜率差 δ |
| 多重类别 | m 个类别放 **m−1** 个虚拟变量 | 全放且含截距 ⇒ **虚拟变量陷阱**（完全共线） |
| 结构变动 | Chow 检验 = 约束 F 检验 | 检验两组所有系数是否相同 |
| 线性-对数 | `Y = β₀ + β₁lnX` | X 上升 1% → Y 变动 `β₁/100` 单位 |
| 对数-线性 | `lnY = β₀ + β₁X` | X 上升 1 单位 → Y 变动约 `100β₁%` |
| **双对数** | `lnY = β₀ + β₁lnX` | `β₁` 直接是**弹性**（最常用） |
| 多项式 / 交互 | `Y = β₀+β₁X+β₂X²` | 边际效应 `β₁+2β₂X` 随 X 变化 |

![多元回归、偏效应与虚拟变量](/econ/econ-multiple.svg)

::: danger 易错 · 多元回归
- 「控制其它变量不变」是**统计上的偏效应**，不代表现实中可以只动一个变量（变量间往往联动）。
- `β̂_j` 的方差随其它解释变量对 `X_j` 的解释力上升而变大：`Var(β̂_j) = σ²/[Sxx_j(1−R²_j)]`，这就是多重共线性的数学根源。
- 加控制变量要警惕**坏控制（bad control）**：控制受处理影响的变量会阻断因果路径（如估计教育对工资影响时控制「职业」）。
- 对数变换要求变量为正；`lnY` 模型的 `R²` 与 `Y` 模型的 `R²` **不可直接比较**。
- 交互项显著时，主效应系数只表示「另一变量为 0 时」的效应，别当成平均效应。
:::

::: tip 补充考点 · Chow 检验的完整操作步骤
检验两个子样本（如改革前/后）的回归系数是否发生结构性变化：
① 分别对子样本 1（n₁）、子样本 2（n₂）与合并样本回归，得 `SSE₁、SSE₂、SSE_p`（p = pooled）；
② `F = [(SSE_p − (SSE₁+SSE₂))/(k+1)] / [(SSE₁+SSE₂)/(n₁+n₂−2(k+1))] ∼ F(k+1, n₁+n₂−2k−2)`，q = k+1（所有系数含截距）；
③ F 大于临界值 ⇒ 结构发生变化，应分段建模或加虚拟变量交互项。
**注意**：任一子样本观测数少于待估参数个数时 Chow 检验失效，改用**虚拟变量法**（D 与各变量交互）等价检验；它本质就是 4.3 节约束 F 检验的特例。
:::

### 4.5 残差几何与 Frisch–Waugh–Lovell 定理

```text
帽子矩阵 H = X(X′X)⁻¹X′   拟合值 ŷ = Hy
残差制造者 M = I − H       残差 e = My = Mu
性质：H、M 对称幂等（H²=H, M²=M），HM=0，MX=0，rank(H)=k+1
SSE = e′e = u′Mu；E(SSE) = σ²·tr(M) = σ²(n−k−1) → σ̂²=SSE/(n−k−1) 无偏
```
**FWL 定理**：多元回归 `y = X₁β₁ + X₂β₂ + u` 中
```text
β̂₁ = (X₁′M₂X₁)⁻¹X₁′M₂y ，其中 M₂ = I − X₂(X₂′X₂)⁻¹X₂′
```
即「先用 y 与 X₁ 分别对 X₂ 回归取残差，再用两组残差做简单回归」。这解释了：
- 偏回归系数为何是「**剔除其它变量线性影响后**」的净效应；
- 固定效应（去个体均值）为何等价于加个体虚拟变量；
- 加控制变量后系数变化，本质是 X₁ 被「净化」了。

### 4.6 函数形式、边际效应与转折点

| 模型 | 系数含义 | 边际效应 |
| --- | --- | --- |
| `Y = β₀+β₁X` | 绝对变化 | `β₁`（常数） |
| `lnY = β₀+β₁X` | X 增 1 单位 → Y 约变 `100β₁%` | `β₁·Y`（随 Y 变） |
| `Y = β₀+β₁lnX` | X 增 1% → Y 变 `β₁/100` 单位 | `β₁/X` |
| `lnY = β₀+β₁lnX` | **弹性** | `β₁·Y/X` |
| `Y = β₀+β₁X+β₂X²` | 二次（U 型/倒 U 型） | `β₁+2β₂X` |

::: tip 工作示例 · 倒 U 型转折点（环境库兹涅茨曲线、经验-工资曲线常用）
估计得 `Ŷ = 10 + 2X − 0.1X²`：
```text
边际效应 dY/dX = 2 − 0.2X
令其为 0 → 转折点 X* = 2/0.2 = 10
X<10 时正效应，X>10 时负效应（倒 U 型）
```
**报告要点**：不能只报 `β₂` 显著为负就说存在倒 U 型，还须检验转折点是否落在**样本数据支持区间**内（Lind-Mehlum 检验），并检查两端区间是否都有足够数据，否则可能只是单调凹曲线的一段。
:::

## 第 5 章 模型的建立与估计中的问题及对策

本章是全课程的核心：**OLS 的优良性质依赖一组假定，实践中的主要工作就是检验假定并修正**。

![五大问题诊断流程](/econ/econ-diagnostics.svg)

### 5.1 误设定（Misspecification）（★★★）

| 错误类型 | 后果 | 检验 / 对策 |
| --- | --- | --- |
| **遗漏相关变量** | 系数**有偏且不一致**（除非遗漏变量与已含变量不相关） | 理论分析、RESET 检验、加入代理变量 / 固定效应 / IV |
| **包含无关变量** | 系数仍无偏一致，但**方差变大**（效率损失） | t 检验、信息准则；不必为了「显著」硬删 |
| 错误的函数形式 | 系数与预测都有偏 | 残差图、RESET、Box-Cox、加平方项/交互项 |
| 测量误差 | 解释变量测量误差 ⇒ **衰减偏误（attenuation）**，系数被压向 0 | 工具变量、多重指标、验证数据 |
| 样本选择 / 同时性 | 选择性偏差、内生性 | Heckman 两阶段、IV |

**Ramsey RESET 检验**：把拟合值的幂 `Ŷ², Ŷ³` 作为附加回归元做 F 检验；显著即提示函数形式误设定。

::: danger 易错 · 误设定与 R²
「加变量让 R² 上升」不能证明模型更好——R² 单调不减，无关变量也会让它上升。判断应看调整 R²、AIC/SC、系数显著性与**理论依据**；反过来，为了得到想要的系数符号而删掉理论上重要的变量，会造成遗漏变量偏误。
:::

### 5.2 多重共线性（Multicollinearity）（★★★）

**完全共线** ⇒ `X′X` 不可逆，OLS 无法计算；**高度（不完全）共线**可估计，但：
① 系数方差与标准误**膨胀** → t 值小、个别不显著而整体 F 显著；
② 系数对样本与设定极敏感、符号可能反常；
③ **预测**（在共线模式继续成立的范围内）仍可可靠。

| 诊断 | 判据 |
| --- | --- |
| 相关系数矩阵 | 两解释变量 `|r| > 0.8` 提示（但无法发现多变量线性组合） |
| **VIF** | `VIF_j = 1/(1−R²_j)`，`R²_j` 为 `X_j` 对其余解释变量回归的决定系数；`VIF>10` 通常认为严重 |
| 容忍度 | `Tol = 1/VIF` |
| 条件数 / 特征值 | 条件数 > 30 提示严重共线 |

::: tip 工作示例 · VIF 手算
把 `X₁` 对其余解释变量做辅助回归得 `R²₁ = 0.90`，则
`VIF₁ = 1/(1−0.90) = 10`，即 `Var(β̂₁)` 是**无共线时的 10 倍**（标准误是 √10 ≈ 3.16 倍）。
对照：`R²_j = 0.8 → VIF=5`；`0.95 → 20`；`0.99 → 100`。
**补救**：① 增加样本或获取更多信息；② 删去冗余变量（须有理论依据）；③ 变量变换（差分、标准化、取比值）；④ 合并成指数/主成分；⑤ 用有偏估计（岭回归、LASSO）预测；⑥ 若研究目标是**总效应**，直接检验线性组合而不纠结单个系数。
:::

### 5.3 异方差性（Heteroscedasticity）（★★★）

`Var(u_i|X) = σ_i²` 非常数（横截面数据常见，如收入越高消费波动越大）。

| 后果 | 说明 |
| --- | --- |
| 系数 | **仍无偏、一致**（只要 `E(u|X)=0`） |
| 有效性 | 不再 BLUE |
| 方差估计 | `σ²(X′X)⁻¹` **有偏** → 标准误、t、F、置信区间全部失效 |
| 预测区间 | 失效 |

| 检验 | 做法 | 统计量 |
| --- | --- | --- |
| 图示法 | 画 `e_i²` 或 `|e_i|` 对 `Ŷ_i` / 某解释变量的散点 | 漏斗形、扇形提示异方差 |
| Park / Glejser | `ln e²` 或 `|e|` 对变量回归 | t 检验 |
| Goldfeld-Quandt | 按可疑变量排序、去中间 c 个、分别回归两段 | `F = SSE₂/SSE₁` |
| **Breusch-Pagan / Godfrey** | `e²` 对全部解释变量辅助回归 | `LM = n·R²_aux ∼ χ²(k)` |
| **White 检验** | 辅助回归含解释变量、平方项与交叉项 | `LM = n·R²_aux ∼ χ²(自由度)`，还能查设定误差 |

::: tip 工作示例 · BP / White 的 LM 检验
`n = 50`，把残差平方对解释变量做辅助回归得 `R²_aux = 0.12`，含 2 个约束：
```text
LM = n × R²_aux = 50 × 0.12 = 6.00
χ²₀.₀₅(2) = 5.99 → 6.00 > 5.99，在 5% 水平拒绝同方差（临界，需谨慎下结论）
```
再如 `n=100, R²_aux=0.08, df=3` → `LM=8.00 > χ²₀.₀₅(3)=7.81` → 拒绝。
**注意**：White 检验的辅助回归项数随 k 快速增长，小样本自由度可能不足；此时用简化版（只对 `Ŷ` 与 `Ŷ²` 回归）。
:::

![异方差的图形与修正](/econ/econ-hetero.svg)

| 修正方法 | 做法 | 适用 |
| --- | --- | --- |
| **异方差稳健标准误**（White / HC0–HC3） | 系数不变，只换标准误 | **现代实证首选**：不需知道异方差具体形式，大样本有效 |
| **WLS 加权最小二乘** | 若 `σ_i² = σ²w_i`，两边除以 `√w_i` 后 OLS | 已知/可估计方差形式时更有效 |
| FGLS | 先用残差估计 σ_i² 再 WLS | 可行 GLS |
| 变量变换 | 取对数、用人均/比率形式 | 常能同时缓解异方差与偏态 |

::: danger 易错 · 异方差
- 异方差**不使系数有偏**，只影响**方差估计与推断**；自相关同理。别答成「系数有偏」。
- 稳健标准误**不能**修复模型设定错误或内生性，只修标准误。
- 小样本下 HC0 偏乐观，常用 HC1（Stata `robust` 默认）或 HC3。
- 面板/分组数据还存在**组内相关**，要用**聚类稳健标准误**（cluster-robust），仅用异方差稳健仍会低估标准误。
:::

### 5.4 自相关（Autocorrelation）（★★★）

`Cov(u_t, u_s) ≠ 0`，时间序列常见。最常用模型 **AR(1)**：`u_t = ρu_{t−1} + ε_t`，`ε_t` 为白噪声。

| 后果 | 系数仍无偏一致（若解释变量严格外生）；**标准误被低估、t 值虚高**；OLS 不再有效；预测失效 |
| --- | --- |

| 检验 | 判据与局限 |
| --- | --- |
| 残差图 / 自相关图 | 残差呈连续正/负串 |
| **DW 检验** | `d = Σ(e_t−e_{t−1})²/Σe_t² ≈ 2(1−ρ̂)`；`d≈2` 无一阶自相关，`d→0` 正相关，`d→4` 负相关 |
| **DW 的硬限制** | ① 只检一阶 AR(1)；② **解释变量不能含被解释变量滞后项**（否则用 Durbin h / LM）；③ 需含截距；④ 有不确定区（d_L、d_U）不能判；⑤ 不能有缺失观测 |
| Breusch-Godfrey LM | `(n−p)R²_aux ∼ χ²(p)`，可检高阶、允许滞后被解释变量，**现代首选** |

![自相关与 DW 判据](/econ/econ-autocorr.svg)

::: tip 工作示例 · DW 手算
沿用第 3 章例题残差 `e = [0, 0.3, −0.4, −0.1, 0.2]`，`SSE = 0.30`：
```text
Σ(e_t−e_{t−1})² = 0.3² + (−0.7)² + 0.3² + 0.3²
                = 0.09 + 0.49 + 0.09 + 0.09 = 0.76
d = 0.76/0.30 = 2.533
ρ̂ = 1 − d/2 = −0.267 → 轻微负一阶自相关（n=5 仅演示算法，实际不可据此判断）
```
对照：`d=0.8 → ρ̂=0.60`（明显正自相关）；`d=1.5 → 0.25`；`d=2.0 → 0`；`d=2.6 → −0.30`；`d=3.4 → −0.70`。
:::

| 修正 | 做法 |
| --- | --- |
| **广义差分 / Cochrane-Orcutt** | 估计 ρ̂ 后做 `Y_t − ρ̂Y_{t−1}` 对 `X_t − ρ̂X_{t−1}` 回归，迭代至收敛；第一观测用 Prais-Winsten 补回 |
| **Newey-West (HAC)** | 系数不变，标准误对异方差 + 自相关都稳健（不需设定 AR 阶数） |
| FGLS / 加入滞后项 | 若自相关源于**模型动态设定不足**，应补上滞后变量而非只修误差 |
| 差分 / 取增长率 | 注意会改变经济含义并可能丢失长期信息 |

::: danger 易错 · 自相关与「伪自相关」
DW 显著偏低未必是误差自相关，也可能是**遗漏了滞后变量或函数形式错**（「伪自相关」）。先检查模型设定，再决定是否做 GLS；否则会把设定误差硬塞进误差项。
:::

::: tip 补充考点 · DW 检验的五区判定规则
给定样本量 n 与解释变量个数 k，查表得下临界值 `d_L` 与上临界值 `d_U`（如 n=30、k=2、5% 时约 `d_L=1.28, d_U=1.57`）：
`0 < d < d_L` ⇒ 存在**正自相关**（拒绝）；`d_L ≤ d ≤ d_U` ⇒ **不能判定**；`d_U < d < 4−d_U` ⇒ 无（一阶）自相关（不拒绝）；`4−d_U ≤ d ≤ 4−d_L` ⇒ 不能判定；`4−d_L < d < 4` ⇒ 存在**负自相关**。
两个「不能判定区」是 DW 检验的固有缺陷，此时应改用 Breusch-Godfrey LM 检验（无不确定区、可检高阶）。
:::

### 5.5 随机解释变量与内生性（★★★）

`Cov(X, u) ≠ 0` 是 OLS 最致命的问题：**有偏且不一致**（增大样本也不能救）。三大来源：
① **遗漏变量**（与 X 相关的因素被留在 u 中）；
② **联立性 / 反向因果**（Y 也影响 X）；
③ **测量误差**（X 的经典测量误差使系数衰减偏误）。

**工具变量 IV / 两阶段最小二乘 2SLS**：找一个 `Z` 满足
- **相关性**（`Cov(Z,X) ≠ 0`，第一阶段足够强）；
- **外生性 / 排他性**（`Cov(Z,u)=0`，Z 只通过 X 影响 Y）。

```text
第一阶段：X = π₀ + π₁Z + 其它外生变量 + v  → 得 X̂
第二阶段：Y = β₀ + β₁X̂ + … + u         → 得 2SLS 估计
```

| 诊断 / 概念 | 结论 |
| --- | --- |
| 恰好识别 / 过度识别 | 工具数 = / > 内生变量数 |
| 弱工具变量 | 第一阶段 F < 10（经验规则）⇒ 2SLS  biased 且 Wald 检验失真；用 Kleibergen-Paap / Cragg-Donald 统计量 |
| 过度识别检验 | Sargan / Hansen J：检验「所有工具都外生」，不拒绝才支持工具有效性 |
| 内生性检验 | Durbin-Wu-Hausman：比较 OLS 与 IV，显著则确有内生性 |
| LATE | 异质效应下 IV 识别的是「被工具撬动的那群人（compliers）」的局部平均处理效应，不是全样本 ATE |

::: tip 现代因果推断工具箱
在工具变量法之外，现代实证研究还须掌握：
- **潜在结果框架（RCM）**：`τ_i = Y_i(1) − Y_i(0)`，根本问题是同一对象不能同时观测两种结果；识别靠随机化或可忽略性假设。
- **DID 双重差分**：处理组前后变化减去对照组前后变化，**平行趋势假定**是关键；用事件研究图检验预趋势；双向固定效应（TWFE）在交错处理时可能偏误，需 Callaway-Sant'Anna / Sun-Abraham 等稳健估计量。
- **RDD 断点回归**：断点附近局部随机化，识别局部因果效应。
- **合成控制、匹配、倾向得分**：构造可比对照组。
- **标准误**：按处理分配层级聚类；DID 常用「处理组层面聚类 + 小样本 wild bootstrap」。
:::

### 5.6 五大问题速查对照表

| 问题 | 系数无偏? | 方差估计? | 主要检验 | 首选对策 |
| --- | --- | --- | --- | --- |
| 遗漏变量 / 内生性 | **否（有偏且不一致）** | 失效 | RESET、DWH、理论分析 | 加控制/固定效应、IV/2SLS、实验或准实验 |
| 多重共线性 | 是 | 变大（t 小） | VIF、条件数 | 增样本、删冗余、变换、岭回归 |
| 异方差 | 是 | 失效 | BP/Godfrey、White、GQ | **稳健标准误**、WLS/FGLS |
| 自相关 | 是（严格外生下） | 失效 | DW、BG-LM | **HAC/Newey-West**、Cochrane-Orcutt |
| 误设定函数形式 | 否 | 失效 | RESET、残差图 | 加平方项/交互、Box-Cox |

### 5.7 稳健标准误、衰减偏误与双重差分

```text
OLS 方差（同方差）：      Var(β̂) = σ²(X′X)⁻¹
HC0 异方差稳健：          Var(β̂) = (X′X)⁻¹ [Σ e_i² x_i x_i′] (X′X)⁻¹
HC1（Stata robust 默认）：乘 n/(n−k−1) 小样本校正
HC3：                    用 e_i²/(1−h_i)²，小样本表现最好
聚类稳健：               按个体 g 分组求和 Σ_g (Σ_{i∈g} e_i x_i)(Σ_{i∈g} e_i x_i)′
```

::: tip 工作示例 · 测量误差衰减偏误与 2×2 DID
**衰减偏误**：真实 X 方差 `σ²_x=9`，测量误差方差 `σ²_v=1`，则 `plim β̂ = β·9/(9+1) = 0.9β`，系数被**压向 0 约 10%**。这与遗漏变量偏误方向不确定不同：经典测量误差一定造成衰减。

**DID 2×2 表**：

| | 政策前 | 政策后 | 变化 |
| --- | --- | --- | --- |
| 处理组 | 10 | 14 | +4 |
| 对照组 | 8 | 10 | +2 |
| 差异 | +2 | +4 | — |

```text
DID = (14 − 10) − (10 − 8) = 4 − 2 = 2
```
等价于回归 `Y = α + β·Treat + γ·Post + δ(Treat×Post) + u` 中的 `δ̂`。成立前提是**平行趋势**（无政策时两组变化相同），必须用政策前多期数据画事件研究图检验；标准误要按处理分配层级聚类。
:::

## 第 6 章 动态经济模型

### 6.1 分布滞后与自回归模型（★★★）

经济行为常有**时滞**（投资到产出、政策到效果），需在模型里引入滞后变量。

| 模型 | 形式 | 说明 |
| --- | --- | --- |
| **分布滞后模型** | `Y_t = α + β₀X_t + β₁X_{t−1} + … + β_sX_{t−s} + u_t` | 解释变量的现期与多期滞后同时出现 |
| **自回归模型** | `Y_t = α + β₀X_t + λY_{t−1} + u_t` | 含**被解释变量滞后项** |
| 短期乘数 | `β₀` | X 当期变动 1 单位对 Y 的当期影响 |
| 延迟乘数 | `β₁, β₂, …` | 各滞后期的额外影响 |
| **长期乘数（长期弹性）** | `Σβ_i` | X 永久变动 1 单位后 Y 的总变化 |

直接估计分布滞后会遇到：滞后长度 s 难定、自由度损失、滞后项间**高度共线**。

![分布滞后、自回归与长期乘数](/econ/econ-lag.svg)

### 6.2 阿尔蒙多项式分布滞后（★★）

假设滞后系数 `β_i` 可由低阶多项式近似：`β_i = a₀ + a₁i + a₂i² + … + a_p i^p (p < s)`。把原模型改写为对**构造变量** `Z_{0t}=ΣX_{t−i}`、`Z_{1t}=Σi·X_{t−i}`、`Z_{2t}=Σi²·X_{t−i}` 的回归，估计出 `a_j` 后回代得到各期 `β_i`。
优点：大幅减少待估参数、缓解共线；代价：对多项式阶数与端点约束（常设 `β_{−1}=β_{s+1}=0`）敏感。

### 6.3 Koyck 变换、部分调整与适应预期（★★★）

| 模型 | 经济动机 | 变换后的共同形式 |
| --- | --- | --- |
| **Koyck 几何滞后** | `β_i = β₀λ^i, 0<λ<1`（远期影响几何衰减） | `Y_t = α(1−λ) + β₀X_t + λY_{t−1} + v_t`，`v_t = u_t − λu_{t−1}` |
| **部分调整 PAM** | 实际调整只完成期望调整的一部分（有调整成本） | 同上形式，长期乘数 `= β₀/(1−λ)` |
| **适应预期 AE** | 预期按误差逐步修正 `X^e_t − X^e_{t−1} = γ(X_t − X^e_{t−1})` | 同上形式，`λ = 1−γ` |

三者数学形式几乎一样，**经济含义与扰动项结构不同**，不能只凭回归式区分。

::: tip 工作示例 · 长期乘数手算
设部分调整模型估计得 `β₀ = 0.5`，`λ = 0.6`（每期完成 60% 的调整）：
```text
短期乘数 = 0.5
长期乘数 = β₀/(1−λ) = 0.5/0.4 = 1.25
含义：X 永久增加 1 单位，当期 Y 只增 0.5，但累积最终增 1.25
调整速度：λ=0.4 → 长期乘数 0.833；λ=0.8 → 2.50（λ 越大，长期效应越大、调整越慢）
平均滞后 ≈ λ/(1−λ)：λ=0.6 → 1.5 期
```
:::

### 6.4 自回归模型的估计问题（★★★）

含 `Y_{t−1}` 时：
- 若 `u_t` 存在自相关，则 `Y_{t−1}` 与 `u_t` **相关**（因为 `Y_{t−1}` 含 `u_{t−1}`）→ OLS **有偏且不一致**；
- **DW 检验失效**（偏向 2，倾向于「检不出」自相关）→ 改用 **Durbin h 检验**（`h = ρ̂√(n/(1−n·Var(λ̂))) ∼ N(0,1)`）或 **Breusch-Godfrey LM**；
- 小样本下 `λ̂` 有向下偏误（动态面板中即 Nickell 偏误，第 9 章）。

### 6.5 Granger 因果关系检验（★★★）

「X Granger 引起 Y」＝**X 的滞后项对 Y 有增量预测能力**（在控制 Y 自身滞后之后），这是**预测意义上的因果**，不等于哲学/结构意义上的因果。

```text
无约束：Y_t = α + Σa_i Y_{t−i} + Σb_j X_{t−j} + u_t   → SSE_u
受约束：Y_t = α + Σa_i Y_{t−i} + u_t  (H₀: 全部 b_j = 0) → SSE_r
F = [(SSE_r − SSE_u)/q] / [SSE_u/(n−k)] ∼ F(q, n−k)
```

::: tip 工作示例 · Granger F 统计量
`SSE_r = 1200`，`SSE_u = 900`，滞后阶 `q=2`，`n=60`，无约束模型参数 `k=5`：
```text
F = [(1200−900)/2] / [900/(60−5)] = 150/16.364 = 9.17
F₀.₀₅(2,55) ≈ 3.17 → 拒绝 H₀，X Granger 引起 Y
```
**三个前提**：① 变量平稳（非平稳须先差分或做协整/VECM）；② 滞后阶数由 AIC/SC 选，结论可能对阶数敏感；③ 存在共同原因、预期先行、遗漏第三变量时「Granger 因果」会被误读。反向也须检验（Y 是否 Granger 引起 X），可能出现双向反馈。
:::

### 6.6 滞后长度选择（★★）

- **由一般到特殊**：从较大阶数逐步删不显著滞后项，配合 AIC/SC 与残差白噪声检验。
- **由特殊到一般**易犯设定错误；数据驱动逐步删项会扭曲 t 统计量的分布（预检验偏误），结论宜作稳健性报告。
- AIC 倾向选大阶（预测导向），SC/BIC 一致地选真阶（更重的惩罚）。

::: danger 易错 · 动态模型
- Koyck 变换后的扰动项是 MA(1)，与 `Y_{t−1}` 相关 ⇒ OLS 不一致，需用 IV/GMM 或显式建模误差结构。
- 「Granger 因果」≠「真因果」：太阳黑子可能 Granger 引起产出，只反映预测信息。
- 非平稳序列直接做 Granger 检验可能产生伪显著，须先做单位根检验（第 7 章）。
:::

### 6.7 阿尔蒙多项式的构造与滞后阶选择

设滞后长度 `s=4`、多项式阶 `p=2`，令 `β_i = a₀ + a₁i + a₂i² (i=0…4)`：
```text
Z₀t = X_t + X_{t−1} + X_{t−2} + X_{t−3} + X_{t−4}
Z₁t =      X_{t−1} + 2X_{t−2} + 3X_{t−3} + 4X_{t−4}
Z₂t =      X_{t−1} + 4X_{t−2} + 9X_{t−3} + 16X_{t−4}
回归 Y_t = α + a₀Z₀t + a₁Z₁t + a₂Z₂t + u_t
回代：β̂_i = â₀ + â₁i + â₂i²，长期乘数 = Σβ̂_i
```
原来要估 5 个 β，现在只估 3 个 a；端点约束（如 `β₅=0` 或 `β_{−1}=0`）可再减 1 个参数，但约束是**先验信息**，设错会系统性扭曲滞后结构。

::: tip 工作示例 · AIC / SC 选阶
`n=100`，两个候选模型：
```text
k=3, SSE=180 → AIC = ln(1.80) + 8/100 = 0.6678；SC = ln(1.80) + 4·ln(100)/100 = 0.7720
k=4, SSE=178 → AIC = ln(1.78) + 10/100 = 0.6766；SC = ln(1.78) + 5·ln(100)/100 = 0.8069
两者都选 k=3（更简洁的模型）
```
SC 的惩罚项 `(k+1)ln n` 比 AIC 的 `2(k+1)` 随样本增长更快，因此在临界情形**更倾向小模型**；AIC 以提高预测精度为目标，SC 具有「真模型若在其中则一致选中它」的性质。
:::

## 第 7 章 时间序列分析

### 7.1 平稳性与常用过程（★★★）

| 概念 | 定义 |
| --- | --- |
| **严格平稳** | 任意 k 个时点的联合分布不随时间平移而改变 |
| **弱（协方差）平稳** | `E(Y_t)=μ`（常数）、`Var(Y_t)=σ²`（常数）、`Cov(Y_t,Y_{t−k})=γ_k` 只依赖间隔 k 而非 t |
| 白噪声 | `E(ε_t)=0`、`Var=σ²`、`Cov(ε_t,ε_s)=0 (t≠s)` |
| 随机游走 | `Y_t = Y_{t−1} + ε_t`（无漂移）/ `Y_t = μ + Y_{t−1} + ε_t`（带漂移）；**非平稳**、`Var` 随 t 线性增长 |
| AR(1) | `Y_t = c + φY_{t−1} + ε_t`；`|φ|<1` 平稳，`φ=1` 为单位根 |
| MA(q) / ARMA(p,q) | 用过去扰动 / 过去值与扰动的组合刻画序列相关 |
| ARIMA(p,d,q) | 差分 d 次后为 ARMA；`d` 为单整阶数 |

![平稳性、单位根与差分](/econ/econ-stationary.svg)

::: danger 易错 · 平稳性
- 「均值恒定」不够：方差或自协方差随时间变也不平稳（如异方差的金融收益率）。
- 确定性趋势（如 `Y_t = a + bt + ε_t`）**不是**平稳，但**去趋势后**平稳，称**趋势平稳**；与单位根过程的本质区别是：趋势平稳的冲击是暂时的，单位根的冲击**永久**改变水平。
- 伪回归：两个独立的随机游走互相回归，常得到高 R² 与显著 t 值（Granger–Newbold 发现），实际上毫无关系。判别信号：`R² > DW`、残差高度自相关。
:::

### 7.2 单位根检验（★★★）

```text
DF 检验：ΔY_t = (ρ−1)Y_{t−1} + ε_t，检验 H₀: ρ=1（有单位根，非平稳）
ADF：加入滞后差分项 ΔY_{t−i} 以消除残差自相关
     ΔY_t = α + βt + γY_{t−1} + Σδ_iΔY_{t−i} + ε_t，H₀: γ = 0
```
**关键点**：检验统计量在原假设下**不服从标准 t 分布**，必须用 **DF / MacKinnon 临界值**（更负，如 5% 约 `−2.86`（含截距）、`−3.41`（含截距和趋势））；`t` 值要**比临界值更负**才能拒绝非平稳。

| 检验 | 原假设 | 备注 |
| --- | --- | --- |
| ADF | 有单位根 | 最常用；滞后阶数由 AIC/SC 选 |
| PP (Phillips-Perron) | 有单位根 | 非参数修正自相关与异方差 |
| KPSS | **平稳**（与 ADF 相反） | 常与 ADF 联合使用做确认 |
| ADF-GLS / ERS | 有单位根 | 功效更高 |
| 结构突变单位根 | 有单位根（允许断点） | Perron、Zivot-Andrews；普通 ADF 遇结构突变易误判 |

**单整**：`Y_t ∼ I(d)` 表示差分 d 次后平稳；`I(0)` 平稳，`I(1)` 一阶单整（多数宏观总量），`I(2)` 少见。

### 7.3 协整与误差修正模型（★★★）

**协整**：若 `Y_t ∼ I(1)`、`X_t ∼ I(1)`，但存在 β 使 `u_t = Y_t − β₀ − β₁X_t ∼ I(0)`，则二者协整，β 称**协整向量**，代表变量间的**长期均衡关系**。

**Engle-Granger 两步法**：
```text
① 用 OLS 估计长期静态回归 Y_t = β₀ + β₁X_t + u_t，取残差 û_t
② 对 û_t 做 ADF 检验（不含趋势，临界值为 AEG/EG 专用，比普通 ADF 更负）
   拒绝「û_t 有单位根」⇒ 协整成立
③ 若协整，建立误差修正模型：
   ΔY_t = α + γ·ECM_{t−1} + Σδ_iΔX_{t−i} + Σθ_jΔY_{t−j} + ε_t
   其中 ECM_{t−1} = û_{t−1} = Y_{t−1} − β̂₀ − β̂₁X_{t−1}
```
**Granger 表述定理**：协整 ⇒ 一定存在 ECM 表示。`γ` 是**调整速度**（应为负），`|γ|` 越大，偏离长期均衡后修复越快；例如 `γ = −0.3` 表示每期约修正 30% 的偏离。

![协整、长期均衡与误差修正](/econ/econ-cointegration.svg)

::: tip 工作示例 · AEG 检验与 ECM 解读
典型例中对协整残差做 ADF 型检验得到 `AEG = −4.99`，而 5% 临界值约 `−3.01`（或 `−3.4` 视设定）：`-4.99 < −3.01` ⇒ **拒绝非平稳，协整成立**。
配套对照：对原序列水平值检验 `t = −1.71 > −3.01`、`−0.72 > −1.96` 等 ⇒ 不能拒绝单位根（非平稳）；`−3.68 < −1.96`、`−3.49 < −1.96` ⇒ 一阶差分后平稳。这正是「`I(1)` 且协整」的典型证据链。
若 ECM 估计得 `γ̂ = −0.25`，含义是上期偏离均衡 1 单位，本期 Y 反向调整 0.25 单位，半衰期约 `ln0.5/ln0.75 ≈ 2.4` 期。
:::

| 方法 | 适用 | 优点 | 局限 |
| --- | --- | --- | --- |
| EG 两步法 | 单方程、一个协整关系 | 简单直观 | 第一步 OLS 小样本有偏；只能找一个协整向量；检验功效低 |
| **Johansen 检验** | 多变量 VAR、多个协整关系 | 迹统计量 / 最大特征值统计量，可定协整秩 r | 需设定 VAR 阶数与确定性项，对设定敏感 |
| ARDL / Pesaran 边界检验 | 变量可混合 `I(0)/I(1)` | 不要求同阶单整，小样本表现好 | 不能有 `I(2)` |
| VECM | 协整系统 | 同时刻画长期均衡与短期动态、可做 Granger 因果与脉冲响应 | 系统较复杂 |

### 7.4 ARIMA / Box-Jenkins 与波动率模型（★★）

**Box-Jenkins 三步**：① 识别（用 ADF 定 d，用 ACF/PACF 定 p、q：AR(p) 的 PACF 在 p 阶截尾、ACF 拖尾；MA(q) 反之）；② 估计（MLE / 条件最小二乘）；③ 诊断（残差应为白噪声，Ljung-Box Q 检验不显著），必要时回到 ①。

| 补充模型 | 用途 |
| --- | --- |
| **ARCH / GARCH** | 金融收益率「波动聚集」：`σ²_t = ω + αε²_{t−1} + βσ²_{t−1}`，`α+β` 接近 1 表示冲击持久；EGARCH / GJR 刻画杠杆效应（坏消息放大波动） |
| VAR | 把所有变量都当内生，每个变量对自身与其它变量滞后回归；用脉冲响应、方差分解分析动态传导 |
| 季节调整 / SARIMA | 含季节周期的数据 |

::: danger 易错 · 时间序列
- ADF 的 H₀ 是「**有单位根（非平稳）**」，拒绝才是平稳；KPSS 恰好相反，别记反。
- 协整要求变量**同阶单整**（EG 框架下）；`I(0)` 与 `I(1)` 混合应考虑 ARDL 边界检验。
- 协整 ≠ 因果：协整只说明存在长期共同运动，方向要靠 ECM/Granger 或理论识别。
- 差分会丢掉**长期水平信息**，因此有协整时必须用 VECM，不能简单全差分。
- 对非平稳序列直接做 t 检验 / Granger 检验易得伪结论；先检验平稳性。
:::

### 7.5 ACF/PACF 定阶、VAR 与 Johansen 检验

| 过程 | ACF | PACF |
| --- | --- | --- |
| AR(p) | 拖尾（指数/阻尼振荡衰减） | **p 阶截尾** |
| MA(q) | **q 阶截尾** | 拖尾 |
| ARMA(p,q) | 拖尾 | 拖尾 |
| 白噪声 | 所有 k>0 均不显著 | 同左 |

Ljung-Box `Q = n(n+2)Σ ρ̂_k²/(n−k) ∼ χ²(m)` 检验残差是否白噪声；显著说明还有结构没提取。

**VAR(p)**：每个变量对**所有**变量的 1…p 期滞后回归；要求各变量平稳（协整则用 VECM）。产出主要是**脉冲响应函数 IRF**（一个变量一单位冲击对其它变量的动态影响）与**方差分解**（各冲击对预测误差方差的贡献）。VAR 的滞后阶由 AIC/SC/LR 定，且需检验特征根是否在单位圆内（稳定性）。

**Johansen 协整检验**流程：① 定 VAR 阶数；② 确定确定性项（截距/趋势）设定；③ 用**迹统计量**（`H₀: r ≤ r₀` vs `r > r₀`）与**最大特征值统计量**（`H₀: r = r₀`）逐个判断协整秩 r；④ 得 r 后写 VECM，施加并检验长期约束（如 `β=(1,−1)` 表示一价定律）。

## 第 8 章 联立方程模型

### 8.1 为什么 OLS 会失效（★★★）

经济系统里变量常**互为因果**。经典宏观例子：
```text
消费函数：C_t = α + βY_t + u_t        （行为方程）
收入恒等：Y_t = C_t + I_t            （恒等式）
```
把第二式代入第一式整理可得 `Y_t = (α+I_t+u_t)/(1−β)`，于是 `Y_t` 含 `u_t` ⇒ `Cov(Y_t, u_t) ≠ 0`。用 OLS 估计消费函数得到的 `β̂` **既有偏又不一致**（称**联立性偏误 / 同时方程偏误**），且样本增大也不消失。

![联立方程、简化式与识别](/econ/econ-simultaneous.svg)

| 概念 | 定义 |
| --- | --- |
| **内生变量** | 由模型内部决定（C、Y） |
| **外生变量** | 模型外部给定（I、政策变量） |
| **前定变量** | 外生变量 + 滞后内生变量（本期已确定） |
| 行为方程 | 描述经济主体行为，含随机扰动与待估参数 |
| 恒等式 | 定义式 / 均衡条件，无待估参数（如 `Y=C+I`） |
| **结构式** | 按经济理论直接写出的方程，系数是结构参数 |
| **简化式** | 每个内生变量只用**前定变量**表示，可直接用 OLS 一致估计 |

### 8.2 识别问题（★★★）

「识别」问的是：能否从**可估计的简化式参数**唯一地解出**结构参数**。设模型共 `G` 个内生变量（方程数）、`K` 个前定变量；某方程含 `g` 个内生变量、`k` 个前定变量，则该方程**排除**了 `G−g` 个内生变量与 `K−k` 个前定变量。

| 判据 | 内容 |
| --- | --- |
| **阶条件（必要非充分）** | 被该方程排除的前定变量数 `K−k ≥ g−1`（该方程包含的内生变量数 −1） |
| 恰好识别 | `K−k = g−1` → 可用**间接最小二乘 ILS** |
| 过度识别 | `K−k > g−1` → 用 **2SLS / LIML / GMM** |
| 不可识别 | `K−k < g−1` → 任何方法都救不了，必须改模型或加外生变量 |
| **秩条件（充要）** | 被排除变量在其它方程中的系数矩阵存在非零 `G−1` 阶行列式；实际由软件或矩阵秩判断 |

::: tip 工作示例 · 阶条件判断
沿用 8.1 宏观模型：`G=2` 个内生变量（C、Y），`K=2` 个前定变量（常数、I）。
- **消费方程** `C = α+βY+u`：含 `g=2` 个内生（C、Y）、`k=1` 个前定（常数），排除了 `K−k=1` 个前定变量（I）。`1 ≥ g−1 = 1` ✓ **恰好识别** → ILS 或 2SLS 均可。
- **收入恒等式** `Y = C+I`：恒等式无需识别。
- 若消费方程改为 `C = α+βY+γC_{−1}+u`（把 `C_{−1}` 作为前定变量纳入，则 `K=3`）：`k=2`（常数、C₋₁），`K−k=1 = g−1` 仍恰好识别。
- 若模型再引入政府支出 G 与税收 T 两个外生变量且都不进消费方程：`K−k = 3 > 1` → **过度识别**，须用 2SLS。

**直觉**：要让一个方程可识别，必须有「别的方程里有、但这个方程里没有」的外生变量充当**工具**——这正是 2SLS 第一阶段用全部前定变量做回归的原因。
:::

### 8.3 估计方法（★★）

| 方法 | 适用 | 要点 |
| --- | --- | --- |
| ILS 间接最小二乘 | 恰好识别 | 先 OLS 估简化式，再代数解回结构参数；过度识别时会得到多个解 |
| **2SLS 两阶段最小二乘** | 恰好 / 过度识别，单方程 | 第一阶段用**全部前定变量**回归每个内生解释变量得拟合值；第二阶段用拟合值替代，等价于 IV；最常用 |
| 3SLS / FIML | 系统估计 | 同时利用跨方程扰动相关，效率更高，但一个方程设定错会污染全系统 |
| LIML / GMM | 弱工具、异方差情形 | LIML 对弱工具更稳健；GMM 可处理异方差与自相关 |

::: danger 易错 · 联立方程
- 阶条件**只是必要**条件：满足阶条件仍可能因秩条件不满足而不可识别（如某变量虽被排除，但在其它方程系数全为 0）。
- 恒等式**没有随机扰动、无需估计**，但仍算一个方程、计入 `G`。
- 2SLS 第二阶段的标准误须用**修正后的残差**（含原始内生变量），直接用拟合值算会低估标准误；软件会自动处理，手算要小心。
- 「简化式系数」不是「结构系数」：简化式给的是外生变量对内生变量的**总效应**（含乘数），例如 `1/(1−β)` 就是投资乘数。
:::

### 8.4 简化式求解与 2SLS 的 IV 等价性

沿用 8.1 的宏观模型：
```text
C_t = α + βY_t + u_t ； Y_t = C_t + I_t
代入：Y_t = α + βY_t + u_t + I_t
    → Y_t = α/(1−β) + I_t/(1−β) + u_t/(1−β)      （简化式）
    → C_t = α/(1−β) + βI_t/(1−β) + u_t/(1−β)
```
`∂Y_t/∂I_t = 1/(1−β)` 就是**投资乘数**。若 `β=0.8`，乘数 = 5。由简化式可解出 `β = π₂/(1+π₂)`（`π₂` 为 I 在 C 方程简化式中的系数），这正是 **ILS 间接最小二乘**：先 OLS 估简化式（前定变量外生，一致），再代数反解结构参数。

**2SLS 与 IV 等价**：第一阶段 `X = ZΠ̂ + v` 得 `X̂ = P_Z X`（`P_Z` 为对全部前定变量的投影矩阵），第二阶段 `β̂_2SLS = (X′P_Z X)⁻¹X′P_Z y`，恰是以 `Z` 为工具的 IV 估计量。当工具数 = 内生变量数时 `X′P_Z X = X′Z(Z′Z)⁻¹Z′X`，退化为标准 IV 公式。

## 第 9 章 面板数据模型

### 9.1 面板数据及其优势（★★★）

面板数据＝**同一批个体**（地区、企业、家庭）在**多个时期**都被观测。设 `i = 1…N` 个个体、`t = 1…T` 期，总观测 `NT`。

| 优势 | 说明 |
| --- | --- |
| 控制不可观测的个体异质性 | 用个体固定效应吸收不随时间变的遗漏因素（文化、地理位置、企业基因）→ 大幅缓解遗漏变量偏误 |
| 更多变异、更大自由度 | 同时含**组间（between）**与**组内（within）**变异 |
| 可研究动态 | 能识别滞后效应、调整过程 |
| 可做更可信的因果设计 | DID、事件研究、个体固定效应 |

代价：面板常有**组内相关**（同一个体跨期误差相关）、**异方差与截面相关**、**样本流失（attrition）**、测量误差；普通 OLS 标准误会严重低估。

```text
通用设定：y_it = α + β′x_it + μ_i + λ_t + ε_it
μ_i：个体效应（不随时间变）；λ_t：时间效应（不随个体变）；ε_it：特异误差
```

![面板数据三种模型与 Hausman 检验](/econ/econ-panel.svg)

### 9.2 三类基本模型（★★★）

| 模型 | 设定 | 估计 | 关键假定 |
| --- | --- | --- | --- |
| **混合回归 Pooled OLS** | 忽略 μ_i，把所有观测堆在一起 | OLS | `μ_i = 0`（无个体效应）；通常不成立 |
| **固定效应 FE** | `μ_i` 视为待估参数，允许与 x 相关 | **LSDV**（加 N−1 个个体虚拟变量）／**组内去均值（within）**／一阶差分 FD | 允许 `Cov(μ_i, x_it) ≠ 0`；一致性更强 |
| **随机效应 RE** | `μ_i` 视为随机且与 x **不相关**，并入复合误差 | FGLS（拟去均值 `y_it − θȳ_i`） | `Cov(μ_i, x_it) = 0`；若成立则更有效，且能估**不随时间变**的变量 |

**组内变换**：`y_it − ȳ_i = β′(x_it − x̄_i) + (ε_it − ε̄_i)`，μ_i 被相减消掉。
- FE **无法估计**不随时间变化的变量（性别、地区固定属性）——它们被去均值消掉。
- FE 的一致性强，但当 T 小、组内变异少时标准误大；RE 效率更高但依赖强假定。
- **双向固定效应 TWFE**：同时加个体与时间虚拟变量，控制共同宏观冲击。

### 9.3 Hausman 检验（★★★）

```text
H₀: 个体效应与解释变量不相关（RE 一致且有效）→ 选 RE
H₁: 相关（RE 不一致，FE 仍一致）      → 选 FE
H = (β̂_FE − β̂_RE)′ [Var(β̂_FE) − Var(β̂_RE)]⁻¹ (β̂_FE − β̂_RE) ∼ χ²(k)
```
显著（H 大于临界值）⇒ 拒绝 H₀ ⇒ **用 FE**；不显著 ⇒ 可用 RE（更有效）。

::: tip 工作示例 · Hausman 手算（单系数）
设 `β̂_FE = 0.62, Var = 0.004`；`β̂_RE = 0.45, Var = 0.001`：
```text
H = (0.62 − 0.45)² / (0.004 − 0.001) = 0.0289 / 0.003 = 9.63
χ²₀.₀₅(1) = 3.84 → 9.63 > 3.84 ⇒ 拒绝 RE，应选固定效应
```
**注意**：① 检验只比较**时变变量**的系数（FE 估不了时不变变量）；② 若 `Var(β̂_FE) − Var(β̂_RE)` 非正定（小样本常见），H 可能为负，需改用稳健版或 `suest`；③ 即便 Hausman 不显著，只要理论上怀疑个体效应与 x 相关（如研究企业效率），多数应用计量仍优先 FE；④ 现代做法常用 **Mundlak / 相关随机效应（CRE）**：把组内均值 `x̄_i` 加入 RE 模型，既保留时不变变量又能检验并缓解相关性。
:::

### 9.4 面板标准误与现代扩展（★★）

| 补充主题 | 要点 |
| --- | --- |
| **聚类稳健标准误** | 按个体聚类（允许任意组内自相关与异方差）；DID 常按处理分配层级聚类；聚类数少（< 40）须用 wild cluster bootstrap |
| 双向聚类 / Driscoll-Kraay | 同时处理截面相关与时间相关 |
| **动态面板与 Nickell 偏误** | 含 `y_{i,t−1}` 且 T 小时，FE 估计不一致（偏误约 `−1/T`）；用 **Arellano-Bond 差分 GMM / Blundell-Bond 系统 GMM**，并做 AR(2) 与 Hansen 检验 |
| 交互固定效应 / 因子结构 | 控制随时间变化但有共同因子的不可观测异质性 |
| 交错处理 DID 的 TWFE 偏误 | 处理时点不同且效应异质时 TWFE 可能给错权重；用 Callaway–Sant'Anna、Sun–Abraham、Borusyak 等稳健估计量 |
| 面板单位根 / 面板协整 | LLC、IPS、Fisher-ADF；Pedroni / Kao 协整检验 |

::: danger 易错 · 面板数据
- 「混合数据 pooled」≠「面板数据」：只有**同一批**个体跨期追踪才是面板，否则不能做组内变换。
- FE 不能估时不变变量的系数，但**能**控制它们（被吸收）；别写成「FE 无法控制性别」。
- RE 的一致性依赖 `Cov(μ_i, x_it)=0`，这个假定通常可疑；Hausman 检验功效有限，「没拒绝」不等于「成立」。
- 面板不等于能自动识别因果：仍可能有随时间变化的遗漏变量、反向因果。
- 用 LSDV 时标准误要按 `NT − N − k` 自由度调整，否则会低估；含很多虚拟变量时直接用组内估计量更高效。
:::

::: tip 补充考点 · 平衡面板与非平衡面板
**平衡面板**：每个个体观测期数相同（N×T 完整矩形）；**非平衡面板**：个体进入/退出、缺失导致期数不齐。非平衡数据不必强行删成平衡：FE/RE 都能直接估计，但**样本流失若非随机**（如经营差的企业退出），会造成**选择性偏差**，结论只适用于"留存者"；Hausman 检验在非平衡面板下的解释也要谨慎。答题时先报告面板是否平衡、N 与 T 各是多少。
:::

### 9.5 面板的三种变异与 Mundlak 设定

```text
总变异 overall   ：y_it − ȳ                    （混合 OLS 用）
组内变异 within  ：y_it − ȳ_i                 （FE 用，只识别时变变量的效应）
组间变异 between ：ȳ_i − ȳ                    （BE 用，易受个体异质性污染）
RE = 组内与组间估计量的加权平均，权重 θ 由 σ²_μ 与 σ²_ε、T 决定
```
**Mundlak / 相关随机效应 CRE**：在 RE 模型中加入各时变变量的**个体均值** `x̄_i`：
```text
y_it = α + β′x_it + γ′x̄_i + μ_i + ε_it
```
若 `γ = 0` 则 RE 假定成立；否则该设定给出与 FE 相同的 `β̂`，同时仍能估计时不变变量，且可做 Hausman 检验的等价 Wald 版本。**这是现代应用计量中常被推荐的折中做法**。

DID 在面板中即 `y_it = α + μ_i + λ_t + δ·D_it + ε_it`（双向固定效应）；`D_it = Treat_i × Post_t`。交错处理时点 + 异质效应下 `δ̂` 是各 2×2 DID 的加权平均且权重可能为负，这就是 **TWFE 偏误**。

## 第 10 章 定性选择模型

### 10.1 线性概率模型 LPM（★★★）

被解释变量是 **0/1**（是否就业、是否违约、选择公交还是自驾）时，直接用 OLS：
```text
P(Y_i=1|X_i) = β₀ + β′X_i（把条件期望当作概率）
```
| 问题 | 说明 |
| --- | --- |
| 预测值越界 | `Xβ` 可能 <0 或 >1，「概率」无意义 |
| 异方差 | `Var(u|X) = p(1−p)` 依赖 X ⇒ 标准误须用稳健标准误 |
| 非正态误差 | u 只能取两个值；小样本 t/F 只是渐近有效 |
| 边际效应恒定 | 隐含「X 对概率的影响处处相同」，通常不合经济直觉 |

**唯一优点**：系数可直接解释为「X 增 1 单位，概率变动 β」，简单、可作基准；在概率集中于 0.2–0.8 时近似尚可。

### 10.2 Logit 与 Probit（★★★）

用**潜变量**框架：`y* = β′X + u`，`y = 1[y* > 0]`；对 u 的分布作假定即得到不同模型，用**极大似然 MLE** 估计。

| 模型 | 分布 | `P(Y=1|X)` | 边际效应 | 系数换算 |
| --- | --- | --- | --- | --- |
| **Logit** | 逻辑分布 | `Λ(z) = 1/(1+e^{−z})` | `β_j·P(1−P)` | `e^{β_j}` = **优势比 odds ratio** |
| **Probit** | 标准正态 | `Φ(z)` | `β_j·φ(z)` | 与 Logit 系数约差 1.6 倍：`β_Logit ≈ 1.6 β_Probit` |
| LPM | — | `z`（线性） | `β_j`（常数） | 直接是概率变化 |

![LPM、Logit 与 Probit 曲线](/econ/econ-logit.svg)

::: tip 工作示例 · Logit 概率、边际效应与优势比（完整演算）
设估计得 `z = −1 + 0.5x`（β₀=−1，β₁=0.5）：

```text
x=2 → z=0    → P = 1/(1+e⁰) = 0.5000，边际效应 = 0.5×0.5×0.5 = 0.1250（最大）
x=4 → z=1    → P = 1/(1+e⁻¹) = 0.7311，边际效应 = 0.5×0.7311×0.2689 = 0.0983
x=6 → z=2    → P = 0.8808，边际效应 = 0.5×0.8808×0.1192 = 0.0525
x=0 → z=−1   → P = 0.2689，边际效应 = 0.0983
优势比 OR = e^{0.5} = 1.649：x 每增 1 单位，发生比（P/(1−P)）乘以 1.649（约 +64.9%）
```
**读法**：① 系数符号决定概率随 x 增减的方向，但**大小不是概率变化**；② 边际效应随 x 变化，在 P≈0.5 处最大、两端趋于 0（S 形曲线）；③ 报告结果应给**平均边际效应 AME** 或指定 x 处的 MEM，而非只报 β；④ Probit 在 z=1 时 `Φ(1)=0.8413`，边际效应 `0.5×φ(1)=0.5×0.2420=0.1210`。
:::

### 10.3 估计、检验与拟合优度（★★）

```text
对数似然：lnL = Σ [ y_i ln F(z_i) + (1−y_i) ln(1−F(z_i)) ]
```
因 MLE 最大化数值，软件用迭代（Newton-Raphson / BHHH）；不收敛、完全分离（某 X 完美预测 y）会导致系数发散，须检查。

| 检验 / 指标 | 说明 |
| --- | --- |
| Wald / z 检验 | 单个系数显著性（渐近正态） |
| **似然比 LR** | `LR = 2(lnL_u − lnL_r) ∼ χ²(q)`，比较嵌套模型，最可靠 |
| LM（得分）检验 | 只需估约束模型 |
| 伪 R²（McFadden） | `1 − lnL_u/lnL_r`，**不能**与 OLS 的 R² 比大小，0.2–0.4 已算不错 |
| 分类表 / ROC-AUC / Hosmer-Lemeshow | 预测准确度与校准度；不平衡样本要看 PR-AUC 与阈值选择 |

### 10.4 扩展模型（★★★）

| 模型 | 适用情形 |
| --- | --- |
| **多项 Logit / Probit** | 因变量多个无序类别（公交/自驾/骑车）；须满足 **IIA 无关选项独立性**（用 Hausman-McFadden 检验），否则用嵌套 Logit / 混合 Logit |
| **有序 Logit / Probit** | 因变量有序（满意度 1–5 级）；假定**平行线（比例优势）**，违反则用广义有序模型 |
| **Tobit（删失回归）** | 因变量在 0 处**角点堆积**（消费支出、工作时间），OLS 会有偏；用 MLE 同时刻画「是否参与」与「参与多少」 |
| **Heckman 两阶段（样本选择）** | 样本非随机进入（只有就业者才有工资）→ 选择偏差；第一阶段选择方程算逆米尔斯比 λ，第二阶段纳入修正；须有**排除变量**才识别 |
| Poisson / 负二项 | 计数因变量（专利数、就诊次数）；过度离散时用负二项或稳健标准误 |
| 生存分析 / Cox | 持续时间数据（失业持续期） |

::: danger 易错 · 定性选择模型
- Logit/Probit 的 β **不是边际效应**；且边际效应依赖 X 取值，不能只报一个 β 就解释。
- 「优势比 1.65」是**发生比**变化 65%，不是「概率增加 65%」。
- 伪 R² 与 OLS 的 R² 不可比；分类准确率高也可能是因为样本极度不平衡（全部预测为多数类）。
- 非线性模型中的**交互项**符号与显著性不能只看乘积项系数（Ai–Norton 问题），须计算交互边际效应。
- 完全分离 / 稀有事件会让 MLE 偏误，可用 Firth 校正或精确 Logit。
:::

### 10.5 Tobit 的边际效应与 Heckman 两阶段

Tobit（潜变量 `y* = β′x+u`，观测 `y = max(0, y*)`）中 β 有三种不同的边际效应，**必须明确报的是哪一个**：
```text
① 潜变量：        ∂E(y*|x)/∂x_j = β_j
② 观测到的 y：    ∂E(y|x)/∂x_j = β_j·Φ(β′x/σ)
③ 参与概率：      ∂P(y>0|x)/∂x_j = φ(β′x/σ)·β_j/σ
④ 条件于 y>0：    ∂E(y|y>0,x)/∂x_j = β_j·[1 − zλ(z) − λ(z)²]，z=β′x/σ
```

**Heckman 两阶段（样本选择）**：
```text
① 选择方程（全样本 Probit）：P(s_i=1|z_i)=Φ(γ′z_i)，估 γ̂
② 对每个被选中的样本算逆米尔斯比 λ_i = φ(γ̂′z_i)/Φ(γ̂′z_i)
③ 结果方程（仅选中样本）：y_i = β′x_i + ρσλ_i + e_i
   λ 显著 ⇒ 存在选择偏差；ρ 为选择与结果误差的相关系数
```
**识别关键**：`z` 中至少要有一个**排除变量**（影响是否进入样本、但不直接影响结果），否则 λ 与 x 高度共线、修正不可靠。

## 综合例题精讲（跨章）

> 按「读题 → 列条件 → 完整演算 → 结论」展开，所有数值均已独立复算，适合闭卷手算练习。

### 综 1 · 一元 OLS 全套手算（第 2、3 章）

**题**：`X=[1,2,3,4,5]`，`Y=[2,4,5,7,9]`。求 OLS 估计式、R²、调整 R²、σ̂²、se(β̂₁)、t 值、95% 置信区间、整体 F 值与 `X=6` 的点预测。

**解**：
```text
① X̄=3, Ȳ=5.4；Sxx=10, Sxy=17
② β̂₁ = 17/10 = 1.7；β̂₀ = 5.4 − 1.7×3 = 0.3 → Ŷ = 0.3 + 1.7X
③ 拟合值 [2.0, 3.7, 5.4, 7.1, 8.8]；残差 [0, 0.3, −0.4, −0.1, 0.2]（和为 0 ✓）
④ SSE = 0.30, SST = 29.20, SSR = 28.90
   R² = 28.90/29.20 = 0.9897；R̄² = 1 − (1−0.9897)×4/3 = 0.9863
⑤ σ̂² = SSE/(n−2) = 0.30/3 = 0.10
   se(β̂₁) = √(0.10/10) = 0.10
⑥ t = 1.7/0.10 = 17.0 > t₀.₀₂₅(3)=3.182 → 拒绝 H₀: β₁=0
   95% CI = 1.7 ± 3.182×0.10 = [1.382, 2.018]
   F = t² = 289
⑦ X=6 → Ŷ = 0.3 + 1.7×6 = 10.5
```
**易错**：σ̂² 用 `n−2` 而不是 `n`；个别值预测区间比均值预测区间多一个 `1`；本例 n=5 过小，t 检验依赖正态性假定。

### 综 2 · 多元回归的约束检验与调整 R²（第 4 章）

**题**：无约束模型 `n=30, k=3, R²_u=0.86`；施加 2 个线性约束后 `R²_r=0.62`。检验约束是否成立，求调整 R² 与整体 F。

**解**：
```text
F = [(R²_u − R²_r)/q] / [(1−R²_u)/(n−k−1)]
  = [(0.86−0.62)/2] / [0.14/26] = 0.12/0.0053846 = 22.29
F₀.₀₅(2,26) ≈ 3.37 → 拒绝约束（被排除变量联合显著）
R̄² = 1 − (1−0.86)×29/26 = 0.8438
整体 F = (0.86/3)/(0.14/26) = 53.24 > F₀.₀₅(3,26)≈2.98 → 方程整体显著
```
**延伸**：若各系数 t 值都很小但整体 F 很大，首先怀疑**多重共线性**；若单个系数符号与经济理论相反且标准误很大，同样指向共线或样本不足。

### 综 3 · 异方差的检验与修正（第 5 章）

**题**：`n=50`，残差平方对解释变量的辅助回归 `R²_aux=0.12`（2 个约束）。判断是否存在异方差，并给出两套处理方案。

**解**：
```text
LM = n·R²_aux = 50×0.12 = 6.00；χ²₀.₀₅(2)=5.99 → 6.00 > 5.99，勉强拒绝同方差
（结论应谨慎：贴近临界值，宜结合残差图与 White 检验；White 的 df 更大，可能不拒绝）
```
- **方案 A（现代实证首选）**：保留 OLS 系数，改用**异方差稳健标准误**（HC1/HC3）重算 t 与置信区间。优点是不需设定 σ_i² 的具体形式。
- **方案 B（效率优先）**：若已知 `Var(u_i)=σ²X_i²`，两边同除 `X_i` 得 WLS；若 σ_i² 未知，先用残差估计再做 FGLS。
- **提醒**：异方差下 `R²`、系数点估计仍可用；失效的是标准误与一切基于它的推断。若数据按个体/地区分组，还要改用**聚类稳健标准误**。

### 综 4 · 自相关 DW 与 Cochrane-Orcutt（第 3、5 章）

**题**：残差 `e=[0, 0.3, −0.4, −0.1, 0.2]`。计算 DW、估计 ρ̂；若另一研究发现 `d=0.8`，说明后果与修正步骤。

**解**：
```text
Σ(e_t−e_{t−1})² = 0.09+0.49+0.09+0.09 = 0.76；Σe_t² = 0.30
d = 0.76/0.30 = 2.533 → ρ̂ = 1 − d/2 = −0.267（轻微负相关；n=5 仅演示算法）
若 d = 0.8 → ρ̂ = 0.60，明显正自相关
```
后果：系数（严格外生下）仍无偏，但 OLS 标准误被**低估**，t 值虚高 → 假阳性；OLS 不再有效。
修正（Cochrane-Orcutt 迭代）：
```text
① 由残差回归 e_t = ρ e_{t−1} + v_t 得 ρ̂
② 广义差分：Y_t − ρ̂Y_{t−1} = β₀(1−ρ̂) + β₁(X_t − ρ̂X_{t−1}) + v_t
③ 对变换后模型做 OLS，用新残差重估 ρ̂，迭代至收敛
④ 第一个观测可用 Prais-Winsten 变换 (√(1−ρ̂²)Y₁) 补回，避免损失样本
```
**更稳妥的现代做法**：直接报告 **Newey-West HAC 标准误**；或先检查是否因**遗漏滞后变量**造成「伪自相关」。

### 综 5 · 多重共线性 VIF（第 4、5 章）

**题**：把 `X₁` 对其余解释变量辅助回归得 `R²₁=0.90`。求 VIF，说明对标准误与 t 值的影响。

**解**：
```text
VIF₁ = 1/(1−0.90) = 10
Var(β̂₁) = σ²/[Sxx₁(1−R²₁)] = 10 ×（无共线时的方差）
se(β̂₁) = √10 ≈ 3.16 倍 → t 值约降为 1/3.16
```
典型症状：整体 F 显著、R² 高，但单个 t 多数不显著；增删少量样本系数剧变甚至符号反转。
**注意**：共线并不使系数有偏，也不必然损害**样本内共线模式延续时**的预测；若只是要检验「两个变量的联合效应」，直接用 F 检验线性组合即可，不必逐个纠结 t 值。

### 综 6 · 动态模型的长期乘数与 Granger 检验（第 6 章）

**题**：部分调整模型估计得 `β₀=0.5, λ=0.6`；另 `SSE_r=1200, SSE_u=900, q=2, n=60, k=5`。求长期乘数、平均滞后与 Granger F 统计量并解读。

**解**：
```text
短期乘数 = 0.5
长期乘数 = β₀/(1−λ) = 0.5/0.4 = 1.25
平均滞后 ≈ λ/(1−λ) = 1.5 期（调整较慢）
F = [(1200−900)/2] / [900/(60−5)] = 150/16.364 = 9.17 > F₀.₀₅(2,55)≈3.17
  → 拒绝「X 的滞后项联合为 0」，X Granger 引起 Y
```
**解读边界**：这只是**增量预测能力**，不等于结构因果；若变量非平稳需先差分或做 VECM；滞后阶数换一档结论可能改变，应报告稳健性。

### 综 7 · 单位根、协整与 ECM（第 7 章）

**题**：对 `Y_t`、`X_t` 的水平值 ADF 检验统计量分别为 `−1.71`、`−0.72`（5% 临界值 `−3.01`）；一阶差分后为 `−3.68`、`−3.49`（5% 临界值 `−1.96`）；协整残差的 AEG 统计量为 `−4.99`（5% 临界值 `−3.01`）。判断单整阶、是否协整，并解释 ECM 中 `γ̂=−0.25` 的含义。

**解**：
```text
水平值：−1.71 > −3.01、−0.72 > −3.01 → 均不能拒绝单位根 ⇒ Y, X ∼ I(1)
一阶差分：−3.68 < −1.96、−3.49 < −1.96 → 拒绝单位根 ⇒ 差分后平稳，确为 I(1)
协整残差：AEG = −4.99 < −3.01 → 拒绝「残差有单位根」⇒ 二者协整，存在长期均衡
```
因此不能简单把两变量差分后回归（会丢长期信息），应建立 **VECM / ECM**：
`ΔY_t = α + γ(Y_{t−1} − β̂₀ − β̂₁X_{t−1}) + Σδ_iΔX_{t−i} + ε_t`。
`γ̂ = −0.25` 表示上期偏离长期均衡 1 单位，本期 Y 反向调整 0.25 单位（约修正 25%），半衰期 `ln0.5/ln0.75 ≈ 2.4` 期；γ 必须显著为负，否则误差修正机制不成立。

### 综 8 · 面板 FE / RE 与 Hausman 检验（第 9 章）

**题**：`β̂_FE=0.62 (Var=0.004)`，`β̂_RE=0.45 (Var=0.001)`。做 Hausman 检验并说明选哪个模型，以及 FE 的两个局限。

**解**：
```text
H = (0.62−0.45)²/(0.004−0.001) = 0.0289/0.003 = 9.63 > χ²₀.₀₅(1)=3.84
→ 拒绝「个体效应与解释变量不相关」，RE 不一致，应选固定效应 FE
```
FE 的局限：① **不能估计**不随时间变化的变量（性别、地区固定属性）的系数（但能控制它们）；② 当 T 小、组内变异少时估计噪声大；③ 含被解释变量滞后项时产生 Nickell 偏误，需 GMM。
报告时还须使用**按个体聚类的稳健标准误**；可用 Mundlak-CRE 作为兼顾时不变变量与相关性的折中方案。

### 综 9 · Logit 概率、边际效应与优势比（第 10 章）

**题**：Logit 模型估计得 `z = −1 + 0.5x`。求 `x=2,4,6` 处的预测概率与边际效应、优势比，并说明为何系数不能直接当边际效应。

**解**：
```text
P = 1/(1+e^{−z})，边际效应 ME = β₁·P(1−P)
x=2 → z=0   → P=0.5000，ME=0.5×0.25=0.1250（最大）
x=4 → z=1   → P=0.7311，ME=0.5×0.7311×0.2689=0.0983
x=6 → z=2   → P=0.8808，ME=0.5×0.8808×0.1192=0.0525
OR = e^{0.5} = 1.649 → x 每增 1 单位，发生比 P/(1−P) 变为 1.649 倍（+64.9%）
```
系数 β 只决定对数发生比的斜率与方向；因为连接函数是 **S 形非线性**，概率变化随 x 而变（P≈0.5 处最陡、两端趋平）。因此实证论文应报告 **平均边际效应 AME** 或指定点的 MEM，而非只报 β；OR 描述的是**发生比**变化，不是概率变化 64.9%。

## 附录 B 易错点速查

1. 计量经济学不是「跑回归软件」：理论设定、识别策略与诊断比估计命令更重要。
2. 随机扰动项 u 不可观测；残差 e 是它的估计，二者不能混用。
3. 混合数据（不同时点不同个体）≠ 面板数据（同一批个体跨期追踪）。
4. 高 R² 不等于模型正确、更不等于因果；低 R² 也不等于模型无用。
5. 点预测之外应给预测区间；样本外远推风险很大。
6. 「统计显著」与「经济显著」是两回事，n 很大时微小系数也会显著。

7. 抽样分布是**估计量**的分布，不是样本数据的分布。
8. 无偏是小样本性质，一致是大样本性质；二者互不蕴含。
9. 有效性只在「同类（线性无偏）」估计量内比较；有偏估计方差可以更小。
10. `Var(aX+b)=a²Var(X)`；常数项不影响方差但影响期望。
11. 协方差为 0 只说明无**线性**相关，不能推出独立。
12. t 分布来自 `Z/√(χ²/m)`；F 来自两个独立 χ² 之比除以各自自由度。
13. `t²(m)=F(1,m)`；大样本下 `Wald/LM/LR` 都渐近 `χ²(q)`。
14. 95% 置信区间是「反复抽样区间覆盖真值的频率」，不是「真值有 95% 概率落在此区间」。
15. 第一类错误概率 = α；第二类错误概率 = β，功效 `1−β`；α 与 β 此消彼长。
16. 「不拒绝 H₀」≠「接受 H₀」；p 值不是「H₀ 为真的概率」。

17. OLS 的「线性」指对**参数**线性，`Y=β₀+β₁X²+u` 仍属线性回归。
18. 高斯-马尔可夫定理**不要求正态性**；正态性只用于小样本精确 t/F 推断。
19. BLUE 的「最佳」限于线性无偏类，且 A1–A6 任一被破坏结论即失效。
20. `σ̂² = SSE/(n−k−1)` 的分母是自由度，不是 n；MLE 用 n 但有偏。
21. `SST=SSR+SSE` 只在**含截距且用 OLS** 时成立，无截距模型不成立。
22. 回归线必过 `(X̄, Ȳ)`；含截距时残差和为 0、残差与 X 不相关。
23. `R²` 单调不减，不能跨不同被解释变量（线性 vs 对数）比较。
24. 调整 R² 可能为负；加变量后要同时看调整 R² / AIC / SC 与理论依据。
25. t 检验显著只能说明线性关联，不能推出因果关系。
26. 个别值预测区间**宽于**均值预测区间（多一个扰动项方差）。
27. 小样本 t/F 推断依赖误差正态性；大样本可用渐近正态与稳健标准误。
28. 遗漏变量会导致系数有偏且不一致；包含无关变量只损失效率。

29. 偏回归系数必须带「其它变量不变」的前提。
30. 遗漏变量偏误方向 = `sign(β₂)×sign(Corr(X₁,X₂))`。
31. 控制「受处理影响」的变量（坏控制）会阻断因果路径，制造偏误。
32. 虚拟变量 m 类只放 m−1 个；全放且含截距 ⇒ 虚拟变量陷阱（完全共线）。
33. 交互项显著时，主效应只代表「另一变量为 0」时的效应。
34. 双对数模型系数是弹性；线性-对数、对数-线性的解释各不相同。
35. 对数变换要求变量取正值；零值不能直接取对数。
36. 单个 t 不显著而整体 F 显著，常是多重共线性的信号。

37. 异方差与自相关**不使系数有偏**，只毁掉标准误、t/F 与置信区间。
38. 内生性（遗漏变量、反向因果、测量误差）才使系数**有偏且不一致**。
39. 增大样本能救不一致之外的多数问题，但**救不了内生性**。
40. VIF = `1/(1−R²_j)`；VIF=10 意味着标准误约为 √10≈3.16 倍。
41. 多重共线下**预测**在共线模式延续时仍可可靠，只是单个系数不可靠。
42. 稳健标准误只修标准误，不修设定错误、不修内生性。
43. 面板 / 分组数据要用**聚类稳健标准误**，仅用异方差稳健仍会低估。
44. DW 只检一阶 AR(1)，且要求解释变量**不含被解释变量滞后项**、含截距、无缺失值。
45. 含 `Y_{t−1}` 时 DW 偏向 2 易漏检，应改用 Durbin h 或 Breusch-Godfrey LM。
46. DW 有「不可判定区」（d_L、d_U），不能只凭 d≈2 下结论。
47. `d=0.8 → ρ̂=0.6`；`d=2 → ρ̂=0`；`d=3.4 → ρ̂=−0.7`。
48. DW 偏低也可能是**遗漏滞后变量**造成的伪自相关，先查设定再修误差。
49. 工具变量必须同时满足相关性与**排他性**（只通过 X 影响 Y）。
50. 弱工具（第一阶段 F<10）会让 2SLS 偏误且 Wald 检验失真。
51. IV 在异质效应下识别的是 **LATE**（compliers 的局部平均效应），不是全样本 ATE。
52. RESET 显著提示函数形式误设定，但不告诉你要加什么变量。

53. 分布滞后模型的长期乘数是 `Σβ_i`，不是当期系数 β₀。
54. Koyck / 部分调整 / 适应预期的回归式相似，但经济含义与扰动结构不同。
55. Koyck 变换后扰动为 MA(1) 且与 `Y_{t−1}` 相关 ⇒ OLS 不一致。
56. 「Granger 因果」是增量**预测**能力，不是结构因果；反向因果也要检验。
57. Granger 检验前须处理非平稳性，且结论对滞后阶数敏感。
58. 滞后阶数用 AIC/SC 选；逐步删项的预检验会扭曲 t 统计量的分布。

59. 弱平稳要求均值、方差**与**自协方差都只依赖间隔而非时点。
60. 确定性趋势序列不平稳，但去趋势后平稳（趋势平稳），与单位根过程不同。
61. 单位根过程的冲击有**永久**效应，趋势平稳的冲击是暂时的。
62. 两个独立随机游走互相回归会产生**伪回归**（高 R²、显著 t、低 DW）。
63. ADF 的 H₀ 是「有单位根」，要用 MacKinnon 临界值，不是标准 t 的 1.96。
64. KPSS 的原假设与 ADF 相反（平稳），可联合使用确认。
65. 协整要求同阶单整（EG 框架）；`I(0)/I(1)` 混合用 ARDL 边界检验。
66. 协整 ⇒ 必存在 ECM 表示；`γ<0` 才是向均衡回调，且差分过大会丢长期信息。

67. 联立方程中内生变量与扰动相关 ⇒ OLS 有偏且**不一致**。
68. 恒等式没有待估参数，但仍计入方程总数 G。
69. 识别阶条件只是**必要**条件，秩条件才是充要条件。
70. 恰好识别可用 ILS；过度识别须用 2SLS / LIML / GMM。
71. 2SLS 第二阶段标准误要用原始内生变量计算的残差修正，不能直接用拟合值。
72. 简化式系数是总效应（含乘数 `1/(1−β)`），不等于结构系数。

73. FE 用组内变换消去 μ_i，允许 `Cov(μ_i,x)≠0`，一致性更强。
74. FE **不能估计**时不变变量的系数，但能控制它们的影响。
75. RE 更有效的代价是强假定 `Cov(μ_i,x)=0`，违反则不一致。
76. Hausman 显著 ⇒ 拒绝 RE、选 FE；不显著只表示「证据不足」，不等于假定成立。
77. 含滞后被解释变量的短面板 FE 有 **Nickell 偏误**（约 `−1/T`），须用系统 GMM。
78. 面板标准误必须按个体聚类；聚类数少时用 wild cluster bootstrap。
79. 交错处理时点的 TWFE 在异质效应下可能偏误，需专用稳健估计量。

80. LPM 的预测概率可能越出 [0,1]，且必然异方差（`p(1−p)`）。
81. Logit/Probit 的 β **不是**边际效应；边际效应随 X 变化。
82. 优势比 `e^β` 描述的是**发生比**变化，不是概率变化。
83. `β_Logit ≈ 1.6 β_Probit`（因分布方差不同），系数数值不可直接比较。
84. 伪 R² 与 OLS 的 R² 不可比；不平衡样本下高分类准确率可能是假象。
85. 多项 Logit 须满足 **IIA**，有序模型须满足**平行线假定**，都要检验。
86. Tobit 处理角点堆积（删失），Heckman 处理非随机样本选择，二者不是一回事。
87. 非线性模型交互项的显著性不能只看乘积项系数（Ai–Norton 问题）。

88. 「相关 ≠ 因果」贯穿全书：系数能作因果解释的前提是**识别成立**（外生性、无遗漏、无同时性、样本无选择性偏差），而不是 t 值够大。
