## 第1章 导论

### 1.1 研究对象与基本问题

**宏观经济学**以整个国民经济活动为研究对象，关注**总量**；微观经济学研究个体经济单位（消费者、企业、单个市场）。

> **合成谬误**：微观是宏观的基础，但**宏观并非微观的简单加总**——对个体成立的结论，对整体未必成立（节俭悖论就是典型例子）。

| 基本问题 | 核心追问 |
| --- | --- |
| 国民收入的决定与变动 | 什么决定总产出水平？ |
| 失业 | 为什么存在失业？如何降低失业率？ |
| 通货膨胀 | 物价为何持续上涨？如何治理？ |
| 经济增长 | 如何实现长期持续增长？ |
| 国际收支与汇率 | 开放条件下如何实现内外平衡？ |

### 1.2 流派演进（记住「谁反对谁」）

| 阶段 | 核心信条 | 政策主张 |
| --- | --- | --- |
| **古典经济学**（18 世纪末—1930s） | 萨伊定律「供给创造自身的需求」，工资价格完全弹性，经济自动趋向充分就业 | 自由放任，不干预 |
| **凯恩斯革命**（1936《就业、利息和货币通论》） | **有效需求不足**导致非自愿失业；三大心理规律：边际消费倾向递减、资本边际效率递减、流动性偏好 | 政府用**财政政策**干预，需求管理，赤字财政 |
| **新古典综合**（1940s—60s，希克斯、汉森、萨缪尔森） | 提出 IS-LM 模型、引入菲利普斯曲线，微宏结合 | 财政与货币政策并用 |
| **货币主义**（1960s—70s，弗里德曼） | 「通胀无论何时何地都是一种货币现象」；自然失业率假说，否定长期菲利普斯曲线 | **单一规则**：固定货币增长率 |
| **理性预期 / 新古典宏观**（1970s—80s，卢卡斯、萨金特） | 理性预期、政策无效性命题、实际经济周期（RBC） | 被预期到的政策不影响实际变量 |
| **新凯恩斯主义**（1980s 至今，曼昆、斯蒂格利茨） | 为工资价格黏性提供微观基础（菜单成本、效率工资） | 市场不完善，货币政策仍有效 |
| **新增长理论**（1980s，罗默、卢卡斯） | 把技术进步与人力资本**内生化**（知识外溢、研发、干中学） | 补贴研发与教育 |

### 1.3 分析方法

| 对比 | 说明 |
| --- | --- |
| 总量分析 | 总产出、总就业、总价格等宏观变量 |
| 均衡分析 | 寻找使经济达到稳定状态的条件 |
| 静态 / 比较静态 / 动态 | 不计时间 / 比较不同均衡 / 考察调整路径 |
| 实证 / 规范 | 「实然」客观描述 / 「应然」含价值判断 |
| 存量 / 流量 | 特定时点（资本存量、财富） / 一定时期（GDP、投资、储蓄） |

### 1.4 易错点

- GDP、投资、储蓄是**流量**；资本存量、财富、债务余额是**存量**。
- 萨伊定律属于**古典**经济学；「有效需求不足」属于**凯恩斯**，两者不要张冠李戴。
- 货币主义否定的是**长期**菲利普斯曲线（长期垂直），并不否认短期替代关系。

## 第2章 宏观经济的基本指标及其衡量

![GDP 三种核算方法与收入流量循环](/macro/macro-gdp.svg)

### 2.1 GDP 的定义与内涵

**国内生产总值（GDP）**：一定时期内（通常一年）一国**国境范围内**所生产的全部**最终产品和服务**的**市场价值**总和。

| 关键词 | 含义 |
| --- | --- |
| 一定时期 | **流量**而非存量；只计当期生产，不含二手货交易 |
| 国境范围 | **国土原则**（GDP），区别于国民原则的 GNI/GNP |
| 最终产品 | 只计最终产品，**不计中间产品**（避免重复计算）；也可用各环节增加值求和 |
| 市场价值 | 按市场价格计价，非市场活动（家务劳动、自给自足）不计入 |
| 生产 | 是「生产」而非「售出」；未售出产品计入**存货投资** |

**几个易考的判断**：
- 自有住房按**估算租金**计入 GDP；购买股票、债券是**金融资产转移**，不计入 GDP；
- 政府**转移支付**（失业救济、养老金）不计入 G，因为没有对应的商品服务交换；
- 家庭购买**新建住房**计入投资 I，不是消费 C；
- 存货变动计入 I；净出口 NX = 出口 − 进口。

### 2.2 三种核算方法

| 方法 | 公式 | 要点 |
| --- | --- | --- |
| **生产法**（增加值法） | GDP = 各部门（总产出 − 中间投入）之和 | 第一、二、三产业增加值加总 |
| **支出法** | **GDP = C + I + G + NX** | C 消费、I 投资（固定投资 + 存货 + 住宅）、G 政府购买（**不含转移支付**）、NX 净出口 |
| **收入法** | GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余 | 从「谁获得收入」角度核算 |

**补充：五个总量指标的换算（易出计算题）**

| 指标 | 换算 |
| --- | --- |
| GNI（国民总收入） | GDP + 来自国外的要素净收入 |
| NDP（国内生产净值） | GDP − 折旧 |
| NI（国民收入） | NDP − 间接税 + 补贴（≈ 要素收入合计） |
| PI（个人收入） | NI − 企业未分配利润 − 社会保险税 + 转移支付 |
| DPI（个人可支配收入） | PI − 个人所得税 |

**恒等式（事后恒等，与「计划相等」的均衡条件不同）**：

| 部门 | 注入 = 漏出 |
| --- | --- |
| 两部门 | I = S |
| 三部门 | I + G = S + T（T 为**净税收** = 税收 − 转移支付） |
| 四部门 | I + G + X = S + T + M |

### 2.3 名义 GDP、实际 GDP 与价格指数

| 概念 | 说明 |
| --- | --- |
| 名义 GDP | 按**当期**价格计算，同时受产量与价格影响 |
| 实际 GDP | 按**基期**价格计算，剔除价格变动 |
| **GDP 平减指数** | 名义 GDP ÷ 实际 GDP × 100 |

**换算公式**：**实际 GDP = 名义 GDP ÷ (价格指数 ÷ 100)**。例：1970 年名义 GDP 7500 亿，价格指数（1960=100）为 120，则按 1960 年价格计的实际 GDP = 7500 ÷ 1.2 = **6250 亿**。

| 指数 | 篮子 | 关键区别 |
| --- | --- | --- |
| CPI | **固定**一篮子消费品与服务 | 含进口消费品；存在替代偏误、新产品偏误、质量偏误 |
| PPI | 企业出售的商品 | 常被视为 CPI 的**先行指标** |
| GDP 平减指数 | **随产出变化**，覆盖全部国内生产品（含投资品） | 只反映国内价格，不含进口品 |

**通胀率 = (当期价格指数 − 上期价格指数) ÷ 上期价格指数 × 100%**。

### 2.4 失业的衡量

- 劳动力人口 = 就业人口 + 失业人口（**失业人口须「没有工作 + 正在积极寻找工作」**，放弃找工作者不计入劳动力）；
- 失业率 = 失业人口 ÷ 劳动力人口 × 100%；
- 劳动参与率 = 劳动力人口 ÷ 劳动年龄人口 × 100%。

**例**：1.9 亿成年人中 1.2 亿就业、0.1 亿找工作、0.45 亿不找工作 → 劳动力 = 1.3 亿，失业率 ≈ 7.7%，劳动参与率 ≈ 68.4%。

### 2.5 GDP 指标的局限

不能衡量收入分配、环境代价、闲暇价值、非市场活动与地下经济，也不直接反映幸福感与可持续性。

### 2.6 易错点

- GDP 是**国土原则**、GNI/GNP 是**国民原则**；「所有居民」的说法用于 GDP 是错的。
- 政府购买 G **不含**转移支付与公债利息。
- 名义 GDP 变动未必是产量变动；实际 GDP 只反映产量变动。
- 事后恒等式 I = S 恒成立；**均衡条件**是「计划投资 = 计划储蓄」，二者不是一回事。

## 第3章 国民收入的决定：收入-支出模型

![45 度线、均衡产出与乘数效应](/macro/macro-cross.svg)

### 3.1 均衡产出与 45 度线

**均衡条件**：总产出 Y = 总支出 AE，等价于**非计划存货投资 = 0**，也等价于**计划投资 = 计划储蓄**。

| 情形 | 非计划存货 | 企业反应 |
| --- | --- | --- |
| AE > Y | 存货**意外减少** | 扩大生产 → Y 上升 |
| AE < Y | 存货**意外增加** | 缩减生产 → Y 下降 |
| AE = Y | 不变 | 达到均衡 |

在 **Y–AE 图**中，45 度线表示 Y = AE；AE 线（斜率为 MPC）与 45 度线的交点即均衡产出。

- **紧缩性缺口**：均衡产出低于充分就业产出，需扩张需求；
- **膨胀性缺口**：均衡产出高于充分就业产出（在既定价格下表现为需求过旺），需紧缩需求。

### 3.2 消费函数与储蓄函数

**凯恩斯消费函数**：**C = a + bY**（a > 0 为自发消费，0 < b < 1 为边际消费倾向 MPC）

| 概念 | 公式 | 性质 |
| --- | --- | --- |
| 边际消费倾向 MPC | ΔC / ΔY = b | 0 < b < 1 |
| 平均消费倾向 APC | C / Y = a/Y + b | 随收入上升而**递减**，恒大于 MPC |
| 储蓄函数 | **S = Y − C = −a + (1−b)Y** | 由消费函数直接推出 |
| 边际储蓄倾向 MPS | ΔS / ΔY = 1 − b | **MPC + MPS = 1** |
| 平均储蓄倾向 APS | S / Y | **APC + APS = 1** |

**三大心理规律之一：边际消费倾向递减**——收入越高，新增收入中用于消费的比例越小，这是消费需求不足的根源。

其他影响消费的因素：利率（替代效应与收入效应方向相反）、价格水平（实际余额效应）、收入分配、预期、财富（财富效应）。

### 3.3 其他消费理论（简答常考）

| 理论 | 提出者 | 核心观点 |
| --- | --- | --- |
| **相对收入** | 杜森贝利 | **示范效应**（攀比）与**棘轮效应**（消费不可逆，由俭入奢易、由奢入俭难） |
| **生命周期** | 莫迪利安尼 | 按一生总收入平滑消费，工作期储蓄、退休期动用储蓄；C = αW + βY |
| **持久收入** | 弗里德曼 | 消费取决于**持久收入**，暂时收入影响很小；解释短期 MPC 小于长期 MPC |

### 3.4 投资函数

**I = I(r)**，与实际利率**负相关**（利率是投资的成本）。

| 概念 | 含义 |
| --- | --- |
| 资本边际效率 MEC | 使资本品预期收益现值等于其供给价格的贴现率；MEC > r 才值得投资 |
| 投资的边际效率 MEI | 考虑资本品价格上涨后随投资增加而递减的收益率 |
| **托宾 q** | 企业市场价值 ÷ 资本重置成本；**q > 1** 时投资有利可图 |

另受预期收益、风险、融资约束影响。IS-LM 中常写 **I = I₀ − d·r**，d 为投资对利率的敏感度。

### 3.5 各部门的均衡收入

| 部门 | 均衡条件 | 均衡收入（Y） |
| --- | --- | --- |
| 两部门 | Y = C + I | **Y = (a + I₀) / (1 − b)** |
| 三部门 | Y = C + I + G，T = T₀ + tY | **Y = (a + I₀ + G₀ − bT₀ + bTR₀) / [1 − b(1−t)]** |
| 四部门 | Y = C + I + G + NX，M = M₀ + mY | 分母再加 m：Y = (…) / [1 − b(1−t) + m] |

> 分母里的每一項（储蓄、税收、进口）都是**漏出**，漏出越多，均衡收入越小、乘数越小。

### 3.6 乘数理论（★ 计算核心）

**机制**：自发支出增加 ΔA → 收入增加 ΔA → 其中 b·ΔA 用于消费 → 又形成他人收入 → 无限递推：

**ΔY = ΔA × (1 + b + b² + …) = ΔA / (1 − b)**，故 **乘数 k = ΔY/ΔA = 1 / (1 − MPC) = 1 / MPS**。

| 乘数 | 公式 | 说明 |
| --- | --- | --- |
| 投资乘数 k_I | 1 / (1 − b) | 与政府购买乘数相同 |
| 政府购买乘数 k_G | 1 / (1 − b) | 直接构成总需求 |
| 税收乘数 k_T | **−b / (1 − b)** | 负号：增税减少收入；绝对值比 k_G 小 1 |
| 转移支付乘数 k_TR | b / (1 − b) | 先影响可支配收入再影响消费 |
| **平衡预算乘数** | **k_G + k_T = 1** | ΔG = ΔT 时，收入仍等额增加 |
| 对外贸易乘数 k_F | 1 / (MPS + MPM) | 开放后进口漏出使乘数变小 |

**乘数发挥作用的前提（易考简答）**：

1. 经济中存在**未充分利用的闲置资源**（未达充分就业）——否则只推高价格不增加实际产出；
2. 利率基本不变——否则**挤出效应**削弱乘数；
3. 价格不变（短期分析假设）；
4. 边际消费倾向稳定且大于 0。

**节俭的悖论**：个体多储蓄是美德，但所有人都增加储蓄 → 消费减少 → 收入成倍下降 → **储蓄总量可能不变甚至减少**。这是合成谬误最经典的例子，前提是经济未达充分就业。

### 3.7 易错点

- 税收乘数为**负**、绝对值小于政府购买乘数；平衡预算乘数**等于 1** 而不是 0。
- APC > MPC（因为 a/Y > 0）；MPC + MPS = 1 与 APC + APS = 1 是两组不同等式。
- 未售出的产品计入**存货投资**而非从 GDP 中扣除。
- 「投资」在宏观里指**实际资本形成**（厂房、设备、住宅、存货），买股票不算投资。

## 第4章 国民收入的决定：IS-LM 模型

![IS 曲线、LM 曲线与一般均衡](/macro/macro-islm.svg)

### 4.1 产品市场均衡与 IS 曲线

**IS 曲线**：使产品市场均衡（I = S）的所有利率 r 与收入 Y 的组合。

以两部门、I = I₀ − d·r 为例：

**Y = (a + I₀ − d·r) / (1 − b)**，即 **r = (a + I₀)/d − [(1−b)/d]·Y**

| 性质 | 结论 |
| --- | --- |
| 斜率 | **向右下方倾斜**：r ↓ → I ↑ → 经乘数放大 Y ↑ |
| 平坦程度 | d 越大（投资对利率越敏感）→ IS 越平；b 越大（乘数越大）→ IS 越平 |
| 右移因素 | 自发消费 a ↑、自发投资 I₀ ↑、**政府购买 G ↑**、**税收 T ↓**、出口 ↑ |
| 左移因素 | 上述反向变化 |
| 失衡 | IS 线**上方**：Y 偏高 → 供过于求 → **I < S**；IS 线**下方**：**I > S** |

### 4.2 货币市场均衡与 LM 曲线

**凯恩斯流动性偏好**：**L = L₁(Y) + L₂(r) = kY − hr**

- 交易动机 + 预防动机 → 随收入 Y **正向**变动（系数 k）；
- 投机动机 → 随利率 r **反向**变动（系数 h，即货币需求的利率弹性）。

货币供给：名义 M 由央行**外生**决定，实际货币供给 = M/P。均衡条件 **M/P = kY − hr**，整理得

**LM 方程：r = (k/h)·Y − (1/h)·(M/P)**

| 性质 | 结论 |
| --- | --- |
| 斜率 | **向右上方倾斜**：Y ↑ → 交易性货币需求 ↑ → r ↑ 以恢复均衡 |
| **凯恩斯区域**（水平段） | 利率极低、**h → ∞**（流动性陷阱），LM 水平 |
| **古典区域**（垂直段） | **h → 0**，货币需求与利率无关，LM 垂直 |
| 中间区域 | 正常向右上方倾斜 |
| 右移因素 | 名义货币供给 M ↑、价格水平 P ↓ |
| 左移因素 | M ↓、P ↑ |

> **补充（资料缺失，考试常考）：货币乘数**。基础货币 B = 通货 + 准备金，**货币供给 M = B × m**，其中 m = (1 + 通货比率) / (法定准备金率 + 超额准备金率 + 通货比率)。法定准备金率越高，货币乘数越小。公开市场买入 → B ↑ → M 多倍扩张。

### 4.3 一般均衡

IS 与 LM 的**交点**同时决定均衡收入 Y\* 与均衡利率 r\*。调整机制：产品市场通过**产出（存货）**调整，货币市场通过**利率（债券买卖）**调整，后者反应更快。

| 冲击 | Y | r |
| --- | --- | --- |
| IS 右移（扩张财政） | ↑ | ↑ |
| LM 右移（扩张货币） | ↑ | ↓ |
| 两者同时右移 | 大幅 ↑ | 不确定 |

### 4.4 政策效果分析（★ 图形必考）

![财政政策、挤出效应与两个极端](/macro/macro-policy.svg)

#### 财政政策与挤出效应

G ↑ → IS 右移 → Y ↑、r ↑ → 利率上升**挤掉私人投资**，这叫**挤出效应（crowding out）**。

| 决定因素 | 影响 |
| --- | --- |
| 投资对利率敏感度 **d 越大** | 挤出**越大**，财政效果越弱 |
| 货币需求对利率敏感度 **h 越小**（LM 越陡） | 利率上升越多，挤出**越大** |
| LM 水平（h → ∞，流动性陷阱） | 利率不升，**挤出为零**，财政政策**最有效** |
| LM 垂直（h → 0，古典区） | **完全挤出**，财政政策**完全无效**（只推高利率） |

#### 货币政策与流动性陷阱

M ↑ → LM 右移 → r ↓ → I ↑ → Y ↑。**传导链**：M ↑ → r ↓ → I ↑ → Y ↑。

| 区域 | 货币政策效果 |
| --- | --- |
| 凯恩斯陷阱（LM 水平） | 增发货币全被投机需求吸收，r 不降 → **完全无效**，财政政策最有效 |
| 古典区域（LM 垂直） | **完全有效**，财政政策完全无效 |
| 中间区域 | 部分有效 |

#### 政策配合

| 组合 | 效果 |
| --- | --- |
| 双扩张（松财政 + 松货币） | Y 大幅 ↑，r 变动不确定 |
| 松财政 + 紧货币 | r 大幅 ↑，Y 不确定（挤出明显） |
| 紧财政 + 松货币 | r 大幅 ↓，Y 不确定，但**改变产出结构**（私人投资占比上升） |

### 4.5 凯恩斯理论的基本框架（简答模板）

有效需求不足是萧条根源 → 三条心理规律分别造成消费不足、投资不足、利率不能充分下降 → 市场不能自动实现充分就业 → 需要政府用财政政策弥补私人需求。**三大规律对应的是边际消费倾向、资本边际效率、货币需求三个变量；货币供给是央行外生给定的，不属于「心理规律」变量**（原 PPT 把「货币供给」列为规律涉及的四个变量之一，属表述错误，此处已修正）。

### 4.6 易错点

- **d 越大 → IS 越平 → 财政挤出越大、货币政策越有效**；**h 越大 → LM 越平 → 财政越有效、货币越无效**。
- 税收使 IS 移动幅度小于等量政府购买（因为税收先打一个 MPC 折扣）。
- 流动性陷阱下**财政最有效、货币完全无效**；古典区完全相反。
- IS 线上方是 I < S（供过于求），不是 I > S。

## 第5章 国民收入的决定：AD-AS 模型

![AD 曲线、三种总供给曲线与冲击分析](/macro/macro-adas.svg)

### 5.1 总需求曲线 AD

**AD = C + I + G + NX**，表示**价格水平 P 与总产出 Y** 之间的反向关系。

**AD 向右下方倾斜的三大效应（简答高频）**：

| 效应 | 传导链 |
| --- | --- |
| **利率效应**（凯恩斯效应） | P ↓ → 实际货币供给 M/P ↑ → r ↓ → I ↑ → Y ↑ |
| **实际余额效应**（庇古效应） | P ↓ → 居民实际财富 ↑ → C ↑ → Y ↑ |
| **汇率效应**（开放经济） | P ↓ → r ↓ → 资本流出、本币贬值 → NX ↑ → Y ↑ |

**从 IS-LM 推导 AD**：P 变动 → M/P 变动 → LM 平移 → 均衡 Y 变动；把不同 P 下的均衡点连起来即 AD 曲线。所以**凡使 IS 或 LM 右移的因素都会使 AD 右移**：G ↑ / T ↓ / M ↑ / 信心 ↑ / 国外收入 ↑（出口 ↑）。

### 5.2 总供给曲线 AS

宏观生产函数：短期 **Y = F(N, K̄)**（资本固定）；劳动需求由 **实际工资 = 劳动边际产品（W/P = MPN）** 决定。

| 形态 | 假设 | 曲线 | 政策含义 |
| --- | --- | --- | --- |
| **古典（长期）AS** | 工资价格**完全弹性**，劳动市场始终出清 | 在充分就业产出 Y_f 处**垂直** | 产出由要素与技术决定，需求管理**只影响价格** |
| **凯恩斯（极端短期）AS** | 工资价格**向下刚性**，存在闲置资源 | **水平线** | 扩需求只增产出、不推高价格，需求管理**最有效** |
| **常规（短期）AS** | 工资/价格黏性、菜单成本、价格错觉 | **向右上方倾斜** | 扩需求同时推高产出与价格 |

**AS 移动**：劳动、资本、技术进步 → AS 右移；原材料涨价、预期价格上升等**不利供给冲击** → AS 左移。

### 5.3 均衡与经济波动

- **短期均衡**：AD 与短期 AS 交点，Y 可偏离 Y_f；
- **长期均衡**：AD、短期 AS、长期 AS **三线交于一点**，Y = Y_f。

| 冲击 | 短期结果 | 政策两难 |
| --- | --- | --- |
| 正向需求冲击（AD 右移） | Y ↑、P ↑（经济过热） | 紧缩需求 |
| 负向需求冲击（AD 左移） | Y ↓、P ↓（衰退） | 扩张需求 |
| **不利供给冲击**（AS 左移，如石油暴涨） | **Y ↓ 且 P ↑ → 滞胀** | 刺激需求会加剧通胀，抑制通胀又进一步压产出 |

> **滞胀（stagflation）** 是需求管理政策最棘手的情景，说明**只调 AD 不够**：需求管理影响 AD，供给管理（减税、技术进步、放松管制）影响 AS，须长短结合。

### 5.4 易错点

- AD 曲线的横轴是**产出 Y**、纵轴是**价格水平 P**，与微观需求曲线（数量—单价）不是一回事，其下倾原因是三大宏观效应而非替代效应。
- 长期 AS 垂直 → **货币中性**：长期货币供给只影响价格，不影响实际产出。
- 滞胀来自**不利供给冲击**，不是需求过热。

## 第6章 失业与通货膨胀

![短期与长期菲利普斯曲线](/macro/macro-phillips.svg)

### 6.1 失业的类型

| 类型 | 成因 | 性质 |
| --- | --- | --- |
| **摩擦性失业** | 找工作、换工作需要时间 | 正常流转，不可避免 |
| **结构性失业** | 技能与岗位不匹配（产业转型） | 持续时间较长 |
| **周期性失业** | 衰退期总需求不足 | 随周期波动，是需求管理针对对象 |
| 季节性失业 | 农业、旅游等季节性行业 | — |

**自然失业率 = 摩擦性 + 结构性失业率**（**不含周期性失业**）；它并非「天然恒定」，受劳动力市场制度、技术进步、人口结构影响。**潜在产出 Y_f** 即自然失业率状态下的产出。

**自愿失业 vs 非自愿失业**：是否愿意接受现行工资水平；凯恩斯强调的是**非自愿失业**。

### 6.2 失业的经济学解释

| 流派 | 解释 |
| --- | --- |
| 古典 | **工资刚性**使劳动市场不能出清：最低工资法、工会、效率工资（企业主动付高工资以提高效率、减少跳槽） |
| 凯恩斯 | **有效需求不足** → 产品滞销 → 减产裁员；名义工资向下刚性使失业均衡可能长期持续 |
| 搜寻—匹配 | 信息不对称导致空缺与失业并存；**贝弗里奇曲线**刻画失业率与职位空缺率的负向关系，曲线外移说明匹配效率下降 |

### 6.3 奥肯定律

**实际失业率每高于自然失业率 1 个百分点，实际 GDP 约低于潜在 GDP 2~3 个百分点**。

**GDP 缺口 ≈ −c × (u − u\*)**，c ≈ 2~3。它把劳动力市场（失业）与产品市场（产出）联系起来，是估算产出损失的经验规律（**不是恒等式，系数因国因时而异**）。

### 6.4 通货膨胀

**定义**：一般价格水平**持续、显著**上涨（不是个别商品涨价、不是一次性上调）。通胀率按 CPI / PPI / GDP 平减指数的变化率计算。

| 分类维度 | 类型 |
| --- | --- |
| 严重程度 | 温和（年率 < 10%）、奔腾式（10%~100%）、恶性通胀 |
| 成因 | **需求拉动型**、**成本推动型**（工资推进、利润推进、输入型）、结构型、混合型、惯性通胀 |
| 是否预期到 | 预期到的（扭曲小）、未预期到的（再分配效应强） |

**成因理论**：

| 理论 | 核心 |
| --- | --- |
| 货币数量论（弗里德曼） | 通胀永远是货币现象：MV = PY，M 增长快于实际产出则 P 上升 |
| 需求拉动 | AD 持续右移，「过多货币追逐过少商品」 |
| 成本推动 | 要素涨价 → AS 左移 → **工资—价格螺旋** |
| 结构性 | 部门生产率不同但工资攀比趋同 |
| 预期 | 通胀预期 → 要求更高工资 → 企业抬价 → **预期自我实现** |

**经济效应**：

- **再分配**：不利于固定收入者、债权人；有利于**债务人**（实际债务负担减轻）；未预期到的通胀效应最强；
- **产出与效率**：温和通胀短期可能刺激产出；严重通胀扭曲价格信号、造成资源错配；恶性通胀使货币功能丧失；
- **微观成本**：菜单成本（频繁调价）、皮鞋成本（频繁跑银行）、税级爬升造成的税收扭曲。

**治理**：紧缩性货币 + 财政政策压需求；收入政策（工资—价格指导线 / 管制）；供给政策（减税、放松管制促竞争）；指数化（把工资、税级与 CPI 挂钩，治标不治本）。

### 6.5 菲利普斯曲线（★）

| 版本 | 结论 |
| --- | --- |
| 原始 PC（菲利普斯 1958，萨缪尔森—索洛修正） | 名义工资变化率（后改为通胀率）与失业率**反向替代** |
| **短期 PC** | 向右下方倾斜，通胀与失业存在 trade-off，政策可在两者间取舍 |
| **长期 PC** | 在**自然失业率 u\*** 处**垂直**，长期不存在替代关系（弗里德曼—费尔普斯） |
| 附加预期 | **π = πᵉ − ε(u − u\*)**；预期通胀上升使短期 PC **整体上移** |

**为什么长期垂直**：短期替代关系只来自**未预期到的**通胀；一旦人们把通胀预期调整到位，实际工资回到原水平，失业率回到 u\*，只会留下更高的通胀。

**解释滞胀**：不利供给冲击 + 通胀预期上移 → 短期 PC 右上移，出现**通胀与失业同时上升**；这也说明「用通胀换就业」只在短期、且只在预期未调整时有效。

**理性预期学派的极端观点**：只有未预期到的政策才影响实际变量，系统性的需求管理连短期也无效（政策无效性命题）。

### 6.6 易错点

- 自然失业率**包含**摩擦性与结构性失业，**不含**周期性失业；「自然失业率为零」是错的。
- 长期菲利普斯曲线垂直；短期替代关系来自**未预期到的**通胀。
- 通胀有利于债务人、不利于债权人与固定收入者，方向别反。
- GDP 缺口与失业缺口是**反向**关系，奥肯定律系数约 2~3，不是 1:1。

## 第7章 经济增长

![索洛模型的稳态与黄金律](/macro/macro-solow.svg)

### 7.1 基本概念

**经济增长**：一国一定时期内产品与劳务数量的持续增加（通常用 GDP 增长率衡量）。

- **增长 ≠ 发展**：增长是「量」，发展还包含结构升级、分配改善、环境可持续等「质」；
- **人均 GDP 增长率 ≈ 总量增长率 − 人口增长率**，衡量生活水平改善更合适。

### 7.2 增长核算

**增长核算方程**：**ΔY/Y = ΔA/A + α·(ΔK/K) + β·(ΔL/L)**（α、β 为资本与劳动的产出弹性，规模报酬不变时 α + β = 1）

**索洛剩余（全要素生产率 TFP）**：**ΔA/A = ΔY/Y − α·ΔK/K − β·ΔL/L**，即产出增长中无法由要素投入解释的部分，主要来自技术进步，是**长期人均收入增长最重要的源泉**。

三个直接源泉：劳动投入（数量 + 人力资本质量）、资本积累、技术进步（TFP）。

### 7.3 哈罗德—多马模型

| 增长率 | 公式 |
| --- | --- |
| 实际增长率 G_A | s / v（s 储蓄率，v 实际资本—产出比） |
| 有保证的增长率 G_W | s / v_r（v_r 为企业合意的资本—产出比） |
| 自然增长率 G_N | n + g（劳动力增长率 + 技术进步率） |

长期稳定增长要求 **G_A = G_W = G_N**，条件极其苛刻，称「**刀刃上的均衡**」。弱点：资本—产出比固定、劳动与资本不可替代。

### 7.4 索洛—斯旺模型（★ 核心模型）

**假设**：规模报酬不变、资本边际产出递减、I = S = sY、人口以外生速率 n 增长、折旧率 δ。

**资本积累方程（人均形式）**：

**Δk = s·f(k) − (n + δ)·k**

| 项 | 含义 |
| --- | --- |
| s·f(k) | 人均储蓄 / 投资，推动**资本深化** |
| (n + δ)k | 为新增人口配备资本 + 补充折旧，即**资本广化** |

**稳态条件**：**s·f(k\*) = (n + δ)k\***，此时 Δk = 0，人均资本 k\* 与人均产出 y\* 都**不再增长**。

| 外生变化 | 稳态影响 |
| --- | --- |
| 储蓄率 s ↑ | k\*、y\* **提高**，但只是**水平效应**，长期人均增长率仍为 0 |
| 人口增长率 n ↑ | 资本被摊薄，k\*、y\* **降低** |
| 折旧率 δ ↑ | k\*、y\* 降低 |

**黄金律（稳态人均消费最大）**：**c = f(k) − (n + δ)k**，最大化条件 **f′(k_gold) = n + δ**，即 **MPK = n + δ**（有技术进步时为 n + g + δ）。若稳态资本超过黄金律水平，则存在**动态无效率**（储蓄过多、消费反而更少）。

> **资料勘误（原框架前后矛盾，此处已修正）**：
> 1. 原框架在「引入技术进步」处同时写了「稳态时人均产出增长率 = 0」和「人均产出增长率 = g」，二者矛盾。**正确的是**：无技术进步时，稳态**人均产出增长率 = 0、总产出增长率 = n**；引入劳动增进型技术进步（Y = F(K, AL)，A 以 g 增长）后，稳态**单位有效劳动产出增长率 = 0，人均产出增长率 = g，总产出增长率 = n + g**。人均生活水平持续提高的**唯一源泉是技术进步**。
> 2. 原框架把黄金律写成「资本的**净**边际产出等于**经济增长率**」，应修正为「资本**边际产出 MPK = n + δ**（含技术进步时 n + g + δ）」，即等于**持平投资所需的人口增长与折旧之和**，而不是等于经济增长率。
> 3. 结论要点：索洛模型中**储蓄率只能改变稳态水平，不能改变长期人均增长率**——这是最常考、也最常被写错的结论。

**收敛假说**：绝对收敛（穷国无条件更快，实证支持有限）；**条件收敛**（控制储蓄率、人口增长、人力资本后穷国趋同更快，实证支持较强）。

### 7.5 内生增长理论

| 模型 | 核心 |
| --- | --- |
| **AK 模型** | Y = AK，资本边际产出**不变**（无递减），Δk/k = sA − (n + δ)，**无稳态**，增长可永久持续；政策能永久改变长期增长率 |
| 罗默（知识外溢 / 研发） | 知识是非竞争性投入，研发有正外部性 → 市场投入不足 → 需专利保护与研发补贴 |
| 卢卡斯（人力资本） | 人力资本积累是增长核心，具有正外部性 → 政府应补贴教育 |

政策含义：教育投资、研发支持、产权与制度完善能促进长期增长——与索洛模型「政策只影响水平」形成鲜明对比。

### 7.6 易错点

- 索洛稳态 **Δk = 0 ≠ k = 0**，更不是「经济不增长」：总产出仍以 n（或 n+g）增长。
- 储蓄率提高**只有水平效应**；长期人均增长靠技术进步。
- 黄金律是**人均消费最大**，不是人均产出最大（后者要求储蓄率趋于 1，消费反而为零）。
- 哈罗德—多马是「刀刃均衡」，索洛通过资本—劳动可替代解决了这一不稳定性。

## 第8章 经济周期

### 8.1 基本概念

**经济周期**：总体经济活动反复出现的扩张与收缩交替。四阶段：**繁荣 → 衰退 → 萧条（谷底）→ 复苏**。技术性衰退常指产出**连续两个季度及以上下降**。

| 变量类型 | 例子 |
| --- | --- |
| 顺周期 | 消费、投资、就业、物价（多与产出同向） |
| 逆周期 | 失业率 |
| 波动特征 | **投资波动幅度远大于消费**，是周期的主要驱动 |

周期长度：基钦存货周期（3—4 年）、朱格拉设备投资周期（7—11 年）、康德拉季耶夫技术长波（50—60 年）。

### 8.2 主要周期理论

| 流派 | 根源 | 政策含义 |
| --- | --- | --- |
| 传统外生论 | 太阳黑子（气候）、政治周期、熊彼特创新浪潮 | — |
| 传统内生论 | 纯货币（信贷扩张收缩）、投资过度、消费不足、心理预期 | — |
| **凯恩斯主义** | 有效需求波动 → 投资最不稳定 → 乘数放大；工资价格向下刚性使衰退不会自动消失 | **积极的逆周期财政货币政策** |
| **货币主义** | 货币供给不稳定增长是波动主因 | **单一规则**替代相机抉择 |
| **理性预期 / 卢卡斯** | 只有**未预期到的**货币变动影响实际产出 | 政策无效性命题 |
| **实际经济周期 RBC** | 技术冲击等**实际供给侧**因素；波动是理性主体的最优反应 | 否定货币政策稳定作用，否认短期菲利普斯曲线 |
| **新凯恩斯主义** | 菜单成本、效率工资、协调失灵为黏性提供微观基础 | 即便理性预期，**货币政策仍有效** |

### 8.3 乘数—加速数模型（萨缪尔森）

- **乘数原理**：投资变动 → 收入成倍变动（收入对投资的反向决定）；
- **加速原理**：收入变动 → 投资变动，**I_t = v(Y_{t−1} − Y_{t−2})**（投资取决于产出的**变化量**而非水平）；
- **相互作用**：投资 ↑ →（乘数）收入更大 ↑ →（加速数）投资再 ↑ → 繁荣；受资源与需求约束后收入增速放缓 → 加速数使投资 ↓ →（乘数）收入继续 ↓ → 衰退；固定资产更新又触发新一轮投资 → 复苏。

解释了「为什么投资波动远大于消费波动」，也说明政府可用干预减轻周期破坏性。

### 8.4 易错点

- 加速数取决于**产出变化量**，产出增速放缓就可能导致投资绝对下降。
- 乘数发挥作用以**存在闲置资源**为前提（PPT 强调过，易与长期分析混淆）。
- RBC 把衰退看作对技术冲击的**最优反应**，与凯恩斯「市场失灵需干预」立场完全相反。

## 第9章 宏观经济政策

### 9.1 四大目标与冲突

| 目标 | 含义 |
| --- | --- |
| 充分就业 | 失业率接近**自然失业率**（不是零失业） |
| 物价稳定 | 通胀控制在可接受的低水平（不是价格固定不变） |
| 经济持续均衡增长 | 避免大起大落 |
| 国际收支平衡 | 维持外部经济稳定 |

**内在冲突**：充分就业 ↔ 物价稳定（短期菲利普斯曲线取舍）；经济增长 ↔ 国际收支平衡（高增长往往带动进口、恶化经常账户）；充分就业 ↔ 国际收支平衡（国内扩张增加进口）。四大目标难以同时完美实现，需依形势权衡。

### 9.2 财政政策

| 工具 | 内容 |
| --- | --- |
| 政府购买 G | 直接构成总需求，乘数最大 |
| 转移支付 TR | 先影响可支配收入，再经 MPC 影响消费，效果小于等额 G |
| 税收 T | 影响可支配收入与激励 |
| 公债 | 为赤字融资，同时影响利率与私人投资 |

**自动稳定器（内在稳定器）**：累进所得税（衰退时税负自动下降）、失业保险与社会保障（衰退时转移支付自动增加）、农产品价格支持。**能减缓波动但不能消除波动，力度有限**。

**斟酌使用的财政政策**：衰退 → 扩张（增 G、减 T，赤字）；过热 → 紧缩（减 G、增 T，盈余）。**功能财政**以经济稳定为目标，不追求逐年预算平衡；可在**一个经济周期内**实现平衡。

**局限与争论**：

| 问题 | 说明 |
| --- | --- |
| 时滞 | 认识时滞 + 决策时滞（立法审批）+ 执行时滞，可能使政策在见效时已过时 |
| 挤出效应 | 政府借款推高利率 → 私人投资下降 |
| 政治约束 | 增税与削支在政治上阻力大 |
| **李嘉图等价**（巴罗） | 公债等于未来税收，理性家庭会增加储蓄应对，从而**总需求不变**、政策失效 |

### 9.3 货币政策

| 一般性工具 | 特点 |
| --- | --- |
| 法定存款准备金率 | 威力最猛、缺乏弹性，不宜日常微调 |
| 再贴现率 | 影响银行融资成本，有告示效应，但**主动权在商业银行**（被动性强） |
| **公开市场操作** | 最灵活、最常用、可微调可逆转 |

其他工具：消费者信用控制、证券市场保证金比例、不动产信用控制、优惠利率；道义劝告 / 窗口指导；直接信用控制（已逐步取消）。中国特色：SLF（常备借贷便利）、MLF（中期借贷便利）、TMLF、PSL（抵押补充贷款）、结构性货币政策工具「精准滴灌」。

**传导渠道**：

| 渠道 | 链条 |
| --- | --- |
| 利率（凯恩斯核心） | M ↑ → r ↓ → I ↑ → Y ↑ |
| 信贷 | M ↑ → 银行可贷资金 ↑ → 企业融资 ↑ → I ↑ |
| 资产价格 | M ↑ → 股价 ↑ → 托宾 q ↑ → I ↑；财富效应 → C ↑ |
| 汇率 | M ↑ → 本币贬值 → NX ↑ → Y ↑ |
| 预期 | 前瞻指引 → 长期利率预期变化 → 即期支出变化 |

**规则 vs 相机抉择**：相机抉择灵活，但有**时间不一致**问题（宣布低通胀后又为刺激产出制造意外通胀）。**泰勒规则**：**i = r\* + π + 0.5(π − π\*) + 0.5·(y − y\*)/y\***，名义利率系统性地对通胀偏离与产出缺口作出反应（资料中的 `i*` 应理解为**均衡实际利率 r\***，不是名义利率目标，此处已澄清）。另有通货膨胀目标制、麦卡勒姆规则、弗里德曼单一规则。

### 9.4 政策配合

| 组合 | 适用 | Y | r |
| --- | --- | --- | --- |
| 双松（松财政 + 松货币） | 严重衰退 | 大幅 ↑ | 不确定 |
| 双紧 | 严重通胀 | 大幅 ↓ | 不确定 |
| 松财政 + 紧货币 | 抑制私人投资、保政府支出 | 不确定 | 大幅 ↑ |
| 紧财政 + 松货币 | 促私人投资与出口 | 不确定 | 大幅 ↓ |

> 配合的意义不只是调**总量**，更是调**产出结构**：松财政 + 紧货币提高政府支出占比，紧财政 + 松货币提高私人投资与净出口占比。

**供给管理政策**：减税激励劳动与投资、放松管制、人力资本投资、研发与知识产权保护、产业政策——作用于 **AS**，用于应对滞胀等需求管理失效的场景。

### 9.5 易错点

- 自动稳定器**减缓但不能消除**波动，且不需要政府临时决策。
- 再贴现政策的局限是**被动性**（取决于银行是否来贴现）；法定准备金率的局限是**过于猛烈**。
- 李嘉图等价成立时，债务融资与税收融资等效，财政扩张失效。
- 转移支付乘数小于政府购买乘数，因为要先乘一次 MPC。

## 第10章 开放经济下的宏观经济

![蒙代尔-弗莱明模型与不可能三角](/macro/macro-mundell.svg)

### 10.1 国际收支平衡表

| 账户 | 内容 |
| --- | --- |
| **经常账户** | 货物贸易、服务贸易、初次收入（投资收益与雇员报酬）、二次收入（侨汇、援助等经常转移） |
| **资本与金融账户** | 资本账户（资本转移、非生产非金融资产）、金融账户（直接投资、证券投资、金融衍生工具、其他投资）、**储备资产** |
| 净误差与遗漏 | 统计残差项 |

**记账原则**：有借必有贷、借贷必相等；借方记支出 / 资金流出，贷方记收入 / 资金流入。失衡的调节有自动机制（价格—现金流、汇率、收入）与政策调节（**支出增减政策**＝财政货币，**支出转换政策**＝汇率）。

### 10.2 汇率基础

| 概念 | 说明 |
| --- | --- |
| 名义汇率 e | 两国货币兑换比率；**直接标价法**：1 单位外币 = 若干本币（我国采用），e 上升＝本币贬值 |
| 间接标价法 | 1 单位本币 = 若干外币 |
| **实际汇率** | **ε = e·P\*/P**（P\* 国外价格、P 国内价格），衡量两国商品相对价格；ε 上升＝本币实际贬值 |
| 有效汇率 | 对一篮子贸易伙伴货币的加权平均汇率 |

**汇率决定理论**：

| 理论 | 结论 |
| --- | --- |
| 购买力平价 PPP | 一价定律 → **e = P/P\***（直接标价法）；受非贸易品、贸易壁垒、产品差异影响，短期常不成立 |
| 利率平价 IRP | 两国利差 = 远期汇率升贴水率，资本流动使套利消失 |
| **马歇尔—勒纳条件** | 本币贬值改善贸易收支要求 **\|η_X + η_M\| > 1**（进出口需求价格弹性绝对值之和大于 1） |
| **J 曲线效应** | 贬值后贸易收支**先恶化、后改善**（合同与数量调整存在时滞） |
| 资产市场法 | 汇率由金融资产存量供求决定 |

**汇率制度**：固定汇率（金本位、布雷顿森林钉住制）、浮动汇率、管理浮动、货币局制度。人民币演进：单一钉住美元 → 参考一篮子货币调节 → **有管理的浮动汇率制**。

### 10.3 蒙代尔—弗莱明模型（IS-LM-BP，★）

在 IS-LM 中加入 **BP 曲线**（国际收支平衡的所有 Y 与 r 组合）。**BP 斜率取决于资本流动程度**：

| 资本流动 | BP 形态 |
| --- | --- |
| 完全不流动 | **垂直**（只有收入变动才能调节贸易收支） |
| 不完全流动 | 向右上方倾斜 |
| **完全流动** | **水平线**，r = r\*（国内利率必须等于世界利率） |

**资本完全流动下的政策效果（核心结论表）**：

| 汇率制度 | 财政政策 | 货币政策 | 机制 |
| --- | --- | --- | --- |
| **固定汇率** | **有效** | **无效** | 货币扩张 → r 下行压力 → 资本外流 → 外汇储备减少 → M 回到原点；财政扩张 → r 上行 → 资本流入 → 央行购汇投放货币 → Y 进一步增加 |
| **浮动汇率** | **无效** | **有效** | 财政扩张 → r 上行 → 资本流入 → 本币升值 → NX 减少完全抵消；货币扩张 → r 下行 → 资本流出 → 本币贬值 → NX 增加 → Y 大幅上升 |

> 记忆口诀：**固定汇率看财政、浮动汇率看货币**（资本完全流动时）。

### 10.4 不可能三角（三元悖论）

**货币政策独立性、资本自由流动、汇率稳定**三者只能同时实现**两个**：

| 取舍 | 代表 |
| --- | --- |
| 放弃汇率稳定 | 浮动汇率 + 资本自由流动 + 独立货币政策 |
| 放弃资本自由流动 | 固定/管理浮动 + 资本管制 + 独立货币政策（我国取向） |
| 放弃货币政策独立性 | 固定汇率 + 资本自由流动（如货币局制度） |

### 10.5 国际协调与中国实践

溢出效应与「以邻为壑」政策（竞争性贬值、加征关税）最终各方受损，需 G20、IMF、WTO 等机制协调。中国：从改革开放、2001 年入世到双循环新发展格局；人民币国际化（跨境结算、2016 年加入 SDR、离岸市场、数字人民币）。

### 10.6 易错点

- 直接标价法下 **e 上升 = 本币贬值**；实际汇率 ε 上升 = 本币实际贬值。
- 马歇尔—勒纳条件是**弹性之和大于 1**，不是「弹性大于 0」；即使满足，短期还有 J 曲线恶化。
- 资本完全流动 + 固定汇率下**货币政策无效**，这是三元悖论的直接推论。
- 购买力平价是**长期**理论，不能用来解释短期汇率波动。

## 第11章 期末速记与资料勘误

### 11.1 核心公式速查

| 主题 | 公式 |
| --- | --- |
| 支出法 GDP | Y = C + I + G + NX |
| 三 / 四部门恒等式 | I + G = S + T；I + G + X = S + T + M |
| GDP 平减指数 | 名义 GDP ÷ 实际 GDP × 100 |
| 消费 / 储蓄函数 | C = a + bY；S = −a + (1−b)Y；MPC + MPS = 1 |
| 两部门均衡收入 | Y = (a + I₀) / (1 − b) |
| 各类乘数 | k_G = k_I = 1/(1−b)；k_T = −b/(1−b)；k_TR = b/(1−b)；**平衡预算乘数 = 1** |
| IS 方程 | r = (a + I₀)/d − [(1−b)/d]·Y |
| LM 方程 | r = (k/h)·Y − (1/h)·(M/P) |
| 货币供给 | M = 基础货币 B × 货币乘数 m |
| 增长核算 | ΔY/Y = ΔA/A + α·ΔK/K + β·ΔL/L |
| 索洛资本积累 | Δk = s·f(k) − (n + δ)k；稳态 s·f(k\*) = (n + δ)k\* |
| 黄金律 | MPK = n + δ（含技术进步 n + g + δ） |
| 附加预期 PC | π = πᵉ − ε(u − u\*) |
| 奥肯定律 | 失业率高于自然率 1 个百分点 → 实际 GDP 低于潜在 GDP 约 2~3 个百分点 |
| 泰勒规则 | i = r\* + π + 0.5(π − π\*) + 0.5·(y − y\*)/y\* |
| 实际汇率 | ε = e·P\*/P（直接标价法） |
| 马歇尔—勒纳条件 | \|η_X + η_M\| > 1 |

### 11.2 曲线速记

| 曲线 | 形状 | 移动因素 |
| --- | --- | --- |
| IS | 右下倾 | G↑ / T↓ / I₀↑ / a↑ → 右移 |
| LM | 右上倾 | M↑ / P↓ → 右移；h→∞ 水平（陷阱），h→0 垂直（古典） |
| AD | 右下倾 | 凡使 IS 或 LM 右移者 → AD 右移 |
| 长期 AS | 垂直（Y_f） | 劳动、资本、技术 → 右移 |
| 短期 AS | 右上倾 | 不利供给冲击 → 左移 |

### 11.4 本次整理所做的勘误与补全

**修正的错误知识点**

1. **索洛模型稳态增长率自相矛盾**：原框架「引入技术进步」处同时写「稳态人均产出增长率 = 0」与「人均产出增长率 = g」。已统一为：无技术进步时人均增长 0、总产出增长 n；有技术进步时人均增长 **g**、总产出增长 **n + g**；单位有效劳动产出增长 0。
2. **黄金律表述错误**：原框架写「资本的**净**边际产出等于**经济增长率**」，已修正为「资本**边际产出 MPK = n + δ**（含技术进步 n + g + δ）」。
3. **三大心理规律的变量归属**：期末 PPT 把「货币供给」列为三大心理规律涉及的四个变量之一；实际三大规律对应的是边际消费倾向、资本边际效率、**货币需求**（流动性偏好），货币供给是央行外生变量，已在第 4 章澄清。
4. **泰勒规则符号**：原框架 `i = i* + π + …` 中的 `i*` 易被误读为名义利率目标，已明确为**均衡实际利率 r\***。
5. **习题册解析错位**：PDF 每页的页码被粘在题号前（如「4 26.」），直接抽题会导致题干与选项错配；本次生成习题时已剥离页码再配对答案。

**补全的缺失知识点**

- 五个国民收入总量指标（GDP → GNI → NDP → NI → PI → DPI）的完整换算链；
- 实际 GDP 与名义 GDP 的**换算公式及数值例题**；
- 乘数效应的**级数推导**与乘数发挥作用的四个前提、膨胀/紧缩性缺口；
- **货币乘数与基础货币**（原框架只在习题中出现，正文缺）；
- AD 曲线**从 IS-LM 推导**的完整链条；
- 奥肯定律的定量表述、贝弗里奇曲线、J 曲线效应；
- 增长核算方程与索洛剩余、AK 模型与内生增长的政策含义。

### 11.5 答题模板

- **「用 IS-LM 说明某政策效果」**：先写政策使哪条曲线向哪移 → 再写 Y、r 的变化 → 最后讨论**挤出效应 / 流动性陷阱**两个极端。
- **「用 AD-AS 说明冲击」**：判断是 AD 还是 AS 移动、方向如何 → 写出短期 Y 与 P 的变化 → 说明长期是否回到 Y_f → 若是滞胀，说明需求管理的两难。
- **「计算均衡收入」**：先写 Y = C + I + G + NX，代入消费函数与税收函数，把含 Y 的项合并到左边，再除系数；乘数就是分母的倒数。
