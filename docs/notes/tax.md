## 第1章 税法总论

![税法总论框架](/tax/tax-framework.svg)

### 1.1 税收与税法

| 项目 | 要点 |
| --- | --- |
| 税收概念 | 政府为满足社会公共需要，**凭借政治权力、强制无偿**取得财政收入的形式；本质是分配关系，目的是满足公共需要，依据是政治权力（区别于按生产要素分配） |
| 税法概念 | 国家立法机关制定的、调整国家与纳税人之间征纳税权利义务关系的法律规范总称 |
| 二者关系 | 税收是**经济学**概念（调整分配关系），税法是**法学**概念（调整权利义务关系）；税收是税法的具体内容，税法是税收的存在形式 |

**税收法律关系**：由**主体**（国家 / 纳税人，双方法律地位平等但权利义务不对等）、**客体**（征税对象）、**内容**（权利义务）构成；产生、变更、消灭由**税收法律事实**决定；对权利主体双方**平等保护**。

**税法与其他法律**：
- 与宪法：税法服从宪法，宪法是征税与纳税的直接法律依据。
- 与民法：民法平等、等价、有偿；税法命令、服从。规范基本相同时税法援引民法；涉及征纳关系以税法为准。
- 与刑法：调整范围不同，违反税法情节严重触及刑律者受刑事处罚；《刑法》已用「逃避缴纳税款」取代「偷税」。
- 与行政法：税法具行政法一般特性，国家始终居领导地位、体现单方意志，无需双方意思表示一致。

### 1.2 税法原则（★★）

| 基本原则 | 含义 |
| --- | --- |
| 税收法定（核心） | 税法主体的权利义务必须由法律规定，各类构成要素只能由法律明确；含**税收要件法定**（立法角度）与**税务合法性**（执法角度） |
| 税收公平 | 横向公平（负担能力相同→税负相同）、纵向公平（能力不同→税负不同）；源于法律平等性原则，**禁止歧视，也禁止无正当理由的特别优惠** |
| 税收效率 | ①经济效率：利于资源有效配置与经济体制有效运行；②行政效率：提高征管效率、节约征管成本 |
| 实质课税 | 按客观事实判断是否符合课税要件、按真实负担能力定税负，**不能只看外观和形式**（实质重于形式） |

| 适用原则 | 含义 |
| --- | --- |
| 法律优位 | 法律效力 > 行政立法效力；税收行政法规 > 行政规章；效力低者与高者冲突时无效 |
| 法律不溯及既往 | 新法实施后，之前的行为不适用新法，只沿用旧法 |
| 新法优于旧法 | 亦称后法优于先法，新旧法对同一事项规定不同时新法优先 |
| 特别法优于普通法 | 对同一事项，特别规定效力高于一般规定；**打破效力等级限制**，级别低的特别法可优于级别高的普通法 |
| 实体从旧、程序从新 | 实体法不具溯及力；程序法在特定条件下具一定溯及力 |
| 程序优于实体 | 税收争讼发生时，程序法优于实体法，以保证国家课税权实现 |

### 1.3 税法（种）要素（11 项）

总则、**纳税义务人**、**征税对象**、税目、**税率**、纳税环节、纳税期限、纳税地点、减税免税、罚则、附则。

| 要素 | 要点 |
| --- | --- |
| 纳税义务人 | 又称纳税主体，直接负有纳税义务的单位和个人，解决「对谁征税」；含自然人与法人。区分**负税人**（最终承担）、**代扣代缴 / 代收代缴义务人** |
| 征税对象 | 又称纳税客体，解决「对什么征税」，是**区别一种税与另一种税的主要标志**；分流转额、所得额、财产、资源、特定行为五类，对应五大税类 |
| 税目 | 征税对象的具体化，反映征税广度 |
| 税率 | 计算税额的尺度，反映征税深度，是**税收制度的核心要素**；三种形式：比例税率、累进税率（全额/超额/超率）、定额税率 |
| 纳税环节 | 税法规定的征税对象在流转过程中应缴税的环节（生产、批发、零售、进口等） |
| 纳税期限 | ①纳税义务发生时间；②纳税期限（按期/按次）；③缴库期限 |
| 减税免税 | 分税基式、税率式、税额式；含起征点、免征额 |

::: danger 易错 · 起征点 vs 免征额
**起征点**：未达到不征，**达到后按全部数额征税**；**免征额**：无论多少都只就**超过部分**征税。二者不可混。
:::

### 1.4 税收立法与我国税法体系

**立法机关与效力层级**：全国人大及其常委会→**法律**（如《企业所得税法》《个人所得税法》《税收征收管理法》《增值税法》）；国务院→**行政法规**（实施条例）；财政部/税务总局/海关总署→**部门规章**；地方人大及政府→地方性法规/规章。


| 税法分类 | 类别 |
| --- | --- |
| 按基本内容和效力 | 税收基本法（我国暂无）、税收实体法、税收程序法 |
| 按主权行使范围 | 国内税法、国际税法、外国税法 |
| 实体法体系（按征税对象） | 流转税类（增值税、消费税、关税）、所得税类（企业所得税、个人所得税）、财产税类（房产税、契税、车船税）、资源税类（资源税、城镇土地使用税、耕地占用税）、特定行为税类（印花税、车辆购置税、烟叶税、环保税、船舶吨税、土地增值税） |
| 程序法体系 | 《税收征收管理法》及其实施细则、《海关法》《进出口关税条例》等 |

### 1.5 税收执法

| 事项 | 要点 |
| --- | --- |
| 税务机构 | 国家税务总局及省以下税务机构（原国地税已合并），按行政区划设置 |
| 征管范围 | 税务机关负责大部分税种；**关税、船舶吨税及进口环节增值税、消费税由海关代征** |
| 税收收入划分 | 中央固定收入（消费税、关税、进口环节增值税等）、地方固定收入（房产税、契税、土地增值税、城镇土地使用税、耕地占用税、车船税、烟叶税、环保税等）、中央地方共享收入（国内增值税、企业所得税、个人所得税、资源税、城建税、印花税等，按比重分成） |
| 税务检查权 | 查账、场地检查、责成提供资料、询问、查证、存款核查等；**税务稽查权**专司偷逃骗抗税案件查处 |
| 税务行政复议裁决权 | 上级税务机关对下级具体行政行为的复议 |

## 第2章 增值税法

![增值税计税逻辑](/tax/tax-vat.svg)

### 2.1 增值税类型与特点

| 类型 | 外购固定资产进项税额 | 我国执行期 |
| --- | --- | --- |
| 生产型 | 不允许抵扣 | 1994-01-01 ~ 2008-12-31 |
| 收入型 | 按折旧额分期抵扣 | 未采用 |
| **消费型** | **一次性全额抵扣** | **2009-01-01 起** |

核心特征：**道道征税、税不重征**（凭票抵扣链条）、价外税、税负转嫁。

### 2.2 征税范围与纳税义务人

**应税交易**：在**境内**①有偿转让货物、不动产所有权；②有偿提供服务；③有偿转让无形资产。货物含电力、热力、气体；服务含交通运输、邮政、电信、建筑、金融、生产生活服务等。

**境内判定**：货物的起运地或所在地在境内；服务/无形资产在境内消费或销售方/购买方在境内；不动产在境内。**境外单位或个人向境内销售完全在境外发生的服务/使用完全在境外的无形资产、出租完全在境外使用的有形动产，不属于境内**。

**视同应税交易**（无对价也要缴税，3 类）：
1. 单位和个体工商户将**自产或委托加工**的货物用于集体福利或个人消费；
2. 单位和个体工商户**无偿转让货物**；
3. 单位和个人**无偿转让无形资产、不动产或金融商品**。

::: danger 易错 · 视同销售的货物范围
「外购」货物用于集体福利/个人消费 → **不视同销售**，但对应进项税额**不得抵扣**（已抵扣的应转出）；「自产/委托加工」货物才视同销售。个人无偿转让货物不视同（仅限单位、个体工商户）。
:::

**非应税交易**（不征增值税，主要 4 类）：员工为受雇单位提供取得工资的服务；收取行政事业性收费、政府性基金；依照法律规定被征收征用取得补偿；取得存款利息收入；以及**纳税人取得的与销售货物/服务/无形资产/不动产收入或数量不直接挂钩的财政补贴**。

**征税范围特殊规定**：
- 与销售数量/收入**直接挂钩**的财政补贴 → 按规定计算缴纳增值税。
- **单用途商业预付卡**：售卡时不缴增值税（可开普通发票不得开专票），持卡消费时由实际销售方缴税；售卡方因发行、销售卡取得的手续费/结算费/服务费按现行规定缴税。
- **支付机构预付卡（多用途卡）**：售卡/充值取得的资金不缴增值税；支付机构收取的手续费等服务费缴税；特约商户收到结算款时缴税。
- 出租车公司向司机收取的管理费、经营租赁将广告位出租、将不动产或飞机车辆等动产广告位出租用于发布广告 → 按「不动产经营租赁 / 有形动产经营租赁」缴税。

**纳税人与扣缴义务人**：

| 项目 | 规定 |
| --- | --- |
| 基本规定 | 在境内发生应税交易、销售货物/服务/无形资产/不动产的单位和个人；**单位以承包、承租、挂靠方式经营的，以承包人/承租人/挂靠人为纳税人**（视谁承担法律责任和以谁名义经营） |
| 小规模纳税人 | 年应征增值税销售额 **≤ 500 万元**；会计核算不健全或不能提供准确税务资料；**偶然发生的销售无形资产、转让不动产的销售额不计入**年应征销售额 |
| 一般纳税人 | 年应税销售额 > 500 万元应办理登记；**未超过 500 万但会计核算健全、能提供准确税务资料的，可自愿登记为一般纳税人**。一经登记，除国家另有规定外不得转为小规模 |
| 年应征销售额口径 | 纳税申报销售额 + 稽查查补销售额 + 纳税评估调整销售额；**含免税销售额、税务机关代开发票销售额**，含纳税申报差额前的销售额 |
| 扣缴义务人 | ①境外单位/个人在境内发生应税交易且未设经营机构 → **以购买方为扣缴义务人**；②境外单位/个人向自然人出租境内不动产，有境内代理人的由代理人扣缴；③自然人发生符合规定的应税交易，支付价款的境内单位为扣缴义务人 |

::: tip 易错 · 未登记的一般纳税人
年应税销售额超过 500 万却未办理一般纳税人登记的，主管税务机关会责令限期办理；逾期仍不办理的，**按销售额依增值税税率计算应纳税额、不得抵扣进项税额、不得使用专用发票**，直至办理登记为止。
:::

### 2.3 税率与征收率

| 档次 | 适用范围 |
| --- | --- |
| **13%** | 销售或进口一般货物、加工修理修配劳务、有形动产租赁服务 |
| **9%** | ①农产品、食用植物油、食用盐；②自来水、暖气、冷气、热水、煤气、石油液化气、天然气、二甲醚、沼气、居民用煤炭制品；③图书、报纸、杂志、音像制品、电子出版物；④饲料、化肥、农药、农机、农膜；⑤交通运输、邮政、基础电信、建筑、不动产租赁与销售、转让土地使用权 |
| **6%** | 增值电信、金融、生活服务、其他无形资产（不含土地使用权）、专业技术服务 |
| **0%** | 出口货物、跨境应税行为（**零税率 ≠ 免税**：零税率是整体税负为零，出口免税且退还以前环节已纳税款） |

**征收率**：一般 **3%**；特定情形 **5%、2%、1.5%、1%、0.5%**（如不动产销售/出租 5%、销售自己使用过的不得抵扣且未抵扣进项的固定资产按 3% 减按 2%、个人出租住房 1.5%、小规模纳税人阶段性减按 1%、二手车经销 0.5% 等）。

**兼营与混合**：

| 情形 | 判定 | 处理 |
| --- | --- | --- |
| **兼营** | 两项以上**相互独立**的应税交易涉及不同税率/征收率 | 分别核算分别适用；**未分别核算 → 从高适用税率** |
| **混合（一项应税交易涉及两个以上税率）** | 同一项交易内含不同税率业务，且业务间有**明显主附关系** | 按**主要业务**适用税率/征收率。可以是「货物+货物」「服务+服务」「无形资产+货物」等组合 |

::: danger 易错 · 混合交易不再按「货物+服务」老标准
新法下混合交易的判定关键是「**一项应税交易 + 明显主附关系**」，不再局限于传统的「一项销售行为既涉及货物又涉及服务」，也不再按纳税人主营业务身份划线。
:::

**废弃物专业化处理**：处理后产生货物且归属委托方→受托方按 **13%**（加工）；归属受托方→处理费按 **6%**（专业技术服务）、货物销售按货物税率；未产生货物→处理费按 **6%**。

### 2.4 一般计税方法

> **核心公式**：`当期应纳税额 = 当期销项税额 − 当期进项税额`（负值结转下期抵扣，符合条件的可申请留抵退税）

#### 2.4.1 销项税额与销售额

**销售额**：取得与之相关的**全部价款和价外费用**（含违约金、延期付款利息、包装费等），但**不包括**销项税额本身，以及代为收取的政府性基金/行政事业性收费、代收代缴的消费税、代垫运费等符合规定的项目。

| 规则 | 内容 |
| --- | --- |
| 含税换算 | 不含税销售额 = 含税销售额 ÷ (1 + 税率) |
| 视同应税交易 | 按市场价格确定销售额；无市场价格按组成计税价格 |
| 外币 | 折合成人民币，可按业务发生当天或当月 1 日汇率中间价，一经确定 12 个月内不得变更 |
| 折扣销售（商业折扣） | 原价与折扣额在**同一张发票上分别注明**，可按折扣后余额计税；折扣额另开发票（不论财务如何处理）**不得减除** |
| 销售折扣（现金折扣） | 属融资性质，**不得从销售额中减除** |
| 销售折让 | 可凭**红字专用发票**按折让/退货金额冲减原销售额与销项税额 |
| 以旧换新 | 一般按**新货物同期销售价格**确定销售额，不得扣减旧货收购价；**金银首饰以旧换新例外**，按实际收取的不含税全部价款计税 |
| 还本销售 | **不得**从销售额中减除还本支出 |
| 以物易物 | 双方均作**购、销两笔**业务处理，各自计算销项并可按规定抵扣进项（需取得合法扣税凭证） |
| 直销 | 向直销员收取的全部价款和价外费用 / 向消费者收取的全部价款和价外费用为销售额 |
| 贷款服务 | 全部利息及利息性质收入为销售额 |
| 直接收费金融服务 | 手续费、佣金、管理费、咨询费等各类费用为销售额 |
| 包装物押金 | 一般货物：单独核算且 1 年内未逾期→不并入；**逾期（以 1 年为限）**未退还的押金并入，按 `逾期押金÷(1+税率)×税率`；**除啤酒、黄酒外的其他酒类产品**押金无论是否返还、会计如何核算，收取时即并入销售额 |
| 核定销售额 | 价格明显偏低/偏高且无正当理由、视同应税交易无销售额 → 按①同类平均售价 → ②其他纳税人同类平均售价 → ③组成计税价格（成本×(1+成本利润率)，成本利润率一般 10%） |

**按差额确定销售额**（主要项目）：

| 项目 | 差额口径 |
| --- | --- |
| 金融商品转让 | 卖出价 − 买入价（**不得开专票**）；正负差相抵，年末仍为负差**不得转入下一年度** |
| 客运场站服务 | 全部价款 − 支付给承运方的运费 |
| 航空运输销售代理 | 全部价款 − 代售其他航司机票款 / 境外航段机票净结算款及相关费用 |
| 签证代理服务 | 全部价款 − 代收代付的签证费、认证费 |
| 境外考试代理（教育考试院及其直属单位） | 全部价款 − 支付给境外单位的考试费 |
| 劳务派遣服务（选择差额） | 全部价款 − 代用工单位支付给员工的工资、福利、社保、住房公积金 |
| 转让土地使用权（简易计税） | 全部价款 − 取得该土地使用权原价 |
| 不动产销售（简易/预缴） | 按规定扣除不动产购置原价或作价 |


#### 2.4.2 进项税额

**准予抵扣**（凭合法扣税凭证）：增值税**专用发票**、海关进口增值税**专用缴款书**、农产品收购发票/销售发票、**代扣代缴完税凭证**、机动车销售统一发票、通行费电子发票等。

| 抵扣特例 | 计算 |
| --- | --- |
| 农产品（一般） | 按票面注明买价 × **9%** 扣除率；用于生产 13% 税率货物的，于生产领用当期**加计 1%**（合计 10%） |
| 从小规模纳税人取得专票（3%） | 按注明金额 × **9%** 扣除率 |
| 烟叶 | 收购烟叶实际支付的价款总额 + 烟叶税，再 × **9%**；其中价款总额 = 收购价款 × (1 + 实际价外补贴率) |
| 国内旅客运输 | 凭注明旅客身份信息的票据计算抵扣：**航空**（票价+燃油附加费）÷(1+9%)×9%；**铁路**票面金额÷(1+9%)×9%；**公路水路**票面金额÷(1+3%)×3% |
| 不动产/在建工程 | 2019-04-01 起**一次性全额抵扣**（不再分两年） |

**不得抵扣**（7 类）：
1. 用于**简易计税方法计税项目**；
2. 用于**免征增值税项目**；
3. 用于**集体福利或个人消费**；
4. **非正常损失**的购进货物及相关加工修理修配服务、交通运输服务；
5. 非正常损失的在产品、产成品所耗用的购进货物（不含固定资产）、加工修理修配服务、交通运输服务；
6. **购进的贷款服务、餐饮服务、居民日常服务和娱乐服务**（提示：国际旅客运费因国际运输免税/零税率也不得抵扣）；
7. 国务院规定的其他项目。

::: danger 易错 · 兼用进项与不得抵扣的计算
一般纳税人**同时**用于应税与简易计税/免税/集体福利等「三类不允许抵扣项目」且**无法划分**的进项税额，按公式分摊转出：

`不得抵扣的进项税额 = 当期无法划分的全部进项税额 × (当期简易计税项目销售额 + 免税项目销售额) ÷ 当期全部销售额`

**固定资产、无形资产、不动产**兼用的进项税额**可以全额抵扣**（只有「专用于」三类项目才不得抵扣）。
:::

**进项转出与转回**：已抵扣进项税额的购进货物/服务事后改变用途用于不得抵扣项目，按当期实际成本 × 适用税率转出；已作转出的项目又用于可抵扣项目，可按规定转回。

### 2.5 简易计税、进口与出口

| 情形 | 计算 |
| --- | --- |
| 简易计税（小规模 / 一般纳税人的特定项目） | 应纳税额 = 销售额（不含税）× **征收率**；**不得抵扣进项**，不得开具专用发票（可按规定代开） |
| 进口货物（一般计税） | **组成计税价格 = 关税完税价格 + 关税 + 消费税**（从价消费税时 = (完税价格+关税)÷(1−消费税税率)）；应纳税额 = 组成计税价格 × 税率（13% 或 9%） |
| 进口环节征收 | 由**海关代征**，纳税义务发生时间为**报关进口当天**，纳税地点为报关地海关，应自海关填发缴款书之日起 **15 日内**缴款 |

**出口退（免）税基本政策**：

| 政策 | 适用 | 含义 |
| --- | --- | --- |
| **免、抵、退** | 生产企业自营/委托出口自产货物、跨境应税行为 | 出口环节免税，相应进项**抵顶内销应纳税额**，未抵完部分退还 |
| **免、退** | 外贸企业出口货物 | 出口免税，按购进金额 × 退税率退还进项 |
| **免、抵、不退（只免）** | 部分跨境应税行为 | 免税但不退税 |
| **征税（不免不退）** | 国家明确取消出口退（免）税的货物 | 视同内销照章征税 |

**留抵退税**：符合纳税信用等级、36 个月无骗税/虚开、2019-04-01 起增量留抵等条件的，可申请退还**增量留抵税额**（部分行业可退存量留抵），按进项构成比例计算。

### 2.6 税收优惠与征收管理

**法定免税项目**（主要）：农业生产者销售的**自产农产品**；避孕药品和用具；古旧图书；直接用于科学研究/科学试验/教学的进口仪器、设备；外国政府/国际组织无偿援助的进口物资和设备；由残疾人的组织直接进口供残疾人专用的物品；**其他个人销售自己使用过的物品**；**销售额未达到起征点的**小规模纳税人等。

::: danger 易错 · 放弃免税
纳税人可放弃免税，按规定缴纳增值税；**一经放弃，36 个月内不得再申请免税**（小规模纳税人另有规定的除外）。免税项目对应的进项税额不得抵扣。
:::

**纳税义务发生时间**：

| 结算方式 | 时间 |
| --- | --- |
| 直接收款 | 收到销售款项或取得索取销售款项凭据的**当天**（不论货物是否发出） |
| 托收承付、委托银行收款 | 发出货物**并**办妥托收手续的当天 |
| 赊销、分期收款 | 书面合同约定的**收款日当天**；无书面合同或未约定的，为**货物发出当天** |
| 预收货款 | **货物发出当天**（生产工期超过 12 个月的大型机械设备等，为收到预收款或合同约定收款日当天） |
| 委托代销 | 收到代销清单或收到全部/部分货款的当天；未收到代销清单及货款的，为**发出代销货物满 180 天**的当天 |
| 视同应税交易 | 货物移送、服务/无形资产/不动产转让完成的当天 |
| 进口 | **报关进口当天** |
| 扣缴义务 | 纳税义务发生当天 |

**纳税地点**：固定业户→**机构所在地**（总分机构不在同一县市的分别申报，经批准可由总机构汇总）；跨县市提供建筑服务/销售出租不动产→**建筑服务发生地/不动产所在地预缴**，再向机构所在地申报；其他个人→应税行为发生地；进口→报关地海关。

**纳税期限**：分别为 **1 日、3 日、5 日、10 日、15 日、1 个月或 1 个季度**。以 1 个月/1 季度为期的，自期满之日起 **15 日内**申报纳税；以 1/3/5/10/15 日为期的，自期满之日起 **5 日内预缴**，次月 1 日起 15 日内申报并结清上月税款。**按季申报**仅适用于小规模纳税人、银行/财务公司/信托投资公司/信用社及财政部税务总局规定的纳税人。

## 第3章 消费税法

### 3.1 特点、纳税人与纳税环节

**特点**：①征税范围**选择性**（15 个税目）；②征税环节**单一性**（多在生产经营起始环节一次征收，税不重征）；③平均税率水平较高且税负差异大（**1%～56%**）；④计税方法灵活（从价、从量、复合）；⑤**价内税**，与增值税交叉征收（同一计税依据通常同时计算增值税与消费税）。

**纳税人**：境内**生产、委托加工、进口**应税消费品的单位和个人，以及国务院确定的**销售**应税消费品的其他单位和个人。

| 纳税环节 | 具体规定 |
| --- | --- |
| 生产销售 | 自产销售时纳税；**自产自用**：用于**连续生产应税消费品 → 不纳税**，用于其他方面（职工福利、奖励、管理部门、非应税项目、捐赠、广告样品等）→ **移送使用时纳税** |
| 进口 | 报关进口时纳税，**海关代征** |
| 委托加工 | 除受托方为**个人**外，由**受托方在交货时代收代缴**（个人受托时由委托方收回后自行缴纳） |
| 零售 | ①**金银首饰、钻石及钻石饰品、铂金首饰**（仅零售环节征收）；②**超豪华小汽车**（不含增值税零售价 **90 万元及以上**，2025 年 7 月起由 130 万下调）在生产/进口环节征税后，**零售环节加征 10%** |
| 卷烟批发 | 批发商销售给**批发商以外的单位和个人**时纳税，税率 **11% + 0.005 元/支**；**批发商之间销售不缴** |
| 电子烟批发 | 取得烟草专卖批发企业许可证并经营电子烟批发业务的企业，批发环节按 **11%** 纳税 |

**视为生产行为**：工业企业以外的单位/个人，将外购的**非应税产品以应税产品**对外销售，或将外购的**低税率应税产品以高税率应税产品**对外销售，视同生产征收消费税。

::: danger 易错 · 从高适用税率的两种情形
①兼营不同税率应税消费品**未分别核算**销售额/销售数量；②将应税消费品与非应税消费品、或不同税率的应税消费品**组成成套消费品**销售 → 一律**从高**适用税率。
:::

### 3.2 税目与税率（15 个税目）

| 税目 | 子目 / 税率要点 |
| --- | --- |
| 一、烟 | 卷烟（**甲类**：调拨价≥70 元/标准条，**56% + 0.003 元/支**；**乙类**：**36% + 0.003 元/支**）；雪茄烟 **36%**；烟丝 **30%**；电子烟 **36%**（生产/进口）、批发 **11%** |
| 二、酒 | **白酒**：复合计税 **20% + 0.5 元/500 克（或 500 毫升）**；**黄酒 240 元/吨**；**啤酒**：甲类 **250 元/吨**、乙类 **220 元/吨**（按出厂价 3000 元/吨划档）；其他酒 **10%**（葡萄酒按「其他酒」10%） |
| 三、高档化妆品 | **15%**；指生产/进口环节不含增值税价 ≥ **10 元/毫升（克）** 或 ≥ **15 元/片** 的高档美容修饰类、护肤类化妆品和成套化妆品；**不含**舞台/戏剧/影视演员化妆用的上妆油、卸妆油、油彩 |
| 四、贵重首饰及珠宝玉石 | 金银首饰、铂金首饰、钻石及钻石饰品 **零售 5%**；其他珠宝玉石及翡翠、珍珠、宝石 **生产/进口 10%** |
| 五、鞭炮焰火 | **15%**；体育用发令纸、鞭炮引线**不属于**应税消费品 |
| 六、成品油 | 汽油、石脑油、溶剂油、润滑油 **1.52 元/升**；柴油、航空煤油（**暂缓征收**）、燃料油 **1.2 元/升**。提示：变压器油、导热类油等绝缘油**不属于润滑油**不征；纯生物柴油免征；废矿物油为原料生产的润滑油基础油、工业油料免征；混合芳烃等按石脑油征收；烷基化油（异辛烷）按汽油征收；石油醚/粗白油/轻质白油/部分工业白油按溶剂油征收 |
| 七、摩托车 | 气缸容量 **250 毫升 → 3%**；**超过 250 毫升 → 10%** |
| 八、小汽车 | 乘用车 **1%～40%**（按气缸容量分档）、中轻型商用客车 **5%**；含 9 座内乘用车、10~23 座中轻型商用客车；**电动汽车、沙滩车、雪地车、卡丁车、高尔夫车不征**；超豪华小汽车（零售价 ≥ 90 万元）零售环节加征 **10%** |
| 九、高尔夫球及球具 | **10%**；含球包、球杆、球袋及杆头、杆身、握把 |
| 十、高档手表 | **20%**（不含增值税价 ≥ 10000 元/只） |
| 十一、游艇 | **10%**（艇身长度 8~90 米） |
| 十二、木制一次性筷子 | **5%** |
| 十三、实木地板 | **5%** |
| 十四、电池 | **4%**（无汞原电池、锂原电池、镍氢/锂蓄电池、燃料电池、太阳能电池免征；铅蓄电池按 4%） |
| 十五、涂料 | **4%**（施工状态下挥发性有机物含量低于 420 克/升的免征） |

::: tip 提示 · 酒类易错点
**调味料酒、酒精不征消费税**；**果啤属于啤酒税目**（按甲类 250 / 乙类 220 元/吨）；**白酒**采用复合计税且组价时**必须把从量税计入组成计税价格**；白酒生产企业销售给销售单位的白酒，计税价格不得低于对外售价的 **60%**（2017-05-01 起由 70% 调为 60%），否则税务机关核定最低计税价格。
:::

### 3.3 计税依据与应纳税额

| 计征方式 | 公式 | 适用 |
| --- | --- | --- |
| 从量定额 | 应纳税额 = 销售数量 × 定额税率 | 啤酒、黄酒、成品油 |
| 从价定率 | 应纳税额 = 销售额 × 比例税率 | 多数税目 |
| **复合计征** | 应纳税额 = 销售数量 × 定额税率 + 销售额 × 比例税率 | **白酒、卷烟**（含批发环节） |

**销售额**：全部价款和价外费用，**不含增值税**，`不含税销售额 = 含增值税销售额 ÷ (1 + 13% 或 3%)`。含**包装物及押金**：一般货物押金 1 年内未逾期不并入、逾期并入；**除啤酒黄酒外其他酒类**押金收取时即并入。

**自产自用 / 委托加工 / 进口的组价**：

| 情形 | 组成计税价格 | 说明 |
| --- | --- | --- |
| 自产自用（从价） | `(成本 + 利润) ÷ (1 − 比例税率)` = `成本×(1+成本利润率)÷(1−比例税率)` | 成本利润率由税务总局规定（如白酒 10%、小汽车 8% 等，例题多用给定值） |
| 自产自用（复合） | `(成本 + 利润 + 自产自用数量 × 定额税率) ÷ (1 − 比例税率)` | **组价含从量税** |
| 委托加工（从价） | `(材料成本 + 加工费) ÷ (1 − 比例税率)` | 代收代缴消费税；**受托方为个人时不代收代缴** |
| 委托加工（复合） | `(材料成本 + 加工费 + 委托加工数量 × 定额税率) ÷ (1 − 比例税率)` | |
| 进口（从价） | `(关税完税价格 + 关税) ÷ (1 − 消费税比例税率)` | 海关代征 |
| 进口（复合） | `(关税完税价格 + 关税 + 进口数量 × 定额税率) ÷ (1 − 比例税率)` | |

对应**增值税**组价与消费税组价相同（同为含消费税不含增值税价），例如进口环节：**进口增值税 = (完税价格 + 关税) ÷ (1 − 消费税税率) × 增值税税率**。

**计税依据特殊规定**：
- 纳税人用于**换取生产资料/消费资料、投资入股、抵偿债务**等，按**同类最高销售价格**计税（增值税仍按平均价，二者不同！）。
- 卷烟计税价格 = 批发环节销售价格 × (1 − 适用批发毛利率)，由国家税务总局核定。
- **金银首饰**零售：与其他产品组成成套销售的按**销售额全额**征收；连同包装物销售的包装物价款一律并入；带料加工按受托方同类售价，无同类按组价；**以旧换新（含翻新改制）按实际收取的不含税全部价款**计税。
- 既销售金银首饰又销售非金银首饰且**不能分别核算**：生产环节一律从高按 **10%**、零售环节一律按金银首饰 **5%**。

**已纳消费税扣除**（避免重复征税，按**当期生产领用数量**扣除）：

| 扣除范围（列举） | 说明 |
| --- | --- |
| 外购/委托加工收回的已税烟丝生产卷烟、已税高档化妆品为原料生产高档化妆品、已税珠宝玉石生产贵重首饰、已税鞭炮焰火生产鞭炮焰火、已税成品油生产成品油、已税白酒/酒精以外的酒生产酒、已税木制一次性筷子/实木地板/石脑油润滑油燃料油等为原料生产同类应税消费品 | **必须在同一税目内、用于连续生产应税消费品**；用于生产非应税消费品或直接出售不再扣除 |
| 计算 | 当期准予扣除 = 当期准予扣除的外购应税消费品**买价 × 适用税率**；或按当期生产领用数量换算。当期应纳税额不足抵扣的，余额**结转下期**抵扣 |

::: danger 易错 · 扣除的边界
**酒类**（除葡萄酒等特定政策外）与**小汽车、高档手表、游艇、电池、涂料**等**不在允许扣除范围内**；且只有「**连续生产应税消费品**」才能扣除，委托加工收回后**直接以高于受托方计税价格出售**的需按规定申报缴纳消费税（准予扣除受托方已代收代缴部分）。
:::

### 3.4 出口退税与征收管理

| 政策 | 适用 | 规则 |
| --- | --- | --- |
| **又免又退** | 有出口经营权的外贸企业**购进**应税消费品直接出口、受其他外贸企业委托代理出口 | 退税率 = 消费税税率；**从价**按出口货物的工厂销售额、**从量**按出口数量计算退税额；复合计征两者都退 |
| **只免不退** | 有出口经营权的**生产企业**自营出口 / 委托外贸企业代理出口自产应税消费品 | 生产环节已免税，出口不再退税（无已纳税额） |
| **不免不退** | 一般商贸企业委托外贸企业代理出口应税消费品 | 照章征税 |

**退税额**：从价 `= 出口货物的工厂销售额（或数量×加权平均单价）× 税率`；从量 `= 出口数量 × 单位税额`。已办理退税后发生退关或国外退货的，须**补缴已退消费税税款**。

**征收管理**：纳税义务发生时间、纳税地点、纳税期限**基本与增值税一致**（本章不重复）。

## 第4章 企业所得税法

![企业所得税计算框架](/tax/tax-income-tax.svg)

### 4.1 纳税人、征税对象与税率

| 类型 | 判定 | 征税对象 | 税率 |
| --- | --- | --- | --- |
| **居民企业** | 依法在境内成立，或**依照外国法律成立但实际管理机构在境内** | 来源于**境内 + 境外**的全部所得 | **25%** |
| **非居民企业（有机构场所）** | 依外国法律成立且实际管理机构在境外，但在境内设立机构、场所 | 所设机构场所取得的境内所得 + 发生在境外但**与境内机构场所有实际联系**的所得 | **25%** |
| **非居民企业（无机构场所 / 所得无实际联系）** | — | 仅就**来源于境内**的所得 | 法定 **20%**，**减按 10%**（预提所得税） |

优惠税率：**20%**（小型微利企业，实际按 `应纳税所得额 × 25% × 20% = 5%` 税负）、**15%**（国家需要重点扶持的高新技术企业、技术先进型服务企业、西部大开发鼓励类产业等）。

**所得来源地判定**：销售货物→交易活动发生地；提供劳务→劳务发生地；转让财产：不动产→不动产所在地，动产→转让方企业所在地，权益性投资资产→被投资企业所在地；股息红利→分配所得企业所在地；利息/租金/特许权使用费→负担支付方所在地。

### 4.2 应纳税所得额

> **核心公式**：`应纳税所得额 = 收入总额 − 不征税收入 − 免税收入 − 各项扣除 − 允许弥补的以前年度亏损`

#### 4.2.1 收入总额（9 类）与确认时点

| 收入类型 | 确认要点 |
| --- | --- |
| 销售货物 | ①商品销售合同已签订、商品所有权相关主要风险和报酬转移；②企业未保留与所有权相联系的继续管理权或控制；③收入金额能可靠计量；④销售成本能可靠核算 |
| 提供劳务 | 按**完工进度（完工百分比）**确认；持续时间超过 12 个月的按纳税年度末完工进度 |
| 转让财产 | 转让或到期兑付时确认 |
| 股息、红利等权益性投资收益 | **被投资方股东会/股东大会作出利润分配或转股决定时**确认 |
| 利息、租金、特许权使用费 | 按**合同约定的应付日期**确认；租金若交易合同规定租赁期限跨年度且租金**提前一次性支付**，可在租赁期内**均匀摊入**各年 |
| 接受捐赠 | **实际收到**捐赠资产的日期 |
| 其他收入 | 包括企业资产溢余收入、逾期未退包装物押金、确实无法偿付的应付款项、已作坏账损失处理后又收回的应收款项、债务重组收入、补贴收入、违约金收入、汇兑收益等 |

**特殊收入与视同销售**：
- **商业折扣**按扣除折扣后金额确认收入；**现金折扣**按扣除前金额确认（折扣额作财务费用）；**销售折让/退回**冲减当期销售收入。
- **买一赠一**不属于捐赠：将总销售金额按各项商品**公允价值比例分摊**确认各项收入（赠品成本可扣除）。
- **视同销售**：将货物、财产、劳务用于**捐赠、偿债、赞助、集资、广告、样品、职工福利、利润分配**等，或发生非货币性资产交换 → 按**公允价值**视同销售（另有规定的除外）。
- **非货币性资产投资**：以评估公允价值扣除计税基础后的余额确认非货币性资产转让所得，可在**不超过 5 年**期限内**分期均匀**计入应纳税所得额。
- **企业转让上市公司限售股**：不能准确计算原值的，主管税务机关按限售股**转让收入的 15%** 核定原值及合理税费。
- **政府/股东划入资产**：作为资本性投入（增加实收资本/资本公积）的不计入收入总额；作为**不征税收入**处理的，其用于支出形成的费用/资产折旧摊销**不得扣除**。
- **撤回/减少投资**：相当于初始出资的部分确认为投资收回，相当于被投资企业累计未分配利润和累计盈余公积按减少实收资本比例计算的部分确认为**股息所得（免税）**，其余确认为**投资资产转让所得**。**股权转让**则不得扣除被投资企业未分配利润等股东留存收益中按股权可能分配的金额。

**不征税收入**：①**财政拨款**；②依法收取并纳入财政管理的**行政事业性收费、政府性基金**；③国务院规定的**其他不征税收入**（专项用途财政性资金，需符合专款专用、单独核算等条件）。
**免税收入**：①**国债利息收入**；②符合条件的**居民企业之间的股息、红利等权益性投资收益**；③在中国境内设立机构场所的非居民企业从居民企业取得与该机构场所有实际联系的股息红利（**不包括连续持有居民企业公开发行并上市流通的股票不足 12 个月取得的投资收益**）；④符合条件的**非营利组织**收入（不含营利活动收入）。

::: danger 易错 · 不征税收入 vs 免税收入
**不征税收入**用于支出形成的**费用、资产折旧摊销不得扣除**（对应支出也不得扣）；**免税收入**对应的成本费用**可以扣除**。二者性质完全不同。此外，专项用途财政性资金在 **5 年（60 个月）**内未发生支出且未缴回的部分，应计入第六年的应税收入总额。
:::

#### 4.2.2 税前扣除（重点）

**扣除原则**：权责发生制、真实性、相关性、合理性、合法性、配比性；企业实际发生的与取得收入**有关的、合理的**支出准予扣除。

**扣除范围**：成本、费用、税金（不含企业所得税和允许抵扣的增值税）、损失（减除责任人赔偿和保险赔款后的余额）、其他支出。

**限额扣除标准总表（★ 必背）**：

| 项目 | 限额 / 标准 | 超支处理 |
| --- | --- | --- |
| 合理的工资薪金 | **据实扣除**（含接受外部劳务派遣用工，直接支付给员工个人的按工资薪金/福利费分别扣） | — |
| 职工福利费 | 工资薪金总额 **14%** | 不得扣除 |
| 工会经费 | 工资薪金总额 **2%**（凭《工会经费收入专用收据》等合法凭证） | 不得扣除 |
| 职工教育经费 | 工资薪金总额 **8%** | **准予结转以后年度扣除** |
| 软件生产企业职工培训费 | 按**实际发生额 100%** 扣除；核电厂操纵员培养费可作为发电成本扣除 | — |
| 基本社会保险（五险一金） | 按规定标准**据实扣除** | — |
| 补充养老 / 补充医疗保险 | 分别在工资总额 **5%** 以内 | 不得扣除 |
| 财产保险、特种职工人身安全险 | 按规定据实扣除；**商业人寿保险一般不得扣除** | — |
| 利息：非金融→金融、金融同业拆借、经批准发行债券 | **据实扣除** | — |
| 利息：非金融→非金融企业/个人 | 不超过按**金融企业同期同类贷款利率**计算的部分据实扣除 | 超过部分不得扣除 |
| 关联方利息（债资比） | 金融企业 **5:1**，其他企业 **2:1** | 超过比例部分不得扣除；能证明符合独立交易原则，或实际税负不高于境内关联方的可例外 |
| 业务招待费 | 按发生额 **60%** 扣除，且**不超过**当年销售（营业）收入 **5‰**，两者**孰低** | 不得扣除（不得结转） |
| 广告费和业务宣传费 | 一般不超过当年销售（营业）收入 **15%**；**化妆品制造/医药制造/饮料制造（不含酒类）30%**；**烟草企业一律不得扣除** | **准予结转以后年度扣除**（关联企业可签分摊协议归集扣除） |
| 公益性捐赠 | 通过公益性社会组织或县级以上人民政府及其部门、用于《公益事业捐赠法》规定公益事业的捐赠，不超过**年度利润总额 12%** | **准予结转以后三年扣除**（全额扣除项目按规定执行，如目标脱贫地区捐赠） |
| 环境保护/生态恢复专项资金 | 按规定提取的准予扣除 | 改变用途的不得扣除 |
| 劳动保护费、统一制作工作服饰费 | 合理支出据实扣除 | — |
| 手续费及佣金 | **保险企业** `(当年全部保费收入 − 退保金) × 18%`；**其他企业** `签订服务协议或合同确认的收入金额 × 5%` | 保险企业超支可结转；其他企业不得扣除。为发行权益性证券支付给承销机构的手续费佣金**不得扣除**；不得直接冲减合同金额 |
| 维简费 | 计提的**不得扣除**；尚未使用的可先不作纳税调整、用于抵减实际发生的维简费；已用于资产投资的不得扣除相应折旧摊销 | — |
| 总机构分摊费用 | 仅适用非居民企业境内机构场所，能提供总机构出具的汇集范围/定额/分配依据等证明文件并合理分摊的准予扣除 | — |
| 会员费、合理会议费、差旅费、违约金、诉讼费用 | 据实扣除 | — |

**计算限额的「销售（营业）收入」基数** = 主营业务收入 + 其他业务收入 + **视同销售收入**；**不含**营业外收入、投资收益（从事股权投资业务的企业除外）、不征税收入。

**不得扣除项目**：①向投资者支付的**股息、红利等权益性投资收益款项**；②**企业所得税税款**；③**税收滞纳金**；④**罚金、罚款和被没收财物的损失**；⑤超标准的捐赠支出及非公益性捐赠；⑥**赞助支出**（非广告性质）；⑦**未经核定的准备金支出**；⑧与取得收入无关的**其他支出**（如企业之间支付的管理费、企业内营业机构之间支付的租金和特许权使用费、非银行企业内营业机构之间支付的利息）；⑨投资者或职工支付的**商业保险费**（国家规定可扣的特定险种除外）。

**亏损弥补**：一般结转 **5 年**（**高新技术企业或科技型中小企业**，具备资格年度之前 5 个年度发生的未弥补亏损可结转 **10 年**；受疫情影响较大的困难行业 2020 年亏损结转 **8 年**）；**境外营业机构的亏损不得抵减境内营业机构的盈利**；亏损弥补**按年顺序、先亏先补**；以前年度应扣未扣支出可**追补至发生年度扣除**，追补期限不超过 5 年。

#### 4.2.3 资产的税务处理

| 资产 | 计税基础 / 摊销 | 最低折旧年限 |
| --- | --- | --- |
| 固定资产 | 按历史成本；**房屋的改扩建**推倒重置的按重置价并入计税基础，提升功能/增加面积的改扩建支出并入并重新计提折旧 | 房屋建筑物 **20 年**；飞机、火车、轮船、机器等生产设备 **10 年**；与生产经营活动有关的器具、工具、家具 **5 年**；飞机火车轮船以外的运输工具 **4 年**；电子设备 **3 年** |
| 生产性生物资产 | 同固定资产（经济林、薪炭林、产畜、役畜等） | 林木类 **10 年**，畜类 **3 年** |
| 无形资产 | 按历史成本，**直线法**摊销，不低于 **10 年**；外购商誉的支出在企业**整体转让或清算**时才准予扣除；**自创商誉不得摊销** | ≥ 10 年 |
| 长期待摊费用 | 已足额提取折旧的固定资产改建支出→按预计尚可使用年限；租入固定资产改建支出→按合同约定剩余租赁期；固定资产大修理支出→按尚可使用年限；其他→**不低于 3 年** | ≥ 3 年（大修理按尚可使用年限） |
| 投资资产 | 成本法，转让/处置时扣除成本 | — |
| 存货 | 按成本，计价方法可在先进先出、加权平均、个别计价中选用，**一经选用不得随意变更** | — |

**不得计提折旧的固定资产**：房屋建筑物以外未投入使用的固定资产；以经营租赁方式租入的固定资产；以融资租赁方式租出的固定资产；已足额提取折旧仍继续使用的固定资产；与经营活动无关的固定资产；单独估价作为固定资产入账的土地等。
**大修理支出条件**：修理支出达到取得固定资产时计税基础的 **50% 以上**，且修理后使用年限延长 **2 年以上**。
**文物、艺术品资产**：用于收藏、展示、保值增值的，作为**投资资产**处理，持有期间不得计提折旧或摊销，处置时按转让所得计税。

#### 4.2.4 企业重组、优惠与应纳税额

**企业重组**分**一般性税务处理**（按公允价值确认资产转让所得/损失，计税基础按公允价值调整，亏损不得结转）与**特殊性税务处理**（满足 5 个条件：具有合理商业目的、不以减免税为主要目的；**收购企业购买的股权/资产不低于被收购企业全部股权/资产的 50%**；重组后连续 12 个月内不改变重组资产原来的实质性经营活动；**股权支付金额不低于交易支付总额的 85%**；原主要股东在重组后连续 12 个月内不得转让所取得的股权）——特殊性处理下，**股权支付部分暂不确认所得/损失**，Non-equity（非股权）支付部分仍应确认，可由当事方选择按规定递延纳税。

**主要税收优惠**：

| 优惠 | 内容 |
| --- | --- |
| 免征 / 减半征收 | 从事农、林、牧、渔业项目所得**免征或减征**；从事国家重点扶持的**公共基础设施项目**投资经营所得 **三免三减半**（自取得第一笔生产经营收入所属年度起）；符合条件的**环境保护、节能节水项目**三免三减半；**技术转让所得**不超过 **500 万元**的部分免征，超过部分减半征收 |
| 高新技术企业 | 减按 **15%** 税率；技术先进型服务企业减按 15% |
| 小型微利企业 | 年应纳税所得额**减按 25% 计入**应纳税所得额，按 **20%** 税率缴纳（**实际税负 5%**），需符合从业人数、资产总额等条件 |
| 研发费用加计扣除 | 一般企业：未形成无形资产的按实际发生额的 **100% 加计扣除**；形成无形资产的按成本 **200% 摊销**；**集成电路企业和工业母机企业** 2023—2027 年按 **120% 加计 / 220% 摊销**；**基础研究**出资可 100% 加计扣除；可在 **7 月、10 月预缴**或年度汇算时享受 |
| 残疾人员工资 | 按支付给残疾职工工资的 **100% 加计扣除** |
| 创业投资企业 | 采取股权投资方式投资于未上市中小高新技术企业/初创科技型企业满 **2 年**的，可按**投资额的 70%** 抵扣应纳税所得额；当年不足抵扣可结转 |
| 税额抵免 | 购置并实际使用规定的**环境保护、节能节水、安全生产专用设备**，按**投资额的 10%** 从当年应纳税额中抵免；不足抵免的可在以后 **5 个纳税年度**结转抵免；**数字化智能化改造**投入按原计税基础 50% 的部分可按 10% 抵免；境外投资者以分配利润直接投资符合条件的可按投资额 **10%** 抵免 |
| 减计收入 | 综合利用资源生产符合规定的产品，按**收入总额的 90%** 计入收入总额 |
| 民族自治地方 | 自治机关可决定对属于地方分享的企业所得税部分**减征或免征** |

> **核心公式**：`应纳税额 = 应纳税所得额 × 适用税率 − 减免税额 − 抵免税额`

**征收管理**：按**纳税年度**（公历 1/1—12/31）计算，**分月或分季预缴**（自月份/季度终了之日起 **15 日内**），年度终了之日起 **5 个月内**汇算清缴、结清应退应补税款；**按季预缴**为常规。年度中间终止经营活动的，自实际终止之日起 **60 日内**办理当期汇算清缴；企业清算的，应在办理注销登记前就清算所得申报纳税。居民企业以**登记注册地**为纳税地点（登记注册地在境外的以实际管理机构所在地）；非居民企业以**机构场所所在地**为主要纳税地点，多个机构场所的可选择主要机构场所汇总缴纳。

### 5.1 纳税人、九项所得与来源地

| 纳税人 | 判定 | 纳税义务 |
| --- | --- | --- |
| **居民个人** | 在境内**有住所**，或**无住所而一个纳税年度内在境内居住累计满 183 天** | 从**境内和境外**取得的所得缴纳个税 |
| **非居民个人** | 无住所又不居住，或无住所且一个纳税年度内境内居住累计**不满 183 天** | 仅就**来源于境内**的所得纳税 |

**无住所个人 6 年规则**：在境内居住累计满 183 天的年度**连续不满 6 年**的，经向主管税务机关备案，其**来源于境外且由境外单位/个人支付**的所得免予缴纳个税；在境内居住累计满 183 天的任一年度中**有一次离境超过 30 天**的，连续年限重新起算。

**九项所得**：①工资薪金；②劳务报酬；③稿酬；④特许权使用费（以上 4 项为**综合所得**）；⑤经营所得；⑥利息、股息、红利所得；⑦财产租赁所得；⑧财产转让所得；⑨偶然所得。

| 所得 | 界定要点 / 易错 |
| --- | --- |
| 工资薪金 | 因**任职或受雇**取得的工资、薪金、奖金、年终加薪、劳动分红、津贴、补贴及与任职受雇有关的其他所得；**不包括**独生子女补贴、执行公务员工资制度未纳入基本工资总额的补贴津贴差额和家属成员副食品补贴、托儿补助费、差旅费津贴、误餐补助 |
| 劳务报酬 | 从事**设计、装潢、安装、制图、医疗、法律、会计、咨询、讲学、翻译、审稿、书画、雕刻、影视、录音、录像、演出、表演、广告、展览、技术服务、介绍服务、经纪服务、代办服务**等 27 项劳务；**关键区分：是否存在雇佣关系**（有→工资薪金，无→劳务报酬） |
| 稿酬 | 作品以图书、报刊等形式**出版、发表**取得的所得 |
| 特许权使用费 | 提供**专利权、商标权、著作权、非专利技术及其他特许权**的使用权取得的所得；提供著作权的使用权所得**不包括稿酬** |
| 经营所得 | 个体工商户生产经营所得、个人独资企业/合伙企业个人投资者生产经营所得、依法从事办学/医疗/咨询等有偿服务活动所得、对企业事业单位承包承租经营及转包转租所得、个人以其他方式从事生产经营活动取得的所得 |
| 利息股息红利 | 拥有债权、股权等而取得的所得；**国债利息、国家发行的金融债券利息免税** |
| 财产租赁 | 出租不动产、机器设备、车船及其他财产取得的所得 |
| 财产转让 | 转让有价证券、股权、合伙企业财产份额、不动产、机器设备、车船及其他财产取得的所得；**境内上市公司股票转让所得暂免征收** |
| 偶然所得 | 得奖、中奖、中彩及其他偶然性质所得；**个人取得企业赠送的礼品按偶然所得**（符合条件的促销赠品除外） |

**所得来源地判定**（不论支付地）：因任职受雇、提供劳务、生产经营等在**境内**活动取得的所得→境内所得；将财产出租给承租人在境内使用、转让境内不动产等财产、从境内企业/组织/居民个人取得利息股息红利、境内企业支付的偶然所得→境内所得。

**应纳税所得额确定**：

| 利息股息红利、偶然所得 | **每次收入额**，不得扣除任何费用 |

| 大病医疗 | 医保目录范围内自付部分累计**超过 15 000 元**的部分，在 **80 000 元/年限额**内据实扣除 | 只能在**年度汇算清缴**时扣除；本人或配偶扣除，未成年子女由父母一方扣除，分别计算 |
| 住房贷款利息 | **1000 元/月**，最长 **240 个月**，仅限**首套**住房贷款 | 夫妻约定一方扣除，年度内不变；**只能享受一次** |
| 住房租金 | 直辖市/省会/计划单列市及国务院确定的其他城市 **1500 元/月**；市辖区户籍人口 > 100 万的城市 **1100 元/月**；≤ 100 万的城市 **800 元/月** | 由签订租赁合同的承租人扣除；夫妻主要工作城市相同只能由一方扣除；**与住房贷款利息不可同时享受** |

**「每次」的确定**：劳务报酬/稿酬/特许权使用费属**一次性收入**的以取得该项收入为一次；属同一项目连续性收入的，以**一个月内**取得的收入为一次。稿酬：同一作品再版视为**另一次**；先在报刊连载再出版（或相反）视为**两次**（连载一次、出版一次）；同一作品在报刊连载取得的收入，以**连载完成后**取得的所有收入合并为一次。

**公益捐赠扣除**：个人通过境内公益性社会组织、县级以上人民政府及其部门等国家机关，向教育、扶贫、济困等公益慈善事业的捐赠，扣除限额为**应纳税所得额的 30%**；国务院规定**全额税前扣除**的按规定执行（如公益性青少年活动场所、福利性非营利老年服务机构、农村义务教育、红十字事业等）；同时发生按 30% 扣除与全额扣除的，可**自行选择扣除次序**。捐赠金额：货币性资产按实际捐赠额；股权、房产按**财产原值**；其他非货币性资产按**市场价格**。

### 5.3 预扣预缴与汇算清缴

**工资薪金（累计预扣法）**：

```
累计预扣预缴应纳税所得额
 = 累计收入 − 累计免税收入 − 累计减除费用 − 累计专项扣除
   − 累计专项附加扣除 − 累计依法确定的其他扣除
（累计减除费用 = 5000 元/月 × 当年截至本月在本单位任职受雇月份数）

本期应预扣预缴税额
 = (累计预扣预缴应纳税所得额 × 预扣率 − 速算扣除数)
   − 累计减免税额 − 累计已预扣预缴税额
```

::: tip 提示 · 累计减除费用的特殊照顾
当年**首次入职**、此前月份未在其他单位取得工资薪金的大学生等，可按 `5000 元/月 × 当年截至本月月份数` 计算累计减除费用（如 7 月入职可一次减 35 000 元），避免入职当年多缴税。
:::

**劳务报酬 / 稿酬 / 特许权使用费预扣预缴**（按次，居民个人）：

| 所得 | 预扣预缴应纳税所得额 | 预扣率 |
| --- | --- | --- |
| 劳务报酬 | 每次收入 ≤ 4000 元减 800 元；> 4000 元按收入 ×(1−20%) | **20%～40% 三级超额累进**（不超过 20 000 元 20%、20 000~50 000 元 30% 速算 2000、超过 50 000 元 40% 速算 7000） |
| 稿酬 | 按上述减除费用后**再 ×70%** | **20%** |
| 特许权使用费 | 按上述减除费用后 | **20%** |

**汇算清缴**：居民个人取得综合所得，按年计算、年度终了后 **3 月 1 日至 6 月 30 日**办理汇算清缴，税款多退少补。需办理的情形：①已预缴税额**大于**年度应纳税额且申请退税；②年度综合所得收入合计超过 **12 万元**且需补税金额超过 **400 元**；③因少报/漏报所得或扣除项目等需要补税。可不办理：年度汇算需补税但**综合所得收入全年不超过 12 万元**、或补税金额**不超过 400 元**、或已预缴税额与年度应纳税额一致、或不申请退税。

### 5.4 经营所得与分类所得

**个体工商户/个人独资/合伙企业**：应纳税所得额 = 收入总额 − 成本 − 费用 − 损失 − 允许弥补的以前年度亏损；**业主工资不得扣除**（可扣 60 000 元/年减除费用）；**从业人员**合理工资可扣；工会经费/职工福利费/职工教育经费分别按**工资总额 2%、14%、2.5%** 扣除；业务招待费按发生额 60% 且不超过**营业收入 5‰**；广告费和业务宣传费不超过**营业收入 15%**；公益捐赠不超过**应纳税所得额 30%**。个人独资企业/合伙企业实行「**先分后税**」，按**分配比例或约定比例**确定各投资者应纳税所得额；**合伙企业对外投资分回的利息股息红利**，按「利息、股息、红利所得」**单独**按 20% 计征。

**财产租赁**：按次计算（**以一个月内取得的收入为一次**），可扣除税费、由纳税人负担的修缮费（**每次 800 元为限**，一次扣不完可下次继续扣）、法定减除费用；**个人按市场价格出租居民住房**取得的所得暂**减按 10%** 征税。

**财产转让**：`应纳税额 = (收入总额 − 财产原值 − 合理税费) × 20%`；**不能提供完整、准确的财产原值凭证**的，按转让收入的 **1%～3%** 幅度内**核定**征收（各地确定）。

**利息股息红利**：按**每次收入额 × 20%**；上市公司股息红利实行**差别化**：持股 **≤ 1 个月**全额计入，1 个月~1 年减按 **50%**，**超过 1 年减按 25%** 计入（另有免征情形按最新政策）。

**偶然所得**：`应纳税额 = 每次收入额 × 20%`。企业促销展业赠送礼品的征税规定：
- **不征税情形**（3 类）：①通过价格折扣、折让方式向个人销售商品（产品）和提供服务；②在向个人销售商品和提供服务的同时给予赠品（如通信企业购手机赠话费、入网费或购话费赠手机）；③对累积消费达到一定额度的个人按消费积分反馈礼品。
- **征税情形**（按「偶然所得」20%，由赠送企业代扣代缴）：企业在业务宣传、广告等活动中随机向本单位以外的个人赠送礼品（含网络红包）；企业在年会、座谈会、庆典及其他活动中向本单位以外的个人赠送礼品（**具有价格折扣或折让性质的消费券、代金券、抵用券、优惠券等除外**）；企业对累积消费达到一定额度的顾客给予额外抽奖机会，个人的获奖所得。
- 所得金额：礼品为**自产产品（服务）**按市场销售价格确定；为**外购商品（服务）**按实际购置价格确定。

### 5.5 税收优惠与境外所得抵免

**免征**：省级人民政府、国务院部委和中国人民解放军军以上单位，以及外国组织、国际组织颁发的**科学、教育、技术、文化、卫生、体育、环境保护等方面的奖金**；**国债和国家发行的金融债券利息**；按国家统一规定发给的**补贴、津贴**；**福利费、抚恤金、救济金**；**保险赔款**；**军人的转业费、复员费、退役金**；按国家统一规定发给干部职工的**安家费、退职费、基本养老金/退休费、离休费、离休生活补助费**；依照法律规定应予免税的**各国驻华使馆、领事馆的外交代表、领事官员和其他人员的所得**；中国政府参加的国际公约、签订的协议中规定免税的所得；国务院规定的其他免税所得。

**减征**：**残疾、孤老人员和烈属**的所得；因**自然灾害遭受重大损失**的（省级政府可规定减征幅度和期限，具体标准由省、自治区、直辖市人民政府规定并报同级人大常委会备案）。

**其他常见优惠**：**全年一次性奖金**（2027-12-31 前可选择**单独计税**：`奖金 ÷ 12` 按月换算表找税率，`应纳税额 = 奖金 × 税率 − 速算扣除数`，也可选择并入综合所得）；**上市公司股权激励**符合条件的单独计税；**个人养老金**：缴费按 **12000 元/年**限额标准在综合所得或经营所得中据实扣除，投资收益暂不征税，领取时**单独按 3%** 计税；**解除劳动关系一次性补偿收入**在当地上年职工平均工资 **3 倍以内**免征，超过部分单独适用综合所得税率表；**企业年金/职业年金**递延纳税；**居民换购住房**退还已缴个税（新购住房金额 ≥ 现住房转让金额的全额退还，小于的按比例退还）；**科技人员职务科技成果转化现金奖励**可减按 **50%** 计入当月工薪所得。

**境外所得抵免**（居民个人）：分**国（地区）又分项**计算抵免限额，`抵免限额 = 该国（地区）综合所得/经营所得/分类所得按我国税法计算的应纳税额之和`；实际已在境外缴纳的个税额与抵免限额比较：**多交不退**（多出部分可在以后 **5 年**内该国抵免限额余额中补扣），**少交补足**。计算顺序：先**分国分项**算限额，再把同一国家不同项目的限额**加总**，最后与已纳税额比较。

### 5.6 特殊问题与征收管理（要点速查）

| 特殊情形 | 处理 |
| --- | --- |
| 全年一次性奖金 | 可选择单独计税或并入综合所得（政策执行至 2027-12-31） |
| 中央企业负责人年度绩效薪金延期兑现 / 任期奖励 | 可比照全年一次性奖金办法 |
| 单位低价向职工售房 | 按「工资薪金」比照全年一次性奖金办法计征 |
| 居民换购住房 | 出售自有住房并在 **1 年内**重新购房的，按规定退还出售住房已缴个税 |
| 律师事务所从业人员 | 出资律师按**经营所得**（本人工资不得扣除）；雇员律师按**工资薪金**；分成收入律师按 `(分成收入 − 办案费用[收入 30% 内]) + 工资` 计征，办案费用不得重复列支 |
| 个体工商户公益性捐赠 | 不超过应纳税所得额 **30%** 的部分可扣除 |
| 国际组织驻华机构、外国使领馆/驻华新闻机构的雇员 | 按居民/非居民身份及所得来源判定 |

**征收管理**：纳税人取得**综合所得**按年计算、由扣缴义务人**按月或按次预扣预缴**；**经营所得**按年计算、月度或季度终了后 **15 日内**预缴，年度终了后 **3 个月内**汇算清缴；**分类所得**按月或按次计算、由扣缴义务人**代扣代缴**。需自行申报的情形：取得综合所得需要办理汇算清缴；取得应税所得**没有扣缴义务人**；扣缴义务人**未扣缴**税款；取得**境外所得**；因移居境外**注销中国户籍**；非居民个人在中国境内从**两处以上**取得工资薪金所得等。

## 第6章 城市维护建设税法、教育费附加与烟叶税法

### 6.1 城市维护建设税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 在境内缴纳**增值税、消费税（两税）**的单位和个人；**进口不征、出口不退** |
| 扣缴义务人 | 增值税、消费税的扣缴义务人**同时**是城建税扣缴义务人（代扣代缴/代收代缴/预缴/补缴两税时，一并缴纳城建税） |
| **税率（按纳税人所在地）** | **市区 7%**、**县城/镇 5%**、**不在市区/县城/镇 1%**；跨地区提供建筑服务、销售出租不动产等按**预缴地**适用税率，回机构所在地申报时按**机构所在地**税率补/退 |
| 计税依据 | **实际缴纳**的两税税额（含**免抵的增值税税额**；**不含**直接减免的两税税额、进口环节海关代征的两税、以及**滞纳金和罚款**）；因减免两税发生退税的，**同时退还**已征城建税 |
| 应纳税额 | `实际缴纳的两税税额 × 适用税率` |
| 优惠 | ①国家重大水利工程建设基金免征；②**至 2027 年底**对增值税小规模纳税人、小型微利企业、个体工商户**减半**征收；③自主就业退役士兵、重点群体创业就业按规定限额依次扣减增值税、城建税、教育费附加、地方教育附加和个税（限额标准最高可上浮 20%） |
| 征管 | 纳税义务发生时间、纳税地点、纳税期限**与增值税、消费税一致** |

::: danger 易错 · 城建税三个「不」
**进口不征**（海关代征的进口增值税/消费税不作为城建税计税依据）、**出口不退**（出口退还增值税/消费税时不退还城建税）、**两税的滞纳金与罚款不计入**计税依据；但**免抵的增值税税额要计入**。
:::

### 6.2 教育费附加与地方教育附加

`应纳教育费附加 / 地方教育附加 = 实际缴纳的增值税、消费税税额 × 3% / 2%`

- 教育费附加征收比率 **3%**，地方教育附加统一 **2%**。
- 与城建税同样：**进口不征、出口不退**；因减免两税退税的可同时退还已征附加，但**出口退还增值税/消费税的不退还**已征教育费附加。
- 至 2027 年底对小规模纳税人、小型微利企业、个体工商户减半征收；纳入产教融合型企业建设培育范围的试点企业，兴办职业教育的投资可按规定**抵免**教育费附加和地方教育附加。

### 6.3 烟叶税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 在境内**收购烟叶**的单位（烟草公司或受其委托收购烟叶的单位） |
| 征税范围 | 烤烟叶、晾晒烟叶 |
| 税率 | **20% 比例税率** |
| 计税依据 | **收购烟叶实际支付的价款总额** = 收购价款 × (1 + **10%** 价外补贴率)；税务机关按此统一核定，无论实际补贴多少 |
| 应纳税额 | `收购价款 × (1+10%) × 20%` |
| 纳税义务发生时间 | 收购烟叶**当日**；纳税地点为**烟叶收购地**主管税务机关；按月计征，纳税期满之日起 **15 日内**申报 |

::: tip 关联知识点
烟叶税是**增值税进项税额**计算的基础之一：`可抵扣进项 = (收购烟叶实际支付的价款总额 + 烟叶税) × 9%`（见第 2 章）。
:::

## 第7章 关税法和船舶吨税法

### 7.1 征税对象、纳税人与税率

**征税对象**：准许**进出关境**的货物和物品。**纳税人**：进口货物的**收货人**、出口货物的**发货人**、进出境物品的**所有人**（携带人/收件人/持有人）。

| 进口关税税率形式 | 说明 |
| --- | --- |
| 最惠国税率 | 适用于与我国签订含最惠国待遇条款贸易协定的国家/地区、以及 WTO 成员 |
| 协定税率 | 适用于与我国签订含关税优惠条款区域性贸易协定的国家/地区 |
| 特惠税率 | 适用于与我国签订含特殊关税优惠条款贸易协定的国家/地区 |
| 普通税率 | 适用于上述以外国家/地区，以及原产地不明的进口货物 |
| 关税配额税率 | 配额内低税率、配额外的按相应税率（小麦、玉米、稻谷、糖、羊毛、棉花、化肥等） |
| 暂定税率 / 报复性关税 / 反倾销反补贴保障关税 | 按国务院关税税则委员会决定执行 |

**税率适用顺序**：最惠国税率**低于**普通税率；同时存在多种税率时，**从低适用**（有特别规定的除外）；出口关税为**一栏比例税率**。进境物品进口税（行邮税）实行**综合税率**，含关税、进口环节增值税、消费税三税合一。

**税率适用时间**：以**申报进口之日**实施的税率为准；进口货物到达前经海关核准先行申报的，按**装载该货物的运输工具申报进境之日**实施的税率。

### 7.2 关税完税价格

**一般进口货物**：以**成交价格**为基础，
`完税价格 = 货价 + 采购费用（运抵境内输入地点起卸前的运输及相关费用、保险费） + 按规定应计入的项目`。

| 应计入完税价格 | **不计入**完税价格 |
| --- | --- |
| 买方负担的除购货佣金以外的**佣金和经纪费**；买方负担的**包装费、包装材料及劳务费**；与进口货物有关且作为销售条件的**特许权使用费**；卖方从买方转售/处置/使用中获得的**收益**；由买方负担的**容器费**；运抵输入地点**起卸前**的运输费、保险费、装卸费及相关费用 | 进口后的**基建、安装、装配、维修、技术援助费**（保修费除外）；货物运抵境内输入地点**起卸后**的运输费及保险费；**进口关税、进口环节海关代征税及其他国内税**；为在境内复制进口货物而支付的费用；境内外技术培训及境外考察费用；买方自行负担的**购货佣金**；符合条件的**利息费用** |

**运输费与保险费的特殊计算**：运费按实际支付额；无法确定时按**运输行业公布的同期的运费率（额）**估算；**运输费与保险费均无法确定**的，按「货价 + 运费」的 **3‰** 估算保险费；邮运进口以**邮费**作为运输及相关费用、保险费。

**估价方法顺序**（成交价格不能确定时）：①相同货物成交价格法 → ②类似货物成交价格法 → ③倒扣价格法 → ④计算价格法 → ⑤合理方法（**不得**使用境内生产的货物在境内的销售价格、最低限价/武断虚构价格等）。

**特殊进口货物完税价格**：运往境外**修理**复运进境→以境外**修理费 + 料件费**为基础（不含复运进境的运费保险费）；运往境外**加工**复运进境→以**加工费 + 料件费 + 复运进境的运输及相关费用、保险费**为基础；**租赁进口**→以**租金**为完税价格（留购的按留购价格）；**暂时进境**且按期复运出境的不缴税，留购的按留购价格；**减免税进口货物**需补税时按**原进口时价格扣除折旧**（折旧按实际已使用月份 / 监管年限折算）。

**出口货物完税价格**：以**成交价格**为基础，含货物运至境内输出地点**装载前**的运输及相关费用、保险费，**不含出口关税**（含出口关税的需除以 `1+出口关税税率` 换算）。

### 7.3 应纳税额计算与跨境电商

| 计征方式 | 公式 |
| --- | --- |
| 从价税 | `应纳关税 = 完税价格 × 关税税率` |
| 从量税 | `应纳关税 = 货物数量 × 单位税额` |
| 复合税 | `从价税额 + 从量税额` |
| 滑准税 | 价格越高税率越低，按**暂定税率表**确定（主要用于棉花等） |

**跨境电子商务零售进口税收政策**：

| 项目 | 规定 |
| --- | --- |
| 纳税人 / 扣缴义务人 | **购买商品的个人**为纳税义务人；**电子商务企业、平台或物流企业**为代收代缴义务人 |
| 完税价格 | **实际交易价格**（含货物零售价格、运费、保险费），**不含**平台优惠券/折扣等 |
| 计征限额 | 单次交易限值 **5 000 元**、年度交易限值 **26 000 元**；限值以内**关税税率暂设为 0%**，进口环节增值税、消费税按**法定应纳税额的 70%** 征收 |
| 超过限值 | 单次超过 5 000 元但低于年度限值、且订单下仅一件商品时，可自跨境电商零售渠道进口，**按货物税率全额征收**关税、增值税、消费税，交易额计入年度总额；年度累计超过 26 000 元的**按一般贸易**管理 |
| 其他 | 完税价格超过 5 000 元单次限值但不可分割的**单个商品**可按一般贸易征税；**不得**进入国内市场再次销售；已购买的电商进口商品**不得**自提退货以外的转售 |

### 7.4 减免规定与征收管理

| 减免类型 | 主要情形 |
| --- | --- |
| **法定减免** | 关税税额在人民币 **50 元以下**的一票货物；无商业价值的广告品和货样；外国政府/国际组织无偿赠送的物资；进出境运输工具装载途中必需的燃料、物料和饮食用品；在海关放行前**遭受损坏或损失**的货物；规定数额以内的物品；法律规定减征免征的其他货物物品 |
| **特定减免** | 科教用品、残疾人专用品、慈善捐赠物资、重大技术装备、支持集成电路与软件产业进口货物（2020-07-27~2030 年）、新型显示产业（2021-01-01~2030-12-31）、民用航空维修用航空器材、抗艾滋病病毒药物、国有公益性收藏单位进口藏品、**边民互市贸易进口生活用品每人每日 8 000 元以下免进口税**、边境小额贸易等 |
| **暂时免税** | 暂时进境/出境且在 **6 个月**内复运出境/进境的展览品、施工机械、货样、体育用品等（可申请延长） |
| **临时减免** | 由国务院关税税则委员会决定 |

**征收管理**：进口货物自**运输工具申报进境之日起 14 日内**、出口货物在**货物运抵海关监管区后装货的 24 小时以前**申报；纳税义务人应自海关填发税款缴款书之日起 **15 日内**缴纳税款，逾期按日加收**万分之五**滞纳金；**因纳税人原因**少征/漏征的，海关可自缴纳税款或货物放行之日起 **3 年内**追征（并加收滞纳金）；**因海关原因**少征/漏征的，自缴纳税款或放行之日起 **1 年内**补征（不加滞纳金）；对**偷逃税款**的可无限期追征。关税**复议前置**：纳税争议须先缴纳税款及滞纳金，再向上一级海关申请复议，对复议不服方可起诉。

### 7.5 船舶吨税

| 项目 | 规定 |
| --- | --- |
| 征税范围 | **自境外港口进入境内港口的船舶**（境外进入境内港口，不含境内港口之间航行） |
| 税率 | **定额税率**，按**船舶净吨位**与**吨税执照期限（1 年 / 90 日 / 30 日）**分档，分**优惠税率**（与我国签订含相互给予船舶税费优惠条款协定/条约国家的船舶）与**普通税率** |
| 应纳税额 | `船舶净吨位 × 适用定额税率`；**净吨位不足 1 吨按 1 吨计，超过 1 吨的尾数四舍五入取整数** |
| 免征 | 应纳税额在人民币 **50 元以下**的船舶；自境外以购买/受赠/继承等方式取得船舶所有权**初次进口到港**且**空载**的；吨税执照期满后**尚未离开港口**的船舶；非机动船舶（**不含非机动驳船**）、捕捞/养殖渔船、避难/防疫隔离/修理且**不下客货**的船舶、军队/武装警察部队专用或征用的船舶等 |
| 征管 | 由**海关**负责征收；应税船舶负责人应在**进入港口前或抵港时**申报领取吨税执照，或申明**延期/分期**缴纳；吨税执照在期满后**尚未离开港口**的，应申明**续期** |

## 第8章 资源税法和环境保护税法

### 8.1 资源税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 在境内和**管辖的其他海域**开发应税资源的单位和个人；**进口不征、出口不退**；在**开采或生产环节销售或自用**时一次课征（**批发零售环节不征**） |
| 税目（5 大类） | **能源矿产**（原油、天然气、页岩气、煤层气、煤、煤成气、铀、钍、油页岩、油砂、天然沥青、地热等）、**金属矿产**（黑色金属、有色金属、贵金属）、**非金属矿产**（矿物类、岩石类、宝玉石类）、**水气矿产**（二氧化碳气、硫化氢气、氦气、氡气、矿泉水）、**盐**（钠盐、钾盐、镁盐、锂盐） |
| 税率 | **从价定率**（主要）与**从量定额**（地热、砂石、矿泉水等部分税目及粘土等）并存；具体按《税目税率表》，实行**幅度税率**的由省级政府提出、同级人大常委会决定 |
| 计税依据 | **从价**：应税资源的**销售额**（不含增值税，含价外费用，**不含**运出矿区/开采地的运费及装卸仓储费用，须取得合法凭证）；**从量**：应税资源的**销售数量** |
| 销售额扣减 | 准予扣减**外购应税产品**的购进金额/数量（避免重复征税），需取得合法有效凭证；**混合销售或自用**时按规定折算 |
| 应纳税额 | 从价 `= 销售额 × 适用税率`；从量 `= 销售数量 × 适用税率` |
| 自用视同销售 | 开采或生产应税产品**自用于连续生产应税产品 → 不缴税**；用于**其他方面**（自用、捐赠、赞助、投资、广告、职工福利、利润分配、非应税产品生产等）→ **视同销售**缴税 |
| 减征免征 | **免征**：开采原油以及在油田范围内运输原油过程中**用于加热**的原油、天然气；**煤炭开采企业因安全生产需要抽采的煤成（层）气**。**减征**：从低丰度油气田开采的原油天然气减征 **20%**；高含硫天然气、三次采油和从深水油气田开采的原油天然气减征 **30%**；稠油、高凝油减征 **40%**；**衰竭期矿山**开采的矿产品减征 **30%**；**充填开采**置换出来的矿产资源减征 **50%**；共伴生矿、低品位矿、尾矿由省级决定减免；**增值税小规模纳税人、小型微利企业、个体工商户 2023—2027 年减半征收**（不含水资源税） |
| 征管 | 纳税义务发生时间：**收讫销售款/取得索取销售款凭据当日**（自用为移送当日）；纳税地点为**应税产品开采地或生产地**；按月或按季申报（**按季**为主），**不能按固定期限的可按次**；**水资源税**试点按实际取水量从量计征（取水量按计量设备或按最大取水能力核定），特种行业取用水、超计划超定额用水**从高**定税，农业生产取用水等免征 |

### 8.2 环境保护税

| 项目 | 规定 |
| --- | --- |
| 特点 | ①**调节型**税种（不是财政收入型）；②**直接排放税**；③**税务征收、环保协同**（纳税人自行申报、税务征收、环保部门负责对污染物监测管理，信息共享）；④收入**全部归地方** |
| 纳税人 | 在境内和管辖的其他海域**直接向环境排放应税污染物**的企业事业单位和其他生产经营者。**不缴税情形**：向**依法设立的污水集中处理、生活垃圾集中处理场所**排放；在**符合国家和地方标准的设施、场所贮存或处置**固体废物；**农业生产**（不含规模化养殖）排放；机动车/铁路机车/船舶/航空器等**流动污染源**排放；**依法设立的城乡污水/生活垃圾集中处理场所**排放相应应税污染物**不超过标准**的 |
| 税目与税率 | ①**大气污染物**（每污染当量 **1.2～12 元**）；②**水污染物**（每污染当量 **1.4～14 元**）；③**固体废物**（煤矸石 5 元/吨、尾矿 15 元/吨、危险废物 1 000 元/吨、冶炼渣/粉煤灰/炉渣/其他固体废物 25 元/吨）；④**工业噪声**（按超标分贝数 **每月 350～11 200 元**）。具体适用税额由省级人大常委会在幅度内决定 |
| 计税依据 | 大气/水污染物按**污染当量数**确定（**按每一排放口的应税污染物种类数，按污染当量数从大到小排序，取前 3 项 / 前 5 项**——第一类水污染物取前 5 项，其他类取前 3 项）；固体废物按**排放量（吨）**；工业噪声按**超标分贝数** |
| 应纳税额 | 大气/水 `= 污染当量数 × 适用税额`；固体废物 `= 排放量 × 适用税额`；噪声按超标分贝数对应的**每月税额** |
| 计税依据确定顺序 | ①安装使用符合国家规定和监测规范的**污染物自动监测设备**→按监测数据；②未安装的→按**监测机构出具的符合国家有关规定和监测规范的监测数据**；③因污染物种类多等**不具备监测条件**→按生态环境主管部门规定的**排污系数、物料衡算方法**计算；④不能按上述方法→按省级生态环境主管部门规定的**抽样测算方法**核定 |
| 减免 | **免征**：农业生产（不含规模化养殖）排放；机动车等流动污染源排放；依法设立的城乡污水/垃圾集中处理场所排放相应污染物**不超过**国家和地方标准的；纳税人**综合利用**的固体废物符合标准的；国务院批准免税的其他情形。**减征**：纳税人排放应税大气/水污染物浓度值**低于**国家和地方标准 **30%** 的，按 **75%** 征收；低于 **50%** 的，按 **50%** 征收（**应分别核算，未分别核算的不予减征**） |
| 征管 | 纳税义务发生时间为**排放应税污染物的当日**；纳税地点为**应税污染物排放地**；**按月计算、按季申报**，不能按固定期限的可按次申报；**税务机关**负责征收管理，**生态环境主管部门**负责对污染物监测管理 |

## 第9章 城镇土地使用税法和耕地占用税法

### 9.1 城镇土地使用税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 在**城市、县城、建制镇、工矿区**使用土地的单位和个人（**不含农村**）：拥有土地使用权者；权属未确定/纠纷未解决→**实际使用人**；土地使用权共有→**共有各方分别**纳税；土地使用人不在土地所在地→**代管人或实际使用人** |
| 税率 | **有幅度的定额税率**（按大/中/小城市、县城建制镇工矿区分级，每档幅度税额差距 **20 倍**）；经济落后地区可降低但降低额不得超过最低税额的 **30%**，经济发达地区提高须报财政部批准 |
| 计税依据 | **实际占用的应税土地面积（平方米）**（以**测定的面积 / 土地使用证书确认面积 / 申报面积**为准，依次） |
| 应纳税额 | `全年应纳税额 = 实际占用应税土地面积 × 适用税额` |
| 法定免征 | 国家机关、人民团体、军队**自用**土地；由国家财政部门拨付事业经费的单位**自用**土地；宗教寺庙、公园、名胜古迹**自用**土地；市政街道、广场、绿化地带等**公共用地**；直接用于**农、林、牧、渔业的生产用地**；经批准开山填海整治的土地和改造的废弃土地**从使用月份起免缴 5～10 年**；由财政部另行规定免税的能源、交通、水利设施用地和其他用地 |
| 省级可减免 | 个人所有的居住房屋及院落用地；房产管理部门在房租调整改革前经租的居民住房用地；免税单位职工家属宿舍用地；民政部门举办的安置残疾人占一定比例的福利工厂用地；集体和个人办的各类学校、医院、托儿所、幼儿园用地等 |
| 其他优惠 | 纳税单位**无偿使用**免税单位土地的，纳税单位**应照缴**；免税单位无偿使用纳税单位土地的**免征**；**专门用于经营农产品**的批发市场、农贸市场土地暂免（同时经营其他产品的按其他产品与农产品交易场地面积比例确定）；**城市轨道交通系统运营用地**免征；**供热企业**为居民供热所用土地免征；**物流企业**大宗商品仓储设施用地减按所属土地等级税额标准的 **50%** 计征；各类危险品仓库/厂房所需的防火防爆防毒等**安全防范用地**可由省级确定减免 |
| 征管 | **按年计算、分期缴纳**；纳税义务发生时间：以出让/转让方式有偿取得土地使用权的**从合同约定交付土地时间的次月起**（合同未约定交付时间的从**合同签订的次月起**）；**新征耕地**自批准征用之日起**满 1 年**时开始缴纳；**新征非耕地**自批准征用**次月起**；购置**新建商品房**自房屋交付使用之**次月起**；购置**存量房**自办理权属转移变更登记、登记机关签发房屋权属证书之**次月起**；出租出借房产自交付出租出借房产之**次月起**；**纳税地点为土地所在地** |

### 9.2 耕地占用税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | **占用耕地**建设建筑物、构筑物或从事**非农业建设**的单位和个人（**含占用园地、林地、草地、农田水利用地、养殖水面、渔业水域滩涂及其他农用地**） |
| 征税范围 | **用于建房或从事非农业建设**而占用的耕地；**占用耕地建设农田水利设施的，不缴**耕地占用税；占用耕地用于**农业生产**、改扩建**直接为农业生产服务**的生产设施的，不缴 |
| 税率 | **地区差别定额税率**（按人均耕地面积分 4 档，每平方米 **5～50 元**）；**人均耕地低于 0.5 亩**的地区可适当提高，但提高部分不得超过当地适用税额的 **50%**；占用**基本农田**的，按当地适用税额**加按 150%**征收（即 2.5 倍） |
| 计税依据 / 税额 | **实际占用的耕地面积（平方米）**；`应纳税额 = 实际占用耕地面积 × 适用定额税率`；**一次性征收**（**占用一次征一次，以后年年不再征**） |
| 免征 | **军事设施、学校、幼儿园、社会福利机构、医疗机构**占用耕地；**农村居民**在规定用地标准以内占用耕地**新建自用住宅**，按规定免征或减半（**其中农村居民经批准搬迁，新建自用住宅占用耕地不超过原宅基地面积的部分免征**）；**农村烈士遗属、因公牺牲军人遗属、残疾军人以及符合农村最低生活保障条件的农村居民**在规定用地标准内新建自用住宅免征 |
| 减征 | **铁路线路、公路线路、飞机场跑道、停机坪、港口、航道、水利工程**占用耕地，**减按每平方米 2 元**征收；**农村居民**在规定用地标准以内占用耕地新建自用住宅，按当地适用税额**减半**征收 |
| 征管 | 纳税义务发生时间为**收到自然资源主管部门办理占用耕地手续通知的当日**；**30 日内**一次性申报缴纳；纳税地点为**耕地所在地**；**未经批准占用**耕地的，纳税义务发生时间为**实际占用耕地之日**，由税务机关**责令限期缴纳**，并可按规定加收滞纳金；**临时占用**耕地（一般不超过 2 年）应缴税，在批准临时占用期满之日起 **1 年内**复垦恢复种植条件的**全额退还**已缴税款；因**挖损、塌陷、压占**等造成耕地毁损的，比照临时占用耕地 |

## 第10章 房产税法、契税法和土地增值税法

### 10.1 房产税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | **房屋所有权人**（产权属国家/集体/个人的由经营管理单位/集体单位/个人缴纳；产权出典的由**承典人**缴纳；产权所有人、承典人不在房产所在地或产权未确定/租典纠纷未解决的，由**房产代管人或使用人**缴纳） |
| 征税范围 | **城市、县城、建制镇和工矿区**内的**经营性**房屋（**农村房屋不征**；个人所有**非营业用**房产免征） |
| 税率 | **从价计征 1.2%**、**从租计征 12%**；**个人出租住房**（不分用途）减按 **4%**；企事业单位/社会团体及其他组织按市场价格向个人出租用于居住的住房减按 **4%** |
| 计税依据 | ①**经营自用**：`房产计税余值 = 房产原值 × (1 − 10%～30%)`（减除比例由省级政府规定，例题常用 30%）；②**出租**：**租金收入（不含增值税）**；③**投资联营**：共担风险的按**计税余值**从价计征，收取固定收入/不承担风险的按**租金收入**从租计征；④**居民住宅区内业主共有的经营性房产**由实际经营（代管）人按计税余值或租金缴纳；⑤**无租使用**其他单位房产的由**使用人**代为缴纳（按计税余值） |
| 应纳税额 | 从价 `= 应税房产原值 × (1−减除比例) × 1.2%`（按年计、分期缴，若年中启用按**实际使用月份**折算）；从租 `= 租金收入 × 12%（或 4%）` |
| 税收优惠 | 国家机关、人民团体、军队**自用**房产；由国家财政部门拨付事业经费的单位**自用**房产；宗教寺庙、公园、名胜古迹**自用**房产；个人所有**非营业用**的房产；**经财政部批准免税的其他房产**（如**公共租赁住房**、廉租住房、保障性住房、纳税人因房屋大修导致连续停用**半年以上**在大修期间免征、**老年服务机构**、**按政府规定价格出租的公有住房和廉租住房**等） |
| 纳税义务发生时间 | 自建房屋→**建成之次月起**；委托施工企业建设→**办理验收手续之次月起**（**在办理验收手续前已使用或出租出借的，从使用或出租出借的当月起**）；购置新建商品房→**房屋交付使用之次月起**；购置存量房→**办理房屋权属转移变更登记、登记机关签发房屋权属证书之次月起**；出租出借→**交付出租出借之次月起**；房地产开发企业自用/出租/出借本企业建造的商品房→**房屋使用或交付之次月起**；**新征耕地**建成后自批准征用之日起**满 1 年**起征 |
| 征管 | **按年征收、分期缴纳**，纳税地点为**房产所在地**（房产不在同一地的按房产坐落地点分别向所在地税务机关缴纳） |

### 10.2 契税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 境内**承受**（受让、购买、受赠、互换等方式取得）土地、房屋权属的**单位和个人** |
| 征税范围 | ①**土地使用权出让**；②**土地使用权转让**（出售、赠与、互换，**不含**土地承包经营权和土地经营权的转移）；③**房屋买卖、赠与、互换**；④以**作价投资（入股）、偿还债务、划转、奖励**等方式转移土地房屋权属的；⑤**土地/房屋权属作价投资入股、以房抵债、以房易房**等视同转移。**注意**：土地房屋权属的**典当、继承、分拆（分割）、出租、抵押**不属于征税范围 |
| 税率 | **3%～5% 幅度比例税率**，由省级政府在幅度内提出、同级人大常委会决定并报全国人大常委会和国务院备案 |
| 计税依据 | **不含增值税**：①出让/出售/买卖→**土地房屋权属转移合同确定的成交价格**（含应交付的货币及实物、其他经济利益对应的价款）；②**互换**→所互换土地房屋价格的**差额**（等价互换免征）；③**赠与**及其他无成交价格的→由征收机关参照**市场价格**依法核定；④**土地使用权出让**→含**土地出让金、市政建设配套费及各种补偿费用**；⑤已购公有住房补缴土地出让金等**按规定核定** |
| 应纳税额 | `计税依据 × 适用税率` |
| 免征 | ①**国家机关、事业单位、社会团体、军事单位承受**土地房屋权属用于办公、教学、医疗、科研、军事设施；②**非营利性的学校、医疗机构、社会福利机构承受**土地房屋权属用于办公、教学、医疗、科研、养老、救助；③**承受荒山荒地荒滩土地使用权**并用于农、林、牧、渔业生产；④**婚姻关系存续期间夫妻之间变更**土地房屋权属；⑤**法定继承人通过继承承受**土地房屋权属；⑥**依照法律规定应当予以免税的外国驻华使馆、领事馆和国际组织驻华代表机构承受**土地房屋权属 |
| 省级可减免 | 因**不可抗力灭失住房而重新承受住房权属**；因**城市规划、国家建设需要而被政府批准征用/占用住房，重新承受住房权属**；**易地扶贫搬迁贫困人口**按规定承受住房等 |
| 特殊优惠 | **个人购买家庭唯一住房**：面积 **140 平米及以下减按 1%**、140 平米以上减按 **1.5%**（2024-12-01 起面积标准由 90 平米提升至 140 平米）；**个人购买家庭第二套住房**：140 平米及以下减按 **1%**、140 平米以上减按 **2%**；**个人购买保障性住房减按 1%**；**个人首次购买 90 平米以下改造安置房按 1%**，超过 90 平米但符合规定的按规定；**已缴纳契税但权属转移合同无效/被撤销/解除**的可申请**退还**已缴税款 |
| 征管 | 纳税义务发生时间为**纳税人签订土地房屋权属转移合同的当日**，或取得其他具有合同性质凭证的当日；**在依法办理土地房屋权属登记手续前**申报缴纳；纳税地点为**土地房屋所在地**；**退税**：在权属登记前合同解除/无效的可申请退税；**未按规定缴纳契税的，不动产登记机构不予办理权属登记** |

### 10.3 土地增值税

![土地增值税五步法](/tax/tax-land-vat.svg)

| 项目 | 规定 |
| --- | --- |
| 纳税人 | **转让国有土地使用权、地上的建筑物及其附着物**（简称转让房地产）并取得**收入**的单位和个人（**含**各类企业、事业单位、国家机关、社会团体及其他组织、个体经营者） |
| 基本征税范围 | ①**转让国有土地使用权**（**出让**土地不属于，出让方是国家、不征）；②**地上建筑物及其附着物连同国有土地使用权一并转让**；③**存量房地产买卖**。**关键判定三要件**：转让的是**国有**土地使用权、权属发生**转移**、转让方**取得收入** |
| 特殊征税范围 | **征税**：以房地产**作价入股进行投资**（**非房地产企业**以房地产作价入股进行投资或联营的，**暂免**；但**房地产开发企业**以其建造的商品房作价入股进行投资/联营的，**应征**）、**合作建房建成后转让**、**以房地产抵债**、**以房地产进行交换**（有价的）、**房地产出租/抵押期未满**不征但**抵押期满以房抵债**征、**房地产重新评估增值**不征（未发生产权转移）、**国家收回/征用**房地产**免征**、**房地产继承/赠与**给直系亲属或承担直接赡养义务人、以及通过公益性社会组织/国家机关赠与教育民政等公益事业的**不征** |
| **税率** | **四级超率累进**：增值率 ≤50% → **30%**（速算扣除 0）；50%~100% → **40%**（5%）；100%~200% → **50%**（15%）；>200% → **60%**（35%） |
| 应税收入 | 转让房地产取得的**全部价款及有关经济利益**（货币、实物、其他收入），**不允许减除任何成本费用**；营改增后**不含增值税** |
| **新建房转让扣除 5 项** | ①**取得土地使用权所支付的金额**（含地价款、按国家统一规定缴纳的有关登记过户手续费及契税）；②**房地产开发成本**（土地征用及拆迁补偿费、前期工程费、建筑安装工程费、基础设施费、公共配套设施费、开发间接费用 6 项）；③**房地产开发费用**：能按项目分摊利息且能提供金融机构贷款证明的 `= 利息 + (①+②) × 5% 以内`（利息**不含**罚息、超过贷款期限的利息和加罚利息，且最高不超过按商业银行同类同期贷款利率计算的金额）；**不能**分摊利息或不能提供证明的 `= (①+②) × 10% 以内`；④**与转让房地产有关的税金**（城建税、教育费附加、地方教育附加、印花税等，**不含增值税**；房地产开发企业的印花税已列入管理费用，不再单独扣除）；⑤**财政部确定的其他扣除项目**：**加计扣除 = (①+②) × 20%**，**仅适用于房地产开发企业** |
| **存量房转让扣除 3 项** | ①**取得土地使用权所支付的金额**；②**房屋及建筑物的评估价格** = `重置成本价 × 成新度折扣率`（须经税务机关确认评估机构出具）；不能取得评估价格但能提供购房发票的，按**发票所载金额并从购买年度起至转让年度止每年加计 5%** 计算（`扣除金额 = 发票金额 × (1 + 5% × 年数)`，**满 12 个月计 1 年、超过 1 年未满 12 个月但超过 6 个月的视同 1 年**），**取得土地使用权所支付的金额和按规定缴纳的有关税费**可另扣，但**不作为加计 5% 的基数**；既无评估价格又无购房发票的，税务机关按**核定征收**；③**与转让房地产有关的税金** |
| **计算五步** | ①确定应税收入 → ②确定扣除项目金额 → ③`增值额 = 收入 − 扣除项目` → ④`增值率 = 增值额 ÷ 扣除项目金额 × 100%`，查表定税率与速算扣除系数 → ⑤`应纳税额 = 增值额 × 适用税率 − 扣除项目金额 × 速算扣除系数` |
| 免税优惠 | **纳税人建造普通标准住宅出售，增值额未超过扣除项目金额 20% 的，免征**（**超过 20% 的应就全部增值额按规定计税**，不得只就超过部分）；因**国家建设需要依法征收、收回**的房地产免征；因**城市规划、国家建设需要而搬迁**，由纳税人**自行转让**原房地产的免征；**企事业单位、社会团体及其他组织转让旧房作为保障性住房且增值额未超过扣除项目金额 20%** 的免征；**个人销售住房**暂免征收土地增值税 |
| **清算** | **清算单位**：以国家有关部门**审批的房地产开发项目**为单位；**分期开发**的以分期项目为单位；开发项目中**同时包含普通住宅与非普通住宅**的应**分别计算增值额**。**应当清算**（满足其一）：①房地产开发项目**全部竣工、完成销售**；②**整体转让未竣工决算**房地产开发项目；③**直接转让土地使用权**。**主管税务机关可要求清算**：①已竣工验收的项目，**已转让的房地产建筑面积占整个项目可售建筑面积的比例在 85% 以上**，或该比例虽未超过 85% 但**剩余可售建筑面积已经出租或自用**；②取得销售（预售）许可证**满 3 年**仍未销售完毕；③纳税人申请注销税务登记但未办理土地增值税清算手续；④省级税务机关规定的其他情况 |
| 清算后再转让 | 清算后**继续销售**或有偿转让房地产的，应按**清算时的单位建筑面积成本费用**计算扣除，即 `单位建筑面积成本费用 = 清算时的扣除项目总金额 ÷ 清算的总建筑面积`，**不得重复计算**已经清算的部分 |
| 核定征收 | 符合下列情形之一可**核定征收**（核定征收率原则上**不得低于 5%**）：①依照法律行政法规应设但未设置账簿；②擅自销毁账簿或拒不提供纳税资料；③虽设账簿但账目混乱或成本资料、收入凭证、费用凭证残缺不全难以确定转让收入或扣除项目金额；④符合清算条件但未按规定期限办理清算，经税务机关责令限期清算逾期仍不清算；⑤**申报的计税依据明显偏低，又无正当理由** |
| 征管 | 纳税人应自**转让房地产合同签订之日起 7 日内**向**房地产所在地**主管税务机关办理纳税申报，并在税务机关核定的期限内缴纳；**房地产开发企业**按**预征率**（各地按普通住宅/非普通住宅等类型确定，举例 1%~3% 幅度内）**预缴**，项目竣工结算后**清算**，多退少补 |

::: danger 易错 · 土增税三个高频陷阱
① **20% 免税是「增值率」而非「增值额占比」**的分界，且超过 20% 就**全额计税**，不是只对超出部分；
② **加计 20% 扣除只给房地产开发企业**，非房企转让新建房、存量房一律不得加计；
③ 房企的**印花税已含在管理费用**（开发费用按 5%/10% 比例计算，不得再单独扣除），但**非房企**转让房地产的印花税可作为「与转让有关税金」扣除。
:::

## 第11章 车辆购置税法、车船税法和印花税法

### 11.1 车辆购置税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 在境内**购置**应税车辆的单位和个人（**购置=购买、进口、自产、受赠、获奖或以其他方式取得并自用**） |
| 征税范围 | **汽车、有轨电车、汽车挂车、排气量超过 150 毫升的摩托车**；**不包括**排气量 150 毫升及以下摩托车、电动自行车、非机动车、拖拉机、设有固定装置的非运输专用作业车辆（**列入免税图册的**） |
| 税率 | **统一比例税率 10%** |
| 计税依据 | ①**购买自用**：发票电子信息中的**不含增值税价**（实际支付给销售者的全部价款，不含增值税）；②**进口自用**：`组成计税价格 = 关税完税价格 + 关税 + 消费税`；③**自产/受赠/获奖或其他方式取得自用**：按购置应税车辆时相关凭证载明的价格（**不含增值税**），无同类售价或价格明显偏低无正当理由的由税务机关**核定**；④**价外费用**（销售方价外向购买方收取的手续费、包装费、储存费、优质费、运输装卸费、代收款项、代垫款项等）**并入**计税价格（符合条件代为收取的保险费、车辆牌照费、车辆购置税税款除外） |
| 应纳税额 | `计税价格 × 10%`；**一辆车只征一次**（**已征车辆购置税的，过户、转售、改变用途不再重复征收**，除非**免税减税条件消失**） |
| 免税减税条件消失 | 已办理免税/减税手续的车辆因**转让、改变用途**等不再属于免税减税范围的，纳税人应在**30 日内**补缴，计税价格按**初次办理纳税申报时确定的计税价格** `× (1 − 使用年限 × 10%)` 计算（**使用年限取整，不满 1 年不计**）；发生转让的，纳税义务发生时间为**车辆转让之日** |
| **免税** | 依照法律规定应当予以免税的**外国驻华使馆、领事馆和国际组织驻华机构及其有关人员自用**的车辆；**中国人民解放军和中国人民武装警察部队列入装备订货计划的车辆**；**悬挂应急救援专用号牌的国家综合性消防救援车辆**；**设有固定装置的非运输专用作业车辆**；**城市公交企业购置的公共汽电车辆**；**新能源汽车**（2024-01-01~2025-12-31 **免征**，2026-01-01~2027-12-31 **减半征收**，每辆减税额不超过 1.5 万元；「换电模式」新能源汽车不含动力电池的按不含电池价格计税） |
| 征管 | **一车一申报**，纳税义务发生时间为**纳税人购置应税车辆的当日**（购买日为发票开具日、进口日为《海关进口增值税专用缴款书》开具日等）；**自纳税义务发生之日起 60 日内**申报缴纳；纳税地点：**购置应税车辆的所在地**（**不需办理车辆登记的**在**纳税人所在地**）；**在未办理纳税申报前不予办理车辆注册登记**；已缴税款办理**退车**的，可申请**退还**（自缴纳税款之日至申请退税之日，每满 1 年扣减 10%，未满 1 年的按已缴税款全额退还） |

### 11.2 车船税

| 项目 | 规定 |
| --- | --- |
| 纳税人 | 境内属于税目规定的**车辆、船舶的所有人或管理人**；**车船出租/出借**的由**所有人**缴纳（**承租人/使用人无纳税义务**，但当事人另有约定的按约定） |
| 征税范围 | 乘用车、商用车（客车、货车）、半挂牵引车、三轮汽车和低速载货汽车、挂车、摩托车、船舶（机动船舶、非机动驳船、拖船、游艇） |
| 税目税额 | **定额税率**（年基准税额）：乘用车按**发动机气缸容量（排气量）**分 7 档（1.0 升以下 60~360 元 … 4.0 升以上 3600~5400 元）；商用车客车按**每辆** 480~1440 元、货车按**整备质量每吨** 16~120 元；挂车按**货车税额的 50%** 计算；摩托车**每辆** 36~180 元；机动船舶按**净吨位每吨** 3~6 元、拖船和非机动驳船分别按**机动船舶税额的 50%** 计算；游艇按**艇身长度每米** 600~2000 元 |
| 应纳税额 | `年应纳税额 = 计税单位 × 年基准税额`（**购置当年**自**取得车船所有权或管理权的当月**起按月计算：`应纳税额 = 年应纳税额 ÷ 12 × 应纳税月份数`） |
| 免征 | **捕捞、养殖渔船**；**军队、武装警察部队专用**的车船；**警用车船**；**悬挂应急救援专用号牌的国家综合性消防救援车辆**；依照法律规定应当予以免税的**外国驻华使馆、领事馆和国际组织驻华机构及其有关人员**的车船；**节约能源、使用新能源**的车船（**减半/免征**，按《享受车船税减免优惠的节约能源使用新能源汽车车型目录》） |
| 减征 / 省级减免 | **省、自治区、直辖市人民政府**可对**公共交通车船**、**农村居民拥有并主要在农村地区使用的摩托车、三轮汽车和低速载货汽车**定期减征或免征；对**受地震、洪涝等严重自然灾害影响纳税困难**以及其他特殊原因确需减免的，可在一定期限内减征或免征 |
| 征管 | 纳税义务发生时间为**取得车船所有权或管理权的当月**（以购买车船的**发票或其他证明文件所载日期的当月**为准）；**按年申报、分月计算、一次性缴纳**，纳税年度为公历 1/1—12/31；纳税地点为**车船登记地**主管税务机关（**依法不需要办理登记的车船**，纳税地点为**车船的所有人或管理人所在地**）；**由保险机构在办理机动车交通事故责任强制保险（交强险）业务时实行代收代缴**（纳税人也可自行向税务机关申报）；**已完税车船在同一纳税年度内办理转让过户的，不另纳税也不退税** |

## 第12章 国际税收税务管理事务

### 12.1 国际税收基础概念

| 概念 | 要点 |
| --- | --- |
| 税收管辖权 | 分**居民（公民）管辖权**（对居民全球所得）、**地域（收入来源地）管辖权**（对境内所得）、**居民与地域双重管辖权**（我国采用）；各国管辖权冲突导致国际重复征税 |
| 国际重复征税 | 两个或以上国家对**同一纳税人、同一征税对象、同一时期**征收相同或类似税收；产生原因是**税收管辖权的重叠**（居民与地域、居民与居民、地域与地域） |
| 减免方法 | **免税法**（居住国放弃征税权）、**抵免法**（最常用，含直接抵免/间接抵免、全额抵免/限额抵免）、**扣除法**（境外税作为费用扣除）、**减免法**（低税率） |
| 国际税收协定 | 两个或以上主权国家为协调相互间税收分配关系、消除重复征税、防止避税而签订的书面协议；我国以 **OECD 范本**与 **UN 范本**为参考，与 100 多个国家/地区签订避免双重征税协定（DTA） |
| 国际避税 | 纳税人利用各国税制差异与漏洞，通过**转让定价、资本弱化、滥用税收协定、利用避税地、改变居民身份**等减少税负（**合法但不合理**）；**国际反避税**相应措施包括转让定价调整、预约定价安排（APA）、成本分摊协议、受控外国企业（CFC）规则、资本弱化限制、一般反避税规则（GAAR）、受益所有人判定等 |

**中新协定典型条款**（了解）：
- **税收居民**：按该国法律因住所、居所、管理机构所在地等负纳税义务的人；**双重居民身份**按「永久性住所 → 重要利益中心 → 习惯性居处 → 国籍 → 双方协商」依次判定。
- **常设机构（PE）**：企业进行全部或部分营业的**固定营业场所**（管理场所、分支机构、办事处、工厂、作业场所、矿场/油井/气井/采石场等）；**建筑工地/建筑装配安装工程**连续 **6 个月以上**（部分协定 12 个月）构成 PE；**专为储存/陈列/交付、采购、收集情报、准备性或辅助性活动**而设的固定场所**不构成** PE；通过**代理人**（有权并经常以企业名义签订合同）在缔约国另一方开展营业也可构成 PE。
- **劳务所得**：独立个人劳务原则上仅在居民国征税，除非在来源国设有**固定基地**或**停留累计超过 183 天**；非独立个人劳务（受雇）一般在来源国征税，但**同时满足**「收款人 12 个月内停留累计不超过 183 天 + 报酬由非来源国居民的雇主支付 + 报酬不由设在来源国的常设机构/固定基地负担」时**仅在居民国**征税。
- **协定管理**：非居民享受协定待遇**「自行判断、申报享受、相关资料留存备查」**，填写《非居民纳税人享受协定待遇信息报告表》，留存资料保存 **10 年**。

### 12.2 非居民企业税收管理

| 项目 | 要点 |
| --- | --- |
| 外国企业常驻代表机构 | **税务登记**：自设立之日起 **30 日内**办理；**账簿凭证**：应设置账簿、按实际发生的费用支出核算；**企业所得税**：按**经费支出换算收入**核定（`收入额 = 本期经费支出额 ÷ (1 − 核定利润率)`，核定利润率**不低于 15%**，`应纳税所得额 = 收入额 × 核定利润率`，税率 25%）；**增值税/附加**：按实际提供服务缴纳；**申报**：按季（或按月）申报，**准确核算收入/成本的可据实申报**；**代表机构不得从事营利性活动**的特定情形按规定免税 |
| 承包工程作业和提供劳务 | 非居民企业在中国境内承包工程作业/提供劳务，应办理税务登记、按**完工进度/工作量**确认收入，构成常设机构的按**实际利润率**核定征收企业所得税；**境内劳务发生地**主管税务机关负责管理 |
| 股息、利息、租金、特许权使用费、财产转让所得 | 非居民企业未设机构场所（或所得与其无实际联系）→ **减按 10% 税率**征收预提所得税，**实行源泉扣缴**，以**支付人**为扣缴义务人，扣缴义务发生时间为**实际支付或到期应支付**的当日；**转让财产所得** = 转让收入 − 财产净值；含**股权转让所得**按「转让价 − 投资成本（不含被投资企业未分配利润等留存收益）」 |
| **境外投资者分得利润直接投资递延纳税** | 境外投资者从中国境内居民企业分得的**股息、红利等权益性投资收益**，**直接用于境内**鼓励类投资项目（**增资、新建、股权收购**等，不含**境内上市公司股票**的增持/收购，符合条件除外）的，**暂不缴纳**预提所得税；须同时满足：①属于**直接投资**（以分得利润进行的**增资、新建、股权收购**等权益性投资，不含新增/转增/收购上市公司股份（**战略投资符合规定的除外**））；②分得利润属于**境内居民企业实际分配的已实现留存收益**；③投资**不得通过中间层**间接进行、资金**直接划转**至被投资企业或股权转让方账户；④**投向禁止类/限制类**项目不适用；⑤符合条件的应**自行判断、申报享受、资料留存备查**；**收回投资时**应补缴并按规定申报（**按实际收回金额比例**补缴、加收滞纳金但不加收利息） |
| 境外投资者以分配利润直接投资税收抵免 | 境外投资者以境内分配利润用于境内直接投资符合条件的，可按**投资额的 10%** 抵免其**当年**应纳税额（含预提所得税与后续转让所得应纳税额），当年不足抵免的可**结转以后年度**；**已享受递延纳税**的可按规定**选择适用**抵免政策（**不得重复**享受） |
| 对外付汇税务备案 | 境内机构和个人向境外**单笔支付等值 5 万美元以上**（不含）的**服务贸易/收益/经常转移/部分资本项目**外汇资金，需向所在地主管税务机关进行**税务备案**（**外国投资者以境内直接投资合法所得在境内再投资**、**境内机构在境外发生的差旅/会议/商品展销等费用**、**进出口贸易佣金/保险费/运输费**、**国际运输/国际金融服务**等情形**免于备案**）；**外国投资者**境内直接投资项下**利润、股息红利**汇出等按外汇管理规定办理 |

### 12.3 境外所得税收管理与反避税

| 项目 | 要点 |
| --- | --- |
| 抵免政策适用范围 | 居民企业来源于**境外**的所得、非居民企业在境内设立机构场所取得**发生在境外但与境内机构场所有实际联系**的所得；**已在境外缴纳的所得税税额**可从当期应纳税额中抵免，**抵免额不超过按我国税法计算的抵免限额** |
| 抵免办法 | **分国不分项**（默认，可按国别分别计算）或**不分国不分项**（综合抵免法，一经选择 **5 年**内不得变更）；**直接抵免**（境外所得直接缴纳的所得税）与**间接抵免**（境外子公司缴纳的、由境内母公司间接负担的所得税） |
| 抵免计算步骤 | ①确定**境外应纳税所得额**（境外税前所得，境外亏损不得抵减境内盈利）；②按我国税率计算**抵免限额** `= 境外应纳税所得额 × 25%（或 15%）`；③确定**可抵免境外已纳税额**（**不含**境外所得税税款返还/补偿、错缴或滞纳罚金、按协定规定不应征收的税额）；④比较，**多不退、少要补**；超出限额部分可在以后 **5 年**内该国的抵免限额余额中结转抵免 |
| 间接抵免 | 适用于**居民企业直接或间接持有境外企业 20% 以上股份**（**单一层级持股 ≥ 20%**，**多层间接持股**合计符合「**每层持股 ≥ 20% 且合计 ≥ 20%**」）；**层数最多 5 层**（含境内母公司直接持股的第一层）；计算：`本层企业所纳税额中由上一层企业负担的税额 = (本层企业就利润和投资收益所实际缴纳的税额 + 符合规定的由本层企业间接负担的税额) × 本层企业向上一层企业分配的股息（红利）÷ 本层企业税后利润额` |
| 税收饶让 | 居住国对**来源国按税收协定给予的减免税优惠**，视同**已在境外缴纳**而给予抵免（我国与部分国家协定含此条款，按协定执行） |
| 简易办法计算抵免 | 境外所得来源国（地区）**法定税率明显高于 25%**，或**实际税负明显偏低**且按规定难以取得完税凭证的，可按**境外应纳税所得额的 12.5%** 作为抵免限额（简易办法，**一经采用 5 年内不得变更**）；**境外分支机构亏损**不得抵减境内盈利，但可用**同一国家（地区）**其他项目或以后年度所得弥补（**5 年**） |
| **特别纳税调整（熟悉）** | **转让定价**：企业与其关联方之间的业务往来不符合**独立交易原则**而减少应纳税收入或所得额的，税务机关可按**可比非受控价格法、再销售价格法、成本加成法、交易净利润法、利润分割法**等方法调整；**关联申报**：年度关联业务往来报告表（**按纳税年度**）；**同期资料**：主体文档（符合条件的企业）、本地文档（**关联交易金额达标**）、特殊事项文档，按规定**自关联交易发生年度次年 6 月 30 日之前准备完毕**并**自税务机关要求之日起 20 日内提供**；**预约定价安排（APA）**：可就**未来 3～5 个年度**关联交易的定价原则和计算方法向税务机关提出申请（分**预备会谈、谈签意向、分析评估、正式申请、协商签署、监控执行** 6 阶段）；**成本分摊协议**、**受控外国企业（CFC）**、**资本弱化**（关联方债资比 5:1 / 2:1）、**一般反避税（GAAR）**；**补征税款加收利息**（**不加滞纳金**，利息按**税款所属纳税年度 12 月 31 日**人民银行人民币贷款基准利率 **加 5 个百分点**计算，**按规定提供同期资料的可只按基准利率**）；**追溯期 10 年** |
| 国际反避税前沿（了解） | **BEPS（税基侵蚀和利润转移）15 项行动计划**；应对经济数字化税收挑战的**「双支柱」方案**（支柱一：重新分配跨国企业利润征税权，金额 A / 金额 B；支柱二：全球最低税 **15%**，含 IIR、UTPR、QDMTT） |
| 国际税收征管合作 | **情报交换**（专项/自动/自发/同期税务检查/行业范围情报交换）、**CRS（金融账户涉税信息自动交换）**、**相互协商程序（MAP）**、**税收协定待遇备案**、**《多边税收征管互助公约》**、**BEPS 包容性框架**、**自动交换国别报告（CbCR）**（**跨国企业集团年度合并收入 ≥ 7.5 亿欧元**需报送） |

## 第13章 税收征收管理法

### 13.1 概述与税务管理

**立法目的**：加强税收征收管理，规范税收征收和缴纳行为，保障国家税收收入，保护纳税人合法权益，促进经济和社会发展。
**适用范围**：由税务机关征收的**各种税收**的征收管理（**关税、船舶吨税及海关代征的进口增值税/消费税**依《海关法》《关税条例》执行；**教育费附加、地方教育附加、社会保险费**等依相关规定参照执行）。**遵守主体**：税务机关、纳税人、扣缴义务人、地方各级人民政府/有关部门和单位、以及**任何单位和个人**（均有权检举违反税收法律、行政法规的行为）。

**税务登记管理**：

| 类型 | 要点 |
| --- | --- |
| 设立登记 | 从事生产、经营的纳税人应自**领取营业执照之日起 30 日内**申报办理税务登记；**临时从事生产经营**的纳税人也应办理；税务机关**当日**办理并发放税务登记证件（**多证合一**后按市场监管部门共享信息办理）；**非独立核算的分支机构**也应办理 |
| 变更登记 | 税务登记内容发生变化的，自**工商变更之日起 30 日内**（不需工商变更的自发生变化之日起 **30 日内**）申报办理 |
| 注销登记 | 发生解散、破产、撤销等情形，应在**向市场监管部门办理注销登记前**持有关证件向税务机关申报办理注销税务登记；**按规定不需要在市场监管部门办理注销**的，自有关机关批准或宣告终止之日起 **15 日内**办理；**被吊销营业执照**的自被吊销之日起 **15 日内**办理；**境外企业**在中国境内承包工程/提供劳务，项目完工、离开中国前 **15 日内**办理；办理注销前须**结清应纳税款、多退（免）税款、滞纳金、罚款，缴销发票、税务登记证件和其他税务证件** |
| 停业、复业登记 | 实行**定期定额征收**的个体工商户需要停业的，应在**停业前**申报办理，停业期限**不得超过 1 年**；停业期间发生纳税义务的应按规定申报纳税；**提前恢复营业**应在恢复营业前申报办理复业登记；**停业期满不能及时恢复营业**的应在停业期满前办理**延长停业登记** |
| 非正常户 | 已办理税务登记的纳税人**未按规定期限申报纳税**，经税务机关责令限期改正逾期不改正、且**实地检查查无下落并且无法强制其履行纳税义务**的，认定为**非正常户**（**超过 3 个月**的，税务机关可宣布其税务登记证件失效）；**超过 2 年**的，税务机关可**注销**其税务登记；认定为非正常户的，就其**逾期未申报**行为接受处罚、缴纳罚款并补办申报后可解除 |

**账簿、凭证及发票管理**：
- 从事生产经营的纳税人应自**领取营业执照或发生纳税义务之日起 15 日内**设置账簿；**扣缴义务人**应自**扣缴义务发生之日起 10 日内**设置代扣代缴、代收代缴税款账簿。
- 账簿、记账凭证、报表、完税凭证、发票、出口凭证及其他涉税资料应**保存 10 年**（法律行政法规另有规定的除外），**不得伪造、变造或擅自损毁**。
- 纳税人**财务会计制度或处理办法**应自领取税务登记证件之日起 **15 日内**报送税务机关备案；**与税收规定抵触**的按税收规定计算应纳税款。
- **发票管理**：由税务机关主管；**增值税专用发票**由国务院税务主管部门确定的企业印制，其他发票按规定印制；发票应**套印全国统一发票监制章**；**电子发票**与纸质发票**法律效力相同**；**不得**虚开、代开、转借、转让、涂改、撕毁、拆本使用、单联填开、跨规定的使用区域携带邮寄运输空白发票；已开具的**发票存根联和发票登记簿保存 5 年**。
- **税控管理**：纳税人应按规定安装、使用税控装置，**不得擅自改动、拆卸或损毁**。

**纳税申报管理**：纳税人、扣缴义务人应按**规定的申报期限、申报内容**如实办理纳税申报（**如实申报**与**按期申报**是两项独立义务）；**延期申报**需在申报期限内提出申请，经核准可按**上期实际缴纳的税额或税务机关核定的税额**预缴，并在核准的延期内办理税款结算；**申报方式**：直接申报（上门）、**邮寄申报**（以**寄出的邮戳日期**为实际申报日期）、**数据电文申报**（以税务机关计算机网络系统接收到该数据的时间为准）、**简易申报/简并征期**（定期定额户）。

### 13.2 税款征收

**税款征收原则（7 项）**：①税务机关是征税的**唯一行政主体**；②只能依法律行政法规征收；③不得违法开征、停征、多征、少征、提前征收、延缓征收或摊派税款；④必须遵守**法定权限和法定程序**；⑤征收税款或扣押查封商品货物或其他财产时**必须向纳税人开具完税凭证或扣押查封清单/收据**；⑥税款、滞纳金、罚款**统一由税务机关上缴国库**；⑦**税款优先**：税收优先于**无担保债权**（法律另有规定除外）；纳税人欠缴税款**发生在**其财产设定抵押/质押或被留置**之前**的，税收**先于**抵押权、质权、留置权执行；欠缴税款同时被行政机关处以**罚款、没收违法所得**的，**税收优先于罚款、没收违法所得**。

| 征收制度 | 要点 |
| --- | --- |
| 征收方式 | 查账征收、查定征收、查验征收、**定期定额征收**、委托代征、代扣代缴/代收代缴、**自核自缴**等 |
| 代扣代缴 / 代收代缴 | 扣缴义务人应**按规定的期限**解缴税款；税务机关按规定**付给扣缴义务人手续费**（**2%**，具体按规定）；**扣缴义务人未扣未收**的，由税务机关向**纳税人**追缴税款，对扣缴义务人处**应扣未扣、应收未收税款 50% 以上 3 倍以下**罚款 |
| **延期缴纳税款** | 因**不可抗力**导致较大损失、正常生产经营活动受较大影响，或**当期货币资金在扣除应付职工工资、社会保险费后不足以缴纳税款**的，可**经省、自治区、直辖市税务局批准**延期缴纳，**最长不得超过 3 个月**，**同一笔税款不得滚动审批**；税务机关应自收到申请之日起 **20 日内**作出决定；**不予批准的从缴纳税款期限届满次日起加收滞纳金**；**关税延期**最长不得超过 **6 个月** |
| **税收滞纳金** | 从**滞纳税款之日起，按日加收滞纳税款万分之五**（年化约 18.25%）；**对纳税人、扣缴义务人、纳税担保人**应缴纳的欠税及滞纳金**不再要求同时缴纳**，可**先行缴纳欠税，再依法缴纳滞纳金**；**因税务机关责任**导致未缴少缴税款的，追缴税款但**不加收滞纳金**（3 年追征期） |
| 减免税收制度 | 纳税人应**书面申请**并按规定报批/备案（**依法可直接享受的**除外）；**地方各级人民政府、各级人民政府主管部门、单位和个人**违反法律行政法规擅自作出的减税免税决定**无效**，税务机关不得执行，并向上级税务机关报告 |
| 税额核定和税收调整 | 纳税人有下列情形之一，税务机关有权**核定**应纳税额：①依法可不设账簿；②应设未设账簿；③擅自销毁账簿或拒不提供纳税资料；④虽设账簿但账目混乱或成本资料/收入凭证/费用凭证残缺不全难以查账；⑤发生纳税义务未按期申报，经责令限期申报逾期仍不申报；⑥**申报的计税依据明显偏低又无正当理由**。核定方法：参照**当地同类行业或类似行业中经营规模和收入水平相近的纳税人**的税负水平 → 按**营业收入或成本加合理费用和利润** → 按**耗用的原材料、燃料、动力等推算或测算** → 按**其他合理方法**（**一种方法不足以正确核定**的可**同时采用两种以上**） |
| **税收保全措施** | 适用：税务机关有根据认为**从事生产经营的纳税人有逃避纳税义务行为**，在**规定的纳税期之前**责令**限期缴纳**、**提供纳税担保**；**不能提供纳税担保**时，经**县以上税务局（分局）局长批准**，可：①**书面通知开户银行或其他金融机构冻结**纳税人金额相当于应纳税款的**存款**；②**扣押、查封**纳税人价值相当于应纳税款的**商品、货物或其他财产**。**个人及其所扶养家属维持生活必需的住房和用品，不在保全措施范围内**（**单价 5 000 元以下**的其他生活用品不采取保全/强制执行）。**限期期满仍未缴纳税款**的，经县以上税务局（分局）局长批准，可**书面通知银行扣缴税款**，或**拍卖/变卖**所扣押查封的商品货物等，以所得抵缴税款 |
| **税收强制执行措施** | 适用：从事生产经营的纳税人、扣缴义务人**未按规定的期限缴纳/解缴税款**，纳税担保人**未按规定期限缴纳所担保的税款**，由税务机关**责令限期缴纳**，**逾期仍未缴纳**的，经**县以上税务局（分局）局长批准**：①书面通知开户银行或其他金融机构**从其存款中扣缴税款**；②**扣押、查封、依法拍卖或变卖**其价值相当于应纳税款的商品货物或其他财产，以拍卖/变卖所得抵缴税款。**强制执行时，对纳税人、扣缴义务人、纳税担保人未缴纳的滞纳金同时强制执行**；**个人及其所扶养家属维持生活必需的住房和用品不在强制执行范围内**；**税务机关滥用职权违法采取保全/强制执行措施**使纳税人合法权益遭受损失的，依法承担**赔偿责任** |
| 欠税清缴 | 欠缴税款的纳税人**因怠于行使到期债权、放弃到期债权、无偿转让财产、以明显不合理低价转让财产且受让人知道该情形**，对国家税收造成损害的，税务机关可行使**代位权、撤销权**（**依照合同法/民法典相关规定**）；**欠缴税款 5 万元以上**的纳税人在**处分其不动产或大额资产之前**应向税务机关**报告**；**欠缴税款的纳税人或其法定代表人需要出境**的，应**结清税款、滞纳金或提供担保**，未结清又不提供担保的，税务机关可通知**出入境管理机关阻止其出境**；**纳税人有合并、分立情形**的应报告并**依法缴清税款**（合并时未缴清的由**合并后的纳税人**继续履行，分立时未缴清的由**分立后的纳税人承担连带责任**） |
| **税款的退还和追征** | **退还**：纳税人**超过应纳税额缴纳**的税款，税务机关发现后应**立即退还**；纳税人**自结算缴纳税款之日起 3 年内**发现的，可向税务机关要求退还**多缴的税款并加算银行同期存款利息**（**不加算滞纳金**），税务机关**自接到退还申请之日起 30 日内**查实并办理退还手续；**涉及从国库中退库的**，依照法律行政法规有关国库管理的规定退还。**追征**：①**因税务机关责任**致未缴少缴→**3 年内**追缴税款，**不加滞纳金**；②**因纳税人/扣缴义务人计算错误等失误**→**3 年内**追缴税款**并加收滞纳金**（**特殊情况累计数额在 10 万元以上**的可延长到 **5 年**）；③**偷税、抗税、骗税**→**无限期追征**（不受前款规定期限限制），并按规定处罚；**补缴和追征税款、滞纳金的期限，自纳税人、扣缴义务人应缴未缴或少缴税款之日起计算** |
| 企业破产清算程序中的税收征管 | 税务机关应按**破产法**规定申报税收债权（**税款本金、滞纳金、罚款**按法定顺序清偿，**税款优先于普通破产债权**）；**破产程序中**税务机关**不得**对纳税人财产采取税收保全/强制执行措施（应通过**破产管理人**依法处理）；**重整/和解**中税收债权按规定受偿；**注销**破产企业税务登记依法院裁定及清算报告办理 |
| 《无欠税证明》开具 | 纳税人**不存在欠税、滞纳金、罚款及未结清的其他税收债权**情形，或已按规定**缴清/办理相关手续**的，可向主管税务机关申请开具（**可线上办理，即时办结**） |

### 13.3 税务检查与法律责任

**税务检查**：税务机关有权检查账簿记账凭证报表及有关资料、到生产经营场所和货物存放地**实地检查**、责成提供纳税资料、**询问**、在交通要道和邮政企业**查证**托运邮寄应税商品货物单据凭证、**经县以上税务局（分局）局长批准**凭**全国统一格式的检查存款账户许可证明**查询从事生产经营的纳税人、扣缴义务人在银行或其他金融机构的**存款账户**（**查询案件涉嫌人员的储蓄存款**须经**设区的市、自治州以上税务局局长批准**）；**检查时不得少于 2 人并出示税务检查证和税务检查通知书**，否则被检查人有权拒绝；**税务机关调查取证时不得超出检查范围，应对纳税人商业秘密及个人隐私保密**。

### 13.4 纳税担保、信用管理与涉税专业服务

| 项目 | 要点 |
| --- | --- |
| **纳税担保** | 经税务机关同意，由纳税人或第三人以**保证、抵押、质押**方式为应缴纳的**税款及滞纳金**提供担保，担保范围含**税款、滞纳金和实现税款、滞纳金的费用**。适用情形：①税务机关有根据认为纳税人有逃避纳税义务行为、在纳税期前责令限期缴纳并要求提供纳税担保；②**欠缴税款、滞纳金的纳税人或其法定代表人需要出境**；③纳税人同税务机关在**纳税上发生争议**而需要依法申请**行政复议**；④法律行政法规规定可以提供纳税担保的其他情形。**保证**须为**具有纳税担保能力的自然人、法人或其他经济组织**（**国家机关、学校幼儿园医院等以公益为目的的事业单位社会团体不得为保证人**，**企业法人的分支机构**有法人书面授权的可在授权范围内提供保证）；**抵押**须**依法办理抵押物登记**（**不得抵押**：土地所有权、耕地宅基地自留地等集体所有土地使用权、学校幼儿园医院等公益设施、所有权使用权不明或有争议的财产、依法被查封扣押监管的财产等）；**质押**以**动产或权利凭证**移交占有 |
| **纳税缴费信用管理** | 税务机关按**年度**评价纳税缴费信用级次，分 **A、B、M、C、D** 五级：**A 级**年度评价指标得分 **90 分以上**；**B 级 70～90 分**；**M 级**为**新设立企业**或**评价年度内无生产经营业务收入且年度评价指标得分 70 分以上**；**C 级 40～70 分**；**D 级 40 分以下**或**有重大税收违法行为**（如偷税金额 10 万元以上且占各税种应纳税总额 10% 以上、逃避追缴欠税、骗取出口退税、虚开专票、D 级纳税人直接责任人员注册登记或负责经营的其他纳税人等）。**A 级激励**：单次可领取 **3 个月**的增值税发票用量、需要调整用量**即时办理**、**普通发票按需领用**、**连续 3 年 A 级可享受绿色通道**、**出口退税便利**等；**D 级惩戒**：公开 D 级纳税人及其直接责任人员名单、**增值税专用发票领用按辅导期一般纳税人政策办理**、**普通发票实行交（验）旧供新、严格限量供应**、加强出口退税审核、加强纳税评估、**列入重点监控对象**、**D 级评价保留 2 年、第三年不得评为 A 级**等；**纳税信用修复**：符合条件的可在规定期限内申请修复（**失信信息公布满 6 个月**、已缴清税款滞纳金罚款等），修复后按**以前年度信用级别**或**修复后的分值**重新评价 |
| **重大税收违法失信主体信息公布** | 认定标准含**伪造/变造/隐匿/擅自销毁账簿凭证**、**不缴少缴应纳税款 100 万元以上且占应纳税总额 10% 以上**、**骗取出口退税/虚开专票**等；**公布信息**含主体名称、统一社会信用代码、法定代表人/负责人、违法事实、法律依据、处理处罚情况、作出处理处罚的税务机关等；**公布满 6 个月**且已按规定**缴清（退）税款、滞纳金、罚款**的，可申请**提前停止公布**；对失信主体采取**纳税信用 D 级**、**限制出境**、**限制高消费**、**禁止参加政府采购**等联合惩戒措施 |
| 税收违法行为检举管理 | 检举可采用**书信、电话、网络、来访**等形式（**实名检举优先**）；**已接收的检举材料原则上不予退还**，不予受理的登记后按规定处理；**检举人**身份信息**严格保密**；**查实并依法处理后**可按规定给予**奖励**（**检举事项经查证属实、依法作出处理处罚、属于奖励范围**）；**匿名检举**一般不奖励（另有规定除外） |
| **涉税专业服务监管** | 涉税专业服务机构含**税务师事务所、会计师事务所、律师事务所、代理记账机构、税务代理公司、财税类咨询公司**等；**涉税专业服务业务范围**：纳税申报代理、一般税务咨询、专业税务顾问、税收策划、涉税鉴证、纳税情况审查、其他涉税事项代理、其他涉税服务（**其中专业税务顾问、税收策划、涉税鉴证、纳税情况审查**仅**税务师事务所、会计师事务所、律师事务所**可从事）；**实名制管理**（机构及人员实名信息报送、**信用积分**评价，分 **TSC1～TSC5** 五级）；**信用积分**与**失信名录**管理；**监管**含**行政登记、实名制、业务信息采集、信用评价、监督检查、违规惩戒**；**涉税专业服务机构及人员**不得**违反法律行政法规**、**未按规定报送实名信息 / 业务信息**、**出具虚假意见**、**以税务机关名义招揽业务**等；载明：税务师事务所**税务师占比应高于 50%**（国家税务总局另有规定除外） |
| 税务文书**电子送达** | 经受送达人**同意并签订《税务文书电子送达确认书》**，税务机关可通过**电子税务局等特定系统**送达税务文书；**电子送达与纸质送达具有同等法律效力**；送达日期以**电子文书到达受送达人特定系统的日期**为准（**受送达人可自行查询下载**）；**税务处理决定书、税务行政处罚决定书、税收保全措施决定书、税收强制执行决定书、税务行政复议决定书**等**暂不适用**电子送达（另有规定的除外） |
| **互联网平台企业涉税信息报送规定** | 互联网平台企业应按规定向主管税务机关**报送平台内经营者、从业人员的身份信息和收入信息**（按**季度**报送，**自 2025 年 6 月**起依《互联网平台企业涉税信息报送规定》执行）；**免予报送**情形：平台内经营者/从业人员**已办理税务登记**且按规定申报、从事**便民劳务活动**依法享受税收优惠或不需要纳税的等；平台企业应对报送信息的**真实性、准确性、完整性**负责；税务机关**依法保密**并**不得用于税收以外用途** |
| 税务人员税收业务违法行为处分规定 | 对税务人员**滥用职权、玩忽职守、徇私舞弊、违规征收/不征少征、泄露秘密、索贿受贿**等行为，依《公务员法》《公职人员政务处分法》《税收征管法》给予**警告、记过、记大过、降级、撤职、开除**等处分；构成犯罪依法追刑责；**违法行使职权给纳税人造成损失**的依法承担**赔偿责任** |

## 第14章 税务行政法制

### 14.1 税务行政处罚

| 项目 | 规定 |
| --- | --- |
| 设定 | **法律**可设定各种行政处罚；**行政法规**可设定除限制人身自由以外的行政处罚；**地方性法规**可设定除限制人身自由、吊销营业执照以外的行政处罚；**部门规章/地方政府规章**可设定**警告、通报批评或一定数额罚款**（罚款限额由国务院或省级人大常委会规定）；**其他规范性文件不得设定**行政处罚 |
| 种类 | **罚款**、**没收财物和违法所得**、**停止出口退税权**、**收缴发票或者停止发售发票**、**提请吊销营业执照**、**通知出境管理机关阻止出境**等（**税务行政处罚不含行政拘留、责令停产停业**，由其他机关实施）；以及《行政处罚法》规定的**警告、通报批评、暂扣/吊销许可证件、限制开展生产经营活动**等 |
| 主体 | **县以上税务机关**（**税务所**可实施**罚款额在 2000 元以下**的行政处罚，属于**授权**而非委托）；**各级税务局的内设机构、派出机构**（未获法律授权）**不得以自己的名义**实施行政处罚 |
| **简易程序** | 违法事实确凿并有法定依据，对**公民处以 200 元以下**、对**法人或其他组织处以 3000 元以下罚款或者警告**的，可**当场**作出处罚决定（执法人员**不得少于 2 人**、出示执法证件、填写预定格式决定书当场交付、告知权利、报所属税务机关备案）；**当事人可当场缴纳罚款**的情形：①**依法给予 20 元以下罚款**；②**不当场收缴事后难以执行**；③在**边远、水上、交通不便地区**当事人向银行缴纳确有困难、经当事人提出 |
| **听证** | 范围：对**公民作出 2000 元以上（含）**罚款、对**法人或其他组织作出 1 万元以上（含）**罚款，以及**没收较大数额违法所得、没收较大价值非法财物、降低资质等级、吊销许可证件、责令停产停业/关闭、限制从业**等较重处罚；当事人应在**《税务行政处罚事项告知书》送达后 5 日内**提出听证申请（**逾期视为放弃**）；税务机关应在**收到听证申请后 15 日内**组织听证，并在**举行听证的 7 日前**通知当事人时间地点；**听证公开举行**（涉及国家秘密、商业秘密或个人隐私的除外）；**听证是非必经程序**，当事人放弃或未提出的不影响处罚决定 |
| 执行 | **罚款决定与罚款收缴分离**：当事人应自**收到行政处罚决定书之日起 15 日内**到**指定银行或通过电子支付系统**缴纳罚款，逾期**每日按罚款数额的 3% 加处罚款**（**加处罚款总额不得超出罚款数额**）；**当事人确有经济困难需延期/分期缴纳**的，经税务机关批准可暂缓或分期缴纳；**当事人对行政处罚决定不服申请行政复议或提起行政诉讼的，行政处罚不停止执行**（法律另有规定除外）；**罚款、没收违法所得/非法财物拍卖的款项必须全部上缴国库**，税务机关**不得截留、私分或变相私分** |
| 裁量权行使规则 | 应遵循**合法、合理、公平公正、过罚相当、处罚与教育相结合、程序正当、公开透明**原则；**同一地区、同一时期、案情相同或相近、违法情节基本相当的违法行为，处罚种类和幅度应基本一致**；**不得因当事人申辩而加重处罚**；**不满 14 周岁**不予处罚（责令监护人管教）、**已满 14 周岁不满 18 周岁**从轻或减轻、**精神病人/智力残疾人在不能辨认或控制自己行为时**不予处罚；**主动消除或减轻危害后果、受他人胁迫或诱骗、主动供述行政机关尚未掌握的违法行为、配合查处有立功表现**等应从轻或减轻；**违法行为轻微并及时改正、没有造成危害后果**的**不予处罚**；**初次违法且危害后果轻微并及时改正**的**可以不予处罚**（首违不罚）；**违法行为在 2 年内未被发现**的不再给予行政处罚（**涉及公民生命健康安全、金融安全且有危害后果的为 5 年**，从违法行为发生之日起计算，有连续或继续状态的从行为终了之日起计算） |
| **「首违不罚」事项清单** | 对**首次发生、危害后果轻微、且在税务机关发现前主动改正或在责令限期改正期限内改正**的特定事项（如**未按规定将其全部银行账号报告税务机关**、**未按规定设置/保管账簿**、**未按规定期限办理纳税申报和报送纳税资料**、**未按规定开具/保管发票**、**未按规定报送财务制度**等），**不予行政处罚**，税务机关进行**提示提醒、辅导改正**（**不影响纳税信用评价**，但**同一当事人同一事项原则上只适用一次**） |

### 14.2 税务行政复议

| 项目 | 规定 |
| --- | --- |
| 特点 | ①以**当事人不服**税务具体行政行为为前提；②**依申请**产生（不告不理）；③一般由**原处理税务机关的上一级税务机关**审理；④与行政诉讼相衔接（**复议前置**或**选择复议**）；⑤**复议不加重处罚**（**不利益变更禁止**）；⑥复议期间**具体行政行为不停止执行**（复议机关认为需要停止、申请人申请且复议机关认为合理、法律规定停止的除外） |
| **受案范围** | **必经复议（复议前置）**：**征税行为**——包括**确认纳税主体、征税对象、征税范围、减税免税及退税、适用税率、计税依据、纳税环节、纳税期限、纳税地点和税款征收方式等具体行政行为，征收税款、加收滞纳金，扣缴义务人/受税务机关委托的单位和个人作出的代扣代缴、代收代缴、代征行为**等；对**当场作出的税务行政处罚决定**不服、**认为税务机关未履行法定职责**、**申请政府信息公开税务机关不予公开**等依《行政复议法》也属复议前置情形。**选择复议**：行政处罚（除当场处罚）、税收保全措施、强制执行措施、行政许可/行政审批、发票管理、纳税信用等级评定、税务检查、行政赔偿、行政奖励、政府信息公开中的其他情形等（**可先复议也可直接起诉**） |
| **管辖** | ①对各级**税务局**的具体行政行为不服→向**上一级税务局**申请；②对**税务所（分局）、各级税务局的稽查局**的具体行政行为不服→向**其所属税务局**申请；③对**国家税务总局**的具体行政行为不服→向**国家税务总局**申请（对复议决定不服可向国务院申请裁决，国务院裁决为**最终裁决**，或向法院起诉）；④对**两个以上税务机关共同作出**的具体行政行为不服→向**共同上一级税务机关**申请；⑤**税务机关被撤销**的→向**继续行使其职权的税务机关的上一级**申请；⑥对**税务机关与其他行政机关共同作出**的行为不服→向**共同上一级行政机关**申请 |
| **申请** | 申请人应**自得知税务机关作出具体行政行为之日起 60 日内**提出复议申请（**因不可抗力或正当理由耽误**的，申请期限自障碍消除之日起继续计算）；**复议前置**的征税行为争议，须**先依照税务机关的纳税决定缴纳/解缴税款及滞纳金或者提供相应的担保**，然后才可**在缴清税款/提供担保后 60 日内**提出复议申请；申请可**书面或口头**（口头申请的复议机关应当场记录）；**申请人、第三人可委托代理人**（**法定代理/委托代理**） |
| **受理** | 复议机关收到申请后应在 **5 日内**审查决定是否受理；**不予受理**或**受理后超过复议期限不作答复**的，申请人可自收到不予受理决定书之日起或**复议期满之日起 15 日内**向法院提起行政诉讼；**受理后 7 日内**将申请书副本发送被申请人，被申请人应在**收到副本之日起 10 日内**提出书面答复并提交当初作出具体行政行为的证据、依据和其他材料 |
| **证据** | **被申请人（税务机关）对其作出的具体行政行为负有举证责任**；复议机关审查证据的**合法性、真实性、关联性**；**复议过程中被申请人不得自行向申请人和其他有关组织或个人收集证据**；**现场勘验所用时间不计入复议审理期限** |
| **审查与决定** | 复议原则上采取**书面审查**（**申请人提出要求或复议机构认为必要时**可听取意见、调查情况）；**复议机关应自受理申请之日起 60 日内**作出复议决定（**情况复杂**经复议机关负责人批准可**延长最多 30 日**）；决定类型：①**维持**（事实清楚、证据确凿、适用依据正确、程序合法、内容适当）；②**责令履行**（被申请人不履行法定职责）；③**撤销、变更或确认违法**（主要事实不清证据不足、适用依据错误、违反法定程序、超越或滥用职权、明显不当），**撤销或确认违法的可责令被申请人在一定期限内重新作出**具体行政行为（**不得以同一事实和理由作出与原行为相同或基本相同**的行为）；④**责令被申请人重新作出**或**确认违法并赔偿**；⑤**调解/和解**（见下） |
| 和解与调解 | **和解**：申请人对被申请人行使**自由裁量权**作出的具体行政行为不服申请复议，可在**复议决定作出前**自愿达成书面和解协议，经复议机构准许可**撤回申请**；**调解**：涉及**行政赔偿、行政补偿、行政机关行使法律、法规规定的自由裁量权**的案件，复议机关可按自愿合法原则调解，制作**行政复议调解书**（经各方签字盖章、加盖复议机关印章后生效）；**和解/调解不得损害国家利益、社会公共利益和他人合法权益** |

### 14.3 税务行政诉讼

| 项目 | 规定 |
| --- | --- |
| 原则 | **人民法院特定主管**（只受理法定受案范围内）、**合法性审查**（原则上只审查**具体行政行为是否合法**，**合理性**仅在**行政处罚明显不当**等法定情形下审查）、**不适用调解**（**行政赔偿、补偿及行政机关行使法定自由裁量权**的案件**可以调解**）、**起诉不停止执行**、**税务机关负举证责任**、**由被告（税务机关）承担举证责任且不得自行向原告/证人收集证据**（**诉讼期间**）、**司法变更权有限**（仅**行政处罚明显不当或款额确定认定确有错误**可判决变更） |
| 受案范围 | 征税行为（**经复议前置后仍不服**）、行政处罚、税收保全/强制执行、行政许可/审批、发票管理、责令限期缴纳/提供担保、纳税信用评定、税务检查、行政赔偿/补偿、不依法履行法定职责、侵犯经营自主权/农村土地承包经营权等；**不受理**：**国防外交等国家行为**、**行政法规规章或行政机关制定发布的具有普遍约束力的决定命令（抽象行政行为）**、**行政机关对行政机关工作人员的奖惩任免等决定（内部行为）**、**法律规定由行政机关最终裁决的具体行政行为**、**公安国家安全等机关依刑事诉讼法明确授权实施的行为**、**行政调解/仲裁行为**、**行政指导行为**、**驳回当事人对行政行为提起申诉的重复处理行为**、**对公民法人权利义务不产生实际影响的行为** |
| 管辖 | **级别管辖**：一般**基层人民法院**管辖第一审税务行政案件；对**国务院部门或县级以上地方人民政府**所作的行政行为提起诉讼、海关处理的案件、**本辖区内重大复杂**案件由**中级人民法院**管辖；**地域管辖**：一般**最初作出行政行为的税务机关所在地**法院管辖；**经复议**的案件也可由**复议机关所在地**法院管辖（**复议改变的**由**复议机关所在地**法院管辖，可选择）；**限制人身自由**的行政强制措施由**被告所在地或原告所在地**法院管辖；**不动产**提起的诉讼由**不动产所在地**法院**专属**管辖 |
| **起诉与受理** | **复议前置**案件：自收到**复议决定书之日起 15 日内**起诉；**复议机关逾期不作决定**的，自**复议期满之日起 15 日内**起诉；**直接起诉**（选择复议）的，应自**知道或应当知道作出行政行为之日起 6 个月内**提出（**未告知诉权或起诉期限**的，从知道或应当知道**起诉期限**之日起算，但**最长不得超过 1 年**）；**因不动产**提起诉讼的案件自行政行为作出之日起**超过 20 年**、其他案件**超过 5 年**提起诉讼的，法院不予受理；**因不可抗力或其他不属于自身原因耽误起诉期限**的，被耽误时间**不计算在起诉期限内**；法院应在**收到起诉状之日起 7 日内**立案或作出不予立案裁定（**不能当场判定的应接收起诉状并出具书面凭证，7 日内决定是否立案**） |
| 审理与判决 | **一审普通程序**：法院应自**立案之日起 6 个月内**作出第一审判决（**有特殊情况需延长**的由高级人民法院批准，高级法院审理的一审案件需延长的由最高法院批准）；**简易程序**：**事实清楚、权利义务关系明确、争议不大**且属**被诉行政行为是依法当场作出 / 案件涉及款额 2000 元以下 / 属于政府信息公开案件**的，可**由审判员一人独任审理**，**立案之日起 45 日内**审结；**判决类型**：①**驳回诉讼请求**（行政行为证据确凿、适用法律法规正确、符合法定程序，或原告诉请理由不成立）；②**撤销判决 / 部分撤销**（主要证据不足、适用法律法规错误、违反法定程序、超越职权、滥用职权、明显不当），**可判决被告重新作出行政行为**（**不得以同一事实理由作出与原行为基本相同**的行为）；③**履行判决**（被告不履行/拖延履行法定职责）；④**给付判决**（被告依法负有给付义务）；⑤**确认违法 / 确认无效**（行政行为**重大且明显违法**如**实施主体不具有行政主体资格、没有依据**等，或撤销会给国家利益社会公共利益造成重大损害、行政行为程序轻微违法但对原告权利不产生实际影响）；⑥**变更判决**（**行政处罚明显不当，或其他行政行为涉及对款额的确定、认定确有错误**）；⑦**行政赔偿/补偿**判决；**二审**：当事人不服一审判决有权在**判决书送达之日起 15 日内**向上一级法院提起上诉（**裁定**为 **10 日内**），法院应自**收到上诉状之日起 3 个月内**作出终审判决 |

| 印花税 | 借款/融资租赁 0.05‰、产权转移书据 0.5‰、营业账簿 0.25‰、租赁/保管/仓储/财产保险/证券交易 1‰、其他合同与部分产权转移书据 0.3‰；证券交易印花税 2023-08-28 起减半、仅对出让方 |
| 滞纳金 / 追征 | 滞纳金**按日万分之五**；税务机关责任 3 年（不加滞纳金）、纳税人失误 3 年（特殊 10 万元以上 5 年）、偷抗骗税**无限期**；多缴税款 3 年内可退并加算利息 |

## 附录 B 各章易错点速查

| # | 易错点 | 正确结论 |
| --- | --- | --- |
| 1 | 起征点 vs 免征额 | 达到起征点按**全部**征税；免征额只对**超过部分**征税 |
| 2 | 增值税视同应税交易 | 自产/委托加工货物用于福利消费才视同；**外购**货物用于福利不视同但**进项不得抵扣**；个人无偿转让货物不视同 |
| 3 | 兼营 vs 混合 | 兼营未分别核算**从高**；混合按**主要业务**税率（关键是「一项交易 + 主附关系」） |
| 4 | 零税率 vs 免税 | 零税率出口免税**且退还**以前环节已纳税款；免税仅本环节免、进项不得抵扣 |
| 5 | 包装物押金 | 一般货物 1 年内未逾期不并入；**除啤酒黄酒外其他酒类**押金收取时即并入 |
| 6 | 白酒组价 | 复合计征**组价必须含从量税** |
| 7 | 消费税扣除 | 按**当期生产领用数量**扣除，且**仅限同一税目内连续生产**；酒类（除特定）/小汽车/高档手表等不得扣 |
| 8 | 用于换抵投的计税依据 | 消费税按**最高售价**（增值税按平均价），二者不同 |
| 9 | 不征税收入 vs 免税收入 | 不征税收入对应支出**不得扣除**；免税收入对应成本费用**可以扣除** |
| 10 | 业务招待费 | 发生额 60% 与销售（营业）收入 5‰ **孰低**，且**不得结转** |
| 11 | 广宣费 / 公益捐赠 / 职工教育经费 | 超支**准予结转**（捐赠结转 3 年，其余无限期）；**烟草企业广宣费一律不得扣除** |
| 12 | 广告费限额基数 | 含**视同销售收入**，不含营业外收入、投资收益（股权投资企业除外） |
| 13 | 稿酬收入额 | 先减 20% 费用**再乘 70%**，即收入 ×56% |
| 14 | 劳务报酬预扣 | 三级预扣率 20%/30%/40%（速算 0/2000/7000），**汇算时并入综合所得按七级重算** |
| 15 | 专项附加扣除 | 房贷利息与住房租金**不能同时享受**；大病医疗**仅汇算时**扣；扣除方式**年度内不得变更** |
| 16 | 城建税 | **进口不征、出口不退**；滞纳金罚款不计入计税依据；**免抵增值税要计入** |
| 17 | 关税完税价格 | 计入**起卸前**运费保险费；**购货佣金不计入**、**经纪费/佣金计入**；进口关税及国内税不计入 |
| 18 | 环保税计税依据 | 大气/水污染物按当量数**排序取前 3 项 / 第一类水污染物前 5 项** |
| 19 | 耕地占用税 | **一次性征收**；占用**基本农田加按 150%**（即 2.5 倍）；农田水利设施**不征** |
| 20 | 契税互换 | 按**价格差额**计税，**等价互换免征** |
| 21 | 土增税 20% 免税 | 是**增值率 ≤20%** 的普通标准住宅；超过 20% **全额计税**，不是只对超出部分 |
| 22 | 土增税加计 20% | **仅房地产开发企业**；非房企、存量房一律不得加计 |
| 23 | 房企印花税 | 已含在开发费用（5%/10%）中，**不得再单独扣除**；非房企可作「与转让有关税金」扣除 |
| 24 | 印花税计税依据 | **未单独列明增值税**的按**含税**合同金额；运输合同按**运费**（不含保险费）；财产保险合同按**保险费**；借款合同按**本金不含利息** |
| 25 | 证券交易印花税 | **仅对出让方**征收、2023-08-28 起**减半**、扣缴义务人是**证券登记结算机构** |
| 26 | 车辆购置税 | **一车一征**，过户/转售不再征（除非免税条件消失）；免税条件消失按 `初次计税价格×(1−使用年限×10%)` 补缴 |
| 27 | 滞纳金与罚没 | 滞纳金**按日万分之五**；**税收优先于**无担保债权、先于后设抵押质权留置权、**优先于罚款没收违法所得** |
| 28 | 追征期 | 税务机关责任 3 年（无滞纳金）；纳税人失误 3 年（≥10 万特殊 5 年）；**偷抗骗无限期** |
| 29 | 复议前置 | **征税行为（含加收滞纳金、扣缴行为）**须**先缴税/提供担保再复议、不服再诉讼**；处罚等可选择复议或直接起诉 |
| 30 | 首违不罚 | 需同时满足**首次 + 危害后果轻微 + 及时改正**；不影响纳税信用，同一事项原则上**只适用一次** |

## 附录 C 学习建议

::: tip 按分值安排复习
- **第一梯队**（分值最高、必出计算题）：第 2 章增值税、第 4 章企业所得税、第 5 章个人所得税、第 10 章土地增值税、第 13 章征管法。这几章要能**独立完整做计算题**，重点练「销项−进项」「收入−扣除」「九项所得」「土增五步」四条主线。
- **第二梯队**（客观题密集）：第 3 章消费税（税目税率、组价、已纳税款扣除）、第 11 章印花税（税目税率表）、第 7 章关税（完税价格）、第 14 章行政法制（期限数字）。
- **第三梯队**（记忆型小税种）：第 6、8、9 章及第 12 章，以「纳税人 / 征税范围 / 税率 / 优惠 / 纳税义务发生时间」五栏表格记忆效率最高。

**通用方法**：①先把附录 A 的税率与数字背熟；②每章按「纳税人 → 征税范围 → 税率 → 计税依据 → 应纳税额 → 优惠 → 征管」七步自测；③把附录 B 的 30 个易错点当作考前最后一遍清单。
:::
