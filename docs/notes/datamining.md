## 第 0 章 数据挖掘课前准备（★★）

### 0.1 数据挖掘是什么、不是什么

**数据挖掘（Data Mining）** 是从大量、不完全、有噪声、模糊且随机的实际应用数据中，提取隐含在其中、人们事先不知道、但又是潜在有用的信息和知识的过程。它不是一个算法，而是一条**完整流程**：

![数据挖掘通用流程与本书章节地图](/dm/dm-overview.svg)

| 易混淆概念 | 区别 | 关系 |
| --- | --- | --- |
| 数据统计 / 描述分析 | 回答「发生了什么」，用汇总量、图表 | 数据挖掘的基础环节 |
| 数据挖掘 | 完整流程：业务 → 数据 → 建模 → 评估 → 部署 | 包含统计建模与机器学习 |
| 机器学习 | 侧重「从数据中学习模型并预测」的算法集合 | 只是数据挖掘「建模」环节的一类方法 |
| 数据分析 | 更宽泛的日常分析活动 | 数据挖掘是其深度形式 |
| 大数据 | 强调数据规模与处理基础设施（4V） | 是数据挖掘的一类数据环境 |

::: tip 三类任务
**描述性**（发生什么：描述统计、可视化、透视） → **预测性**（将会怎样：回归、时序、分类） → **探索性**（发现结构：聚类、降维、关联规则、网络分析）。做题时先判断题型，再选方法。
:::

::: tip CRISP-DM 六阶段（必背主线）
**业务理解 → 数据理解 → 数据准备 → 建模 → 评估 → 部署**，六个阶段构成闭环迭代：评估不达标可回退到业务理解或数据准备重新来过；数据准备与建模之间也常反复多轮。数据挖掘项目 60%–80% 的工作量集中在「数据理解 + 数据准备」，这决定了建模结果的上限。
:::

::: danger 易错 · 流程观
- 数据挖掘 ≠ 建模：教学与考试常把「数据理解 / 数据准备」略过，但真实项目中这部分占绝大部分工作量，且直接决定结果可信度。
- CRISP-DM 是**闭环迭代**：评估不达标要回退到业务理解或数据准备，不是一次性线性流水线。
- 「数据中发现的规律」不等于「因果规律」，也不等于「可推广到未来」。
:::

## 第 1 章 数据收集与分析软件（★★）

### 1.1 数据收集过程

数据收集是分析的第一步，核心原则是「先明确分析目标，再决定收集什么」。完整过程见第 1 张图：

![数据收集过程与数据类型](/dm/dm-datacollect.svg)

| 步骤 | 关键问题 | 常见产出 |
| --- | --- | --- |
| ① 明确分析目标 | 要回答什么业务问题？评价指标是什么？ | 指标定义表 |
| ② 确定数据来源 | 内部业务库 / 公开数据 / 问卷 / 网页 / API | 数据源清单 |
| ③ 设计采集方案 | 抽样还是全量？字段口径？频率？ | 采集脚本 / 问卷 |
| ④ 实施与录入 | 编码、存储格式、字段类型 | csv / Excel / 数据库表 |
| ⑤ 质量核查 | 完整性、一致性、重复、异常、口径 | 数据质量报告 |

::: danger 易错 · 抽样与口径
- **抽样偏差**：只收集「容易拿到」的样本（如仅在线用户）会让结论系统性偏向，增大样本量**不能**消除偏差。
- **口径不一致**：同一「销售额」在两份系统里可能含税/不含税、按下单/按支付，合并前必须对齐定义。
- **数据泄露（leakage）**：建模时误把「未来才可得」的变量当特征，会得到虚高的评估指标。
:::

::: tip 常用抽样方法一览
- **概率抽样**（可估计抽样误差、能推断总体）：简单随机抽样、**分层抽样**（层内同质、层间异质，按比例或最优分配）、**系统抽样**（等距，警惕周期性）、**整群抽样**（群内异质，成本低但精度差）。
- **非概率抽样**（不能推断总体）：便利抽样、配额抽样、雪球抽样（适合隐蔽群体）。
选择口诀：要推断总体就必须用概率抽样；分层与整群方向相反——分层要求层内尽量相似，整群要求群内尽量多样。
:::

### 1.2 数据的类型（★★★，最易考）

#### 1.2.1 按度量尺度分

| 尺度 | 允许的关系 | 可用统计量 | 例子 |
| --- | --- | --- | --- |
| 定类（名义） | =、≠ | 频数、众数、列联表 | 性别、专业、地区 |
| 定序（顺序） | 上面 + 大小顺序 | 中位数、分位数、秩相关 | 满意度等级、职级 |
| 定距（区间） | 上面 + 加减 | 均值、方差、相关系数 | 温度（℃）、年份 |
| 定比（比率） | 上面 + 乘除（有绝对零点） | 全部，含变异系数 | 收入、身高、销售额 |

::: danger 易错 · 度量尺度
- 定序数据**求均值无意义**（如满意度 1–5 分的均值可作近似描述，但严格说等级间距未必相等）。
- 把定类变量编码成 1/2/3 后**不能直接当数值做回归**（会人为引入大小顺序），必须用独热编码 / 哑变量。
- 「温度 0℃」不是没有温度（无绝对零点），故 20℃ 不能说成「10℃ 的两倍热」；定比量才可以作倍数比较。
:::

#### 1.2.2 按结构与时间形态分

| 形态 | 定义 | 典型方法 | 本书对应章 |
| --- | --- | --- | --- |
| 截面数据 | 同一时点、多个个体 | 描述、相关、回归、聚类 | 第 2–4 章 |
| 时间序列 | 同一个体、多个时点 | 平稳性、ARIMA、预测 | 第 5 章 |
| 面板数据 | 多个个体 × 多个时点 | 面板模型、综合评价 | 第 4 章 |
| 多元数据 | 一个个体、多个指标 | 相关矩阵、PCA、聚类 | 第 4 章 |

**结构化程度**：结构化（关系表 / 数据库） → 半结构化（JSON / XML / HTML） → 非结构化（文本 / 图像 / 音视频）。第 6–8 章处理的网页、题录、网络关系主要属于半结构化与图数据。

::: tip 缺失机制：MCAR / MAR / MNAR
实际项目还须判断**缺失机制**：MCAR（完全随机缺失）、MAR（随机缺失，依赖于已观测变量）、MNAR（非随机缺失，依赖于缺失值本身）。MNAR 会造成系统性偏差，简单删除或均值填补都不可靠，需要建模或敏感性分析。
:::

#### 1.4.2 基本数据类型与容器

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| int / float / bool | `3`、`2.5`、`True` | 数值与逻辑 |
| str | `'数据挖掘'` | 不可变，支持切片、split、join |
| list | `[1, 2, 3]` | 可变、有序、可含异构元素 |
| tuple | `(1, 2)` | 不可变，可作字典键 |
| dict | `{'a': 1}` | 键值对，按键查找 O(1) |
| set | `{1, 2, 3}` | 去重、集合运算 |
| ndarray | `np.array([1, 2, 3])` | 同构、向量化运算 |
| Series / DataFrame | `pd.Series(...)` / `pd.DataFrame(...)` | 带标签，DataFrame 列可异构 |

```python
import numpy as np, pandas as pd

s = pd.Series([178, 165, 170], index=['李勇', '刘晨', '王敏'], name='身高')
df = pd.DataFrame({'姓名': ['李勇', '刘晨', '王敏'],
                   '专业': ['CS', 'CS', 'MA'],
                   '身高': [178, 165, 170],
                   '成绩': [92, 85, 78]})
print(s.mean(), s.std())          # 171.0  6.5574...（ddof=1）
print(df['身高'].tolist())         # [178, 165, 170]
print(df.loc[df['专业'] == 'CS', ['姓名', '成绩']])
```

::: tip 工作例题 · Series.std() 的 ddof
`pd.Series([178,165,170]).std()` 用 **ddof=1**（除以 n−1=2）：均值 171，偏差平方 49+36+1=86，86/2=43，√43≈**6.5574**。而 `numpy.std()` 默认 **ddof=0**（除以 n=3）得 √(86/3)≈5.3541。这是 pandas 与 numpy 最经典的数值差异。
:::

::: danger 易错 · Python 基础
- `list` 的 `+` 是拼接、`numpy` 数组的 `+` 是逐元素相加，混用会出错。
- `df['列']` 取单列得 Series，`df[['列']]` 得 DataFrame；链式赋值 `df[df.a&gt;0]['b']=1` 触发 `SettingWithCopyWarning`，应改用 `.loc`。
- 可变对象作函数默认参数（如 `def f(x=[])`）会跨调用累积状态。
:::

## 第 2 章 数据挖掘的分析基础（★★★）

本章是全书使用频率最高的一章：**描述分析**回答「数据长什么样」，**透视分析**回答「不同分组之间有什么差异」。二者都不需要建模假设，是任何分析项目的第一步。

### 2.1 数据的描述分析

![描述分析三类统计量](/dm/dm-descriptive.svg)

#### 2.1.1 三类统计量总表

| 类别 | 统计量 | 公式 / 定义 | pandas 方法 |
| --- | --- | --- | --- |
| 集中趋势 | 均值 | x̄ = Σxᵢ/n | `mean()` |
| 集中趋势 | 中位数 | 排序后居中值（偶数取中间两数均值） | `median()` |
| 集中趋势 | 众数 | 频数最高的取值 | `mode()` |
| 离散程度 | 极差 | max − min | `max()-min()` |
| 离散程度 | 方差 | s² = Σ(xᵢ−x̄)²/(n−1) | `var()` |
| 离散程度 | 标准差 | s = √s² | `std()` |
| 离散程度 | 四分位距 | IQR = Q3 − Q1 | `quantile(.75)-quantile(.25)` |
| 离散程度 | 变异系数 | CV = s / x̄（无量纲，可跨量纲比较） | `std()/mean()` |
| 分布形态 | 偏度 | 三阶标准矩，右偏为正 | `skew()` |
| 分布形态 | 峰度 | 四阶标准矩，尖峰厚尾为正 | `kurt()` |
| 分位数 | Q1 / Q3 | 25% / 75% 分位 | `quantile([.25,.75])` |

```python
import pandas as pd
x = pd.Series([2, 4, 5, 7, 9], name='样本')
print(x.describe())
# count 5.000000 | mean 5.400000 | std 2.701851 | min 2.00
# 25% 4.00 | 50% 5.00 | 75% 7.00 | max 9.00
print('方差', x.var(), '偏度', round(x.skew(), 4), '峰度', round(x.kurt(), 4))
print('IQR', x.quantile(.75) - x.quantile(.25), 'CV', round(x.std()/x.mean(), 4))
```

::: tip 工作例题 · 手算全过程（2, 4, 5, 7, 9）
x̄ = 27/5 = **5.4**；中位数 = **5**；
偏差平方：11.56 + 1.96 + 0.16 + 2.56 + 12.96 = **29.20**；
样本方差 s² = 29.20/4 = **7.30**（ddof=1）；s = √7.30 ≈ **2.7019**；
Q1=4、Q3=7 → IQR=3 → 上界 7+1.5×3 = **11.5**，无异常值；
CV = 2.7019/5.4 ≈ **0.5003**。
:::

::: danger 易错 · 方差与偏度
- `pd.Series.var()` / `std()` 默认 **ddof=1**（样本），`np.var()` / `np.std()` 默认 **ddof=0**（总体）；两者数值不同，答题须写明用哪个。
- 均值对异常值敏感，中位数稳健；**右偏分布**中 均值 &gt; 中位数 &gt; 众数（长尾把均值拉向右侧）。
- 偏度/峰度是「标准化矩」，受样本量影响大，小样本不宜过度解读。
- `describe()` 默认只对数值列生效；要看分类列需 `describe(include='object')` 或 `include='all'`。
:::

import matplotlib.pyplot as plt
x.plot.hist(bins=5, edgecolor='white', title='频数直方图')
x.plot.box(title='箱线图')
plt.show()

### 2.2 数据的透视分析（★★★）

![透视分析：分组、透视表与列联表](/dm/dm-pivot.svg)

#### 2.2.1 三种工具对照

| 工具 | 输入 | 输出 | 关键参数 |
| --- | --- | --- | --- |
| `groupby(键).agg(函数)` | 一个/多个分组键 | 分组汇总表 | `agg(['mean','std','count'])` |
| `pivot_table()` | 行维 + 列维 + 值 | 二维交叉表 | `index / columns / values / aggfunc / margins` |
| `crosstab()` | 两个分类变量 | 频数 / 比例列联表 | `normalize / margins` |

```python
import pandas as pd
df = pd.DataFrame({
    '姓名': ['李勇','刘晨','王敏','张立'],
    '性别': ['男','女','女','男'],
    '专业': ['CS','CS','MA','IS'],
    '身高': [178,165,170,172],
    '成绩': [92,85,78,65]})

# ① 分组聚合：按专业统计人数、平均身高、平均成绩
g = df.groupby('专业').agg(人数=('姓名','count'),
                           平均身高=('身高','mean'),
                           平均成绩=('成绩','mean'))
print(g)
#     人数  平均身高  平均成绩
# CS   2   171.5    88.5
# IS   1   172.0    65.0
# MA   1   170.0    78.0

# ② 透视表：性别 × 专业 的平均成绩
pt = pd.pivot_table(df, index='性别', columns='专业',
                    values='成绩', aggfunc='mean', margins=True,
                    margins_name='合计')
print(pt)

# ③ 列联表：性别 × 专业 的人数与行百分比
print(pd.crosstab(df['性别'], df['专业']))
print(pd.crosstab(df['性别'], df['专业'], normalize='index').round(2))
```

::: tip 工作例题 · 读结果
`groupby('专业')` 中 CS 有 2 人，身高 (178+165)/2 = **171.5**，成绩 (92+85)/2 = **88.5**；MA、IS 各 1 人，均值即其本身。`pivot_table` 的 `margins=True` 会额外生成「合计」行列（按整体 aggfunc 计算，而不是简单把格内均值再平均）。
:::

::: danger 易错 · 透视分析
- `df.groupby('专业')` 返回的是 **GroupBy 中间对象**，不接聚合函数不会输出表格——这是初学者最常踩的坑。
- `pivot_table` 默认 `aggfunc='mean'`；若行/列组合有重复，会自动聚合，而 `pivot` **不允许重复索引组合**（会报错），需先聚合。
- `count` 不计 NaN、`size` 计所有行（含 NaN），分组人数统计别用错。
- `crosstab(normalize='index')` 是按**行**归一（每行和为 1）；`normalize='columns'` 按列；`normalize='all'` 按全体。
:::

::: tip 多层索引与重塑
多个分组键会产生 MultiIndex，用 `unstack()` 把某层索引转成列、`stack()` 反向；`reset_index()` 把索引变回普通列便于导出。宽表转长表用 `melt()`，常与 `seaborn` 分组绘图配合。
:::

::: tip 数据预处理三板斧：缺失、编码、标准化
- **缺失值**：`dropna()` 删除（缺失少且非 MNAR 时）、`fillna(均值/中位数/众数)`、`interpolate()`（时序插值）、或建缺失指示列；填补必须在训练集内拟合（见 4.8 节数据泄露）。
- **分类变量编码**：定类变量用**独热编码** `pd.get_dummies()` / `OneHotEncoder`（无序，避免引入虚假大小）；有序等级可用标签编码 `map` 成 1,2,3…；高基数类别可考虑目标编码（防泄露须交叉拟合）。
- **标准化/归一化**：`StandardScaler`（z 分数，PCA/回归/距离计算前必做）与 `MinMaxScaler`（0–1 区间，对异常值敏感）；树模型（决策树、随机森林、GBDT）**不需要**标准化。
:::

## 第 3 章 简单数据的统计分析（★★★）

本章从「描述」跨到「**推断**」：先给随机变量与分布，再用蒙特卡罗模拟理解随机性，最后落在单变量检验与一元线性回归。

### 3.1 随机变量及其分布

![常见分布与随机模拟](/dm/dm-distribution.svg)

#### 3.1.1 常见分布速查

| 分布 | 参数 | E(X) | Var(X) | 典型用途 |
| --- | --- | --- | --- | --- |
| 正态 N(μ,σ²) | μ, σ² | μ | σ² | 测量误差、连续变量 |
| 标准正态 N(0,1) | — | 0 | 1 | Z 检验、置信区间 |
| t(n) | 自由度 n | 0 (n&gt;1) | n/(n−2) (n&gt;2) | 小样本、σ 未知 |
| χ²(k) | 自由度 k | k | 2k | 方差检验、拟合优度 |
| F(d₁,d₂) | 两个自由度 | d₂/(d₂−2) | — | 方差分析、回归整体检验 |
| 二项 B(n,p) | n, p | np | np(1−p) | n 次独立试验成功次数 |
| 泊松 P(λ) | λ | λ | λ | 单位时间稀有事件计数 |
| 均匀 U(a,b) | a, b | (a+b)/2 | (b−a)²/12 | 随机数生成基础 |
| 指数 Exp(λ) | λ | 1/λ | 1/λ² | 等待时间、寿命 |

```python
import numpy as np
rng = np.random.default_rng(42)          # 现代推荐写法（替代 np.random.seed）
print(rng.integers(1, 100, size=5))      # 整数随机数
print(rng.uniform(0, 1, size=5))         # 均匀分布
print(rng.normal(0, 1, size=5))          # 标准正态
print(rng.binomial(n=10, p=0.3, size=5)) # 二项；E=np=3, Var=np(1-p)=2.1
print(rng.poisson(lam=2, size=5))        # 泊松；E=Var=2
```

::: danger 易错 · 分布与极限定理
- **中心极限定理**说的是「样本**均值**的分布近似正态」，不是「总体变成正态」；总体可以严重偏态。
- t 分布比正态**尾部更厚**，自由度越小越明显；n→∞ 时 t 趋近标准正态。
- 泊松分布的均值 = 方差 = λ，若实际数据方差远大于均值（过度离散），应考虑负二项模型。
- χ² 与 F 分布只取非负值，检验是**单侧**的（拒绝域在右尾）。
:::

### 3.2 随机模拟及其应用（蒙特卡罗）

**蒙特卡罗（Monte Carlo）模拟**：以概率统计理论为基础，用大量随机抽样近似求解难以解析计算的问题。四步：① 建立概率模型 → ② 按分布生成随机数 → ③ 重复 N 次试验 → ④ 用频率近似概率 / 用样本均值近似期望。理论依据是**大数定律**（频率收敛于概率）与中心极限定理（误差约 O(1/√N)）。

```python
import numpy as np
rng = np.random.default_rng(42)
N = 100_000
pts = rng.uniform(0, 1, size=(N, 2))          # [0,1]² 内均匀投点
inside = np.sum(pts[:, 0]**2 + pts[:, 1]**2 <= 1)
pi_hat = 4 * inside / N
print(f'π ≈ {pi_hat:.4f}, 绝对误差 {abs(pi_hat - np.pi):.4f}')
```

::: tip 工作例题 · 投针估算 π
单位正方形内四分之一圆面积占比 = π/4，故 π ≈ 4×(落入圆内点数/N)。以 seed=42、N=100000 的古典伪随机数实算约 **3.1373**（误差约 0.004）；把 N 提高 100 倍，误差约缩小 10 倍，这正是 O(1/√N) 收敛速度。
:::

::: tip 模拟的常见用途
估计复杂积分与概率、检验统计量的抽样分布、评估模型在极端情形下的风险（压力测试）、Bootstrap 重抽样估计置信区间。工程上应尽量**向量化**（一次生成 N×k 数组）而不是 Python 循环，速度可差几十倍。
:::

::: danger 易错 · 随机模拟
- `np.random.seed()` 只保证**可复现**，不改变分布，也不让结果「更准确」。
- 模拟精度由 N 与方差决定，不是由「随机种子好坏」决定；报告结果时应给标准误或重复次数。
- 默认随机数是**伪随机**；密码学场景须用 `secrets` 模块，不能用于此。
:::

### 3.3 单变量统计分析模型

![假设检验与一元线性回归](/dm/dm-inference.svg)

#### 3.3.1 假设检验六步与两类错误

| 步骤 | 内容 |
| --- | --- |
| ① | 提出原假设 H₀ 与备择假设 H₁（H₀ 通常含等号） |
| ② | 选择检验统计量并明确其抽样分布 |
| ③ | 给定显著性水平 α（常用 0.05、0.01） |
| ④ | 由样本计算统计量与 p 值 |
| ⑤ | p ≤ α 则拒绝 H₀，否则「不拒绝」 |
| ⑥ | 结合业务含义解释（统计显著 ≠ 实际重要） |

| 真实情况 \ 决策 | 不拒绝 H₀ | 拒绝 H₀ |
| --- | --- | --- |
| H₀ 为真 | 正确 (1−α) | **第一类错误**（概率 α） |
| H₀ 为假 | **第二类错误**（概率 β） | 正确（功效 1−β） |

```python
import math
n, xbar, s, mu0 = 16, 52, 4, 50
t = (xbar - mu0) / (s / math.sqrt(n))
se = s / math.sqrt(n)
tcrit = 2.131          # t_{0.025}(15) 查表值
print(f't = {t:.2f}, df = {n-1}, 临界值 = {tcrit}')
print(f'95% CI = [{xbar - tcrit*se:.3f}, {xbar + tcrit*se:.3f}]')
# t = 2.00, df = 15, 临界值 = 2.131
# 95% CI = [49.869, 54.131]
```

::: tip 工作例题 · 单样本 t 检验
n=16，x̄=52，s=4，检验 H₀: μ=50（α=0.05，双侧）。
t = (52−50)/(4/√16) = **2.00**，df=15，临界值 t₀.₀₂₅(15)=**2.131**。
因 |t| &lt; 2.131（p &gt; 0.05）→ **不拒绝 H₀**；95% 置信区间 **[49.869, 54.131]** 包含 50，结论一致。
:::

::: danger 易错 · p 值
- p 值是「**在 H₀ 成立的前提下，观察到当前或更极端样本的概率**」，不是「H₀ 为真的概率」。
- 「不拒绝 H₀」≠「证明 H₀ 成立」，可能只是样本量不足（功效低）。
- 增大样本量会让微小差异也变得「显著」，因此必须同时报告**效应量**与置信区间。
- σ 已知用 Z 检验，σ 未知用 t 检验；大样本时两者数值接近但概念不同。
:::

::: tip 常见检验方法的选择
| 场景 | 方法 | scipy 函数 |
| --- | --- | --- |
| 单样本均值（σ 未知） | 单样本 t 检验 | `scipy.stats.ttest_1samp` |
| 两独立组均值 | 独立样本 t 检验（先做方差齐性 Levene 检验，不齐用 Welch 校正） | `ttest_ind(equal_var=False)` |
| 同一对象前后测量 | **配对** t 检验 | `ttest_rel` |
| 三组及以上均值 | 单因素方差分析 ANOVA（事后两两比较用 Tukey HSD） | `f_oneway` |
| 正态性 | Shapiro-Wilk（小样本）/ K-S | `shapiro` |
| 不满足正态的秩替代 | Mann-Whitney U / Wilcoxon 符号秩 / Kruskal-Wallis | `mannwhitneyu` 等 |
| 两个分类变量独立性 | χ² 独立性检验（期望频数 < 5 的格子多时用 Fisher 精确检验） | `chi2_contingency` |
记忆链条：先看变量类型（连续→t/ANOVA，分类→χ²），再看是否满足正态与方差齐性，不满足换非参数方法。
:::

#### 3.3.2 单变量（一元）线性回归模型与预测

模型 `y = β₀ + β₁x + ε`，最小二乘解：

```text
β̂₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)² = Sxy / Sxx
β̂₀ = ȳ − β̂₁·x̄
ŷᵢ  = β̂₀ + β̂₁xᵢ ;  eᵢ = yᵢ − ŷᵢ
R²  = 1 − SSE/SST = SSR/SST
```

```python
import numpy as np
x = np.array([1, 2, 3, 4, 5], dtype=float)
y = np.array([2, 4, 5, 7, 9], dtype=float)
Sxx = ((x - x.mean())**2).sum()
Sxy = ((x - x.mean()) * (y - y.mean())).sum()
b1, b0 = Sxy / Sxx, y.mean() - (Sxy / Sxx) * x.mean()
fit = b0 + b1 * x
SSE = ((y - fit)**2).sum()
SST = ((y - y.mean())**2).sum()
print(f'Sxx={Sxx:.0f} Sxy={Sxy:.0f} β̂1={b1:.1f} β̂0={b0:.1f}')
print(f'SSE={SSE:.2f} SST={SST:.2f} R²={1-SSE/SST:.6f}')
print('拟合值', fit, ' x=6 预测', b0 + b1*6)
# Sxx=10 Sxy=17 β̂1=1.7 β̂0=0.3
# SSE=0.30 SST=29.20 R²=0.989726
# 拟合值 [2.0 3.7 5.4 7.1 8.8]  x=6 预测 10.5
```

::: tip 工作例题 · 完整手算
x=[1,2,3,4,5]、y=[2,4,5,7,9]：x̄=3、ȳ=5.4，Sxx=10、Sxy=17 → **β̂₁=1.7、β̂₀=0.3**，即 ŷ=0.3+1.7x。
拟合值 [2.0, 3.7, 5.4, 7.1, 8.8]、残差 [0, 0.3, −0.4, −0.1, 0.2]；
SSE=0.30、SST=29.20 → **R²=0.989726**；se(β̂₁)=√(0.30/3/10)=0.1 → **t=17**（极显著）。
x=6 时 ŷ=**10.5**，但已超出样本范围，属**外推**，需谨慎。
:::

```python
# statsmodels 写法（给完整推断表）
import statsmodels.formula.api as smf
import pandas as pd
df = pd.DataFrame({'x': x, 'y': y})
fm = smf.ols('y ~ x', data=df).fit()
print(fm.summary())                       # 系数、标准误、t、p、R²、F、置信区间
print(fm.predict(pd.DataFrame({'x': [6, 7]})))   # 对新数据预测
```

::: danger 易错 · 一元回归
- 回归显著 ≠ 存在因果；可能存在共同原因、反向因果或纯偶然相关。
- R² 高不代表模型前提成立：仍须看残差图（非线性、异方差）、Q-Q 图（正态性）、异常点。
- `predict()` 要求传入 **DataFrame 且列名与公式中的自变量一致**，传数组或列名不符会报错。
- 区分「均值的置信区间」与「单个新观测的预测区间」，后者更宽。
:::

### 3.4 抽样分布、标准误与中心极限定理

`describe()` 与 t 检验的背后是**抽样分布**理论。区分三个概念：

| 概念 | 含义 | 记号 |
| --- | --- | --- |
| 总体分布 | 全体个体的取值分布 | X ~ (μ, σ²) |
| 样本分布 | 一次抽样的 n 个观测的直方图 | 近似总体形状 |
| 抽样分布 | 统计量（如 x̄）在反复抽样下的分布 | x̄ ~ N(μ, σ²/n) |

**标准误** `SE = σ/√n`（σ 未知时用 s 估计）。中心极限定理保证 n 足够大时 x̄ 近似正态，与总体分布形状无关；这就是 t 检验/置信区间的理论依据。

::: tip 工作例题 · 标准误与样本量
总体 σ=10、n=25 → SE = 10/5 = **2**；若 n 提高到 100 → SE = **1**，精度提升 2 倍。要把标准误减半，样本量须**翻 4 倍**（SE ∝ 1/√n），这是样本量估算的核心权衡。
:::

### 3.5 检验功效、效应量与样本量

`功效 = 1 − β = P(拒绝 H₀ | H₀ 为假)`。影响功效的四要素：α 越大、真实效应 θ 越大、标准误越小（n 越大）、单侧检验 → 功效越高。

```python
import math
Phi = lambda z: 0.5 * (1 + math.erf(z / math.sqrt(2)))
z_crit, theta, se = 1.96, 2.0, 1.0
power = 1 - Phi((z_crit - theta)/se) + Phi((-z_crit - theta)/se)
print(round(power, 4))          # 0.516
```

::: tip 工作例题 · 功效
α=0.05 双侧（临界值 1.96），真实效应 θ=2、se=1 → 功效 ≈ **0.516**，即约有一半概率漏检（第二类错误 β≈0.484）。要达到常用 0.8 的功效，须增大 n（降低 se）或接受更大 α。这解释了「p &gt; 0.05」不能直接下「无效应」结论。
:::

::: tip 效应量
`Cohen's d = (x̄ − μ₀)/s` 衡量差异**大小**，不受 n 影响；置信区间同时给出方向与精度。论文与考试都应「p 值 + 效应量 + 置信区间」三者一起报告。
:::

## 第 4 章 多元数据的综合分析（★★★，全书最重）

本章方法最密集，四条主线：**相关分析 → 多元回归 → 综合评价 → 降维与聚类**。前两条处理「变量间关系」，后两条处理「多指标压缩与分组」。

### 4.1 多元线性相关与回归分析

#### 4.1.1 多元相关分析

![多元相关分析与散点图判读](/dm/dm-correlation.svg)

协方差 `Cov(X,Y)=Σ(xᵢ−x̄)(yᵢ−ȳ)/(n−1)` 带量纲、无法横向比较，故标准化为 **Pearson 相关系数**：

```text
r = Cov(X,Y) / (sₓ·sᵧ) = Σ(xᵢ−x̄)(yᵢ−ȳ) / √[Σ(xᵢ−x̄)²·Σ(yᵢ−ȳ)²]
取值范围 [−1, 1]；|r| 越大线性相关越强
检验 H₀: ρ=0 用 t = r·√((n−2)/(1−r²))，df = n−2
```

```python
import pandas as pd, numpy as np, math
df = pd.DataFrame({'身高': [178,165,170,172,180],
                   '体重': [72,50,58,65,78],
                   '成绩': [92,85,78,65,88]})
R = df.corr(method='pearson')            # 相关矩阵（对称，对角为 1）
print(R.round(3))
print(df['身高'].corr(df['体重']))

# 相关系数的显著性检验
n, r = 20, 0.6
t = r * math.sqrt((n - 2) / (1 - r*r))
print(f't = {t:.3f}, df = {n-2}')        # t = 3.182, df = 18
# t0.025(18) = 2.101 → |t| > 2.101，拒绝 H₀: ρ=0，相关显著
```

::: tip 工作例题 · 相关系数检验
n=20、r=0.6 → t = 0.6×√(18/0.64) = 0.6×5.3033 = **3.182**，df=18，临界值 2.101 → **相关显著**。
注意：显著性强烈依赖 n——n=10 时同样的 r=0.6 得 t=0.6×√(8/0.64)=2.121，df=8 临界值 2.306，就不显著了。
:::

| r 的绝对值 | 常用描述 | 注意事项 |
| --- | --- | --- |
| 0.00–0.30 | 弱相关 | 大样本下也可能「统计显著」 |
| 0.30–0.70 | 中等相关 | 结合散点图判断 |
| 0.70–1.00 | 强相关 | 变量间高度共线时回归不稳 |

::: danger 易错 · 相关分析
- **相关 ≠ 因果**：共同原因（如「季节」同时影响冰淇淋销量与溺水数）、反向因果、纯偶然都会产生高相关。
- `r=0` 只说明**无线性**相关，U 形等非线性关系可完全存在（务必先画散点图）。
- 异常点会大幅拉高或拉低 r；定序变量或单调非线性关系应用 **Spearman / Kendall 秩相关**。
- 相关矩阵中多个 r 各自显著，也不代表整体模型可用；自变量间高相关会造成多重共线性。
:::

::: tip 多重共线性诊断
`VIFⱼ = 1/(1−Rⱼ²)`，其中 Rⱼ² 是用其余自变量回归 Xⱼ 的决定系数。经验阈值：VIF &gt; 5 需警惕，VIF &gt; 10 视为严重。例：某自变量与其他变量的相关达 0.95 → VIF≈**10.26**；r=0.9 → VIF≈**5.26**。处理方式：剔除冗余变量、增大样本、岭回归 / 主成分回归。
:::

#### 4.1.2 多元线性回归：估计、检验与评判

![多元线性回归估计、检验与评判](/dm/dm-multireg.svg)

**矩阵形式**：`Y = Xβ + ε`（X 首列为常数列，n×(k+1)），最小二乘解 `β̂ = (XᵀX)⁻¹XᵀY`，拟合值 `Ŷ = Xβ̂`，残差 `e = Y − Ŷ`。前提假设：线性、误差零均值且同方差、无自相关、自变量无完全共线；正态性主要用于小样本推断。

```python
import numpy as np
X = np.column_stack([np.ones(5), [1,2,3,4,5], [2,1,4,3,5]])
Y = np.array([2, 4, 5, 7, 9], dtype=float)
beta = np.linalg.solve(X.T @ X, X.T @ Y)     # 比直接求逆更数值稳定
fit = X @ beta
SSE = ((Y - fit)**2).sum()
SST = ((Y - Y.mean())**2).sum()
R2 = 1 - SSE/SST
n, k = X.shape[0], X.shape[1] - 1
adj_R2 = 1 - (1 - R2) * (n - 1) / (n - k - 1)
F = (R2 / k) / ((1 - R2) / (n - k - 1))
print('β̂', beta.round(3), 'R²', round(R2, 4), '调整R²', round(adj_R2, 4), 'F', round(F, 3))
```

**三层检验**：

| 层次 | 假设 | 统计量 | 判定 |
| --- | --- | --- | --- |
| 整体显著 | H₀: β₁=…=βₖ=0 | `F = (SSR/k) / (SSE/(n−k−1))` ~ F(k, n−k−1) | F 大 / p 小 → 模型整体有用 |
| 单个系数 | H₀: βⱼ=0 | `t = β̂ⱼ / se(β̂ⱼ)`，df=n−k−1 | 逐个判断变量必要性 |
| 拟合优度 | — | R²、调整 R²、AIC/BIC、残差标准误 | 越接近 1（或越小）越好 |

::: tip 工作例题 · 数值演算（n=30, k=3, R²=0.86）
- 调整 R² = 1 − (1−0.86)×(29/26) = 1 − 0.15615 = **0.8438**；
- 整体 F = (0.86/3)/(0.14/26) = 0.28667/0.0053846 ≈ **53.24**（远大于临界值，模型整体显著）；
- 若约束 q=2 个系数后受限模型 R²=0.62，则 F = [(0.86−0.62)/2]/(0.14/26) = 0.12/0.0053846 ≈ **22.29**，拒绝约束。
:::

```python
# statsmodels 完整回归表（推荐写法）
import statsmodels.formula.api as smf
import pandas as pd
df = pd.DataFrame({'y': Y, 'x1': X[:, 1], 'x2': X[:, 2]})
m = smf.ols('y ~ x1 + x2', data=df).fit()
print(m.summary())          # coef / std err / t / P>|t| / [0.025, 0.975]
print('R²', m.rsquared, '调整R²', m.rsquared_adj, 'F', m.fvalue, 'AIC', m.aic, 'BIC', m.bic)
```

::: danger 易错 · 多元回归
- **增加变量 R² 一定不降**，故比较不同变量数的模型必须看**调整 R² / AIC / BIC**，不能只看 R²。
- F 显著但个别 t 不显著 → 常见原因是多重共线性（系数方差被放大），不是「变量一定无用」。
- `np.linalg.inv(X.T@X)` 在共线时会奇异/数值不稳，工程上用 `lstsq` 或 `solve`。
- 残差诊断四项：残差-拟合图（非线性/异方差）、Q-Q 图（正态性）、DW（自相关）、Cook 距离（强影响点）。
- 预测区间宽于置信区间；**外推**（超出样本自变量范围）风险高。
:::

### 4.2 综合评价指标体系（★★★）

![综合评价指标体系与权重确定](/dm/dm-evaluation.svg)

#### 4.2.1 指标体系构建与无量纲化

构建原则：**目的性、全面性、可测性、独立性、层次性**（目标层 → 准则层 → 指标层）。核心难点是把不同量纲、不同方向的指标变成可加的分数。

```text
正向指标（越大越好）：z = (x − min) / (max − min)
负向指标（越小越好）：z = (max − x) / (max − min)
标准分数法：          z = (x − x̄) / s
适度指标（越接近某值越好）：z = 1 − |x − x*| / max|x − x*|
```

::: danger 易错 · 指标方向
把「成本」「污染」「失业率」等**逆向指标**未正向化就直接加权，方向反了结论必错。正向化后再标准化，且全体样本必须使用**同一套 min/max 参数**，不能用各自分组的极值。
:::

#### 4.2.2 权重确定：主观法与客观法

| 方法 | 类型 | 做法 | 优点 / 局限 |
| --- | --- | --- | --- |
| 德尔菲法 | 主观 | 多轮匿名专家打分、反馈直至收敛，用均值/中位数定权 | 能纳入经验；耗时、主观 |
| 层次分析法 AHP | 主观 | 1–9 标度建判断矩阵，求 λmax 与特征向量 | 结构清晰；须通过一致性检验 |
| 变异系数法 | 客观 | `CVⱼ = sⱼ/x̄ⱼ`，`wⱼ = CVⱼ/ΣCVⱼ` | 区分度大的指标权重大；依赖样本 |
| 熵权法 | 客观 | 信息熵越小（离散度越大）权重越大 | 完全由数据驱动 |
| CRITIC | 客观 | 对比强度（标准差）× 冲突性（1−相关系数） | 兼顾信息量与独立性 |
| 组合赋权 | 混合 | 主客观权重线性/乘法合成 | 平衡专家经验与数据 |

```python
import numpy as np
# ① 变异系数法
Z = np.array([[0.8, 0.6, 0.4],      # 3 个对象、3 个（已正向化）指标
              [0.5, 0.9, 0.7],
              [0.2, 0.3, 1.0]])
cv = Z.std(axis=0, ddof=1) / Z.mean(axis=0)
w = cv / cv.sum()
print('变异系数', cv.round(3), '权重', w.round(3))

# ② AHP 一致性检验
RI = {1:0, 2:0, 3:0.58, 4:0.90, 5:1.12, 6:1.24, 7:1.32, 8:1.41, 9:1.45}
A = np.array([[1, 3, 5], [1/3, 1, 3], [1/5, 1/3, 1]], dtype=float)
lam = np.linalg.eigvals(A).real.max()
n = A.shape[0]
CI = (lam - n) / (n - 1)
CR = CI / RI[n]
print(f'λmax={lam:.4f}, CI={CI:.4f}, CR={CR:.4f}', '通过一致性检验' if CR < 0.1 else '需重调判断矩阵')
```

::: tip AHP 判定规则
`CI = (λmax − n)/(n−1)`，`CR = CI/RI(n)`。仅当 **CR &lt; 0.1** 时判断矩阵一致性可接受，权重才可用；否则须重新调整两两比较标度。RI 查表：n=3→0.58、4→0.90、5→1.12。
:::

#### 4.2.3 两种综合评分法（工作例题）

```text
简单平均法（隐含等权）：S = (z₁ + z₂ + … + zₚ)/p
加权综合评分法：      S = Σ wⱼ·zⱼ
```

::: tip 工作例题
某单位三个指标标准化得分 z=(0.8, 0.6, 0.4)：
- 等权简单平均：S = 1.8/3 = **0.60**；
- 权重 w=(0.5, 0.3, 0.2)：S = 0.4 + 0.18 + 0.08 = **0.66**。
同一对象因权重不同而排名可能变化，故必须做**敏感性分析**并公开权重来源。
:::

::: tip TOPSIS 逼近理想解排序法
构造正理想解 Z⁺（各指标最优）与负理想解 Z⁻，计算每个对象到二者的加权欧氏距离 `D⁺, D⁻`，贴近度 `C = D⁻/(D⁺+D⁻)`，C 越大越优。相比加权求和，TOPSIS 利用了指标空间的距离信息，对「单项突出但其他项很差」的对象更敏感。完整算例见 4.5 节。
:::

### 4.3 主成分分析 PCA（★★★）

![主成分分析思想、推导与步骤](/dm/dm-pca.svg)

#### 4.3.1 基本思想与推导

把 p 个**彼此相关**的原始变量 `X₁,…,Xₚ` 作正交变换，得到互不相关的综合变量 `F₁,…,Fₚ`：

```text
Fⱼ = aⱼ₁X₁ + aⱼ₂X₂ + … + aⱼₚXₚ
约束：① Cov(Fᵢ, Fⱼ)=0 (i≠j)；② aⱼ 为单位向量；③ Var(F₁) ≥ Var(F₂) ≥ …
求解：对标准化后的相关矩阵 R 求特征值 λⱼ 与单位特征向量 aⱼ
      Var(Fⱼ)=λⱼ，且 Σλⱼ = p（标准化后）
方差贡献率 = λⱼ/Σλᵢ ；累计贡献率 = (λ₁+…+λₘ)/Σλᵢ
载荷 = aⱼᵢ·√λⱼ（用于解释主成分的实际含义）
```

**几何解释**：找到数据方差最大的方向作第一主轴，再在与已选轴正交的方向上依次找次大方差方向。降维即保留前 m 个主轴、丢弃方差小的方向。

#### 4.3.2 标准步骤

| 步 | 内容 | 常见坑 |
| --- | --- | --- |
| ① | 指标正向化 + **标准化** | 漏掉标准化，量纲大的变量独霸 F₁ |
| ② | 计算相关矩阵 R，做适用性检验 | 变量几乎不相关时 PCA 无意义（KMO / Bartlett） |
| ③ | 求特征值与特征向量 | 用相关矩阵还是协方差矩阵要一致 |
| ④ | 按累计贡献率（≥80%）或碎石图拐点定 m | 只看「&gt;1 特征值」准则在大 p 时不可靠 |
| ⑤ | 用载荷解释并命名主成分 | 载荷符号可整体翻转，解释看相对大小 |
| ⑥ | 计算主成分得分，做综合评价/回归/聚类 | 得分是标准化线性组合，勿与原量纲混用 |

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X = np.array([[178,72,92],[165,50,85],[170,58,78],[172,65,65],[180,78,88]], dtype=float)
Z = StandardScaler().fit_transform(X)             # ① 必须标准化
pca = PCA().fit(Z)
print('特征值(解释方差)', pca.explained_variance_.round(3))
print('贡献率', pca.explained_variance_ratio_.round(3))
print('累计贡献率', np.cumsum(pca.explained_variance_ratio_).round(3))
score = pca.transform(Z)[:, :2]                   # 前两个主成分得分
print('主成分得分\n', score.round(3))
```

::: tip 工作例题 · 贡献率手算
p=4 个变量，特征值 λ=(2.4, 0.9, 0.5, 0.2)，Σλ=4.0：
贡献率依次为 **60%、22.5%、12.5%、5%**；前两个累计 **82.5% ≥ 80%** → 取 m=2。
综合得分若按归一化权重：F = (60/82.5)F₁ + (22.5/82.5)F₂ = **0.727F₁ + 0.273F₂**；
若直接用贡献率加权则为 F = 0.60F₁ + 0.225F₂。两种写法须**明确说明**并前后一致。
:::

::: danger 易错 · PCA
- **必须先标准化**：否则量纲大（如「收入」以元计）的变量会主导第一主成分。
- 主成分保证「累计方差最大」，**不保证业务解释性**；必要时用因子分析 + 旋转（varimax）。
- PCA 是**无监督**降维（不利用标签），若目标是提升分类精度，可考虑 LDA（有监督）。
- 主成分个数 m 的选择会影响后续所有结论，须报告累计贡献率。
- 主成分之间互不相关，但**不等于相互独立**；也不意味着「原始变量不重要」。
:::

### 4.4 聚类分析方法（★★★）

![聚类：距离度量与系统聚类](/dm/dm-cluster.svg)

#### 4.4.1 概念与相似性度量

聚类是**无监督**学习：按「物以类聚」把样品分成若干类，使**类内相似、类间相异**。两大类统计量：

| 类别 | 度量 | 公式 / 说明 | 值域含义 |
| --- | --- | --- | --- |
| 距离（Q 型，样品间） | 欧氏 | `d = √Σ(xᵢ−yᵢ)²` | 越小越相似 |
| 距离 | 曼哈顿 | `d = Σ|xᵢ−yᵢ|` | 对异常值较稳健 |
| 距离 | 闵可夫斯基 | `d = (Σ|xᵢ−yᵢ|^p)^(1/p)` | p=1 曼哈顿、p=2 欧氏 |
| 距离 | 马氏 | `d = √[(x−y)ᵀ S⁻¹ (x−y)]` | 消除量纲与变量相关 |
| 相似系数（R 型，变量间） | 夹角余弦 | `cosθ = X·Y/(|X|·|Y|)` | 越大越相似 |
| 相似系数 | Pearson r | 线性相关程度 | 越大越相似 |

::: tip 工作例题 · 欧氏距离
点 (1,2) 与 (4,6)：d = √[(4−1)²+(6−2)²] = √(9+16) = **5**。
若两变量量纲不同（如身高 cm 与成绩 分），欧氏距离会被量纲大的变量支配 → 先标准化或改用马氏距离。
:::

#### 4.4.2 系统（层次）聚类

**基本思想**：开始时 n 个样品各自成类，每次把**距离最近**的两类合并，重算类间距离，直到全部并成一类，形成谱系图（树状图）；再由树的「跳跃高度」或业务需要决定最终分类数。

```python
import numpy as np
from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
from scipy.spatial.distance import pdist
from sklearn.preprocessing import StandardScaler

X = np.array([[1,1],[1,2],[2,1],[8,8],[8,9],[9,8]], dtype=float)
Z = StandardScaler().fit_transform(X)
D = pdist(Z, metric='euclidean')
for method in ['single', 'complete', 'average', 'ward']:
    L = linkage(D, method=method)
    labels = fcluster(L, t=2, criterion='maxclust')
    print(method, labels)
```

| 类间距离定义 | 定义 | 特点 |
| --- | --- | --- |
| 最短距离法 single | 两类**最近**样品的距离 | 易产生链式长条类 |
| 最长距离法 complete | 两类**最远**样品的距离 | 倾向紧凑、大小相近的类 |
| 类平均法 average | 两两样品平方距离的均值 | 折中、最常用 |
| 重心法 / 重心距离 | 两类重心（均值向量）间距离 | 可能出现距离非单调 |
| Ward 法 | 合并使类内离差平方和增量最小 | 偏球形类、常与 K-means 配合 |

::: danger 易错 · 系统聚类
- **贪心不可撤销**：一旦合并就不能再拆开，早期错误合并会累积影响。
- 必须先标准化；不同距离/连接方法可能给出**不同的类**，应结合业务解释并做稳定性检验。
- 谱系图只给「合并顺序与距离」，**分类数由人决定**，不存在自动的「正确答案」。
- 聚类无标签，**不能用准确率评价**；用轮廓系数、Calinski-Harabasz 等内部指标或业务可解释性。
:::

::: tip K-means 与 DBSCAN
**K-means**：先定 K 个初始质心 → 每个点归到最近质心 → 重算质心 → 迭代至收敛。适合大样本、球形簇，但对初始质心与异常值敏感；用肘部法/轮廓系数选 K，并多次初始化（`n_init`）。
**DBSCAN**：基于密度，自动识别任意形状簇并标记噪声点，无需预设 K，但对 `eps`、`min_samples` 参数敏感。
**轮廓系数** `s ∈ [−1, 1]`，越大表示类内紧、类间分得开。
:::

### 4.5 相关与回归的代数联系

**一元回归中，决定系数恰等于相关系数的平方**：

```text
R² = SSR/SST = Sxy²/(Sxx·Syy) = r²
```

::: tip 工作例题 · 验证
沿用 x=[1..5], y=[2,4,5,7,9]：Sxx=10、Syy=29.20、Sxy=17
→ r = 17/√(10×29.2) = 17/17.088 ≈ **0.99485**，r² = **0.989726**；
而 3.3.2 手算 R² = 1 − 0.30/29.20 = **0.989726**，两者完全一致。
这也说明：一元线性回归的 F 检验与相关系数 t 检验等价（F = t²）。
:::

::: danger 易错 · R² = r² 的适用条件
该等式**只在含截距的一元线性回归**成立；多元回归中没有「单个 r² = R²」的简单对应，过原点回归的 R² 定义也不同，不能混用。
:::

### 4.6 多重共线性的补救：岭回归与 Lasso

OLS 遇到严重共线时系数方差被放大、极不稳定。正则化在损失函数中加惩罚项：

```text
岭回归 (L2)：min Σ(y − Xβ)² + λ·Σβⱼ²     → 系数缩小但不为 0，稳住共线
Lasso  (L1)：min Σ(y − Xβ)² + λ·Σ|βⱼ|    → 部分系数恰为 0，可自动选变量
弹性网：L1 + L2 折中。λ 由交叉验证选；使用前必须标准化自变量。
```

```python
from sklearn.linear_model import Ridge, Lasso
from sklearn.preprocessing import StandardScaler
Z = StandardScaler().fit_transform(X)          # X 为自变量矩阵（不含常数列）
for lam in (0.1, 1.0, 10.0):
    m = Ridge(alpha=lam).fit(Z, Y)
    print(lam, m.coef_.round(3))
```

::: danger 易错 · 正则化
- 惩罚项**不含截距**；自变量必须先标准化，否则量纲不同会让惩罚不公平。
- 岭回归系数是有偏的（以偏差换方差），因此**不能再按普通 OLS 的 p 值解释**。
- 变量筛选后的显著性检验存在「选择性推断」问题，需额外处理。
:::

### 4.7 熵权法与 TOPSIS 完整计算

**熵权法**：先按列归一化 `pᵢⱼ = zᵢⱼ/Σᵢzᵢⱼ`，再算熵 `eⱼ = −Σᵢpᵢⱼ·ln(pᵢⱼ)/ln(n)`，差异系数 `gⱼ = 1 − eⱼ`，权重 `wⱼ = gⱼ/Σgⱼ`。熵越小（该指标取值越分散）权重越大。

::: tip 工作例题 · 两种客观赋权对照（3 对象 × 3 指标）
标准化矩阵 Z = [[0.8,0.6,0.4],[0.5,0.9,0.7],[0.2,0.3,1.0]]：
- **变异系数法**：CV = (0.6000, 0.5000, 0.4286) → 权重 **(0.3925, 0.3271, 0.2804)**；
- **熵权法**：e = (0.8830, 0.9206, 0.9424) → 差异系数 (0.1170, 0.0794, 0.0576) → 权重 **(0.4606, 0.3126, 0.2268)**。
两种方法都让「指标 1」权重最高，但数值不同 → 客观赋权也**不是唯一的**，须说明方法。
:::

**TOPSIS**：正理想解 Z⁺（各列最大）、负理想解 Z⁻（各列最小），加权距离 `D⁺ = √Σwⱼ(zⱼ−z⁺ⱼ)²`、`D⁻ = √Σwⱼ(zⱼ−z⁻ⱼ)²`，贴近度 `C = D⁻/(D⁺+D⁻)`。

::: tip 工作例题 · TOPSIS
Z = [[1.0,0.2],[0.6,0.8],[0.2,1.0]]、w=(0.5,0.5) → Z⁺=(1,1)、Z⁻=(0.2,0.2)：
对象 1：D⁺=D⁻=0.5657 → C=**0.500**；
对象 2：D⁺=0.3162、D⁻=0.5099 → C=**0.6172**；
对象 3：D⁺=D⁻=0.5657 → C=**0.500**。
排序 **2 &gt; 1 = 3**：TOPSIS 偏好「各项均衡」，单项极端但另一项很差的 1、3 反而落后——这正是它与简单加权求和的区别。
:::

### 4.8 交叉验证与数据泄露

模型评估的正确姿势取决于数据形态：

| 数据形态 | 正确切分 | 错误做法 |
| --- | --- | --- |
| 截面独立数据 | K 折随机交叉验证（`KFold`，可分层） | 在**全量数据**上先标准化/选特征再切分（泄露） |
| 时间序列 | 按时间前向切分（`TimeSeriesSplit`） | 随机打乱（用未来预测过去） |
| 分组数据（同一人多条） | `GroupKFold` | 同一人同时出现在训练与测试集 |

::: danger 易错 · 数据泄露
任何**用到全体数据统计量**的预处理（标准化、缺失值填补、PCA、特征选择）都必须在**训练集内拟合并应用到测试集**（sklearn 的 `Pipeline` 正是为此设计）。在时序问题上用随机 K 折会得到虚高的分数。
:::

## 第 5 章 时序数据的模型分析（★★★）

时间序列与截面数据的根本区别：**观测值按时间排列、彼此不独立**，因此不能直接套用普通回归，必须先处理平稳性与自相关。

### 5.1 时间序列的概念与预处理

![时间序列分析与 ARIMA 建模流程](/dm/dm-timeseries.svg)

#### 5.1.1 平稳性与白噪声

**严平稳**：任意时间平移后联合分布不变；**宽平稳**（实际常用）：均值恒定、方差恒定、自协方差只依赖滞后阶数 k 而与时间 t 无关。

```text
白噪声 uₜ：E(uₜ)=0, Var(uₜ)=σ², Cov(uₜ, uₛ)=0 (t≠s)，常记作 uₜ ~ N(0, σ²)
```

::: danger 易错 · 平稳性
- 「均值看起来不变」不等于平稳：方差随时间变化（如异方差、波动聚集）也是非平稳。
- **伪回归**：两条互不相关的非平稳序列（都有趋势）做回归常得到高 R² 与显著 t，但结论完全虚假。计量教材特别强调这一点，建模前必须先检验平稳性。
- 金融价格序列通常是**非平稳**的，但**收益率**（差分后）常近似平稳，这正是金融分析要先计算股票收益率的原因。
:::

```python
import numpy as np, pandas as pd
rng = np.random.default_rng(42)
n = 200
# 平稳 AR(1)：yₜ = 0.6·yₜ₋₁ + uₜ
y = np.zeros(n)
for t in range(1, n):
    y[t] = 0.6 * y[t-1] + rng.normal(0, 1)
# 非平稳随机游走：yₜ = yₜ₋₁ + uₜ（含单位根）
rw = np.cumsum(rng.normal(0, 1, n))
print('AR(1) 前后段均值', y[:100].mean().round(3), y[100:].mean().round(3))
print('随机游走前后段均值', rw[:100].mean().round(3), rw[100:].mean().round(3))

# 由价格算简单收益率与对数收益率
price = pd.Series([100, 102, 101, 105, 108, 107])
simple_ret = price.pct_change()
log_ret = np.log(price / price.shift(1))
print(simple_ret.round(4).tolist())
# [nan, 0.0200, -0.0098, 0.0396, 0.0286, -0.0093]
```

::: tip 工作例题 · 收益率
价格 100→102：简单收益率 2/100 = **0.0200**；102→101：(101−102)/102 ≈ **−0.0098**；
对数收益率 ln(101/102) ≈ −0.00985。对数收益率可跨期相加、近似对称，金融建模更常用。
:::

#### 5.1.2 差分与平稳化

```python
d1 = price.diff()                 # 一阶差分
d_log = np.log(price).diff()      # 对数一阶差分 ≈ 收益率
d2 = d1.diff()                    # 二阶差分（一般很少需要）
print('原序列', price.tolist(), '一阶差分', d1.tolist())
# 一阶差分 [nan, 2, -1, 4, 3, -1]
```

::: tip 过度差分
差分能消除趋势，但**过度差分**会人为引入负自相关、放大噪声。定 d 的原则：差分后 ADF 拒绝单位根且序列方差无明显趋势即可，通常 d=0 或 1，季节性强时再做季节差分 D=1。
:::

::: tip 时间序列的三大成分与分解
任何时序可视为三种成分的组合：**趋势（Trend）**长期上升/下降、**季节（Seasonal）**固定周期的重复波动、**残差（Residual）**去势去季节后的随机部分。组合方式有加法模型 `y = T + S + R`（季节幅度不随水平变化）与乘法模型 `y = T × S × R`（季节幅度随水平放大，常见于经济数据，可先取对数转为加法）。Python 用 `statsmodels.tsa.seasonal.seasonal_decompose(y, model='additive')`；分解图是判断 d 与季节差分 D 的第一步。另外**格兰杰因果检验**（`grangercausalitytests`）判断的是「X 的历史能否改进对 Y 的预测」，是**预测意义**上的因果，不是真实因果机制。
:::

### 5.2 时间序列分析模型

| 模型 | 表达式 | 适用 |
| --- | --- | --- |
| AR(p) 自回归 | `yₜ = φ₁yₜ₋₁ + … + φₚyₜ₋ₚ + uₜ` | 平稳，历史值影响当前 |
| MA(q) 移动平均 | `yₜ = uₜ + θ₁uₜ₋₁ + … + θ_q uₜ₋q` | 平稳，历史冲击影响当前 |
| ARMA(p,q) | AR + MA 组合 | **平稳**序列 |
| ARIMA(p,d,q) | 先 d 阶差分，再对差分序列建 ARMA | 非平稳但可差分平稳 |
| SARIMA | 再加季节项 (P,D,Q,s) | 有季节周期 |

```text
ARIMA(p,d,q)：p=自回归阶数，d=差分次数，q=移动平均阶数
Box-Jenkins 方法：识别 → 估计 → 诊断 → 预测，四步循环
```

::: danger 易错 · 模型记号
`ARIMA(p,d,q)` 中的 **d 是差分阶数**，不是「因变量个数」；`ARIMA(1,1,1)` 表示对原序列做 1 阶差分后建 ARMA(1,1)。部分资料把 q 误印为 `g`（如 `ARIMA(p,d,g)`），那是排版错误，统一以 `ARIMA(p,d,q)` 为准。
:::

### 5.3 ARMA 模型的构建

#### 5.3.1 相关性检验：ACF 与 PACF

- **ACF（自相关函数）**：`ρₖ = Cov(yₜ, yₜ₋ₖ)/Var(yₜ)`，衡量 yₜ 与 yₜ₋ₖ 的直接 + 间接相关。
- **PACF（偏自相关函数）**：剔除中间变量 yₜ₋₁,…,yₜ₋ₖ₊₁ 影响后 yₜ 与 yₜ₋ₖ 的**净相关**。

| 模型 | ACF | PACF | 定阶 |
| --- | --- | --- | --- |
| AR(p) | 拖尾（指数/振荡衰减） | **p 阶截尾** | p = PACF 截尾阶 |
| MA(q) | **q 阶截尾** | 拖尾 | q = ACF 截尾阶 |
| ARMA(p,q) | 拖尾 | 拖尾 | 用 AIC/BIC 网格搜索 |

```python
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import matplotlib.pyplot as plt
fig, axes = plt.subplots(1, 2, figsize=(10, 3))
plot_acf(y, lags=20, ax=axes[0], alpha=0.05)     # 阴影为 95% 置信带
plot_pacf(y, lags=20, ax=axes[1], alpha=0.05)
plt.show()
```

::: tip 判读要点
「**截尾**」指超过某阶后相关系数落进置信带（与 0 无显著差异）；「**拖尾**」指缓慢衰减、多阶仍显著。截尾阶数即模型阶数；两者都拖尾时不要硬猜，交给 AIC/BIC 网格搜索。
:::

#### 5.3.2 平稳性检验：DF 与 ADF

**DF 检验**：对 `Δyₜ = γ·yₜ₋₁ + uₜ` 检验 H₀: γ=0（存在单位根、非平稳）。
**ADF（扩展 DF）**：在回归式中加入滞后差分项以消除残差自相关，并可能包含常数项/趋势项：

```text
Δyₜ = α + βt + γ·yₜ₋₁ + Σ δᵢ·Δyₜ₋ᵢ + uₜ
H₀: γ = 0（有单位根，非平稳）；H₁: γ < 0（平稳）
```

```python
from statsmodels.tsa.stattools import adfuller
for name, series in [('AR(1) 平稳', y), ('随机游走 非平稳', rw)]:
    stat, pval, lags, nobs, crit, icbest = adfuller(series, autolag='AIC')
    print(f'{name}: ADF={stat:.3f}, p={pval:.4f}, 1%临界={crit["1%"]:.3f}')
    print('  结论:', '拒绝单位根 → 平稳' if pval < 0.05 else '不拒绝单位根 → 非平稳，需差分')
```

::: danger 易错 · ADF
- **ADF 统计量不服从常规 t 分布**，临界值必须用 **MacKinnon 表**（`adfuller` 返回的 `crit`），不能拿 1.96 去比。
- 结论是「拒绝 / 不拒绝单位根」，不是「证明平稳」。
- 检验式是否含常数项、趋势项会改变临界值与结论；`autolag='AIC'` 自动选滞后阶。
- 结构性突变（如政策变更）会让 ADF 误判为有单位根，必要时用带断点的检验。
:::

#### 5.3.3 参数估计、定阶与残差诊断

```python
import warnings, itertools
from statsmodels.tsa.arima.model import ARIMA
warnings.filterwarnings('ignore')
best = None
for p, q in itertools.product(range(3), range(3)):
    try:
        m = ARIMA(y, order=(p, 0, q)).fit()
        if best is None or m.aic < best[0]:
            best = (m.aic, (p, 0, q), m.bic)
    except Exception:
        continue
print('最小 AIC 模型', best)
```

**定阶准则**：

```text
AIC = −2·ln(L) + 2k          （k 为待估参数个数）
BIC = −2·ln(L) + ln(n)·k    （n 为样本量，惩罚更重）
两者都是越小越好；BIC 倾向更简洁的模型，AIC 倾向预测更优的模型
```

::: tip 工作例题 · AIC 与 BIC 分歧
n=200，ln(n)≈5.298。模型 A：k=2、lnL=−120 → AIC=**244.00**、BIC=**250.60**；
模型 B：k=3、lnL=−118.5 → AIC=**243.00**、BIC=**252.89**。
AIC 选 B（243 &lt; 244），BIC 选 A（250.60 &lt; 252.89）——正体现「BIC 惩罚更重、偏好简约」。
:::

::: danger 易错 · 模型诊断
- 定阶后必须检验**残差是否为白噪声**（Ljung-Box：p &gt; 0.05 才合格）；残差仍有自相关说明信息没提干净，需重新定阶。
- 参数须显著且满足平稳/可逆条件（AR 根在单位圆外、MA 根在单位圆外）。
- AIC/BIC 只能在**同一数据、同一差分阶 d** 的模型间比较，跨不同 d 直接比 AIC 不严谨。
:::

### 5.4 模型的预测

```python
from statsmodels.tsa.arima.model import ARIMA
m = ARIMA(y, order=(1, 0, 0)).fit()
fc = m.get_forecast(steps=5)
print(fc.predicted_mean.round(3).tolist())
print(fc.conf_int().round(3))       # 预测区间随步长变宽
```

::: tip 预测区间的形状
ARIMA 的多步预测会随着步长增大**逐渐回归到序列均值**，且预测区间单调变宽——这是平稳模型的固有性质，不是模型「越算越不准」的 bug。长期预测应定期用新数据滚动重估（rolling forecast）。
:::

::: tip 时序预测的现代方法
指数平滑 / Holt-Winters（趋势+季节）、SARIMA、GARCH（建模波动率聚集）、Prophet（节假日与趋势分解）、LSTM/Transformer（非线性）、以及针对金融序列的「样本外滚动评估」。评估指标用 MAE/RMSE/MAPE，务必用**时间序列切分**（不能随机打乱做交叉验证，会泄露未来信息）。
:::

### 6.1 大数据的概念

### 6.2 字符串的基本操作

```python
s = 'Python数据挖掘,Python爬虫,数据挖掘'
print(len(s), s.count('Python'), s.count('数据'))      # 长度 / 子串计数
a, b = 'Python', '数据挖掘'
print(a + ' ' + b)                                    # + 连接
print('-'.join(['a', 'b', 'c']))                      # join 批量连接 → 'a-b-c'
print(s.split(','))                                   # 拆分 → ['Python数据挖掘','Python爬虫','数据挖掘']
print('Python' in s, s.find('爬虫'))                   # 查询：in / find（找不到返回 -1）
print(s.replace('Python', 'Java'))                    # 替换
print('  前后空格  '.strip())                          # 去首尾空白

import re
text = '房价 117.05平米，面积 72.27平米，总价 235万'
print(re.findall(r'\d+\.?\d*', text))                 # ['117.05', '72.27', '235']
print(re.sub(r'\s+', '', text))                       # 删除所有空白
```

| 操作 | 方法 | 易错点 |
| --- | --- | --- |
| 统计 | `len()`、`count()` | `count` 不重叠计数 |
| 连接 | `+`、`join()` | 循环用 `+` 拼字符串是 O(n²)，应改用 `join` |
| 拆分 | `split(sep)`、`rsplit` | 不传 sep 时按任意空白切分并丢弃空串 |
| 查询 | `in`、`find`、`index`、`startswith` | `find` 返回 −1，`index` 抛异常 |
| 替换 | `replace`、`re.sub` | `replace` 默认替换**全部**匹配 |
| 清洗 | `strip`、`lstrip`、`rstrip` | 只去首尾，不动中间 |

::: tip 正则表达式常用元字符
`\d` 数字、`\w` 单词字符、`\s` 空白、`.` 任意字符、`* + ?` 量词、`[]` 字符集、`()` 分组捕获、`^ $` 锚点。贪婪匹配用 `.*?` 转非贪婪。爬取网页时正则适合作**字段后处理**，结构性提取优先用 CSS 选择器 / XPath。
:::

### 6.3 网络爬虫

#### 6.3.1 HTML 结构与 CSS 选择器

网页是 DOM 树：标签（tag）+ 属性（class / id / href）+ 文本。CSS 选择器用于定位节点：

| 选择器 | 含义 | bs4 写法 |
| --- | --- | --- |
| `div` | 标签名 | `soup.select('div')` |
| `.price` | class = price | `soup.select('.price')` |
| `#main` | id = main | `soup.select('#main')` |
| `div .title` | 后代 | `soup.select('div .title')` |
| `a[href]` | 含属性 | `soup.select('a[href]')` |

#### 6.3.2 爬虫五步（链家二手房案例）

```python
import time, requests
from bs4 import BeautifulSoup
import pandas as pd

HEADERS = {'User-Agent': 'Mozilla/5.0 (compatible; DataMiningCourse/1.0)'}

def read_html(url):
    """把 requests + bs4 封装成 read_html()"""
    resp = requests.get(url, headers=HEADERS, timeout=10)
    resp.raise_for_status()
    resp.encoding = resp.apparent_encoding        # 避免中文乱码
    return BeautifulSoup(resp.text, 'html.parser')

def parse_page(soup):
    rows = []
    for li in soup.select('li.clear'):             # 房源列表项
        title = li.select_one('.title a')
        price = li.select_one('.totalPrice span')
        area  = li.select_one('.houseInfo')
        if title and price:
            rows.append({'标题': title.get_text(strip=True),
                         '总价': price.get_text(strip=True),
                         '信息': area.get_text(' ', strip=True) if area else ''})
    return rows

all_rows = []
for page in range(1, 4):                           # 批量翻页
    url = f'https://example.com/ershoufang/pg{page}/'   # 教学占位地址
    try:
        all_rows += parse_page(read_html(url))
    except requests.RequestException as e:
        print('第', page, '页失败：', e)
    time.sleep(1)                                  # 控制频率，礼貌爬取
df = pd.DataFrame(all_rows)
print(df.head(), df.shape)
```

::: tip 工作例题 · 从 HTML 文本提取结构化数值
网页字段中常见「117.05平米」「72.27平米」「10.977s」等文本，标准做法是先 `get_text` 再用正则抽取数字：
```python
import re
s = '3室2厅 | 117.05平米 | 南北 | 精装'
area = float(re.search(r'([\d.]+)平米', s).group(1))
print(area)          # 117.05
```
:::

::: danger 易错 · 爬虫合规
- 优先使用**官方 API / 公开数据集**；爬取前检查 `robots.txt` 与网站服务条款。
- 设置合理 `User-Agent`、请求间隔（`time.sleep`）与超时，不并发轰炸服务器；失败要重试且限制次数。
- 只采集**公开、非个人敏感**数据，不绕过登录/验证码/付费墙；注明数据来源与用途，尊重著作权与隐私法规。
- 网页结构会变，选择器要有容错（判空、try/except），并保存原始 HTML 便于复现。
:::

### 6.4 数据库技术与 SQLite

Python 通过统一的 **DB-API** 访问数据库：`connect() → cursor() → execute() → commit() → close()`。SQLite 是零配置的文件型数据库，适合教学与中小规模数据落地。

```python
import sqlite3, pandas as pd

conn = sqlite3.connect('house.db')                  # 文件不存在则自动创建
cur = conn.cursor()
cur.execute('''CREATE TABLE IF NOT EXISTS house (
                 id INTEGER PRIMARY KEY AUTOINCREMENT,
                 title TEXT NOT NULL,
                 total_price REAL,
                 area REAL)''')
# 参数化插入（? 占位符，防 SQL 注入、自动处理引号）
cur.executemany('INSERT INTO house (title, total_price, area) VALUES (?, ?, ?)',
                [('A 小区 3 室', 235.0, 117.05), ('B 小区 2 室', 168.0, 72.27)])
conn.commit()

df = pd.read_sql_query('SELECT * FROM house WHERE total_price >= ?',
                       conn, params=(200,))
print(df)
#    id      title  total_price    area
# 0   1  A 小区 3 室        235.0  117.05
conn.close()
```

::: tip 工作例题 · 读结果
插入 2 条记录后查询 `total_price &gt;= 200`，只有 235.0 那条满足 → 返回 1 行。注意 `CREATE TABLE IF NOT EXISTS` 保证脚本可重复运行；`executemany` 比循环 `execute` 更快。
:::

::: danger 易错 · 数据库操作
- **绝不要用字符串拼接 SQL**（`f"SELECT ... WHERE x='{v}'"`），会造成 SQL 注入；一律用 `?` 占位符 / 参数化。
- `INSERT/UPDATE/DELETE` 后必须 `commit()` 才真正写入；只读查询不需要。
- 忘记 `close()` 会导致文件锁与连接泄漏，推荐用 `with sqlite3.connect(...) as conn`。
- SQLite 是单机嵌入式数据库，不适合高并发写入；MySQL/PostgreSQL 需各自驱动，但 DB-API 调用方式一致。
:::

### 6.5 真正的大数据技术栈

存储：HDFS、对象存储（S3/OSS）、列式格式 Parquet/ORC、数据湖仓；
计算：MapReduce、Spark（内存迭代）、Flink（流批一体）；
查询：Hive / Presto / ClickHouse；NoSQL：HBase、MongoDB、Redis；
Python 侧：`pyspark`、`dask`、`polars`，以及 `pd.read_csv(..., chunksize=...)` 分块读取。
判断标准不是「文件多大」，而是「单机是否能在合理时间内完成」。

### 6.6 文本与爬虫数据的清洗流水线

```python
import re, pandas as pd
raw = [' 3室2厅 | 117.05平米 | 总价235万 ', '2室1厅 | 72.27平米 | 总价168万', None]
clean = []
for s in raw:
    if not s: continue
    s = re.sub(r'\s+', '', s)                       # 去空白
    parts = s.split('|')
    d = {'户型': parts[0]}
    d['面积'] = float(re.search(r'([\d.]+)平米', s).group(1))
    d['总价'] = float(re.search(r'总价([\d.]+)万', s).group(1))
    d['单价'] = round(d['总价'] * 10000 / d['面积'], 2)   # 派生指标
    clean.append(d)
print(pd.DataFrame(clean))
```

::: tip 工作例题 · 派生指标
第一条：117.05 平米、235 万 → 单价 = 2350000/117.05 ≈ **20076.89 元/平米**；
第二条：72.27 平米、168 万 → 单价 ≈ **23246.16 元/平米**。
清洗的价值往往体现在「派生指标」上：原始字段只有面积与总价，真正的分析对象是单价。缺失值（第三条 None）要显式跳过或标记，不能静默丢弃而不记录。
:::

::: danger 易错 · 清洗
`None`/`NaN` 参与正则会抛异常；单位（万/元、平米/亩）不统一会让数值差几个数量级；清洗必须保留原始列以便回溯与复现。
:::

### 7.1 文献计量学基本概念

**文献计量学**：用数学与统计学方法，定量地分析一切知识载体的分布结构、数量关系与变化规律，从而揭示某学科的发展脉络、研究热点与学术影响力。

| 数据源 | 特点 | 常见导出字段 |
| --- | --- | --- |
| Web of Science / Scopus | 外文、含参考文献与被引 | 作者、机构、关键词、摘要、参考文献、被引频次、基金 |
| CNKI / 万方 | 中文、含基金项目 | 题名、作者、单位、关键词、基金、期刊 |
| CNKI E-Study / CiteSpace / VOSviewer | 题录管理与可视化 | 标准化后的题录数据库 |

::: tip 文献计量三大经典定律
**洛特卡定律**（作者发文频次分布：写 n 篇论文的作者数约与 1/n² 成正比）、**布拉德福定律**（期刊文献集中与分散）、**齐普夫/普赖斯定律**（词频分布与核心作者/文献的老化）。
:::

### 7.2 文献数据的收集与分析

#### 7.2.1 分析流程

```text
① 确定检索式与数据库 → ② 导出题录（含参考文献） → ③ 去重与字段清洗
→ ④ 描述统计（年度、机构、基金、作者、关键词） → ⑤ 共现/共被引矩阵
→ ⑥ 知识图谱与聚类 → ⑦ 科研评价与前沿解读
```

```python
import pandas as pd
# 题录表（教学示意）：一篇文献一行
bib = pd.DataFrame({
    '年份': [2021, 2021, 2022, 2022, 2023],
    '单位': ['A 大学', 'A 大学', 'B 大学', 'A 大学', 'C 研究院'],
    '基金': ['国家自然科学基金', '省基金', '国家自然科学基金', '无', '国家自然科学基金'],
    '作者': ['张三;李四', '王五', '张三;赵六', '李四', '王五;赵六'],
    '关键词': ['数据挖掘;聚类', '爬虫;文本', '数据挖掘;PCA', '聚类;评价', '社会网络;中心性'],
    '被引': [25, 14, 9, 6, 5]})

print(bib['单位'].value_counts())
print(pd.crosstab(bib['年份'], bib['单位']))
print(bib.groupby('基金')['被引'].agg(['count', 'mean']).round(2))

# 拆分多值字段并统计词频（核心操作）
kw = bib['关键词'].str.split(';').explode().str.strip()
print(kw.value_counts())
```

::: tip 工作例题 · 词频统计
上面 5 条题录的关键词展开后：`数据挖掘` 2 次、`聚类` 2 次，其余各 1 次。多值字段必须先用 `str.split(';').explode()` 拆成一行一词，再 `value_counts()`；直接对原始字符串计数会把「数据挖掘;聚类」当成一个整体，结论失真。
:::

#### 7.2.2 三类统计

| 统计对象 | 做法 | 可回答的问题 |
| --- | --- | --- |
| 科研单位与基金 | 按单位/基金分组计数、算被引均值 | 谁在主导研究？哪类资助产出高？ |
| 作者 | 拆作者字段、统计发文与合著关系 | 核心作者群、合作网络 |
| 关键词 | 词频、共词矩阵、词云、突发词 | 研究热点与演化趋势 |

::: danger 易错 · 题录清洗
- **同一机构多种写法**（「A 大学」/「A 大学管理学院」/「A Univ.」）必须归并，否则机构排名严重失真。
- 作者重名、英文名缩写、关键词单复数/同义词都需规范化；否则共现矩阵被稀释。
- 导出时务必包含**参考文献字段**，否则无法做共被引与文献耦合分析。
:::

### 7.3 科研评价指标与知识图谱

#### 7.3.1 h 指数与常用指标

| 指标 | 定义 | 局限 |
| --- | --- | --- |
| h 指数 | 某作者有 **h 篇**论文每篇至少被引 **h 次**，且其余论文被引均不超过 h | 受学科、学术年限、自引、合作署名影响；不利于青年学者 |
| 总被引 / 篇均被引 | 影响力总量与平均质量 | 易被少数高被引论文拉高 |
| g 指数 | 前 g 篇累计被引 ≥ g² | 比 h 更重视顶尖论文 |
| 期刊影响因子 | 期刊前两年论文在当年的平均被引 | 不能用于评价单篇论文或单个作者 |
| FWCI / Altmetric | 学科归一化被引 / 社会关注度 | 需同领域同年份归一化 |

::: tip 工作例题 · h 指数手算
某作者 8 篇论文被引次数降序：**25, 14, 9, 6, 5, 3, 1, 0**。
逐位检查「第 i 篇被引 ≥ i」：i=1(25≥1) ✓ … i=5(5≥5) ✓，i=6(3 &lt; 6) ✗ → **h = 5**。
注意 h 指数不能跨学科直接比较，也不能单独作为人才评价依据。
:::

#### 7.3.2 共被引、耦合与知识图谱

| 关系 | 定义 | 用途 |
| --- | --- | --- |
| 共被引 | 两篇文献被**同一篇后续文献**同时引用 | 识别知识基础与研究流派 |
| 文献耦合 | 两篇文献**共同引用**了相同参考文献 | 识别当前研究前沿的关联 |
| 共词分析 | 两个关键词在**同一篇文献**共同出现 | 识别研究主题与热点结构 |
| 作者合作 / 机构合作 | 共同署名 | 识别科研协作网络 |

```python
# 共词矩阵（邻接矩阵思想，与第 8 章打通）
import itertools, collections
pairs = collections.Counter()
for kws in bib['关键词'].str.split(';'):
    ks = sorted({k.strip() for k in kws})
    for a, b in itertools.combinations(ks, 2):
        pairs[(a, b)] += 1
for pair, cnt in pairs.most_common(5):
    print(pair, cnt)
```

::: tip 常用工具与前沿
CiteSpace（突现词、时间线、共被引聚类）、VOSviewer（密度/叠加可视化）、bibliometrix（R 包，全流程）、`wordcloud` + `jieba`（中文词云）。评价指标之外，还应报告「研究前沿突现词」「国际合作率」等结构性结论，避免只堆计数。
:::

## 第 8 章 社会网络分析方法（★★）

![社会网络图、中心性与凝聚子群](/dm/dm-network.svg)

### 8.1 社会网络的初步印象

**社会网络分析（SNA）** 最早由社会学家基于**图论**与统计学发展，研究行动者之间的关系结构如何塑造信息流动、权力与群体行为。两大要素：

| 要素 | 图中表示 | 例子 |
| --- | --- | --- |
| 行动者 actor | **节点 node（V）** | 人、机构、论文、城市 |
| 关系 tie | **边 edge（E）** | 合作、引用、关注、资金往来 |

关系可有**方向**（有向图）、**强度**（加权图），也可以是二模网（如「作者—论文」两类节点）。

::: tip 与第 7 章的联系
文献计量里的「作者合作网络」「共被引网络」「共词网络」本质上都是社会网络，因此第 7 章产出共现矩阵后，第 8 章的中心性与社群发现可以直接复用——这是本书后半部分最重要的方法串联。
:::

### 8.2 网络的表示与构建

| 表示 | 形式 | 适用 |
| --- | --- | --- |
| 邻接矩阵 A | aᵢⱼ = 1（或权重）表示 i 与 j 相连；无向图对称 | 小规模稠密图、矩阵运算 |
| 边表 / 邻接表 | `(u, v, weight)` 逐条记录 | 大规模稀疏图（实际更常用） |
| networkx 图对象 | `G = nx.Graph()` / `nx.DiGraph()` | Python 建模与分析 |

```python
import networkx as nx
G = nx.Graph()
G.add_edges_from([('A','B'), ('A','C'), ('B','C'),
                  ('B','D'), ('C','E'), ('D','E')])
print('节点数', G.number_of_nodes(), '边数', G.number_of_edges())
print('密度', round(nx.density(G), 3))           # 0.6
print('各点度', dict(G.degree()))
print('直径', nx.diameter(G), '平均最短路径', round(nx.average_shortest_path_length(G), 3))
print('度中心性', {k: round(v,3) for k,v in nx.degree_centrality(G).items()})
print('介数中心性', {k: round(v,3) for k,v in nx.betweenness_centrality(G).items()})
print('接近中心性', {k: round(v,3) for k,v in nx.closeness_centrality(G).items()})
```

::: tip 工作例题 · 手算核对（左图，n=5）
边共 6 条：A-B、A-C、B-C、B-D、C-E、D-E。
度：A=2、B=3、C=3、D=2、E=2 → 总度数 12 = 2×边数 ✓；
无向完全图最多 5×4/2 = 10 条边 → **密度 = 6/10 = 0.6**；
标准化点度中心度 = 3/(5−1) = **0.75**（B、C 并列最高）；
B、C 是连接左簇 {A,B,C} 与右簇 {D,E} 的**桥节点**，故介数中心性最高。
:::

### 8.3 中心性与网络整体属性

| 层次 | 指标 | 含义 |
| --- | --- | --- |
| 个体 | 点度中心度 | 直接邻居数 / (n−1)，衡量「活跃度」 |
| 个体 | 接近中心度 | 到其他所有节点平均最短路径的倒数，衡量「信息效率」 |
| 个体 | 中介中心度 | 经过该节点的最短路径占比，衡量「桥梁 / 控制力」 |
| 个体 | 特征向量中心度 / PageRank | 「邻居也重要则更重要」，衡量声望 |
| 整体 | 密度 | 实际边数 / 可能边数，衡量连接紧密程度 |
| 整体 | 直径 | 任意两点间距离的最大值（最长最短路径） |
| 整体 | 平均路径长度、聚类系数 | 小世界效应判据 |
| 整体 | 凝聚子群 / 小团体 | 内部联系明显强于外部的子集 |

::: danger 易错 · 中心性
- **中心度必须标准化**才能跨不同规模的网络比较；原始「度」依赖 n。
- 有向图要区分**入度**（被关注、声望）与**出度**（主动联系），`nx.DiGraph()` 的 `degree_centrality` 语义与无向图不同。
- 介数中心性计算复杂度高，大图需近似算法；且它度量的是「控制信息流」，不等于「最重要」。
- 密度只适用于同一规模网络间比较；节点数变化会改变「可能边数」的分母。
:::

::: tip 社群发现算法
**模块度 Q** 衡量「社区内部边数相对随机连接期望的超出程度」，Q 越大社群结构越明显；常用 **Louvain / Leiden**（贪心优化 Q）与 **Girvan-Newman**（逐条删高介数边）。此外还有 k-core（凝聚子群的形式化）、连通分量、二模网投影、链路预测等。
:::

### 8.4 模块度与 PageRank

```text
模块度 Q = (1/2m)·Σᵢⱼ [Aᵢⱼ − kᵢkⱼ/(2m)]·δ(cᵢ, cⱼ)
（m 为边数，kᵢ 为节点 i 的度，δ 表示 i、j 属于同一社区）
Q 越大表示社区内部连边显著多于随机期望；Louvain 通过贪心优化 Q 发现社群。

PageRank：PR(v) = (1−d)/N + d·Σ_{u→v} PR(u)/out(u)，d 常取 0.85
```

::: danger 易错 · 图算法
- 模块度存在「分辨率极限」：大网络中过小的社区可能被合并，Q 高不必然等于业务上合理。
- PageRank 用于**有向图**（入链即「投票」）；把它当无向图的度中心性会丢掉方向信息。
- 网络指标对缺失边非常敏感，采集不全时的中心性排名不可靠。
:::

## 综合例题精讲（跨章）

### 综 1 描述统计 + 透视分析（第 2 章）

**题**：某班 10 人成绩 `[52, 68, 71, 71, 75, 80, 85, 88, 92, 98]`，专业分组为前 5 人 CS、后 5 人 MA。求①均值/中位数/样本标准差；②按专业分组的平均分；③判断是否有异常值。

**解**：
① Σ=780 → x̄=**78**；中位数=(75+80)/2=**77.5**；偏差平方和：
676+100+49+49+9+4+49+100+196+400 = **1632** → s²=1632/9≈**181.33**，s≈**13.47**。
② CS 前 5 人：52+68+71+71+75=337 → 平均 **67.4**；MA 后 5 人：80+85+88+92+98=443 → 平均 **88.6**。
③ 用 pandas 线性插值：Q1 位置 (10−1)×0.25=2.25 → 71+0.25×(71−71)=**71**；Q3 位置 6.75 → 85+0.75×(88−85)=**87.25**；IQR=16.25 → 下界 71−24.375=**46.625**、上界 87.25+24.375=**111.625**，全部成绩在区间内 → **无异常值**。

::: tip 解题要点
「按专业分组」正是 `groupby`；分组均值差异大（67.4 vs 88.6）说明**专业是与成绩相关的分组变量**，但仅凭描述统计不能断言因果（可能是课程难度、选课群体差异）。
:::

### 综 2 相关 → 回归 → 共线诊断（第 3–4 章）

**题**：已知 x=[1,2,3,4,5]、y=[2,4,5,7,9]，求①r；②一元回归方程与 R²；③验证 r²=R²；④若再加入一个与 x 相关性达 0.95 的变量，说明风险与对策。

**解**：
① Sxx=10、Syy=29.2、Sxy=17 → r=17/√(10×29.2)=**0.99485**。
② β̂₁=17/10=**1.7**、β̂₀=5.4−1.7×3=**0.3** → ŷ=0.3+1.7x；SSE=0.30 → R²=1−0.30/29.2=**0.989726**。
③ r²=(0.99485)²=**0.989726** = R² ✓（含截距的一元回归恒等）。
④ r=0.95 → VIF≈1/(1−0.9025)=**10.26 &gt; 10**，严重共线：系数符号/大小不稳、t 值变小但整体 F 仍显著。对策：剔除其一、主成分回归、岭回归，或增大样本。

### 综 3 t 检验 + 功效 + 置信区间（第 3 章）

**题**：n=16、x̄=52、s=4，检验 H₀: μ=50（α=0.05 双侧），给结论并讨论「不拒绝」的含义。

**解**：t=2/(4/4)=**2.00**，df=15，t₀.₀₂₅(15)=**2.131**；|t| &lt; 2.131 → **不拒绝 H₀**；95%CI = 52 ± 2.131×1 = **[49.869, 54.131]**，含 50，与检验一致。
「不拒绝」不等于「μ=50 成立」：可能是真实差异存在但样本量不足。由 3.5 节可知，在 θ=2、se=1 的情形功效仅约 **0.516**，漏检概率约 48%。应报告效应量 d=(52−50)/4=**0.5**（中等）并考虑扩大样本。

### 综 4 PCA + 聚类 + 综合评价（第 4 章）

**题**：4 个指标的特征值 λ=(2.4,0.9,0.5,0.2)。①求各贡献率与应取主成分数；②给归一化综合得分权重；③说明为什么 PCA 之前必须标准化；④若要对 5 个样品聚类，列出完整步骤。

**解**：
① Σλ=4 → 贡献率 **60%、22.5%、12.5%、5%**；前两个累计 **82.5% ≥ 80%** → 取 m=2。
② 归一化权重 (60/82.5, 22.5/82.5) = **(0.727, 0.273)** → F = 0.727F₁ + 0.273F₂。
③ 未标准化时量纲大的变量方差主导相关矩阵，第一主成分将只反映该变量，降维失去意义；相关矩阵等价于对各变量做标准化后的协方差矩阵。
④ 步骤：正向化 → 标准化 → 选距离（欧氏/马氏）→ 计算距离矩阵 → 选类间距离法（建议 average 或 Ward）→ 层次合并得谱系图 → 按跳跃高度定类数 → 用轮廓系数/业务含义验证 → 解释各类特征。

### 综 5 ARIMA 完整建模（第 5 章）

**题**：某非平稳序列一阶差分后平稳，ACF 拖尾、PACF 在 1 阶截尾；n=200，两个候选模型 A(k=2, lnL=−120)、B(k=3, lnL=−118.5)。给出建模方案与选择。

**解**：
① 原序列 ADF 不拒绝单位根 → **d=1**；② 差分后 ACF 拖尾、PACF 一阶截尾 → **AR(1)**，即 ARIMA(1,1,0)；③ 估计参数并检验显著性；
④ AIC/BIC：A → 244.00 / 250.60，B → 243.00 / 252.89 → **AIC 选 B、BIC 选 A**；结合「PACF 一阶截尾」支持更简约的 A；
⑤ 对残差做 Ljung-Box 检验（须 p &gt; 0.05，即白噪声），并检查参数平稳/可逆条件；⑥ 用 `get_forecast(steps=5)` 预测并给预测区间；
⑦ 评估用时间序列切分的样本外 MAE/RMSE，随新数据滚动重估。

::: tip 解题要点
定阶不能只靠 AIC——图形判读、信息准则、残差白噪声三者要相互印证；AIC/BIC 分歧时，若以解释/简约为目标偏 BIC，若以预测为目标偏 AIC，并在报告里写明取舍理由。
:::

### 综 6 爬虫 → 清洗 → 落库 → 统计（第 6 + 2 章）

**题**：从网页抓到房源字段 `['3室2厅 | 117.05平米 | 总价235万', '2室1厅 | 72.27平米 | 总价168万']`，设计完整处理链并算出单价。

**解**：
① `requests.get` + `BeautifulSoup` 按 CSS 选择器定位列表项，`sleep` 控频；② `re` 抽取面积与总价、去空格、跳过缺失；③ 派生「单价 = 总价×10000/面积」；④ 参数化 `INSERT` 存入 SQLite 的 `house` 表；⑤ `pd.read_sql_query` 读回，`describe()` 看单价分布，`groupby('户型')` 比较均价；⑥ 结果：两条单价分别 ≈ **20076.89** 与 **23246.16 元/平米**，后者更高。

### 综 8 数据分析方案设计（简答模板）

**题**：给定一个「用户消费表」（用户 ID、日期、金额、品类、地区），要求分析消费趋势并给出营销建议，写出方案。

**参考要点**（按 CRISP-DM 组织）：

### A.2 概率分布与推断

| 项目 | 公式 / 写法 |

| 置信区间 | `x̄ ± t_{α/2}(n−1)·s/√n` |

### A.3 回归、综合评价与多元方法

| 项目 | 公式 / 写法 |
| --- | --- |
| 一元回归 | `β̂₁=Sxy/Sxx, β̂₀=ȳ−β̂₁x̄` |
| 决定系数 | `R² = 1 − SSE/SST`；一元时 `R² = r²` |
| 多元估计 | `β̂ = (XᵀX)⁻¹XᵀY`；用 `np.linalg.solve` / `lstsq` |
| 调整 R² | `1 − (1−R²)(n−1)/(n−k−1)` |
| 整体 F | `F = (SSR/k)/(SSE/(n−k−1))` |
| 约束 F | `F = [(R²ᵤ−R²ᵣ)/q]/[(1−R²ᵤ)/(n−k−1)]` |
| 系数 t | `t = β̂ⱼ/se(β̂ⱼ)` |
| VIF | `VIFⱼ = 1/(1−Rⱼ²)`；&gt;10 严重共线 |
| 岭 / Lasso | `min Σ(y−Xβ)² + λΣβ²` / `+ λΣ|β|` |
| smf.ols | `smf.ols('y ~ x1 + x2', data=df).fit().summary()` |
| 正向化 | `z=(x−min)/(max−min)`；负向 `z=(max−x)/(max−min)` |
| 变异系数权 | `wⱼ = CVⱼ/ΣCVⱼ` |
| 熵权 | `eⱼ=−Σpᵢⱼln pᵢⱼ/ln n`；`wⱼ=(1−eⱼ)/Σ(1−e)` |
| AHP | `CI=(λmax−n)/(n−1)`；`CR=CI/RI &lt; 0.1` |
| TOPSIS | `C = D⁻/(D⁺+D⁻)`，越大越优 |
| PCA | 相关矩阵特征值 `λⱼ`；贡献率 `λⱼ/Σλᵢ`；累计 ≥80% 定 m |
| 载荷 | `aⱼᵢ√λⱼ` |
| 欧氏距离 | `d=√Σ(xᵢ−yᵢ)²` |
| 夹角余弦 | `cosθ = X·Y/(|X||Y|)` |
| 轮廓系数 | `s=(b−a)/max(a,b) ∈ [−1,1]` |
| PCA 代码 | `StandardScaler().fit_transform(X); PCA().fit(Z)` |
| 层次聚类 | `pdist → linkage(method='ward') → fcluster(t=K)` |

### A.4 时间序列

| 项目 | 公式 / 写法 |
| --- | --- |
| 收益率 | 简单 `pct_change()`；对数 `ln(Pₜ/Pₜ₋₁)` |
| 差分 | `diff()`；`ARIMA(p,d,q)` 中 d 为差分阶数 |
| AR(p) | `yₜ = Σφᵢyₜ₋ᵢ + uₜ` |
| MA(q) | `yₜ = uₜ + Σθᵢuₜ₋ᵢ` |
| 白噪声 | `E=0, Var=σ², Cov=0 (t≠s)` |
| ACF / PACF | `ρₖ = Cov(yₜ,yₜ₋ₖ)/Var(yₜ)`；PACF 剔除中间变量 |
| 定阶 | AR: PACF 截尾；MA: ACF 截尾；ARMA: AIC/BIC 网格 |
| ADF | `Δyₜ = α + βt + γyₜ₋₁ + ΣδᵢΔyₜ₋ᵢ + uₜ`，H₀: γ=0 |
| 临界值 | 用 MacKinnon 表（`adfuller` 返回 `crit`），非 1.96 |
| AIC / BIC | `−2lnL+2k` / `−2lnL+ln(n)k`，越小越好 |
| 残差诊断 | Ljung-Box：p &gt; 0.05 才为白噪声 |
| 预测 | `m.get_forecast(steps=h).predicted_mean / conf_int()` |

| 正则 | `re.findall(r'\d+\.?\d*', s)`、`re.sub(r'\s+','',s)` |
| 爬虫 | `requests.get(url, headers, timeout)` → `BeautifulSoup` → `select()` |
| 选择器 | `.class` / `#id` / `tag` / `a[href]` / `div .title` |
| DB-API | `connect → cursor → execute(?, params) → commit → close` |
| 参数化 | `cur.execute('... WHERE x &gt;= ?', (v,))` |
| h 指数 | 有 h 篇每篇被引 ≥ h 次 |
| 模块度 | `Q = (1/2m)Σᵢⱼ[Aᵢⱼ − kᵢkⱼ/(2m)]δ(cᵢ,cⱼ)` |
| PageRank | `PR(v)=(1−d)/N + d·Σ_{u→v}PR(u)/out(u)` |
| 密度 | 无向图 `2|E|/(|V|(|V|−1))` |
| 度中心度 | `deg(v)/(n−1)` |
| networkx | `nx.Graph(); add_edges_from(); nx.degree_centrality(G)` |

## 附录 B 易错点速查

1. 数据挖掘是「业务理解→数据理解→准备→建模→评估→部署」的完整闭环，不是建模算法的同义词。
2. CRISP-DM 是迭代流程，评估不达标要回退到业务理解或数据准备，不是一次性流水线。
3. 描述性（发生了什么）、预测性（将会怎样）、探索性（发现结构）三类任务的方法不可混用。
4. 数据挖掘 ≠ 机器学习：后者只是「建模」环节的一类方法。
5. 「数据中发现的规律」不等于因果规律，也不等于可推广到未来。
6. 统计显著 ≠ 实际重要；报告结论须同时给效应量与置信区间。
7. 增大样本量不能消除抽样偏差，偏差来自「样本如何被选中」。
8. 合并数据前必须核对口径（含税/不含税、下单/支付），否则汇总无意义。
9. 定序数据求均值严格说无意义；定类编码成 1/2/3 后不可直接做回归，须独热编码。
10. 定距量（温度℃）无绝对零点，不能作倍数比较；定比量（收入）才可以。
11. 截面、时序、面板三种数据结构适用的方法不同：时序不能套普通 OLS。
12. 结构化 / 半结构化 / 非结构化数据的解析方式不同，网页与题录属半结构化。
13. 缺失机制 MNAR（非随机缺失）无法用简单删除或均值填补解决，会造成系统偏差。
14. 示例代码若用绝对路径与未固定随机种子，换机器常无法复现。
15. `pd.Series.var()/std()` 默认 ddof=1（样本），`np.var()/np.std()` 默认 ddof=0（总体）。
16. 右偏分布中 均值 &gt; 中位数 &gt; 众数；均值对异常值敏感，中位数稳健。
17. 偏度 &gt; 0 为右偏、峰度 &gt; 0 为尖峰厚尾；小样本不宜过度解读二者。
18. `describe()` 默认只处理数值列，分类列须 `include='object'` 或 `include='all'`。
19. 箱线图异常判据是 `[Q1−1.5IQR, Q3+1.5IQR]`；3σ 法假定近似正态。
20. 异常值不一定是错误，须区分录入错误、真实极端值与新现象后再处置。
21. `groupby()` 返回 GroupBy 中间对象，不接聚合函数不会输出表格。
22. `pivot_table` 默认 `aggfunc='mean'` 且能聚合重复组合；`pivot` 遇到重复组合会报错。
23. `count` 不计 NaN、`size` 计所有行，分组人数统计勿用错。
24. `crosstab(normalize='index')` 按行归一、`'columns'` 按列、`'all'` 按全体。
25. 中心极限定理说的是「样本均值的分布」趋近正态，不是总体变正态。
26. t 分布尾部比正态厚，自由度越小越明显；n→∞ 时趋近标准正态。
27. 泊松分布均值 = 方差 = λ；实际方差远大于均值时为过度离散，应考虑负二项。
28. χ² 与 F 分布只取非负值，拒绝域在右尾（单侧）。
29. `np.random.seed()` 只保证可复现，不改变分布，也不提高精度。
30. p 值不是「H₀ 为真的概率」，而是「H₀ 成立时观察到当前或更极端结果的概率」。
31. 「不拒绝 H₀」≠「证明 H₀ 成立」，可能只是功效不足（第二类错误）。
32. 第一类错误概率 α、第二类错误概率 β、功效 = 1−β；三者不可同时最优。
33. 置信区间是「均值的不确定性」，预测区间是「单个新观测」，后者更宽。
34. 一元回归 `predict()` 须传 DataFrame 且列名与公式一致；超出样本范围是外推。
35. 相关 ≠ 因果：共同原因、反向因果、纯偶然都会产生高相关。
36. `r=0` 只说明无线性相关，U 形等非线性关系可能很强，必须先看散点图。
37. 异常点会显著拉高或拉低 r；单调非线性关系应用 Spearman/Kendall 秩相关。
38. 相关系数显著性强烈依赖 n：同样 r=0.6，n=20 显著而 n=10 不显著。
39. 增加变量 R² 必不降，比较不同变量数的模型须用调整 R² / AIC / BIC。
40. F 显著但个别 t 不显著，常见原因是多重共线性，不是「变量一定无用」。
41. `VIF = 1/(1−Rⱼ²)`，&gt;10 严重共线；共线时 `XᵀX` 近奇异，应用 `lstsq`/`solve`。
42. 多元回归前提：线性、零均值、同方差、无自相关、无完全共线；正态性用于小样本推断。
43. 残差诊断四项：残差-拟合图、Q-Q 图、DW 自相关、Cook 距离强影响点。
44. `R² = r²` 只在**含截距的一元**回归成立，多元回归没有简单对应。
45. 综合评价前必须把逆向指标（成本、污染）正向化，方向反了结论必错。
46. 全体样本须用同一套 min/max 做无量纲化，不能分组各自取极值。
47. AHP 必须做一致性检验 CR &lt; 0.1，否则判断矩阵权重不可用。
48. 变异系数法、熵权法、CRITIC 给出的权重不同，客观赋权也不唯一，须注明方法。
49. 加权求和允许「线性补偿」（某项极高可掩盖另一项极低），TOPSIS 偏好均衡。
50. 评价排序随权重与无量纲化方法变化，必须做敏感性分析。
51. PCA 之前必须标准化，否则量纲大的变量独霸第一主成分。
52. 主成分保证「累计方差最大」，不保证业务解释性；必要时用因子分析 + 旋转。
53. PCA 是无监督降维（不利用标签）；目标是分类精度时应考虑 LDA。
54. 载荷可整体变号，解释看相对大小；主成分互不相关 ≠ 相互独立。
55. 聚类是无监督，没有「正确率」；用轮廓系数等内部指标或业务可解释性评价。
56. 距离度量前必须标准化；量纲不同时欧氏距离被大尺度变量支配。
57. 距离越小越相似、相似系数越大越相似；Q 型（样品）与 R 型（变量）勿混。
58. 系统聚类贪心不可撤销，早期错误合并会累积；不同连接方法可能给出不同类。
59. 谱系图只给合并顺序，分类数由人决定，不存在自动的「正确答案」。
60. K-means 对初始质心与异常值敏感，须多次初始化并用肘部法/轮廓系数选 K。
61. 平稳性要求均值、方差恒定且自协方差只依赖滞后阶；仅「均值不变」不够。
62. 两条无关的非平稳序列做回归易产生伪回归（高 R²、显著 t 但毫无关系）。
63. 金融价格序列通常非平稳，收益率（差分后）常近似平稳。
64. 过度差分会引入负自相关、放大噪声；通常 d=0 或 1 即可。
65. ADF 统计量不服从常规 t 分布，临界值必须用 MacKinnon 表，不能拿 1.96 比。
66. `ARIMA(p,d,q)` 中 d 是差分阶数，不是变量个数；d 不同不能直接比 AIC。
67. AR 看 PACF 截尾、MA 看 ACF 截尾、两者拖尾用 AIC/BIC 网格定阶。
68. 定阶后残差必须是白噪声（Ljung-Box p &gt; 0.05），否则说明信息未提干净。
69. AIC 惩罚 2k、BIC 惩罚 ln(n)·k；BIC 更偏简约，二者分歧时须说明取舍目标。
70. 多步预测区间随步长变宽并回归均值，是平稳模型的性质，不是模型失效。
71. 时序评估必须用按时间前向切分，随机 K 折会用未来信息泄露。
72. 大数据 4V 是数据特征描述，不等于用了 Hadoop/Spark 分布式平台。
73. 第 6 章入门实操（单机字符串/爬虫/SQLite）属大数据分析的「数据准备入门」，不等于分布式大数据平台。
74. 循环用 `+` 拼接字符串是 O(n²)，应改用 `join()`。
75. `find()` 找不到返回 −1，`index()` 找不到抛异常，二者不可互换。
76. 正则适合字段后处理，结构性提取优先用 CSS 选择器 / XPath。
77. 爬取前须检查 robots.txt 与服务条款，优先官方 API，控制频率并只取公开数据。
78. 绝不能字符串拼接 SQL，一律用 `?` 占位符参数化以防注入。
79. `INSERT/UPDATE/DELETE` 后必须 `commit()`；连接用完须 `close()` 或用 `with`。
80. SQLite 是单机嵌入式数据库，不适合高并发写入。
81. 多值字段（作者、关键词）必须 `explode()` 展开后再计数，否则词频失真。
82. 同一机构的多种写法、作者重名、同义词须规范化，否则共现矩阵被稀释。
83. 导出题录时务必包含参考文献字段，否则无法做共被引与耦合分析。
84. h 指数受学科、年限、自引、合作署名影响，不能跨学科比较或单独用于人才评价。
85. 期刊影响因子评价的是期刊，不能用于评价单篇论文或单个作者。
86. 中心度须标准化才能跨不同规模网络比较；有向图要区分入度与出度。
87. 介数中心性衡量「控制信息流」，不等于「最重要」；密度分母随节点数变化。
88. 任何用到全体数据统计量的预处理（标准化、填补、PCA、特征选择）都必须在训练集内拟合，再用 Pipeline 应用到测试集，否则数据泄露。
