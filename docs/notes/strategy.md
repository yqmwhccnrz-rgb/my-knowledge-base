## 第 1 章 战略与战略管理

### 1.1 公司战略的三种定义（★★）

| 概念 | 提出者 | 核心表述 | 属性 / 记忆口诀 |
| --- | --- | --- | --- |
| **传统概念** | 波特 | 战略是公司为之奋斗的**终点**与达到它们而寻求的**途径**的结合物 | **计划性、全局性、长期性**（计长全）；以计划为基点，视战略为理性计划的产物 |
| **现代概念** | 明茨伯格（1989） | 战略是**一系列或整套的决策或行动方式**，含刻意安排（计划性）与临时出现（非计划性） | **应变性、竞争性、风险性**（应风景）；组织是有限理性，重点在不可预测约束下的适应性 |
| **折中概念** | 汤姆森（1998） | 战略既是**预先性**（预谋战略）又是**反应性**（适应性战略）；大部分战略是事先计划与突发应变的组合 | 公司应**主动预测未来、影响变化**，而非被动反应；实际战略是不断规划与再规划的结果 |

::: danger 易错 · 现代概念不排斥计划性
现代概念把「刻意安排（计划性）的战略」也包含在内，只是**否定「战略＝理性计划的产物」**这一命题。因此「战略的现代概念完全排斥计划性」是错的；「应变性、长期性、综合性」中的「长期性、综合性」属于干扰项，现代概念只有应变性、竞争性、风险性。
:::

### 1.2 公司的使命与目标（★★ 主观题）

**使命**主要阐明企业组织的根本性质与存在理由，一般包括**三个方面**：

| 组成 | 回答的问题 | 要点 |
| --- | --- | --- |
| **公司目的** | 公司为什么存在 | 企业组织根本性质和存在理由的直接体现。营利组织首要目的是**为所有者带来经济价值**，其次是履行社会责任；非营利组织首要目的是提高社会福利、促进政治和社会变革 |
| **公司宗旨** | 公司是做什么的 | 阐述公司**长期的战略意向**，说明目前与未来从事的**经营业务范围**（产品/服务、顾客、市场、技术），反映企业定位。**产品线与业务范围变化 = 宗旨变化** |
| **经营哲学** | 公司怎么做 | 公司为经营活动方式确立的**价值观、基本信念和行为准则**，是企业文化的高度概括；通过**对利益相关者的态度、共同价值观、政策与目标、管理风格**体现 |

::: tip 使命 vs 目标（选择题判别三招）
使命通常**模糊抽象**；目标是使命的**具体化**。表述中有以下任一者即为**目标**而非使命：① 明确指标（如"加强质量管理"）；② 定量数字（如"2 个地标"）；③ 明确完成时间（如"5 年内"）。
:::

**目标体系**（公司目标是使命的具体化，需两类业绩标准，且均要从短期与长期两个角度体现）：

| 体系 | 性质 | 典型指标 |
| --- | --- | --- |
| **财务目标体系** | 定量、短期为主 | 市场占有率、收益增长率、投资回报率、股利增长率、股票价格评价、现金流 |
| **战略目标体系** | 定性、长期为主 | 获取足够市场竞争优势；在产品质量、客户服务、产品革新上压倒对手；**使整体成本低于竞争对手**；提高客户声誉；在国际市场建立更强大立足点；建立技术领导地位；获得持久竞争优势；抓住诱人的成长机会 |

::: danger 易错 · 指标归属
「市场占有率」「股票价格评价」「收益增长率」「资产回报率」→ **财务/经营性业绩**；「重大创新、国家级称号、企业声誉、整体成本低于对手、客户服务质量」→ **战略性业绩**。资料中将"整体成本低于竞争对手"作为战略目标体系的正确选项，就是这个道理。
:::

### 1.3 公司战略的三个层次

| 层次 | 别名 | 制定主体 | 核心内容 |
| --- | --- | --- | --- |
| **总体战略** | 公司层战略 | 最高管理层 | 选择经营领域、配置资源；企业**最高层次**的战略 |
| **业务单位战略** | 竞争战略 | 事业部门管理层 | 与竞争对手厮杀，如何在某产业/市场取得竞争优势 |
| **职能战略** | 职能层战略 | 职能部门管理层 | 营销、财务、生产、研发、人力、信息技术等如何更好配置内部资源、为各级战略服务、提高组织效率 |

::: tip 单业务公司
对**单一业务公司**来说，总体战略与业务单位战略**合二为一**；只有业务多元化的公司，区分二者才有意义。
:::

### 1.4 战略管理过程与特征

**内涵与特征**：战略管理是综合性（涉及所有管理部门、业务单位及相关因素）、高层次（由高层领导推动）、动态性（随内外部条件变化调整）的管理活动。

**战略管理过程**：

| 阶段 | 要点 |
| --- | --- |
| 战略分析 | 第 2 章（内外部环境 + SWOT 综合） |
| 战略选择 | 第 3 章。**制定备选方案的三种方法**：自上而下（总部先定总体战略，下属具体化）、自下而上（下属提交方案，总部协调平衡后确认）、上下结合（上下级共同参与、沟通磋商）；**不包括"外部提供的方法"** |
| 评估备选方案 | 三标准：**适宜性**（是否发挥优势、克服劣势、利用机会、削减威胁、有助实现目标）、**可接受性**（能否被利益相关者接受）、**可行性**（最终落到收益、风险与可行性的财务指标）；无"综合性标准" |
| 选择战略 | 提交上级管理部门审批 / 聘请外部专家 |
| 战略实施 | 第 4 章 |

### 1.5 战略创新管理（2027 重点新增，主观题）

**创新类型体系**（四种划分维度）：

| 划分维度 | 类型 |
| --- | --- |
| 按内容与对象 | **产品创新、流程创新、定位创新、范式创新** |
| 按新颖程度与影响 | 渐进性创新、突破性创新、颠覆性创新 |
| 按系统层面 | 组件（模块）创新、架构创新 |
| 按导向与目的 | 商业创新、社会创新、服务创新、商业模式创新 |

::: tip 流程创新判别
「优化各邮递环节、APP 下单与查询物流」= **流程创新**（产品与服务的**生产和交付方式**变化），不是产品创新。
:::

**创新的战略模式**：创新生命周期、领先者战略与追随者战略、创新战略的实现路径选择；**创新战略的制定与执行**：精益创新、共同使命与领导力与创新意愿、适应性组织架构、关键个体。

**构建创新型组织的七要素**：共同使命/领导力与创新意愿、适应性组织架构、关键个体、全员参与创新、高效团队合作、创造性的氛围、跨越边界、鼓励创新的文化（口诀：使领组关全队氛跨文）。

**创新过程管理**：搜索 → 选择 → 实施 → 获取，以及创新流程模型。
**创新绩效评价与衡量**四类指标：投入指标、过程指标、产出指标、影响指标。

### 1.6 利益相关者与权力

**主要矛盾与均衡**：投资者与经理人员的矛盾与均衡；企业员工与企业（股东或经理）之间的利益矛盾与均衡；企业利益与社会利益的矛盾与均衡（保证利益相关者基本利益要求、保护自然环境、赞助和支持社会公益事业）。

**权力来源**：对资源的控制与交换的权力；在管理层次中的地位（**法定权 = 奖励权 + 强制权**）；个人的素质和影响（**榜样权、专家权**）；参与或影响企业战略决策与实施过程；利益相关者集中或联合的程度。

**处理矛盾与冲突的行为模式**（按「坚定性 × 合作性」）：协作（双高）、**折中（中等坚定 + 中等合作，双方讨价还价、互相让步）**、和解、规避。例如政府要求降价 30%，经多次谈判降到 20%，属于**折中**。

## 第 2 章 战略分析

### 2.1 宏观环境分析：PEST（★★ 主观题）

| 因素 | 主要分析内容 | 易混归属 |
| --- | --- | --- |
| **政治和法律 (P)** | 政局稳定状况；政府行为对企业的影响；执政党态度与基本政策（外交、人口、税收、进出口限制）及其连续性；政治利益集团；法律法规（**四个保护**：保护企业反对不正当竞争、保护消费者、保护员工、保护公众权益） | 政局稳定、进出口限制、反垄断法、保护企业反对不正当竞争 → P；**"国家推出产业行动计划"也可归 P** |
| **经济 (E)** | 社会经济结构；经济发展水平与状况（GDP、人均 GDP、人均国民收入、经济增长速度；税收水平、通胀率、贸易差额与汇率、失业率、利率、信贷投放、政府补助）；经济体制；**宏观经济政策**（财政、货币、产业、国民收入分配）；其他经济条件及发展趋势 | **货币政策、产业政策、财政补贴、利率、社会经济结构 → E**（不是 P，也不是 S） |
| **社会和文化 (S)** | 人口因素（地理分布、密度、年龄、教育水平、国籍；结婚率、离婚率、出生率死亡率、平均寿命）、社会流动性、**消费心理**（从众、求异、攀比、求实）、生活方式变化、文化传统、价值观 | 消费心理、文化传统、"女人和孩子的钱好赚"、中东不卖猪肉汉堡 → S |
| **技术 (T)** | 科技体制、科技政策、科技水平、科技发展趋势；**两新技术三进步**：更有效分析市场与客户、创造竞争优势、使现有产品淘汰或缩短生命周期、扩大经营范围或开辟新市场、更多关注环保与社会责任 | 技术水平、技术进步可创造的竞争优势、冷链物流、移动互联网 → T |

::: danger 易错 · PEST 常见混淆
① **货币政策、产业政策、财政补贴**属经济因素，不是政治法律因素；② **政局稳定状况**属政治和法律因素；③ **消费心理、生活方式变化**属社会和文化因素；④ **竞争对手数量众多**属产业环境分析（五力），根本不属于宏观环境。
:::

### 2.2 产业环境分析（一）：产品生命周期（★★★）

四个阶段以**产业销售额增长率曲线的拐点**划分；大多数（非全部）产业增长呈「S」形；假设一个产业只生产一种产品。

| 维度 | 导入期 | 成长期 | 成熟期 | 衰退期 |
| --- | --- | --- | --- | --- |
| **销量** | 小，用户很少（只有高收入用户尝试） | **节节攀升，客户群扩大（成长期标志）** | 新客户减少，靠老客户重复购买；市场巨大但基本饱和 | 逐步下降，客户对性价比要求很高 |
| 技术/性能 | 设计新颖，质量有待提高、可靠性差 | 质量参差不齐，各厂家技术性能差异大 | 逐步标准化，差异不明显、改进缓慢 | 产品差别小，为降成本质量可能出问题 |
| 竞争 | 只有很少的竞争对手 | 市场扩大、竞争者涌入，争夺人才资源，出现兼并 | **出现挑衅性价格战（成熟期标志）** | 有些竞争者先于产品退出市场 |
| 成本 | 营销成本高、广告费大、产能过剩、生产成本高 | 广告费较高但单位分担下降 | 生产稳定、局部产能过剩；**单位成本最低** | 销量下降使单位成本上升 |
| 价格 | 价格弹性小，高价格、高毛利 | 需求大于供应，**价格最高** | 价格开始下降 | 价格很低，后期多数企业退出才有望上扬 |
| 利润 | 高价格高毛利，但销量小 → 净利润较低 | **单位产品净利润最高** | 毛利率净利率都下降，利润空间适中 | 毛利很低 |
| 规模 | 可能非常小 | 产能不足，需向大批量生产转换 | 销售额达前所未有的规模且稳定 | 产能严重过剩 |
| **经营风险** | **非常高** | 有所下降但仍较高 | 进一步降低，中等水平 | **进一步降低（最低）** |
| **战略目标** | 扩大市场份额，争取成为"领头羊" | 争取最大市场份额，坚持到成熟期 | 巩固市场份额同时提高投资报酬率 | 首先是防御，获取最后现金流 |
| **战略路径** | 投资研发与技术改进，提高产品质量 | 市场营销（改变价格形象和质量形象的好时机） | **提高效率、降低成本** | 控制成本维持正现金流；无成本优势则尽早退出 |

::: tip 经营风险与财务风险的反向搭配（第 3 章财务战略会用）
经营风险：导入期非常高 → 成长期高 → 成熟期中等 → 衰退期**低**；财务风险：导入期非常低 → 成长期低 → 成熟期中等 → 衰退期**高**。一般采用「高经营风险 + 低财务风险」或「低经营风险 + 高财务风险」搭配，共同满足债权人和股东需求。
:::

**产品生命周期理论的局限**（全选常考）：① 各阶段的持续时间随产业不同而不同，无法判断所属阶段；② 产业增长并不总是呈「S」形；③ 易受其他因素（如技术创新）影响，可能出现跳跃；④ 每一阶段的竞争属性随产业不同而不同；⑤ 难以据此直接制定战略。

### 2.3 产业环境分析（二）：五力模型（★★★）

![波特五力模型](/strategy/str-five-forces.svg)

**五种竞争力**：潜在进入者的进入威胁、替代品的替代威胁、供应者讨价还价能力、购买者讨价还价能力、产业内现有企业的竞争。

**① 潜在进入者的进入威胁**：从两方面减少现有厂商利润——瓜分原有市场份额；降低市场集中、激化竞争、减少价格—成本差。威胁大小取决于**进入障碍**（结构性障碍 + 行为性障碍）。

| 进入障碍分类 | 内容 |
| --- | --- |
| **结构性障碍（进入壁垒/客观障碍）** | **波特七种**：规模经济、产品差异（品牌忠诚度）、资金需求、转换成本、分销渠道、其他优势及政府政策；**贝恩三种**：规模经济、现有企业对关键资源的控制、现有企业的市场优势（品牌优势 + 政府政策） |
| **行为性障碍（战略性障碍/主观障碍）** | 现有企业对进入者实施报复：**限制进入定价**、**进入对方领域**（寡头垄断常见） |

- **规模经济**：一定时期内产量绝对量增加时单位成本下降（汽车、电器制造）。
- **现有企业对关键资源的控制**：资金、专利或专有技术、原材料供应、分销渠道、**学习曲线**等。学习曲线＝累积产量增加带来的单位成本下降（经验与专有技术积累）；学习经济与规模经济常交叉影响，此小彼大。
- **现有企业的市场优势**：主要表现**品牌优势**（产品差异化结果），也可表现为政府政策。

**② 替代品的替代威胁**：指**间接产品替代**（能起相同作用的产品非直接取代）；能否替代取决于**性价比**；不必然最终取代，几种替代品可长期共存。

**③ 供应者 / ④ 购买者讨价还价能力**：供应方/购买方集中程度、投入品或产品差异化与标准化程度、转换成本、纵向一体化能力、信息掌握程度。

**⑤ 产业内现有企业竞争程度的影响因素**（简答题）：① 产业内有众多或势均力敌的竞争对手；② 产业发展缓慢；③ 顾客认为所有商品同质；④ 产业中存在过剩生产能力；⑤ **产业进入障碍低而退出障碍高**。

**对付五力的三种战略（冷门主观题）**：① 公司必须自我定位，通过**成本优势或差异优势**把公司与五种竞争力相隔离；② 识别在产业哪一个细分市场中五力影响更少；③ **改进**五力——与供应者或购买者建立长期战略联盟、寻求进入阻绝战略以减少潜在进入者威胁。

**五力模型的局限性**：静态、假设产业结构稳定；忽略企业间合作与互补；难以解释同一产业内企业绩效差异；未考虑政府等外部因素的动态影响；对新兴产业与快速变化产业适用性弱。

**成功关键因素（KSF）**：企业取得产业成功的前提条件；**随产业不同而不同**；**随产品寿命周期演变而变化**（资料习题把"不会改变"作为错误项）；同一产业中不同企业侧重点可能不同。

### 2.4 产业环境分析（三）：市场环境分析（2027 新增）

| 考点 | 要点 |
| --- | --- |
| **市场集中度** | 反映市场上少数企业对市场份额的控制程度；具体指标如行业集中率（CRn）、赫芬达尔指数（HHI）等 |
| **影响因素** | ① 供给端因素——企业自身能力与行业特性；② 需求端因素——市场规模与消费者偏好；③ 政策与制度环境——外部规则的引导；④ 外部冲击因素——突发事件的短期扰动 |
| **市场结构分类** | **完全竞争、垄断竞争、寡头垄断、完全垄断**（按竞争程度由高到低） |
| 类型划分的意义 | 判断企业定价空间、进入障碍与竞争策略选择 |

### 2.5 竞争环境分析

**竞争对手分析四要素**：竞争对手的**未来目标**、**假设**、**现行战略**、**能力**。

**竞争对手的五类能力**（多选高频）：

| 能力 | 决定因素 |
| --- | --- |
| 核心能力 | 企业在某项/某些职能活动方面独有的长处（行业领先的研发能力、客户服务能力、组织及文化优势） |
| 成长能力 | 人员、技术开发与创新、生产能力、财务状况 |
| **快速反应能力** | **自由现金储备、留存借贷能力、厂房设备的余力、定型的但尚未推出的新产品** |
| 适应变化能力 | 对环境变化的调整能力 |
| 持久力 | 现金储备、管理人员的协调统一、长远的财务目标 |

::: danger 易错
「财务能力」属于**企业内部环境分析的企业能力**（研发、生产管理、营销、财务、组织管理五类），**不属于**竞争对手能力五分类；「自由现金储备、定型但未推出的新产品」对应**快速反应能力**，不要误选持久力。
:::

**战略群组分析**：为识别战略群组，必须选择 **2~3 项**战略特征，并**避免选择同一产业中所有公司都相同的特征**。四方面意义：① 有助于了解战略群组间竞争状况，主动发现近处和远处的竞争者，了解某群组与其他群组的不同；② 有助于了解各群组之间的「**移动障碍**」；③ 有助于了解群组内企业竞争的主要着眼点；④ 利用战略群组图可**预测市场变化或发现战略机会**。

### 2.6 企业内部环境分析：资源与能力（★★★）

| 资源类型 | 内容 |
| --- | --- |
| **有形资源** | 物质资源（土地、厂房、生产设备、原材料）+ 财务资源（应收账款、有价证券） |
| **无形资源** | 长期积累、无实物形态、甚至无法用货币精确度量：品牌、商誉、技术、专利、商标、**企业文化及组织经验**；因难以被了解、购买、模仿或替代，是**核心竞争力的重要来源** |
| **人力资源** | 组织成员向组织提供的**技能、知识以及推理和决策能力** |

**决定企业竞争优势的资源判断标准（4 条）**：**稀缺性、不可模仿性、不可替代性、持久性**。

**资源不可模仿性的四种形式**（案例题必考）：

| 形式 | 判别关键词 |
| --- | --- |
| **物理上独特的资源** | 物质本身特性决定（有利地理位置、海景、矿产） |
| **具有路径依赖性的资源** | 必须**经过长期积累**才能获得（"长久以来不断完善科研管理体制"、世代相传的技艺、长期形成的产业链优势） |
| **具有因果含糊性的资源** | 企业对资源形成原因**不能给出清晰解释**（典型：**企业文化**） |
| **具有经济制约性的资源** | 竞争对手已具备复制能力，但**市场空间有限**不能与其竞争 |

**企业能力五类**：研发能力、生产管理能力、营销能力（产品竞争能力 / 销售活动能力 / 市场决策能力）、财务能力、组织管理能力。能力来源于有形、无形与人力资源的**整合**。

**核心能力**：企业在具有重要竞争意义的经营活动中能够**持续比其他竞争对手做得更好**的能力。特征：价值性、独特性、可延展性、不可替代性、动态性、整合性。

::: danger 易错 · 核心能力三个陷阱
① 一个企业**可能拥有不止一种**核心能力；② 核心能力**不是单项**知识、技术或资源，而是各部分有效合作、各单项资源整合的结果；③ 核心能力**不只有研发能力**，还可表现为开发受欢迎产品的创新能力、生产高质量产品的技巧、售后服务能力、吸引客户深度参与设计的机制等。
:::

**核心能力识别与评价的五种方法**：① 企业的自我评价（绩效趋势分析、内部人员依行业经验判断）；② 产业内部比较（产业专家收集市场份额、成本结构、关键成本、顾客满意度等数据比较）；③ **基准分析**（比较自己与竞争对手的业绩，含单个或多种具体活动、系统或过程）；④ 成本驱动力和作业成本法；⑤ 收集竞争对手的信息。

**基准分析的五种类型**：

| 类型 | 判别 |
| --- | --- |
| 内部基准 | 企业内部各单位之间比较 |
| **竞争性基准** | 直接以**竞争对手**为基准（"以行业内优秀企业的标准制定改善方案"） |
| 过程或活动基准 | 以**具有相似功能/活动**的企业为基准（不同产业但活动相同） |
| **一般基准** | 以**具有相同业务功能**的企业为基准；**同一产业、不同国家、不构成直接竞争关系**（丁餐饮学习乙餐饮的差异化战略） |
| **顾客基准** | 以**顾客的预期**为基准（顾客满意度调查） |

**基准对象**（优先选择的活动）：占用较多资金的活动；能显著改善与顾客关系的活动；能最终影响企业结果的活动。

### 2.7 钻石模型与价值链（★★★ 主观题）

**波特钻石模型**（《国家竞争优势》，分析**国家或地区产业层面**的整体资源配置，不是单个企业）：

| 四要素 | 要点 |
| --- | --- |
| **生产要素** | **初级**（天然资源、气候、地理位置、非技术工人、资金）与**高级**（现代通讯/信息/交通等基础设施、受过高等教育的人力、研究机构）。**高级要素更关键** |
| **需求条件** | 本地客户越挑剔，越能激发该国企业竞争优势（能满足最难缠顾客，其他就不在话下） |
| **相关与支持性产业** | 上游供应商具国际竞争优势，即使下游产业不在国际上竞争，影响仍是正面的 |
| **企业战略、企业结构和同业竞争** | 创造与持续产业竞争优势**最大关联因素是国内市场强有力的竞争对手**（与传统观念相反） |

::: danger 易错 · 钻石模型两个反直觉结论
① 竞争优势**可以在不利的生产要素中形成**（人工短缺、资源不足、气候恶劣反而形成创新压力）；② **政府政策不属于钻石模型四要素**（政府是影响因素，不是四要素之一）。
:::

**价值链两类活动**：

| 基本活动（5） | 支持活动（4） |
| --- | --- |
| **内部后勤**（原材料装卸、入库、盘存、运输、退货）、**生产经营**（部件装配）、**外部后勤**（最终产品入库、接受订单、送货）、**市场销售**（广告、销售渠道）、**服务**（培训、修理、零部件供应、调试） | **采购管理**（广义：包括聘请咨询公司做广告策划）、**技术开发**（信息系统开发）、**人力资源管理**（招聘）、**企业基础设施**（组织结构、管理、控制系统、企业文化） |

::: danger 易错 · 企业基础设施
是**站在管理角度**的制度性基础设施（组织结构、控制系统、企业文化），**不是厂房、设备等固定资产**（那是物质资源）。「聘请咨询公司做广告策划」属于**采购管理**（支持活动），不是市场销售。
:::

**企业资源能力的价值链分析要明确三点**：① 确认那些**支持企业竞争优势的关键性活动**（单个活动）；② 明确**价值链内各种活动之间的联系**（内部联系）；③ 明确**价值系统内各项价值活动之间的联系**（外部联系：供应商、分销商、客户）。注意不包括「各项活动与企业目标实现之间的联系」。

### 2.8 业务组合分析与 SWOT

![SWOT 与波士顿矩阵](/strategy/str-swot-bcg.svg)

**波士顿矩阵**：纵轴**市场增长率**（分界 10%）、横轴**相对市场占有率**（本企业某业务市场占有率 ÷ 该业务最大竞争对手市场占有率，分界 1.0）。四种业务与对策、组织要求如上图。四种战略：**发展、保持、收割、放弃**。

::: tip 收割战略适用
为控制成本、减少亏损、增加现金流而减少投资；适用于**处境不佳的现金牛业务、没有发展前途的问题业务、瘦狗业务**（不适用于明星业务）。
:::

**局限**：确定各业务市场增长率与占有率在实践中**比较困难**；只考虑两个指标、忽略业务间关联；假设市场份额与成本正相关等。

**通用矩阵**（GE 矩阵）：两大指标**产业吸引力、竞争地位**；**左上方三个方格**→增长与发展战略；**右下方三个方格**→停止、转移、撤退战略；**对角线三个方格**→维持或有选择地发展。局限：指标主观性强、难以量化、缺乏业务间协同考虑。

**SWOT 综合分析**：S 优势、W 劣势（内部）；O 机会、T 威胁（外部）。

| 战略 | 组合 | 适用 |
| --- | --- | --- |
| **增长型 SO** | 机会 + 优势 | 进攻、扩张 |
| **扭转型 WO** | 机会 + **劣势** | 先补短板再利用机会 |
| **防御型 WT** | 威胁 + 劣势 | 收缩、退出、防御 |
| **多种经营 ST** | 威胁 + 优势 | 多元化分散风险 |

::: danger 易错 · 资料解析此处有笔误（见附录 C）
配套习题答案第 2 章第 33 题解析写「扭转型战略对应外部环境机会与内部环境**优势**」，**错误**——扭转型（WO）对应的是「外部机会 + 内部**劣势**」；同时该解析把「增长型战略对应机会+优势」也标成"错误"，实际该表述本身正确，只是不符合该题题干（题干为外部威胁 + 内部劣势 → 防御型 WT）。做题时以本表为准。
:::

## 第 3 章 战略选择（★★★ 约 36 分，全书最高）

![总体战略体系](/strategy/str-corporate.svg)

**总体战略三大类**：**发展战略、稳定战略、收缩（撤退）战略**。注意「成本领先战略」属于**业务单位战略**，不属于总体战略。

### 3.1 发展战略之一：一体化战略

| 类型 | 含义 | 主要优点 | 适用条件 | 主要风险 |
| --- | --- | --- | --- | --- |
| **前向一体化** | 获得**分销商或零售商**的所有权或加强对其控制权（靠近客户） | 控制销售过程和渠道，有利于控制和掌握市场，增强对消费者需求变化的敏感性，提高产品市场适用性和竞争力 | ① 现有**销售商**销售成本较高或可靠性较差；② 所在产业增长潜力较大；③ 具备所需资金、人力资源；④ **销售环节利润率较高** | 不熟悉新业务领域的风险；增加内部管理成本 |
| **后向一体化** | 获得**供应商**的所有权或加强对其控制权（靠近原材料） | 有效控制关键原材料等投入的**成本、质量及供应可靠性**，确保生产经营稳步进行 | ① 现有**供应商**供应成本较高或可靠性较差；② 供应商数量少而需求方竞争者众多；③ 产业增长潜力较大且具备资金人力；④ **供应环节利润率较高**；⑤ **企业产品价格的稳定十分关键** | 纵向一体化尤其是后向一体化**投资数额较大且资产专用性强**，增加退出成本 |
| **横向一体化** | 向**产业价值链相同阶段**方向扩张 | 减少竞争压力、实现规模经济、增强对市场的控制力 | ① 产业竞争较为激烈；② **产业规模经济较为显著**；③ 符合反垄断法规、能在局部地区获得一定垄断地位；④ 产业增长潜力较大；⑤ 具备所需资金人力 | 反垄断法律风险、整合风险 |

::: danger 易错 · 一体化适用条件四选一
题目给「确保原材料供应可靠性」→ **后向**；「现有销售商可靠性差 / 销售环节利润率高」→ **前向**；「产业规模经济显著」→ **横向**。另外「政府与社会约束、感情障碍」属于**收缩战略的退出障碍**，不是纵向一体化风险。
:::

### 3.2 发展战略之二：密集型战略（安索夫矩阵）

| 战略 | 产品 × 市场 | 判别关键词 |
| --- | --- | --- |
| **市场渗透** | 现有产品 × **现有市场** | 「坚守阵地」，发展单一产品，通过更强营销手段获更大份额；目标是**增加产品使用频率**（周末打折、现场体验、免费试用、买赠、美化包装、联名卡） |
| **市场开发** | 现有产品 × **新市场** | 开辟其他区域市场或细分市场、出口、异地建厂、面向新消费群体 |
| **产品开发** | **新产品** × 现有市场 | 在原有市场通过技术改进与开发研制新产品；可延长寿命周期、提高差异化程度；也包括对现有产品作较小改变 |
| **多元化** | 新产品 × 新市场 | 单独归为发展战略第三类（不属于密集型三种之一） |

**市场渗透的三种方法**：扩大市场份额（适用于整体正在成长的市场）、开发小众市场（适合规模较小企业）、保持市场份额（适用于衰退市场）。
**市场渗透适用情况（5 条）**：① 整个市场正在增长；② 企业决定将利益局限在现有产品或市场领域（即使市场衰退也不允许销售额下降）；③ 其他企业由于各种原因离开市场；④ 企业拥有强大市场地位并能借经验能力获得独特竞争优势；⑤ 对应风险较低、高级管理者参与度较高、需要投资较少。

**市场开发适用情况（6 条）**：存在未开发或未饱和的市场；可得到新的可靠经济高质量的销售渠道；在现有经营领域十分成功；拥有扩大经营所需资金人力；存在过剩生产能力；主业属于正在迅速全球化的产业。

**产品开发适用条件（5 条）**：产品具有较高市场信誉度和顾客满意度；所在产业属适宜创新的高速发展高新技术产业；产业正处于高速增长阶段；具有较强研发能力；竞争对手以近似价格提供更高质量（性价比高）产品。

### 3.3 发展战略之三：多元化战略（★★★ 主观题）

| 类型 | 含义 | 判别 |
| --- | --- | --- |
| **相关多元化（同心）** | 以**现有业务或市场为基础**进入**相关**产业或市场 | 相关性表现为生产、技术、市场、管理技能、营销技能、用户等方面类似（豆浆机→大豆加工；饮用品之间；数字技术→广告业务） |
| **非相关多元化（离心）** | 进入与**当前产业和市场均不相关**的产业 | 无行业联系（旅游→教育培训） |

**三大原因（口诀「木子李」＝目标、资金、利润）**：① 在现有产品或市场中持续经营**不能达到目标**；② 以前成功经营保留的**资金超过**现有产品或市场财务扩张所需；③ 与在现有产品/市场中扩张相比，多元化意味着**更高的利润**。

**七大优点**：① 分散风险；② 在原产业无法增长时找到新的增长点；③ 利用未被充分利用的资源；④ 运用盈余资金；⑤ 运用企业在某产业/市场中的形象和声誉进入另一产业/市场；⑥ 更容易从资本市场获得融资；⑦ 获得资金或其他财务利益（如累计税项亏损）。

**五大风险**：① 来自原有经营产业的风险；② 市场整体风险；③ 产业进入风险；④ 产业退出风险；⑤ 内部经营整合风险。

::: danger 易错 · 优点归属
「减少竞争压力、实现规模经济」是**横向一体化战略**的优点，**不是**多元化的优点；「其他企业离开市场」属于**市场渗透战略**的适用情况，不是多元化原因。
:::

### 3.4 稳定战略与收缩战略

**稳定战略**（冷门主观题）：保持现有经营战略。风险：① 外部环境发生较大变动时，**战略目标、外部环境、企业实力三者失去平衡**，企业陷入困境；② 容易使企业减弱风险意识，形成惧怕风险、回避风险的文化，降低对风险的敏感性和适应性。

**收缩战略的原因**：主动原因（满足企业战略重组的需要）、被动原因（外部环境原因：宏观经济形势、产业周期、技术、政策、社会价值观或时尚重大变化、市场饱和、竞争加剧；内部环境原因：内部经营机制不顺、决策失误、管理不善导致陷入困境）。

| 收缩方式 | 具体做法 |
| --- | --- |
| **紧缩与集中战略** | 着眼于短期效益，采取补救措施制止利润下滑：**机制变革、财政和财务战略、削减成本战略**（改善激励与约束机制、建立有效财务控制系统严格控制现金流量） |
| **转向战略** | 涉及经营方向或策略改变：**重新定位或调整现有产品和服务、调整营销策略** |
| **放弃战略** | 将一个或若干个部门**出售、转让或停止经营**（含特许经营） |

**退出障碍（5 条）**：① 固定资产的专用性程度；② 退出成本；③ 内部战略联系；④ 感情障碍；⑤ 政府与社会约束。

### 3.5 发展战略的三大途径（★★★ 主观题）

| 途径 | 要点 |
| --- | --- |
| **外部发展（并购）** | **三大动机**：① 避开进入壁垒，迅速进入，争取市场机会、规避风险；② 获得**协同效应**（产生于互补资源，通过技术转移或经营活动共享实现）；③ 克服企业**负外部性**，减少竞争，增强对市场控制力。**并购失败四原因**：决策不当（高估潜在效益）、并购后不能很好整合、支付过高并购费用、跨国并购面临政治风险 |
| **内部发展（新建）** | 不收购其他企业、利用自身规模利润活动等内部资源实现扩张（狭义＝新建）。**五大缺点**：① 增加竞争者、激化竞争；② 接触不到另一知名企业的知识及系统，风险更大；③ 从一开始就缺乏规模经济或经验曲线效应；④ 市场发展很快时显得过于缓慢；⑤ 进入新市场可能面对非常高的障碍 |
| **战略联盟** | 两个或两个以上经营实体为达到某种战略目的建立的合作关系。**六大动因**：促进技术创新、避免经营风险、避免或减少竞争、实现资源互补、开拓新市场、降低协调成本 |

**并购类型**（多选高频）：

| 划分标准 | 类型 |
| --- | --- |
| 按并购方身份 | **产业资本并购**（谋求产业利润）、**金融资本并购**（投行、私募、风投等，靠购入再售出企业所有权获得投资利润，**不以产业利润为首要目的**） |
| 按收购资金来源 | **杠杆收购**（70% 及以上资金来自对外负债）、非杠杆收购 |
| 按并购双方产业关系 | 横向、纵向、混合并购 |

**战略联盟类型**（按股权参与和契约联结方式）：**合资企业、相互持股投资、功能性协议**（契约式，含技术交流协议、合作研究开发协议、生产营销协议等）。

::: danger 易错 · 契约式 vs 股权式
**契约式**更强调协调与默契，**更具战略联盟的本质特征**，在经营灵活性、自主权和经济效益方面更优；但**沟通不充分**是其先天不足。股权式联盟优势在于稳定性与长期利益绑定、利于扩大资金实力与共同承担风险。「获得协同效应」属于**并购动机**，不是内部发展优点。
:::

**战略联盟管控（协议四项基本内容）**：严格界定联盟目标、周密设计联盟结构、准确评估投入资产、规定违约责任和解散条款（含违约生效条件、争执解决方法、期满续约程序）。新发展：**网络合作联盟**。

### 3.6 业务单位战略：三种基本竞争战略（★★★）

![战略钟](/strategy/str-clock.svg)

| 战略 | 含义 | 所需资源与能力 | 实施条件（市场情况） | 主要风险 |
| --- | --- | --- | --- | --- |
| **成本领先** | 内部加强成本控制，在研发、生产、销售、服务、广告等领域把成本降到最低限度，成为产业中的成本领先者 | 规模经济显著的产业中装备相应生产设施；降低各种生产要素成本；提高生产率；改进产品工艺设计；提高生产能力利用程度；选择适宜的交易组织形式；资源集中配置 | ① 产品**价格弹性高**、大量价格敏感用户；② 产品**标准化**、难以差异化；③ 购买者不关注品牌、使用方式相同；④ **价格竞争是主要手段**；⑤ 转换成本低 | 技术变化使过去降成本的投资与经验积累**一笔勾销**；新进入者/后来者模仿；过度关注成本忽视需求变化 |
| **差异化** | 提供被全产业范围认可的**独具特色**的产品或服务 | 强大研发与产品设计能力、创造性眼光、很强市场营销能力、质量或技术领先声誉、销售渠道高度合作 | 顾客需求多样化；产品可差异化且顾客重视；产业内差异化途径不多；技术变革快、竞争集中在产品创新 | 竞争者模仿使差异缩小；**买方对差异化的需求下降**；差异化的**成本过高**使价格差距超出顾客承受力 |
| **集中化** | 针对**某一特定购买群体、产品细分市场或区域市场**，采用成本领先或差异化获取竞争优势 | 同上，但聚焦特定目标市场 | 目标市场有足够规模与增长潜力、与其他细分市场差异明显、竞争者未在该细分市场专注 | 目标市场与整体市场差距缩小；竞争者进入并进一步细分；目标市场需求消失 |

::: danger 易错 · 条件归属
「顾客需求多样化」→ **差异化**实施条件；「价格弹性高、产品标准化、价格竞争为主要手段、转换成本低」→ **成本领先**实施条件；「特定细分市场」→ **集中化**。集中化又可细分为**集中成本领先**与**集中差异化**（主打地方菜系并营造文化氛围＝集中差异化）。
:::

**成本领先战略三大优势**（案例题）：形成进入障碍（主动大幅降价令新进入者望而却步）、增强讨价还价能力（能消化高成本投入物）、保持领先的竞争地位。

### 3.7 战略钟、零散产业、新兴产业与蓝海战略

**战略钟**（克利夫·鲍曼，横轴价格、纵轴顾客认可价值）八条路径见上图：
- 成本领先：路径 1 低价低值、路径 2 低价；
- 差异化：路径 4 高值、路径 5 高价高值；
- **混合战略**：路径 3，为顾客提供更高认可价值的同时获得成本优势；
- **失败战略**：路径 6 提高价格但不提供更高认可价值；路径 7 降低认可价值同时提高价格；路径 8 价格不变但降低认可价值。

::: danger 易错 · 蓝海战略原文勘误
资料习题答案第 3 章第 66 题解析写「打破**价值与战术互替定律**」，系**笔误**，教材正确表述为「打破**价值与成本互替定律**」（value-cost trade-off），即同时追求差异化与低成本。战略钟第 49 题解析「提高响应的价格」应为「相应提高价格」。详见附录 C。
:::

**零散产业**（造成零散的原因）：① 进入障碍低或存在退出障碍；② 市场需求多样导致高度产品差异化；③ 不存在规模经济或难以达到经济规模；④ 政府政策与地方法规对产业集中的限制；⑤ 新产业中尚无企业掌握足够技能与能力占据重要份额。

| 零散产业战略选择 | 内容 |
| --- | --- |
| **克服零散—获得成本优势** | 连锁经营或特许经营；技术创新以创造规模经济；尽早发现产业趋势 |
| **增加附加价值—提高差异化程度** | 提高产品/服务差异化 |
| **专门化—目标集聚** | 集中于特定细分市场/产品类型/地理区域 |

**谨防潜在的战略陷阱（5 条）**：避免寻求支配地位；保持严格的战略约束力；避免过分集权化；了解竞争者的战略目标与管理费用；避免对新产品做出过度反应。

**新兴产业**：共同特征（技术不确定、战略不确定、成本高但下降快、萌芽企业与另立门户、首次购买者、客户困惑、短期目标导向、补贴与政府干预）；发展障碍（原材料零部件资金等供给不足、缺乏基础设施与标准、顾客观望）与机遇；早期进入适当的情况（**企业形象和声望对顾客至关重要**、学习曲线重要且经验难模仿、顾客忠诚非常重要、早期与原材料供应/分销渠道建立的合作关系至关重要；产业发展成熟后早期进入企业面临过高转换成本则是危险的）。

**蓝海战略**（重建市场边界，开创无人竞争的市场空间）：

| 类别 | 原则 |
| --- | --- |
| **战略制定四原则** | 重建市场边界、注重全局而非数字、超越现有需求、遵循合理的战略顺序 |
| **战略执行二原则** | 克服关键组织障碍、将战略执行建成战略的一部分 |
| **重建市场边界六路径** | ① 审视他择产业；② 跨越战略群组；③ 重新界定产业的买方群体；④ 放眼互补性产品或服务；⑤ 重设客户的功能性或情感性诉求；⑥ 跨越时间、参与塑造外部潮流 |

**蓝海 vs 红海关键差异**（案例题）：规避竞争、拓展非竞争性市场空间；创造并攫取新需求；打破价值与成本互替定律、同时追求差异化与低成本；把企业行为整合成一个体系。

**商业模式**：商业模式画布；商业模式创新类型（**平台商业模式、长尾商业模式、免费商业模式**）。

### 3.8 职能战略（2027 大幅扩充）

| 职能战略 | 核心考点 |
| --- | --- |
| **市场营销** | 市场细分（消费者市场：地理、人口、心理、行为；产业市场细分依据）；目标市场选择（无差异性、差异性、集中性营销）；市场定位（避强、迎头、并存、取代、重新、领先定位）；**4P**：产品（组合策略扩大/缩减/延伸、品牌策略、新产品开发）、价格（成本/需求/竞争导向；心理定价、产品组合定价、折扣与折让、差别定价；新产品定价：渗透、撇脂、温和、免费；）、分销（渠道结构、基于成员关系的渠道系统、渠道管理）、促销（**广告促销、公关营销/宣传、营业推广、人员推销**；推式、拉式、推拉结合） |
| **研究与开发** | 研发层次（基础性、应用型、开发型）；类型（产品、技术、工艺、流程研发）；流程（调研→产品设计→开发和测试→产品制造和发布→维护和升级）；动力来源；四种模式（自主、合作、委托、开放研发）；研发定位（成为向市场推出新技术产品的企业 / 成功产品的创新模仿者 / 成功产品的低成本生产者 / 成功产品低成本生产者的模仿者） |
| **生产运营** | 运营流程四因素（批量、种类、需求变动、可见性）；自制或外购、生产与运营方式选择；供应链与配送网络六种选择；竞争重点 **TQCF**（交货期 Time、质量 Quality、成本 Cost、制造柔性 Flexibility）；产能计划三种（领先、滞后、匹配）；平衡产能与需求三种方法（资源订单式、订单生产式、库存生产式） |
| **采购** | 三种货源策略（少数或单一货源、多货源少批量、平衡货源）；交易策略（市场交易、短期合作、功能性联盟、创新性联盟）；采购模式（传统、MRP、JIT、VMI、数字化采购） |
| **人力资源** | 规划内容与步骤、供需平衡策略；获取、培训与开发、绩效评估；薪酬激励五原则（战略性、公平性、合法性、竞争性、经济性）；薪酬结构（基本、可变、间接薪酬）；薪酬水平策略（领先、匹配、滞后、混合）；企业竞争战略与薪酬策略匹配 |
| **财务** | 财务战略的确立（融资渠道与方式、融资成本、最优资本结构、股利分配策略）；**基于产品生命周期的财务战略选择**（各阶段经营/财务风险搭配）；**基于价值创造或增长率的财务战略选择**（价值创造/价值损害 × 现金余缺的四种组合） |

::: danger 易错 · 促销组合四要素
「试用品、折扣、礼品」＝**营业推广**（非媒体促销手段）；「媒体投放广告」＝广告促销；「宣传企业形象、建立良好公众形象」＝公关营销；「销售代表直接与客户接触、解释细节、演示用途」＝人员推销。
:::

::: danger 易错 · 新产品定价策略名称
资料习题答案第 3 章第 60 题只列「渗透、撇脂、**满意**定价」三种，而思维导图列的是「渗透、撇脂、**温和**、**免费**」四种（"满意定价"与"温和定价"是同一策略的不同叫法）。**撇脂定价**＝上市之初高价、随产能提高逐步降价，旨在生命周期最初阶段获取较高单位利润；**渗透定价**＝低价迅速占领市场。
:::

### 3.9 国际化经营战略（★★★ 主观题）

| 考点 | 要点 |
| --- | --- |
| **四大动因** | 寻求市场、寻求效率、寻求资源、**寻求现成资产**（主动获得发达国家企业的垄断优势：品牌、先进技术与管理经验） |
| **主要方式** | ① **出口贸易**；② **对外直接投资**（全资子公司/独资经营、合资经营）；③ **非股权形式**（合约制造、服务外包、订单农业、特许经营、许可经营、管理合约及其他合约关系） |
| **全球价值链角色定位** | 领先企业、一级供应商、其他层级供应商、合同制造商 |
| **五种分工模式** | 科层型、市场型、俘获型、模块型、关联型价值链 |
| **企业升级四类型** | 工艺升级、产品升级、功能升级、价值链升级 |
| **四种战略类型** | **国际战略**、**多国本土化战略**、**全球化战略**、**跨国战略**（见下表） |

**四种国际化战略的适用条件**（案例题必考）：

| 战略 | 适用条件 | 不适合 |
| --- | --- | --- |
| **国际战略** | 特殊竞争力在国外市场有竞争优势，且该市场**降低成本压力较小** | 当地市场要求按当地情况提供产品与服务时不合适 |
| **多国本土化战略** | 当地市场**强烈要求按当地需求**提供产品和服务 | 生产设施重复建设、**成本结构高**，不适合成本压力大的产业 |

| **跨国战略** | 本土独立性与适应能力高，**且**全球协作程度高 | — |

**新兴市场的企业战略**：利用本土优势保护受政府政策限制的市场、通过「学习—模仿—创新」实现升级、借助跨国并购获取现成资产等。

## 第 4 章 战略实施（★★★ 约 15 分，含 2027 新增两节）

### 4.1 组织结构的构成要素

| 要素 | 要点 |
| --- | --- |
| **分工** | 企业为创造价值而对人员和资源进行的分配；**纵向分工**＝管理层次的构成及管理者所管理的人数（如何分配决策权）、**横向分工**＝人员、职能部门及事业部的分配（核心是专业化分工与专业化水平）。不同职能、事业部越多、越专业，分工程度越高 |
| **整合** | 为实现预期目标而用来协调人员与职能的手段，即**实行部门化管理**；把分工切割开的各部分再结合起来 |

::: tip 记忆
分工＝把企业**转换成不同职能及事业部**的手段；整合＝把**不同部门结合**起来。
:::

### 4.2 纵向分工结构

| 类型 | 特点 |
| --- | --- |
| **高长型** | 管理层次多、管理幅度窄；信息传递易扭曲、战略难实施、管理费用大幅增加；需较多中层管理人员 |
| **扁平型** | 管理层次少、管理幅度宽；**能及时反映市场变化并作出反应**，但**容易造成管理的失控**；更能调动管理人员积极性 |

**集权 vs 分权**：

| | 集权型 | 分权型 |
| --- | --- | --- |
| 含义 | 高层管理人员拥有最重要的决策权力；多级管理层、决策权在顶部、幅度窄、层级式 | 权力分配给事业部、职能部门及较低层次管理人员；层次少、幅度宽、扁平型 |
| 优点 | ① 易于协调各职能间的决策；② 易于规范上下沟通形式；③ 能与企业的目标达成一致；④ 危急情况下能快速决策；⑤ 有助于实现规模经济；⑥ 适用于由外部机构实施密切监控的企业 | ① 减少信息沟通障碍；② 提高企业反应能力；③ 为决策提供更多信息；④ 对员工产生激励效应；⑤ 减少管理层次、降低内部管理成本 |
| 缺点 | ① 高层可能不重视个别部门的不同要求；② 决策需逐级向上汇报，决策时间过长；③ 级别较低的管理者职业发展空间有限 | 容易造成管理失控 |
| 适用 | 产品线数量有限且关系较为密切的企业 | 多元化、环境变化快、需快速反应的企业 |

**纵向分工组织内部四个管理问题**：集权与分权、中层管理人员人数、信息传递、协调与激励。要点：**层次越多，成本越高**；为降低成本应减少管理层次；扁平型比高长型更能调动管理人员积极性。

### 4.3 横向分工结构的九种基本类型（★★★ 主观题）

| 类型 | 含义 | 优点 | 缺点 | 适用 |
| --- | --- | --- | --- | --- |
| **创业型** | 所有者或管理者对若干下属直接控制，中心人员负责所有重要经营决策，无职能机构 | 结构简单、责任分明、命令统一 | 弹性小、缺乏专业分工，成功依赖中心人员个人能力（需通晓多种知识技能） | 规模小、生产技术简单的小型企业 |
| **职能制** | 按职能专业化分工，职权责任分派给专门单元管理者，CEO 更多关注职能协调与发展战略 | ① 单一部门集中同类活动实现规模经济；② 有利于培养职能专家；③ 常规重复任务使工作效率提高；④ 董事会易于监控各部门 | ① 过度细分导致协调不同职能出问题；② 难以确定各项产品盈亏；③ 职能间易冲突、各自为政；④ 集权化决策放慢反应速度 | **单一业务企业** |
| **事业部制** | 按产品、服务、市场或地区划归不同事业部；战略决策与经营决策相分离；总部负责计划协调与资源安排，事业部承担运营与自身战略规划 | 见分型 | 管理成本重复、各事业部易各自为政 | 多元化、跨区域经营企业 |
| **M 型** | 多部门结构，按产品/市场/地区划分半自主事业部，总部设财务、战略等职能部门统一协调 | 便于高层聚焦战略与资源配置、利于绩效比较与考核 | 总部与事业部之间协调成本高、可能产生内部竞争 | 大型多元化企业 |
| **战略业务单元 (SBU)** | 在事业部之上再按相关业务归并成战略业务单元，便于在更高层面配置资源 | 便于协调相关事业部、共享资源与能力 | 增加管理层次、决策链变长 | 业务种类多且相互关联的大型企业 |
| **矩阵制** | 由纵向（职能部门）与横向（项目/产品小组）两个系统组成，员工同时受原职能部门经理与项目经理领导 | 加强横向联系、资源共享、柔性强、利于跨职能协作 | 双重领导易产生权责冲突、协调成本高、稳定性差 | 需要跨职能协作的项目型、创新型企业 |
| **H 型（控股企业/控股集团）** | 母公司通过持有子公司股权实施控制，子公司独立经营、自负盈亏 | 分散经营风险、母公司控制成本低、便于资本运作 | 母子公司目标易冲突、整体协同弱、控制力有限 | 业务关联度低、以资本运作为主的集团 |
| **平台型** | 以数字平台连接供给方与需求方，通过规则、数据与生态治理创造价值 | 网络效应、边际成本低、可扩展性强 | 平台治理与质量管控难、监管与合规风险高 | 数智化、双边/多边市场企业 |
| **国际化经营企业** | 与国际化战略类型相匹配的组织结构（国际部、全球产品分部、全球区域分部、跨国网络等） | 与全球协作/本地响应要求匹配 | 跨文化协调复杂 | 跨国经营企业 |

**事业部制三种类型**：区域事业部制（优点：更快实现区域决策、削减成本费用如差旅、有利于海外企业应对环境变化；缺点：管理成本重复、难处理跨区域大客户事务）、产品/品牌事业部制（优点：通过事业部经理协调不同职能活动、集中精力于自身产品、更具灵活性有助实施差异化）、客户细分或市场细分事业部制。

**六种基本协调机制**：相互调适、直接监督、工作过程标准化、工作成果标准化、技能（知识）标准化、共同信念（价值观）标准化。**「工作过程标准化」**＝生产前明确工作内容或制定操作规程与规章制度，要求过程中所有活动按标准进行以实现协调。

::: tip 企业发展阶段与组织结构
初步发展（市场渗透战略）→ 简单结构；开始发展（市场开发战略）→ 职能制结构；进一步发展（纵向一体化战略）→ 事业部制结构；成熟期（多元化战略）→ 战略业务单元组织结构、矩阵制、H 型。核心结论：**战略的前导性与组织结构的滞后性**。
:::

### 4.4 组织的四种战略类型

| 类型 | 特点 |
| --- | --- |
| **防御型** | 追求**稳定的环境**，通过解决开创性问题（创造稳定经营领域、占领一部分产品市场，生产有限一组产品）达到稳定；用竞争性定价或高质量产品阻止对手进入 |
| **开拓型** | 不断寻找和开发新产品与新市场机会，追求技术与市场领先；重视创新与柔性 |
| **分析型** | 介于二者之间：在稳定业务领域追求效率，同时有选择地跟随开拓者的创新 |
| **反应型** | 对外部环境采取**动荡不定的调整模式**，缺少随机应变机制，永远处于不稳定状态。成因：① 决策层没有明文表达企业战略；② 管理层次中没有形成适用于现有战略的组织结构；③ 只注重保持现有战略与结构关系、忽视外部环境变化 |

### 4.5 公司战略与企业文化

**企业文化四类型**：

| 类型 | 特点 |
| --- | --- |
| **权力导向型** | 权力集中于中心人物，组织结构往往是传统框架，**决策可以很快做出**；常见于小型、创业型企业 |
| **角色导向型** | 强调职务、规则与程序，层级分明、稳定但反应慢；常见于官僚机构与大型稳定组织 |
| **任务导向型** | **实现目标是主要思想**，不容许任何事情阻碍目标达成；**个人专长是个人权力和职权的主要来源**；强调团队合作与项目完成 |
| **人员导向型** | 以个人或小群体为中心，组织为个人服务；常见于**俱乐部、协会、专业团体和小型咨询公司** |

**企业文化为企业创造价值的三条途径**：① 文化**简化了信息处理**；② 文化**补充了正式控制**；③ 文化**促进合作并减少讨价还价成本**。

**文化与绩效**：文化、惯性与不良绩效（文化惯性可能阻碍战略变革）；企业文化成为维持竞争优势源泉的条件（**价值性、稀有性、难以模仿性、不可替代性**）。企业文化**不可能完全由契约明确下来**。

**战略稳定性与文化适应性**：组织要素变化不大且与企业目前文化高度一致时（多发生在**稳定战略**下），应考虑：① 利用目前有利条件，巩固和加强企业文化；② 利用文化相对稳定的时机，根据企业文化需求解决生产经营中的问题。

### 4.6 战略控制（★★）

**战略失效三类型**：**早期失效**（实施初期因未预料因素）、**晚期失效**（实施后期因环境变化）、**偶然失效**（意想不到的因素，如无法预料的行业政策变化）。
**战略控制过程**：制定绩效标准 → 衡量实际绩效 → 分析偏差原因 → 采取纠正措施。

**预算两种类型**：

| 类型 | 含义 |
| --- | --- |
| **增量预算** | 在以前期间的预算或实际业绩基础上，**增加相应内容**编制新预算 |
| **零基预算** | 在新预算期**不受以往预算安排影响**、不考虑过去预算项目和收支水平，**以零为基点**编制预算 |

**企业业绩衡量**：

| 类别 | 要点 |
| --- | --- |
| 财务衡量指标 | 常用比率（盈利能力、偿债能力、营运能力、增长能力等）。**使用比率的主要原因**：① 比较不同时期比率容易发现变动；② 相对实物数量或货币绝对数值更合适；③ 适合作既简单又易理解的业绩目标；④ 提供总结业绩与经营成果的工具，并可在同类企业间比较 |
| **比率的局限（8 条）** | ① 信息获取困难；② 信息使用有局限；③ 不便于不同行业或同行业不同企业业绩比较；④ 有时不能准确反映真实情况；⑤ 有时体现被扭曲的结果；⑥ 可能鼓励短期行为；⑦ 忽略其他战略要素；⑧ 激励、控制的人员范围有限 |
| 非财务指标 | 常见：市场份额、顾客满意度、产品质量、交货期、员工满意度、研发与培训投入等。**局限**：① 不能用统一比率标准，不易发现业绩变化或比较；② 指标多由各经营部门分别产生使用，不能作为企业整体性业绩目标；③ 难以避免外部环境因素变化，不能客观真实衡量业绩 |

**战略控制方法**：预算、企业业绩衡量、平衡计分卡的企业业绩衡量、统计分析与专题报告。

**平衡计分卡四角度**（案例题必考）：

| 角度 | 典型指标 |
| --- | --- |
| **财务** | 利润增长率、投资报酬率、营业收入 |
| **顾客** | 市场份额、客户满意度、客户保持率 |
| **内部流程** | 采购成本和周期、生产周期、合格率 |
| **创新与学习** | 研发费用占销售额比例、新产品销售额占总销售额比例、数字化技术采用率、员工培训费用及次数、员工满意度 |

### 4.7 公司战略与数智化转型（2027 新增，★★）

| 考点 | 要点 |
| --- | --- |
| **数智化发展趋势** | 政策环境 + 技术发展（**云计算、大数据、物联网、移动互联网、人工智能、区块链**）+ 应用趋势（信息化 → 数字化 → **数智化**） |
| **与公司战略的关系** | ① **公司战略引领数智化转型**；② **数智化转型全方位支撑公司战略** |
| **主要内容（四类变革）** | **技术变革**（数智化基础设施、数智化研发）；**组织变革**（建立数智化企业架构、培育数智化人才）；**业务变革**（营销数智化、生产数智化、供应链数智化）；**管理变革**（财务管理数智化 ERP、人才管理数智化「选育用留」、风险管理数智化「大风控」数字生态） |
| **实施路径（5 条）** | 流程优化驱动、数据赋能驱动、技术应用驱动、商业模式创新、全面协同 |
| **保障措施（5 项）** | **制度**保障、绩效保障、人才保障、文化保障、安全保障 |
| **挑战及应对** | 组织业务模式及流程变革（制定转型战略、建立企业架构、推动组织变革）；数据治理与高效运营（数据质量、数据孤岛）；隐私安全与数字伦理（隐私安全、**算法偏见与歧视**：文化驱动的预存性偏见、数据驱动的技术性偏见、应用驱动的突生性偏见；学术伦理规范；技术误用滥用）；数字文化与人员素养 |

### 4.8 公司战略与可持续发展管理（2027 新增，★★）

| 考点 | 要点 |
| --- | --- |
| **融入战略的价值逻辑（5 条）** | 指明企业的发展方向、提升企业形象、提升核心竞争力、增强盈利能力、满足利益相关者需求 |
| **驱动因素** | 外部：政策监管、自然环境、投资环境、顾客价值；内部：经济收益、企业文化、员工福祉 |
| **披露标准（国际）** | **强制披露**（美国、法国、澳大利亚）；**半强制披露**（「强制 + 自愿」，**英国、中国大陆**）；**不披露但需要作出解释**（巴西、新加坡）。2024 年沪、深、北三所发布《上市公司可持续发展报告指引》，分环境、社会、治理三维度 |
| **评价原则（4 条）** | **客观性、独立性、一致性、适宜性** |
| **评价指标体系三维度** | 环境（碳及温室气体排放、能源与水资源、生物多样性、绿色采购、环境成本核算等）；社会（国家战略响应、员工权益与平等、职业健康安全、产品安全与质量、供应链责任、数据安全与隐私、公益慈善等）；治理（治理结构、股东权益保护、董事会独立性与多样性、信息披露、反贪污受贿、反不公平竞争、风险管理等） |
| **评价方法** | 收集信息数据 → 筛选指标 → 确定权重 → 综合评价 |
| **风险识别与管理** | 可持续发展管理风险的分类、可持续发展风险管理 |

::: tip 三维度判别（例题）
「产品安全性和质量达到国际先进标准」「对各级管理人员进行管理培训」→ **社会维度**；「低碳包装物使用率」→ **环境维度**；「建立完善的风险管理体系」→ **治理维度**。
:::

## 第 5 章 公司治理（★★ 5–10 分）

### 5.1 公司治理概述

| 考点 | 要点 |
| --- | --- |
| **企业制度演进** | **业主制（单人业主制）→ 合伙制 → 公司制**；合伙制特点是共同经营、共享利润 |
| **治理概念** | **狭义**：所有者（主要是股东）对经营者的监督与制衡；**广义**：公司与**所有利益相关者**之间的利益分配与权力安排 |
| **五大理论** | 产权理论、委托代理理论、不完全契约理论、资源依赖理论、**利益相关者理论**（与「股东至上主义」相对：公司发展离不开各利益相关者投入或参与，追求**利益相关者整体利益**而非仅某主体利益） |
| **内部治理结构三模式** | 外部控制主导型、内部控制主导型、家族控制主导型（及其各自演变趋势） |
| **内部治理主体** | 股东和股东会、董事会、经理层、企业各级党委（党组） |

::: danger 易错 · 股东会 vs 董事会职权
**股东大会**决定公司的**经营方针和投资计划**；**董事会**执行股东大会决议，决定公司**年度经营计划和投资方案**、决定公司内部管理机构设置。
:::

**外部治理机制**：市场机制（**产品市场、资本市场、经理人市场**）+ 外部监督机制（行政监督、司法监督、中介机构执业监督、舆论监督）。

**《OECD 公司治理原则》六项**：① 确保有效的公司治理框架；② 股东权利和主要的所有者功能；③ 平等对待全体股东；④ 利益相关者在公司治理中的作用；⑤ **信息披露和透明度**；⑥ 董事会的义务。

### 5.2 公司治理三大问题（★★★ 主观题）

**问题一：股东与经理层之间的利益冲突（「内部人控制」）**

| 义务 | 主要表现 |
| --- | --- |
| **违背忠诚义务** | ① 利用职务为自己或他人牟取不正当利益（**过高的在职消费**、直接侵吞公司财物、虚假交易或报销套取资金、关联方不公平交易、违规处置公司资产、长期占用公司资产）；② 从事损害公司利益的活动（**违反竞业禁止义务**、泄露商业秘密）；③ **薪酬发放不合理、侵占利润**（自利激励方案、任期短期业绩冲刺、**工资奖金等收入增长过快**）；④ 不当行使表决权；⑤ 违反信息披露义务（**会计信息作假、财务作假**、披露虚假信息、隐瞒重大信息）；⑥ **盲目过度投资、经营行为短期化**；⑦ **建设个人帝国** |
| **违背勤勉义务** | ① **敷衍偷懒不作为**（决策拖延、不认真履职、回避风险冲突、工作搞花架子、报告敷衍或造假）；② **缺乏战略视野**（经营过于求稳缺乏创新、急功近利、全局观不足）；③ **财务杠杆过度保守**；④ **轻视、拒绝自我学习和成长** |

::: danger 易错 · 忠诚 vs 勤勉判别
「在职消费水平过高」「工资奖金增长过快侵占利润」「盲目过度投资」「会计报告作假」「违规担保关联交易」→ **违背忠诚义务**；「敷衍偷懒不作为致使安全隐患」「经营过于稳健缺乏创新」「财务杠杆过度保守」→ **违背勤勉义务**。习题中同一现象在不同题里的归类需按此标准判断。
:::

**治理对策**：从强化监督约束机制入手——完善公司治理体系加大监督力度；强化监事会、审计委员会监督职能形成内部权力制衡；加强内部审计；完善外部监督体系使利益相关者参与监管。

**问题二：大股东与中小股东之间的利益冲突（「隧道挖掘」）**

- 实质：大股东利用控制权，以牺牲中小股东利益为代价追求自利目标而非公司价值目标。
- 成因：存在具绝对影响力的大股东，第一大股东与其他大股东常有关联或形成控制联盟；中小股东只有名义控制权，与实际承担风险不对等；**隧道挖掘收益 > 成本**。
- 治理重点：防止大股东利用控制权侵占中小股东利益。

| 表现 | 内容 |
| --- | --- |
| **滥用企业资源** | 并非以占有资源为目的，但未按企业整体目标行动（违背**勤勉义务**） |
| **直接占用资源**（违背**忠诚义务**） | 直接借款、代垫费用、代偿债务、代发工资、违规担保、虚假出资；**预付账款**；占用商标品牌专利等无形资产、抢占公司商业机会 |
| **关联性交易** | ① 商品服务交易活动（**高买低卖**转移利润）；② 资产租用和交易活动（房屋、土地使用权、机器设备、商标专利）；③ 费用分摊活动（随意分摊借此获利） |
| **掠夺性财务活动** | ① **掠夺性融资**（财务造假骗取融资资格、虚假包装、过度融资、**向终极股东低价定向增发股票**）；② **内幕交易**；③ **掠夺性资本运作**（公司高价收购终极股东持有的其他公司股权）；④ 超额股利 |

**保护中小股东权益五项措施**：**累积投票制**、建立有效的**股东民事赔偿制度**、建立**表决权排除制度**、完善小股东的**代理投票权**、建立**股东退出机制**。

::: danger 易错 · 低价定向增发
公司以明显低于市价的价格向控股股东定向增发股票 → 属于**掠夺性融资**，不是内幕交易，也不是掠夺性资本运作。
:::

**问题三：股东与其他利益相关者之间的利益冲突**：企业目标与社会目标冲突、对员工/债权人/供应商/社区/环境责任的忽视；治理思路是把利益相关者纳入治理框架。

### 5.3 管理实践发展与公司治理（2027 新增）

| 考点 | 要点 |
| --- | --- |
| **双重股权结构** | 同股不同权（A/B 股表决权差异），有助于创始人保持控制权、抵御短期市场压力，但可能加剧代理问题、损害中小股东知情与表决权益 |
| **可持续发展与公司治理** | 优化公司治理结构、完善公司治理机制、提升公司治理水平、提高企业信息披露质量、推动公司治理国际化 |
| **数智化与公司治理** | 数智化影响：**提升治理效率、提高信息透明度、优化企业决策、赋能外部治理机制** |

::: tip 版本差异提醒
配套习题册第五章第四节标题仍为「**公司治理原则**」（考 OECD 六原则、董事权利义务、信息披露制度），而 2027 讲义已改为「**管理实践发展与公司治理**」（双重股权结构、可持续发展、数智化）。两者都需掌握，详见附录 C。
:::

## 第 6 章 风险与风险管理概述（★ 约 2 分）

### 6.1 风险的概念与三要素

**风险**：指未来的不确定性对企业实现其经营目标的影响；是**一系列可能发生的结果**，**不能简单理解为最可能的结果**。

| 要素 | 内容 |
| --- | --- |
| **风险因素** | **有形风险因素**（物质实体，如设备老化）；**无形风险因素**：**道德风险因素**（故意、不诚实行为）、**心理风险因素**（疏忽、无意、侥幸） |
| **风险事件（事故）** | 造成损失的偶发事件，是风险由可能性转化为现实的中介 |
| **风险后果** | **直接损失**（财产毁损、人员伤亡）、**间接损失**（停工、声誉、连带赔偿） |

### 6.2 风险管理的概念、特征、目标与职能

**六大特征**：**客观性、战略性、可行性、系统性、专业性、二重性**（二重性＝风险既可能带来损失也可能带来机会）。

**四层目标**：

| 层次 | 内容 |
| --- | --- |
| **基本目标** | 企业与组织及成员的**生存和发展** |
| **直接目标** | 保证组织各项活动恢复正常运转；尽快实现企业持续稳定的收益 |
| **核心目标** | 确保**风险管理与总体战略目标相匹配** |
| **支撑目标** | 加强**企业文化建设** |

::: tip 与《中央企业全面风险管理指引》总体目标的区分
教材另一处列「风险管理总体目标」五条：确保风险控制在与总体目标相适应并可承受范围内；确保内外部（尤其与股东之间）真实可靠的信息沟通、编制提供真实可靠财务报告；确保遵守法律法规；确保规章制度与重大措施贯彻执行、提高经营活动效率效果、降低实现经营目标的不确定性；确保建立重大风险危机处理计划、保护企业不因灾害性风险或人为失误遭受重大损失。这是**总体目标**的表述，与上面「四层目标」并不矛盾，答题按题目问法选用。
:::

**四项职能**：**计划职能、组织职能、指导职能、控制职能**。
**理论演进与实践发展**：传统风险管理专注于**纯粹风险和灾害性风险**；现代全面风险管理从整体战略出发、统筹所有风险与机会。

## 第 7 章 风险管理的流程、体系和方法（★★ 5–10 分，含难点）

![风险管理流程与七种策略工具](/strategy/str-risk.svg)

![风险管理体系与 11 种方法](/strategy/str-risk-system.svg)

### 7.1 风险管理基本流程（五步）

① **收集风险管理初始信息** → ② **进行风险评估**（风险**辨识**＝种类 → 风险**分析**＝发生可能性 → 风险**评价**＝影响程度）→ ③ **制定风险管理策略** → ④ **提出和实施风险管理解决方案** → ⑤ **风险管理的监督与改进**。

### 7.2 风险管理体系

**（一）组织职能体系（六级）**：规范的公司法人治理结构 → 风险管理委员会 → 风险管理职能部门 → 审计委员会 → 其他职能部门及各业务单位 → 下属公司。
**（二）与公司战略的关系**：风险管理体系与**战略分析 / 战略选项 / 战略实施**三个环节相衔接。

**（三）风险管理策略的组成部分（4 项）**：① 风险偏好与风险承受度；② 全面风险管理的**有效性标准**；③ **风险管理策略工具**的选择；④ 风险管理的**资源配置**。

**风险偏好 vs 风险承受度**：

| | 风险偏好 | 风险承受度 |
| --- | --- | --- |
| 含义 | 企业追求战略和业务目标时**愿意接受的风险类型和程度**（希望承担什么风险） | 企业追求目标过程中**所能接受的风险水平或范围**，即可接受的与实现目标相关的**绩效变化界限** |
| 性质 | 可只**定性**；体现企业运营风格，受各利益相关方价值取向与利益追求方式影响调节 | 必须**定量**；可作为企业采取行动的**预警指标**，可设若干指标显示不同警示级别 |

::: danger 易错 · 三个「不一定」
① 风险偏好与承受度针对**重大风险**确定，非重大风险**不一定要十分明确**、甚至可先不提出；② 重大风险的风险偏好与承受度是**重大决策，应由董事会决定**；③ 企业应对所采取的风险度量方法**取得共识**，但**不一定在整个企业使用唯一的风险度量方法**，不同风险可用不同度量方法。
:::

**（四）六种风险度量方法**（案例题必考）：

| 方法 | 判别关键词 |
| --- | --- |
| **最大可能损失** | **无法判断或无须判断概率**时使用；风险发生可能性难以预测且危害巨大 |
| **概率值** | 只有好坏/对错/是否/输赢/生死等**简单结果**；「开发项目失败**可能性**」 |
| **期望值** | 概率加权平均值：每一事件概率 × 影响，再求和；「60% 收益 45%、30% 收益 20%、10% 收益 5% → 33.5%」 |
| **波动性** | 反映数据离散程度（离期望值的距离），用**方差或均方差**表示 |
| **在险值 (VaR)** | 正常市场条件下、给定时间段与**置信区间**内预期可能发生的**最大损失**；特点：**通用、直观、灵活**；局限：适用风险范围小、数据要求严格、计算困难、**对肥尾效应无能为力** |
| **直观方法** | 不依赖概率统计结果（专家意见法）；统计数据不足或需度量结果包含人们偏好时使用 |

**风险量化的困难**：方法误差；数据不足或质量不好；信息系统传递不及时；整合管理（数据不能与现实管理连接）。

**统计推论三类**：**前推法**（根据历史经验和数据推断未来发生概率及后果）、后推法、旁推法。

**（五）七种风险管理策略工具**见本章配图。判别口诀：
- **保险 / 业务外包承包 → 风险转移**；
- **应急资本协议 / 风险准备金 → 风险补偿**；
- **质检部门检验、采用成熟技术、迭代式开发 → 风险控制**；
- **资产组合、多外币结算、多种经营、套期保值、跨行业周期对冲 → 风险对冲**。

**风险承担**四种情形：未辨识出的风险只能承担；已辨识但① 处于风险承受范围内、② 缺乏能力主动管理、③ 无其他备选方案、④ 成本效益上最适宜。**重大风险一般不应采用风险承担**。

**（六）确定风险管理优先顺序、资源配置、策略检查。**

**（七）内部控制系统**：美国 COSO 框架、我国内控规范体系；**内控五要素**：控制（内部）环境、风险评估、控制活动、信息与沟通、内部监督。

**常见控制活动（7 项）**：不相容职务分离控制、授权审批控制、会计系统控制、财产保护控制、预算控制、运营分析控制、绩效考评控制。

::: danger 易错 · 不相容职务
**决策审批与监督检查不得由一人兼任**；资料习题答案第 7 章第 9 题解析写「决策审批与监督检查可以由一个人完成」属于**表述错误**（应为「不可以」），详见附录 C。
:::

**反舞弊工作重点（4 项）**：未经授权或采取其他不法方式侵占挪用企业资产牟取不当利益；财务会计报告和信息披露中的虚假记载、误导性陈述或重大遗漏；董事、监事、经理及其他高级管理人员滥用职权；相关机构或人员串通舞弊。

**风险管理信息系统**、**运用金融工具实施风险管理策略**（必要性、特点、原则要求、主要措施）。

### 7.3 风险管理的技术与方法（11 种）

| 方法 | 核心含义 / 适用 |
| --- | --- |
| **头脑风暴法** | 又称智力激励法、BS 法、自由思考法；刺激并鼓励一群知识渊博、知悉风险情况的人员畅所欲言、集体讨论 |
| **德尔菲法** | **背对背**通信方式征询专家小组意见，专家之间不互相讨论、不发生横向联系，只能与调查人员发生关系；反复填写问卷形成共识。适用于**在专家一致性意见基础上，在风险识别阶段进行定性分析** |
| **失效模式、影响和危害度分析法 (FMECA)** | 逐一分析系统各组成部分可能的失效模式、影响与危害度 |
| **流程图分析法** | 按业务流程环节逐一识别风险点 |
| **马尔科夫分析法** | 依据状态转移概率分析系统状态变化与风险 |
| **风险评估系图法** | 风险坐标图：以发生可能性与影响程度两维定位风险、确定优先顺序 |
| **情景分析法** | 构造多种未来情景，分析各情景下的风险与应对 |
| **敏感性分析法** | 研究项目各种不确定因素变化至一定幅度时，计算主要经济指标的**变化率及敏感程度**；常选销售收入、经营成本、生产能力、初始投资、寿命期、建设期等参数 |
| **事件树分析法 (ETA)** | 由**初始事件**出发**正向**推演各种后续结果与概率 |
| **决策树法** | 用树形图列示备选方案、概率与收益，进行定量决策 |
| **统计推论法** | 前推、后推、旁推 |

## 第 8 章 企业面对的主要风险与应对（★★★ 5–15 分，主观题主战场）

### 8.1 五类风险总览

| 类别 | 含义与影响因素 | 主要表现 |
| --- | --- | --- |
| **战略风险** | 战略制定、实施、调整及复盘过程中，因内外部环境变化或决策失误导致战略目标无法实现 | **战略制定风险、战略实施风险、战略调整风险、战略复盘整改风险** |
| **市场风险** | 因**市场趋势变化、竞争格局、客户与分销渠道变化、原材料供应的充足性稳定性与价格、汇率利率股价指数、税收政策**变化带来的风险 | **市场趋势风险、分销风险**、客户信用与需求变化、价格与汇率波动 |
| **财务风险** | 财务结构不合理、融资不当使公司可能丧失偿债能力，导致投资者预期收益下降、陷入财务困境甚至破产 | **全面预算管理、筹资管理、资金营运管理、投资管理、财务报告、担保**六类风险 |
| **运营风险** | 由内部流程、人员、系统或外部事件不完善/失灵带来的风险 | **组织架构、人力资源、社会责任、企业文化、采购业务、资产管理、销售业务、研究与开发、工程项目、业务外包、合同管理、内部信息传递、信息系统**十三类风险 |
| **法律风险与合规风险** | 因违反法律法规、合同约定、监管要求或行为规范而承担法律责任、遭受处罚或损失 | **法律责任风险、行为规范风险、监管风险** |

::: danger 易错 · 风险归类（案例题最高频）
「原材料价格上涨导致原料紧缺」「汇率波动多付货款」「税收政策和利率、汇率、股票价格指数变化」「竞争对手增多、市场份额被挤占」→ **市场风险**；「社群管理缺失、团长素质低、假货、物流慢、顾客投诉、产品化学药品暴晒释放毒烟」→ **运营风险**；「战略部署失当、多项发展计划搁置错失扩张时机、盲目扩张致资产负债率高达 80%」→ **战略风险**；「连续两年亏损、业绩亏损影响筹资、银行还款压力剧增」→ **财务风险**；「被卷入劳工诉讼、接到政府整改通知书」→ **法律风险与合规风险**。
:::

### 8.2 战略风险与应对

- **战略调整通常发生在四种情况**：① 战略过于激进或过于保守；② 战略方向失准、失误；③ 战略部署失当；④ 管理层或决策层轮换。
- **影响战略风险的因素**：外部宏观与产业环境变化、竞争格局、技术变革、政策监管；内部治理与决策机制、信息与数据质量、资源配置、执行力。
- **应对**：完善战略制定程序与论证、建立环境扫描与预警、加强战略实施过程监控与偏差纠正、重大调整履行决策审批、开展战略复盘整改闭环。

### 8.3 市场风险与应对

**需关注的主要表现**：市场趋势风险（需求变化、消费习惯改变、竞争加剧、供大于求）、分销风险（渠道布局整合、渠道管理失效、进入门槛低导致竞争者增多）、价格与汇率波动、客户信用与供应链稳定性。
**应对**：加强市场调研与需求预测、多元化市场与渠道布局、优化客户信用管理、运用套期保值等金融工具对冲价格与汇率风险、建立供应链备份与议价机制。

### 8.4 财务风险与应对

| 风险 | 需关注的主要风险 |
| --- | --- |
| **全面预算管理** | 预算编制不科学、执行缺乏刚性、考核不到位导致资源错配 |
| **筹资管理** | 融资结构不合理、债务期限错配、偿债能力不足 |
| **资金营运管理** | 资金调度不当、现金流断裂、应收账款回收不力 |
| **投资管理** | 投资决策论证不充分、盲目扩张、投资回报低于预期 |
| **财务报告** | ① 编制违反会计法律法规和统一会计准则制度，可能承担法律责任和声誉受损；② **提供虚假财务报告**误导使用者、造成决策失误、干扰市场秩序；③ **不能有效利用财务报告**、难以及时发现经营管理问题，可能导致财务和经营风险失控 |
| **担保** | ① 对担保申请人资信调查不深、审批不严或越权审批，导致担保决策失误或遭受欺诈；② 对被担保人财务困难监控不力、应对不当，导致承担法律责任；③ 担保过程中存在舞弊，导致经办审批人员涉案或企业利益受损 |

### 8.5 运营风险与应对（★★★ 案例题）

**运营风险至少考虑八方面**：① 企业产品结构、新产品研发；② 新市场开发、市场营销策略（定价与销售渠道、营销环境）；③ 组织效能、管理现状、企业文化，高中层管理人员和重要业务流程专业人员的知识结构与专业经验；④ **期货等衍生产品业务中发生失误**；⑤ **质量、安全、环保、信息安全等管理中发生失误**；⑥ 内外部人员的道德风险或业务控制系统失灵；⑦ 自然灾害等造成损失；⑧ 现有业务流程和信息系统操作运行的监管、运行评价及持续改进能力。

| 业务 | 需关注的主要风险 |
| --- | --- |
| **销售业务** | ① 销售政策和策略不当、市场预测不准确、销售渠道管理不当 → 销售不畅、库存积压、经营难以为继；② 客户信用管理不到位、结算方式选择不当、账款回收不力 → 销售款项不能收回或遭受欺诈；③ 销售过程存在舞弊 → 企业利益受损 |
| **组织架构** | ① 治理结构形同虚设、缺乏科学决策良性运行机制和执行力 → 经营失败、难以实现发展战略；② 内部机构设计不科学、权责分配不合理 → 机构重叠、职能交叉或缺失、推诿扯皮、效率低下 |
| **人力资源** | ① 人力资源缺乏或过剩、结构不合理、开发机制不健全 → 发展战略难以实现；② 激励约束制度不合理、关键岗位人员管理不完善 → 人才流失、经营效率低下或关键技术/商业秘密/国家机密泄露；③ 人力资源退出机制不当 → 法律诉讼或企业声誉受损 |
| **资产管理** | ① 存货积压或短缺 → 流动资金占用过量、存货价值贬损或生产中断；② 固定资产更新改造不够、使用效能低下、维护不当、产能过剩 → 缺乏竞争力、资产价值贬损、安全事故频发或资源浪费；③ 无形资产缺乏核心技术、权属不清、技术落后、存在重大技术安全隐患 → 法律纠纷、缺乏可持续发展能力 |
| **研究与开发** | ① 研究项目未经科学论证或论证不充分 → 创新不足或资源浪费；② 研发人员配备不合理或研发过程管理不善 → 研发成本过高、舞弊或研发失败；③ 研究成果转化应用不足、保护措施不力 → 企业利益受损 |
| **社会责任** | 产品质量低劣侵害消费者利益 → 巨额赔偿、形象受损甚至破产（**注意：这属于社会责任风险，不是人力资源风险**） |
| **合同管理** | 合同未全面履行或监控不当、合同纠纷处理不当、合同对方主体资格未达到要求、未经授权对外订立合同 |

### 8.6 法律风险与合规风险与应对

实务中一般按**法律责任风险、行为规范风险、监管风险**三类采取应对措施。应对：建立合规管理体系与合规审查、加强合同与用工法律审核、跟踪监管政策变化、建立举报与整改机制、开展合规培训。

### 8.7 风险应对综合案例的答题框架

1. **识别**：从材料逐句摘取风险信号，按「战略 / 市场 / 财务 / 运营 / 法律合规」五类归类（同一事实可能同时体现两类，如竞争对手增多既属市场趋势风险、也牵动战略风险）。
2. **定性**：说明风险的影响因素与可能后果。
3. **应对**：把措施对应到**七种策略工具**（风险控制、风险转移、风险补偿、风险规避、风险对冲、风险承担、风险转换）并点明具体工具（保险、应急资本、业务外包、成熟技术、套期保值）。
4. **方法**：若涉及风险识别/评估，指出所用技术与方法（如**德尔菲法**：背对背问卷、反复征询专家意见、达成共识、适用于风险识别阶段的定性分析）。

## 附录 B 各章易错点速查

| # | 易错点 | 正确结论 |
| --- | --- | --- |
| 1 | 战略现代概念 | 只有**应变性、竞争性、风险性**；并不排斥计划性，但否定「战略＝理性计划产物」 |
| 2 | 使命三要素 | 目的（为什么存在）、宗旨（业务范围）、经营哲学（价值观与行为准则，企业文化高度概括） |

| 7 | 替代品威胁 | 指**间接产品替代**，取决于性价比，可长期共存 |
| 8 | 快速反应能力 | 自由现金储备、留存借贷能力、厂房设备余力、定型但未推出的新产品 |
| 9 | 企业基础设施 | 组织结构、管理、控制系统、企业文化；**不是厂房设备** |
| 10 | 一般基准 vs 过程基准 | 一般基准＝同业务功能、不同国家、不构成直接竞争；过程/活动基准＝不同产业但相似活动 |
| 11 | 钻石模型 | 政府政策**不属于**四要素；竞争优势**可在不利要素中形成** |
| 12 | 内部后勤 vs 采购管理 | 原材料装卸入库＝内部后勤（基本活动）；聘请咨询公司做广告策划＝采购管理（支持活动） |
| 13 | 收割战略 | 适用于处境不佳现金牛、无前途问题业务、瘦狗；**不适用于明星** |

| 16 | 纵向一体化风险 | 不熟悉新业务；投资大、资产专用性强、退出成本高；**感情障碍/政府社会约束是收缩退出障碍** |
| 17 | 多元化优点 | 不含「减少竞争压力、实现规模经济」（那是横向一体化） |
| 18 | 收缩三种方式 | 紧缩与集中（机制/财务/削减成本）、转向（重定位/调营销）、放弃（出售转让停业、特许经营） |
| 19 | 并购动机 | 避壁垒、协同效应、克服负外部性；**「获得协同效应」不是内部发展优点** |
| 20 | 契约式联盟 | 更灵活、更具本质特征；**沟通不充分**是先天不足 |
| 21 | 成本领先条件 | 价格弹性高、标准化、价格竞争为主、转换成本低；顾客需求多样化 → 差异化 |
| 22 | 战略钟 | 鲍曼提出；低价低值属成本领先且可成功；混合战略＝高认可价值 + 成本优势 |
| 23 | 集中化 | 特定细分市场实施成本领先或差异化 → 集中成本领先 / 集中差异化 |
| 24 | 营业推广 | 试用品、折扣、礼品＝非媒体促销手段的营业推广 |
| 25 | 撇脂定价 | 上市之初高价、随产能提高逐步降价，旨在最初阶段获取较高单位利润 |
| 26 | 四种国际化战略 | 国际（成本压力小）、多国本土化（当地响应强但成本结构高）、全球化（成本压力大、当地要求小）、跨国（本土适应与全球协作均高） |
| 27 | 集权 vs 分权 | 集权六优点含危急快速决策与规模经济；分权减少信息障碍、提高反应、激励员工、降低管理成本 |
| 28 | 扁平型结构 | 能及时反映市场变化，**但容易造成管理失控** |
| 29 | 矩阵制 | 双重领导（职能经理 + 项目经理），纵向横向两系统 |
| 30 | 反应型组织三成因 | 无明文战略、无适用组织结构、忽视外部环境变化 |
| 31 | 任务导向型文化 | 实现目标是主要思想，**个人专长是权力与职权主要来源**；人员导向型常见于俱乐部、协会、小型咨询公司 |
| 32 | 文化创造价值三途径 | 简化信息处理、补充正式控制、促进合作减少讨价还价成本 |
| 33 | 战略失效 | 早期、晚期、**偶然**（无法预料的行业政策变化） |
| 34 | 比率评价八局限 | 信息获取/使用、跨企业比较、不真实、扭曲、鼓励短期、忽略战略要素、激励控制范围有限 |
| 35 | 平衡计分卡归属 | 市场份额 → 顾客；采购成本与周期 → 内部流程；员工满意度、研发费占销售额 → 创新与学习；利润增长率 → 财务 |
| 36 | 可持续发展评价四原则 | 客观性、独立性、一致性、适宜性；披露半强制＝英国、中国大陆 |
| 37 | 股东会 vs 董事会 | 股东会定经营方针与投资计划；董事会定年度经营计划与投资方案 |
| 38 | 忠诚 vs 勤勉义务 | 在职消费过高/盲目过度投资/财务作假 → 忠诚；敷衍偷懒/财务杠杆过度保守/缺乏战略视野 → 勤勉 |
| 39 | 隧道挖掘 | 低价定向增发＝掠夺性融资；高买低卖关联交易＝关联性交易 |
| 40 | 保护中小股东五措施 | 累积投票制、民事赔偿、表决权排除、代理投票权、股东退出机制 |
| 41 | 风险管理六特征 | 客观性、战略性、可行性、系统性、专业性、二重性 |
| 42 | 风险四层目标 | 基本生存发展、直接恢复正常运转、核心与总体战略匹配、支撑企业文化建设 |
| 43 | 偏好 vs 承受度 | 偏好可定性、承受度必须定量；重大风险由董事会决定；不必全企业唯一度量方法 |
| 44 | 在险值 VaR | 通用直观灵活；局限：风险范围小、数据要求严、计算难、对肥尾效应无能为力 |
| 45 | 最大可能损失 | 无法判断或无须判断概率时使用 |
| 46 | 七工具判别 | 保险/外包＝转移；应急资本＝补偿；质检/成熟技术＝控制；套期保值/多币种＝对冲 |
| 47 | 前推法 | 根据历史经验和数据推断未来发生概率及其后果 |
| 48 | 德尔菲法 | 背对背、反复问卷、专家不横向联系；适用于风险识别阶段定性分析 |
| 49 | 风险归类 | 原材料/汇率/税收/竞争 → 市场；社群管理/假货/物流 → 运营；亏损/偿债 → 财务；诉讼/整改通知 → 法律合规 |
| 50 | 社会责任风险 | 产品质量低劣侵害消费者 → **社会责任风险**，不是人力资源风险 |

### C.3 补充的易漏结论（资料零散、易被忽略）

1. **对付五力的三种战略**（自我定位隔离、识别五力影响更小的细分市场、改进五力）是思维导图明确标注的「主观题冷门点」，讲义正文分散，容易被漏背。
2. **稳定战略的两条风险**（三者失衡、削弱风险意识）是标注的「主观题冷门点」。
3. **新兴市场企业战略**、**全球价值链分工模式与企业升级**在思维导图多处标注「主观题」，但习题册未出题。
4. **风险管理策略的组成部分只有 4 项**（偏好承受度、有效性标准、策略工具、资源配置），资料部分例题把「重点管理某业务环节的风险」也列入判断（正确选项是排除它）。
5. **使用非财务指标衡量的三条局限**与**使用比率衡量的八条局限**容易串用，答题需看清问的是哪一个。
6. **可持续发展管理披露三分类**（强制 / 半强制 / 不披露但需解释）及对应国家是新增易考的纯记忆点。
