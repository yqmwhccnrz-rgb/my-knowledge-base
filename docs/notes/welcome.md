## 第1章 C语言入门基础

### 1.1 第一个 C 程序

```c
#include <stdio.h>

int main()
{
    printf("Hello, world!\n");
    return 0;
}
```

- 每个 C 程序从 `main` 函数开始执行
- 每条语句以分号 `;` 结尾，大括号 `{ }` 表示一个代码块
- `#include <stdio.h>` 引入标准输入输出库

::: info 补充 · main 与编译
标准规定的完整签名是 `int main(void)` 或 `int main(int argc, char *argv[])`；写成 `int main()` 在 C89～C17 里表示「参数未指定」，建议明确写 `void`。`return 0` 向操作系统报告「正常结束」，C99 起在 `main` 末尾省略 `return` 会默认返回 0。

命令行编译建议始终打开告警：`gcc -std=c11 -Wall -Wextra -o hello hello.c`。
:::

### 1.2 注释

1. 单行注释：`// 注释内容`
2. 多行注释：`/* 注释内容 */`
3. VS 快捷键：
   - 添加注释：`Ctrl + K`，`Ctrl + C`
   - 取消注释：`Ctrl + K`，`Ctrl + U`

::: tip 提示
注释是写给读代码的人（包括未来的自己）看的，编译器会直接忽略它们。复杂的逻辑一定要写注释 —— 但更重要的是解释**为什么**这么写，而不是重复代码在做什么。
:::

::: warning 补充 · 多行注释不能嵌套
`/* ... /* ... */ ... */` 会在第一个 `*/` 就结束，剩下的内容会变成代码并报错。想临时注释掉一整段含注释的代码，用 `#if 0 ... #endif` 更稳妥。
:::

### 1.3 关键字

`int`、`return` 等都是 C 语言的关键字（保留字），有固定含义，**不能用作变量名**。

::: info 补充 · 关键字随标准增加
C89 有 32 个关键字，C99 增加 `_Bool`、`_Complex`、`_Imaginary`、`inline`、`restrict`，C11 增加 `_Alignas`、`_Alignof`、`_Atomic`、`_Generic`、`_Noreturn`、`_Static_assert`、`_Thread_local`，C23 又加入 `true`、`false`、`nullptr`、`typeof` 等。写代码时避开这些名字即可，不必死记。
:::

### 1.4 常量

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 整型常量 | 正整数、负整数、零 | `18`、`-5`、`0` |
| 实型常量 | 所有带小数点的数字 | `0.93` 等同于 `.93`，`18.0` 等同于 `18.` |
| 字符常量 | 单引号引起来的字母、数字、符号 | `'a'`、`'1'`、`'+'` |
| 字符串常量 | 双引号引起来的内容 | `"hello"` |

::: info 补充 · 字面量的类型
带小数点的字面量默认是 `double`，写 `float` 要加后缀 `3.14f`；整数字面量默认是 `int`，超出范围会依次升级到 `long`、`long long`，可用 `18L`、`18LL`、`18U` 显式指定。`0x1F` 是十六进制，`0b1010` 是 C23 起支持的二进制写法。
:::

### 1.5 变量

**语法**：`数据类型 变量名;`

```c
int a = 10;
int b = 20;
int c = a + b;
```

- 一条语句可以定义多个变量：`int a, b, c;`（定义了三个变量）
- 变量只能保存一个值；同一作用域内变量名不允许重复定义
- 变量在使用之前一定要赋值（初始化）
- 变量定义的位置：C99 及以后的标准中任意位置均可定义；C89 要求变量定义在块的最前面，然后才能开始使用
- 变量的作用域范围一定要清楚（详见 4.7 本地变量）

::: danger 易错点 · 订正
原笔记写「未初始化的变量中存放的是内存残留的随机值，直接使用会产生不可预料的错误」。

更准确的说法是：**读取未初始化的自动变量属于未定义行为（UB）**。它不一定会给你一个"随机值" —— 编译器可以假定这种情况不会发生，从而删掉整段代码、让两个分支都走同一条路。局部变量一律在定义时初始化：

```c
int count = 0;      /* 好 */
int count;          /* 危险：后续任何读取都是 UB */
```
:::

### 1.6 输出 printf

`printf(参数1, 参数2);` —— 参数 1 是输出内容的最终样式（含占位符），参数 2 是填补的内容。

| 占位符 | 含义 |
| --- | --- |
| `%d` | 整型（`int`） |
| `%f` | 实型（`float` / `double` 输出均可） |
| `%lf` | 实型（`double`，主要用于 `scanf`） |
| `%c` | 字符型（`char`） |
| `%s` | 字符串 |
| `%zu` | `sizeof` 测量结果的占位符 |

```c
printf("%d", 18);   /* 以整型格式输出 18 */
```

::: warning 订正 · printf 里的 %lf
表格容易让人误以为「输出 `double` 要用 `%lf`」。实际上在 `printf` 中，可变参数里的 `float` 会被自动提升为 `double`，所以 **`%f` 就是输出 `double` 的占位符**；`%lf` 只是 C99 起被允许写、且与 `%f` 完全等价。

真正需要区分的是 `scanf`：`%f` 读入 `float*`，`%lf` 读入 `double*`，写错就是未定义行为。
:::

::: warning 补充 · 占位符不匹配是 UB
`printf("%d", 3.14)` 或 `printf("%zu", 1)` 这类类型不匹配，标准不保证任何结果，轻则输出乱码，重则崩溃。开启 `-Wall -Wextra` 后编译器会直接提示格式串问题。
:::

### 1.7 输入 scanf

- `scanf` 需要配合 `&` 取地址：`scanf("%d", &x);`
- 输入浮点数（`double`）时必须用 `%lf` 作占位符
- `scanf` 不会像 `printf` 那样自动做类型提升（详见 2.9）

::: danger 易错点
忘写 `&` 是最常见的运行时崩溃原因之一：`scanf("%d", x)` 会把 `x` 的**值**当成地址去写。`%s` 读入字符串时数组名本身已是地址，**不写** `&`。

另外要检查返回值：`if (scanf("%d", &x) != 1) { /* 输入非法 */ }`，否则输入字母时 `x` 保持未初始化状态。
:::

### 1.8 换行符

| 平台 | 换行符 |
| --- | --- |
| Windows | `\r\n` |
| Mac（早期） | `\r` |
| Linux / 现代 macOS | `\n` |

::: tip 提示
C 代码里统一写 `\n` 即可，编译器与运行环境会处理平台差异（现代 macOS 也用 `\n`）。文本模式下的标准库会自动完成与平台换行符的转换。
:::

### 本章补充 · C 标准版本速查

| 标准 | 常用称呼 | 与笔记相关的变化 |
| --- | --- | --- |
| C89 / C90 | ANSI C | 变量必须在块首定义；`void f()` 表示参数未知 |
| C99 | — | 变量可随处定义、`bool`（`<stdbool.h>`）、`long long`、`%zu`、变长数组、指定初始化 |
| C11 | — | 原子操作、`_Static_assert`、匿名结构/联合 |
| C17 | — | C11 的修订版，无新语言特性 |
| C23 | C2x | `true`/`false`/`nullptr` 成为关键字、`void f()` 等价于 `void f(void)`、`%b` 二进制输出 |

笔记里凡涉及「C99 ONLY」「传统 C」的地方，都可以对照这张表理解。

## 第2章 数据与运算

### 2.1 计算机的存储规则

- 二进制：逢二进一，借一当二（0、1）
- 十进制：逢十进一，借一当十（0 ~ 9）
- 计算机内部所有数据都以二进制形式存储

### 2.2 数据类型

数据类型决定两件事：变量中能存储什么类型的数据（整数、小数、字符等）；存储空间的大小。

| 类别 | 类型 |
| --- | --- |
| 整数 | `short`、`int`、`long`（数值后缀 `L`，打印 `%ld`）、`long long`（C99，后缀 `LL`，打印 `%lld`） |
| 小数 | `float`、`double` |
| 字符 | `char` |

原文还给出：

- 内存中表达的形式：整数用二进制（补码）；浮点数用编码（符号位 + 指数 + 尾数）
- 浮点数表示范围更大，但存在精度限制

::: danger 订正 · 类型范围的排序
原笔记写「各类型所能表达数的范围（大致）：`char < short < int < float < double`」。这句话把**整型**和**浮点型**混在一条链里比较，是不成立的：

- 标准只保证整型内部 `char ≤ short ≤ int ≤ long ≤ long long`，以及浮点内部 `float ≤ double ≤ long double`；
- `float` 的数值范围约为 ±3.4×10³⁸，远大于 64 位整数（约 ±9.2×10¹⁸），所以 `int < float` 若指「数值上限」倒是对的，但 `float < double` 与前面的整型完全不是同一个维度；
- 更容易踩坑的是**精度**：`float` 只有约 7 位有效数字，无法精确表示所有 32 位 `int`。`int x = 16777217; float f = x;` 后 `f` 已经不等于 `x`。

正确记法：整型比「宽度与范围」，浮点比「范围与有效位数」，两者不要串成一条链。
:::

::: info 补充 · 别靠记忆，用标准头文件
`int` 到底是 2 字节还是 4 字节由实现决定。可移植的写法是：

```c
#include <limits.h>   /* INT_MAX, CHAR_BIT, LONG_MAX ... */
#include <stdint.h>   /* int8_t, int32_t, uint64_t, intptr_t ... */
#include <float.h>    /* FLT_MAX, DBL_EPSILON, FLT_DIG ... */
```

需要精确宽度（如网络协议、文件格式）时用 `int32_t` / `uint64_t`，输出可配合 `<inttypes.h>` 的 `PRId64` 等宏。
:::

### 2.3 sizeof

::: tip 定义
`sizeof` 是**静态**的：`sizeof` 的结果在编译期就确定了，运行期不会改变。
:::

- 语法：`sizeof(变量名/数据类型)`，返回所占的字节数
- 用 `%zu` 作占位符输出

```c
printf("%zu", sizeof(int));   /* 通常输出 4 */
```

::: warning 补充 · 一个例外
C99 的变长数组（VLA）是唯一 `sizeof` 在**运行期**求值的情况：`int a[n]; sizeof(a)` 等于 `n * sizeof(int)`。另外 `sizeof` 的操作数不求值，所以 `sizeof(i++)` 不会让 `i` 增加。
:::

### 2.4 整数运算与浮点数

- 两个整数的运算结果只能是整数（除法直接截断小数部分）
- 浮点数：带小数点的数值

::: danger 易错点
`5 / 2` 的结果是 `2` 而不是 `2.5`。要得到小数结果，至少一个操作数应是浮点数：`5.0 / 2`。

负数除法 C99 起**向零截断**（`-5 / 2 == -2`），取余的符号跟被除数一致（`-5 % 2 == -1`）；C89 之前是实现定义的。
:::

::: info 补充 · 溢出与浮点比较
- **有符号整数溢出是未定义行为**：`INT_MAX + 1` 不是"变成负数"，标准不保证结果，编译器可能直接优化掉相关判断。无符号整数溢出才有定义的回绕（模 2ⁿ）。
- **浮点数不要用 `==` 比较**：`0.1 + 0.2 != 0.3`。用 `fabs(a - b) < 1e-9`（需 `<math.h>`），并注意误差尺度应随数量级变化。
:::

### 2.5 运算符

**取余 `%`**：`7 % 3` 的结果是 `1`，只能对整数使用。

**复合赋值**：`+=`、`-=`、`*=`、`/=`、`%=`，如 `a += 5;` 等价于 `a = a + 5;`（但 `a` 只求值一次，对含副作用的表达式不等价）。

**递增递减 `++` / `--`**：

- `a++` 的值是 a 加 1 **以前**的值；`++a` 的值是 a 加了 1 **以后**的值；无论哪种写法，a 本身都已经加了 1
- `count++` 等效于 `count += 1`，等效于 `count = count + 1`

**比较运算符**：`==` 相等；`!=` 不相等；`>` 大于；`>=` 大于或等于；`<` 小于；`<=` 小于或等于。

- 比较结果成立则输出 1（真），不成立则输出 0（假）
- 判断是否相等（`==`、`!=`）的优先级比大小判断（`<`、`<=`、`>`、`>=`）**低**
- 连续的关系运算符从左到右进行

::: danger 易错点
`if (0 < x < 10)` 在 C 里**永远为真**（当 `x` 任意）：先算 `0 < x` 得到 0 或 1，再拿它和 10 比。必须写成 `if (0 < x && x < 10)`。

另一个高频错误：`if (x = 5)` 是赋值不是比较。写成 `if (5 == x)` 可以让编译器在漏写等号时报错。
:::

### 2.6 二进制负数与 unsigned

原笔记的思路：仿照十进制，用一个特殊的标志表示负数；取中间的数为 0，它左边是负数，右边是正数。

- **补码**：负数以补码形式存储
- 直观理解：一个字节（8 位）能表示 −128 ~ 127；在 0 的左边依次是 −1、−2、……
- `unsigned`：不以补码的形式看待这个数 —— 不能表达负数，但正数的范围扩大一倍
- 例题：`unsigned char` 表示 0 ~ 255，`signed char` 表示 −128 ~ 127

::: warning 订正 · 补码到底怎么算
原笔记写「补码和原码（源码）可以加出一个溢出的 1，两者互为凑满溢出的关系」，这个说法容易让人算错。准确定义是：

> 在 n 位下，负数 −x 的补码等于 **2ⁿ − x**；对正数 x 的二进制表示**按位取反再加一**就能得到它。

例如 8 位下 −5：5 是 `00000101`，取反 `11111010`，加一 `11111011`（= 251 = 256 − 5）。这样加法器无需区分正负，符号位也参与运算，这就是补码被采用的原因。
:::

::: info 补充 · char 的符号性
`char` 究竟是 `signed` 还是 `unsigned` **由实现决定**，不是标准规定的；`signed char` 与 `char` 也是不同类型。题目里「unsigned char 0~255」成立的前提是 `CHAR_BIT == 8`，虽然绝大多数平台如此，但标准只保证 `CHAR_BIT >= 8`。需要确定范围时请查 `<limits.h>` 的 `UCHAR_MAX`。
:::

### 2.7 整数与浮点的输入输出 · 输出进阶

- `%o` 用于输出八进制；`%x` 用于输出十六进制
- `%e` 或 `%E` 以科学计数法输出
- 输出精度：在 `%` 和 `f` 之间加上 `.n` 可以指定输出小数点后 n 位（输出时做四舍五入），如 `%.2f`
- `inf` 表示超过范围的浮点数（无穷）；`nan` 表示不存在的浮点数
- 带小数点的字面量是 `double`；`float` 需要 `f` 或 `F` 后缀表明身份，如 `3.14f`
- `fabs()`：求绝对值（需引入 `<math.h>`）

::: tip 提示
选择浮点类型：如果没有特殊需要，选 `double`。
:::

::: info 补充 · 格式宽度与标志
`%5d` 最小宽度 5、`%-5d` 左对齐、`%05d` 补零、`%.3f` 三位小数、`%+d` 强制显示符号。判断 `inf` / `nan` 用 `<math.h>` 的 `isfinite()`、`isnan()`，不要用 `==`。C23 新增 `%b` / `%B` 输出二进制整数。
:::

### 2.8 字符类型

`char`：字符的输入、输出与计算都按 ASCII 码进行。常用 ASCII 码：`'A'` 是 65，`'a'` 是 97，`'0'` 是 48。

**逃逸字符**：

| 字符 | 意义 | 字符 | 意义 |
| --- | --- | --- | --- |
| `\b` | 回退一格 | `\"` | 双引号 |
| `\t` | 到下一个表格位 | `\'` | 单引号 |
| `\n` | 换行 | `\\` | 反斜杠本身 |
| `\r` | 回车 | `\0` | 空字符（字符串结束） |

::: info 补充 · 大小写转换与字符判断
由 ASCII 的连续性可得 `ch - 'a' + 'A'` 把小写转大写、`ch - '0'` 把数字字符转数值。但判断字符类别请用 `<ctype.h>` 的 `isalpha()` / `isdigit()` / `tolower()`，并把参数转成 `unsigned char`，避免 `char` 为负时越界访问。
:::

### 2.9 类型转换

- **自动类型转换**：对于 `printf`，任何小于 `int` 的类型会被转换成 `int`；`float` 会被转换成 `double`。但 `scanf` 不会自动转换 —— `short` 输入要用 `%hd`
- **强制类型转换**（通常是转换成较大的类型）：格式 `(类型)值`

```c
int i = (int)3.14;   /* i == 3 */
```

- 强制转换类型的优先级高于四则运算

::: info 补充 · 整型提升的坑
「转换成较大的类型」这个说法不够准确。C 的**常用算术转换**有一套规则：先整型提升，再按「范围更大、能容纳另一方所有值」的原则选公共类型，还涉及有符号/无符号的优先级。典型陷阱：

```c
unsigned int u = 1;
int i = -2;
printf("%s\n", (i < u) ? "小于" : "不小于");  /* 输出「不小于」 */
```

`i` 被转换成 `unsigned int` 后变成一个很大的正数。混合有符号与无符号时，显式转换并打开 `-Wsign-compare` 告警最稳妥。
:::

### 2.10 逻辑类型与运算

```c
#include <stdbool.h>   /* 之后就可以使用 bool、true、false */
```

- 逻辑运算是对逻辑量进行的运算，结果只有 0 或 1
- 逻辑量是关系运算或逻辑运算的结果
- 优先级：`!` > `&&` > `\|\|`，例如 `!done && (count > MAX)`

| 运算符 | 描述 | 示例 | 结果 |
| --- | --- | --- | --- |
| `!` | 逻辑非 | `!a` | a 是 true 则结果为 false；a 是 false 则结果为 true |
| `&&` | 逻辑与 | `a && b` | a 和 b 都是 true 结果才为 true，否则为 false |
| `\|\|` | 逻辑或 | `a \|\| b` | a 和 b 都是 false 结果才为 false，否则为 true |

**运算符优先级总表**（由高到低）：

| 优先级 | 运算符 | 结合性 |
| --- | --- | --- |
| 1 | `()` | 从左到右 |
| 2 | `!` `+` `-` `++` `--`（单目） | 从右到左 |
| 3 | `*` `/` `%` | 从左到右 |
| 4 | `+` `-` | 从左到右 |
| 5 | `<` `<=` `>` `>=` | 从左到右 |
| 6 | `==` `!=` | 从左到右 |
| 7 | `&&` | 从左到右 |
| 8 | `\|\|` | 从左到右 |
| 9 | `=` `+=` `-=` `*=` `/=` `%=` | 从右到左 |

::: warning 订正 · 补全优先级表
原笔记的表中第 8 行（逻辑或 `\|\|`）在 PDF 里印成了空白，第 9 行条件运算符 `?:` 也没有列进来。完整顺序应为：`\|\|` 低于 `&&`，`?:` 又低于 `\|\|`、高于赋值。不确定时**一律加括号**，比背表可靠。
:::

**短路**：逻辑运算是自左向右进行的，如果左边的结果已经能够决定结果了，就不会做右边的计算。

- 对于 `&&`：左边是 false 时就不做右边了
- 对于 `\|\|`：左边是 true 时就不做右边了

::: danger 易错点
不要把赋值或复合赋值写进逻辑表达式（如 `a == 6 && b += 1`）—— 短路会让右边的赋值「有时执行、有时不执行」。短路也常被用来安全地写 `p != NULL && p->x > 0`。
:::

**条件运算符**：

```c
count = (count > 20) ? count - 10 : count + 10;
```

- `?` 前是条件，`?` 后是条件满足时的值，`:` 后是条件不满足时的值
- 与下面的 if-else 完全等价：

```c
if (count > 20) count = count - 10;
else            count = count + 10;
```

- 条件运算符的优先级只**高于**赋值，低于其他运算符

### 2.11 逗号运算

- 逗号用来连接两个表达式，并且以右边表达式的值作为整个表达式的结果
- 逗号的优先级是最低的
- 主要在 `for` 中使用：`for (i = 1, sum = 0; i <= 10; i++) { ... }`

::: tip 区分
调用函数时圆括号里的逗号是**标点符号**，不是运算。`f(a, b)` 传两个值；`f((a, b))` 是逗号运算，只传一个值（b 的值）。
:::

## 第3章 流程控制

### 3.1 if 条件语句

**格式**：`if (条件) {代码}`

```c
if (score >= 60) {
    printf("及格\n");
}
```

### 3.2 if-else 语句

**格式**：`if (条件) {代码} else {代码}`

```c
if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

- if-else 可以嵌套（**else 与最近的、还没有 else 配对的 if 配对**）
- 多分支 `else if`：

```c
if (条件1)      { ... }
else if (条件2) { ... }
else if (条件3) { ... }
else            { ... }
```

::: tip 提示
无论分支里只有一行还是多行，都写上 `{ }`。省略大括号时，「悬空 else」和后续插入一行代码的错误非常常见（历史上还造成过真实的重大缺陷）。
:::

### 3.3 switch case 语句

```c
switch (控制表达式) {
    case 常量: 语句; break;
    case 常量: 语句; break;
    default:   语句;
}
```

- `case` 后面的常量可以是常数，也可以是常数计算表达式
- `break` 是这一 case 的终止信号，如果没有 break 则会「穿透」进下一个 case
- `default` 匹配所有未命中的情况

::: danger 订正 · 控制表达式的类型
原笔记写「控制表达式必须是 int 型的」。准确说法是：必须是**整数类型**（integer type），包括 `char`、各种 `short`/`int`/`long`、枚举，以及它们的无符号版本；`float`、`double`、指针、字符串都不行。`case` 标签也必须是**整型常量表达式**，不能是变量或字符串。
:::

::: info 补充 · 有意的穿透要写明
穿透（fallthrough）并不总是错误，比如多个 case 共用一段处理逻辑。为了让读代码的人和静态检查工具知道这是故意的，写一个显式注释；C23 起可以用标准属性 `[[fallthrough]];`：

```c
case 'a':
case 'A':
    count_a++;
    /* fallthrough */
case 'e':
    count_vowel++;
    break;
```
:::

### 3.4 while 循环

**格式**：`while (条件) {循环体}`

```c
int i = 1;
while (i <= 10) {
    printf("%d ", i);
    i++;
}
```

`if` 和 `while` 的区别：`if` 是一次性判断，`while` 是多次循环。

### 3.5 do-while 循环

```c
do {
    <循环体语句>
} while (<循环条件>);
```

和 `while` 的区别：do-while 是先进入循环体再判断条件（**至少执行一次**）；while 是先判断条件才进入循环体。注意结尾的分号不能漏。

### 3.6 for 循环

**格式**：`for (初始动作; 条件; 每轮的动作) {循环体}`

```c
for (i = 1; i <= 10; i++) {
    sum += i;
}
```

- `for` 中的每个表达式都是可以省略的
- `for (; 条件; )` 等价于 `while (条件)`（注意：两个分号不能省）

::: info 补充 · C99 起可在 for 内定义变量
`for (int i = 0; i < 10; i++)` 中的 `i` 作用域只在循环内，能避免变量污染和外部误用，推荐这样写（需 `-std=c99` 或更新）。循环条件里不要用浮点数做相等判断，也不要在循环体内修改循环变量之外的计数状态。
:::

### 3.7 三种循环的选择

| 场景 | 选择 |
| --- | --- |
| 有固定次数 | `for` |
| 必须执行一次 | `do-while` |
| 其他情况 | `while` |

### 3.8 break 与 continue

- `break`：跳出（它所在的）循环
- `continue`：跳过循环这一轮剩下的语句，进入下一轮循环
- `break` 和 `continue` 只能对它所在的那**一层**循环起作用

::: warning 易错点
`while` 里的 `continue` 会直接跳到条件判断，如果递增语句写在 `continue` 之后，就会死循环；`for` 里的 `continue` 会先执行「每轮的动作」再判断条件，行为不同。
:::

### 3.9 嵌套循环与 goto

- 循环可以嵌套：内层循环完整跑完一遍，外层循环才走一步
- `goto` 可以跳到所指标号处（如 `goto out`），常用于多重循环中一次性跳出：

```c
for (...) {
    for (...) {
        if (...) { goto out; }
    }
}
out:
return 0;
```

::: tip 提示
`goto` 只建议用于「多重循环整体跳出」和「统一错误处理、集中释放资源」这类场景，滥用会让程序流程混乱难读。多数情况下把内层逻辑抽成函数再 `return` 更清晰。
:::

### 3.10 随机数 rand()

- `rand()` 返回一个 0 到 `RAND_MAX` 之间的随机整数（需引入 `<stdlib.h>`）
- 配合 `%` 可以得到指定范围的随机数：`rand() % 100` 得到 0 ~ 99
- 默认每次运行序列相同，可配合 `srand(time(0))` 改变随机种子

::: info 补充 · rand() 的三个坑
1. **种子只播一次**：`srand()` 应放在程序开始处，不要放进循环里反复调用，否则连续调用会得到相同序列。
2. **取模有偏**：`RAND_MAX + 1` 通常不能被 100 整除，小的余数出现概率略高。要求均匀时用拒绝采样。
3. **质量不保证**：`rand()` 是实现定义的伪随机算法，不适合密码学、也不适合严肃模拟。需要可复现的高质量随机可用 PCG / xoshiro 等实现，密码学场景用系统提供的安全随机源。
:::

### 3.11 经典循环应用

#### 整数的分解

- 取个位数：对整数做 `% 10` 的操作
- 去掉个位数：对整数做 `/ 10` 的操作
- 取十位数：先去掉个位数（`/ 10`），再对得到的结果做 `% 10` 的操作
- 由此类推，可以得到任意位

#### 取逆序

```c
#include <stdio.h>

int main() {
    int x;
    scanf("%d", &x);
    int digit;
    int ret = 0;

    while (x > 0) {
        digit = x % 10;
        ret = ret * 10 + digit;
        printf("x=%d, digit=%d, ret=%d\n", x, digit, ret);  /* 调试输出 */
        x /= 10;
    }

    printf("%d", ret);
    return 0;
}
```

::: tip 提示
核心是两句话：`digit = x % 10;` 取出最后一位，`ret = ret * 10 + digit;` 把这一位接到结果尾部。中间那个 `printf` 是调试输出，用来观察每一步的变化。
:::

::: warning 补充 · 边界情况
`x = 0` 时循环一次都不进，输出 `0`（正确）；`x` 为负数时 `x > 0` 直接不成立，需要先取绝对值；末尾有 0 的数（如 1200）逆序后前导零会自然丢失，这是数学上的正确结果，若要求保留位数应改用字符串处理。
:::

#### 阶乘

```c
int n;
scanf("%d", &n);
int fact = 1;
int i = 1;

while (i <= n) {
    fact *= i;
    i++;
}

printf("%d!=%d\n", n, fact);
```

::: danger 补充 · 阶乘极易溢出
`12!` 已经超过 32 位 `int`，`20!` 超过 64 位 `unsigned long long`。原笔记用 `int` 只是为了演示循环，实际计算大阶乘要用 `double`（近似）、大整数库，或先检查 `n` 的上限。
:::

#### 求和

```c
int i;
int sum;

for (i = 1, sum = 0; i <= 10; i++) {
    sum += i;
}

printf("%d到%d的和是%d\n", 1, 10, sum);
```

::: tip 提示
循环经常要做「计数」和「累加」两件事：计数 `count = 0; count++;`，累加 `sum = 0; sum += x;`，注意**初始值一定是 0**（累加）或 1（累乘）。这类「累加器」就是后面第 4 章把重复代码提取成函数的动机。
:::

## 第4章 函数

### 4.1 为什么要写函数

同样的代码写三遍，既啰嗦又难改；把重复代码提取成一个函数，**一处定义、多处调用**：

```c
int i;
int sum;

for (i = 1, sum = 0; i <= 10; i++)  { sum += i; }
printf("%d到%d的和是%d\n", 1, 10, sum);
for (i = 20, sum = 0; i <= 30; i++) { sum += i; }
printf("%d到%d的和是%d\n", 20, 30, sum);
for (i = 35, sum = 0; i <= 45; i++) { sum += i; }
printf("%d到%d的和是%d\n", 35, 45, sum);
```

提取成函数后：

```c
void sum(int begin, int end) {
    int i;
    int sum = 0;
    for (i = begin; i <= end; i++) {
        sum += i;
    }
    printf("%d到%d的和是%d\n", begin, end, sum);
}

int main() {
    sum(1, 10);
    sum(20, 30);
    sum(35, 45);
    return 0;
}
```

::: info 补充 · 函数的价值不只是少打字
它给一段计算**起了名字**、划定了**作用域**、明确了**输入输出**，于是可以单独测试、单独修改、单独复用。判断该不该抽函数，看的是「这段逻辑能不能用一句话命名」，而不是它有多长。
:::

### 4.2 函数的定义

函数由**函数头**（第一行）和**函数体**（`{ }` 内的代码）组成：

```c
void sum(int begin, int end)   // ← 函数头（函数原型）  {  // ┐
    int i;                                        //  │
    int sum = 0;                                  //  │ 函数体
    for (i = begin; i <= end; i++) {              //  │
        sum += i;                                //  │
    }                                            //  │
    printf("%d到%d的和是%d\n", begin, end, sum); //  │
}                                                //  ┘
```

**函数头的各部件**（以上例为准）：

| 部件 | 上例中的值 |
| --- | --- |
| 返回类型 | `void`（不返回任何东西） |
| 函数名 | `sum` |
| 参数表 | `(int begin, int end)` |

::: info 补充 · 定义与声明不是一回事
「函数头 + 分号」是**声明**（告诉编译器这个函数长什么样），「函数头 + 函数体」是**定义**（真正给出实现）。一个函数可以有多个声明，但整个程序里只能有一个定义。上面的注释把函数头称作"函数原型"，严格说只有带分号时才是原型。
:::

### 4.3 调用函数

**格式**：`函数名(参数值);`

- 即使没有参数也要写 `()`
- 如果有参数，则需要给出正确的数量和顺序（类型也要正确）
- 可以传递给函数的值是「表达式的结果」，包括：字面量、变量、函数返回值、计算结果

```c
int a, b, c;
a = 5; b = 6;

c = max(10, 12);          /* 字面量 */
c = max(a, b);            /* 变量 */
c = max(c, 23);           /* 变量 + 字面量 */
c = max(max(23, 45), a);  /* 函数的返回值 */
c = max(23 + 45, b);      /* 计算结果 */
```

::: warning 补充 · 求值顺序不确定
`f(g(), h())` 里 `g` 和 `h` 谁先执行是**未指定**的；`f(i++, i++)` 更是未定义行为。别让参数表达式互相依赖，先算好再传。
:::

### 4.4 返回值

`return` 停止函数的执行，并送回一个值。两种形式：`return;` 和 `return 表达式;`

- 一个函数可以出现多个 `return` 语句
- **没有返回值的函数（`void`）**：不能使用带值的 `return`；可以没有 `return`；调用的时候不能把返回值拿来参与运算
- 如果函数有返回值，则必须使用带值的 `return`

```c
int max(int a, int b) {
    int ret;
    if (a > b) { ret = a; }
    else       { ret = b; }
    return ret;
}
```

::: danger 补充 · 别返回局部变量的地址
`return &local;` 返回的是函数栈帧上的地址，函数返回后那块空间已经失效，属于**悬垂指针**。需要返回一块内存时，用 `malloc` 分配、或由调用者传入缓冲区。
:::

### 4.5 函数原型声明

C 的编译器从上到下顺序分析你的代码。在调用 `sum(1, 10)` 的时候，编译器需要知道 `sum()` 长什么样：要几个参数、每个参数的类型如何、返回什么类型。

**函数头以分号 `;` 结尾，就构成了函数的原型**，原型的目的就是提前告诉编译器这个函数长什么样：

```c
double max(double a, double b);   /* 函数原型（提前声明） */

int main() {
    int a, b, c;
    a = 5; b = 6;
    c = max(10, 12);
    printf("%d\n", c);
    return 0;
}

double max(double a, double b) {  /* 实际的函数定义可以写在后面 */
    ...
}
```

旧标准习惯把函数原型写在调用它的函数**里**；现在一般写在调用它的函数**前**（更常见的做法是放进 `.h` 头文件）。

::: warning 订正 · 上例的类型不一致
原笔记这段示例声明 `double max(double, double)`，却用 `int c` 接收返回值、再用 `%d` 打印。返回值会被隐式截断成 `int`，`%d` 与实参类型也对不上。教学示例应统一类型，例如改成 `int max(int, int)`，或把 `c` 声明为 `double` 并用 `%f` 输出。
:::

### 4.6 值传递（传值）

```c
void swap(int a, int b);

int main() {
    int a = 5; int b = 6;
    swap(a, b);
    printf("a=%d b=%d\n", a, b);
    return 0;
}

void swap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}
```

::: tip 核心结论
> C 语言在调用函数时，永远只能**传值**给函数。函数对参数的修改不会影响调用处的变量 —— 所以上面这样的代码不能交换 a 和 b 的值。想交换，必须用指针（见 6.4）。
:::

::: info 补充 · 数组是"例外"吗
不是。传数组时确实能改到原数组，但那是因为数组名退化成了**指向首元素的地址**，传进去的值是地址，函数通过地址间接访问了同一块内存 —— 本质上仍然是传值。这也解释了为什么函数内部 `sizeof(数组参数)` 得到的是指针大小。
:::

### 4.7 本地变量

**本地变量的规则**：

- 每个函数有自己的变量空间，参数也位于这个独立的空间中，和其他函数没有关系
- 过去把函数参数表中的参数叫做「形式参数」，调用函数时给的值叫做「实际参数」。这种称呼容易让初学者误以为调用函数时把变量（而不是值）传了进去，所以现在不建议继续使用
- **生存期**：什么时候这个变量开始出现，到什么时候它消亡
- **作用域**：在（代码）什么范围内可以访问这个变量
- 对于本地变量，这两个问题的答案是统一的：**大括号内 —— 块**
- 本地变量定义在块内 —— 可以是函数的块内，也可以是语句的块内，甚至可以随便拉一对括号来定义变量
- 程序运行进入这个块之前，其中的变量不存在；离开这个块，其中的变量就消失了
- 块外定义的变量在块内仍然有效
- 块内定义了和外面同名的变量，则掩盖了外面的
- 不能在一个块内定义同名的变量
- 本地变量不会被默认初始化；参数在进入函数的时候被初始化了

**没有参数时**：

```c
void f(void);   /* 明确表示没有参数 */
void f();       /* 在传统 C 中，表示 f 的参数表未知，并不表示没有参数 */
```

::: warning 订正 · C23 起变了
`void f();` 在 C89～C17 中确实表示「参数未指定」，编译器不会检查实参；但 **C23 起 `void f()` 已等价于 `void f(void)`**，明确表示不接收参数。写新代码时一律写 `void f(void)`，跨标准都不会有歧义。
:::

::: danger 易错点
C 语言**不允许函数嵌套定义**（函数里不能再定义函数）。GCC 的嵌套函数是非标准扩展。另外，`static` 局部变量虽然作用域仍在块内，但生存期是整个程序运行期，且只初始化一次 —— 它不属于这里说的「本地变量」常规情形。
:::

## 第5章 数组

### 5.1 定义数组

```c
<类型> 变量名称[元素数量];

int grades[100];
double weight[20];
```

- 元素数量必须是整数
- C99 之前：元素数量必须是编译时刻确定的字面量

### 5.2 数组的特点

数组是一种容器（放东西的东西），特点是：

- 其中所有的元素具有相同的数据类型
- 一旦创建，大小不能改变
- 数组中的元素在内存中是连续依次排列的
- 数组的每个单元就是该类型的一个变量，可以出现在赋值的左边或右边（在赋值左边的叫做**左值**）

```c
int a[10];              /* 10 个单元：a[0], a[1], ... a[9] */
a[2] = a[1] + 6;        /* 下标做左值，也可以做右值 */
```

使用数组时放在 `[ ]` 中的数字叫做**下标**或**索引**，下标从 0 开始计数：`grades[0]`、`grades[99]`、`average[5]`。

### 5.3 下标越界

::: danger 易错点
编译器和运行环境都**不会检查**数组下标是否越界（无论读还是写都不检查）。一旦程序运行时越界，可能造成数据被改写、导致程序崩溃（segmentation fault），但也可能运行得好好的、没造成严重后果 —— 所以保证下标在 `[0, 数组长度-1]` 之内是程序员的责任。
:::

原笔记还提到 `int a[0];` 可以存在。

::: warning 订正 · 零长数组不是标准 C
标准 C 要求数组长度是**大于 0** 的整型常量表达式（VLA 同理）。`int a[0];` 是 GCC / Clang 的扩展，加上 `-pedantic` 就会告警，在 MSVC 等编译器上会直接报错。结构体末尾的「柔性数组成员」要写 `int a[];`（C99），而且它只能作为结构体的最后一个成员、且不能单独定义对象 —— 这跟 `a[0]` 不是一回事。
:::

::: info 补充 · 越界为什么难以发现
它属于**未定义行为**，不是「一定会崩」。可用工具帮忙：`gcc -fsanitize=address`（ASan）会在越界访问时立刻报告文件名和行号；Valgrind、Clang 的 UBSan 也有效。调试阶段养成打开 sanitizer 的习惯，比事后找随机崩溃划算得多。
:::

### 5.4 数组初始化

**集成初始化**：

```c
int a[10] = {0};   /* 其余位置自动补零 */
```

**C99 支持定位初始化（C99 ONLY）**：

```c
int a[10] = { [0] = 2, [2] = 3, 6, };
```

- 用 `[n]` 在初始化数据中给出定位
- 没有定位的数据接在前面的位置之后（上例的 `6` 落在 `a[3]`）
- 其他位置的值补零
- 也可以不给出数组长度，让编译器去数：`int a[] = {1, 2, 3};`
- 特别适合初始数据稀疏的数组

**数组的大小**：`sizeof` 给出数组所占的字节数，元素个数 = `sizeof(a) / sizeof(a[0])`。

**数组的赋值**：一个数组不能直接赋值给另一个数组，只能逐个单元复制。

```c
for (i = 0; i < length; i++) {
    b[i] = a[i];   /* 复制数组 */
}
```

**const 数组**：

```c
const int a[] = {1, 2, 3, 4, 5, 6,};
```

::: danger 订正 · "数组变量已经是 const 的指针"
原笔记用「数组变量是 const 的指针」来解释为什么 `const int a[]` 表示每个单元都是 `const int`，这个说法不严谨：

- **数组名不是指针变量**。它是数组类型的表达式，在大多数上下文里会**退化**（decay）为指向首元素的指针值，这个值不是可修改的左值，所以不能赋值。
- 正因为是退化而不是"本身是指针"，`sizeof(a)` 在数组所在作用域得到**整个数组的字节数**，而一旦作为函数参数传进去，`sizeof(a)` 就变成指针大小了。
- `const int a[]` 里的 `const` 修饰的是**元素类型**，所以每个单元都是 `const int`，必须在初始化时赋值，之后不能改。

把「退化」和「指针变量」分清楚，后面第 6 章的指针运算才不会绕。
:::

::: info 补充 · 复制数组的正确姿势
除了循环，还可以用 `memcpy(b, a, sizeof(a))`（需 `<string.h>`），前提是目标空间足够且两块内存不重叠；重叠时用 `memmove`。注意 `sizeof(a)` 只在数组作用域内有效，传进函数后要显式传长度。
:::

### 5.5 遍历数组

通常都是使用 `for` 循环，让循环变量 `i` 从 0 到 **< 数组长度**，这样循环体内最大的 `i` 正好是数组最大的有效下标：

```c
for (i = 0; i < length; i++) {
    if (a[i] == key) {   /* 查找 */
        ret = i;
        break;
    }
}
```

**完整例：统计数字出现次数**

```c
const int number = 10;
int x;
int count[number];      /* 定义数组 */
int i;

for (i = 0; i < number; i++) {
    count[i] = 0;      /* 初始化数组 */
}

scanf("%d", &x);
while (x != -1) {
    if (x >= 0 && x <= 9) {
        count[x]++;    /* 数组参与运算 */
    }
    scanf("%d", &x);
}

for (i = 0; i < number; i++) {
    printf("%d:%d\n", i, count[i]);
}
```

::: danger 易错点
常犯的两个错误：

1. 循环结束条件写成 `<= 数组长度`（越界）；
2. 离开循环后，继续用 `i` 的值来做数组元素的下标（此时 `i` 已经等于数组长度，正好越界）。
:::

::: info 补充 · 让长度自己算
尽量别把长度写死成魔法数字：

```c
int a[] = {3, 1, 4, 1, 5};
size_t n = sizeof(a) / sizeof(a[0]);
for (size_t i = 0; i < n; i++) { ... }
```

`sizeof` 返回 `size_t`（无符号），循环变量也用 `size_t` 可避免有符号/无符号比较告警。
:::

### 5.6 二维数组

```c
int a[3][5];   /* 三行五列的矩阵 */
```

`a[i, j]` 是**错误**的 —— 逗号运算让整个表达式最后只表达为 `a[j]`（详见 2.11），二维数组必须写 `a[i][j]`。

**初始化**：

```c
int a[][5] = {
    {0, 1, 2, 3, 4},
    {2, 3, 4, 5, 6},
};
```

- 列数是必须给出的，行数可以由编译器来数
- 每个 `{ }` 一行，逗号分隔
- 最后的逗号可以存在，有古老的传统
- 如果省略，表示补零
- 也可以定位初始化（C99 ONLY）

::: info 补充 · 内存是"一维"的
二维数组在内存里仍然是**按行连续排列**的一整块：`a[0][0], a[0][1], ..., a[0][4], a[1][0], ...`。因此可以用 `a[0]` 当作指向首元素的指针做线性遍历，也解释了为什么声明时**只有第一维可以省略** —— 编译器必须知道一行有多长才能算出 `a[i]` 的偏移。

传二维数组给函数时，除第一维外的维度必须写全：

```c
void fill(int a[][5], int rows);        /* 等价写法：int (*a)[5] */
```
:::

## 第6章 指针

### 6.1 取地址运算 &

`scanf("%d", &i);` 中的 `&`：获得变量的地址，它的操作数必须是**变量**。

- `&` 不能对别的东西取地址（如 `a++`、`++i` 不是变量）
- 想要输出地址，用 `%p` 作占位符
- 地址的大小是否与 `int` 相同取决于编译器和平台
- 相邻数组元素的地址差正好是元素类型的大小（`int` 数组相邻元素相差 4 个字节）

```c
int i;
printf("%p", &i);
```

::: warning 订正 · %p 需要 void*
`%p` 期望的参数类型是 `void *`，而 `&i` 是 `int *`。虽然多数平台上两者表示相同，但可变参数不做类型转换，严格来说是未定义行为。正确写法：

```c
printf("%p\n", (void *)&i);
```
:::

::: info 补充 · 指针大小由数据模型决定
32 位程序通常 4 字节，64 位程序通常 8 字节，与 `int`（通常恒为 4 字节）无关。需要能容纳指针的整数类型用 `<stdint.h>` 的 `uintptr_t`，不要强转进 `int`。
:::

### 6.2 指针变量

**指针就是保存地址的变量。**

```c
int i;
int *p = &i;
```

::: danger 易错点
`int* p, q;` 中**只有 `p` 是指针**，`q` 是普通的 `int`！星号只修饰最近的变量名（写成 `int *p, q;` 与之等价）。建议每次只定义一个指针，或用 `typedef` / 分行声明。
:::

**示意图**：

```
普通变量的值是实际的值：
count  ┌─────┐
       │  7  │
       └─────┘

指针变量的值是另一个变量的地址：
countPtr ────► count
```

指针变量的值是「具有实际值的变量的地址」。

### 6.3 解引用 *

`*` 是一个单目运算符，用来访问指针的值所表示的地址上的变量。可以做右值也可以做左值（在左边是写，在右边是读取）：

```c
int k = *p;      /* 读取：k 得到 p 所指变量的值 */
*p = k + 1;      /* 写：p 所指的变量被改成 k+1 */
```

`*p` 是一个 `int`。

::: danger 补充 · 解引用前必须确认指针有效
对 `NULL`、未初始化、已 `free`、或指向已失效栈帧的指针解引用，都是未定义行为。养成两习惯：定义时立即初始化（`int *p = NULL;`），使用前判断（`if (p != NULL)`）。
:::

### 6.4 指针的应用场景

**1. 交换两个变量的值（配合函数，实现真正的交换）**

```c
void swap(int *pa, int *pb) {
    int t = *pa;
    *pa = *pb;
    *pb = t;
}
```

::: tip 提示
对照 4.6 的失败版本：函数拿到地址后，通过 `*` 访问到的就是调用处真正的变量，所以能修改它们。
:::

**2. 函数返回多个值**：函数返回运算的**状态**，结果通过指针返回。

常用的套路是让函数返回特殊的不属于有效范围内的值来表示出错：`-1` 或 `0`。但是当任何数值都是有效的可能结果时，就得把「状态」和「结果」分开返回了。

**3. 其他典型场景**：

- 需要传递较大的数据时作参数（省去复制）
- 传数组后对数组做操作
- 函数返回不止一个结果
- 需要函数来修改不止一个变量
- 动态申请的内存

### 6.5 const 与指针

**指针是 const**：表示一旦得到了某个变量的地址，不能再指向其他变量。

```c
int * const q = &i;
*q = 26;   /* OK */
q++;       /* ERROR */
```

**所指是 const**：表示不能通过这个指针去修改那个变量（**并不能使那个变量本身成为 const**）。

```c
const int *p = &i;
*p = 26;   /* ERROR（*p 是 const） */
i = 26;    /* OK */
p = &j;    /* OK */
```

::: tip 核心结论
> 规律：`const` 在 `*` 的**前面** → 所指的东西不能修改；`const` 在 `*` 的**后面** → 指针本身不能被修改。

```c
const int *p;        /* 所指只读 */
int const *p;        /* 同上，写法等价 */
int * const p;       /* 指针只读 */
const int * const p; /* 两者都只读 */
```
:::

**转换**：总是可以把一个**非 const** 的值转换成 const 的（反过来要显式强转，且可能引发 UB）。

**保护数组值**：因为把数组传给函数时传递的是地址，所以函数内部可以修改数组的值。为了保护数组不被函数破坏，可以把参数设为 const：

```c
void f(const int *x);
int sum(const int a[], int length);   /* 等价：a 的元素只读 */

int a = 15;         f(&a);        /* OK */
const int b = a;    f(&b);        /* OK */
b = a + 1;                       /* Error! */
```

当要传递的参数的类型是地址的时候，这是常用的手段：既能用较少的字节数传递值给参数，又能避免函数对外面的变量的修改。

### 6.6 指针运算

给一个指针加 1 表示要让指针指向**下一个变量**（地址增加 `sizeof(类型)`）：

```c
int a[10];
int *p = a;
*(p + 1);   /* -> a[1] */
```

- 如果指针不是指向连续分配的空间（如数组），则这种运算没有意义
- 可以对指针做的算术运算：给指针加、减一个整数（`+`、`+=`、`-`、`-=`）；递增递减（`++` / `--`）；两个指针相减（得到它们之间相差的**元素个数**）
- `*p++`：取出 p 所指的那个数据来，完事之后顺便把 p 移到下一个位置去
- `*` 的优先级虽然高，但是没有 `++` 高
- 指针比较：`<`、`<=`、`==`、`>`、`>=`、`!=` 都可以对指针做，比较的是它们在内存中的地址；数组中的单元的地址肯定是线性递增的
- 常用于数组类的连续空间操作，在某些 CPU 上可以直接被翻译成一条汇编指令

::: warning 补充 · 指针比较的边界
标准只保证**同一数组内**（以及"恰好越过末尾一个位置"）的指针比较和相减有定义；两个不相关对象的指针互相比较大小是未指定的。另外 `p + n` 越出数组范围（除了末尾后一位）本身就是 UB，即使不解引用。
:::

### 6.7 数组与指针

**0 地址**：内存中有 0 地址，但 0 地址通常是个不能随便碰的地址，所以指针不应该随意具有 0 值。因此可以用 0 地址来表示特殊的事情：返回的指针是无效的；指针没有被真正初始化（先初始化为 0）。`NULL` 是一个预定义的符号，表示 0 地址。

::: warning 订正 · 空指针不等于"物理地址 0"
`NULL` 是**空指针常量**，标准只保证它与任何有效对象/函数的指针都不相等，并不要求它在机器层面就是全 0 位模式（虽然绝大多数实现如此）。写 `NULL` 或 C23 的 `nullptr`，不要写 `0` 或 `(void*)0` 之外的魔法值；判断时用 `if (p == NULL)` 或简写 `if (!p)`。
:::

**指针的类型**：

- 无论指向什么类型，所有指针的**大小**都是一样的，因为都是地址
- 但是指向不同类型的指针是不能直接互相赋值的，这是为了避免用错指针
- `void *` 表示「不知道指向什么的指针」，可以和其他对象指针互相转换（无需强转）
- 指针也可以转换类型：

```c
int *p = &i;
void *q = (void *)p;
```

这并没有改变 `p` 所指的变量的类型，只是让后面用不同的眼光通过 `q` 看它所指的变量。

::: danger 订正 · void* 不能做算术
原笔记写「`void *` 计算时与 `char *` 相同」。标准 C 里 `void *` 是**不完整类型**，不能解引用、也不能做 `+` / `++` 等指针算术（GCC 把它当 `char *` 是非标准扩展，`-pedantic` 会告警）。要做字节级偏移，显式转成 `unsigned char *` 或 `char *`。
:::

**数组与指针的关系**：

数组变量本身表达地址，所以：

```c
int a[10];
int *p = a;        /* 不需要 & 取地址 */
```

但是数组的单元表达的是变量，需要 `&` 取地址。

- `a == &a[0]`
- `[ ]` 运算符可以对数组做，也可以对指针做：`p[0] <==> a[0]`
- `*` 运算符可以对指针做，也可以对数组做：`*a = 25;`
- 数组名不能赋值（详见第 5 章「退化」的订正）

**函数参数表中的数组实际上是指针**：`sizeof(a) == sizeof(int *)`，但是可以使用数组的运算符 `[ ]` 进行运算。

```c
int isPrime(int x, int knownPrimes[], int numberofKnownPrimes) {
    int ret = 1;
    int i;
    for (i = 0; i < numberofKnownPrimes; i++) {
        if (x % knownPrimes[i] == 0) {
            ret = 0;
            break;
        }
    }
    return ret;
}
```

以下四种函数原型是等价的：

```c
int sum(int *ar, int n);
int sum(int *, int);
int sum(int ar[], int n);
int sum(int [], int);
```

### 6.8 动态内存分配

```c
#include <stdlib.h>

void *malloc(size_t size);
```

- 向 `malloc` 申请空间的单位是**字节**
- 返回的结果是 `void *`，需要转换为需要的类型：`(int *)malloc(n * sizeof(int))`
- 如果没空间，则 `malloc` 会返回 `0` 或者 `NULL`
- 申请过的空间，最终都应该要还（借出来，迟早都是要还的）
- 只能还申请来的空间的**首地址**

**`free()`**：把申请得来的空间还给「系统」。

::: danger 易错点 · 常见问题
1. 申请了没 `free` —— 长时间运行内存逐渐下降（新：忘了；旧：找不到合适的 `free` 时机）
2. `free` 过了再 `free`（double free）
3. 地址变过了，直接去 `free`（传入的不是当初返回的首地址）
:::

::: info 补充 · 现代写法与配套函数
`malloc` 的返回类型在 C 里**不需要强转**（`void *` 会自动转换），强转反而可能掩盖漏写 `#include <stdlib.h>` 的错误。推荐写法：

```c
int *a = malloc(n * sizeof *a);   /* 跟着变量类型走，改类型时不会漏改 */
if (a == NULL) { /* 处理失败 */ }
/* ... 使用 ... */
free(a);
a = NULL;                          /* 避免悬垂指针被误用 */
```

配套：`calloc(n, size)` 会把内存清零；`realloc(p, new_size)` 调整大小（失败时返回 NULL 且**原内存仍有效**，别直接把返回值赋回 `p`）。另外 `malloc` 出来的内存**未初始化**，直接读是 UB。检测泄漏可用 ASan 的 LeakSanitizer 或 Valgrind。
:::

## 第7章 字符串

### 7.1 字符数组与字符串

```c
char word[] = {'H', 'e', 'l', 'l', 'o', '!'};
```

| word[0] | word[1] | word[2] | word[3] | word[4] | word[5] |
| --- | --- | --- | --- | --- | --- |
| H | e | l | l | o | ! |

::: danger 易错点
这**不是 C 语言的字符串**，因为不能用字符串的方式做计算 —— 它缺少结尾的 0。
:::

**字符串**：以 0（整数 0）结尾的一串字符。

- `0` 或 `'\0'` 是一样的，但是和 `'0'`（字符 0）不同
- `0` 标志字符串的结束，但它不是字符串的一部分；计算字符串长度的时候不包含这个 0
- 字符串以数组的形式存在，以数组或指针的形式访问（更多的是以指针的形式）
- C 语言的字符串是以字符数组的形态存在的
- 不能对字符串用运算符做运算
- 通过数组的方式可以遍历字符串
- 唯一特殊的地方是字符串字面量可以用来初始化字符数组，以及标准库提供了一系列字符串函数（`string.h`）

::: warning 订正 · '\0' 与整数 0 的大小
原笔记写「`'\0'` 是一个字节，整数 `0` 是四个字节」。在 C 里，**字符常量 `'\0'` 的类型是 `int`**（通常 4 字节），并不是 `char`；只有把它存进 `char` 数组时，才按 `char` 占 1 字节。

准确的记法是：`'\0'` 与 `0` **值相等**（都是 0），`sizeof('\0') == sizeof(int)`，而 `sizeof(char) == 1`。字符串末尾那一个字节是 0，与 `'0'`（ASCII 48）完全不同。
:::

::: info 补充 · 字符串长度与数组长度
`char s[] = "hello";` 的数组长度是 **6**（5 个字符 + 1 个 `'\0'`），`strlen(s)` 是 **5**。`sizeof` 算存储空间，`strlen` 算到第一个 `'\0'` 之前的字符数，两者别混用。
:::

### 7.2 字符串常量与指针

```c
char *s = "Hello, world!";
```

`s` 是一个指针，初始化为指向一个字符串常量。由于这个常量所在的地方是**只读区域**，所以实际上应该是 `const char *s`；但由于历史原因，编译器接受不带 `const` 的写法。然而试图对 `s` 所指的字符串做写操作会导致严重的后果。

如果需要修改字符串，应该用数组：

```c
char s[] = "Hello, world!";
```

**指针还是数组？**

| | 含义 |
| --- | --- |
| `char *str = "Hello";` | 字符串常量，只读；`str` 可改指向 |
| `char word[] = "Hello";` | 在本地变量空间里复制了一份，可改内容；`word` 不可改指向 |

- 数组：这个字符串「在这里」（作为本地变量空间，自动被回收）
- 指针：这个字符串「不知道在哪」（处理参数、动态分配空间）
- 如果要**构造**一个字符串 → 数组；如果要**处理**一个字符串 → 指针

::: danger 订正 · 请写 const
`char *s = "Hello";` 在 C 里能编译，但 `s[0] = 'h';` 是**未定义行为**（多数平台直接段错误）。写成 `const char *s = "Hello";` 后，这类错误会在**编译期**被拦下。C++ 早已要求必须写 `const`，C 只是因为历史兼容才放行 —— 新代码一律加 `const`。
:::

### 7.3 字符串的输入输出

```c
char string[8];
scanf("%s", string);
printf("%s", string);
```

- `scanf` 读一个单词（到空格、tab 或回车为止）
- `scanf` 是**不安全**的，因为不知道要读的内容的长度（可能越界）

**安全的输入**：

```c
char string[8];
scanf("%7s", string);
```

在 `%` 和 `s` 之间的数字表示最多允许读的字符数量，这个数字应该比数组长度**小 1**（给结尾的 `'\0'` 留位置）。

::: info 补充 · 更推荐 fgets
`scanf("%s")` 有两个硬伤：遇空格就停、宽度必须手算且容易和数组长度不同步。更稳妥的是：

```c
char buf[128];
if (fgets(buf, sizeof buf, stdin) != NULL) {
    buf[strcspn(buf, "\n")] = '\0';   /* 去掉末尾换行 */
}
```

`fgets` 会把宽度和 `'\0'` 一起算好，并保留空格。注意它**会**把换行符读进来，所以要处理。
:::

**空字符串**：

```c
char buffer[100] = "";   /* 空字符串，buffer[0] == '\0' */
char buffer[] = "";      /* 这个数组的长度只有 1！只放得下结尾的 '\0' */
```

::: danger 易错点
```c
char *string;
scanf("%s", string);     /* 严重错误 */
```
以为 `char *` 就是「字符串类型」，定义了一个字符串类型的变量 `string` 就可以直接使用了。由于没有对 `string` 初始化为 0（没有指向任何有效空间），所以不一定每次运行都出错，但随时可能崩。指针必须先指向一块有效内存（数组、`malloc` 的结果）再写入。
:::

### 7.4 程序参数

```c
int main(int argc, char const *argv[])
```

- `argv[0]` 是命令本身
- 当使用 Unix 的符号链接时，反映的是符号链接的名字
- `argc` 是参数个数，`argv[argc]` 保证为 `NULL`

::: info 补充
`argc` / `argv` 的名字只是约定，可以改，但类型必须是 `int` 和 `char **` 等价形式。命令行参数都是**字符串**，要当数字用需要 `strtol`（比 `atoi` 好在能检测转换失败）。
:::

### 7.5 单字符输入输出

```c
int putchar(int c);   /* 向标准输出写一个字符；返回写了的字符，EOF(-1) 表示写失败 */
int getchar(void);    /* 从标准输入读一个字符 */
```

`getchar` 的返回类型是 `int` 而不是 `char`，是为了能返回 `EOF`（-1）。

输入结束标志：Windows → `Ctrl-Z`；Unix / macOS → `Ctrl-D`。

::: danger 补充 · 别用 char 接 getchar
```c
char c;
while ((c = getchar()) != EOF) { ... }   /* 可能死循环或提前结束 */
```
若 `char` 是无符号的，`EOF`(-1) 会被转成 255，永远不等于 `EOF`；若是有符号的，值为 0xFF 的合法字符会被误判为 `EOF`。**变量必须是 `int`**。
:::

### 7.6 字符串函数（string.h）

**strlen —— 求字符串长度**：

```c
size_t strlen(const char *s);
```

返回 `s` 的字符串长度（不包括结尾的 0）。

::: info 补充 · 返回值是 size_t
`strlen` 返回无符号的 `size_t`，写 `if (strlen(s) - 1 < 0)` 永远不会成立（会回绕成很大的正数）。另外 `strlen` 是 O(n)，在循环条件里反复调用会让算法退化成 O(n²)。
:::

**strcmp —— 比较两个字符串**：

```c
int strcmp(const char *s1, const char *s2);
```

原笔记写「返回：0 表示 s1 == s2；1 表示 s1 > s2；-1 表示 s1 < s2（教材简化说法）」，并在旁边补了一句说明标准实际规定返回 ASCII 差值。

::: warning 订正 · 只判断符号
标准只规定返回值是**负 / 0 / 正**，并不保证是 ±1。常见实现返回首个不同字符的差值（例如 `strcmp("b","a")` 可能返回 1，但 `strcmp("z","a")` 返回 25）。所以：

```c
if (strcmp(a, b) == 0)  { /* 相等 */ }
if (strcmp(a, b) > 0)   { /* a 更大 */ }
if (strcmp(a, b) == 1)  { /* 错：依赖具体实现 */ }
```

需要只比较前 n 个字符用 `strncmp`。
:::

**strcpy —— 拷贝字符串**：

```c
char *strcpy(char *restrict dst, const char *restrict src);
```

- 把 `src` 的字符串拷到 `dst`（**目的在前，源在后**）
- `restrict` 表明 `src` 和 `dst` 不重叠（C99）
- 返回 `dst`，为了能链起代码来
- 类似地还有 `strcat`（字符串拼接），同样是目的在前、源在后

复制一个字符串（先申请空间，再拷贝）：

```c
char *dst = (char *)malloc(strlen(src) + 1);
strcpy(dst, src);
```

::: tip 提示
申请 `strlen(src) + 1` 个字节而不是 `strlen(src)` —— 多出的 1 个字节放结尾的 `'\0'`。
:::

::: danger 补充 · strcpy / strcat 的溢出风险
这两个函数**不检查目标空间大小**，是历史上缓冲区溢出漏洞的主要来源。更安全的是 `snprintf(dst, sizeof dst, "%s", src)`，或在明确边界时用 `strncpy`（但它不保证补 `'\0'`，必须手动加）。`strncat` 的 n 参数是"还可追加的最大字符数"，也容易用错。
:::

**字符串中找字符**：

```c
char *strchr(const char *s, int c);    /* 从前往后找 */
char *strrchr(const char *s, int c);   /* 从后往前找 */
```

**字符串中找字符串**：

```c
char *strstr(const char *s1, const char *s2);
char *strcasestr(const char *s1, const char *s2);   /* 忽略大小写 */
```

返回 `NULL` 表示没有找到。

::: info 补充 · strcasestr 不是标准 C
`strcasestr` 来自 POSIX / GNU 扩展，MSVC 上没有，编译时要定义 `_GNU_SOURCE` 之类的宏。可移植做法是自己转小写后比较，或用平台对应的函数（Windows 上是 `_stristr`）。另外这些函数返回的指针指向**原字符串内部**，不要 `free`。
:::

## 第8–9章 枚举与结构体

### 第8章 枚举

#### 8.1 枚举的定义

枚举是一种用户定义的数据类型，用关键字 `enum` 按如下语法声明：

```c
enum 枚举类型名字 { 名字0, …, 名字n };
```

枚举类型名字通常并不真的使用，要的是括号里的名字，因为它们就是**常量符号**，类型是 `int`，值依次从 0 到 n：

```c
enum colors { red, yellow, green };
```

这就创建了三个常量，`red` 的值是 0，`yellow` 是 1，`green` 是 2。

当需要一些可以排列起来的常量值时，定义枚举的意义就是给这些常量值起了名字。

::: info 补充 · 枚举 vs `#define` vs `const`
`#define RED 0` 只是文本替换，没有类型、调试器里看不到名字；`const int RED = 0;` 在 C 里不是编译期常量（不能作 `case` 标签、不能定义数组长度）；枚举常量是真正的编译期整型常量，还能被调试器显示成 `red`。C23 起可以用 `enum color : unsigned char { ... };` 显式指定底层类型，节省空间。
:::

#### 8.2 枚举的使用

```c
#include <stdio.h>

enum color { red, yellow, green };

void f(enum color c);

int main(void) {
    enum color t = red;
    scanf("%d", &t);
    f(t);
    return 0;
}

void f(enum color c) {
    printf("%d\n", c);
}
```

- 枚举量可以作为值
- 枚举类型可以跟上 `enum` 作为类型
- 但是实际上是以整数来做内部计算和外部输入输出

::: warning 订正 · 扫进枚举变量要小心
`scanf("%d", &t)` 要求 `t` 的底层类型恰好与 `int` 兼容。标准只保证枚举常量是 `int`，**枚举类型本身**的兼容整数类型由实现选择（虽然通常是 `int`）。更稳妥的做法是先读入 `int`，做范围校验后再赋给枚举变量。
:::

#### 8.3 套路：自动计数的枚举

```c
enum COLOR { RED, YELLOW, GREEN, NumCOLORS };
```

最后那个名字 `NumCOLORS` 自动等于枚举量的个数（这里是 3）。这样需要遍历所有枚举量、或者需要建一个以枚举量做下标的数组的时候就很方便了：

```c
#include <stdio.h>

enum COLOR { RED, YELLOW, GREEN, NumCOLORS };

int main(int argc, char const *argv[]) {
    int color = -1;
    char *ColorNames[NumCOLORS] = { "red", "yellow", "green", };
    char *colorName = NULL;

    printf("输入你喜欢的颜色的代码：");
    scanf("%d", &color);

    if (color >= 0 && color < NumCOLORS) {
        colorName = ColorNames[color];
    } else {
        colorName = "unknown";
    }

    printf("你喜欢的颜色是%s\n", colorName);
    return 0;
}
```

::: tip 提示
这个套路的关键约定是：**计数项永远放最后、永远不显式赋值**。中间插入新枚举量时，`NumCOLORS` 会自动跟着变，数组长度和循环上界都不用手改。字符串数组建议写成 `const char *`，理由见第 7 章。
:::

#### 8.4 枚举量指定值

声明枚举量时可以指定值：

```c
enum COLOR { RED = 1, YELLOW, GREEN = 5, NumCOLORS };
```

未指定值的名字是前一个值 + 1（所以 `YELLOW` 是 2，`NumCOLORS` 是 6）。

```c
#include <stdio.h>

enum COLOR { RED = 1, YELLOW, GREEN = 5, NumCOLORS };

int main(int argc, char const *argv[]) {
    printf("code for GREEN is %d\n", GREEN);
    return 0;
}
```

::: danger 易错点
枚举只是 int：即使给枚举类型的变量赋一个不存在的整数值，也没有任何 warning 或 error。（C23 起若指定了底层类型，超出范围的行为由实现定义。）所以**不要**把枚举当成「自动校验的有限集合」，边界检查仍要自己写 —— 上例中的 `if (color >= 0 && color < NumCOLORS)` 不能省。

另外注意：一旦中间手动指定了大数值（如 `GREEN = 5`），`NumCOLORS` 就不再等于**枚举个数**了（这里变成 6，但只有 3 个颜色）。「自动计数」套路要求**所有值都不显式指定**。
:::

#### 8.5 小结

- 枚举类型可以当作类型使用，但是实际上很少需要这么用
- 如果有意义上排列的名字，枚举比 `const int` 方便
- 枚举比宏（macro）好，因为枚举有类型信息，调试时能看到名字

---

### 第9章 结构体

#### 9.1 结构体的定义

结构体是用户定义的复合数据类型，把相关联的数据组合在一起：

```c
struct date {
    int year;
    int month;
    int day;
};
```

**匿名结构体**：定义时不写名字，仅当场定义变量（一次性使用）。

**`typedef` 起别名，简化使用**：

```c
typedef struct {
    int year;
    int month;
    int day;
} Date;
```

之后就可以直接写 `Date today;`。

::: info 补充 · struct 标签与 typedef 的区别
`struct date { ... };` 之后要写 `struct date today;`（C 里 `struct` 不能省）；`typedef` 之后写 `Date today;`。两者可以并存：

```c
typedef struct date { ... } Date;
```

需要在结构体内部引用自身（如链表节点）时，**必须**有标签：`typedef struct Node { struct Node *next; } Node;`，因为 typedef 的名字在定义完成前还不可用。
:::

#### 9.2 结构体变量

- **结构体变量赋值**：同类型的结构体变量可以直接整体赋值（`today = other;`）
- **结构体嵌套**：结构体的成员可以是另一个结构体
- **访问结构体成员**：变量名 + `.` 来操作

```c
Date today;
today.year  = 2026;
today.month = 11;
```

如果是指针的话要用变量名 + `->` 来操作：

```c
Date *p = &today;
p->day = 4;          /* 等价于 (*p).day = 4; */
```

#### 9.3 结构体与函数、数组、指针

- **结构体作为函数参数**：整体传值（会复制整个结构体）；结构体大的时候用指针传参更高效，只读时加 `const`
- **结构体数组**：

```c
Date dates[10];
dates[0].year = 2020;
```

- **结构体指针**：函数内通过 `->` 修改调用处的结构体

```c
void set_date(Date *p, int y, int m, int d) {
    p->year  = y;
    p->month = m;
    p->day   = d;
}
```

::: danger 补充 · 结构体不能用 == 比较
即使两个结构体所有成员都相等，`a == b` 也是**编译错误**（`==` 不支持结构体类型）。因为填充字节（padding）的内容不确定，标准也不打算逐字节比较。要自己写比较函数，或逐成员比较；同理也不能直接 `memcmp` 整个结构体。

赋值（`a = b`）倒是合法的，且会正确处理填充字节之外的所有成员。
:::

#### 9.4 内存对齐

结构体在内存中的大小**不一定等于**各成员之和。编译器为了让访问速度更快，会让每个成员对齐到其类型大小的整数倍地址上（填充 padding 字节）。

::: tip 例题
```c
struct { char c; int i; };
```

在典型 32/64 位平台上大小是 **8** 而不是 5 —— `char` 之后填充了 3 个字节，让 `int` 对齐到 4 的整数倍地址。
:::

::: tip 提示
成员的排列顺序会影响结构体大小：把大的成员放前面通常更省空间。可以用 `sizeof` 查看实际大小。
:::

::: info 补充 · 对齐的实用工具
- `offsetof(struct S, member)`（`<stddef.h>`）能直接看某个成员的偏移，验证填充位置；
- `_Alignof(type)` / `alignof`（C11）查看类型对齐要求；
- `#pragma pack(1)` 或 `__attribute__((packed))` 可取消填充，但会导致**非对齐访问**，在部分架构上变慢甚至触发异常，主要用于与外部二进制格式/硬件寄存器严格对应时；
- 结构体末尾还可以放**柔性数组成员** `char data[];`（C99），配合一次 `malloc(sizeof(S) + n)` 分配，避免二次分配和指针间接访问。

注意：示例大小 8 是常见平台的结果，标准并不保证；请用 `sizeof` 实测，不要写死。
:::

### 1. 找零计算器

**思路**：输入金额，按面额从大到小用贪心法计算各面额需要的张数（`/` 算张数、`%` 算余额）。

```c
#include <stdio.h>

int main() {
    int money, n, i;
    int faces[] = {100, 50, 20, 10, 5, 1};

    printf("请输入金额：");
    scanf("%d", &money);

    for (i = 0; i < 6; i++) {
        n = money / faces[i];
        money %= faces[i];
        if (n > 0) {
            printf("%d 元：%d 张\n", faces[i], n);
        }
    }
    return 0;
}
```

::: info 补充
贪心对人民币这类**规范面额系统**是最优的；若换成任意面额集合（如 `{1, 3, 4}`，凑 6），贪心会给出 4+1+1 而不是最优的 3+3，那时要用动态规划。另外应校验 `money >= 0`。
:::

### 2. 输出百以内的素数

**思路**：素数只能被 1 和自身整除。嵌套循环逐个判断 2~99 的每个数。

```c
#include <stdio.h>

int main() {
    int i, j, isPrime;
    for (i = 2; i < 100; i++) {
        isPrime = 1;
        for (j = 2; j < i; j++) {
            if (i % j == 0) { isPrime = 0; break; }
        }
        if (isPrime) { printf("%d ", i); }
    }
    return 0;
}
```

::: info 补充
内层只需试除到 `j * j <= i`，复杂度从 O(n²) 降到 O(n√n)。还可以跳过所有偶数。注意 `j * j` 在 `i` 很大时可能溢出，写成 `j <= i / j` 更稳。
:::

### 3. 输出前 50 个素数

**思路**：计数器统计已找到的素数个数，找满 50 个就停。

```c
#include <stdio.h>

int main() {
    int x = 2, cnt = 0, i, isPrime;
    while (cnt < 50) {
        isPrime = 1;
        for (i = 2; i < x; i++) {
            if (x % i == 0) { isPrime = 0; break; }
        }
        if (isPrime) { printf("%d ", x); cnt++; }
        x++;
    }
    return 0;
}
```

### 4. 凑硬币（一角、两角、五角凑出 10 元以下的金额）

**思路**：穷举五角和两角的个数，一角的个数由余额推算（单位统一为角，金额 < 100）。

```c
#include <stdio.h>

int main() {
    int amount;             /* 单位：角 */
    int x, y, z, count = 0;

    printf("请输入金额（角，10 元以下）：");
    scanf("%d", &amount);

    for (x = 0; x <= amount / 5; x++) {       /* 五角个数 */
        for (y = 0; y <= amount / 2; y++) {   /* 两角个数 */
            z = amount - 5 * x - 2 * y;       /* 剩余由一角补 */
            if (z >= 0) {
                printf("%d个五角 %d个两角 %d个一角\n", x, y, z);
                count++;
            }
        }
    }
    printf("共 %d 种凑法\n", count);
    return 0;
}
```

### 5. 求和

**思路**：循环累加，注意 `sum` 初始化为 0。

```c
#include <stdio.h>

int main() {
    int n, i, sum = 0;
    printf("请输入 n：");
    scanf("%d", &n);
    for (i = 1; i <= n; i++) { sum += i; }
    printf("1 到 %d 的和是 %d\n", n, sum);
    return 0;
}
```

::: info 补充
有闭式公式 `n * (n + 1) / 2`，复杂度 O(1)；但循环版也要防溢出：先除后乘（`n % 2 == 0 ? (n/2)*(n+1) : n*((n+1)/2)`）能撑到更大的 n。
:::

### 6. 整数的逆序输出

**思路**：反复 `%10` 取个位、`/10` 去个位，把取出的位接到结果尾部。

```c
#include <stdio.h>

int main() {
    int x, digit, ret = 0;
    printf("请输入一个整数：");
    scanf("%d", &x);
    while (x > 0) {
        digit = x % 10;
        ret = ret * 10 + digit;
        x /= 10;
    }
    printf("逆序为 %d\n", ret);
    return 0;
}
```

### 7. 整数正序输出（逐位分解）

**思路**：先构造最高位的 mask（10、100、…），再反复 `/mask` 取最高位、`%mask` 去掉最高位。

```c
#include <stdio.h>

int main() {
    int x, mask = 1, t;
    printf("请输入一个整数：");
    scanf("%d", &x);

    t = x;
    while (t > 9) {          /* 构造最高位的 mask */
        t /= 10;
        mask *= 10;
    }
    do {
        printf("%d", x / mask);
        if (mask > 9) printf(" ");
        x %= mask;
        mask /= 10;
    } while (mask > 0);

    return 0;
}
```

::: info 补充
`x = 0` 时 mask 保持 1，会正确输出 `0`；`x` 为负数时 `t > 9` 不成立，但 `x / mask` 为负，需要先取绝对值并处理 `INT_MIN`（其绝对值溢出）。
:::

### 8. 求最大公约数

**思路**：辗转相除法（欧几里得算法）：`gcd(a, b) = gcd(b, a % b)`，直到 b 为 0。

```c
#include <stdio.h>

int main() {
    int a, b, t;
    printf("请输入两个整数：");
    scanf("%d %d", &a, &b);
    while (b != 0) {
        t = a % b;
        a = b;
        b = t;
    }
    printf("最大公约数是 %d\n", a);
    return 0;
}
```

::: info 补充
复杂度 O(log min(a,b))。输入含 0 时也成立（`gcd(a, 0) = a`）；含负数时结果可能为负，先取绝对值更符合直觉。最小公倍数可用 `a / gcd * b`（先除后乘防溢出）。
:::

### 9. 水仙花数

**思路**：三位数等于其各位数字的**立方和**。分解出百位、十位、个位后判断。

```c
#include <stdio.h>

int main() {
    int i, a, b, c;
    for (i = 100; i <= 999; i++) {
        a = i / 100;         /* 百位 */
        b = i / 10 % 10;     /* 十位 */
        c = i % 10;          /* 个位 */
        if (a*a*a + b*b*b + c*c*c == i) {
            printf("%d\n", i);
        }
    }
    return 0;
}
```

::: info 补充
100~999 中共有 4 个：153、370、371、407。别和「各位数字之和」混淆 —— 那是判断能否被 3 整除的规则。
:::

### 10. 九九乘法表

**思路**：嵌套循环，外层控制行（1~9），内层控制列（1~行号）。

```c
#include <stdio.h>

int main() {
    int i, j;
    for (i = 1; i <= 9; i++) {
        for (j = 1; j <= i; j++) {
            printf("%d×%d=%d\t", j, i, i * j);
        }
        printf("\n");
    }
    return 0;
}
```

### 11. 统计素数并求和

**思路**：在 100~200 之间判断素数，是素数则计数并累加。判断时只需试除到 `j * j <= i`。

```c
#include <stdio.h>

int main() {
    int i, j, isPrime, count = 0, sum = 0;
    for (i = 100; i <= 200; i++) {
        isPrime = 1;
        for (j = 2; j * j <= i; j++) {
            if (i % j == 0) { isPrime = 0; break; }
        }
        if (isPrime) { count++; sum += i; }
    }
    printf("素数个数：%d，和：%d\n", count, sum);
    return 0;
}
```

### 12. 猜数字游戏（给出一个数字，让计算机猜）

**思路**：人在心中想一个 1~100 的数，计算机用**二分查找**猜，人回答「大了 / 小了 / 对了」。

```c
#include <stdio.h>

int main() {
    int low = 1, high = 100, mid;
    char ans;

    printf("请在心中想一个 1~100 的数，按回车开始\n");
    getchar();

    while (low <= high) {
        mid = (low + high) / 2;
        printf("我猜是 %d？(大了L / 小了S / 对了Y)：", mid);
        scanf(" %c", &ans);
        if (ans == 'Y' || ans == 'y') {
            printf("我猜中啦！\n"); return 0;
        } else if (ans == 'L' || ans == 'l') {
            high = mid - 1;         /* 猜大了 */
        } else {
            low = mid + 1;          /* 猜小了 */
        }
    }
    printf("不可能！你骗我！\n");
    return 0;
}
```

::: warning 订正 · 提示文字要和输出一致
原代码的提示只写 `L/S/对Y`，没说明 L、S 分别代表什么，很容易答反。上面把提示改成「大了 L / 小了 S」，与 `high = mid - 1`、`low = mid + 1` 的分支对应。另外 `scanf(" %c")` 中 `%c` **前面的空格不能删** —— 它用来吃掉上一次输入留下的换行符。

`mid = (low + high) / 2` 在 `low + high` 很大时可能溢出，通用写法是 `low + (high - low) / 2`。
:::

### 13. 构造素数表

**思路**：筛法（埃拉托斯特尼筛法）：把每个素数的倍数全部划掉，剩下的就是素数。

```c
#include <stdio.h>

int main() {
    const int n = 100;
    int prime[n + 1];       /* 0 表示是素数，1 表示被划掉 */
    int i, j;

    for (i = 0; i <= n; i++) { prime[i] = 0; }

    for (i = 2; i * i <= n; i++) {
        if (prime[i] == 0) {
            for (j = i * i; j <= n; j += i) {
                prime[j] = 1;
            }
        }
    }

    for (i = 2; i <= n; i++) {
        if (prime[i] == 0) { printf("%d ", i); }
    }
    return 0;
}
```

::: info 补充
复杂度 O(n log log n)，比逐个数试除快得多。`j` 从 `i * i` 开始是因为更小的倍数已被更小的素数划掉了。

注意 `const int n = 100;` 在 C 里**不是编译期常量**，`int prime[n+1]` 属于 VLA（C99 起支持，C11 起为可选特性，MSVC 不支持）。要兼容所有编译器，用 `#define N 100` 或 `enum { N = 100 };`，或直接 `malloc`。另外 0 和 1 不是素数，输出从 2 开始是对的。
:::

### 14. 井字棋

**思路**：用 3×3 二维数组存棋盘，双方轮流落子，每次落子后检查横、竖、对角线是否连成一条线。

```c
#include <stdio.h>

char board[3][3];       /* ' ' 空，'X'，'O' */

void init(void) {
    int i, j;
    for (i = 0; i < 3; i++)
        for (j = 0; j < 3; j++)
            board[i][j] = ' ';
}

void draw(void) {
    printf(" %c | %c | %c \n", board[0][0], board[0][1], board[0][2]);
    printf("---+---+---\n");
    printf(" %c | %c | %c \n", board[1][0], board[1][1], board[1][2]);
    printf("---+---+---\n");
    printf(" %c | %c | %c \n", board[2][0], board[2][1], board[2][2]);
}

int win(char c) {
    int i;
    for (i = 0; i < 3; i++) {
        if (board[i][0] == c && board[i][1] == c && board[i][2] == c) return 1;
        if (board[0][i] == c && board[1][i] == c && board[2][i] == c) return 1;
    }
    if (board[0][0] == c && board[1][1] == c && board[2][2] == c) return 1;
    if (board[0][2] == c && board[1][1] == c && board[2][0] == c) return 1;
    return 0;
}

int main(void) {
    int x, y, turn = 0;
    char c;

    init();
    draw();

    while (turn < 9) {
        c = (turn % 2 == 0) ? 'X' : 'O';
        printf("%c 落子，输入行列（0-2 0-2）：", c);
        scanf("%d %d", &x, &y);
        if (x < 0 || x > 2 || y < 0 || y > 2 || board[x][y] != ' ') {
            printf("无效位置，重新输入\n");
            continue;
        }
        board[x][y] = c;
        draw();
        if (win(c)) { printf("%c 获胜！\n", c); return 0; }
        turn++;
    }
    printf("平局！\n");
    return 0;
}
```

::: info 补充
`scanf("%d %d", &x, &y)` 若读到非法字符会返回 0，而 `x`、`y` 保持未初始化 —— 此时后面的越界判断也是不可靠的。应检查返回值并清空输入缓冲：

```c
if (scanf("%d %d", &x, &y) != 2) {
    while (getchar() != '\n') { }
    printf("请输入两个数字\n");
    continue;
}
```
