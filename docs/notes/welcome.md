# 欢迎来到知识库

这是基础框架里的第一篇示例文章，用来演示 Markdown 会被排成什么样。以后你把自己写的 `.md` 文件放进 `docs/notes/` 目录，左侧导航就会自动出现对应条目，不需要手工改配置。

## 标题层级会自动形成目录

二级标题和三级标题会被收集到页面右侧的「本页目录」里，长文章可以快速跳转。

### 一个三级标题

正文段落会自动按适合阅读的行宽和行距排版，中英文混排也能正常显示。

## 常见的排版元素

- 无序列表第一项
- 无序列表第二项
  - 嵌套的列表项

1. 有序列表第一项
2. 有序列表第二项

> 引用块可以用来放提醒、结论或者原文摘录。

| 内容类型 | 展示方式 | 原文是否保留 |
| --- | --- | --- |
| Markdown | 排好版的文章页 | 是 |
| PDF | 在线预览 + 下载 | 是 |
| 图片 | 直接嵌在文章里 | 是 |

行内代码 `int a = 1;` 和代码块也都支持：

```c
#include <stdio.h>

int main(void) {
    printf("hello\n");
    return 0;
}
```
