# 全站学习地图与跨科索引

> 这篇不是新学科，而是全站导航：先按目标选路线，再用跨科表把同一概念的不同口径接起来，最后按计算题索引查漏补缺。

## 1. 先选学习目标

| 目标 | 推荐顺序 | 先修要求 | 学完应能完成 |
| --- | --- | --- | --- |
| **CPA 六科** | 会计 → 税法 → 财管 → 审计 → 经济法 → 战略 | 基础会计概念、简单财算 | 做题时能区分会计处理、税务处理、估值与风险判断 |
| **408 计算机四门** | C 基础 → 数据结构 → 组成原理 → 操作系统 → 计算机网络 | 二进制、基本程序设计 | 手算复杂度、地址转换、调度、子网与协议流程 |
| **经济与金融** | 数学 → 微观 → 宏观 → 计量 → 利息理论 → 金融学 → 证券投资 | 微积分、线性代数、概率统计 | 从模型假设推出均衡、检验、定价与投资结论 |
| **数据科学与编程** | C/Python/MATLAB → 数据结构 → 数据库 → 数据挖掘 → 机器学习 → 机器学习理论 | 编程基础、线性代数、概率统计 | 完成数据清洗、建模、评估、调参与结果解释 |

**组合路线**：CPA 会计/税法/财管可与数学、计量、金融交叉；408 路线可与 Java、数据库、机器学习交叉。不要同时开四条主线，先选一条走完再扩展。

## 2. 跨科概念地图

| 核心概念 | 工具基础 | 主要应用 | 最常见的跨科误区 |
| --- | --- | --- | --- |
| **边际、弹性与最优化** | 导数、拉格朗日乘数 | 微观均衡、垄断定价、要素需求、资本预算 | 把“斜率”直接当弹性；忽略约束与二阶条件 |
| **现值、贴现与利率** | 指数、对数、级数 | 债券、年金、项目估值、久期、货币时间价值 | 混淆名义利率、实际利率、YTM 与即期利率 |
| **概率、方差与风险** | 概率分布、协方差、大数定律 | 计量推断、组合理论、CAPM、保险与审计抽样 | 把相关当因果；把样本结论当成总体定律 |
| **时间序列与增长** | 差分、自回归、索洛模型 | 宏观增长、ARIMA、协整、预测 | 对非平稳序列直接回归；把预测区间当点预测 |
| **资产生命周期** | 复利、折旧、现金流 | 会计确认、税务扣除、资本预算、资产减值 | 会计折旧与税务折旧混用；账面价值当计税基础 |
| **企业价值与资本成本** | 折现、资本结构、MM 理论 | 财管估值、证券定价、并购、EVA | 把 WACC 当无风险利率；忽略现金流与折现率口径一致 |
| **并发、事务与锁** | 状态机、图、调度 | OS 同步、数据库 ACID、Java 并发 | 把互斥当可串行化；把线程安全当业务正确 |
| **存储、缓存与索引** | 地址映射、局部性、树 | 组成原理 Cache、虚存、数据库 B+树、JVM GC | 混淆命中率与缺失代价；忽略局部性与工作集 |
| **复杂度与模型选择** | 渐进分析、偏差—方差 | 数据结构、算法、机器学习调参 | 只看平均不看最坏；只看训练分数不看泛化 |
| **风险与控制** | 流程、证据、概率 | 审计、内控、战略风险管理 | 把“有制度”当“控制有效”；忽视证据链与执行频率 |

## 3. 符号口径速查

| 符号 | 常见含义 | 使用提醒 |
| --- | --- | --- |
| $r$ | 实际利率、要求收益率或模型内利率 | 经济模型、费雪方程、债券贴现率要按语境区分 |
| $i$ | 名义/年实际利率、收入或指标 | 利息理论中 $i^{(m)}$ 表示年名义利率，$i$ 表示年实际利率 |
| $y$ | 债券到期收益率 YTM | 不等于票面利率；非平坦曲线下也不能替代即期利率 |
| $D$ / $D^*$ | 麦考利久期 / 修正久期 | $D^*=D/(1+y/m)$；单位通常为年或期 |
| $C$ / $C^{M}$ | 名义收益率凸度 / 麦考利凸度 | 注意复利频率 $m$，不能混用两套二阶导口径 |
| $\alpha$ / $\beta$ | 学习率、显著性水平、CAPM 系统风险系数 | 机器学习与金融中的 $\alpha,\beta$ 无关，必须看上下文 |
| $\sigma^2$ | 方差、现金流时间方差或残差方差 | 组合方差用协方差矩阵；计量中还要区分同方差假定 |
| $\mathrm{MPC}$ / $\mathrm{MPS}$ | 边际消费倾向 / 边际储蓄倾向 | 两部门通常 $\mathrm{MPC}+\mathrm{MPS}=1$ |
| $\mathrm{ROIC}$ / $\mathrm{WACC}$ | 投入资本回报率 / 加权平均资本成本 | 财务战略矩阵纵轴用 $\mathrm{ROIC}-\mathrm{WACC}$ |
| $\mathrm{NPV}$ / $\mathrm{IRR}$ | 净现值 / 内部收益率 | 多重收益率时 IRR 失效，NPV 仍可用于互斥方案比较 |
| ACID / CAP | 事务原子性、一致性、隔离性、持久性 / 分布式一致性、可用性、分区容错 | CAP 的“三选二”是网络分区发生时的权衡，不是平时随意放弃两项 |
| $p$ / PTE | 缺页率 / 页表项 | 计算 EAT 时不要把缺页处理时间与普通访存时间重复计入 |

## 5. 四条路线的阶段检查

### CPA 路线

1. **会计关**：能否为一笔交易同时说出会计科目、计税基础和现金流影响？
2. **税法关**：能否区分会计扣除、税务扣除与暂时性/永久性差异？
3. **财管关**：能否把财报数据转成投资、融资与经营决策？
4. **审计关**：能否从认定出发设计证据，而不是只背审计程序？
5. **经济法/战略关**：能否把法律程序、治理与风险控制放进企业决策链？

### 408 路线

1. 能否手算时间复杂度、地址转换、缺页与磁盘访问时间？
2. 能否画出进程状态、TCP 握手、事务调度与流水线时空图？
3. 能否解释“为什么这样设计”，而不只记结论？
4. 能否把 C/Java 代码与内存、锁、集合、索引对应起来？

### 经济金融路线

1. 能否从假设推出均衡条件，再用图形和代数双重验算？
2. 能否区分相关、因果、显著性与经济意义？
3. 能否统一现金流、折现率、时间单位与风险口径？
4. 能否解释模型失效条件，而不是只记公式？

### 数据科学路线

1. 能否说明数据从原始表到模型矩阵的每一步？
2. 能否解释偏差—方差、正则化与模型容量？
3. 能否用 Pipeline 防止预处理泄露？
4. 能否根据业务代价选择 Precision、Recall、AP、ROC-AUC 或 RMSE？

## 6. 每周复盘法

- **周一**：选一条主线，只复习一个章节；先看先修知识，再看新课。
- **周三**：做 3—5 道计算题，必须写“已知 → 模型 → 求解 → 验算”。
- **周五**：用跨科表把一个概念解释给“另一科”听，例如用会计现金流解释债券定价。
- **周日**：做一次随机自测，记录错因属于“概念、公式、计算、审题、口径”哪一类。
